# 龍魂 DNA 追溯码规范 v2.0（焊死级）
生效: 2026-08-03 · 基线: 2026-07-19格式切换决议 · 扩展: 唯一性双锚
归属: 龍魂系统 · UID9622 · 确认码: #CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z

## 第一条 · 格式（唯一合法格式）
```
#龍芯⚡️{年干支}·{月干支}·{日干支}·{时辰}·{卦符卦名}-{动作标签}-{版本}-{日序号}-{哈希8}
```
实例（本规范实测输出）:
`#龍芯⚡️丙午·丁酉·己酉·未时·䷗复-DNA-GENERATOR-SPEC-v2.0-0001-d7ea5f95`

字段定义:
| 段 | 来源 | 说明 |
|---|---|---|
| 年干支 | (year-4)%10/%12 | 立春近似=公历年 |
| 月干支 | 五虎遁，正月建寅 | 公历月近似，节气精确版留升级口 |
| 日干支 | (JDN+49)%60 | 锚点2000-01-01=戊午，已双源校验 |
| 时辰 | (hour+1)//2%12 | 23:00起为子时 |
| 卦符卦名 | SM3首字节%64 | 王弼序，䷀乾…䷿未济，确定性可复现 |
| 动作标签 | 大写连字符 | 如 AUDIT-REPORT |
| 版本 | vX.Y | 语义化 |
| 日序号 | counter.json | 0001起，当日单调递增，持久化 |
| 哈希8 | SM3前8hex | 输入=标题|动作|版本|ISO时间|序号 |

## 第二条 · 唯一性（数学保证）
同一天内序号唯一 ⟹ DNA全局唯一；跨天日柱不同 ⟹ 天然不同。
哈希段为内容指纹，用于校验而非主唯一键。AI输出再多也不会重复。

## 第三条 · 旧码处置（P0：不删除只冻结）
2026-07-19前的时间戳格式、年-月-日连字符格式一律冻结。
用 `register` 命令登记入注册表（legacy标记），不追溯改写。

## 第四条 · 注册表（统一归类/拓展/压缩/恢复）
- 归类：category ∈ protocol/script/doc/paper/asset/log/intel/other（可在registry直接拓展）
- 压缩：`compress` 生成 gzip 快照至 registry/archive/
- 恢复：`recover --dna <码>` 输出元数据+全文（file_path在本机时）
- 校验：`verify` 检查注册状态+文件SHA256完整性
