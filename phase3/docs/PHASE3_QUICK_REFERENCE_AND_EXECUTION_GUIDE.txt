## 🔍 系统检查清单

### 环境检查

```bash
# 1. 检查 Docker
docker --version
# Expected: Docker version 20.10+

# 2. 检查 Docker Compose
docker-compose --version
# Expected: Docker Compose version 2.0+

# 3. 检查 Git（可选）
git --version

# 4. 检查磁盘空间
df -h
# 需要至少 5GB 可用空间
```

### 部署检查

```bash
# 1. 检查容器状态
docker ps
# 应该看到 longhun-backend 和 longhun-frontend

# 2. 检查后端健康状态
curl http://localhost:8000/api/v1/health
# 应该返回 JSON 格式的健康检查数据

# 3. 检查前端访问
curl http://localhost:3000
# 应该返回 HTML 页面

# 4. 检查 WebSocket 连接
curl -i -N -H "Connection: Upgrade" -H "Upgrade: websocket" \
  http://localhost:8000/ws/v1/stream
# 应该返回 101 Switching Protocols

# 5. 查看日志
docker-compose logs backend
docker-compose logs frontend
```

### 功能检查

```bash
# 1. 列出技能
curl http://localhost:8000/api/v1/skills

# 2. 创建技能
curl -X POST http://localhost:8000/api/v1/skills \
  -H "Content-Type: application/json" \
  -d '{
    "id": "/test",
    "name": "测试技能",
    "platform": "longhun",
    "category": "test",
    "priority": 5
  }'

# 3. 执行技能
curl -X POST http://localhost:8000/api/v1/skills/test/execute \
  -H "Content-Type: application/json"

# 4. 查看告警
curl http://localhost:8000/api/v1/alerts

# 5. 查看执行历史
curl http://localhost:8000/api/v1/logs?limit=10
```

## 🚨 故障排除

### 问题 1: Docker 无法启动

```bash
# 解决方案:
1. 确保 Docker Desktop 已运行
2. 重启 Docker: `docker-compose down` && `docker-compose up`
3. 检查端口占用: `lsof -i :8000` 和 `lsof -i :3000`
4. 清理旧容器: `docker-compose down -v`
```

### 问题 2: 前端无法连接后端

```bash
# 解决方案:
1. 检查环境变数: cat longhun-phase3/.env
2. 确保 API_URL 正确: http://localhost:8000/api/v1
3. 检查 CORS 设置: 查看 main.py 中的 CORSMiddleware
4. 查看浏览器控制台错误信息
```

### 问题 3: API 返回 404

```bash
# 解决方案:
1. 检查端点名称是否正确
2. 确保路由已注册: curl http://localhost:8000/api/docs
3. 查看后端日志: docker-compose logs backend
4. 检查请求方法: GET/POST/PUT 是否正确
```

### 问题 4: 内存或 CPU 过高

```bash
# 解决方案:
1. 检查容器资源限制: docker stats
2. 重启服务: docker-compose restart
3. 清理未使用的镜像: docker image prune
4. 检查后端日志中的无限循环或内存泄漏
```
