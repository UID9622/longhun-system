## 🔍 系統檢查清單

### 環境檢查

```bash
# 1. 檢查 Docker
docker --version
# Expected: Docker version 20.10+

# 2. 檢查 Docker Compose
docker-compose --version
# Expected: Docker Compose version 2.0+

# 3. 檢查 Git（可選）
git --version

# 4. 檢查磁盤空間
df -h
# 需要至少 5GB 可用空間
```

### 部署檢查

```bash
# 1. 檢查容器狀態
docker ps
# 應該看到 longhun-backend 和 longhun-frontend

# 2. 檢查後端健康狀態
curl http://localhost:8000/api/v1/health
# 應該返回 JSON 格式的健康檢查數據

# 3. 檢查前端訪問
curl http://localhost:3000
# 應該返回 HTML 頁面

# 4. 檢查 WebSocket 連接
curl -i -N -H "Connection: Upgrade" -H "Upgrade: websocket" \
  http://localhost:8000/ws/v1/stream
# 應該返回 101 Switching Protocols

# 5. 查看日誌
docker-compose logs backend
docker-compose logs frontend
```

### 功能檢查

```bash
# 1. 列出技能
curl http://localhost:8000/api/v1/skills

# 2. 創建技能
curl -X POST http://localhost:8000/api/v1/skills \
  -H "Content-Type: application/json" \
  -d '{
    "id": "/test",
    "name": "測試技能",
    "platform": "longhun",
    "category": "test",
    "priority": 5
  }'

# 3. 執行技能
curl -X POST http://localhost:8000/api/v1/skills/test/execute \
  -H "Content-Type: application/json"

# 4. 查看告警
curl http://localhost:8000/api/v1/alerts

# 5. 查看執行歷史
curl http://localhost:8000/api/v1/logs?limit=10
```

## 🚨 故障排除

### 問題 1: Docker 無法啟動

```bash
# 解決方案:
1. 確保 Docker Desktop 已運行
2. 重啟 Docker: `docker-compose down` && `docker-compose up`
3. 檢查端口佔用: `lsof -i :8000` 和 `lsof -i :3000`
4. 清理舊容器: `docker-compose down -v`
```

### 問題 2: 前端無法連接後端

```bash
# 解決方案:
1. 檢查環境變數: cat longhun-phase3/.env
2. 確保 API_URL 正確: http://localhost:8000/api/v1
3. 檢查 CORS 設置: 查看 main.py 中的 CORSMiddleware
4. 查看瀏覽器控制台錯誤信息
```

### 問題 3: API 返回 404

```bash
# 解決方案:
1. 檢查端點名稱是否正確
2. 確保路由已註冊: curl http://localhost:8000/api/docs
3. 查看後端日誌: docker-compose logs backend
4. 檢查請求方法: GET/POST/PUT 是否正確
```

### 問題 4: 內存或 CPU 過高

```bash
# 解決方案:
1. 檢查容器資源限制: docker stats
2. 重啟服務: docker-compose restart
3. 清理未使用的鏡像: docker image prune
4. 檢查後端日誌中的無限循環或內存泄漏
```
