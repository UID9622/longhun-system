## Description

龍魂三核心優化器（LongHun 3-Core Optimizer）是龍魂體系的核心性能優化模塊，整合五大子系統提供完整的三才主權計算、七因子行為驗證、認知狀態管理、技能路由和人格決策能力。

### 五大優化模塊

1. **三才主權指數系統 (SI)** ~410行: 人/地/天三維權重動態調整，激活/削弱/失錨三態判定，自適應權重優化，趨勢預測
2. **F1-F7七因子驗證系統** ~620行: 行為密碼學指紋生成（BLAKE2b加速），乘積置信度模型（對數空間計算），LRU緩存，批量驗證
3. **認知DNA粒子系統** ~520行: 認知狀態二進制壓縮/恢復（struct+zlib），SI條件激活，情感摺疊優化，8維情感量化
4. **執行路由器系統** ~480行: manifest.json加速解析（LRU緩存），位運算權限檢查，技能發現引擎，並行掃描
5. **人格路由系統 (PersonaRouter)** ~550行: Aho-Corasick自動機虛偽詞彙4分類檢測，加權人格決策，5人格動態路由

### 核心優化點

| 優化項 | 技術 | 加速比 |
|--------|------|--------|
| 行為指紋 | BLAKE2b替代多次SHA256 | 3-5x |
| 乘積置信度 | 對數空間+查找表 | 2-3x |
| 虛偽檢測 | AC自動機O(n) | 10-50x |
| 權限檢查 | 位運算+LRU緩存 | 5-10x |
| 狀態壓縮 | struct二進制+zlib | 3-5x |

## Error Handling

| 錯誤碼 | 描述 | 處理策略 |
|--------|------|----------|
| `SI-E001` | 權重總和不為1.0 | 自動正規化並記錄警告 |
| `SI-E002` | 閾值配置矛盾 | 拒絕配置，返回錯誤列表 |
| `7F-E001` | 緩存溢出 | LRU淘汰最舊條目 |
| `7F-E002` | 指紋碰撞 | 增加迭代次數或數據長度 |
| `DNA-E001` | 壓縮數據損壞 | zlib解壓失敗，跳過該粒子 |
| `DNA-E002` | 校驗和失敗 | 記錄異常，丟棄損壞粒子 |
| `RT-E001` | 技能未找到 | 返回404，建議掃描路徑 |
| `RT-E002` | 權限不足 | 返回403，記錄訪問嘗試 |
| `PR-E001` | AC自動機構建失敗 | 回退到簡單字符串匹配 |
| `PR-E002` | 人格決策平局 | 使用歷史偏好打破平局 |

## Notes

### 君子協議 (Junzi Protocol)

1. **不篡改歷史**: 所有歷史粒子記錄一經寫入不可修改，僅可追加
2. **配置審計**: 任何配置變更必須記錄時間戳和變更原因
3. **權重正規化**: 三才權重總和必須嚴格等於1.0，否則自動正規化
4. **透明決策**: 人格路由決策必須提供可解釋的切換原因
5. **數據完整性**: 每個粒子都包含SHA256校驗和，確保未被篡改
