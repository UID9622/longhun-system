## 一、仓储区域划分（必查项）

### 1.1 标准区域要求

根据《温州电商仓储管理制度》，仓库必须划分以下专用区域：

| 区域名称 | 功能说明 | 标识要求 | 必查 |
|----------|----------|----------|------|
| **待检区** | 新到货物等待质检的区域 | 黄色标识/地标 | 🟢 必查 |
| **合格区** | 质检通过可上架销售的区域 | 绿色标识/地标 | 🟢 必查 |
| **不合格区** | 质检不通过需隔离的区域 | 红色标识/地标 | 🟢 必查 |
| **待发区** | 已打包等待发货的区域 | 蓝色标识/地标 | 🟢 必查 |
| **退货区** | 客户退货商品暂存区域 | 橙色标识/地标 | 🟢 必查 |
| **呆滞品区** | 长期滞销商品存放区域 | 灰色标识/地标 | 🟡 建议 |
| **耗材区** | 包材/耗材存放区域 | 白色标识/地标 | 🟡 建议 |
| **设备区** | 叉车/地牛等设备停放区 | 黑色标识/地标 | 🟡 建议 |

### 1.2 区域管理检查表

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 区域划分清晰 | 物理隔离，地标线清晰 | 3分 |
| 标识规范 | 区域标识牌统一规范 | 2分 |
| 区域台账 | 各区域面积/容量有台账 | 2分 |
| 区域清洁 | 各区域定期清洁维护 | 2分 |
| 通道畅通 | 消防通道≥1.2米，主通道≥2米 | 1分 |

## 二、不合格货物处理（必查项）

### 2.1 处理流程

```
发现不合格品 → 立即隔离 → 标识不合格标签 → 记录不合格台账 
→ 通知相关人员 → 判定处理方式 → 执行处理 → 记录处理结果 → 归档
```

### 2.2 处理方式

| 处理方式 | 适用场景 | 审批要求 |
|----------|----------|----------|
| **退货** | 供应商来货不合格 | 仓库主管审批 |
| **报废** | 过期/破损无法销售 | 仓库主管+品控审批 |
| **降级** | 轻微瑕疵可折价销售 | 品控+运营审批 |
| **返工** | 包装破损可重新包装 | 仓库主管审批 |
| **暂存** | 待供应商确认 | 记录暂存原因和期限 |

### 2.3 追溯要求（完整可追溯）

| 追溯要素 | 必须记录 | 分值 |
|----------|----------|------|
| 发现时间 | 精确到分钟 | 2分 |
| 发现人 | 操作人员签名 | 2分 |
| 不合格原因 | 具体不合格描述 | 2分 |
| 涉及批次 | 批次号/SKU/数量 | 2分 |
| 处理方式 | 退货/报废/降级/返工 | 2分 |
| 处理结果 | 实际处理结果记录 | 2分 |
| 处理人 | 处理人员签名 | 2分 |
| 审批记录 | 各级审批人签名 | 2分 |
| 照片留痕 | 不合格品照片存档 | 2分 |
| 供应商通知 | 供应商确认记录 | 2分 |

## 三、作业流程规范

### 3.1 标准作业流程（SOP）

```
收货 → 质检 → 上架 → 存储 → 拣货 → 复核 → 打包 → 发货 → 回传
```

每个环节必须有：
1. 操作标准（什么标准算合格）
2. 操作步骤（具体怎么做）
3. 检查要点（重点检查什么）
4. 异常处理（异常怎么办）
5. 记录要求（记录什么内容）

### 3.2 各环节检查要点

| 环节 | 检查要点 | 常见问题 |
|------|----------|----------|
| 收货 | 数量核对/外包装检查/单据匹配 | 短少/破损/错发 |
| 质检 | 抽检比例/检验标准/合格判定 | 标准不一/漏检 |
| 上架 | 库位指定/上架确认/系统更新 | 放错库位/未扫码 |
| 存储 | 堆码规范/先进先出/安全防护 | 超高堆码/混批 |
| 拣货 | 波次分配/路径优化/扫码确认 | 拣错/漏拣 |
| 复核 | 订单核对/数量核对/商品核对 | 复核流于形式 |
| 打包 | 包材选择/称重/贴单 | 包装不当/错单 |
| 发货 | 快递交接/回传状态/留底 | 漏发/状态未回传 |

## 四、5S管理要求

| S | 内容 | 要求 | 检查方法 |
|---|------|------|----------|
| **整理** | 要与不要分开 | 现场无无用物品 | 目视检查 |
| **整顿** | 定位定量摆放 | 物品有固定位置 | 现场检查 |
| **清扫** | 清除垃圾脏污 | 地面/货架清洁 | 现场检查 |
| **清洁** | 维持前3S成果 | 有清洁标准/制度 | 查制度+现场 |
| **素养** | 养成良好习惯 | 员工遵守规范 | 抽查员工 |

## 五、安全管理要求

### 5.1 消防安全

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 灭火器 | 每50㎡配2具，压力正常 | 2分 |
| 消防栓 | 水压正常，无遮挡 | 2分 |
| 应急灯 | 断电自动亮，每月测试 | 2分 |
| 疏散标识 | 指向清晰，无遮挡 | 2分 |
| 消防通道 | ≥1.2米，无堵塞 | 2分 |

### 5.2 防盗安全

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 监控覆盖 | 关键区域无盲区 | 2分 |
| 门禁管理 | 进出记录完整 | 2分 |
| 贵重品区 | 独立加锁区域 | 1分 |

### 5.3 环境安全

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 防潮 | 湿度≤70%，有除湿设备 | 2分 |
| 防虫 | 定期消杀，无虫害 | 1分 |
| 温控 | 温度0-30℃，有温控设备 | 2分 |

### 5.4 应急预案

| 检查项 | 要求 | 分值 |
|--------|------|------|
| 火灾预案 | 有火灾应急预案和演练 | 2分 |
| 水灾预案 | 有暴雨/漏水应急预案 | 1分 |
| 系统故障 | 有系统故障应急方案 | 2分 |
| 人员安全 | 有人员受伤应急处理 | 1分 |
