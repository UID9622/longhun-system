【三层防御机制】

第一层：PAUSE GATE（暂停闸）
  → 任何代码进入前都能暂停
  → 让你看清楚、想清楚、决策清楚
  → 用户交互式决策

第二层：DEEP TRANSLATION（深度转译）
  → 不只看代码，而是理解逻辑
  → 把代码转译成人类可读的步骤
  → 识别危险函数、外部调用、副作用

第三层：COMPREHENSIVE VERIFICATION（完整验证）
  → DNA签证验证
  → 底座原则检查
  → 环境一致性验证
  → 副作用评估
  → 最后确认

【5项安全检查】

1. 危险函数检测
   ✓ exec, eval, __import__, compile 等

2. 外部调用检测
   ✓ subprocess, os.system, shell=True 等

3. 文件操作检测
   ✓ 文件读写、删除、操作等

4. 网络操作检测
   ✓ HTTP请求、套接字、网络通信等

5. 底座原则检查
   ✓ 简体龍字、蒸馏、投机、违禁词等

【风险评分体系】

评分方式：
  危险函数      +20 分
  外部调用      +15 分
  文件操作      +10 分
  网络操作      +10 分
  底座违反      +30 分

风险等级：
  🔴 高风险 >= 50分   （禁止执行）
  🟡 中风险 25-49分   （需要审查）
  🟢 低风险 < 25分    （可以执行）
