【改进2】置信度融合算法

老：
  脚本置信度 = CNSH检查结果
  系统置信度 = 10维平均
  （两者独立，无法联合判断）

新：
  脚本_CNSH_conf = CNSH对齐检查
  系统_10维_conf = 10维平均
  
  if 脚本_CNSH_conf == 🔴:
      综合评分 = 🔴（拒绝）
  else:
      综合评分 = max(脚本_CNSH_conf, 系统_10维_conf)
      三色 = tricolor(综合评分)

这样确保：
  ✓ 代码底座错了，无论系统多健康都拒绝
  ✓ 系统不健康，脚本也不能执行
  ✓ 二者缺一不可
