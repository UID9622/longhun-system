Notion 免费算力使用方案 (老大说没美金的解决方案)
================================================================

核心思路:
  Notion 不参与"计算" (没 API 调用大模型)
  Notion 只做 "数据库 + 看板 + 协作"
  所有逻辑在本机 Python 跑 · 结果同步给 Notion 展示

四个免费用法:

┌─ 用法 1 · 通心译字典存 Notion Database ─────────────────────┐
│ 建一个 database:                                            │
│   - Chinese (title)                                         │
│   - Context (select)                                        │
│   - 释义 (text)                                             │
│   - English (text)                                          │
│   - Totem (text)                                            │
│   - Warning (text)                                          │
│                                                             │
│ 本机 tongxinyi.py 用 export_for_notion() 导出 JSON          │
│ 老大手动复制到 Notion (一次性) · 之后增量更新                │
│ 终端宝宝读取本机字典 JSON · 不调 Notion API                 │
└─────────────────────────────────────────────────────────────┘

┌─ 用法 2 · 执行日志看板 ─────────────────────────────────────┐
│ on_execute 的 logs/execute_trace.jsonl 在本机             │
│ 每日定时 tail -n 50 复制到 Notion 看板页 (手动 OK)        │
│ 看板展示: 今天跑了多少任务 / 五色分布 / 失败原因           │
│ 完全不调 API                                                │
└─────────────────────────────────────────────────────────────┘

┌─ 用法 3 · 身份验证审计链存 Notion ──────────────────────────┐
│ on_identity 输出 IdentityResult.to_yaml()                   │
│ 关键节点 (主控登录/拒绝事件) 手动复制到 Notion              │
│ Notion 当"永久审计档案" · 不可改                            │
└─────────────────────────────────────────────────────────────┘

┌─ 用法 4 · 任务卡片 Kanban ──────────────────────────────────┐
│ 老大在 Notion 建任务 (Card)                                 │
│ 标签: factors (五因子) + triadic (三才) + context           │
│ 终端宝宝读 Notion (用 notion-fetch · 已有 MCP)              │
│ 跑 on_execute 处理 · 结果回写 Notion 卡片状态               │
│                                                             │
│ ⚠ 这一条需要 Notion API · 但读卡片不烧 LLM tokens          │
│   (Notion API 本身免费 · 不要美金)                          │
└─────────────────────────────────────────────────────────────┘
