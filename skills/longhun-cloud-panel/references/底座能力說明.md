## 概述

底座能力是龍魂操作台的基礎支撐系統，包含三大核心模塊：龍盾安全、CNSH 中文編程、融合審計。所有模塊通過統一接口 `POST /panel/api/v1/foundation/call` 調用。

---

## 一、龍盾安全 (longhun-shield)

### 功能
- **身份認證** — 用戶身份驗證與令牌管理
- **權限控制** — 基於角色的訪問控制 (RBAC)
- **請求簽名** — HMAC-SHA256 請求簽名驗證
- **流量限制** — QPS 限流保護
- **入侵檢測** — 異常行為檢測

### 調用示例
```json
{
  "模塊名": "龍盾安全",
  "操作": "認證",
  "參數": {
    "用戶名": "admin",
    "密碼": "secure_password"
  }
}
```

### 響應示例
```json
{
  "認證狀態": "✅ 已認證",
  "令牌": "lh-token-a1b2c3d4e5f67890",
  "過期時間": "3600s"
}
```

## 二、CNSH 中文編程 (cnsh-core)

### 功能
- **中文變量名** — 全部變量/函數/類使用中文命名
- **繁體龍字** — 龍字統一使用繁體「龍」
- **DNA 追溯** — 每個模塊攜帶 DNA 標記
- **三色審計** — 紅(錯誤)·黃(警告)·綠(正常)
- **君子協議** — 不免責聲明

### 調用示例
```json
{
  "模塊名": "CNSH中文編程",
  "操作": "規範檢查",
  "參數": {}
}
```

### 響應示例
```json
{
  "規範檢查": "✅ 通過",
  "中文變量名": "✅ 啟用",
  "繁體龍字": "✅ 啟用",
  "DNA追溯": "✅ 啟用",
  "三色審計": "✅ 啟用",
  "君子協議": "✅ 啟用"
```

## 三、融合審計 (fusion-audit)

### 功能
- **日誌記錄** — 全量操作日誌記錄
- **行為追蹤** — 用戶行為分析與追蹤
- **異常告警** — 異常行為自動告警
- **合規檢查** — 規範合規性自動檢查
- **報表生成** — 審計報表自動生成

### 調用示例
```json
{
  "模塊名": "融合審計",
  "操作": "日誌查詢",
  "參數": {
    "限制": 100,
    "時間範圍": "24h"
  }
}
```

### 響應示例

```json
  "日誌條目": [...],

```
