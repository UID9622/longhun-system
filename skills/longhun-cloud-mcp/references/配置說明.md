## 2. 運行時配置（環境變量）

| 變量 | 默認值 | 說明 | 示例 |
|------|--------|------|------|
| MCP_PORT | 8443 | 服務端口 | 9000 |
| MCP_HOST | 0.0.0.0 | 監聽地址 | 127.0.0.1 |
| MCP_DEBUG | false | 調試模式 | true |
| MCP_LOG_LEVEL | INFO | 日誌級別 | DEBUG |

| MCP_MAX_CONCURRENT | 100 | 最大並發 | 200 |

## 5. 配置管理 API

```python

全部配置 = 配置.獲取全部()
端口配置 = 配置.獲取("安全", {})
```

