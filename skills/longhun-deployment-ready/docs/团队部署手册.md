## 1. 欢迎来到龍魂部署系统

本手册专为**新团队成员**编写，帮助你快速理解和掌握龍魂系统的部署流程。无需经验，按步骤操作即可完成部署。

### 1.1 什么是龍魂部署就绪系统？

龍魂部署就绪系统是一个**全自动部署检查与执行框架**，包含：

- **27项部署检查** - 覆盖环境、代码、依赖、配置、数据库、服务、监控、日志、备份
- **自动部署执行器** - 按步骤自动执行部署，支持分阶段和回滚
- **故障排查助手** - 12类常见问题的诊断与解决方案

### 1.2 部署流程概览

```

|  环境准备   | -> |  代码拉取   | -> |  依赖安装   | -> |  配置初始化 |
```

## 3. 详细部署指南

### 3.1 阶段一：环境准备 (步骤1-4)

**目标**: 确保运行环境满足最低要求

```bash
# 运行环境验证器
python3 scripts/环境验证器.py

# 它会检查：
# ✓ Python >= 3.9
# ✓ pip >= 21.0
# ✓ 操作系统兼容
# ✓ 内存 >= 512MB
# ✓ 磁盘 >= 5GB
# ✓ 端口可用
# ✓ Git已安装
# ✓ 网络工具可用
```

**常见问题**:
- Python版本低? 使用 pyenv 安装新版本: `pyenv install 3.11`
- pip太旧? 升级: `python3 -m pip install --upgrade pip`

### 3.2 阶段二：代码拉取 (步骤5-7)

**目标**: 获取正确的代码版本

```bash
# 验证Git仓库
git status
git log --oneline -5

# 检出指定版本
git checkout v5.2.0
```

### 3.3 阶段三：依赖安装 (步骤8-10)

**目标**: 安装所有Python依赖

```bash
# 安装依赖
python3 -m pip install -r requirements.txt

# 验证安装
python3 -m pip check

# 或使用环境验证器
python3 scripts/环境验证器.py
```

### 3.4 阶段四：配置初始化 (步骤11-13)

**目标**: 确保配置文件完整且安全

```bash
# 运行配置验证器
python3 scripts/配置验证器.py

# 它会检查：
# ✓ 配置文件存在
# ✓ 权限安全 (.env应为600)
# ✓ 敏感信息未硬编码
# ✓ 环境变量已设置
```

**设置环境变量**:

```bash
# 复制示例配置
cp .env.example .env

# 编辑必要变量
vim .env
# 至少设置:
#   APP_ENV=production
#   DATABASE_URL=postgresql://user:pass@localhost/dbname
#   SECRET_KEY=your-secret-key-here
```

### 3.5 阶段五：数据库准备 (步骤14-16)

**目标**: 数据库就绪且Schema最新

```bash
# 执行数据库迁移
alembic upgrade head

# 验证迁移状态
alembic current
alembic history
```

### 3.6 阶段六：服务启动 (步骤17-19)

**目标**: 服务正常启动

```bash
# 检查端口
python3 -c "
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.bind(('0.0.0.0', 8000))
print('端口8000可用')
sock.close()
"

# 启动服务
python3 -m uvicorn app:app --host 0.0.0.0 --port 8000

# 或使用启动脚本
./start.sh
```

### 3.7 阶段七：健康检查 (步骤20-22)

**目标**: 验证服务正常运行

```bash
# 检查健康端点
curl http://localhost:8000/health

# 预期返回:
# {"status": "ok", "version": "5.2.0"}
```

### 3.8 阶段八：监控配置 (步骤23-24)

**目标**: 监控和告警就绪

```bash
# 启动Prometheus (如已配置)
prometheus --config.file=prometheus.yml

# 配置Grafana数据源
# 参见 docs/DEPLOYMENT_GUIDE_v1.0.md
```

### 3.9 阶段九：日志确认 (步骤25)

**目标**: 日志正常输出

```bash
# 检查日志目录
ls -la logs/

# 查看应用日志
tail -f logs/app.log
```

### 3.10 阶段十：备份验证 (步骤26-27)

**目标**: 备份策略有效

```bash
# 执行备份
./backup.sh

# 验证备份文件
ls -la backups/

# 定期进行恢复演练 (手动步骤)
```

## 4. 故障排查速查表

### 4.1 遇到问题怎么办？

```bash
# 第一步：使用故障排查助手
python3 scripts/故障排查助手.py "你的错误信息"

# 第二步：查看日志
tail -n 100 logs/deploy-YYYYMMDD.log

# 第三步：运行检查器定位问题
python3 scripts/部署就绪检查器.py --step [问题步骤编号]
```

### 4.2 常见错误速查

| 错误信息 | 可能原因 | 快速解决 |
|----------|----------|----------|
| `Address already in use` | 端口被占用 | `kill -9 $(lsof -t -i :8000)` |
| `Connection refused` | 数据库未启动 | `sudo systemctl start postgresql` |
| `ModuleNotFoundError` | 依赖未安装 | `pip install -r requirements.txt` |
| `Permission denied` | 文件权限不足 | `chmod +x start.sh` |
| `KeyError: SECRET_KEY` | 环境变量未设置 | `export SECRET_KEY=xxx` |
| `alembic error` | 迁移失败 | `alembic downgrade -1` |

### 4.3 获取帮助

```bash
# 查看所有故障
python3 scripts/故障排查助手.py --list

# 交互式排查
python3 scripts/故障排查助手.py --interactive

# 查看部署手册
cat docs/DEPLOYMENT_GUIDE_v1.0.md
```

## 5. 高级用法

### 5.1 分阶段部署

```bash

python3 scripts/部署执行器.py --stage db       # 仅数据库
python3 scripts/部署执行器.py --stage service  # 仅服务启动
```

### 5.2 模拟部署 (不实际执行)

```bash
# Dry-run 模式
python3 scripts/部署执行器.py --dry-run
```

### 5.3 自动修复

```bash
# 检查器自动修复问题
python3 scripts/部署就绪检查器.py --fix

# 配置验证器自动修复权限
```

## 6. CI/CD 集成

### 6.1 GitHub Actions 示例

```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Run Readiness Check
        run: python3 scripts/部署就绪检查器.py --json
      - name: Execute Deployment
        run: python3 scripts/部署执行器.py --stage service
```

### 6.2 GitLab CI 示例

```yaml
# .gitlab-ci.yml
deploy:
  stage: deploy
  image: python:3.11
  script:
    - python3 scripts/部署就绪检查器.py
    - python3 scripts/部署执行器.py
  only:
    - main
```
