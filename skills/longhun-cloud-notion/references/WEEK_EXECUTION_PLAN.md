# 週執行計劃規範 (WEEK EXECUTION PLAN)

> DNA: #龍芯⚡️2026-06-19-LONGHUN-NOTION-v5.0

## 概述

本文檔定義龍魂體系每週執行計劃的標準格式與同步規範，用於指導 Notion 同步器自動化週報生成。

## 週報結構

### 1. 週次標識
- 格式: `YYYY-WNN` (例: 2026-W25)
- 週起始: 週一
- 週結束: 週日

### 2. 目標設定
- 每週開始時設定3-5個主要目標
- 目標需符合SMART原則
- 目標與龍魂體系整體路線圖對齊

### 3. 進度追踪
- 每日更新任務狀態
- 狀態分類: 已完成 / 進行中 / 阻塞 / 未開始
- 阻塞項需標記原因與預計解決時間

### 4. 團隊統計
- 每個成員本週完成任務數
- 技能掌握進度
- 整體完成率百分比

## 同步規範

### Notion 數據庫結構

| 屬性名 | 類型 | 說明 |
|--------|------|------|
| Name | Title | 任務名稱 |
| Status | Select | 狀態: 未開始/進行中/已完成/阻塞 |

## 自動化規則

1. **每週五 18:00** 自動生成週報
2. **每小時** 同步任務狀態
3. **每日凌晨** 執行DNA完整性檢查
4. 週報生成後自動推送至Notion週報數據庫

## 君子協議

- 所有數據必須真實準確
- 不得偽造任務完成狀態
- DNA標記必須完整保留
- 團隊統計應公平客觀
