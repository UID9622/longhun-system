# DNA 校驗協議 (DNA CHECK PROTOCOL)

> DNA: #龍芯⚡️2026-06-19-LONGHUN-NOTION-v5.0

## 概述

DNA校驗協議定義了龍魂體系數據完整性驗證的標準流程，確保每條數據都可追溯、可驗證、不可篡改。

## DNA 標記格式

### 結構
```
#龍芯⚡️{日期}-{項目}-{版本}
```

### 示例
```
#龍芯⚡️2026-06-19-LONGHUN-NOTION-v5.0
```

## 校驗哈希算法

### SHA-256 哈希
```python
源數據 = f"{數據標識}:{創建時間}:{來源技能}:{DNA標記}"
哈希值 = SHA256(源數據).hexdigest()[:16]
```

### 驗證流程
1. 讀取記錄的DNA哈希值
2. 重新計算期望哈希值
3. 比較兩個哈希值
4. 匹配 → 已驗證 / 不匹配 → 異常

## 校驗狀態

| 狀態 | 標記 | 說明 |
|------|------|------|
| 待驗證 | 🟡 | 新記錄，尚未驗證 |
| 已驗證 | 🟢 | 哈希匹配，數據完整 |
| 異常 | 🔴 | 哈希不匹配，數據可能被篡改 |

## 完整性分數

### 計算公式
```
完整性分數 = (已驗證記錄數 / 總記錄數) × 100%
```

### 等級
- 100%: 完美 (所有記錄驗證通過)
- 95-99%: 優秀 (少量待驗證)
- 80-94%: 良好 (部分異常需關注)
- <80%: 警告 (大量異常需立即處理)

## 定期檢查

### 檢查頻率
- 自動: 每6小時執行一次
- 手動: 隨時可觸發
- 重要操作前: 強制執行

### 檢查範圍
- 全部數據記錄
- 配置文件完整性
- 快取數據一致性

## 異常處理

### 發現異常記錄
1. 立即標記為異常狀態
2. 記錄禁止級審計日誌
3. 通知管理員
4. 嘗試從備份恢復

### 數據恢復
1. 從Notion重新拉取原始數據
2. 重新計算DNA哈希
3. 替換異常記錄
4. 驗證恢復結果

## 君子協議

- 不偽造DNA哈希值
- 不繞過校驗流程
- 及時處理異常記錄
- 保持校驗記錄透明公開
