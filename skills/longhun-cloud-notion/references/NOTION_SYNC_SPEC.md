# Notion 同步規範 (NOTION SYNC SPECIFICATION)

> DNA: #龍芯⚡️2026-06-19-LONGHUN-NOTION-v5.0

## API 配置

### 認證
- 方式: Bearer Token
- Header: `Authorization: Bearer {NOTION_API_KEY}`
- API版本: `Notion-Version: 2022-06-28`

### 速率限制
- 限制: 3 requests per second
- 超過限制返回 429 狀態碼
- Retry-After header 指示等待秒數

## 同步策略

### 雙向同步流程
1. **拉取階段**: 從Notion獲取最新數據
2. **比較階段**: 與本地快取比較差異
3. **衝突解決**: 以時間戳較新者為準
4. **推送階段**: 將本地變更推送至Notion
5. **驗證階段**: DNA校驗確保數據完整性

### 快取策略
- 本地JSON文件快取
- 記錄每條數據的最後同步時間
- 增量同步減少API調用

## 數據映射

### 任務狀態映射
| Notion狀態 | 本地狀態 |
|-----------|---------|
| Not started | 未開始 |
| In progress | 進行中 |
| Done | 已完成 |
| Blocked | 阻塞 |

### 優先級映射
| Notion優先級 | 本地優先級 |
|-------------|-----------|
| P0 | 緊急 |
| P1 | 高 |
| P2 | 中 |
| P3 | 低 |

## 錯誤處理

### 網路錯誤
- 自動重試3次
- 指數退避策略
- 超過重試次數記錄錯誤日誌

### 數據衝突
- 比較last_edited_time
- 以較新數據為準
- 記錄衝突解決決策

## 安全配置

### API密鑰管理
- 存儲於環境變量或本地配置文件
- 不在日誌中輸出完整密鑰
- 支持密鑰輪換

### 數據保護
- 本地快取文件設置適當權限
- 不傳輸敏感信息至未授權服務
