## 🐉 你的模式做什么

**模式名称:** 龍魂 · 君子协议
**标签:** 主权身份验证协议

| 要素 | 说明 |
|------|------|
| 付费对象 | 系统本身（不是内容，不是服务） |
| 付费理由 | 存在性证明（证明你是活人，不是机器人） |
| 金额 | 任意金额（≥1元），上不封顶 |
| 付费频率 | 每月一次（续费证明还在） |
| 回报 | '你在系统里被承认为君子'的身份 |
| 违约 | 不走法律，走耻辱柱（道德约束） |

> 你给我 1 块钱，我证明你是活人；你多给，我认可你的意愿；你违约，我公开记录。
