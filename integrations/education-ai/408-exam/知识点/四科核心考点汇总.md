# 第一篇：数据结构（45分）

## 1. 时间复杂度分析（必考1-2题）
- 常见复杂度排序：O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
- 循环分析、递归分析（主定理）

## 2. 线性表
| 操作 | 顺序表 | 单链表 | 双链表 |
|------|:---:|:---:|:---:|
| 按值查找 | O(n) | O(n) | O(n) |
| 按序号查找 | O(1) | O(n) | O(n) |
| 插入/删除 | O(n) | O(1)* | O(1)* |

> *已知插入位置指针时

## 3. 栈与队列
- **栈**：先进后出（LIFO）· 表达式求值· 括号匹配· 递归
- **队列**：先进先出（FIFO）· 循环队列· BFS
- **关键公式**：循环队列 `(rear + 1) % maxSize == front` 队满

## 4. 树与二叉树 ⭐核心章
- **二叉树性质**：
  - 第i层最多2^(i-1)个节点
  - 深度为k的二叉树最多2^k - 1个节点
  - n0 = n2 + 1（叶子数 = 度为2节点数 + 1）
  - 完全二叉树深度 d = ⌊log₂n⌋ + 1
- **遍历**：前序(NLR)、中序(LNR)、后序(LRN)、层次
  - 前+中 → 唯一确定二叉树
  - 后+中 → 唯一确定二叉树
- **线索二叉树**：利用空指针指向前驱/后继
- **哈夫曼树**：带权路径长度最小 · 哈夫曼编码（前缀编码）
- **堆**：小根堆/大根堆 · 堆排序 · 优先队列 ⭐新增考点

## 5. 图
- **存储**：邻接矩阵O(n²)、邻接表O(n+e)
- **遍历**：DFS（栈/递归）、BFS（队列）
- **MST最小生成树**：
  - Prim O(n²) — 稠密图
  - Kruskal O(e·loge) — 稀疏图
- **最短路径**：
  - Dijkstra O(n²) — 单源·无负权
  - Floyd O(n³) — 多源
- **拓扑排序**：AOV网 · 选入度为0 · 判断是否有环
- **关键路径**：AOE网 · 最早/最晚开始时间

## 6. 查找
- **二分查找**：O(logn) · 仅有序表
- **BST二叉搜索树**：左<根<右 · 中序递增
- **AVL平衡二叉树**：|平衡因子|≤1 · LL/RR/LR/RL旋转
- **红黑树**：5性质 · 查找O(logn)
- **B树/B+树**：多路平衡 · B+树所有关键字在叶子
- **散列表**：散列函数 · 冲突处理（拉链法、开放定址法）
- **KMP**：next数组 · O(m+n)

## 7. 排序 ⭐必考
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|:---:|:---:|:---:|:---:|:---:|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |
| 希尔 | — | O(n^1.3) | — | O(1) | ❌ |
| **快速** | O(nlogn) | O(nlogn) | O(n²) | O(logn) | ❌ |
| **堆** | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | ❌ |
| **归并** | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | ✅ |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | ✅ |

# 第二篇：计算机组成原理（45分）

## 1. 数据的表示与运算
- **补码**：[x]补 = 2^n + x（mod 2^n）
- **IEEE 754 单精度浮点数**：1位符号 + 8位阶码(偏置127) + 23位尾数
- **加减步骤**：对阶（小阶→大阶）→ 尾数加减 → 规格化 → 舍入 → 溢出判断

## 2. 存储系统 ⭐核心
- **SRAM vs DRAM**：
  - SRAM：触发器 · 快 · 贵 · Cache用
  - DRAM：电容 · 需刷新 · 主存用
- **Cache映射方式**：
  | 方式 | 优点 | 缺点 |
  |------|------|------|
  | 直接映射 | 简单 | 冲突多 |
  | 全相联 | 灵活 | 硬件复杂 |
  | **组相联** | 折中 | 最佳 |
- **命中率公式**：命中率 = 命中次数 / 总访问次数
- **平均访问时间**：MAT = 命中时间 + (1-命中率) × 失效开销
- **替换算法**：FIFO、**LRU**（最重要）、随机
- **写策略**：写直达(Write-through) · 写回(Write-back)
- **虚拟存储器**：页表、TLB快表、缺页中断

## 3. 指令系统
- **操作码** + **地址码**
- **RISC vs CISC**：
  | 特性 | RISC | CISC |
  |------|------|------|
  | 指令长度 | 固定 | 可变 |
  | 寻址方式 | 少 | 多 |
  | 实现 | 硬布线 | 微程序 |
- **9种寻址方式**：立即、直接、间接、寄存器、寄存器间接、相对、基址、变址、堆栈

## 4. CPU ⭐必考大题
- **CPU组成**：控制器(CU) + 运算器(ALU) + 寄存器组
- **指令周期**：取指→译码→执行→访存→写回（5阶段）
- **流水线**：
  - 加速比 S = 顺序执行时间 / 流水执行时间
  - 吞吐率 TP = n / Tk
  - **三种冒险**：结构(资源冲突) · 数据(RAW/WAR/WAW) · 控制(分支)
  - 解决数据冒险：**旁路技术（转发）**

## 5. 总线
- **分类**：片内总线、系统总线（数据/地址/控制）、通信总线
- **仲裁**：集中仲裁（链式查询、计数器、独立请求）
- **定时**：同步、异步、半同步

## 6. I/O系统
- **4种I/O方式对比**：
  | 方式 | CPU干预 | 传输单位 | 适用 |
  |------|:---:|:---:|------|
  | 程序查询 | 全程 | 字 | 低速 |
  | **中断** | 数据传送时 | 字 | 中速 |
  | **DMA** | 开始/结束 | 块 | 高速 |
  | 通道 | 极少 | 块组 | 大型机 |

# 第三篇：操作系统（35分）

## 1. 进程管理 ⭐大分值
- **进程5状态**：创建→就绪→运行→阻塞→终止
- **进程通信**：共享存储、消息传递、管道
- **调度算法**：
  | 算法 | 类型 | 特点 |
  |------|------|------|
  | FCFS | 非剥夺 | 简单，可能长等待 |
  | SJF/SPF | 非剥夺/剥夺 | 最短优先，需预测 |
  | 优先级 | 均可 | 可能饥饿 |
  | 高响应比 | 非剥夺 | R=(等待+服务)/服务 |
  | **时间片轮转** | 剥夺 | 分时系统 |
  | **多级反馈队列** | 剥夺 | 最通用 |
- **PV操作** ⭐必考大题
  - P(S)：S.value--；若<0，阻塞
  - V(S)：S.value++；若≤0，唤醒
  - 经典问题：生产者-消费者、读者-写者、哲学家进餐
- **死锁**：
  - 4必要条件：互斥·不可剥夺·请求保持·循环等待
  - **银行家算法**：安全序列判断
  - 死锁定理：(RAG)资源分配图不可完全化简

## 2. 内存管理
- **连续分配**：单一连续·固定分区·**动态分区**（首次/最佳/最坏适应）
- **分页**：页号+页内偏移 · 页表
- **分段**：段号+段内偏移 · 段表
- **段页式**：段号→页号→页内偏移
- **页面置换算法**：
  | 算法 | 说明 | Belady异常 |
  |------|------|:---:|
  | OPT | 理论最优 | — |
  | FIFO | 先进先出 | ✅有 |
  | **LRU** | 最近最久未用 | ❌无 |
  | CLOCK/NRU | 近似LRU | ❌无 |
  | 改进CLOCK | 考虑修改位 | ❌无 |
- **抖动**：频繁缺页，CPU利用率低

## 3. 文件管理
- **文件逻辑结构**：无结构(流式) · 有结构(记录式)
- **文件物理结构**（分配方式）：
  | 方式 | 优点 | 缺点 |
  |------|------|------|
  | 连续分配 | 简单·快速 | 外碎片 |
  | 链接分配 | 无碎片 | 随机访问慢 |
  | **索引分配** | 随机访问 | 索引表开销 |
- **目录结构**：单级→两级→树形→无环图
- **磁盘调度**：FCFS·SSTF·SCAN(电梯)·C-SCAN

## 4. I/O管理
- **I/O控制方式**：程序直接→中断驱动→DMA→通道
- **SPOOLing**：假脱机 · 输入井/输出井
- **缓冲区**：单缓冲·双缓冲·循环缓冲·缓冲池

# 第四篇：计算机网络（25分）

## 1. 体系结构
- **OSI 7层** vs **TCP/IP 4层**：
  ```
  OSI: 应用→表示→会话→传输→网络→数据链路→物理
  TCP/IP: 应用→传输→网际→网络接口
  教学5层: 应用→传输→网络→数据链路→物理
  ```
- **封装过程**：数据→段(TCP头)→包(IP头)→帧(帧头尾)→比特流

## 2. 物理层
- **奈奎斯特**：理想信道最大速率 = 2W·log₂V
- **香农定理**：有噪声最大速率 = W·log₂(1+S/N)
- **复用**：FDM(频分)·TDM(时分)·WDM(波分)·CDMA(码分)

## 3. 数据链路层
- **三种可靠传输协议**：
  | 协议 | 窗口 | 效率 |
  |------|:---:|:---:|
  | 停等 | 1 | 低 |
  | GBN | N | 中 |
  | **SR** | N | 高 |
- **CSMA/CD**（以太网核心）：
  - 先听后发·边发边听·冲突停发·延迟重发
  - 最短帧长 = 2τ × 数据率
  - 二进制指数退避算法
- **VLAN** ⭐新增：802.1Q标签·隔离广播域

## 4. 网络层
- **IP地址分类**：A(1-126)·B(128-191)·C(192-223)·D·E
- **子网划分**：子网掩码 · CIDR（无分类编址）
- **NAT**：私有↔公网地址转换
- **路由协议**：
  | 协议 | 类型 | 算法 | 适用范围 |
  |------|------|------|------|
  | RIP | IGP | 距离向量 | 小型 |
  | OSPF | IGP | **链路状态(Dijkstra)** | 大中型 |
  | BGP | EGP | 路径向量 | 自治系统间 |
- **SDN** ⭐新增：控制平面与数据平面分离·可编程

## 5. 传输层 ⭐核心
- **TCP vs UDP**：
  | 特性 | TCP | UDP |
  |------|:---:|:---:|
  | 连接 | 面向连接 | 无连接 |
  | 可靠性 | 可靠 | 不可靠 |
  | 头部 | 20B | 8B |
  | 应用 | HTTP/FTP | DNS/视频 |
- **TCP连接管理**：
  - **三次握手**：SYN→SYN-ACK→ACK
  - **四次挥手**：FIN→ACK→FIN→ACK
- **TCP拥塞控制** ⭐必考：
  ```
  慢启动(cwnd指数增长) → 到达ssthresh → 
  拥塞避免(cwnd线性增长) → 超时 →
  ssthresh = cwnd/2, cwnd = 1 → 慢启动
  [快重传: 3个重复ACK] → 
  快恢复: ssthresh = cwnd/2, cwnd = ssthresh
  ```

## 6. 应用层
- **DNS**：域名→IP · 递归查询/迭代查询 · UDP 53端口
- **HTTP**：请求-响应 · 状态码(200/301/302/304/404/500)
- **FTP**：控制连接21 + 数据连接20
- **SMTP**：发邮件 · TCP 25
- **POP3/IMAP**：收邮件 · 110/143
- **DHCP**：Discover→Offer→Request→Ack · UDP 67/68
