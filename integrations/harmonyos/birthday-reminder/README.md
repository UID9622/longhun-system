## 📐 项目定位

鸿蒙原生团队生日提醒应用，深度集成龍魂人格系统和情感协议。

### 核心能力

| 维度 | 说明 |
|------|------|
| **人格联动** | 10个活跃人格各司其职（宝宝编排、李白祝福、鲁班定时、诸葛亮规划...） |
| **情感分级** | 5级关系（密友/队友/同事/领导/伙伴）→ 不同共情·温暖·边界参数 |
| **祝福智能生成** | 5种人格风格（诗意/暖心/正式/豁达/传统），一键切换 |
| **农历引擎** | 1900-2100完整农历转换，自动识别农历生日 |
| **生肖干支** | 自动推算生肖、天干地支 |
| **数据安全** | 本地加密存储(S2级) · DNA签名 · 审计追踪 · 不上传云端 |
| **办公交互** | 导入导出 · 分享 · 群发祝福 · 系统日历同步 |

### 对比原始版本的增强

| 无成员编辑弹窗 | 完整编辑/详情/祝福编辑器 |
| 仅列表 | 5标签（全部/7天/今天/本月/仪表盘） |
| 无关系体系 | 密友·队友·同事·领导·伙伴 五级 |
