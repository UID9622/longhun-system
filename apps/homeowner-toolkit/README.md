## 快速上手（3步）

### 第一步：发现物业违规
1. 打开 `docs/01-取证SOP.md` → 按"黄金30分钟"操作
2. 截图 + 录屏 + 区块链存证（10元焊死）
3. 打开 `docs/02-法律文书模板.md` → 选对应模板填空

### 第二步：发函施压
1. 打印函件 → EMS邮寄物业/业委会
2. 同步提交 12345 + 政府信息公开申请
3. 设定7天死线，超期自动升级

### 第三步：聚合业主
1. 终端运行 `python3 vote.py`
2. 把弹出的局域网地址发到业主群
3. 业主连同一 WiFi，浏览器打开链接投票
4. 数据存在 `votes.json`，纯文本，随时查看

## 升级路径

```
Day 0:  发现违规 → 取证 → 发函
Day 7:  物业不理 → 12345 + 信息公开
Day 22: 12345无果 → 信访 / 纪委监委
Day 37: 信息不公开 → 行政复议
Day 60: 复议无果 → 行政诉讼 / 民事诉讼
```

每一步该做什么，SOP 里写得清清楚楚。
