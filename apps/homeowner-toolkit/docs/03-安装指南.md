## 一、截图录屏取证工具

### ShareX（Windows，推荐）

```
下载：https://getsharex.com/
安装：下载 .exe，双击安装，全程默认
配置：
  1. 打开 ShareX → 截图后任务 → 添加"图像水印"
  2. 水印内容：%dt:yyyy-MM-dd HH:mm:ss（自动加时间戳）
  3. 保存路径：D:\龍魂取证\%y-%mo-%d\

快捷键：
  PrintScreen          → 全屏截图
  Ctrl+PrintScreen     → 区域截图
  Shift+PrintScreen    → 录屏
```

### Flameshot（Mac / Linux）

```
Mac 安装  : brew install flameshot
Linux 安装: sudo apt install flameshot
使用      : flameshot gui（选区截图，自带标注工具）
```

## 二、PDF 编辑 + 数字签名

### LibreOffice（全平台，免费）

```
下载：https://www.libreoffice.org/download/
安装：按提示安装
使用：
  1. 打开 LibreOffice Draw
  2. 拖入图片/截图 → 导出为 PDF
  3. 工具 → 数字签名 → 选择你的 GPG 证书

你已有 GPG 密钥，直接用来签名 PDF，防篡改。
```

## 四、本地投票系统（数据不进互联网）

### 使用 `vote.py`

本工具包自带的投票脚本，零依赖，双击/终端即可运行。

```bash
# Mac / Linux 终端
cd 本工具包目录
python3 vote.py

# Windows
# 双击 vote.py 或在命令行运行 python vote.py
```

运行后会打印：
```
============================================================
  🐉  龍魂业主投票系统 v1.1
============================================================
  本机访问 : http://localhost:8080
  局域网访问: http://192.168.x.x:8080
```

将局域网地址发到业主群，业主连同一 WiFi 后浏览器打开即可投票。

特性：
- 零依赖，仅需 Python 3（Mac/Linux 自带）
- 数据保存在 `votes.json`，纯文本随时查看
- 同一房号可更新投票（覆盖旧票）
- 自动检测可用端口（8080-8090）
- 前端实时显示结果

## 五、文件归档加密

### 7-Zip（全平台，免费开源）

```
下载：https://www.7-zip.org/
使用：
  1. 选中证据文件夹 → 右键 → 7-Zip → 添加到压缩包
  2. 格式选 zip 或 7z
  3. 加密方式选 AES-256
  4. 输入密码（建议 16 位以上，字母+数字+符号）
  5. 压缩包 = 加密证据袋，U盘备份 + 云盘双备份
```

### 纯文本待办（最稳，不依赖任何软件）

创建一个文本文件 `维权进度.txt`：

```
2026-08-01 [DONE]     截图取证，区块链存证
2026-08-02 [TODO]     打印函件，EMS 邮寄物业
2026-08-09 [DEADLINE] 物业答复期限（7天）
2026-08-10 [TODO]     如未答复，12345 投诉
2026-08-17 [DEADLINE] 政府信息公开答复（15天）
...
```

每天早上打开看，做完打勾，超期标红。

### Mac / Linux：crontab + 弹窗

```bash
# 终端输入：crontab -e
# 添加以下行（每天9点提醒检查进度）：
0 9 * * * osascript -e 'display notification "检查维权进度！" with title "龍魂提醒"'
```

### Windows：任务计划程序

创建基本任务 → 每天触发 → 显示消息。
