## 第一步：发现违规 → 立即固化（黄金 30 分钟）

### 1.1 截图规范

- **全屏截图**：包含网址栏、时间、页面完整内容
- **关键信息红框标注**：金额、日期、签名、公章
- **连续截图**：如果页面很长，分段截，确保每段有重叠区域

### 1.2 录屏规范（比截图更强）

- 打开手机/电脑录屏，**从打开浏览器/APP 开始录**
- 边录边念："今天是 2026 年 X 月 X 日，我现在打开 XX 小区物业公众号，查看公共收益公示，发现以下问题……"
- 录完立即导出，**不要编辑**，原始文件 = 证据原件

### 1.3 区块链存证（10 元焊死，法院认可）

## 第二步：EMS 邮寄（国家时间戳，最便宜的公证）

### 2.1 为什么要 EMS？

- 邮政是"国家信使"，EMS 底单 = 官方送达证明
- 对方"没收到"？EMS 有签收记录，法院直接认
- 比公证处便宜 90%，效果一样

### 2.2 操作清单

1. 打印所有材料（截图、函件、证据清单）
2. 装进 EMS 信封，**拍照留底**
3. 在 EMS 详情单"内件品名"写：
   ```
   《关于XX小区公共收益违规支出的函》及证据材料
   ```
4. 保留 EMS 底单（上面有快递单号）
5. 3 天后查签收记录，截图保存

## 第三步：政府信息公开（逼对方交账本）

### 3.1 申请什么？

向区/县住建局申请公开：
- 本小区维修基金缴存、使用明细
- 本小区物业服务合同备案
- 本小区业主大会备案材料
- 本小区公共收益监管账户流水

### 3.2 怎么申请？

1. 打开当地政府官网 → 搜索"政府信息公开"
2. 在线填写申请表（或用本包模板打印邮寄）
3. **15 个工作日内必须答复**
4. 答复内容不满意 → 行政复议（60 天内）
5. 复议不满意 → 行政诉讼

### 3.3 对方不答复？

= **违法**。直接行政复议，一告一个准。

## 第四步：业主聚合（匿名投票，不留靶子）

### 4.1 为什么匿名？

- 物业会找"带头业主"麻烦：停水、骚扰、威胁
- 匿名 = 保护战友

### 4.2 操作

1. 用本工具包的 `vote.py` 部署本地投票系统
2. 问题设计：
   ```
   您是否同意就物业违规使用公共收益一事，
   授权业主代表向政府投诉/起诉？

   □ 同意    □ 不同意    □ 弃权

   您的房号：____栋____室（仅用于统计面积/人数）
   联系方式：________（可选，用于接收进展）
   ```
3. 收集双过半：面积 2/3 + 人数 2/3（或依事项过半）
4. 统计结果打印，全体签字确认
