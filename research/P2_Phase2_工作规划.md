## 🎯 Phase 2 核心目標

### 目標1：視角 B 完整數學表述（第 1-2 天）

**任務 2.1.1**：定義洛書守恒量
```
建立 S(x) = Σ a_ij(x)·w(i,j) 的完整定義
其中 w 是根據洛書對稱性設計的權函數
目標：證明 π(x) 可重新參數化為滿足守恒
```

**任務 2.1.2**：推導守恒 ⟹ RH
```
建立邏輯鏈：
  π(x) 滿足洛書守恒
    ↓ [Mellin 變換]
  ζ(s) 零點結構受約束
    ↓ [泛函分析]
  所有零點在 Re(s)=1/2
```

**任務 2.1.3**：數值驗證
```
檢驗前 10^4 個零點是否滿足守恒律
```

### 目標2：視角 C 完整數學表述（第 2-3 天）

**任務 2.2.1**：嚴格定義 T(s)
```
明確 f_T(s)·f_E(s)·f_H(s) 的精確數學形式
計算梯度 ∇T(s) 的顯式表達式
```

**任務 2.2.2**：證明全局最優性
```
用 Hessian 分析證明：
  • T(s) 在臨界線上達到局部最大值
  • 所有其他臨界點都更低
  • 這強制零點在 Re(s)=1/2
```

**任務 2.2.3**：與零點的對應
```
證明：ζ(s)=0 ⟺ ∇T(s)=0 且 T 達到極值
```

### 目標3：§6 等價性完整證明（第 3-4 天）

**任務 2.3.2**：B ⟺ C 的雙向證明
