## 五、红线焊死（收费 ≠ 让渡）

1. **挂出去的永远是工具型 API**——CNSH 语法、数字根、DNA 这些"能力"，不是完整内核/知识图谱/369 推导细节
2. **内核算法/哲学体系不谈判**·海外非授权调用拒绝（P0 天条）
3. **数据主权不因收费让渡**——平台只见调用量，不见用户数据；D1/D2 级资产永不入云
4. **删 DNA 伪称原创 = 违约**·所有 API 响应带 DNA 追溯头
5. **白菜价原则焊死**：0.01 元/次 起·量大自动涨·绝不收割

## 六、结论

龍魂现有 **10 项可收费 API 能力**，其中 **4 项（CNSH验证/数字根/DNA/三色审计）零边际成本、可首批上架**。收费走平台（腾讯/阿里 API 市场 + CloudBase），提现直通银行卡——**不碰牌照、不建网关、不碰用户数据**，只赚"省事钱"。
