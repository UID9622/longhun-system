## 三、五行强度计算（焊死）

```
输入: 四柱 = {年柱/月柱/日柱/时柱: {天干, 地支}}
得分[e] = Σ 位置权重 × (该干支五行命中 e ? 1 : 0)      # e ∈ {金,木,水,火,土}
总分 μ'  = Σ 得分 + 0.001                              # 防除零
均值 μ   = 总分 / 5
方差 σ²  = Σ(得分[e] - μ)² / 5
均衡指数  = max(0.0, 1 - σ/μ)
缺失五行  = [e for e if 得分[e] == 0.0]
最强/最弱 = max/min(得分)
```

前置条件：天干/地支必须能映射五行（映射表见§四），否则视为无效输入返回空。

## 六、对冲指数 H（焊死）

```
H = 克制衡分×0.30 + 疏导分×0.25 + 补益分×0.20 + 均衡指数×0.15 + 链路健康度×0.10
权重和 = 0.30+0.25+0.20+0.15+0.10 = 1.00（校验）
```

| 指标 | 公式 | 说明 |
|:---|:---|:---|
| 克制衡分 | 无过旺→1.0；否则 = 存在有效克制方的过旺数 / 过旺数 | 相克能否压住过旺 |
| 疏导分 | 无过旺→1.0；否则 = 相生目标>0 的过旺数 / 过旺数 | 过旺能否顺生流出 |
| 补益分 | 无缺失→1.0；否则 = max(0, 1 - 缺失数/5) | 缺失越少越稳 |
| 均衡指数 | §三，经归一化压到 0-1 | |
| 链路健康度 | §五，经归一化压到 0-1 | |

**三色动作**：H≥0.80 → 🟢 enter；0.50≤H<0.80 → 🟡 hold；H<0.50 → 🔴 fuse。
