## 一、为什么要做激活经济？

龍魂系统不是资本黑箱，不靠卖 API 次数赚钱。
用户调用大模型用的是自己的算力或自己的 API，龍魂只是**入场券**——
这张入场券让用户获得：

- 龍魂人格矩阵加载权限
- 核心引擎调用权限（路径规划、MFA、审计等）
- 龍魂 DNA 追溯身份
- 国内合规的实名激活记录

激活收益模型：**站着要，凭支持进。**

## 二、经济主权设计

### 2.1 定价

| 项目 | 规则 |
|:---|:---|
| 起步价 | **1 元人民币** |
| 上限 | **无上限**，支持多次支付 |
| 周期 | 不限月/年，想付就付 |
| 性质 | 支持票 / 打赏 / 激活凭证 |
| 对象 | 个人、企业、组织均可 |

### 2.2 实名留痕

每一笔激活必须记录：

- 支付人真实姓名（或企业名）
- 支付金额
- 支付时间
- 订单号
- 交易单号（tx_id）
- DNA 追溯码
- 激活设备/账号绑定关系

**数据存储**：本地 `~/.longhun/payment_registry.json`，不上传第三方。

### 2.3 主权归属

- 支付记录属于 UID9622 / 龍魂系统本地资产
- 不依赖微信/支付宝/华为等平台的长期数据留存
- 平台只作为收款通道，龍魂本地保存激活主权账本
- 用户激活后，核心功能永久可用（除非主动解绑）

## 三、激活流程

```
用户选择金额（≥1元）
  ↓
系统生成订单 + DNA + 支付二维码
  ↓
用户扫码/转账并备注订单号
  ↓
用户回填交易单号（tx_id）
  ↓
系统确认到账 → 写入支付账本 → 发放激活票
  ↓
用户用激活票绑定 MFA → 正式启用龍魂核心功能
```

---

## 四、核心规则

1. **一元起步**：金额小于 1 元拒绝生成订单。
2. **上不封顶**：支持任意金额，多次支付。
3. **交易单号唯一**：同一 tx_id 不能重复确认，防重放。
4. **实名可选但推荐**：个人用户可匿名支付，企业用户必须实名。
5. **激活票可累加**：多次支付累计支持金额，记录在个人/企业档案。
6. **退款不删除**：只冻结退款记录，原 DNA 链保留。

---

## 五、与 MFA 的关系

支付激活是**经济层**，MFA 绑定是**安全层**。

- 只有完成支付的账号才能进入 MFA 绑定流程
- MFA 绑定后，设备获得核心引擎调用权限
- 解绑 MFA 不删除支付记录，只是关闭该设备权限

## 七、对接真实支付通道（预留）

当前默认实现为**本地订单登记 + 手动确认**。
如需自动回调，可配置环境变量接入官方 SDK：

```bash
export WECHAT_PAY_MCHID=xxx
export WECHAT_PAY_APIV3_KEY=xxx
export ALIPAY_APPID=xxx
export ALIPAY_PRIVATE_KEY=xxx
```

自动回调接口：`POST /api/payment/webhook/wechat` 与 `/api/payment/webhook/alipay`
