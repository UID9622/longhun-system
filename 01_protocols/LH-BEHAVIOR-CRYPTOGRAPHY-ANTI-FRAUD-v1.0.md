## 一、哲學根基：彎彎繞繞原理

### 1.1 核心命題
> **想要賺錢或幹嘛，直接表露出來就好了。彎彎繞繞的，肯定有原因。**

這個命題是行為密碼學反詐體系的哲學基石。它斷言了一個簡單但深刻的規律：

| 行為模式 | 信號 | 推論 |
|:---|:---|:---|
| 直接表達意圖 | 透明 | 可信度高 |
| 繞彎子表達 | 隱瞞 | 可信度低 |
| 繞很多彎子 | 套路 | 高度可疑 |
| 繞到最後才亮意圖 | 欺騙 | 🔴紅燈 |

### 1.2 為什麼「彎彎繞繞」= 可疑

1. **信息效率論**：正常溝通追求效率，直接說重點。繞彎子是在浪費雙方時間，浪費時間一定有目的——通常是在鋪墊情緒/降低防備。
2. **認知負荷論**：編造謊言需要更多認知資源。繞彎子的話術結構複雜，因為編的比真的難組織。
3. **意圖隱藏論**：如果意圖是正當的，沒有隱藏的必要。隱藏意圖 = 意圖有問題。

### 1.3 彎彎繞繞的三層結構

```
第一層：建立信任（我為你好/關心你/家人們）
       ↓
第二層：鋪墊情緒（講故事/製造焦慮/從眾壓力）
       ↓
第三層：亮出底牌（推薦產品/要你花錢/要你信息）
```

**規律**：層次越多，風險越高。直接亮底牌=正常銷售；三層以上=套路。

## 二、行為密碼學五大公理

### 公理一：意圖對稱律
> 表達的時間/篇幅應與意圖的重要性成正比。繞彎子=意圖與表達不對稱。

應用：核心信息字數 ÷ 總字數。低於0.2 = 🟡

### 公理二：主語明確律
> 可信的信息有明確的主語、來源、時間、地點。模糊化=不可信。

應用：模糊詞（可能/大概/據說/有人說）占比 > 40% = 🟡

### 公理三：反問推責律
> 被質疑時正面回答=可信；反問推責=迴避。連續2次反問=🔴

應用：不回答問題而反問「你說呢/你覺得呢/你想想看」= 🟡

### 公理四：時間自由律
> 允許你慢慢考慮的=可信；催促你馬上決定的=不可信。

應用：出現「限時/倒計時/不買就沒了/猶豫就會敗北」= 🟡

### 公理五：稱謂距離律
> 對陌生人群稱「家人/老鐵/自己人」=在製造虛假親近感。

應用：帶貨直播間出現「家人們」+促銷 = 🟡→🔴

## 四、識別算法：彎彎繞繞量化公式

### 4.1 彎繞指數（Winding Index, WI）

```
WI = α·IDR + β·TJR + γ·KWR + δ·QER + ε·VAR

其中：
  IDR (信息密度比) = 核心信息字數 / 總字數
  TJR (目標跳躍次數) = 話題方向變更次數
  KWR (關鍵詞迂迴度) = 1 - (關鍵詞首次出現位置 / 總字數)
  QER (反問反製度) = 反問次數 / 總對話輪次
  VAR (模糊主語率) = 模糊主語句子數 / 總句子數

權重 (α,β,γ,δ,ε) = (0.30, 0.20, 0.25, 0.15, 0.10)

判定：
  WI < 0.25 → 🟢 直接透明
  WI ∈ [0.25, 0.50) → 🟡 有點繞，保持警惕
  WI ∈ [0.50, 0.75) → 🟠 高度繞彎，大概率有問題
  WI ≥ 0.75 → 🔴 典型套路，立即拒絕
```

### 4.2 綜合風險評分（CRS）

```
CRS = Σᵢ wᵢ · sᵢ · dᵢ

其中：
  sᵢ ∈ {0,1} — 維度 i 是否被觸發
  dᵢ ∈ [0,1] — 維度 i 的嚴重程度
  wᵢ — 維度 i 的權重
  14個維度的權重向量 w = [0.10, 0.08, 0.04, 0.15, 0.05, 0.08, 0.12, 0.06, 0.08, 0.07, 0.05, 0.05, 0.04, 0.03]

判定：
  CRS < 0.20 → 🟢 低風險
  CRS ∈ [0.20, 0.40) → 🟡 中風險，謹慎
  CRS ∈ [0.40, 0.65) → 🟠 高風險，建議拒絕
  CRS ≥ 0.65 → 🔴 極高風險，立即拒絕+舉報
```

### 4.3 必紅燈規則（Hard Rules）

以下任一觸發 → 直接🔴，無需計算CRS：
1. 公檢法/安全賬戶/配合調查
2. 屏幕共享 + 金錢操作
3. 「不是廣告/純分享」+ 購買鏈接
4. 「順便推薦」出現在情感鋪墊後
5. 「帶你賺錢/跟著我」+ 要求付費
6. 「不用想/信我就完了」+ 催促下單
7. 3項以上必紅燈同時觸發 → 詐騙概率 > 95%

## 五、實戰模板：場景×話術×反制

### 5.1 彎彎繞繞推銷模板

| 階段 | 典型話術 | 行為密碼解讀 | 反制話術 |
|:---|:---|:---|:---|
| 建立信任 | 「我為你好才跟你說」 | 意圖隱藏，WI開場即升 | 「你直接說想幹嘛」 |
| 鋪墊故事 | 「我一個朋友之前也...」 | 故事型繞彎 I003 | 「你朋友的事跟我有什麼關係？」 |
| 製造共鳴 | 「你也有這種感覺對不對？」 | 反問卸責 I004 | 「別問我，說你自己」 |
| 亮底牌 | 「其實我有一個...順便推薦給你」 | 「順便」= 🔴信號 | 「這才是你想說的吧」 |
| 催促 | 「這個價格只有今天」 | 緊迫感 A001 | 「那我明天再買」 |
| 情感壓 | 「你不信我也沒辦法」 | 情感綁架 F | 「對，我不信。再見。」 |

### 5.2 偽科學實驗模板

| 實驗類型 | 演示內容 | 科學真相 | 反制話術 |
|:---|:---|:---|:---|
| 溶解實驗 | 產品放水裡溶解=好吸收 | 消化系統≠一杯水 | 「鹽溶解更快，所以我該喝鹽水治病？」 |
| pH試紙 | 產品是鹼性=健康 | 人體pH是恆定的 | 「我的胃酸pH=2，你要幫我調成鹼性嗎？」 |
| 碘伏褪色 | 產品讓碘伏褪色=抗氧化 | 這是氧化還原反應，維C也行 | 「檸檬汁也褪色，檸檬能治癌嗎？」 |
| 滲透實驗 | 產品滲透快=能進皮膚 | 透明紙≠角質層 | 「這張紙是我的皮膚嗎？」 |
| 磁場檢測 | 儀器顯示有能量 | 沒有科學證據 | 「把實驗方法發到Nature上再來找我」 |

### 5.3 抖音直播套路模板

| 套路 | 關鍵話術 | 本質 | 反制 |
|:---|:---|:---|:---|
| 砍價戲 | 「原價999，今天9塊9」 | 原價是編的 | 去淘寶搜同款看真實價格 |
| 雙簧 | 主播vs廠家「吵架」 | 都是同事 | 「每天吵架幾十場還不辭職？」 |
| 庫存緊張 | 「只剩10單」→又補貨 | 數字可隨便改 | 換號看庫存數是否一樣 |
| 家人收割 | 「家人們」→催下單 | 假親近真收割 | 「你連我叫什麼都不知道」 |
| 連麥問診 | 觀眾求助→主播分析→推產品 | 觀眾是演員 | 點主页看是不是空號/新號 |
