## 一、蒸馏器的定位（先钉死边界）

**龍魂蒸馏器 = 合法合规地把「有主知识」炼成「龍魂训练数据」的管道。**

三条铁律（焊死）：

1. **只蒸馏有主的东西，且主在龍魂**：自己写的代码、自己训练的对话、已授权/开源许可的内容（Apache-2.0/MIT/MulanPSL 等）、公开协议。
   → **禁止蒸馏**：他人未授权作品、版权小说/文章/视频、商业闭源产品输出。碰即 L1 数据熔断。
2. **蒸馏 ≠ 窃取**：对齐反蒸馏协议 L2 节流——只炼「知识/能力」，不搬运「原文表达」。
   → 炼化阶段强制改写+重述，保留推理链（reasoning_chain）而非原文。同时遵守「中国版权法第24条合理使用」与「AI生成内容双标识」（战后整顿协议）。
3. **蒸馏不损知识与能力**：入库前过「三保闸」——去重保质量、来源标注保主权、样本蒸馏度≤阈值保不被反向稀释。

> 反蒸馏协议是「防别人蒸我们」，蒸馏器是「我们合法炼自己」——同一 DNA 体系，方向相反，互为镜像。两个都要焊死。

## 三、合法合规矩阵（L1 核心规则）

| 源类型 | 允许? | 规则 | 熔断 |
|:---|:---:|:---|:---|
| 自有对话/代码/文档 | ✅ | 直接蒸馏·全程 DNA | — |
| 开源许可内容 | ✅ | 白名单许可（Apache-2.0/MIT/BSD/MulanPSL/CC-BY）·保留署名链 | 未在许可白名单=拒绝 |
| 公有领域/政府公开数据 | ✅ | 标注来源 | — |
| 学术摘要/论文 | 🟡 | 仅摘要·带链接·≤引用阈值 | 全文抓取=拒绝 |
| 版权作品（小说/影视/文章） | ❌ | — | L1 熔断 |
| 商业闭源模型输出 | ❌ | 非自有调用=拒绝 | L1 熔断 |

> 熔断执行：`lh_distill.py distill` 前自动跑 `compliance_check(source)`，失败即停，写审计日志。

## 四、不损知识与能力的三保闸（细化）

### 4.1 保质量（已有，强化阈值）
- quality_score ≥ 0.75（默认 0.7 上调）
- SimHash 全局去重（已实现）· 跨域去重新增：`domain + hash` 双键

### 4.2 保主权（血缘哈希链·复用反蒸馏 §5.3）
```
DNAₙ = SHA-256( DNAₙ₋₁ ‖ hash(内容) ‖ license ‖ UTC ) 取前128bit
```
每条样本必带字段：`dna / source / license / source_url / gpg_hash`
缺任一字段 → 不入库（P05 审计闸拦截）。

### 4.3 保能力（核心技能配额·新增）
- 蒸馏批次入库前统计：核心域（CNSH/DNA/369/人格/协议/审计）占比
- 配额：核心域 ≥ 20%，低于则本批驳回或补齐
- 防灾难性遗忘：关键技能样本永不删除，只增量（对齐「不删除只冻结」）
