## 二、可视化类型

### 2.1 类型一：人格权重矩阵热力图

```
生成: 20x20 热力图（x=发起人格, y=接收人格）
颜色: 权重0(深黑)→0.5(金)→1.0(白金)
数据源: 治理白皮书§2.1 人格权重分配表
用途: 一眼看出谁跟谁关系最紧密
```

### 2.2 类型二：意图路由桑基图

```
生成: 桑基图（Sankey Diagram）
流向: 用户意图→P00解析→分发给各人格→产出
宽度: 概率权重
颜色: 人格专属色
用途: 理解"一句话进来怎么分发的"
```

### 2.3 类型三：审计链路时间线

```
生成: 甘特图式时间线
显示: GATE-01~10 闸口审计流程
标注: 每个闸口责任人·耗时·三色标记
用途: 交付审计可视化
```

### 2.4 类型四：人格协作力导向图

```
生成: 力导向网络图
节点: 20个人格（大小=权重, 颜色=层级）
边: 协作关系（粗细=协作频率, 虚线=熔断）
动画: 实时任务流动
```

### 2.5 类型五：四层权重饼图

```
四层占比:
  战略层(P00+P01): 25%
  执行层(P02+P03+P04+P07+P14): 36%
  文化层(P08+P09+P10+P11+P12): 15%
  守护层(P05+P06+P13+P15+P72): 19%
  安全+子系统(P77+S1+S2+S3): 5%
```
