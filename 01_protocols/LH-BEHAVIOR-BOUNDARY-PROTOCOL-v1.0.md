## 一、协议定位

本协议是行为密码学七因子框架的**补充条款**，定义了内容在**私域/公域/指定社区**三种场景下的行为边界与责任归属规则。核心逻辑是：**私域不管，公域可查，乱发必追。**

## 二、行为边界三域划分

```
┌─────────────────────────────────────────────────────────────┐
│  🟢 私域 · 完全豁免                                        │
│  定义：点对点通信（含好友、家庭、情侣、亲密关系）           │
│  规则：不审计、不干预、不留公域痕迹                        │
│  示例：微信私聊 · 情侣密语 · 家庭群聊                      │
├─────────────────────────────────────────────────────────────┤
│  🟡 指定社区 · 有条件允许                                  │
│  定义：需验证身份的成年人社区（含兴趣圈、专业论坛、私密组） │
│  规则：必须留痕、可审计、可追溯                            │
│  示例：验证年龄的社区 · 行业论坛 · 付费社群                │
├─────────────────────────────────────────────────────────────┤
│  🔴 公域 · 全链路可查                                      │
│  定义：任何人可访问的平台（含微博、抖音、公众号、新闻评论）  │
│  规则：DNA全链路追索，责任人定位，违规即熔断               │
│  示例：抖音推荐流 · 微博公共话题 · 知乎公开回答            │
└─────────────────────────────────────────────────────────────┘
```

## 三、DNA三级授权码

每一条内容在生成时，DNA中嵌入**三级授权码**，定义其允许传播范围：

| 授权码 | 级别 | 含义 | 授权范围 |
|:---|:---|:---|:---|
| **A0** | 私域 | 仅限点对点，禁止公域传播 | 仅本人 + 接收方 |
| **A1** | 社区 | 指定社区可见 | 指定社区成员（需身份验证） |
| **A2** | 公域 | 全员可见 | 所有人（需全链路追溯） |

**DNA结构示例：**
```

                          ↑
                    授权码: A0/A1/A2
```

## 四、私域豁免条款

**条款4.1 私域内容免责**
- A0级内容不受三色审计的🔴级干预
- A0级内容**不进入公域审计流**
- A0级内容的DNA码**仅对发送方和接收方可见**

**条款4.2 私域内容不设限**
- 两个成年人之间的私域内容，不设内容限制
- 平台不得以"审核"为由截留A0级私域内容
- "打情骂俏"类内容不在公域、不在社区、只在私域，完全豁免

**条款4.3 私域截屏免责**
- A0级内容被截屏，DNA追溯码仍嵌于截屏中
- 若截屏被**故意**传播至公域，责任方为**截屏传播者**，非原始发送者

## 五、公域溯源条款

**条款5.1 公域内容强制DNA绑定**
- A2级内容必须在生成时**强制嵌入完整DNA追溯链**
- 包含：发送者ID、发送时间、发送地点（IP模糊）、内容指纹

**条款5.2 全链路追索**
- A2级内容在公域传播时，**每一跳（转发、复制、截图）**必须追加DNA子码
- 追加规则：`父DNA + 子DNA + 传播者身份 + 传播时间`
- 形成**不可篡改的传播树**

**条款5.3 责任人定位**
- 当A2级内容出现违规行为（如冒充、欺诈、恶意传播），回溯DNA链可定位到传播树上的**任意节点**
- 定位精度：**传播者身份码 + 时间窗 ± 5 分钟**

## 六、指定社区条款

**条款6.1 社区准入验证**
- A1级内容仅对**经过身份验证的成年用户**可见
- 验证方式：身份证年龄 + 自愿申请加入社区

**条款6.2 社区内部留痕**
- A1级内容在社区内部传播时，**必须留DNA追溯码**
- 留痕范围：发送者、发送时间、社区ID
- 社区管理员可查阅本社区的DNA追溯日志

**条款6.3 社区内容外溢**
- 若A1级内容被截屏/转发至公域，**DNA自动升级为A2级**
- 责任判定：**泄露者承担**，非社区全体成员

## 七、授权码定义与验证接口

| 内容类型 | 授权码 | 验证方式 |
|:---|:---|:---|
| 点对点私域 | A0 | 接收方身份 + 发送方身份（双向绑定） |
| 指定社区 | A1 | 社区ID + 用户身份（单社区绑定） |
| 公开传播 | A2 | 无限制，但全链路留痕 |

## 八、跨域传播的降级/升级规则

| 源 | 目标 | 规则 |
|:---|:---|:---|
| 私域 A0 | 社区 A1 | 需发送方**主动授权升级**，否则截屏自带水印 |
| 私域 A0 | 公域 A2 | 需发送方**双重授权**，否则截屏可追溯至传播者 |
| 社区 A1 | 公域 A2 | 自动升级，DNA标记泄露节点为**传播者** |
