## 一、设计理念

> **不管输出什么、审计什么，都走同一张表、同一条路径。**
> **结构优先、不遗漏、自动化、低算力。**

### 为什么需要统一模板？

| 问题 | 解决方案 |
|------|----------|
| 每次输出格式不统一 | 一张表管所有输出 |
| 审计时漏查项 | 清单式逐项勾选 |
| 不知道问自己什么 | 预设问题，逐项自检 |
| 版本迭代混乱 | 强制版本对齐 |
| 冲突发现不及时 | 前置冲突检测 |
