第三章 核心原则（天条，不可违背）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第1条：双视角焊死
  一切产出（规则/字典/审计/记忆/路由/页面/数据库/脚本/事件）必须
  M::×CNSH:: 双段封装。M::负责验收真假，CNSH::负责守住归属。
  标题是地址，正文是江山。

第2条：中文为体，机器为用（GAP-01分层裁决）
  人读层全中文：目录、文件名、注释、报告——一眼懂，维护不求人。
  机器层留原样：M::/CNSH::/DNA/CONFIRM/SEAL 是验收标识符，
  不是文件名，不译不动（译了机器就瞎）。
  两层各安其所，互不入侵——这不是妥协，是分工。

第3条：中文主版本（Q2焊点·GAP-02裁决）
  协议文档中文版是唯一权威版；英文版及一切后续语言版均为
  通心译镜像。镜像必须与主版本同版本号、同章节结构（4.3）。
  语义冲突时，中文版胜——中文即标准，不是翻译件。

第4条：扩展不破坏
  新语言 = 协议文档/ 下新建 {语言自名} 目录（Tiếng Việt/日本語/…），
  走双引擎流水线填空（6.4）。不动现有目录、不改现有文件、
  不碰他人镜像。

第5条：进来就得守（Q3焊点）
  使用龍魂能力即视为签署生态协议（第七章）：四允许、四禁止。
  准入不看声明看三锚——DNA/CONFIRM/SEAL 齐全才放行，缺一即拒（4.4）。

第四章 规则模型（每条设计可判定、可执行）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4.1 双视角一致性矩阵（M:: × CNSH:: 联动真值表）
  M::status 与 CNSH::policy 必须落在允许组合内，否则判 🔴 双视角分裂：
  | M::status | 允许 CNSH::policy | 对应三色 |
  |-----------|------------------|----------|
  | true      | pass             | 🟢 |
  | pending   | hold / rewrite   | 🟡 |
  | false     | hold / rewrite   | 🟡 |
  | error     | fuse             | 🔴 |
  一致性判定：C(m, p) = (m, p) ∈ 允许集。机器说 true 而路由说 fuse，
  或机器说 error 而路由说 pass——必有一环被篡改，立即熔断审查。

4.2 命名合规判定（Q1的数学形式）
  对路径 P 逐段判定：段 s 合规 ⟺ 含中文字符（[\u4e00-\u9fff]）
  ∨ s ∈ 机器层白名单（M::/CNSH::/DNA/CONFIRM/SEAL/README/English/
  .git/.sh/.py/.md 等扩展名与系统保留名）
  ∨ 主名为全大写机器约定（正则 ^[A-Z0-9_-]+$，如 README/LICENSE/
  LONGHUN_PROTOCOL——国际通用大写惯例，非"看不懂的小写英文名"）。
  人读层中文覆盖率：γ = 合规段数 / 总段数，硬要求 γ = 1.0。
  发现裸英文主名（如 longhun_rules_engine_v2.py）→ 🔴 拒收入库，
  查 v2→v3 对照表给出迁移建议（第五章）。

4.3 双版本同步判定（Q2的数学形式·GAP-02执行器）
  版本锁：V(中文版) = V(镜像版)，不等即 🔴。
  结构偏差率：δ = |n_中 − n_镜像| / max(n_中, n_镜像) ≤ 0.10
  （n = 章节/段落数），δ 超标 → 🟡 镜像待更新，并标注"以中文版为准"。
  语义冲突仲裁：中文版胜（第3条），镜像修订须回链主版本DNA。

4.4 生态三锚准入（Q3的数学形式）
  准入(A) ⟺ DNA(A) ∧ CONFIRM(A) ∧ SEAL(A) 三锚齐全且格式合法。
  与门判定，fail-closed：缺一锚 → 拒绝安装/拒绝接入 🔴。
  三锚格式（正则焊死）：
    DNA     = #龍芯⚡️YYYY-MM-DD-主题-vX.Y（繁体龍，不可简体）
    CONFIRM = #CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z

4.5 迁移兼容层（GAP-03，改名不断链）
  每个被改名的文件，在原路径留 symlink 指向新中文路径：
    旧路径 → 新路径（ln -s）
  兼容期 T = 90 天：期内旧引用照常工作，调用日志计数；

  铁律：兼容层是桥不是家——新代码一律直接引用中文路径。

  生态开放——门开在野，谁都来得了；但同人先有规矩，
  四允许四禁止就是那片野的篱笆。

  文件名是万物之母：名字看不懂，万物皆混沌；中文命名，让万物各有其母。

  命名也要有边界——机器层标识不译，就是"知止"，知止所以不殆。
