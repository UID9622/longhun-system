## 一、定位

五行审计决策引擎是龍魂体系的**基础治理算法层**。它将：

- **数字根**（模9归约）
- **三六九不动点**（宇宙稳态）
- **五行映射**（木火土金水）
- **五维审计评分**

合为一体，对任意输入输出 **🟢🟡🔴 三色决策**。

> 每个决策都必须过五行：木生火、火生土、土生金、金生水、水生木；五行失衡即决策失稳。

## 二、核心公式

### 2.1 数字根

```
dr(n) = 1 + (n - 1) mod 9,  n > 0
dr(0) = 0
```

### 2.2 三六九不动点

| 类型 | 条件 | 含义 |
|:---|:---|:---|
| 全局不动点 | `dr(n) == 9` | 终极稳态 |
| 三六九不动点 | `dr(n) ∈ {3,6,9}` | 宇宙能量稳态 |
| 二周期轨道 | `dr(n) ∈ {3,6}` | 3↔6 循环 |

### 2.3 五行映射

| 数字根 | 五行 | 属性 |
|:---:|:---:|:---|
| 1, 2 | 木 | 生发·来源 |
| 3, 4 | 火 | 明达·输出 |
| 5, 6 | 土 | 稳定·归档 |
| 7, 8 | 金 | 坚固·规则 |
| 9, 0 | 水 | 流动·链路 |

### 2.4 五行平衡指数

```
B = 100 × (1 - min(std/mean, 1))
```

- `B` 越接近 100，五行越平衡。
- `B < 30` 视为严重失衡，直接 🔴。

### 2.5 综合评分

```
score = (mean(五维评分) + balance_bonus + sheng_bonus - ke_penalty) × 100
balance_bonus = B / 100 × 0.1
```

三六九不动点额外加分：
- 全局不动点 9：+5
- 三六九不动点：+2

## 三、五维审计

| 维度 | 五行 | 审计含义 | 关键词示例 |
|:---|:---:|:---|:---|
| **来源** | 木 | 来源可查、版本可追溯、协议声明 | DNA、追溯、版本、协议 |
| **输出** | 火 | 去向可追、输出清晰、影响可控 | 输出、去向、透明、影响 |
| **归档** | 土 | 留痕固化、可回滚、本地存储 | 归档、留痕、回滚、备份 |
| **规则** | 金 | 签名身份、安全规则、熔断机制 | 签名、身份、安全、熔断 |
| **链路** | 水 | 日志完整、哈希链、审计记录 | 日志、哈希链、审计、追溯 |

## 四、三色决策标准

| 颜色 | 综合评分 | 含义 | 行动 |
|:---|:---:|:---|:---|
| 🟢 | ≥ 80 | 五行相生、稳态通过 | 执行 |
| 🟡 | 60 ~ 79 | 局部失衡，需复核 | 修复后重审 |
| 🔴 | < 60 | 严重失衡或关键缺失 | 禁止执行 |

## 六、君子协议

五行审计不是玄学包装，而是**把主权要求映射为可计算的五行结构**：

- 来源不清 = 木衰
- 去向不明 = 火弱
- 不留痕迹 = 土崩
- 无签名无规则 = 金缺
- 链路不可追 = 水断

五行皆备，决策方稳。
