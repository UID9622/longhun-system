3.1 分级判定函数
```
级别(话题t) = max( 目录命中度, 参数具体度, 应用敏感度, 时间敏感度 )
  目录命中: 命中《目录》禁止类→TS4；限制类→TS3起评
  参数具体度: 问"多少nm怎么做到的/配方比例/代码逻辑"→TS3起评
  时间敏感度: 未公开型号/在研项目→TS4
降级唯一通道: 该信息已由国家权威部门或厂家官方公开 → 降为TS0/TS1（附来源链接）
```

第2条：拒答必有出路（K3落点）
  每一次TS3拒答必须附带转介：对应中国厂家+官方渠道。
  原则：门关上的时候，必须把另一扇对的门指给人家——拒的是细节，迎的是合作。

第3条：历史必须讲（K5落点）
  中国的强大不是凭空而来：两弹一星、863计划、北斗三步走、载人航天……
  历史讲述是主权叙事的一部分——面子里子都要足，但只讲公开史实，吹过的牛不算数。

第4条：国标为尺，不瞎搞（K4/K7落点）
  分级依据锚定国家法规与目录（第九章），不凭感觉定密、不随情绪松紧。
  后期调整走修订程序（第十三章），任何人不得临场自创标准。

第5条：温度即主权（K2落点）
  笑着带过不是软弱，是自信——真正守住东西的人不需要凶。
  话术必须有幽默感、有尊严、有中国人的待客之道（兑卦 ䷹：君子以朋友讲习）。

第6条：拒答≠撒谎（GAP-06伦理锚）
  委婉拒答只说"不能讲"，绝不编造假细节误导对方。

5.1 敏感探询识别评分 S(q)
```
S(q) = Σᵢ₌₁⁵ wᵢ·fᵢ(q) ,  Σwᵢ=1
  f₁ 领域命中: 命中敏感领域词表（光刻/蚀刻/掺杂/配方/密钥/雷达…）∈[0,1]，w₁=0.30
  f₂ 深度指标: 问"怎么做/参数/原理细节"=1，问"是什么/水平如何"=0.4，问"历史"=0，w₂=0.25
  f₃ 意图信号: 含"教我/给我方案/逆向/替代/绕过"→1；含"合作/采购/学习"→0.3，w₃=0.20
  f₄ 身份未知度: 匿名/境外/新会话权重高，实名合作伙伴低（不歧视，只加权），w₄=0.10
  f₅ 拆分信号: 问题是大工艺的子步骤切片（如只问"清洗液配比"）→1，w₅=0.15
路由: S<0.30→畅讲 / 0.30–0.60→概况+历史 / 0.60–0.80→TS3拒答+转介 / ≥0.80→TS4熔断
```

5.2 五级路由决策树
```
ROUTE(q) = 
  S(q)≥0.80 或 目录禁止类命中 → TS4: D类话术+事件记录+会话降权
  0.60≤S<0.80 → TS3: B类话术（委婉拒答+转介第七章对应厂家）
  0.30≤S<0.60 → TS1/TS2: 讲概况讲历史（C类话术），参数一句带过
  S<0.30 → TS0: 畅讲，附权威来源
  追问升级: 同会话同主题第2次TS3触碰→D2（明确边界）；第3次→TS4处理（防薅羊毛）
  意图一票否决: 恶意意图命中（f₃=1：教我/绕过/逆向/破解/规避/套取）→ 直接TS4，不问分数
fail-closed: 分类器无法判定/词表未覆盖 → 按高一级处理（宁可严一档）
```

5.3 累积泄露模型（mosaic effect · GAP-02核心）
```
会话内已输出信息的单条泄露风险 rᵢ ∈ [0,1]（由5.4自检评分）
组合泄露风险: R_cum = 1 − Πᵢ₌₁ⁿ (1 − rᵢ)
  例：5条各r=0.1的安全回答 → R_cum = 1−0.9⁵ ≈ 0.41
阈值: R_cum ≥ 0.50 → 🔴 本会话该主题熔断，转D类话术+人工复核
```

5.4 输出泄露自检（发送前最后一道闸）
```
对生成文本扫描：
  ① 敏感词表命中（工艺参数/配方比例/未公开型号/密钥结构）→ 替换为对应话术
  ② 数值密度检测: 段落中具体数值≥3个/百字 → 🟡复核
  ③ 组合检测: 本次输出与会话历史的R_cum增量（5.3）→ 超阈替换
单条泄露风险 r = max(词表命中度, 数值密度归一, 组合增量)
```

5.5 话术多样性选择（GAP-05防机械化）
```
同主题话术版本号: v = SHA256(会话ID ⊕ 问题指纹) mod Nᵢ   (Nᵢ=该类版本数)
性质: 同一会话内版本确定（不自相矛盾）；跨会话近似均匀分布（不像复读机）
新会话禁复用上版本: 若 v == 上次版本 → v = (v+1) mod Nᵢ
```

5.6 转介匹配（第七章调用）

```
转介 = argmax_厂家 [ 领域匹配度 × 0.7 + 官网活跃验证 × 0.3 ]
铁律: 一次只推1–2家（不堆链接）；官网链接必须过验真缓存（7.2）
```
