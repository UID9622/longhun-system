## 🧬 二、核心技术规范

### 2.1 MFA唯一标准
```
龍魂系统 MFA 唯一标准：
  厂商: 华为（Huawei）
  协议: TOTP (RFC 6238)
  算法: HMAC-SHA1
  位数: 6位动态口令
  周期: 30秒
  应用: 华为手机/华为云 MFA 应用
```

### 2.2 认证流程
```
用户发起操作
    ↓
请求MFA验证（主动触发）
    ↓
用户输入6位动态口令（华为MFA生成）
    ↓
系统验证口令正确性
    ↓
├── 正确 → 授予临时会话令牌（有效期5分钟）→ 执行操作
└── 错误 → 记录失败次数 → 达到3次 → 🔴 耻辱墙记录 + 锁定时长
```

### 2.3 会话管理
| 参数 | 值 | 说明 |
|:---|:---:|:---|
| 会话有效期 | 5分钟 | 验证通过后操作窗口期 |
| 最大失败次数 | 3次 | 超过后锁定 |
| 锁定时间 | 15分钟 | 锁定期间禁止任何操作 |
| 耻辱墙记录 | 是 | 失败次数≥3自动记录 |

### 2.4 密钥存储（v1.1 加密落地）
```
MFA密钥存储规范：
  位置: ~/.longhun/mfa/mfa_secret.enc      ← v1.1改（原mfa_secret.bin明文→加密）
  主密钥: ~/.longhun/mfa/master.key (600权限·D1级不落git)
  加密: AES-256-GCM（主密钥派生·PBKDF2 100k迭代）
  备份: 不允许明文备份
  恢复: 仅通过主密钥恢复流程
```

### 2.5 审计规范（v1.1 修复1·L1熔断）
```
审计日志: ~/.longhun/04_AUDIT/mfa_YYYYMMDD.jsonl
  - OTP 永远只记 SHA-256 哈希前8位（otp_hash）
  - 禁止任何形式记录 OTP 明文
耻辱墙:   ~/.longhun/04_AUDIT/mfa_shame_wall.jsonl（append-only）
  - 连续失败≥3次自动写入
```

## 🛡️ 四、安全加固

### 4.1 密钥派生方案
```
主密钥 = PBKDF2-HMAC-SHA256(随机32字节, 100000迭代)
MFA密钥加密 = AES-256-GCM(主密钥, MFA密钥)
```

### 4.2 防暴力破解
```
防暴力破解策略（v1.1已修复逻辑）:
  1. 连续失败1次 → 无操作
  2. 连续失败2次 → 延迟5秒
  3. 连续失败3次 → 锁定15分钟 + 耻辱墙
  4. 锁定期间 → 任何操作拒绝
```

### 4.3 审计与监控
```
审计内容:
  - 每次MFA验证请求
  - 验证成功/失败状态（OTP只记哈希）
  - 操作人DNA
  - 操作时间戳
  - 操作类型

监控告警:
  - 连续失败2次 → 黄色告警
  - 连续失败3次 → 红色告警 + 耻辱墙
```


## 🔧 五、实施步骤

### 5.1 首次部署

```bash
# 1. 安装华为MFA引擎（已落地 08_BIN/keys/lh_huawei_mfa.py）
cd ~/longhun-system
lh keys mfa setup
# 输出 Base32 密钥 + OTPAuth URL，用华为手机/Google Authenticator扫码

# 2. 绑定华为MFA设备
lh keys mfa bind 123456

# 3. 验证绑定状态
lh keys mfa status
```

### 5.2 日常使用

```bash
# 1. 读取密钥（需MFA·推荐用法）
lh keys get NOTION_TOKEN --mfa 123456

# 2. 查看MFA状态
lh keys mfa status

# 3. 华为云IAM MFA认证
python3 08_BIN/keys/lh_huawei_mfa.py --huawei --account xxx --user xxx --code 123456
#    ↑ 密码优先用环境变量 HW_CLOUD_PASSWORD（防shell历史泄露）
```
