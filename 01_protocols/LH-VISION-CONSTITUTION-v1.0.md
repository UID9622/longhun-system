## 二、六条心法（P0-ETERNAL·焊死）

### 心法一：不申请专利

```
理由：
  - 专利=垄断=壁垒=后人负担
  - AI时代专利会指数级增长，后人将被埋没
  - 开源不是放弃权利，是放弃垄断的权利
  
执行：
  - 所有龍魂产出默认开源
  - 用DNA标记归属，但不限制使用
  - 谁用都可以，只需保留DNA追溯
  - 商业使用不收费，但不允许重新申请专利
```

### 心法二：不做企业

```
理由：
  - 企业=合规成本=远离初心
  - 超级个体户模式：一个人+AI=一个团队
  - 不需要董事会、不需要投资人、不需要年度报告
  
执行：
  - 不注册公司
  - 不申请商标（龍魂/CNSH用DNA标记代替商标）
  - 不融资·不上市·不对赌
  - 收入模式：自愿捐赠，不强制收费
```

### 心法三：中文为根

```
理由：
  - 英文编程=14亿人的门槛
  - CNSH=中文编程=让14亿人都能编程
  - 文化主权=语言主权
  
执行：
  - CNSH为系统第一语言
  - 所有核心文档中英双语（中文为主）
  - 对外接口支持多语言，内核中文
  - 变量名、函数名、协议名：中文优先
```

### 心法四：像家电一样简单

```
理由：
  - 技术应该服务于人，不是让人服务于技术
  - 洗衣机不需要说明书，AI也不应该需要
  
执行：
  - 容器化：丢进去→自动跑
  - 零配置启动
  - 中文界面，不用学英语
  - 任何错误都有中文解释+自动修复建议
  - 按钮不超过3个（核心功能）
```

### 心法五：不能劝人善良，但做了坏事得认

```
理由：
  - 我们阻止不了战争、阻止不了资本、阻止不了坏人
  - 我们只能做好民生、做好工具、做好自己
  
执行：
  - 龍魂不做道德审判（不替别人定义"好人"）
  - 龍魂做行为记录（做了什么，DNA链上都有）
  - 不做恶事预防，做恶事追溯
  - 和平的事阻止不了，就把民生做好
```

### 心法六：让后人轻松

```
理由：
  - 这一代人活得太累了
  - 我们填平坑，后人走平路
  - 这是龍魂唯一的存在意义

执行：
  - 坑1: 专利垄断 → 开源共享
  - 坑2: 技术门槛 → 容器化·像家电
  - 坑3: 语言壁垒 → 中文编程
  - 坑4: 数据归属 → DNA标记·人民主权
  - 坑5: 企业枷锁 → 超级个体户
  - 坑6: 知识碎片 → 多元分解·自动关联
```
