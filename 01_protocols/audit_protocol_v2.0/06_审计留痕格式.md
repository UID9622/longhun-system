## 6.3 日志轮转策略

```bash
#!/bin/bash
# 审计日志轮转（每日执行 @midnight）

LOG_DIR="$HOME/longhun/audit"

# 绿色日志：7天后压缩归档
find "$LOG_DIR/green_pass.jsonl" -mtime +7 -exec gzip {} \;

# 黄色日志：90天后压缩归档
find "$LOG_DIR/yellow_hold.jsonl" -mtime +90 -exec gzip {} \;

# 红色日志：永不删除，只追加

# 耻辱柱：永不删除，只追加
```

## 6.4 日志完整性校验

```python
# 每小时校验审计日志完整性
def verify_audit_integrity():
    """校验 dragon_ledger.jsonl 的完整性和不可篡改性"""
    ledger = Path("~/longhun/audit/dragon_ledger.jsonl")
    
    # 1. 校验行数单调递增（不允许删行）
    # 2. 校验每条记录DNA签章有效性
    # 3. 校验 audit_id 顺序性
    # 4. 校验无空白/跳行
    
    prev_id = None
    with open(ledger) as f:
        for i, line in enumerate(f, 1):
            record = json.loads(line)
            
            # 必须字段检查
            required = ["audit_id", "dna", "decision"]
            if not all(k in record for k in required):
                raise AuditIntegrityError(f"Line {i}: missing required fields")
            
            # DNA签名验证
            if not record["dna"].get("immutable"):
                raise AuditTamperError(f"Line {i}: DNA immutability broken")
            
            # ID顺序性
            if prev_id and record["audit_id"] <= prev_id:
                raise AuditOrderError(f"Line {i}: audit_id out of order")

    return True
```
