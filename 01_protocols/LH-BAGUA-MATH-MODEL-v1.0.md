2.2 先天 vs 后天 = 两套排列（🟢严格）
- 先天八卦（伏羲）圆图序：乾兑离震·巽坎艮坤 = (7,3,5,1,6,2,4,0)。
  定理（对跖互补）：先天圆图对跖位置两卦之和恒为 7，即互为按位取反：
  乾(111)↔坤(000)、兑(110)↔艮(001)、离(101)↔坎(010)、震(100)↔巽(011)。
  证明：逐对列举即得 XOR=111。□
  含义：先天图是一张"完美对冲图"——每个位置的正对面都是它的完全反面，整体阴阳绝对平衡。
- 后天八卦（文王）方位序：坎北、艮东北、震东、巽东南、离南、坤西南、兑西、乾西北。
  用于"给人走的空间"（村落、罗盘、方位），与洛书九宫绑定（见2.3）。
- 两套体系的关系：先天为体（平衡结构），后天为用（方位运行）——数学上是同一集合 {0,1}³ 的两个不同排列 σ先天、σ后天 ∈ S₈。

2.6 破阵算法与收敛证明（🟢严格，承接上游v1.3）
模型：格点图 G，中心 c=(1,1)。高程函数 h(x,y)=√((x−1)²+(y−1)²) ≥ 0。
算法：每步沿 −∇h 走一步（往低走），遇障右手脱困限N步，数字根dr序列检循环强制换向。
定理（有限步收敛）：理想格点上，梯度步每步使 h 严格下降 ≥ δ₀（格点最小高度差），
  故步数 ≤ h(起点)/δ₀，必达唯一全局最小点 c。h(c)=0 ⟺ x=c，不动点唯一。□
  （Lyapunov论证：h 为Lyapunov函数，严格递减有下界 → 收敛。）
物理补丁（🟡）：真人步长不精确 → 0.5格模糊收敛 + 三感（视/听/触）≥2票一致才判到达。

4.2 太极双极模型（🟡模型假设——类比建模，非物理断言）
钟池半水半陆 = 太极阴阳鱼眼的物理体现[^3^]。建模为一对等量反号源（偶极）：
```
源A(水,阴): q = −1，位于 (−d/2, 0)
源B(陆,阳): q = +1，位于 (+d/2, 0)
势场: Φ(p) = q_A/|p−p_A| + q_B/|p−p_B|
场强: E = −∇Φ
```
性质（🟢数学严格）：
- 中垂线上 Φ=0（阴阳平衡线）；
- 偶极矩 p̂ = q·d，方向由阴指向阳；
- 远场衰减 ∝ 1/r²——"眼"的影响随距离平方衰减，故阵眼只需很小（3.4%面积比）即可定场。

```
Φ(p) = Σₖ₌₀⁷ q / |p − R₂·e(θ_k)|      e(θ)=(sinθ, cosθ)
```
定理（中心对称性）：对8重旋转对称的等强源分布，中心点场强为零且为唯一对称稳定点：
  E(0) = −∇Φ(0) = 0。（证明：对称性要求 E(0) 在旋转45°下不变，唯一不变的向量是零向量。□）
物理诠释：八山环抱 → 中心是场的"不动点"——古人选钟池为中宫，与场论的唯一对称点同构。
  这不是说古人会算梯度，而是说：经验选址收敛到的解，和对称场论的解是同一个。

  E[L_内] ≈ 2（经中宫直达）；E[L_外] 取决于似通非通的支巷迷宫深度，迷宫设计使 κ ≫ 1

def 洛书验证():

    对角 = [sum(LUOSHU[i][i] for i in range(3)),

HOUTIAN_BEARING = {"坎":0,"艮":45,"震":90,"巽":135,

    return 序[round(θ/45) % 8]

    c = (1, 1); 路径 = [起点]; x, y = 起点; dr史 = []

        y += 0 if y == 1 else (1 if y < 1 else -1)
        dr = (abs(x)*97 + abs(y)*31 + 1) % 9 + 1     # 数字根编码
        if dr in dr史[-3:]:                          # 复卦loop检测→强制换向
            x, y = (min(x+1, 2), y)
        dr史.append(dr); 路径.append((x, y))

    """max_τ ρ(τ)：刷量脚本有固定节拍，ρ峰值趋1；真人杂乱，趋0"""
    n = len(时序); 均 = sum(时序)/n
    方差 = sum((v-均)**2 for v in 时序)
    if 方差 < 1e-9:

    def ρ(τ):
        return sum((时序[i]-均)*(时序[i+τ]-均) for i in range(n-τ)) / 方差
    return max(ρ(τ) for τ in range(1, min(最大延迟, n//2) + 1))
