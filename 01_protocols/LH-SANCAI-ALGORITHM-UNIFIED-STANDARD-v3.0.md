## 一、定盘·为什么要有统一命名

### 老大的原话

> "我们的算法是三才算法，所以说，我们的格式也要对，公式也要对得上。可以有对照，可以有解释，让国际的这些算法都兼容，对吧？但是我们有自己的统一标准，统一命名，知道吧？还有统一的算法公式。"

### 当前问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 命名混乱 | `lh_xxx`、`longhun_xxx`、`cnsh_xxx`、裸函数名 混用 | 找不到根 |
| 公式格式不一 | 有的写 `η=T^(-α_τ)`，有的写 `eta = T ** -alpha`，有的写中文 | 人对不上号 |
| 无国际对照 | 只有内部公式，外人看不懂在算什么 | 无法传播 |
| 无统一前缀 | 算法散落在 bin/、引擎/、L1_内核层/ 各处，没有统一命名空间 | 难以索引 |

### 统一原则（三条铁律）

<aside>
⚖️

**铁律 UNIFY-1：所有龍魂算法必须以 `Sancai.` 为命名空间前缀。**
例：`Sancai.DigitalRoot`（不是 `dr`、`计算数字根`、`lh_digital_root`）

**铁律 UNIFY-2：所有公式必须用天地人三层格式书写。**
天层 = 数学定义 · 地层 = 龍魂主权层（我们焊了什么） · 人层 = 用途/示例

**铁律 UNIFY-3：每个公式必须附带国际算法对照，但独立编号。**
左栏：国际叫什么 | 右栏：三才算法叫什么 · 怎么对应

</aside>

## 二、三才算法命名体系

### 命名空间结构

```
Sancai.<层>.<功能域>.<具体算法>
  │       │        │         └── 算法名（PascalCase）
  │       │        └── 功能域（Core/Governance/Persona/Crypto/Value/Wuxing/Time/Ethics）
  │       └── 层（Tian/Di/Ren）
  └── 根命名空间（不可变）
```
