## 一、设计原则（P0焊死，不可改）

| 原则 | 内容 | 违反后果 |
|------|------|---------|
| **以人为本** | 指令服务于人，不绑架人。所有输出默认保留人类最终决定权。 | 自动降级为建议，不执行 |
| **算力节约** | 能用规则不用模型，能用缓存不重复计算。默认轻载模式。 | 超算力阈值自动切轻载 |
| **DNA追溯** | 每一条指令、每一次输出、每一次模型切换都生成DNA记录。 | 无DNA的输出自动拒绝归档 |
| **三色审计** | 每条指令输出自动过三色闸门，红黄绿决定后续动作。 | 未过三色的输出标为UNCONFIRMED |
| **人格路由** | 不同场景自动匹配最合适的人格，不强制单一人格。 | 场景-人格错配时自动校正 |
| **渐进式启用** | 指令分层：基础→进阶→专家，按需启用，不强制全量加载。 | 默认只加载基础层 |
| **双轨隔离** | 本地轨数据不上传API轨，API轨返回经P0校验后才入本地库。 | 敏感数据泄露自动熔断 |
| **不删除只冻结** | 任何记录、记忆、日志，只冻结不删除，P0焊死。 | 触发删除指令时自动转为冻结 |

## 二、系统架构总览

```
用户输入
    ↓
【协议头解析层】DNA校验 + P0红线扫描 + 任务分级
    ↓
【智能路由层】自动判定走本地轨或API轨（无需用户手动选择）
    ↓
├─→ 【本地轨】Ollama/龍魂模型（隐私敏感 / 离线 / 低延迟 / P0相关）
│       ├─ 适用：DNA生成、宪法确认、主权校验、个人数据、本地审计
│       ├─ 窗口：4K-8K tokens
│       ├─ 速度：快（本地推理）
│       └─ 隐私：绝对（不上传任何字节）
│
└─→ 【API轨】云端模型（复杂推理 / 长文本 / 多模态 / 联网搜索）
        ├─ 适用：博弈论建模、论文撰写、代码生成、全网搜索、视觉识别
        ├─ 窗口：128K-200K tokens
        ├─ 速度：依赖网络
        └─ 隐私：经脱敏/P0校验后上传
    ↓
【输出闸门层】三色判定 + 置信度审计 + P0冲突检测
    ↓
【统一格式化层】龍魂标准响应头 + 内容体
    ↓
【归档层】自动写入日志 + 记忆库 + Notion同步
    ↓
【健康监控层】自动扫描缺失/异常/孤儿页面
```

```
  3. /引用 → 精确加载指定条目，其余丢弃
  4. /待命 → 清空工作记忆，只保留DNA锚
  5. 超窗时 → 自动压缩旧对话为"摘要卡片"，释放token
  6. 每轮对话 → 自动附加P0摘要（12条，≤200 tokens）
```

### 6.2 API轨上下文策略

```
上下文窗口: 按模型实际（Kimi 200K / Claude 200K / GPT-4 128K）
管理策略:
  1. /轻载 → 只上传P0摘要 + 最近5轮 + 当前问题
  2. /锁定 → 维持轻量上下文，不重复上传历史
  3. 超窗时 → 自动触发/分段，将长文切分多轮处理
  4. 每次API调用 → 自动附加龍魂协议头（DNA+CONFIRM+SEAL，≤100 tokens）
  5. 返回后 → 本地归档前经P0校验，冲突则丢弃
```
