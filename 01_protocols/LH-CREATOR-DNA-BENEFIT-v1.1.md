## 🧬 二、龍魂DNA受益算法 · 核心理念

### 2.1 算法定义

**龍魂DNA受益算法（Creator DNA Benefit Algorithm）**是一个基于**行为贡献度证明**的利益分配机制，它将"受益权"与"创造行为"绑定，而非与"注册时间"或"资本投入"绑定。

### 2.2 核心公式

```
创作者受益权 = ∑(行为贡献值 × 时间衰减因子 × 社区验证权重)

其中：
- 行为贡献值：代码提交、文档撰写、问题解答、生态贡献
- 时间衰减因子：早期贡献权重更高（激励先创）
- 社区验证权重：被引用/使用越多，权重越高
```

### 2.3 运行机制

```
【创造行为发生】
    ↓
【DNA追溯码锚定】
    #龍芯⚡️丙午·...-创意描述-UID9622
    ↓
【行为上链/存证】
    Git提交 / 区块链 / Notion时间戳
    ↓
【社区验证】
    被引用次数 / 使用量 / 二次创作
    ↓
【受益权计算】
    动态权重 × 贡献度 × 时间因子
    ↓
【受益分配】
    商业收益回馈 / 使用权开放 / 共同治理权
```

## 🛡️ 六、反作弊与博弈安全（🆕 v1.1 新增 · 受益算法的生死线）

没有这一层，社区验证就是刷分机器。四道闸全部实现在 v1.1 引擎中：

| 闸 | 攻击场景 | 防御机制 | 引擎实现 |
|----|----------|----------|----------|
| **闸一 · 禁自证** | 创作者给自己的作品刷满分 | 验证者=创作者 → 🔴 直接拒绝 | `SELF_VERIFY_FORBIDDEN` |
| **闸二 · 验证去重** | 同一人反复验证同一件作品堆权重 | (dna, verifier) 主键去重，重复不计权 | verifications 表 |
| **闸三 · 权重封顶** | 千人群控账号灌爆单件作品 | 单创作验证权重 ≤100，接近封顶转 🟡 人工复核 | `MAX_WEIGHT_PER_CREATION` |
| **闸四 · 互刷检测** | A刷B、B刷A 的团伙对敲 | 审计接口比对验证者集合重复率，<1 → 🔴 | `audit_creation()` |

**博弈论说明**：刷分的收益必须**小于**被审计标记的成本。三色审计记录进耻辱柱（承龍魂体系），信任分 `trust_score` 一旦跌落将拉低该创作者**全部历史作品**的受益指数——让作弊的期望收益为负，作弊自然停止。

## 💱 七、分配通道 · e-CNY 集成（🆕 v1.1 新增 · 承 L0·R5）

L0 宪法 R5 规定：**数字人民币 e-CNY 唯一支付通道**。受益分配因此不是"记个数字"，而是主权货币结算：

```
【受益指数达标】
    ↓
【三色审计 🟢】
    ↓
【e-CNY 钱包校验】（创作者主权激活 = DCEP 绑定，承身份系统）
    ↓
【distribute_benefit() 记账 + 哈希存证】
    ↓
【e-CNY 转账执行】（链下对接钱包 API）
    ↓
【分配回执上链】（distribution_hash 不可篡改）
```

| 规则 | 说明 |
|------|------|
| 唯一通道 | 禁止任何法币/代币/积分替代结算 |
| 未激活不分配 | 接收者未完成 e-CNY 绑定 → 🟡 挂账待激活，不逾期作废 |
| 全程留痕 | 每笔分配双哈希（ID哈希 + 内容哈希），可回滚审计 |
