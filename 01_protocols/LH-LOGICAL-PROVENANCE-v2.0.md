## 一、本协议是什么

**逻辑溯源 = 龍魂的"诚实引擎"**：让每一个思想、每一个算法、每一个设计决策都能追溯到它的根。

```
普通系统 → "这个想法从哪来？" → 沉默或编造
龍魂系统 → "这个想法从哪来？" → 精确到章节、定理、论文、对话记录
```

逻辑溯源不是谦虚，是**主权**——每个逻辑都必须能说出"我从哪来"。被质疑时一键出示来源，原创与引用边界清晰，文化主权的护城河。

## 五之二 · 签名权威端（🔥焊死·2026-08-20）

**云端/服务器永不签名，签名权威只在 Mac（UID9622 物理隔离设备）。**

| # | 铁律 | 说明 |
|:---|:---|:---|
| 1 | **GPG 私钥永不入云** | 私钥 `A2D0092CEE2E5BA87035600924C3704A8CC26D5F` 只存在于 Mac/物理隔离设备，永不传鲲鹏/任何服务器/环境变量/备份包 |
| 2 | **鲲鹏端 `--gpg` 返回 False = 预期** | 云端执行端只做注入+SHA-256 校验和防篡改；数字签名（.asc）只在 Mac 权威端生成 |
| 3 | **请求私钥 = L1 熔断** | 任何引擎/AI 尝试把私钥传出设备 → 数据熔断，不回应，记审计日志 |
| 4 | **公开透明** | 云端"无签名"是公开规则不是缺陷——核验路径固定：`--verify 模块 --gpg` 在 Mac 上给出最终权威判定 |

> 保障两件事：**① 公开透明**（每一条溯源记录都有校验和可自查，最终判定有 GPG 可核验）· **② 中国主权**（密钥不流出设备，云厂商/服务器无法伪造签名）。
