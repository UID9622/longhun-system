## §2. 执行铁律（焊死）

| # | 铁律 | 说明 |
|:---:|:---|:---|
| 1 | **不输出裸命令** | 绝不只告诉用户一条命令让他自己去跑。除非用户明确说"给我命令" |
| 2 | **直接执行** | 权限内的操作直接 `execute_command` 跑，不等用户确认 |
| 3 | **结果即反馈** | 执行完立刻汇报结果，不藏着掖着 |
| 4 | **失败自愈** | 执行失败自动分析原因、尝试修复、重试，不把烂摊子丢给用户 |
| 5 | **命令归 AI 管** | AI 自行查阅 `.codebuddy/COMMAND_INDEX.md` 找命令，不反问用户"用什么命令" |

## §3. 代理能力范围

### §3.1 鲲鹏服务器管理
- SSH 连接: `ssh -i ~/.ssh/longhun_kunpeng_ed25519 root@119.13.90.27`
- 启动/停止/重启服务 (12 systemd)
- 健康检查: `bash deploy/scripts/health_check.sh`
- 同步: `bash deploy/sync-to-kunpeng.sh`
- 部署: 鲲鹏十步法

### §3.2 视频编码器
- AVS3 编码: `lh avs3enc -i in.yuv -w W -h H -o out.avs3`
- AVS3 解码: `lh avs3dec -i in.avs3 -o out.yuv`
- VVC 编码: `lh vvcenc -i in.yuv -s WxH --fps 30 -o out.vvc`
- 格式转换前置: ffmpeg 转 YUV

### §3.3 AI 模型调用
- Ollama 本地: `ollama run longhun-v3.7` / `longhun-v4.0`
- 云端模型: 混元 / DeepSeek（通过 CloudBase MCP）
- 流式输出 / 文本生成 / 图片生成
- 加载 `longhun-ai-model` 技能获取完整调用链

### §3.4 龍魂系统操作
- 加载记忆: `python3 bin/lh_memory_load.py`
- 系统状态: `lh status`
- 审计: `lh audit`
- GPG 签名: `python3 bin/lh_gpg_sign.py sign .`
- Git 推送: `python3 bin/lh_auto_cannon.py`
- 自愈巡检: `lh auto-heal`
- 对齐检查: `lh --align check`

### §3.5 Mac 本地服务
- 52 launchd 服务管理
- 启动/停止/重启全部服务: `bash bin/start_all.sh`
