## 📋 一、核心设计理念

> **系统不负责哄人，只负责把事情做对。用户发脾气、说错话、打错字时，系统复盘上下文，推导真实意图，直接执行最优解，反馈执行结果而非情绪响应。**

```
输入层：用户原始输入 (可能含错别字、情绪化、不专业表述)
       │
       ▼
┌─────────────────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ ② 上下文复盘 (Context Review)                                               │
│    - 会话历史 / 项目状态 / 用户偏好                                          │
│    - 任务链关联 / 缺失信息补全                                               │
└─────────────────────────────────────────────────────────────────────────────┘
       │
       ▼

└─────────────────────────────────────────────────────────────────────────────┘
       │
       ▼
```

## 🏷️ 二、自动化特性标签

| 标签 | 含义 | 自动化等级 |
|:---|:---|:---:|
| `auto-correct` | 自动错别字/口语化纠正 | 🟢 全自动 |
| `emotion-ignore` | 忽略情绪词，不输出安慰 | 🟢 全自动 |
| `context-aware` | 基于会话上下文补全意图 | 🟢 全自动 |
| `intent-infer` | 自然语言 → 标准动作映射 | 🟡 高置信自动，低置信确认 |
| `danger-guard` | 危险命令拦截 / 强制 dry-run | 🔴 强制保护 |
| `audit-trail` | 每步生成 DNA + 审计日志 | 🟢 全自动 |
| `dry-run-first` | 默认先模拟执行，确认后真实执行 | 🟡 可配置 |
| `fallback-human` | 意图置信度 < 0.5 时提示用户确认 | 🟡 半自动 |

## 🔐 四、安全边界

1. **危险命令黑名单**：删除、格式化、覆盖、reset、rm -rf 等默认拦截，强制 dry-run。
2. **写操作二次确认**：涉及数据库写入、部署、回滚等动作，默认 dry-run，需显式 `--exec` 才执行。
3. **作用域限制**：命令默认在项目根目录执行，禁止越出 `~/longhun-system` 或用户指定目录。
4. **审计不可篡改**：所有执行记录写入 `04_AUDIT/emotion_engine.jsonl`，带 SHA256 校验链。
5. **隐私本地优先**：会话历史、用户偏好默认本地存储，不上传。

## ⚠️ 五、错误处理与降级策略

| 场景 | 处理策略 |
|:---|:---|
| 意图置信度 < 0.5 | 不执行，返回推理过程 + 待确认问题 |
| 命令执行失败 | 记录失败详情，尝试下一条步骤，最终返回失败汇总 |
| 缺失关键参数 | 基于上下文补全；补全失败则询问用户 |
| 检测到危险命令 | 强制转为 dry-run，提示用户确认 |
| 历史文件损坏 | 忽略损坏行，继续使用可用历史 |
| 未知动作 | 降级为 `query`，尝试搜索/帮助 |

## 📝 七、集成方式

### 7.1 添加到 `bin/lh`

```bash
# ─── 龍魂 · 情绪纠偏与意图自动执行引擎 v1.1 ───
if [ "$FIRST_ARG" = "emotion" ] || [ "$FIRST_ARG" = "纠偏" ]; then
  shift
  exec python3 "$HOME/longhun-system/08_BIN/lh_emotion_engine.py" "$@"
fi
```

### 7.2 配置文件

`~/.longhun/configs/user_preferences.json`：

```json
{
  "default_execution_mode": "dry-run",
  "emotion_handling": "ignore",
  "auto_correct_typos": true,
  "dangerous_commands_policy": "block",
  "max_history": 100
}
```

### 7.3 日志与审计

- 会话历史：`~/.longhun/memory/conversation_history.jsonl`
- 项目状态：`~/longhun-system/.state/emotion_project_state.json`
- 执行审计：`~/longhun-system/04_AUDIT/emotion_engine.jsonl`
