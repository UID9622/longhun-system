Rule 1: Dual-View Welded
  All output (rules/dictionaries/audits/memory/routes/pages/databases/scripts/events) MUST
  use M::×CNSH:: dual-segment encapsulation. M:: verifies truth; CNSH:: guards attribution.
  The header is the address; the body is the territory.

Rule 2: Chinese as Body, Machine as Utility (GAP-01 Layered Adjudication)
  Human-Read Layer: fully Chinese — directories, filenames, comments, reports — understood at a glance, maintenance without begging.
  Machine Layer: keep original — M::/CNSH::/DNA/CONFIRM/SEAL are verification identifiers,
  not filenames; do not translate, do not alter (translation blinds the machine).
  Each layer in its place, no mutual invasion — this is not compromise, it is division of labor.

Rule 3: Chinese Master Version (Q2 Weld Point · GAP-02 Adjudication)
  Protocol documents: the Chinese version is the sole authoritative version; English and all subsequent language versions
  are Tongxinyi mirrors. Mirrors MUST bear the same version number and identical chapter structure as the master (§4.3).
  On semantic conflict: Chinese version prevails — Chinese IS the standard, not a translation.

Rule 4: Extend Without Breaking
  New language = create `{language-self-name}/` directory under `协议文档/` (Tiếng Việt / 日本語 / …),
  following the dual-engine pipeline fill-in (§6.4). Do not touch existing directories, do not modify existing files,
  do not touch others' mirrors.

Rule 5: Enter, Then Obey (Q3 Weld Point)
  Using LongHun capabilities constitutes signing the Ecosystem Protocol (Chapter 7): 4 permissions, 4 prohibitions.
  Admission is based not on declarations but on the Three Anchors — DNA/CONFIRM/SEAL must all be present to pass; one missing = reject (§4.4).

4.1 Dual-View Consistency Matrix (M:: × CNSH:: Linkage Truth Table)
  M::status and CNSH::policy MUST fall within permitted combinations; otherwise 🔴 dual-view split:
  | M::status | Permitted CNSH::policy | Corresponding Color |
  |-----------|------------------------|---------------------|
  | true      | pass                   | 🟢 |
  | pending   | hold / rewrite         | 🟡 |
  | false     | hold / rewrite         | 🟡 |
  | error     | fuse                   | 🔴 |
  Consistency judgment: C(m, p) = (m, p) ∈ permitted set. Machine says true but route says fuse,
  or machine says error but route says pass — one link has been tampered with; immediate fuse audit.

4.2 Naming Compliance Judgment (Q1 Mathematical Form)
  For path P, judge segment by segment: segment s is compliant ⟺ contains Chinese characters ([\u4e00-\u9fff])
  ∨ s ∈ machine-layer whitelist (M::/CNSH::/DNA/CONFIRM/SEAL/README/English/
  .git/.sh/.py/.md and other extensions & system-reserved names)
  ∨ s matches all-caps machine convention (regex ^[A-Z0-9_-]+$, e.g. README / LICENSE /
  LONGHUN_PROTOCOL — international uppercase convention, NOT "unreadable lowercase English names").
  Human-Read Layer Chinese coverage rate: γ = compliant_segments / total_segments, hard requirement γ = 1.0.
  Bare English stem detected (e.g. longhun_rules_engine_v2.py) → 🔴 reject from repository,
  query v2→v3 mapping table for migration suggestion (Chapter 5).

4.3 Dual-Version Sync Judgment (Q2 Mathematical Form · GAP-02 Executor)
  Version lock: V(Chinese) = V(Mirror); inequality → 🔴.
  Structural deviation rate: δ = |n_zh − n_mirror| / max(n_zh, n_mirror) ≤ 0.10
  (n = chapter/paragraph count); δ exceeds threshold → 🟡 mirror pending update, marked "subject to Chinese version".
  Semantic conflict arbitration: Chinese version prevails (Rule 3); mirror revisions must back-link to master version DNA.

4.4 Ecosystem Three-Anchor Admission (Q3 Mathematical Form)
  Admission(A) ⟺ DNA(A) ∧ CONFIRM(A) ∧ SEAL(A) — all three anchors present with valid format.
  AND-gate judgment, fail-closed: one anchor missing → reject installation / reject access 🔴.
  Three-anchor format (regex welded):

4.5 Migration Compatibility Layer (GAP-03 — Rename Without Breaking Links)
  For each renamed file, leave a symlink at the original path pointing to the new Chinese path:
    old_path → new_path (ln -s)

  Iron Law: compatibility layer is a bridge, not a home — new code always directly references Chinese paths.
