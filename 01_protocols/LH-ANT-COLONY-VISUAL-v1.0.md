## 一、概述

### 1.1 一句话

**把蚁群的"看不见的分布式协作"变成"看得见的可视化图表+听得懂的语音解说"。**

### 1.2 为什么要可视化蚁群

蚁群系统是龍魂体系的"神经网络层"——192个引擎通过信息素网络协作。但如果只靠日志看，就像用听诊器检查互联网——根本看不到全局。

本协议定义了三层可视化：
1. **分布图**：蚁后/工蚁/哨兵的位置和健康状态
2. **信息素流图**：任务在网络中的传播路径和强度
3. **涌现仪表盘**：从个体行为到群体智能的涌现过程

### 1.3 与纳米视觉协议的关系

| 维度 | 纳米视觉协议 | 本协议 |
|:---|:---|:---|
| 对象 | 物理图像（照片/扫描/光刻） | 抽象系统（节点/边/信息素） |
| 方法 | 八卦阵卷积+多尺度金字塔 | 力导向布局+信息素热力图 |
| 输出 | 超分辨率图像 | 系统拓扑图/健康仪表盘 |
| 声音 | 事后解说 | 实时状态播报 |

## 三、可视化类型定义

### 3.1 类型一：蚁后-工蚁分布拓扑图

```
生成方式: lh_visual_engine.py → chart=topology
```

```
生成方式: lh_visual_engine.py → chart=heatmap

视觉元素:
  - 背景: 暗色网格
  - 热力: 信息素浓度→暖色（金→橙→红）

```

## 四、数学建模

### 4.1 力导向布局（节点排布）

```
目标: 最小化总能量
E = Σ_{i,j} k_ij * (d_ij - l_ij)² + Σ_i w_i * d(i, 中心)²

其中:
  k_ij = 边权重（信息素浓度）
  d_ij = 节点i和j的当前距离
  l_ij = 理想距离（与权重反比）
  w_i  = 节点i的中心引力系数（蚁后=0, 外围工蚁=1）
```

### 4.2 信息素热力

```
热力值 H(x,y) = Σ_i C_i * exp(-α * dist((x,y), pos_i))

其中:
  C_i = 节点i的信息素浓度
  pos_i = 节点i在画布上的位置
  α = 衰减系数（通常 0.01-0.05）
```

### 4.3 涌现指数

```
涌现指数 E = σ(任务完成量) / μ(任务完成量) * log(合作边缘数+1)

E > 0.7: 涌现（集群智能出现）
0.3 < E < 0.7: 正常协作
E < 0.3: 各自为战（需要蚁后干预）
```
