## 零、协议定位

> "一句话下去，全链路跑完。"

本协议定义了龍魂系统对外输出的**自动执行入口**。用户不需要理解人格编排、不需要手动指定链路、不需要逐个调用引擎——只需一句自然语言指令，系统自动完成：

```
意图解析 → 路径推演 → 人格联动 → 七闸审计 → DNA签章 → 归档入库
```

**三份协议的分工**：

| 协议 | 层级 | 职责 |
|:---|:---|:---|
| `LH-CREATOR-PROTECTION-v1.0.md` | 法律底座 | 原创保护·署名强制·去来源追责 |
| **`LH-AUTOFLOW-EXEC-PROTOCOL-v1.0.md`** (本文) | **操作执行层** | **一句话自动流·人格链路·闸口审计** |
| `LH-PERSONA-GOVERNANCE-WHITEPAPER-v1.4.md` (文件正确版本号) | 治理监督层 | 20人格治理·签章规则·输出声明 |

## 八、CLI 使用方式

### 基本用法

```bash
# 一句话执行
python3 bin/lh_autoflow.py "审计系统安全状态"

# JSON 输出
python3 bin/lh_autoflow.py --json "检查安全漏洞"

# 详细输出（含每步详情）
python3 bin/lh_autoflow.py --verbose "部署到鲲鹏"

# 干运行（仅推演不执行）
python3 bin/lh_autoflow.py --dry-run "分析抖音水军"

# 查看所有路由
python3 bin/lh_autoflow.py --list-routes

# 查看所有闸口
python3 bin/lh_autoflow.py --list-gates

# 健康检查
python3 bin/lh_autoflow.py --health

# 内置自检
python3 bin/lh_autoflow.py --test
```

### Python API

```python
from bin.lh_autoflow import LonghunAutoFlow

engine = LonghunAutoFlow(enable_gpg=False)
result = engine.execute("审计系统安全状态")

print(result.status)       # "SUCCESS" | "PARTIAL" | "REJECTED"
print(result.audit_mark)   # "🟢" | "🟡" | "🔴"
print(result.dna)          # DNA 追溯码
print(result.execution_chain)  # "P05 → P06 → P15 → P03"
```
