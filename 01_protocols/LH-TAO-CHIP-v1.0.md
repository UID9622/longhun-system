## 三、核心实现

**引擎**：`engines/lh_tao_chip.py`

### 3.1 算力分层调度器

```python
from engines.lh_tao_chip import TaoChipScheduler, ChipTask, TaskType, TaskPriority

scheduler = TaoChipScheduler()

# L1 守护任务
t1 = ChipTask(task_id='h1', task_type=TaskType.GUARD, priority=TaskPriority.P2)
scheduler.submit(t1)

# L2 弹性推理
t2 = ChipTask(task_id='i1', task_type=TaskType.INFERENCE,
              priority=TaskPriority.P1, require_elastic=True)
scheduler.submit(t2)

# L3 暗涌爆发
t3 = ChipTask(task_id='a1', task_type=TaskType.SECURITY_AUDIT,
              priority=TaskPriority.P0, deadline_sec=0.5)
scheduler.submit(t3)

# 查看状态
print(scheduler.get_state())
scheduler.shutdown()
```

## 五、焊死规矩

| # | 规矩 | 级别 | 说明 |
|:---:|:---|:---:|:---|
| 1 | **L3暗涌层平时必须断电** | P0 | 物理断电，不是软件休眠，不留痕迹 |
| 2 | **L3触发后必须限时** | P0 | 最长5分钟，超时强制断电，防过热防暴露 |
| 3 | **L3不允许直接从L1跳** | P0 | 必须经过L2过渡，100ms缓冲，保护芯片 |
| 4 | **超温必须强制降级** | P0 | 95度硬限制，不商量，不断电就烧 |
| 5 | **硬件密钥槽用完即清** | P0 | 加密完立即清除，密钥不在内存停留 |
| 6 | **所有状态转换带DNA** | P1 | 功耗记录、温度记录、任务记录，全部追溯 |
| 7 | **L3任务必须P0级** | P0 | 不是紧急任务不配用暗涌层 |
| 8 | **L3运行期间禁止其他任务抢占** | P0 | 暗涌层独占，确保一击必成 |
