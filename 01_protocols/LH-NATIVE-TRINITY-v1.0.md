## 〇、序 · 为什么是「厚德载物」

> **《易》坤卦：地势坤，君子以厚德载物。**

龍魂起于苹果生态——Swift 写的第一行代码、乔前辈的设计哲学是底座的一部分。**承其厚德，方载万物**。所以本方案三端并立，不偏不倚：

| 端 | 哲学 | 立场 |
|:---|:---|:---|
| 鸿蒙 + 国产芯片 | **自立** | 底座永为中国自主知识产权 |
| iOS / Apple | **承德** | 乔前辈的设计之德不可忘，苹果是画布不是主人 |
| 昇腾 / 鲲鹏 | **载物** | 算力底座，载得起生态 |

**君子协议三不**（焊死）：
1. **不拆台**——在 iOS 上不骂苹果，在鸿蒙上不贬安卓，兼容并蓄
2. **不绑架**——用户数据主权永远归用户，画布可换，底座不移
3. **不独食**——君子喻于义，生态开放给人用，语法主权归龍魂，协作门槛归零

## 一、三端全景架构

```
┌─────────────────────────── 终端层 ───────────────────────────┐
│  iOS (SwiftUI)      HarmonyOS (ArkTS)      鸿蒙座舱 CarOS     │
│  LonghunApp         龙魂 App                龙魂车载 DNA 引擎   │
│  LonghunKit(SPM)    harmonyos-universe      LongHunCarOS      │
└───────────────┬───────────────────────────────────────────────┘
                │  HTTPS / WebSocket · DNA 追溯码 · 端侧国密 SM2/SM3
┌───────────────▼───────────────────────────────────────────────┐
│                     服务层 · 鲲鹏 920 (ARM v8.2)              │
│   portal-api :8777 · control-gate :7631 · 三重主权 :8091       │
│   CNSH 编译器 · 通心译 · DNA 追溯 · 统一密钥库 lh_vault        │
└───────────────┬───────────────────────────────────────────────┘
                │  AscendCL / MindSpore · 昇腾 310/910 (NPU)
┌───────────────▼───────────────────────────────────────────────┐
│                      AI 推理层 · 昇腾 NPU                     │
│   龙魂大模型推理 · 通心译转译 · 语义路由 · 数字分身 · 七因子   │
└───────────────────────────────────────────────────────────────┘
```

**同源优势**：鸿蒙 App 编译目标 `arm64-v8a`，鲲鹏 920 同为 ARM——**指令集同源**，容器/二进制无缝跑，不踩 x86 迁移坑。iOS 走 HTTPS 标准协议，同一套 API 三端复用。

## 四、昇腾 AI 接入（补齐最后一环）

### 4.1 为什么是昇腾
- 鲲鹏=服务器 CPU · 昇腾=AI NPU（310 推理 / 910 训练）· 华为云同生态，**一个控制台全管**
- 龙魂 AI（qwen2.5 / 混元）推理从 CPU 挪到 NPU，**推理速度数倍提升，能耗大降**（呼应节能协议）

### 4.2 接入路径
1. **ModelArts + 昇腾 310**：华为云开 NPU 推理实例，模型转 MindIR 格式（MindSpore 模型仓库）
2. **AscendCL 推理封装**：`08_BIN/` 新增 `lh_ascend_infer.py`——统一推理入口，API 与现有模型调用兼容（`/infer` 同签名），**上层无感切换**
3. **三层算力调度**（焊死）：
   ```
   终端(麒麟/Apple NPU) ── 轻量推理/端侧加密
        │
   鲲鹏 CPU ────────────── 标准推理/通心译
        │
   昇腾 NPU ────────────── 重推理/大模型/批量转译
   ```
   调度规则：按任务权重自动分派（P06 数字根权重），昇腾满了降级鲲鹏，**算力按需付费**
4. **降级兜底**：昇腾实例不可达 → 自动降级鲲鹏 CPU 推理 → 失败才告警（节能协议降级规则：首次失败禁自动重试）

## 五、厚德载物 · 君子协议落地点

> 本方案的「德」不是口号，是每一条都焊进代码的检查点：

| 德 | 落地检查点 | 违反后果 |
|:---|:---|:---|
| **不拆台** | iOS/鸿蒙代码注释不出现贬损他端措辞 | P05 🔴 审计否决 |
| **不绑架** | 用户数据端侧加密、云上只存密文、可随时导出删除 | L1 数据熔断 |
| **不独食** | 三端 SDK 均附 MulanPSL v2，开源给人用 | 锁死即违约 |
| **承德** | iOS 工程头带「承乔前辈之德」署名块 | 缺署名=P15 签章拒绝 |
| **厚道** | 对外发布必挂归属名（诸葛鑫）· 来源链不断 | 匿名发布=耻辱柱 |

**君子协议一条总纲**：语法主权在龍魂（CNSH 收口），创作自由归众生（任意语法入），利润分配见君子（创作者 DNA 受益算法）。**以德载物，物方能长久。**
