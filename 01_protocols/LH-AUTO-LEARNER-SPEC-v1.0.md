## 三、自动化学习管道（怎么学）

**引擎**：`bin/lh_auto_learner.py`

**工作流程**：

```yaml
pipeline:
  - stage: 定时抓取
    engine: crawler
    frequency: 见上表
    output: data/auto-learned/raw/
    rules:
      - 支持RSS、GitHub API、HuggingFace API
      - 抓取结果先存本地，不做任何处理
      - 所有抓取记录打DNA追溯码
      
  - stage: 质量过滤
    engine: filter
    trigger: 抓取完成后自动
    rules:
      - 过滤纯英文内容（除非关键技术文档）
      - 过滤低质量：GitHub星标<10、技术文章阅读<1000
      - 过滤价值观冲突：鼓吹数据收割、用户监控的教程
      - 过滤结果标记：PASS / FAIL / SUSPICIOUS
      
  - stage: CNSH对齐
    engine: cnsh_aligner
    trigger: 过滤通过后自动
    rules:
      - 提取关键概念，生成CNSH语法映射
      - 所有对齐结果存入 knowledge/auto-learned/
      - 每条对齐记录带DNA追溯码
      
  - stage: 场景推演
    engine: scenario_simulator
    trigger: 对齐后自动
    rules:
      - 推演在龍魂生态里的应用场景
      - 生成推演报告：创新点、联动方式、风险
      
  - stage: 推送建议
    engine: recommender
    trigger: 推演后自动
    rules:
      - 可落地 → 生成落地计划，推送老大
      - 不可落地 → 存入知识库，标记"待观察"
      - 老大只需回复"干"或"不干"
```
