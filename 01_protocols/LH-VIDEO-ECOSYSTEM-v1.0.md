## 📋 核心判断

> **视频生态不是“把素材堆在一起”，而是让历史、文化、教育知识自动流入创作管线，经过多智能体协作生成可审计、可发布、可追溯的视频内容。索引是根，智能体是手，外部工具是器，三色审计是闸——人在意图层拍板，系统在执行层自动化。**

## 🔧 三、代码实现

### 3.1 核心脚本

|:---|:---|

## 🚀 四、命令入口

```bash
# 添加素材
lh video-eco --add-material --title "七七事变" --category 抗战 --era "1937" \
  --description "1937年7月7日卢沟桥事变，全面抗战爆发" \
  --keywords "抗战,卢沟桥,1937,七七事变"

# 搜索素材
lh video-eco --search 抗战
lh video-eco --search 七七事变 --category 抗战

# 创建视频（自动检索素材 → 编剧 → 导演 → 剪辑 → 审计 → 工具调用）
lh video-eco --create "抗战精神" --category 抗战 --style 解说

# 查看生态状态
lh video-eco --status

# 列出集成工具
lh video-eco --tools
```

别名：
- `lh veco ...`
- `lh 视频生态 ...`

## 🛡️ 五、安全边界

1. **外部工具默认模拟调用**：`VideoTools.run_tool()` 默认返回 `status: simulated`，不会真实执行任何外部命令，避免未安装工具导致崩溃或误操作。
2. **真实调用需显式安装**：StoryFab/NarratoAI/Vynaro/VideoClaw/video-recap 需按各自仓库独立安装，并在配置中启用 `EXECUTE_TOOLS=true`（v1.1 支持）。
3. **素材不上传云端**：所有素材、脚本、审计结果默认保存在本地 `~/.longhun/video_knowledge` 与 `~/.longhun/video_output`。
4. **敏感词熔断**：审核 Agent 对 "虚构"、"伪造"、"不存在" 等词进行扣分，防止历史内容失真。
5. **人格矩阵降级**：若 `lh_persona_runner.py` 不存在，智能体自动降级为空字典，不影响主流程。

## 🔌 六、扩展接口

### 6.1 添加新的外部工具

在 `08_BIN/lh_video_tools.py` 的 `TOOLS` 字典中新增条目：

```python
"mytool": {
    "name": "MyTool",
    "desc": "我的视频工具",
    "cmd": ["python3", "mytool/main.py"],
},
```

并在 `auto_select()` 映射中添加任务类型到工具 id 的推荐关系。

### 6.2 接入真实 LLM

`VideoAgent.write_script()` 当前使用模板生成。替换为真实 LLM 时，保持返回 `Script` 对象即可，确保 `scenes`、`narration`、`style` 字段完整。

### 6.3 多平台发布

v1.1 计划新增 `08_BIN/lh_video_publish.py`，接收 `VideoEcosystem` 输出，调用各平台 API（CSDN/抖音/B站/视频号），并返回发布 URL 与 DNA。

## 📝 八、日志与审计

1. **素材日志**：`~/.longhun/video_knowledge/{id}.json`，每条素材独立文件，包含完整 DNA。
2. **创建结果**：`VideoEcosystem.create_video()` 运行时打印到 stdout，v1.1 将持久化到 `~/.longhun/video_history/`。
3. **审计结果**：每次创建输出 `audit` 字段，包含 `tricolor`、`score`、`issues`。
4. **DNA 追溯链**：素材 DNA → 脚本 DNA → 分镜 DNA → 剪辑方案 DNA → 创建任务 DNA，形成完整链条。

## ⚠️ 十一、错误处理

| 场景 | 行为 |
|:---|:---|
| 未提供 `--title` 添加素材 | 打印 `❌ 请提供 --title`，退出 |
| 未知外部工具 id | 返回 `{"status": "failed", "error": "未知工具: ..."}` |
| 人格矩阵加载失败 | 降级为空字典，继续执行 |
| 创建视频时主题未命中素材 | 按分类兜底；无分类则 0 素材，仍生成通用脚本 |
| 外部工具真实调用失败 | 保持 `status: simulated`，记录 `exec_error` |
