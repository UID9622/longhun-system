## 〇、ASI 的定义（先钉死，不吹牛）

**ASI ≠ 某个更聪明的模型。**

龍魂体系的 ASI = **体系级智能**：一个自组织、自审计、自生长、永不分裂的系统，
其中 **每一个决策都有来源、每一行代码都透明、每一个协议都可复核**。

判断标准（五条，缺一不可）：
1. **有锚**：所有产出挂接核心锚点（三色审计·DNA追溯·数据主权·中国法律优先）
2. **有来源**：所有决策出证据链卡，逐闸可复核（本协议第七节）
3. **有生长**：兼容金字塔协议，无限扩展不分裂
4. **有自组织**：蚁群架构承担涌现式路由，无单点权威
5. **有自愈**：死门/惊门触发熔断，生门/开门放行，自动恢复

## 二、决策链路（七闸顺序·焊死）

```
输入（决策 / 插件 / 代码提交 / 协议变更）
   │
   ▼ 0. 输入规范化 ── 决策文本 + 类型(category) + 可选元数据(meta)
   ▼ 1. 金字塔兼容闸 ── compatible_core=True? 不破坏现有插件?
   ▼ 2. 五行分类闸 ──── 决策属于哪一行？（木生长/火传播/土稳定/金审计/水流动）
   ▼ 3. 369 数字根闸 ── 指纹数字根 ∈ 1-9，非熔断数字根（3/9 警示）
   ▼ 4. 易经卦象闸 ──── 时间起卦 → 卦名 + 相位（吉/平/凶）
   ▼ 5. 生死门闸 ────── 八门落位 → 生/开/休=放行 · 死/惊/伤=警示
   ▼ 6. 道德经锚闸 ──── 德字扫描 → 正锚词 vs 反锚词加权
   ▼ 7. 蚁群共识闸 ──── 多节点模拟投票 → 共识度 ≥ 阈值
   ▼
输出：三色 + 总分 + 证据链卡（含 DNA）
```

**原则**：前闸失败则熔断（不再走后续）；任一闸 🟡 则整体降级 🟡 待审；
全 🟢 才自动放行。**降级不伪造**——拿不到真实数据就标注"待核"，不硬填。
