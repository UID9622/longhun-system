## 一、协议目的

把「重大决策/融合/升级」从一次跑通变成**收敛工程**：
每一轮跑 → 复盘找细节 → 补正 → 再跑，直到七闸全绿 + 共识全绿 + 攻击测试通过。

## 二、循环骨架

```
┌─ 跑: 七闸裁决 / 多智能体融合 / 攻击测试
├─ 复盘: 逐闸/逐事件找细节（缺什么·为什么·根因在哪）
├─ 补正: 语义等价改写 / 锚点焊死 / 证据补入 / 防御加固
└─ 再跑: 直到终止条件
```

**终止条件（三绿才算跑通）**：
1. 🟢 七闸：金字塔/五行/369/易经/生死门/道德经/蚁群 全绿
   （易经为时间相位驱动，相位=调整时由 P12 六誓验证补正覆盖——记入报告不静默跳过）
2. 🟢 人格共识：无人格反对（反对者须收敛或被明确记录裁决）
3. 🟢 攻击测试：红蓝对抗全载荷防御命中率 100%
