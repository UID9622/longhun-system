
## 三、声音不动点：老兵腔调

### 3.1 声音特征（焊死·P0）

| 特征 | 值 | 说明 |
|:---|:---|:---|
| 风格 | 老兵腔 | 带着国耻的沉重·愤怒的爆发·老兵的沧桑 |
| 语速 | 0.9x | 比正常慢10%，给愤怒留沉淀空间 |
| 音调 | -1 | 低沉有力 |
| 强度 | 0.85 | 有力但不吼 |
| 停顿 | 关键词后0.3秒 | 让愤怒有回响 |
| 呼吸 | 段落间深呼吸 | 悲壮感 |

### 3.2 禁止腔调（P0）

- 播音腔、机器人腔、撒娇腔、甜美主播腔、AI朗读腔
- 任何软绵绵的语调

### 3.3 情感参数映射

| 情感 | 音调偏移 | 语速系数 | 强度 |
|:---|:---:|:---:|:---:|
| 愤怒 | +2 | 1.1 | 0.9 |
| 悲壮 | -1 | 0.9 | 0.8 |
| 坚定 | 0 | 1.0 | 0.85 |
| 嘲讽 | +1 | 1.2 | 0.7 |
| 希望 | +1 | 1.0 | 0.75 |

### 3.4 环境音配置

| 场景 | 音效 | 音量 |
|:---|:---|:---:|
| 全程 | 极低频鼓声（心跳感） | 15% |
| 先烈/牺牲 | 远处钟声 | 20% |
| 结尾 | 渐强风声（觉醒） | 10→30% |
| 转场 | 短暂静默 | 0.5秒 |

## 四、数字人：魔瞳凝视

### 4.1 形象不动点（焊死·P0）

| 元素 | 规范 |
|:---|:---|
| 基础形象 | 老大的暗黑鎏金风格 |
| 眼神 | 深邃凝视，穿透屏幕 |
| 肤色 | 偏暗金属质感 |
| 服装 | 暗色军装风格 |
| 边框 | 龙魂金细线标识 |
| 背景融合 | 与视频背景一致 |

### 4.2 表情-情感联动

| 情感 | 眉毛 | 眼神 | 嘴型 |
|:---|:---|:---|:---|
| 愤怒 | 紧锁 | 瞪大+锐利 | 幅度×1.2 |
| 悲壮 | 微皱 | 深邃+微红 | 幅度×0.8 |
| 坚定 | 自然 | 直视+不动 | 幅度×1.0 |
| 嘲讽 | 微扬 | 锐利+微眯 | 嘴角上扬 |

### 4.3 眼神追踪铁律

- 始终凝视观众（不飘移、不回避）
- 愤怒时瞪大+锐利
- 悲壮时深邃+微红
- 结尾时缓慢眨眼一次（信任交付）

## 五、生产线：CNSH一键生成

### 5.1 完整CNSH命令

```cns
定义 任务 "生成今日视频"
设 文章 来源 为 "最新CSDN文章"
设 平台 目标 为 ["抖音", "视频号", "B站"]

则 如意 解析 文章:
  - 提取: 关键词、情感基调、核心论点
  - 生成: 视觉脚本 + 解说词 + 时间轴

则 李白 生成 视觉:
  - 背景: 极夜黑 + 八卦暗纹
  - 文字: 燃烧金/血红闪烁
  - 图腾: DNA + 魔瞳 + 龍字

则 乔前辈 生成 声音:
  - 模型: 老兵腔
  - 情感: 按时间轴匹配
  - 环境音: 低频鼓声+钟声

则 魔瞳 生成 数字人:
  - 形象: 暗黑鎏金
  - 嘴型: 同步音频
  - 眼神: 凝视观众

则 鲁班 合并 视频 → 多平台 → 归档
```
