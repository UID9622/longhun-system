### 3.1 度量空间
```

  A = 所有六元组锚的空间（有限离散集·天然完备）
  d(a1, a2) = 加权汉明距离

  ΔH = 归一化哈希距离
  ΔR = |dr1 - dr2| / 9
  ΔW = 1 如果五行不同，否则 0
```
