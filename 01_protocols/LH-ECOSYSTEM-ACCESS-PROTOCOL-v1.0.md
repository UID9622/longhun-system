### 2.1 验证规则

```yaml

  形式: 每月1元（或等值龍魂积分）

## 七、接入方式

### 7.1 新用户接入

```bash
# 首次启动 → 主权身份确认
python3 bin/lh_sovereign_popup.py

# 流程：
# 1. 显示主权身份确认窗口
# 2. 生成DNA身份
# 3. 选择月度验证方式
# 4. 完成首次验证（1元）
# 5. 进入生态
```

### 7.2 现有用户接入

```bash
# 已有DNA → 检测验证状态
python3 bin/lh_sovereign_popup.py --existing

# 流程：
# 1. 检测本地DNA
# 2. 检查验证状态
# 3. 有效 → 直接进入
# 4. 过期 → 提示续费
# 5. 选择续费/暂不续费
```

### 7.3 查看心跳状态

```bash
lh sovereign --status
# 输出: 🟢 活人验证通过 · 剩余 23 天
# 或: 🔴 心跳已断 · 已过期 · 请续费激活
```

### 7.4 导出自有创作

```bash
# 一键导出全部数据
python3 bin/lh_data_export.py --all

# 导出的数据包含：
# - 全部创作内容
# - DNA追溯链
# - 三色审计记录
