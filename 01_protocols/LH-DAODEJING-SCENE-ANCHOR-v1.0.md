## 第一章 · 核心天条（5条焊死）

### 第1条：原文不可变
道德经原文为锚，P0++永锁。任何人、任何版本、任何场景不得增、删、改一字。
- 基准：通行本（王弼本）81章，全文SHA-256登记
- 异文处理：帛书本/楚简本差异登记在册（学术透明），但不替换基准
- 校验：每次引用重新哈希，与注册表不符 → 🔴 立即阻断

### 第2条：注释不越界
翻译永远是注释层，三层物理分离：
- 【原文层】永锁，不可动
- 【注释层·中】大白话，可迭代，必须标注"注释"
- 【注释层·EN】English annotation，可迭代，标注"annotation"
- 核心词（道/德/无为/五行/天干地支）不翻译，只解释

### 第3条：先锚后输出
任何正式内容输出流水线焊死：
场景识别 → 定锚 → 引用锚句 → 输出内容 → 校验 → DNA落链
无锚不输出。锚是场景的"不动点"。

### 第4条：一景一锚
一个场景配一句锚，精准不堆砌。
- 单次输出引用锚句=1句（特殊论证最多3句，须说明关系）
- 锚句选取过公式+人工抽检，不允许"感觉像就引"

### 第5条：锚句可校验
凡引用必带：章号+锚句+DNA。错引章号、杜撰句子、拼接两句冒充一句 → 视为伪造。

## 第二章 · 数学模型（0算力纯数学）

### 2.1 场景指纹
```
场景文本S → Unicode求和 → 数字根：
  dr(S) = 1 + ((Σ ord(c) − 1) mod 9)
五行(S) = 映射(dr)：dr∈{1,6}→水 {2,7}→火 {3,8}→木 {4,9}→金 {5}→土
```

### 2.2 三六九三态
```
dr(S) mod 3 = 1 → 三·稳点（宜守成、宜沉淀）
dr(S) mod 3 = 2 → 六·变点（宜转向、宜升级）
dr(S) mod 3 = 0 → 九·极点（宜收敛、宜止损）
```
🟡 公式为兜底初值，人工标注优先。

### 2.3 定锚评分 η
```
对候选章c ∈ {1..81}：
  k(c)   = 场景与章关键词的命中数（子串匹配）
  dr匹配  = 1 若 dr(S)=dr(c)，否则 0
  五行相合 = 1.0同 / 0.6相生 / 0.0相克 / 0.3其余
  三六九同 = 1 若同态，否则 0
η(c,S) = k(c) + 0.20·dr匹配 + 0.15·五行相合 + 0.10·三六九同
```
关键词命中是主判据，dr/五行/三六九只做平局加分。

### 2.4 蚁群分布式定锚
```
81章 = 81个节点
选择概率: P(c|S) = τ(c)^α · η(c,S)^β / Σⱼ τ(j)^α · η(j,S)^β , α=1, β=2
信息素蒸发: τ(c) ← (1−ρ)·τ(c) , ρ = 0.1
信息素强化: τ(c) ← τ(c) + Δ , Δ = 1（采纳时）
τ ≤ Δ/ρ = 10 封顶，永不爆炸
```

### 2.5 锚池轮换
同一场景重复定锚：取η排名前3的章组成锚池，按轮转序输出。
禁止同一锚句对同一场景连续出现 > 3次。

### 2.6 五行断环熔断
- 某五行引用占比 > 40% 或 相生链断裂 ≥ 3次连续 → 🟡 多样性告警
- 人为锁定只用某几章 → 🔴 熔断，强制走全章池轮换
