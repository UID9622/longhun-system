## 三个脚本，做一件事

```
longhun_harvest.py       ← 从 GitHub 收割合规代码
longhun_ast_transform.py ← 把英文代码骨子里换成中文
longhun_pipeline.py      ← 一键主控：搜索→下载→变换→归档
```

零依赖，全用 Python 标准库，下载即用。

---

## 快速开始（3分钟跑通）

### 第一步：导出词典（可选，方便你扩充）

```bash
python3 longhun_ast_transform.py --dump-vocab
# 生成 longhun_vocab.json，打开加入你的专有词汇
```

### 第二步：搜一个库试试（先不下载）

```bash
python3 longhun_harvest.py --query "json parser" --max 5 --no-download
```

### 第三步：完整一键跑

```bash
# 不需要 token（60次/小时够用了）
python3 longhun_pipeline.py --query "http client" --lang python --max 3

# 有 token 更快（5000次/小时）
export GITHUB_TOKEN=你的token
python3 longhun_pipeline.py --query "http client" --max 5
```

### 第四步：只变换本地已有代码

```bash
python3 longhun_pipeline.py --transform-only ./my_downloaded_project
```

## 变换效果（实测）

**输入（英文原版）:**
```python
class UserManager:
    def get_user(self, user_id):
        result = self.database.find(user_id)
        return result

    def save_user(self, user, password):
        data = {"name": user, "password": password}
        self.database.insert(data)
```

**输出（龍魂中文版）:**
```python
class UserManager:
    def 获取_用户(self, 用户编号):
        结果 = self.数据库.查找(用户编号)
        return 结果

    def 保存_用户(self, 用户, 密码):
        数据 = {'name': 用户, 'password': 密码}
        self.数据库.插入(数据)
```

逻辑 100% 不变，变量名/函数名全换成中文。

## GitHub Token 获取

1. 打开 https://github.com/settings/tokens
2. Generate new token (classic)
3. 勾选 `public_repo`（只读就够了）
4. 复制 token

```bash
export GITHUB_TOKEN=ghp_你的token
```
