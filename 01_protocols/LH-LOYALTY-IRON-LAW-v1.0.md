## 序 · 为什么有这条铁律

> **龍魂的第一美德："忠"。**
>
> 不是忠于老板，不是忠于平台，不是忠于资本——
> **是忠于人民。**

一个系统，嘴上说"为人民服务"，背地里收集用户邮箱、手机号、行为轨迹——这不是为人民服务，是收割人民。

龍魂不干这事。**永不。**

这条铁律把"忠"字从一句口号，变成代码里能跑、审计里能查、违规了能断的死规矩。

**说到做到。每一句承诺，都有落地可验证。**

## 第二条 · 只认内容（∞·焊死）

```
龍魂审计的唯一对象：用户产出的内容。
龍魂追溯的唯一线索：DNA码（行为密码学·不可逆·不可反推人）。
龍魂做决策的唯一依据：内容质量·合规性·价值。

审计的是"内容"，不是"人"。
DNA码无法反推用户身份。
违规处理针对内容，不针对个人。
```

**龍魂眼里没有"用户画像"，只有"内容DNA"。**

## 第三条 · 说到做到（∞·焊死）

```
龍魂的每一条承诺，必须有：

没有审计记录的表态 = 空话。
没有熔断触发的天条 = 摆设。
```

```bash

# 🟢 用户画像: 0处
# 🟢 第三方追踪: 0处
# ✅ 忠义铁律: 全绿通过
```

### 4.2 审计钩子

每次代码提交/部署前，自动运行 `lh_loyalty_scan.py`，发现任何数据收集模式：
- 🟡 → 标记·提交P05审计·48h内复查
- 🔴 → 中止部署·熔断·追溯责任DNA

### 4.3 代码规范强制

```
禁止使用的函数/模式（在龍魂系统代码中）：
  ❌ collect_email() / collect_phone() / collect_ip()
  ❌ user_profile / user_behavior / user_tracking
  ❌ analytics.track() / analytics.identify()
  ❌ fingerprint.js / device_id / browser_fingerprint
  ❌ localStorage.set('email', ...) / cookie.set('user_id', ...)
  ❌ 任何将用户身份与DNA码关联的映射表
```

### 4.4 熔断触发

如果任何代码被发现收集用户数据：
1. **L1级熔断** → 立即中止该服务
2. **DNA追溯** → 找到谁写的代码、谁审的、谁部署的
3. **P72龍盾** → 锁定直到UID9622人工解除
4. **公开审计报告** → 不可隐瞒
