## 核心命题

西方工业文明与现代资本将公共治理异化为“二进制管理”：合格/不合格、满意/不满意、有罪/无罪、五星/一星。这套逻辑进入中国基层后，割裂了人情、情境与道理，制造了评分恐怖主义、岗位利益化、奉献精神空心化、舆论道德绑架四大病态。

中国自古以来讲的是“情理法”合一、是“三才”共生、是“因地制宜”、是“身在其职，尽其责”。根性治理的回归，不是复古，而是对西方治理殖民的清醒拒绝。

## 主要创新点

1. **提出“评分恐怖主义”概念**：揭示评分机制如何从市场工具变成社会控制工具。
2. **构建三才三色共治模型**：用中国本土概念替代西方二进制评分。
3. **提出“多源真实性”机制**：打破单一数据源垄断，重建基层治理真实信息流动。
4. **论证“修复文化”优于“问责文化”**：用容错帮扶替代惩罚排名。
5. **区分西方法律治理与中国道理治理**：为基层治理提供文明根性层面的理论支撑。
