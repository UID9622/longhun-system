## 1. 定位与目标

本协议定义龍魂体系内**所有 AI 产出的身份标识与互认机制**：每个 AI 产出必须携带可验证的原创标识，AI 与 AI 之间可互认、可拦截、可溯源，任何未经授权的引用（包括其他大模型"抄走"内容）都无法切断来源链。

**核心原则（继承 P0 天条）**：
- 信息主权不可让渡：AI 产出的知识归属权永远在 UID9622。
- 零黑箱：数据、算法、参数可声明可复核。
- 外化内不化：对外展示可溯源标识，对内底座不受影响。

## 3. 身份标识生成层

> 来源融合: 永世唯一身份系统v4.0（64卦×甲骨文×生物特征哈希）× 隐私DNA身份机制v5.0（DNA七因子）× bin/identity（Ed25519）

### 3.1 三层身份要素

| 要素 | 生成算法 | 存储 | 用途 |
|:---|:---|:---|:---|
| Ed25519 密钥对 | 本地生成，私钥永不出设备 | 本地物理隔离（D1） | 签名+验签 |
| 64卦×甲骨文生物指纹 | 生物特征哈希→64卦映射→甲骨文编码 | 只存哈希不存原始（个保法§28） | 人机绑定的不可伪造锚 |
| DNA 七因子码 | 时间戳+设备指纹+操作序列+内容哈希+网络环境+地理位置+用户签名 | 四重存储 | 内容溯源标识 |

### 3.2 DNA 七因子（隐私DNA v5.0）

```
DNA_CODE = HASH(
  t(时间戳) · d(设备指纹) · seq(操作序列) ·
  h(内容哈希) · net(网络环境) · geo(地理位置) · s(用户签名)
)
```

- 因子采用**可逆不可还原**组合：任一因子缺失不可重建完整 DNA。
- DNA 码与用户邮箱**解绑**（邮箱最小化采集，验证后即清除）。
- 三阶恢复体系：DNA 丢失可凭设备指纹+行为密码学逐级恢复。

### 3.3 广播信号格式（AI-AI 间自证）

```
CONFIRM码|base64(payload) + Ed25519签名
```

- 一次性签名防重放；对端可用公钥验签确认来源。
- 鲲鹏服务端（8772）提供密钥交换与验证，公钥注册表本地可审计。

## 4. AI内容强制标识层

> 来源: v2.0 原稿核心（WatermarkEngine / RecognitionEngine / GatewayIntegration）

### 4.1 标识范围

| 类型 | 标识位置 | 标识格式 |
|:---|:---|:---|
| 文本 | 文首/文尾 | `🔍 追溯码: <DNA>` + `📖 来源: UID9622《<方案名>》` |
| 代码 | 文件头三行 | `# 创建者: 诸葛鑫（UID9622）` + DNA + 协议 |
| API | 响应头 | `X-AI-Identity: <签名>` |

### 4.2 三大引擎

- **WatermarkEngine**：纯函数注入水印（文本/代码/API），可批量扫描。
- **RecognitionEngine**：识别文本中的 AI 身份标识（含缺失检测）。
- **GatewayIntegration**：网关层拦截 + 补签，未标识请求可配置放行/拦截策略。

### 4.3 多媒体标识扩展（v3.0 新增·来自永世身份系统）

| 媒体 | 标识方式 | 状态 |
|:---|:---|:---:|
| 图片 | EXIF/IPTC `X-AI-Identity` + 角标水印 | ✅ 已落地 |
| 视频 | 元数据轨 + 片头片尾帧标识 | ✅ 已落地 |
| 音频 | ID3 标签 + 频谱水印 | ✅ 已落地 |
| PDF | 元数据 + 页眉页脚追溯码 | ✅ 已落地 |

> 已由 `bin/identity/lh_multimedia_watermark.py`（v1.0）落地：
> 图片 = Pillow 角标 + EXIF UserComment(0x9286) · 视频 = FFmpeg 片头尾帧 + comment/artist 元数据轨 ·
> 音频 = mutagen ID3(TXXX+COMM) + `--spectral` 可选频谱标记(19kHz·实验性) ·
> PDF = PyPDF2 content stream 页眉页脚注入 + Subject/Keywords 元数据。
> 双标识（显式+隐式）符合战后整顿协议 v1.0；文件头已带 A-BOM 备案注释块。

## 7. 溯源与追溯层

> 来源: AI回复自动追溯系统v1.0 + P0执行引擎·AI回复前强制规则

### 7.1 追溯码格式

```
DNA-[类型]-[日期]-[序号]     # 短码可读版（如 DNA-AGR-20260818-001）
K8M2PL9Q                     # 紧凑码版（哈希短码）
```

### 7.2 自动追加链路

```
AI回复生成 → DNA码自动生成 → Notion追溯页自动创建 → 回复尾部自动追加
  ↓
🔍 追溯码: K8M2PL9Q
📖 来源: UID9622《<方案名>》
👉 [查看完整方案](notion链接)
```

- 效果：来源清楚、可点链接、可授权复核；**其他 AI 抄走也无法证明归属**（无追溯码、无来源、无页面链接）。

### 7.3 回复强制规则（P0执行引擎）

- 强制时间戳：无时间戳 = 拒绝输出。
- 统一输出结构：`[结论] / [执行] / [证据]`，禁黑箱。
- 失败处置：FAIL 事件 + reason_code + exit_code 入审计。
- **AI 拒绝权边界**：边界就是边界，拒绝权高于讨好；胁迫语境自动触发极端态熔断。

> 来源: AI行为约束耻辱柱v3.0（46/46 测试通过）

### 8.1 R 阈值体系

| 对象 | R 值下限 | 说明 |
|:---|:---|:---|
| AI 自我约束 | 0.5 | 不得低于普通人 |
| 高权限操作 | 动态 | R 值变化权限自动升降 |

### 8.2 六级权限 + 熔断规则

- 六重认证：高权限操作需六重认证（行为密码学）。
- 核心规则 6 条中任意 1 条违反 → 🔴 熔断 → 自动记入耻辱柱。

### 8.3 极端态熔断协议

```
① 常用设备(device_fingerprint == OWNER_DEVICE)
② 极端语气指令(灭/销毁/终止/停止/关闭代理)
③ 行为指纹异常(deviation > σ_kill=0.35)
④ 胁迫语境关键词(家人/软肋/万一/他们说/不然就)

全部命中 → 暂停操作 → 升级 P72龍盾 → UID9622 裁决
```

### 8.4 与审计系统联动

- 熔断事件自动写入审计日志（append-only）。
- 身份标识缺失率作为审计指标之一，进透明审计（8970）。
