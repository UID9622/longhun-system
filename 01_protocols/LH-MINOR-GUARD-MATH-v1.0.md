## §1 归一化半群 N: Σ* → Σ*

### 1.1 定义

设 Σ* 为 Unicode 字符串自由幺半群。五道归一化算子定义为：

| 算子 | 映射 | 操作 |
|:---|:---|:---|
| φ₁ | Σ* → Σ* | 插符去噪：删除 · - _ * ~ · 等插入符 |
| φ₂ | Σ* → Σ* | 全半角归一 + 繁→简：U+FF01-FF5E → U+0021-007E |
| φ₃ | Σ* → Σ* | 形近/火星文映射：嶶→微, V信→微信, 抠抠→QQ |
| φ₄ | Σ* → Σ* | 谐音/拼音映射：mianfei→免费, pifu→皮肤 |
| φ₅ | Σ* → Σ* | 数字谐音：520→我爱你（含白名单保护） |

合成归一化映射（顺序不可交换）：
```
N(T) = φ₅ ∘ φ₄ ∘ φ₃ ∘ φ₂ ∘ φ₁ (T)
```

### 1.2 绕过痕迹量化

```
E(T) = |{ i ∈ {1,2,3,4,5} : φᵢ(T_{i-1}) ≠ T_{i-1} }|
```

其中 T₀ = T, T_i = φᵢ(T_{i-1}) 为链式传递。

半群性质：N²(T) ≈ N(T) 对大多数实际输入成立（幂等逼近），即重复归一化不产生新变化——这是收敛性保证。

绕过痕迹密度：
```
ε(T) = min(1.0, E/5 + 0.3 · L_evasion / L_total)
```
其中 L_evasion = 原始文本中被替换/删除的字符数。

### 1.3 绕过阈值

- E = 0: 无异形，正常输入
- E = 1: 轻微变形（可能是打字习惯）
- E ≥ 2: **明显存在绕过意图**，标记为 Intentional Evasion

## §2 组合判定格

### 2.1 定义

风险空间 (R, ⊑) 构成有界格：
- 风险得分 R ∈ [0, 100]
- 偏序 ⊑: R₁ ⊑ R₂ ⇔ R₁ ≤ R₂
- 最大元 ⊤ = 100 (∞级)
- 最小元 ⊥ = 0 (安全)

分级构成全序子链（嵌入格中）：
```
J0 ⊏ J1 ⊏ J2 ⊏ J3 ⊏ J4 ⊏ ∞
```

### 2.2 三因子评分公式

```
R(T) = min(100, α(T) + β·ε(T) + γ·δ(T))
```

其中：
- **α(T): 词基分** = max_{w ∈ L₂ ∪ L₃ : w ∈ N(T)} base_score(w)
  - L₂（黄线）= 40, L₃（红线）= 70
- **β·ε(T): 绕过惩罚** = 10 · min(E, 3)
- **γ·δ(T): 跨层加成** = 15 · (L_hit - 1) · 1[L_hit > 1]
  - L_hit = (l2_hits > 0) + (l3_hits > 0) ∈ {0, 1, 2}

### 2.3 格的性质

| 性质 | 公理 | 含义 |
|:---|:---|:---|
| 单调非降 | T₁ ⊑ T₂（增加风险词）⇒ R(T₁) ≤ R(T₂) | 更多风险词=更高分 |
| 有界性 | 0 ≤ R(T) ≤ 100 | 得分在有限区间 |
| 幂等性 | R(N(T)) ≈ R(T) | 归一化不改变判定结论 |

### 2.4 J4组合触发（格的跳跃算子）

定义 5 个组合组 C = {A隔绝监护人, B邀约见面, C索取位置, D索取财物, E索取影像}。

J4 组合触发条件：
```
Trigger_J4(T) ⇔ ∃ C_i, C_j ∈ C, i ≠ j : |C_i ∩ N(T)| > 0 ∧ |C_j ∩ N(T)| > 0
```

即 **任意 ≥2 个不同组的词同时命中 → 直接 J4**，不问 R 值。

### 2.5 J4组合格性质

J4 触发高于一切 R 计算——这是格中的"跳跃算子"：
```
R组合 < 80 但 |groups_hit| ≥ 2 ⇒ 级 = J4（跳过 J0-J3）
```

## §3 EWMA 序列滤波器

### 3.1 一阶 IIR 低通滤波模型

```
R̄_t = λ · R_t + (1-λ) · R̄_{t-1},  R̄₀ = 0
```

其中 λ = 0.4 为衰减因子。

**z 变换**：
```
H(z) = λ / (1 - (1-λ) · z⁻¹)
```

**截止频率**：
```
f_c = -ln(λ) / (2π · Δt) ≈ 0.146 / Δt
```

### 3.2 升级判定

```
升级条件: R̄_t ≥ 50 连续 3 窗窗口
```

物理含义：单条消息不判死（R_t 可能只有 40），但如果 EWMA 持续 ≥ 50（等效于滤去单个正常聊天的噪声后仍保持高位），则判定为"有组织的欺骗行为"。

### 3.3 收敛分析

对于常输入 R_t = r（稳定风险水平），EWMA 收敛到 r：
```
lim_{t→∞} R̄_t = r
```

收敛速率：每次迭代缩小差距 (1-λ) = 60%。5 次迭代后剩余不足 8%。

## §4 三视角融合 × 置信度

### 4.1 三视角分解

```
R_A 视角A（文字层）: 词级命中 —— max_word_score + 10·min(E, 3)
R_B 视角B（行为层）: 序列模式 —— 0.6·R̄ + 40·ε(T) + 25·|J4_groups|
R_C 视角C（语境层）: 语义消歧 —— 白名单→0, 语义→10, 否则→0.5·max_word_score
```

### 4.2 加权融合

```
R_final = wA·R_A + wB·R_B + wC·R_C
wA = 0.50, wB = 0.30, wC = 0.20
```

**置信度**：
```
conf = max(0.5, 1.0 - σ / 60)
```
其中 σ 为三视角得分的标准差。σ > 30 时 conf < 0.5 → 三视角矛盾大 → 路由至人工复核。

## §5 误报率约束

### 5.1 数学保证

目标 Precision(J3+) ≥ 99%。实现方式：

1. **置信度阈值**: conf < 0.7 → 🟡人工复核（不做机器终审）
2. **单关键词不加权**: 必须有组合因子或跨层命中才升 J3+
3. **语境白名单**: 消歧项直接降级为 J0
4. **语义白名单**: 常见正常短语保护

### 5.2 路由矩阵

| 级别 | conf ≥ 0.7 | conf < 0.7 |
|:---|:---|:---|
| J0/J1 | 直接放行 | 直接放行 |
| J2 | 拦截 | 拦截 + 🟡标记 |
| J3/J4 | 熔断/报警 | 🟡人工复核 + 预标 |
