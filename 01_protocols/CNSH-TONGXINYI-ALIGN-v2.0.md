## §2. 双向不对称原则

### 为什么不对称？

```
人气→CNSH (压缩方向):  信息密度提升·去冗余·符号化
CNSH→人气 (展开方向): 信息扩散·补语境·人可读

压缩率目标: ≥ 3.0x
展开保真度: ≥ 0.92
```

### 不对称度量

```
压缩不对称指数:
  A_compress = CR(中→CNSH) / CR(英→CNSH)
  目标: A_compress ∈ [0.8, 1.2]（中英对称压缩）

展开不对称指数:
  A_expand = Fidelity(CNSH→中) / Fidelity(CNSH→英)
  目标: A_expand ∈ [0.9, 1.1]（中英对称展开）
```

## §4. 语义磨损检测

### 磨损定义

语义磨损 = 翻译过程中语义信息丢失

```
Wear_rate = 1 - Total_Alignment

最大允许磨损: 10%（即 Total_Alignment ≥ 0.90）
危险磨损: >25%（即 Total_Alignment < 0.75）
```

### 磨损分类

| 类型 | 描述 | 常见原因 | 对策 |
|:---|:---|:---|:---|
| 词汇磨损 | 专业术语丢失 | 词典不全 | 自动补词·人工复核 |
| 语法磨损 | 句式结构变形 | 语序差异 | 句法树对齐 |
| 意图磨损 | 核心意思偏差 | 歧义 | 意图向量双重校验 |
| 语境磨损 | 背景信息丢失 | 上下文截断 | 上下文窗口拓展 |
| 文化磨损 | 文化内涵消失 | 文化不可译 | 文化锚点保留标记 |
