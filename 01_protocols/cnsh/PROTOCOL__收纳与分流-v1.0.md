## 0. 老大原话（写死）

- **清洗不是洗没了，是收纳。**
- **不占位**：未审计内容不得占 L0/P0 规则位、不得占执行链默认路径。
- **禁区**：已证明错误且影响面大的方法/观点 → 标记禁区 · 熔断 · 可检索但**不可当系统依据**。
- **不是逃避**：不删历史；不拿自己以外的人当实验对象（伦理不动点）。

---

## 1. 三分仓（所有粘贴/投喂先进这里）

| 仓 | 名称 | 条件 | 动作 |
|----|------|------|------|
| **正本** | L0–L1 祠堂 | 你拍板 + DNA + 三色🟢 + 不动点编号 | 写入 `01_protocols/` · 同步 Notion 正本 |
| **收纳** | 沙盒档案 | 🟡 或 待你审 · 有创意/有结构 | `sandbox/intake/` + 花名册·桶4 |
| **禁区** | 熔断封存 | 🔴 或 禁区表命中 · 禁止推广为家法 | `sandbox/forbidden/` · 只读对照 · 不执行 |

**未分流前**：一律 `execute_allowed=false`（与第一道闸门一致）。

## 2. 自动分流管线（本地）

```
粘贴/文件/外源投喂
  → cnsh.intake.triage()     # 收纳分拣
  → gate_v3.decide()         # 闸门
  → 语义抽屉 detect          # 通心译归一（别名→抽屉→职责）
  → 输出 INTAKE 记录 + 建议桶 + Notion 同步提示
```

工程入口：`python3 -m cnsh.intake.triage --file sandbox/intake/xxx.md`

## 3. 通心译 vs 花名册（两层·别混）

| 层 | 是什么 | 干什么 |
|----|--------|--------|
| **语义抽屉** | 通心译词典 v1.2 的工程切片 | 别名→抽屉→职责；**只归义，不调度** |
| **花名册** | 家族中枢神经 `FAMILY-ROSTER.local.yaml` | 谁在用、什么模块、升格/降级、全链联动 |

升格 ≠ 抽屉升级版。升格 = **花名册登记 L2 模块** + IPA 编号 + `decision_chain` 可回放。

- **不划掉**多种说法（量子甲骨文 / 易经64 / 甲骨占卜…）。
- **归并**到：抽屉 ID → 花名册模块 → `[IPA-xxx]`。
- 对外话术可变；对内编号不变。
