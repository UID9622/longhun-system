```json
{
  "message": "你的输入",
  "operator_id": "UID9622",
  "operator_tier": "T0",
  "channel": "cursor",
  "auto_execute": false,
  "tags": {
    "confirm_code": "#CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z",
    "gpg": "A2D0092CEE2E5BA87035600924C3704A8CC26D5F"
  }

```

- `auto_execute: false` → **过闸门+流场审计，但不执行**（你要的「放着等审计」）
- `auto_execute: true` → 闸门🟢且显式授权后才跑完整执行链

### 投喂并进流场（一单清·不用你再选）

网关：`127.0.0.1:8765` · 头：`X-DNA-Token` = `.env` 里 `DNA_TOKEN`。与 Notion [专用投喂入口 v1.1](https://www.notion.so/4dfcb90d97344139b823e49a6ebac696) 同一语义：先过流场闸门，再 **`feeding_gateway` 落档**；返回 JSON 顶栏有人话 **「【投喂·一单清】」**，下面仍是原流场 `reply`。

任选一种触发：`"mode": "feed"`，或 `tags.feed: true`，或 `message` 以 **`/投喂`** 开头。

```bash
curl -s -X POST http://127.0.0.1:8765/flow \
  -H "Content-Type: application/json" \
  -H "X-DNA-Token: 你的DNA_TOKEN" \
  -d '{
    "mode": "feed",
    "message": "第一条当标题（可改短）\n\n后面全是正文，随便粘。",
    "operator_id": "UID9622",
    "operator_tier": "T0",
    "channel": "drop_zone",
    "auto_execute": false,
    "tags": {
      "confirm_code": "#CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z",
      "gpg": "A2D0092CEE2E5BA87035600924C3704A8CC26D5F"
    }
  }'
```

大块粘贴可用 **`tags.title` + `tags.content`**（避免和 `/投喂` 抢第一行）。`source_type` 默认 **F1**，若要改：`tags.source_type` 或顶层 `"source_type":"F2"`。
