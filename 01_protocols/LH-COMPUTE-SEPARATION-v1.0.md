## 二、第一步：本地数据保险柜
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**引擎**：`engines/lh_local_vault.py`

### 2.1 保险柜架构

- 存储路径：`~/.longhun/vault/`
- 加密：AES-256-GCM
- 密钥派生：设备指纹 + 用户密码 + 生物特征盐 → HKDF-SHA256
- 数据分类型存储：浏览记录、AI对话、文件、行为数据、用户偏好
- 读取：需要生物特征验证
- 写入：自动加密，无需验证
- 删除：需要生物特征 + DNA 追溯码双重验证
- 审计：每次访问/修改均记录审计日志，只冻结不删除

### 2.2 数据分类

| 类型 | 敏感度 | 加密强度 | 访问控制 |
|:---|:---:|:---:|:---|
| 浏览历史 | D2 | AES-256-GCM | 生物特征 |
| AI对话 | D1 | AES-256-GCM | 生物特征+DNA |
| 下载文件 | D2 | AES-256-GCM | 生物特征 |
| 行为模式 | D1 | AES-256-GCM | 生物特征+DNA |
| 用户偏好 | D3 | AES-256-GCM | 密码 |
| 设备指纹 | D1 | AES-256-GCM | 仅系统内部读写 |

### 2.3 浏览器史官升级

浏览器史官 v2 统一走保险柜后端：
- storage.backend = local_vault
- data_types: browsing_history / ai_conversations / downloaded_files / behavior_patterns / user_preferences
- access_control: read 需生物特征 / write 自动加密 / delete 需双重验证

## 三、第二步：零信任计算管道
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**引擎**：`bin/lh_stateless_compute_api.py`（鲲鹏部署，端口8785）

### 3.1 脱敏处理引擎（本地）

- 实体识别 → 敏感信息替换（PERSON/LOCATION/ORG/TIME/CONTACT）
- 语义泛化 → 将具体请求映射为标准语义模板
- 替换映射加密存储于本地，用于结果还原
- 原始请求哈希用于链路验证

### 3.2 无状态API网关（鲲鹏）

| 参数 | 值 |
|:---|:---|
| 端口 | 8785 |
| 安全 | TLS 1.3 + 双向证书 |
| 会话超时 | 300秒 |
| 最大持久存储 | 0（零留存） |
| 日志级别 | none |
| 数据留存策略 | immediate_deletion |

核心流程：接收脱敏请求 → 分配算力（内存中处理） → 返回结果+算力证明 → 立即清除所有临时数据 → 验证内存零残留。

### 3.3 算力证明字段

| 字段 | 说明 |
|:---|:---|
| session_id | 会话唯一ID |
| request_hash | 请求哈希 |
| result_hash | 结果哈希 |
| model_used | 使用模型 |
| compute_start/end | 计算开始/结束时间 |
| node_id | 计算节点 |
| data_retention | ZERO（零留存声明） |
| signature | 鲲鹏私钥 ECDSA-secp256k1 签名 |

## 四、第三步：算力证明

**引擎**：`bin/lh_compute_proof.py`

### 4.1 证明验证流程

1. 验证鲲鹏签名（ECDSA-secp256k1，本地公钥验签）
2. 验证请求哈希一致性（防传输篡改）
3. 验证零留存声明（data_retention == "ZERO"）
4. 归档到本地保险柜

### 4.2 审计链

- 所有算力证明的完整记录
- Merkle根完整性验证
- DNA追溯：`#龍芯⚡️{干支}·{干支}·{干支}·{干支}·{卦名}-COMPUTE-PROOF-{session_id}`

## 五、第四步：同心锁·物理闸门
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**复用**：`bin/lh_tongxin_lock_firewall.py` + `bin/lh_tongxin_lock_monitor.py`

**引擎**：`bin/lh_compute_gate_controller.py`

### 5.1 闸门控制

- 默认关闭，只有生物特征验证后临时打开
- 只允许鲲鹏IP:8785，TLS 1.3
- 300秒超时自动关闭，计算完成立即关闭
- 异常立即熔断

### 5.2 监控告警

| 告警 | 触发条件 | 动作 |
|:---|:---|:---|
| 闸门打开过长 | >300秒 | 自动关闭 |
| 未授权访问 | 非法IP/端口尝试 | 熔断+告警 |
| 生物特征失败 | 连续3次 | 锁定15分钟 |
| 鲲鹏响应异常 | 签名无效/超时/连接断开 | 断开+告警 |
