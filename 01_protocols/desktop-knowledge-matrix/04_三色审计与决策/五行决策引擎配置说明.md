## 2. 核心公式说明

### 2.1 公式A：五行平衡指数

```
平衡指数 = 100 - (σ/avg × 100)

其中：
  σ   = 五行能量的标准差
  avg = 五行能量的平均值
  CV  = σ/avg = 变异系数

输出范围：0 - 100
  100 = 完美平衡（所有五行能量相等）
  0   = 极度失衡（某一五行能量为0）

熔断阈值：平衡指数 < 20 触发熔断
```

**Python实现:**
```python
balance_index = FormulaA_BalanceIndex.calculate(five_core)
```

### 2.2 公式B：相生相克强度

```
强度 = G(A→B) - R(A⇒B)

其中：
  G(A→B) = A对B的相生强度（和谐度）
  R(A⇒B) = A对B的相克强度（冲突度）

输出范围：-1 ~ 1
  > 0 : 相生主导（关系和谐）
  < 0 : 相克主导（存在冲突）
  = 0 : 阴阳平衡

相生链：木 → 火 → 土 → 金 → 水 → 木
相克链：木克土，土克水，水克火，火克金，金克木

熔断阈值：相克强度 > 0.85 触发熔断
```

**Python实现:**
```python
formula_b = FormulaB_GenerateRestraint(five_core)
strength = formula_b.calculate(FiveElement.WOOD, FiveElement.FIRE)
```

### 2.3 公式C：三才平衡系数

```
C = Heaven×0.35 + Earth×0.20 + Human×0.45

其中：
  Heaven = 天维度评分（0-1）
  Earth  = 地维度评分（0-1）
  Human  = 人维度评分（0-1）

输出范围：0 - 1
```

**铁律**: `Human ≥ 0.34`（人永远不低于34%）

**Python实现:**
```python
sancai = SancaiBalance(heaven=0.35, earth=0.20, human=0.45)
formula_c = FormulaC_SancaiCoefficient(sancai)
coefficient = formula_c.calculate(heaven_score=0.8, earth_score=0.7, human_score=0.9)
```

### 2.4 公式D：复合决策强度

```
D = A×0.35 + B×0.30 + C×0.35

其中：
  A = 五行平衡指数（归一化到 0-1）
  B = 1 - |相生相克强度|（越小表示越平衡）
  C = 三才平衡系数

权重分配：
  A(平衡指数):  35%
  B(生克强度):  30%
  C(三才平衡):  35%

输出范围：0 - 1
  该值同时作为最终置信度

熔断阈值：置信度 < 0.40 触发熔断
```

**Python实现:**
```python
result = FormulaD_CompositeDecision.calculate(
    balance_index=85.0,       # 公式A结果
    net_strength=0.1,         # 公式B结果
    sancai_coefficient=0.8,   # 公式C结果
)
score = result["composite_score"]      # 复合得分
confidence = result["confidence"]      # 置信度
decision = result["decision"]          # PASS 或 FUSE
```

## 4. 三才平衡系统

### 4.1 三才定义

| 维度 | 权重 | 含义 | 作用 |
|------|------|------|------|
| 天(Heaven) | 0.35 | 天时/战略 | 方向判断 |
| 地(Earth) | 0.20 | 地利/资源 | 资源评估 |
| 人(Human) | 0.45 | 人和/执行 | 人为因素 |

### 4.2 铁律

> **Human ≥ 0.34**（人永远不低于34%）

当配置中Human权重低于0.34时，系统会自动调整权重分配，强制将Human提升至0.34，其余权重按比例缩减。

### 4.3 自动归一化

系统会自动对三才权重进行归一化处理，确保三者之和为1.0。

## 5. 熔断条件详解

### 5.1 熔断规则总表

| 规则编号 | 条件 | 说明 | 优先级 |
|----------|------|------|--------|
| R1 | `dr ∈ {3, 9}` | 决策路由值为3或9时直接熔断 | 最高 |
| R2 | `AI自审失败` | AI自我审核未通过时熔断 | 高 |
| R3 | `置信度 < 0.40` | 最终置信度低于40%时熔断 | 高 |
| R4 | `平衡指数 < 20` | 五行平衡指数低于20时熔断 | 高 |
| R5 | `相克强度 > 0.85` | 五行相克强度超过0.85时熔断 | 高 |

### 5.2 熔断检测代码示例

```python
fuse = FuseDetector()
result = fuse.full_check(
    dr=5,                    # 决策路由值
    audit_passed=True,       # AI自审是否通过
    confidence=0.85,         # 置信度
    balance_index=75,        # 平衡指数
    restraint_intensity=0.2, # 相克强度
)

if result["fused"]:
    print(f"熔断触发！原因: {result['fuse_reasons']}")
else:
    print("熔断未触发，可以执行决策")
```

## 7. 价值观体系

### 7.1 铁律：忠 > 孝 > 义

| 价值观 | 标准权重 | 含义 |
|--------|----------|------|
| 忠 | 0.5 | 最高优先级 |
| 孝 | 0.3 | 次优先级 |
| 义 | 0.2 | 基础优先级 |

### 7.2 校验规则

- `忠` 的权重必须最高
- `孝` 的权重必须次之
- `义` 的权重必须最低
- 标准配置必须为 `忠(0.5) > 孝(0.3) > 义(0.2)`

### 7.3 代码示例

```python
validator = ValueSystemValidator()
check = validator.validate({"忠": 0.5, "孝": 0.3, "义": 0.2})
if not check["valid"]:
    print(f"价值观违规: {check['errors']}")
```

## 9. 快速开始

### 9.1 安装与导入

```python
# 直接导入模块
from 五行融合决策引擎_v3_0 import (
    WuxingDecisionEngine, FiveElementsCore, FiveElement,
    SancaiBalance, FuseDetector, ThreeColorAudit
)
```

### 9.2 基本使用

```python
# 步骤1: 创建引擎
engine = WuxingDecisionEngine(uid="UID9622", operator="操作者名称")

# 步骤2: 初始化
engine.initialize(
    energies={
        FiveElement.WOOD: 20,
        FiveElement.FIRE: 20,
        FiveElement.EARTH: 20,
        FiveElement.METAL: 20,
        FiveElement.WATER: 20,
    },
    sancai_config={"heaven": 0.35, "earth": 0.20, "human": 0.45}
)

# 步骤3: 执行决策
result = engine.decide({
    "dr": 5,                        # 决策路由值
    "heaven_score": 0.8,            # 天维度评分
    "earth_score": 0.7,             # 地维度评分
    "human_score": 0.9,             # 人维度评分
    "ai_audit_passed": True,        # AI自审是否通过
    "values": {"忠": 0.5, "孝": 0.3, "义": 0.2},  # 价值观权重
    "context": {"scenario": "示例决策"},           # 附加上下文
})

# 步骤4: 查看结果
print(f"决策结果: {result['decision']}")          # EXECUTE 或 REJECT
print(f"复合强度: {result['formulas']['D_composite']['composite_score']}")
print(f"审计状态: {result['audit']['color']} {result['audit']['status']}")
print(f"是否熔断: {result['fuse_check']['fused']}")
```

### 9.3 查看引擎报告

```python
report = engine.get_report()
print(f"总决策数: {report['statistics']['total_decisions']}")
print(f"通过执行: {report['statistics']['executed']}")
print(f"被拒绝: {report['statistics']['rejected']}")
```
