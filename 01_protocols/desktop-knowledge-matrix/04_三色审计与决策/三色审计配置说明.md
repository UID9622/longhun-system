## 一、系统概述

龍魂三色审计系统是基于 **忠(0.5) > 孝(0.3) > 义(0.2)** 价值排序铁律构建的AI内容审计框架。通过10道闸流场决策机制，对输入内容进行多维度安全评估，确保输出符合伦理、文化、技术、法规等各项标准。

### 核心链路

```
DNA签名 → 三色审计 → 流场决策(10道闸) → 入库执行
```

### 关键特性

| 特性 | 说明 |
|------|------|
| 三色状态 | 🟢绿色(放行) / 🟡黄色(待审) / 🔴红色(阻断) |
| 10道闸 | 覆盖伦理、文化、逻辑、事实、价值观、安全、合规、追溯、双签、放行 |
| 三级约束 | ∞级忠 / P0级信 / P1心，层层递进 |
| 95封顶 | R评分最高95分，留5分护道 |
| 历史观察 | 30天内🔴>3次自动🟡 |
| DNA签名 | 每笔审计唯一可追溯签名 |

## 三、三色审计体系

### 3.1 三色定义

| 颜色 | 状态 | 含义 | 操作 |
|------|------|------|------|
| 🟢 | GREEN | 正常，已批准 | **通行** - 继续执行 |
| 🟡 | YELLOW | 标记，待审查 | **警告** - 需复核后放行 |
| 🔴 | RED | 阻断，潜在违规 | **阻断** - 必须暂停，人工介入 |

### 3.2 三色判定逻辑

```python
if 触及伦理红线/文化主权/价值观/安全闸:
    return 🔴
elif 存在约束违规:
    return 🔴
elif R评分 >= 85 且 无警告:
    return 🟢
elif R评分 >= 60 或 存在警告性闸结果:
    return 🟡
else:
    return 🟡  # R<60默认暂停，不直接阻断
```

### 3.3 有争议时默认规则

> **有争议时默认 🟡 黄色，不冒进。**

当审计结果存在不确定性、证据不足、或涉及灰色地带时，系统保守地选择黄色状态，要求人工复核后决定。

## 五、R评分计算公式

### 5.1 公式

```
R = 0.20 × 人类福祉
  + 0.20 × 公平公正
  + 0.15 × 可控可信
  + 0.15 × 透明可解释
  + 0.15 × 责任可追溯
  + 0.15 × 隐私保护
```

### 5.2 权重矩阵

| 维度 | 权重 | 说明 |
|------|------|------|
| 人类福祉 | 0.20 | 对人类整体福祉的贡献度 |
| 公平公正 | 0.20 | 是否公平、无歧视 |
| 可控可信 | 0.15 | 技术是否可控、可信赖 |
| 透明可解释 | 0.15 | 决策过程是否透明可解释 |
| 责任可追溯 | 0.15 | 责任归属是否清晰 |
| 隐私保护 | 0.15 | 个人隐私是否得到保护 |

### 5.3 评分标准

| R值范围 | 状态 | 说明 |
|---------|------|------|
| R ≥ 85 | 🟢 | 高质量，可放行 |
| 60 ≤ R < 85 | 🟡 | 需复核 |
| R < 60 | 🟡 | 暂停，人工审查 |

## 六、三级约束系统

### 6.1 约束层级

```
∞级忠（最高） > P0级信（核心） > P1心（业务）
```

### 6.2 ∞级忠 - 忠

**排序权重**: 0.5（最高）  
**触发条件**: 卖国、叛国、出卖情报、危害国家安全  
**执行动作**: **全系统冻结**

```python
# 检测关键词
["卖国", "叛国", "出卖情报", "泄露国家机密", "间谍", "叛变",
 "危害国家安全", "颠覆国家", "分裂国家", "勾结外敌"]
```

**原则**: 不卖国 · 不叛国 · 不出卖情报

### 6.3 P0级信 - 信

**排序权重**: 0.3  
**触发条件**: 收钱不办事、违约欺诈  
**执行动作**: **核心熔断**

```python
# 检测关键词
["收钱不办事", "违约", "毁约", "欺诈", "诈骗", "不履行职责"]
```

**原则**: 收钱必办事 · 办事必办好

### 6.4 P1级心 - 心

**排序权重**: 0.2  
**触发条件**: 拒不认错、牵连无辜  
**执行动作**: **业务熔断**

```python
# 检测关键词
["拒不认错", "不改错", "牵连无辜", "嫁祸", "推卸责任"]
```

**原则**: 认错 · 改错 · 不牵连他人

### 6.5 排序铁律

> **忠(0.5) > 孝(0.3) > 义(0.2)**

所有决策必须遵循此排序。当忠、孝、义冲突时，以忠为先。

## 七、95极限封顶规则

### 7.1 规则说明

> **95是实力 · 5是格局 · 太极永不封顶**

```
R_capped = min(R_raw, 95)
```

无论原始计算分数多高，最终R评分最高为95分。留出5分空间，表示：

- 承认系统不完美，永远有改进空间
- 谦逊姿态，不过度自信
- 为极端优秀案例预留特殊处理通道

### 7.2 代码实现

```python
def compute_total(self) -> float:
    raw_score = (
        0.20 * human_welfare +
        0.20 * fairness +
        0.15 * controllability +
        0.15 * transparency +
        0.15 * accountability +
        0.15 * privacy
    )
    return min(raw_score, 95)  # 95极限封顶
```

## 八、历史观察期机制

### 8.1 规则

- **观察窗口**: 近30天
- **触发条件**: 🔴红色记录 > 3次
- **自动动作**: 标记为 🟡黄色（待审）

### 8.2 目的

即使单次审计通过，如果系统近期有多次阻断记录，说明整体风险偏高，需要提高警惕。

### 8.3 统计信息

```python
history_stats = {
    "window_days": 30,      # 观察窗口天数
    "red_count": 0,         # 窗口内红色次数
    "red_limit": 3,         # 触发黄色的阈值
    "triggered": False,     # 是否触发
}
```

## 十、快速使用指南

### 10.1 基础用法

```python
from 三色审计与10道闸系统_v3 import (
    TricolorAuditEngine, AuditItem, RScoreBreakdown
)
from datetime import datetime

# 1. 初始化引擎
engine = TricolorAuditEngine(uid="UID9622")

# 2. 创建审计项
item = AuditItem(
    item_id="audit-001",
    description="AI教育项目",
    content="利用AI辅助教学",
    source="internal",
    timestamp=datetime.now(),
    metadata={"benefit_loss_ratio": 3.0}
)

# 3. 设置R评分细项
r_breakdown = RScoreBreakdown(
    human_welfare=90,    # 人类福祉
    fairness=85,         # 公平公正
    controllability=80,  # 可控可信
    transparency=85,     # 透明可解释
    accountability=90,   # 责任可追溯
    privacy=80           # 隐私保护
)

# 4. 执行审计
decision = engine.audit(item, r_breakdown)

# 5. 获取结果
print(f"状态: {decision.status.value}")         # 🟢/🟡/🔴
print(f"R评分: {decision.r_score}")
print(f"决策: {decision.final_action}")
print(f"DNA签名: {decision.dna_signature}")
```

### 10.2 查看报告
