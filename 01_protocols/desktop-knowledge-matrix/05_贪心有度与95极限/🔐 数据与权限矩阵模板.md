# 数据与权限矩阵（Data & Permissions Matrix Template）

## 权限等级定义

- **SYSTEM**：系统级访问，只有核心系统组件
- **PERSONAS**：人格级访问，经授权的AI人格
- **UID9622**：最高管理员权限，系统中枢专有
- **ADMIN**：管理员级别，可配置和管理
- **READ**：只读权限
- **WRITE**：读写权限

---

## 核心资源权限矩阵

| Resource | Type | Read | Write | Admin | Notes |
| --- | --- | --- | --- | --- | --- |
| Content Items DB | Notion DB | SYSTEM / PERSONAS | SYSTEM | UID9622 | 默认加密字段: activation |
| Activations Store | Encrypted File / Vault | SYSTEM | SYSTEM | UID9622 | 存放激活码加密 + 审计日志 |
| Backups | S3 / Encrypted | SYSTEM | SYSTEM (ops) | UID9622 | 版本保留 90 天 |
| API Keys | Secret Manager | - | - | UID9622 | 定期轮换策略 30 天 |
| System Config | Notion Pages | PERSONAS | ADMIN | UID9622 | 包含系统参数和配置 |
| Audit Logs | Notion DB | SYSTEM / ADMIN | SYSTEM | UID9622 | 不可删除，只能追加 |

## 人格权限分级

### L5 最高权限（系统中枢）

- **UID9622 系统中枢**
- **权限范围**：所有资源的完全访问权
- **特殊能力**：激活码管理、系统关闭、紧急回滚

### L4 高级权限（治理层）

- **雯雯-内控**
- **安全官**
- **PMO-路线图**
- **权限范围**：跨模块管理、审计执行、权限分配

### L3 中级权限（专业层）

- **数据大师**
- **架构师-激活码**
- **架构师-工程**
- **权限范围**：专业领域全权、跨领域读取

### L2 基础权限（操作层）

- **外交官**
- **译者**
- **情报官-科技**
- **权限范围**：本领域读写、其他领域只读

### L1 限制权限（新手/临时）

- **新增人格**
- **临时访问者**
- **权限范围**：仅公开文档读取、个人任务操作

---

## 数据分级与保护

### 数据分类

- **公开级**：所有人可访问，如文档模板
- **内部级**：仅系统内部人格可访问
- **保密级**：需要特殊授权，如激活码
- **机密级**：仅系统中枢可访问

### 加密策略

- **静态加密**：所有存储数据默认加密
- **传输加密**：所有API调用必须HTTPS/TLS
- **密钥管理**：定期轮换，多重备份
- **访问控制**：双重认证 + 行为监控

---

## 审计与监控

### 访问日志

**记录内容**：

- 用户ID / 人格标识
- 操作时间和操作类型
- 访问资源和权限级别
- 操作结果和异常信息

### 权限变更日志

**记录内容**：

- 变更时间和变更人
- 变更前后权限对比
- 变更原因和批准记录
- 影响范围和回滚计划
