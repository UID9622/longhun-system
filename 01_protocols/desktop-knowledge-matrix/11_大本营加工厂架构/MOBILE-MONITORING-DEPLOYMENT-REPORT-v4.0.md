```bash
# 查看環境配置
cat .env.monitoring

# 修改採樣率 (降低成本)
sed -i 's/LONGHUN_SAMPLE_RATE=1.0/LONGHUN_SAMPLE_RATE=0.5/' .env.monitoring

# 重新部署
bash mobile-monitoring/deploy-all.sh
```

### **故障排查**

```bash
# 查看隊列中的事件
```
