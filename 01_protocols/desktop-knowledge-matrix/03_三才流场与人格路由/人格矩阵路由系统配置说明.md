## 1. 系统概述

人格矩阵路由系统 v3.0 是龍魂体系的核心决策引擎，基于五大元知（军事/历史/哲学/经济/政治）构建AI人格的动态调配和决策路由机制。系统采用7步叠加算法，结合价值校准（忠孝义信和）和三色审计，实现智能化的情境感知和人格路由。

### 核心特性

- **五大元知体系**: 军事(MIL)、历史(HIS)、哲学(PHI)、经济(ECO)、政治(POL)
- **7步叠加算法**: 情境解析 → 权重初分配 → 价值校准 → 资源约束 → 情报修正 → 归一化 → 路由生成
- **6种路由模板**: 军事主导、哲学主导、经济主导、政治主导、历史主导、均衡型
- **价值校准**: 基于忠(0.5)、孝(0.3)、义(0.2)、信(0.15)、和(0.15)的伦理校准
- **三色审计**: 🟢正常 / 🟡警告 / 🔴严重的质量监督机制
- **反馈回路**: 基于结果反馈的自适应校准机制
- **DNA签名**: 每个决策的唯一身份标识

## 4. 价值优先级体系

### 价值权重表

| 价值 | 权重 | 校准目标 | 校准乘数 | 说明 |
|------|------|----------|----------|------|
| **忠** | 0.50 | MIL(军事) | 1.2 | 最高优先级，军事思维增强 |
| **孝** | 0.30 | HIS(历史) | 1.1 | 历史思维增强 |
| **义** | 0.20 | PHI(哲学) | 1.3 | 哲学思维显著增强 |
| **信** | 0.15 | ECO(经济) | 1.2 | 经济思维增强 |
| **和** | 0.15 | POL(政治) | 1.3 | 政治思维显著增强 |

### 校准公式

```
calibration_factor = 1.0 + (multiplier - 1.0) * priority_weight * 2

例如: 忠 → MIL
  calibration_factor = 1.0 + (1.2 - 1.0) * 0.50 * 2 = 1.20
  MIL权重 *= 1.20
```

## 5. 7步叠加算法详解

### 步骤流程图

```
输入文本/指令
    │
    ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 1.情境解析  │───▶│ 2.权重初分配 │───▶│ 3.价值校准  │
│ 识别情境类型 │    │ 基础权重计算  │    │ 忠孝义信和  │
└─────────────┘    └─────────────┘    └─────────────┘
    │
    ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 4.资源约束  │───▶│ 5.情报修正  │───▶│ 6.归一化   │
│ 检查资源边界 │    │ 实时情报调整  │    │ 标准化权重  │
└─────────────┘    └─────────────┘    └─────────────┘
    │
    ▼
┌─────────────┐    ┌─────────────┐
│ 7.路由生成  │───▶│ 输出决策结果 │
│ 6种模板匹配 │    │ + DNA签名   │
└─────────────┘    └─────────────┘
```

### 各步骤详细说明

#### 步骤1: 情境解析
- **模块**: `SituationParser`
- **功能**: 基于关键词匹配和规则评分自动识别情境类型
- **输出**: `SituationContext`（包含情境类型、紧急度、复杂度等参数）
- **配置**: 可通过 `KEYWORD_MAP` 自定义关键词

#### 步骤2: 权重初分配
- **模块**: `WeightDistributor`
- **功能**: 基于6种基础模板分配初始权重
- **输出**: `(路由类型, 元知权重映射)`
- **微调因子**: 紧急度、复杂度、资源稀缺性、利益相关方数量

#### 步骤3: 价值校准
- **模块**: `ValueCalibrator`
- **功能**: 基于五大价值对权重进行伦理校准
- **输出**: `(校准后权重, 应用的校准值)`

#### 步骤4: 资源约束
- **模块**: `ResourceConstraintChecker`
- **功能**: 检查决策是否在资源约束范围内
- **资源类型**: 计算力、时间、数据、人力、风险容忍度

#### 步骤5: 情报修正
- **模块**: `IntelligenceCorrector`
- **功能**: 基于实时情报和历史效能修正权重
- **输入**: 情报缓冲区（最近50条）

#### 步骤6: 归一化
- **模块**: `NormalizationEngine`
- **策略**: SOFTMAX / LINEAR / POWER / ENTROPY_BALANCED
- **默认**: ENTROPY_BALANCED（保持多样性）

#### 步骤7: 路由生成
- **模块**: `RouteGenerator`
- **功能**: 基于6种模板生成完整决策路由
- **输出**: 决策路径、推荐行动、风险评估

## 7. 模块配置说明

### 7.1 引擎配置参数

```python
engine = PersonaMatrixEngine(config={
    "active_values": ["忠", "孝", "义", "信", "和"],  # 激活的价值维度
    "resources": {                                    # 可用资源
        "compute": 1.0,       # 计算力
        "time": 1.0,          # 时间
        "data": 1.0,          # 数据
        "human": 1.0,         # 人力
        "risk_tolerance": 1.0 # 风险容忍度
    },
    "intel_buffer_size": 50,   # 情报缓冲区大小
    "temperature": 1.0,        # 归一化温度参数
    "learning_rate": 0.1,      # 反馈学习率
    "calibration_decay": 0.95, # 校准衰减率
})
```

### 7.2 各子系统配置

#### 情境解析器 (SituationParser)
- `KEYWORD_MAP`: 可自定义各情境类型的关键词
- 自动提取紧急度、复杂度、模糊度等参数

#### 权重分配器 (WeightDistributor)
- `BASE_TEMPLATES`: 6种路由类型的基础权重模板
- 支持基于情境参数和元知画像的微调

#### 价值校准器 (ValueCalibrator)
- `CALIBRATION_RULES`: 五大价值的校准规则
- `VALUE_PRIORITY`: 价值优先级权重
- `active_values`: 当前激活的价值维度

#### 约束检查器 (ResourceConstraintChecker)
- `RESOURCE_BASELINE`: 各路由类型的资源需求基线
- `available_resources`: 当前可用资源

#### 归一化引擎 (NormalizationEngine)
- **策略选项**:
  - `SOFTMAX`: Softmax归一化
  - `LINEAR`: 线性归一化
  - `POWER`: 幂归一化
  - `ENTROPY_BALANCED`: 熵平衡归一化（默认）

#### 反馈校准器 (FeedbackCalibrator)
- `learning_rate`: 学习率（默认0.1）
- `calibration_decay`: 偏差衰减率（默认0.95）

