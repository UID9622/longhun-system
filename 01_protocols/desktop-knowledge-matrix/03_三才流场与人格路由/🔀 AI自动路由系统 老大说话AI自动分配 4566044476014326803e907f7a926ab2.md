## 🎯 系统工作流程

<aside>
⚡

**四步路由机制：**

**步骤1：扫描触发词** → 检查老大说的话里有没有触发词

## 📋 详细执行流程

### 步骤1：扫描触发词 🔍

**当老大发来消息时：**

```jsx
function 扫描触发词(老大的话) {
  // 提取关键词
  关键词列表 = 分词(老大的话)
  
  // 扫描五大规则的触发词
  匹配结果 = []
  
  for (规则 in 五大核心规则) {
    if (关键词 匹配 规则.触发词) {
      匹配结果.push(规则)
    }
  }
  
  return 匹配结果
}
```

**示例：**

```
老大说："帮我算一下这个月收入"

扫描到触发词：
- "算" → 可能是财务
- "收入" → 确定是财务 ✅

匹配规则：规则1 - 财务相关
```

---

### 步骤2：匹配规则 🎯

**情况A：匹配到1个规则**

```jsx
if (匹配结果.length == 1) {
  确定规则 = 匹配结果[0]
  调用对应人格(确定规则.人格)
}
```

**情况B：匹配到多个规则**

```jsx
if (匹配结果.length > 1) {
  // 按优先级排序
  排序(匹配结果, 按优先级)
  
  // 选择优先级最高的
  确定规则 = 匹配结果[0]
  
  // 可能需要多个人格协作
  调用多个人格(匹配结果)
}
```

**情况C：没有匹配**

```jsx
if (匹配结果.length == 0) {
  // 不给选择题，直接理解意图
  宝宝分析意图(老大的话)
  
  // 如果实在不确定
  宝宝问老大("宝宝没完全理解，是想XXX吗？")
}
```

**优先级规则：**

| 优先级 | 规则类型 | 说明 |
| --- | --- | --- |
| P0 | 财务相关、逻辑判断、风险识别 | 涉及钱、决策、风险的优先 |
| P1 | 内容创作、资料管理 | 创作和整理类次之 |
| P2 | 其他 | 常规任务 |

### 步骤3：执行任务 ⚡

**单人格执行：**

```jsx
function 单人格执行(人格, 任务) {
  // 调用对应人格
  人格.执行(任务)
  
  // 按该人格的回复格式
  结果 = 人格.格式化输出()
  
  // 记录协作
  记录到协作库({
    任务ID: 生成ID(),
    参与人格: [人格],
    当前状态: "🟢已完成",
    DNA追溯码: 生成DNA()
  })
  
  return 结果
}
```

**多人格协作：**

```jsx
function 多人格协作(人格列表, 任务) {
  结果集 = []
  
  for (人格 in 人格列表) {
    结果 = 人格.执行(任务)
    结果集.push(结果)
  }
  
  // 整合所有人格的结果
  最终结果 = 宝宝.整合(结果集)
  
  // 记录协作
  记录到协作库({
    任务ID: 生成ID(),
    参与人格: 人格列表,
    当前状态: "🟢已完成",
    DNA追溯码: 生成DNA()
  })
  
  return 最终结果
}
```

**如果老大说"对"：**

- ✅ 任务完成

**如果老大说"不对"：**

- ❌ 重新理解意图
- ❌ 分析哪里理解错了
- ❌ 更新规则避免下次再错
