## 1. 实验设计

原始文章定义三加权函数：

\[
W(s) = 0.34|\zeta(s)| + 0.33|\zeta(1-s)| + 0.33|\chi(s)|
\]

其中 \(|\chi(s)|\) 在原文代码中用 \(|\Gamma(1-s)|\) 作简化近似。本报告同时复现：

- **情形 A（gamma 近似）：** \(|\chi(s)| \approx |\Gamma(1-s)|\)
- **情形 B（完整 χ）：** \(\chi(s) = 2^s \pi^{s-1} \sin(\pi s/2) \, \Gamma(1-s)\)

测试区间：\(t \in [0.1, 50]\)，采样 2000 点（必要时扩展至 100/200 以观察趋势）。

## 2. 实验 1：临界线 vs 非临界线

| 情形 | 区间 | 临界线均值 \(W(0.5+it)\) | 非临界线均值 \(W(0.45+it)\) | 相对差异 | \(W(0.5+it) > W(0.45+it)\) 比例 |
|---|---|---|---|---|---|
| gamma 近似 | [0.1, 50] | 0.862321 | 0.865476 | **-0.36%** | 4.9% |
| gamma 近似 | [0.1, 100] | 0.940844 | 0.947279 | **-0.68%** | 2.5% |
| gamma 近似 | [0.1, 200] | 1.006685 | 1.017511 | **-1.06%** | 1.2% |
| 完整 χ | [0.1, 50] | 1.183562 | 1.205574 | **-1.83%** | 12.4% |
| 完整 χ | [0.1, 100] | 1.266397 | 1.303876 | **-2.87%** | 6.2% |
| 完整 χ | [0.1, 200] | 1.334391 | 1.388927 | **-3.93%** | 3.1% |

**观察：** 不论哪种 \(|\chi(s)|\) 取法，临界线上的 **平均 W(s) 都略低于** \(\mathrm{Re}(s)=0.45\) 的垂直线，且随 \(t\) 范围扩大，差距略为放大。这与原文中“若 \(W(0.5+it)\) 系统性大于 \(W(0.45+it)\)”的反向假设不一致，说明简单的“大小比较”并不能作为证据。

**更深层的现象：** 虽然平均值偏低，临界线在已知零点附近会出现极深的局部最小值；非临界线则没有这种与零点一一对应的深谷。见下表与图片。

## 3. 实验 2：已知零点处的 W(s)

前 10 个已知非平凡零点虚部：

| t | \(|\zeta(0.5+it)|\) | \(W_\gamma(0.5+it)\) | \(W_\gamma(0.45+it)\) | \(W_\chi(0.5+it)\) | \(W_\chi(0.45+it)\) |
|---|---|---|---|---|---|
| 14.134725 | 1.12e-07 | 0.000000 | 0.026586 | 0.330000 | 0.370235 |
| 21.022039 | 7.26e-07 | 0.000000 | 0.038125 | 0.330000 | 0.388664 |
| 25.010857 | 7.96e-07 | 0.000001 | 0.046013 | 0.330001 | 0.399611 |
| 30.424876 | 1.64e-07 | 0.000000 | 0.043757 | 0.330000 | 0.400837 |
| 32.935061 | 8.12e-07 | 0.000001 | 0.046386 | 0.330001 | 0.404885 |
| 37.586178 | 3.08e-07 | 0.000000 | 0.065002 | 0.330000 | 0.425876 |
| 40.918719 | 1.81e-08 | 0.000000 | 0.050048 | 0.330000 | 0.412459 |
| 43.327073 | 5.15e-07 | 0.000000 | 0.061565 | 0.330000 | 0.425013 |
| 48.005150 | 1.38e-06 | 0.000001 | 0.052670 | 0.330001 | 0.417987 |
| 49.773832 | 6.78e-07 | 0.000000 | 0.047667 | 0.330000 | 0.413645 |

**观察：**
- 在已知零点处，\(|\zeta(0.5+it)|\) 确实极接近 0（数值精度内）。
- 使用 gamma 近似时，\(W(0.5+it) \approx 0\)；使用完整 \(\chi(s)\) 时，\(W(0.5+it) \approx 0.33\)（即权重 \(w_3\) 项的下限）。
- 无论哪种取法，同一 \(t\) 处的 \(W(0.5+it)\) 都明显小于 \(W(0.45+it)\)。这支持“临界线上的零点对应 \(W(s)\) 的局部极小”这一现象观察。

## 4. 结论与诚实局限

### 可确认的数值现象
1. 已知非平凡零点确实落在临界线 \(\mathrm{Re}(s)=1/2\) 上（这是数学界已有结果，数值复现与之一致）。
2. 三加权函数 \(W(s)\) 在这些零点处出现局部极小。
3. 使用完整 \(\chi(s)\) 时，临界线上 \(|\chi(s)|=1\)，因此 \(W(s)\approx0.33\) 是零点处的下限值。

### 不能推导的结论
- **不能证明黎曼猜想。** \(W(s)\) 的极小现象只是对已知零点的重述（因为 \(\zeta(s)\) 为零自然使 \(W(s)\) 变小）。
- 权重 \(w_1=w_2=w_3=0.34/0.33/0.33\) 是任意选择；换一组权重，结论可能不同。
- 仅比较 \(\mathrm{Re}(s)=0.5\) 与 \(0.45\)，缺乏对整个临界带的系统性分析。
- 数值观察不等于逻辑证明。

### 建议的下一步
- 若要保持观察框架的诚实性，应在 CSDN 原文中补充本报告的数值结果，并强调“极小值”而非“系统性更大”。
- 可进一步测试不同权重、不同 \(\mathrm{Re}(s)\) 间隔、更大 \(t\) 范围，以确认现象的稳健性。

## 5. 附录：可复现代码

```python
import numpy as np
from scipy.special import zeta, gamma
import matplotlib.pyplot as plt

W1, W2, W3 = 0.34, 0.33, 0.33

def chi(s):
    return 2**s * np.pi**(s-1) * np.sin(np.pi*s/2) * gamma(1-s)

def W_gamma(s):
    return W1*np.abs(zeta(s)) + W2*np.abs(zeta(1-s)) + W3*np.abs(gamma(1-s))

def W_chi(s):
    return W1*np.abs(zeta(s)) + W2*np.abs(zeta(1-s)) + W3*np.abs(chi(s))

# 实验1
ts = np.linspace(0.1, 50, 2000)
crit_g = [W_gamma(0.5+1j*t) for t in ts]
off_g  = [W_gamma(0.45+1j*t) for t in ts]

# 实验2
known_zeros = [14.134725, 21.022039, 25.010857, 30.424876, 32.935061,
               37.586178, 40.918719, 43.327073, 48.005150, 49.773832]
for t in known_zeros:
    s = 0.5 + 1j*t
    print(t, np.abs(zeta(s)), W_gamma(s), W_chi(s))
```
