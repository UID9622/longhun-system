## 🗂️ 分区四：CSDN 发布索引

> 龍魂论文系统化发布到 CSDN 的闭环索引。
> 由 **P16·平台运营官** 自动维护，来源论文 ↔ CSDN 文章 ↔ 互动数据反向关联。

<aside>
💻

**发布流程：**
1. `bin/generate_academic_registry.py` 扫描论文目录 → 生成 `academic_papers_registry.json`
2. `CSDN适配器.批量生成CSDN稿件()` → 生成含“算法公式对照表”的标准 CSDN Markdown
3. 人工/浏览器自动化发布到 CSDN → 获得 URL
4. `CSDN适配器.更新发布状态()` → 回写登记册
5. 本索引自动同步

**相关文件：**
- 登记册: `academic_papers_registry.json`
- 稿件模板: `cnsh/platform_adapters/csdn_academic_templates.py`
- 公式对照: `cnsh-core/mathematics/formula_comparison_table.py`
- CSDN 适配器: `cnsh/platform_adapters/CSDN适配器.py`

**当前状态：** 已登记 28 篇论文，3 篇核心论文已完成“EU HLEG 七因子可信 AI”升级并同步 CSDN 草稿（v2）。新增公式 **F11 · EU 七因子可信 AI 合规评分**。

**升级记录：**
- 2026-06-22：PAPER-001 / PAPER-011 / PAPER-014 增加 EU HLEG 七因子映射、F11 公式、参考文献，CSDN saveArticle API 更新成功。
