# 龍魂数字身份主权协议 v2.0

> **核心原则：人民数据主权 · 平台服务降级**
>
> **一句话：芯可龍，云可私，网可断，心不可失。**
>
> **技术底座：龍芯 × 华为 × CNSH 融合**
>
> DNA: `#ZHUGEXIN⚡️2025-🇨🇳🐉⚖️♠️🧚🏼‍♀️❤️♾️-DEVICE-BIND-SOUL`

---

## 1. 身份层：魂灵ID

- 国家签发，公民持有。
- 本地哈希计算，不上传原始编号。
- 一次认证，全网通行。
- 随时撤回，平台立即失效。

## 2. 计算层：芯可龍

- 龍芯/鲲鹏自主指令集。
- 本地 AI 推理，数据不上传。
- 可信执行环境（TEE），用户持密钥。
- 断网可用，核心功能离线运行。

## 3. 系统层：虚实合一

- 华为双系统物理隔离。
- 工作系统：受监管、可审计。
- 生活系统：用户完全掌控。
- 鸿蒙微内核调度，互不窥探。

## 4. 存储层：私云归藏

- 本地加密存储为主。
- 家庭边缘节点备份。
- 云端仅为镜像，可断开。
- 应急 Mesh 广播，灾时数据不丢失。

## 5. 通讯层：烽火传心

- 北斗短报文：无地面信号时发文字。
- 星闪 NearLink：1公里内高速自组网。
- 鸿蒙软总线：设备自动发现协同。
- 断网不断联，人民自救数字烽火台。

## 6. 平台权限边界

**可获取：** 魂灵ID哈希值（仅用于验证）。

**不可获取：**
- 手机号
- 真实姓名
- 地址
- 人脸
- 生物特征
- 行为数据
- 社交关系

**不可行为：**
- 画像
- 广告
- 推荐
- 转卖
- 训练模型
- 出境传输

## 7. 审计层：民主审计

- 所有 AI 行为受 CNSH 民主审计约束。
- 开放审计 API（只读权限）。
- 用户可查看所有数据流动记录。
- 审计链全程可追溯，密码学保障。

## 8. 违规处置

| 次数 | 处置 |
|---|---|
| 第一次 | 警告 + 公示 |
| 第二次 | 暂停接入 + 罚款 |
| 第三次 | 永久驱逐 + 法律追责 |

### 生物特征泄露特别处置

**人脸、指纹、虹膜、声纹、物业信息、家庭成员信息一旦泄露或被黑客窃取：**

- **追溯本源**：通过 DNA 追溯链、日志哈希、访问记录，定位泄露节点。
- **一查到底**：从执行人员、管理层到系统供应商，层层追责。
- **绝不放过**：行政处罚 + 民事赔偿 + 刑事追责，三管齐下。
- **写入耻辱墙**：涉事单位、系统、个人永久标记，供全社会审计。

**强制采集红线**：

| 场景 | 判定 |
|:---|:---:|
| 物业强制录入人脸才能进门 | 🔴 越界 |
| 平台以"优化服务"索要通讯录/位置/相册 | 🔴 越界 |
| 工地/工厂强制采集指纹虹膜并商用/联网上传 | 🔴 越界 |
| 基层部门超范围收集全家信息 | 🔴 越界 |
| 公安机关依法刑事侦查（有法律文书） | 🟢 合法授权 |
| 政府民生部门有授权、用途明确 | 🟢 合法授权 |
| 国企关键基础设施有等保+上级授权 | 🟢 合法授权 |
| 国标认证机构持有有效国密/国标证书 | 🟢 合法授权 |
| 本地哈希验证、用户自持密钥、用完即焚 | 🟢 合规 |

**合法授权三要素**：证书/授权 + 明确用途 + DNA 回执。

## 命令行用法

```bash
cd ~/longhun-system

# 输出完整协议
python3 -m sovereignty.cli --protocol

# 检查平台授权是否越界
python3 -m sovereignty.cli --check 某物业APP --auth 手机号,人脸照片,位置,通讯录

# 按层次输出方案（不按群体贴标签）
python3 -m sovereignty.cli --layer L1   # 执行层：一线人员被要求采集
python3 -m sovereignty.cli --layer L2   # 协调层：主管/干部两头受气
python3 -m sovereignty.cli --layer L3   # 监督层：居民/业主维权

# 生成投诉书
python3 -m sovereignty.cli --complain 某平台 --behavior "强制收集人脸并用于广告推荐"

# 生成最小授权方案
python3 -m sovereignty.cli --min-auth 小区门禁

# 输出基层可直接用的模板
python3 -m sovereignty.cli --template 居民告知书 --name 阳光社区

# 主动触发清单
python3 -m sovereignty.cli --signals
```
