# 龍魂民生行为密码学引擎 (longhun-behavior-engine) · v5.2

**DNA**: `#龍芯⚡️丙午·丙申·庚申·亥时-LONGHUN-BEHAVIOR-ENGINE-v5.2`

## 核心思想

> 为人民服务的人，必须亮出来。
> 我们不看身份，只看行为；不记恶名，只记善意；不评价言论，只保护表达。
> 民生行为密码学（LBC）不是评价人，而是让善意被看见。

## 五大核心原则

| 原则 | 说明 |
|------|------|
| **民生治理 ≠ 个人征信** | 不记录金融信用、不评分人格、不用于贷款/就业 |
| **只看行为，不看身份** | 行为归因于事实，不关联个人身份背景 |
| **只记善意，不记恶名** | 只记录正向贡献行为，负向行为不计入 |
| **自愿参与权重高** | 强制行为 V=0，自愿行为 V=1，半自愿 V=0.5~0.7 |
| **言论自由绝对保护** | 任何表达观点、批评、建议均不计入行为档案 |

## 五大行为分类

| 代码 | 分类 | 示例 |
|------|------|------|
| A | 主动善意类 | 帮助弱势群体、失物归还、紧急援助 |
| B | 社区参与类 | 村口唱歌、志愿者服务、社区议事 |
| C | 公共服务类 | 服务型执法、公益服务、应急服务 |
| D | 文化共建类 | 文化传承、技艺传授、文化教育 |
| E | 环境维护类 | 环保行动、生态保护、绿色创新 |

## 三大核心公式

### 公式一：民生行为权重 W

```
W_i = B_i × V_i × C_i × T(t_i) × F(n_i) × R_i
S_total = Σ W_i
```

| 符号 | 名称 | 说明 |
|------|------|------|
| B | 基础权重 | 3 ~ 10，由行为分类确定 |
| V | 自愿系数 | 0 ~ 1，强制=0，完全自愿=1 |
| C | 社区验证系数 | 0 ~ 1，多方见证=1，自说自话=0.1 |
| T(t) | 时间衰减函数 | 半衰期2年，最低保留10% |
| F(n) | 频率调节因子 | 防止刷分 |
| R | 社区反响系数 | 0.8 ~ 1.2，受益人反馈微调 |

### 公式二：社区信任度 Θ

```
Θ = (1 - e^(-α·S_total)) × (1 + β·D) × γ
```

- α = 0.05（灵敏度参数）
- β = 0.3（多样性权重）
- D = 有效行为类别数 / 5
- γ = 社区调节因子（0.8 ~ 1.0）

### 公式三：提案优先级 P

```
P_j = Θ_j × Q_j × (1 + ln(1 + S_relevant))
```

- Θ_j：提案人社区信任度
- Q_j：提案质量分（评审团独立评定）
- S_relevant：提案人在该领域的相关行为积分

## 民生熔断线（W_i = 0 的绝对阻断）

以下行为**绝对不计分**：

| 熔断类型 | 说明 |
|----------|------|
| 强制行为 | V = 0 |
| 言论表达 | 观点、批评、建议、演讲、写作 |
| 个人消费选择 | 买什么、吃什么、穿什么 |
| 监督公权力 | 批评政府、监督官员、举报腐败 |
| 无法验证 | C < 0.1 |
| 商业行为 | 以营利为目的的服务 |
| 违法行为 | 任何违反法律的行为 |

## 为人民服务

LBC 的设计初心是服务人民：

1. **服务社区自治**：让居民提案有依据，排序有规则。
2. **保护普通人**：不贴标签、不排名、不评价人格。
3. **激励善意行为**：村口唱歌、帮助邻居、志愿服务都被看见。
4. **捍卫言论自由**：批评与表达绝不计入行为档案。
5. **数据归本人**：本人可查询、删除、导出，社区只代为记录。

## 为国家繁荣昌盛而努力蜕变

LBC v5.2 在 v5.1 基础上进一步对齐国家与人民利益：

- **服务老百姓**：所有行为分类面向基层日常善意，不搞精英评级。
- **支持社会治理**：为社区、村镇、街道提供 lightweight 自治工具，不替代政府治理。
- **与国家征信绝缘**：民生行为档案绝对不与金融征信、就业背景调查挂钩。
- **促进文化共建**：村口唱歌、传统技艺、文化教育计入正向行为，助力基层文化繁荣。
- **坚持中国标准**：数据主权归本人，记录可审计、可删除，符合中国数据治理方向。
