### 🟢🔴🟡 三色审计声明

```
🟢 GREEN（宜做）: 穷态正确触发 → 拆分到底层 → 互搏达成共识 → 沉淀为标准路径
🔴 RED（禁做）: 没有穷态证据就强行创新 · 互搏未共识就合流 ·  suppress 反例
🟡 YELLOW（慎做）: 创新路径需标注「待验证」· 认知边界突破需保留回滚接口
```

### 君子协议

本引擎遵循 **「站普通人一边」** 原则。创新不是为了炫技，是为了在系统卡住时找到真正可行的新路径。所有创新路径必须可追溯、可审计、可回滚。

## 二、四态状态机

### 2.1 状态总表

| 状态 | 名称 | 五行 | 三色标记 | 核心动作 | 停留时限 |
|------|------|------|----------|----------|----------|
| QIONG (窮) | 困顿 | 水 | 🔴红色/熔断边缘 | 识别边界、触发变机制 | ≤3 次尝试 |
| BIAN (變) | 生发 | 木 | 🟡黄色/审计中 | 左右互搏、拆分到底层 | 直到共识 |
| TONG (通) | 明达 | 火 | 🟢绿色/通过 | 结果合流、路径打通 | 即时转久 |
| JIU (久) | 稳定 | 土 | 🟢绿色/沉淀 | 标准答案入库、保留创新接口 | 持久态 |

### 2.2 状态流转

```
QIONG（窮·水） ──触发──> BIAN（變·木） ──共识──> TONG（通·火） ──入库──> JIU（久·土）
    │                         │
    └─ 超时/熔断 ──> 人工介入   └─ 对立不可调 ──> 🔴熔断
```

**五行相生驱动**: 水生木 → 木生火 → 火生土。系统按相生顺序自然流转，若出现相克（如水克火）则触发熔断。

### 2.3 各状态触发条件

#### QIONG（窮）—— 水到边界

满足任一即入窮态：

1. 复合决策强度 D < 0.40
2. 五行平衡指数 < 30
3. 三才平衡系数中 Human < 0.34（铁律触发）
4. 同一问题连续 3 次迭代无进展
5. 左右互搏结果标记为 🔴 红色
6. DNA 追溯失败（无 DNA 或链断裂）

#### BIAN（變）—— 木来生发

满足任一即入變态：

1. 窮态确认成立（主触发）
2. 外部指令要求「深度审计」
3. 系统检测到潜在认知盲区（置信度 30%~60%）

#### TONG（通）—— 火来明达

满足任一即入通态：

1. 變态中左右互搏达成共识
2. 拆分计算的原子结果合流产生新解
3. 五行平衡指数经變态调整后 ≥ 60
4. 复合决策强度 D ≥ 0.65 且 Human ≥ 0.34

#### JIU（久）—— 土来稳定

通态结果完成入库后自动转入久态：

- 标准化解决方案写入模板库
- 保留「再次变」的金属性窗口（土生金 → 金生水 → 再次进入窮态）
- 生成可复制的模板签名

## 三、核心引擎

### 3.1 拆分计算引擎

**文件**: `scripts/拆分计算引擎.py`

**流程**: 大问题 → 递归拆分 → 原子单元 → 独立计算 → 结果合流 → 新解法检测

**核心类**: `SplitComputeEngine`

```python
from scripts.拆分计算引擎 import SplitComputeEngine

engine = SplitComputeEngine(max_depth=5)
atoms = engine.split("如何设计高可用分布式系统")
results = [engine.compute_atomic(a) for a in atoms]
merged = engine.merge(results)
print(f"发现新解法: {merged.innovation_detected}")
```

### 3.2 左右互搏审计引擎

**文件**: `scripts/左右互搏审计引擎.py`

**设计**: 左人格（保守者） vs 右人格（探索者）互相审计，冲突解决，新解法检测。

**核心类**: `DuelAuditEngine`

```python
from scripts.左右互搏审计引擎 import DuelAuditEngine

duel = DuelAuditEngine()
result = duel.duel(problem="是否引入新架构", solution="迁移到微服务")
print(f"共识: {result.consensus}, 评分: {result.score}, 颜色: {result.color}")
```

### 3.3 穷则思变创新引擎

**文件**: `scripts/穷则思变创新引擎.py`

**设计**: 生产级四态状态机，集成阈值判断、创新路径生成、五行平衡、输出路由、Prometheus 指标。

**核心类**: `InnovationEngine`

```python
from scripts.穷则思变创新引擎 import InnovationEngine, Context

engine = InnovationEngine()
context = Context(confidence=0.35, human_weight=0.5, balance_index=25.0)
result = engine.process(context, raw_input="系统性能到达瓶颈")
print(result)
```
