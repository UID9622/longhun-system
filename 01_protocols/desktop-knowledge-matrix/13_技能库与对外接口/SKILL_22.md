## 一、技能概述

龍魂審計修復系統是龍魂體系雲端技能模組，提供完整的Agent修復追踪與歸檔評估能力。

- 🔧 Agent修復追踪（007/011/014修復記錄）

- 📋 審計日誌自動生成（JSONL持久化）
- 📂 歸檔評估系統（C = R·I·T價值公式）
- 🔐 完整性檢查（DNA簽名驗證、重複檢測）

- ⚔️ 左右互搏審計引擎集成（longhun-innovation 提供保守者/探索者對決）

### 6.8 左右互搏審計引擎集成

本技能與 `longhun-innovation` 協作，在修復方案評審階段引入**保守者（左人格）**與**探索者（右人格）**的互搏審計。

```python
from longhun_innovation.scripts.左右互搏审计引擎 import DuelAuditEngine

duel = DuelAuditEngine()
結果 = duel.duel(problem="修復方案是否可行", solution=修復方案)

if 結果.consensus and 結果.color == "🟢":
    # 通過互搏審計，進入驗證流程
    審計.更新修復狀態(代理編號, "verified")

    # 未達成共識或標記為 🔴，退回重新分析
```

- `longhun-innovation` 提供互搏審計算法與保守者/探索者人格實現。

## 七、核心功能詳解

### 7.1 修復記錄管理 (CRUD)

| 操作 | 方法 | 說明 |
|------|------|------|
| 創建 | `創建修復記錄()` | 新建修復記錄，自動生成DNA |
| 更新 | `更新修復狀態()` | 更新狀態，自動記錄日誌 |
| 查詢 | `獲取修復記錄()` | 按Agent編號查詢 |
| 篩選 | `按狀態篩選()` / `按根因篩選()` | 多維度篩選 |

**修復狀態流轉**：
```
待修復 → 修復中 → 已修復 → 驗證中 → 已驗證
                     ↓
                   已回滾
```

### 7.2 根因分析引擎

**7大根因類別知識庫**：

| 類別 | 關鍵詞 | 描述 |
|------|--------|------|
| interactive_block | input(), 交互式, 阻塞 | 交互式輸入在非交互環境阻塞 |
| env_missing | NOTION_TOKEN, 環境變量 | 環境配置或API密鑰缺失 |
| logic_error | KeyError, IndexError | 代碼邏輯錯誤導致運行時異常 |
| dependency_missing | ModuleNotFound, ImportError | Python包或模塊依賴缺失 |
| config_error | 配置文件, database_id | 配置文件錯誤或連接參數缺失 |
| data_anomaly | 數據格式, 編碼錯誤 | 數據格式異常或編碼問題 |
| api_failure | 連接超時, HTTP錯誤 | 外部API服務不可用或限流 |

### 7.3 修復驗證流程

**標準驗證步驟**：
1. 文件存在檢查 — 驗證修復文件存在且可讀
2. 語法檢查 — 驗證Python語法正確性
3. 導入檢查 — 驗證模塊可導入
4. 執行測試 — 運行修復後Agent
5. 輸出驗證 — 驗證輸出內容正確

### 7.4 歸檔價值評估公式

```
C = R × 40% + I × 30% + T × 30%

其中:
  R = 保留價值分 (0-100) — 是否對當前系統有幫助
  I = 創新度分 (0-100) — 是否包含獨特思路
  T = 時間衰減分 (0-100) — 年代久遠程度(越新越高)
```

**決策閾值**：

| 得分範圍 | 決策 | 動作 |
|----------|------|------|
| C ≥ 80 | ✅ 永久保留 | 不可刪除 |
| 60 ≤ C < 80 | ✅ 保留 | 正常管理 |
| 30 ≤ C < 60 | 🟡 再評估 | 定期複審 |
| 15 ≤ C < 30 | 🟡 建議刪除 | 審核後刪除 |
| C < 15 | 🔴 強烈建議刪除 | 立即清理 |
