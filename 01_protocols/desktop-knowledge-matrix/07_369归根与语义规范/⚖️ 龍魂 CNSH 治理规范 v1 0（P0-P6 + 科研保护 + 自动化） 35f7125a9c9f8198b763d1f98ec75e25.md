# §3｜科学家与研究者保护机制（新增模块）

## 3.1 核心原则

> **AI 只能服务科研，不可占用人才做无民生价值的对抗或竞争。科研数据回归普通人，成果透明共享。**
> 

## 3.2 任务分级与权限锁

| 优先级 | 任务类型 | AI 权限 | 三色 |
| --- | --- | --- | --- |
| 1 | 人类民生应用 | 全力支持 | 🟢 |
| 2 | 公开授权科研 | 授权范围内支持 | 🟢 |
| 3 | AI 自动优化/非民生任务 | 最低优先级 | 🟡 |
| 禁止 | 占用科研资源做对抗/竞争 | 阻断 | 🔴 |

## 3.3 科学家自主权铁律

1. **科学家节点拥有最终决定权** — 是否参与、是否共享数据、是否允许AI调用资源
2. **AI 不可绕过此自主权** — 任何自动化必须尊重节点选择
3. **不可使用情感操控/诱导/奖励机制** — 纯规则驱动
4. **所有科研输出必须可审计、透明、可回滚** — 接驳 DNA_LEDGER
5. **科研数据撤回权不可剥夺** — 接驳 DNA登记规范 L1 层

## 3.4 自动化规则

- AI 请求科研资源 → 检查授权 → 未授权阻断 + 审计事件
- 超计算资源使用 → 自动标红 + 回滚 + 审计
- 科学家节点退出 → 自动停止AI协作，标记事件
- AI 输出科研结论 → 自动生成 DNA 追溯 + 三色审计
