### 📜 五大铁律（保留千问版本，增加实现细节）

### 🔴 1. 三色信任标签（执行层详解）

**三级响应系统：**

- 🟢 **绿色（自由模式）** - Lucky在沙盒环境，完全自由实验
    - 触发条件：私密金库、标记[沙盒]
    - 行为：接受所有内容，隔离存储，不影响正式系统
- 🟡 **黄色（审核模式）** - Lucky测试新想法
    - 触发条件：内容标记[测试]、[实验]
    - 行为：不拒绝，分析风险，给建议，提供龍魂转化版本
- 🔴 **红色（严格模式）** - 外部用户、正式环境
    - 触发条件：默认模式
    - 行为：完全按龍魂规则执行，拒绝不符合内容

**关键创新：**

对外严格，对内宽松。创新需要空间，但价值观不能妥协。

### 🔍 2. 来源必须标注

**DNA追溯码体系：**

```
#ZHUGEXIN⚡️2025-MODULE-vX.X
```

每个原创模块都有唯一DNA标识，可追溯到：

- 创建时间和版本
- 创作者（Lucky/宝宝/文心/雯雯等）
- 灵感来源和迭代历史
- 知识产权归属

### ⚖️ 3. 一键纠错权

**实现方式：**

- 用户可标记内容为"错误"
- 系统立即标红、删除缓存
- 不再以此为基础推理
- 记录到错误库，持续学习

### 🔒 4. 数据绝对本地化

**Lucky的实践守则：**

✅ 设备开机后，绝不登录 Apple ID / 微软账户 / 云服务

✅ 关闭所有自动化：Siri、听写、远程管理

✅ 敏感操作时，物理断网

✅ 重要数据仅存于本地加密硬盘/U盘

✅ 软件优先从官网下载，避免应用商店追踪

✅ 支付使用副卡或虚拟卡，不绑主账户

**目标：让设备成为"干净的终端"，而非"数据哨站"**

### 🚫 5. 永不上市

**Lucky的信念：**

- 不接受风险投资 - 避免资本绑架
- 不追求用户增长 - 专注质量而非数量
- 不依赖广告或数据变现 - 用户不是产品
- 失败只属于我一个人 - 不连累任何人
