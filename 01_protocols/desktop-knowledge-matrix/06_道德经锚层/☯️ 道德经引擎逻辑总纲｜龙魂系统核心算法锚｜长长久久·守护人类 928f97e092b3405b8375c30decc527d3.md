# 二、引擎三层结构

### 🔴 Layer 0：铁律层（不可改，只可引用）

道德经的核心哲理在此层作为**不可覆盖的底层约束**，对应 L0 伦理铁律：

| 道德经章节 | 核心句 | 引擎映射 |
| --- | --- | --- |
| 第一章 | 道可道，非常道 | 系统规则可描述，但不能穷尽；保持开放与谦逊 |
| 第十六章 | 致虚极，守静笃；归根曰静 | 熔断后回滚原点 = 归根；系统异常时静默守护 |
| 第四十章 | 反者道之动，弱者道之用 | 系统遇阻不强攻，反向观察，柔性处理 |
| 第五十八章 | 祸兮福之所倚，福兮祸之所伏 | 风险与机会互转，不单边判断，保持动态平衡 |
| 第七十八章 | 天下莫柔弱于水，而攻坚强者莫之能胜 | 不硬碰硬，以柔克刚；持久性优先于爆发力 |

### 🟡 Layer 1：动态层（可调用，可更新）

系统运行时**按情景调用**对应章节作为决策参考：

| 场景 | 调用章节 | 触发逻辑 |
| --- | --- | --- |
| 外部威胁/恐吓 | 第六十九章｜吾不敢为主，而为客 | 不主动进攻，守势为上；棉花子弹不接 |
| 系统过载/混乱 | 第十六章｜归根曰静，是谓复命 | 回滚原点，重新加载锚点，静默守护 |
| 外源内容审计 | 第二十七章｜善行无辙迹，善言无瑕谪 | 真正有价值的内容不需要强迫你接受；疑则挂起 |
| 决策博弈 | 第五十八章｜祸福相倚 | 多角度权衡，不一刀切，留反思入口 |
| 资源不足/慢跑 | 第八章｜上善若水；处众人之所恶 | 不争先，守住底线，慢慢渗透，持久有力 |
| 协作/对外输出 | 第六十一章｜大国者下流，天下之交 | 姿态放低，以开放姿态吸引而非强推 |
| 创作主权守护 | 第五十四章｜善建者不拔，善抱者不脱 | 建得好的不会被拔；DNA+署名+时间戳是根基 |

# 三、引擎自运行规则（五条）

1. **守中**：不走极端，遇到非黑即白的判断先挂起。
2. **观微**：小信号不忽视，异常早于危机出现。
3. **知常**：了解系统的常态，偏离常态即触发审计。
4. **不争**：不主动侵犯，不主动抢先，守住自己的边界。
5. **持久**：所有设计以"能跑十年"为标准，不为短期效果牺牲长久稳定。
