# 乡镇基层“多源真实性”协同校验协议

**协议编号**：LH-GOV-GRASSROOTS-REALITY-2026-001  
**发起方**：龍魂系统 · 基层治理观察组  
**适用对象**：乡镇派出所、退役军人事务站、民政办、司法所、县级公安局  
**生效日期**：2026-06-25  
**协议状态**：试行

---

## 一、问题定性：不是“不会服务”，是“真实信息被层层过滤”

### 1.1 多维底层疑惑

基层群众走进派出所，表面上是“办事慢、态度差”，底层是四个互相关联的疑惑：

| 维度 | 群众真实疑惑 | 现行机制如何过滤真相 |
|---|---|---|
| 认知维度 | 民警到底懂不懂AI反诈？ | 培训记录齐全，但实战不会用 |
| 服务维度 | 等待两小时有没有人管我？ | 台账照片齐全，但群众体感冰冷 |
| 协同维度 | 退伍军人事到底归谁管？ | 部门各有一套说法，边界不清 |
| 数据维度 | 墙上高分是真的吗？ | 评分系统由被评单位自己掌控 |

### 1.2 核心定性

这不是“政府不会安排”，也不是“基层人员不努力”。  
这是**多部门、多利益、多评分体系共同作用下，真实信息被逐级稀释、替换、表演化**的制度性病态。  
当“不出错”“高评分”“台账完整”成为最高目标，真正该被服务的群众反而成了流程的配角。

### 1.3 本协议的定位

本协议不是问责令、不是调度表、不是政府内部的工作分工。  
它是**一套“真实性校验”的制度补丁**：  
- 让真实需求上得来；  
- 让真实问题藏不住；  
- 让真实改进看得见；  
- 让表演性数据自然失效。

---

## 二、协议目标

### 2.1 总目标

把乡镇基层窗口从“评分驱动、台账自证、部门割裂”的运营模式，  
转向**“真实需求可穿透、真实问题可追责、真实改进可验证”**的协同模式。

### 2.2 分目标

| 维度 | 旧目标 | 新目标 |
|---|---|---|
| 认知 | 培训课时达标 | 实战能力可被匿名抽测 |
| 服务 | 台账照片完整 | 群众真实体感可被独立采集 |
| 协同 | 各部门有分工文件 | 跨部门事项必须留痕且可追踪 |
| 评分 | 满意度越高越好 | 评分真实性可被校验，差评必须闭环 |

---

## 三、多维度真实性校验机制

### 3.1 认知真实性校验

**问题**：培训记录有了，但民警实战不会用AI反诈工具。

**补丁条款**：

1. 培训课程内容由一线民警参与制定，每季度至少征集一次实战需求；
2. 考核方式从“选择题笔试”改为“模拟案例处置”，由县级公安局随机抽题；
3. 引入第三方匿名测评：每季度随机抽取办事群众，询问“民警是否使用了有效工具帮你解决问题”，作为认知转化率的硬指标；
4. 培训不得占用休息时间，不得作为额外负担转嫁民警。

### 3.2 服务真实性校验

**问题**：服务标准写在纸上，但群众感受不到。

**补丁条款**：

1. 服务细节清单必须由群众抽样确认，而不是仅靠内部自查：
   - 群众进门是否被主动询问；
   - 等候超过15分钟是否被告知预计时间；
   - 登记超过30分钟是否提供饮用水；
   - 办事结束是否被告知反馈渠道。
2. 等候区设置独立的“真实反馈终端”（触屏或扫码），数据直传县级平台，派出所仅可查看、不可修改、不可删除；
3. 每月由乡镇纪委或群众代表随机抽查至少5个办事录像（脱敏处理），核验服务细节执行率。

### 3.3 协同真实性校验

**问题**：部门边界模糊，群众被踢皮球，退伍军人身份无法触发绿色通道。

**补丁条款**：

1. **首问负责制**：第一个接待的部门必须生成可追踪的工单号，口头推诿视为违规；
2. **职责边界公开**：制作《乡镇基层服务职责边界手册》并在办事大厅公示，群众可拍照、可查阅；
3. **退伍军人绿色通道**：任一窗口识别退伍军人身份后，必须在5分钟内同步通知退役军人事务站，并在15分钟内给出联合响应方案；
4. **超时自动升级**：跨部门事项超过承诺时限未解决，系统自动抄送乡镇分管领导和县级主管部门；
5. **连带责任说明**：协同事项最终未解决，相关部门必须共同出具书面说明，不得单独以“不归我管”结案。

### 3.4 评分真实性校验

**问题**：评分成为被评单位自我表演的工具，差评被压、好评被刷。

**补丁条款**：

1. 评分系统由**县级独立技术方**维护，被评单位仅有查看权限，无修改、删除、筛选权限；
2. 引入反作弊算法：连续相同评分、异常时间分布、同一设备高频评分等触发复核；
3. **差评必须闭环**：所有低于70分的评价，必须在24小时内电话或现场回访，并记录改进措施；
4. 公开数据不得只展示“满意度”，必须同步展示：
   - 参评率；
   - 差评数量及分类；
   - 差评闭环率；
   - 群众主动提出的改进建议数。

## 四、考核去表演化条款

### 4.1 取消单一排名

不再对乡镇派出所进行“满意度总分排名”。  
排名驱动的结果必然是刷分、压差评、做台账。

### 4.2 引入真实性正向指标

| 指标 | 含义 | 用途 |
|---|---|---|
| 真实参评率 | 办事后实际评价数 / 总办件数 | 防止“只让满意的人评” |
| 差评闭环率 | 已回访并改进的差评 / 总差评 | 防止差评被压 |
| 问题发现率 | 主动发现并上报的流程漏洞数 | 鼓励暴露问题而非掩盖 |
| 跨部门协同响应率 | 规定时限内响应的协同事项 / 总协同事项 | 防止推诿 |

### 4.3 帮扶替代惩罚

- 任一指标连续两月低于阈值，触发**县级帮扶机制**：派专人驻点指导，而非通报批评；
- 对主动暴露问题、主动改进的部门，给予正向记录；
- 对数据造假、删除差评、拦截群众反馈的行为，启动纪律审查。

## 五、四方责任与权利

### 5.1 派出所（执行与反馈方）

**责任**：
1. 执行服务真实性清单；
2. 为每位办事群众主动提供独立评价渠道；
3. 对跨部门事项必须生成工单并跟踪；
4. 配合县级匿名抽测和群众代表抽查。

**权利**：
1. 对不合理、不可操作的指标提出申诉；
2. 获得县级技术培训和系统支持；
3. 评分数据被篡改时可申请县级复核。

### 5.2 县级公安局（统筹与技术方）

**责任**：
1. 统一维护独立评分系统，确保数据不可被基层修改；
2. 组织实战导向的AI认知培训；
3. 每季度发布《基层窗口真实性审计报告》；
4. 对评分异常、数据造假启动核查。

**权利**：
1. 要求派出所接入统一平台；
2. 对连续不达标的单位启动帮扶；
3. 对恶意刷分、压差评行为提出处理建议。

### 5.3 跨部门协同小组

**成员**：派出所、退役军人事务站、民政办、司法所。

**责任**：
1. 每周固定时间联合坐班或线上联动；
2. 对任一部门受理的跨部门事项，其余部门同步收到通知；
3. 每月召开一次“真实性复盘会”，讨论被群众质疑或推诿的典型案例；
4. 共同维护并更新《职责边界公开手册》。

**权利**：
1. 联合申请专项经费；
2. 对上级不合理的职责划分提出联合调整建议；
3. 对协同效果突出的部门或个人推荐表彰。

### 5.4 群众（真实信息源与监督方）

**权利**：
1. 每次办事后通过独立渠道匿名评价；
2. 查阅《职责边界公开手册》；
3. 查询办事进度和跨部门流转记录；
4. 退伍军人享受标识明确的绿色通道。

**义务**：
1. 如实配合必要登记；
2. 客观评价，不恶意刷分；
3. 通过正规渠道反馈，不散布不实信息。

## 六、监督与迭代

### 6.1 独立监督

- 乡镇纪委：对服务态度和群众投诉进行独立调查；
- 县级公安局：对评分系统真实性和培训效果进行技术审计；
- 群众代表：每季度随机抽查服务细节，人数不少于3人。

### 6.2 季度迭代

每季度根据以下数据更新协议条款：
- 真实参评率与差评闭环率；
- 跨部门协同响应率；
- 群众主动提出的改进建议；
- 民警和基层工作人员反馈的操作障碍。

### 6.3 版本控制

每次迭代生成新版本，旧版本归档，确保制度演进可追溯。

## 七、最终声明

本协议不追究个人、不制造对立、不增加形式主义负担。

它的唯一目的是：**把被过滤掉的真实信息，重新引入基层治理的闭环。**

让群众知道——  
他们的问题被真实记录、真实流转、真实解决，  
而不是被台账、评分、照片和部门壁垒所替代。
