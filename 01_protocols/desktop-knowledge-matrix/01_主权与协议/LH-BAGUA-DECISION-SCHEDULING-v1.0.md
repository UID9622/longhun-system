# 龍魂八卦决策调度协议 v1.0（执行指令版）

**DNA:** `#龍芯⚡️丙午·丙申·庚申·丁亥·䷡大壮-LONGHUN-BAGUA-SCHEDULER-v1.0`
**归属:** 中华人民共和国 · 龍魂系统
**生效:** 2026-06-28 · 即时执行


## 一、协议状态变量

全局运行状态存储在 `~/.龍魂/state/bagua_state.json`：

```json
{
  "态势值": 0,
  "当前卦象": "☵ 水洄",
  "熔断": false,
  "上次熔断": null,
  "校验失败次数": 0,
  "丁卯巡逻记录": [],
  "最后更新时间": "ISO8601"
}
```


## 二、执行命令格式

```bash
lh-bagua status          # 查看当前态势值、卦象、熔断状态
lh-bagua set <0-100>     # 手动设定态势值（用于测试）
lh-bagua trigger          # 触发一次完整态势评估
lh-bagua reset            # 重置状态（解除熔断）
lh-bagua log              # 查看最近12次调度记录
lh-bagua dashboard        # 显示状态看板
```


## 三、自动触发机制（Mac Launch Agent）

每小时自动运行一次态势评估：

- 脚本：`/Users/zuimeidedeyihan/.local/bin/bagua_check`
- 实质：`exec /Users/zuimeidedeyihan/longhun-system/bin/lh-bagua hourly`
- Launch Agent：`~/Library/LaunchAgents/com.longhun.bagua.plist`
- `StartInterval = 3600`，`RunAtLoad = true`


## 四、丁卯时序自动调度

| 时辰 | 时间 | 执行动作 | 触发条件 |
|------|------|----------|---------|
| 丁卯时 | 05:00 | `lh-bagua trigger` | 每日自动 |
| 午时 | 11:00 | `lh-bagua status` | 每日自动 |
| 酉时 | 17:00 | `lh-bagua trigger` → `lh-bagua log` | 每日自动 |
| 子时 | 23:00 | `lh-bagua reset`（日结） | 每日自动 |


## 五、熔断状态与手工解除

熔断后状态机：

```
熔断触发 → ☴风入持续监察 + ☰天行独断裁决
         → 所有其他卦象进入冻结/封闭/暂停状态
         → 手工解除唯一通道：lh-bagua reset
         → 解除前需 ☰天行 自判日志留痕
```

如果熔断触发，`lh-bagua status` 输出会显示异常状态。


## 六、态势值的实时数据源

| 数据源 | 字段 | 权重 |
|--------|------|------|
| `lh-index status`（或日志兜底） | 最近异常日志数 | 0.2 |
| `lh-cal --json` | 今日卦象/节气/农历/三色 | 0.1 |
| 系统负载 | 5分钟平均负载 | 0.3 |
| 自定义 | `~/.龍魂/state/alert_override` | 0.4 |

## 八、协议验证

修改 `~/.龍魂/state/bagua_state.json` 中 `态势值` 为测试值，观察 `lh-bagua status` 输出是否符合预期，并确认熔断触发阈值正常工作。

部署后，运行 `lh-bagua status` 确认基础功能。当前建议状态：态势值默认 0、当前卦为 ☵ 水洄、熔断未触发。
