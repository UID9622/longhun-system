## 前言：评分不是鞭子，真实才是目标

现在的社会被一种资本算法搞坏了：

- 外卖骑手要被五星，否则扣钱；
- 空调维修工要被五星，否则没单；
- 移动装机师傅要被五星，否则绩效难看；
- 乡镇民警也要被满意度排名，否则通报批评。

这不是服务，这是**评分恐怖主义**。

一个人、一个基层工作者，被一个数字定义好坏。一个差评就能抹掉一百个好评。没有容错、没有解释、没有情境、没有对话。人和人之间的关系，被压缩成一个星星、一个分数、一条排名。

本协议不搞这套。

我们用**龍魂“三才三色”真实度算法**：不是压人，不是排名，不是表演，而是**帮助每个环节回到真实、回到人情、回到改进**。

## 第一部分：问题定性

### 1.1 多维底层疑惑

基层群众走进派出所，表面是“办事慢、态度差”，底层是四个互相关联的疑惑：

| 维度 | 群众真实疑惑 | 现行机制如何过滤真相 |
|---|---|---|
| 认知维度 | 民警到底懂不懂AI反诈？ | 培训记录齐全，但实战不会用 |
| 服务维度 | 等待两小时有没有人管我？ | 台账照片齐全，但群众体感冰冷 |
| 协同维度 | 退伍军人事到底归谁管？ | 部门各有一套说法，边界不清 |
| 数据维度 | 墙上高分是真的吗？ | 评分系统由被评单位自己掌控 |

### 1.2 核心定性

这不是“政府不会安排”，也不是“基层人员不努力”。  
这是**多部门、多利益、多评分体系共同作用下，真实信息被逐级稀释、替换、表演化**的制度性病态。  
当“不出错”“高评分”“台账完整”成为最高目标，真正该被服务的群众反而成了流程的配角。

## 第三部分：多维度真实性校验机制

### 3.1 认知真实性校验

**问题**：培训记录有了，但民警实战不会用AI反诈工具。

**补丁条款**：

1. 培训课程内容由一线民警参与制定，每季度至少征集一次实战需求；
2. 考核方式从“选择题笔试”改为“模拟案例处置”，由县级公安局随机抽题；
3. 引入第三方匿名测评：每季度随机抽取办事群众，询问“民警是否使用了有效工具帮你解决问题”，作为认知转化率的硬指标；
4. 培训不得占用休息时间，不得作为额外负担转嫁民警。

### 3.2 服务真实性校验

**问题**：服务标准写在纸上，但群众感受不到。

**补丁条款**：

1. 服务细节清单必须由群众抽样确认，而不是仅靠内部自查：
   - 群众进门是否被主动询问；
   - 等候超过15分钟是否被告知预计时间；
   - 登记超过30分钟是否提供饮用水；
   - 办事结束是否被告知反馈渠道。
2. 等候区设置独立的“真实反馈终端”（触屏或扫码），数据直传县级平台，派出所仅可查看、不可修改、不可删除；
3. 每月由乡镇纪委或群众代表随机抽查至少5个办事录像（脱敏处理），核验服务细节执行率。

### 3.3 协同真实性校验

**问题**：部门边界模糊，群众被踢皮球，退伍军人身份无法触发绿色通道。

**补丁条款**：

1. **首问负责制**：第一个接待的部门必须生成可追踪的工单号，口头推诿视为违规；
2. **职责边界公开**：制作《乡镇基层服务职责边界手册》并在办事大厅公示，群众可拍照、可查阅；
3. **退伍军人绿色通道**：任一窗口识别退伍军人身份后，必须在5分钟内同步通知退役军人事务站，并在15分钟内给出联合响应方案；
4. **超时自动升级**：跨部门事项超过承诺时限未解决，系统自动抄送乡镇分管领导和县级主管部门；
5. **连带责任说明**：协同事项最终未解决，相关部门必须共同出具书面说明，不得单独以“不归我管”结案。

### 3.4 评分真实性校验

**问题**：评分成为被评单位自我表演的工具，差评被压、好评被刷。

**补丁条款**：

1. 评分系统由**县级独立技术方**维护，被评单位仅有查看权限，无修改、删除、筛选权限；
2. 引入反作弊算法：连续相同评分、异常时间分布、同一设备高频评分等触发复核；
3. **差评必须闭环**：所有异常低分评价，必须在24小时内电话或现场回访，并记录改进措施；
4. 公开数据不得只展示“满意度”，必须同步展示：
   - 参评率；
   - 异常反馈数量及分类；
   - 反馈闭环率；
   - 群众主动提出的改进建议数。

## 第四部分：评分机制重设计（龍魂“三才三色”真实度法）

### 4.1 为什么现行评分是错的

现行评分有几个致命问题：

| 问题 | 表现 | 后果 |
|---|---|---|
| 一元化 | 一个总分决定好坏 | 抹杀复杂情境 |
| 不可逆 | 一个差评拉低整体 | 没有容错空间 |
| 可操控 | 被评单位自己收集 | 数据失真 |
| 异化 | 为了分数而服务 | 人和事都变形 |
| 无对话 | 评价后没有回访 | 问题无法解决 |

这不是评估，这是**用数字压人**。

### 4.2 三才三色评分法

我们不问“你满意吗？打几颗星？”  
我们问三个独立维度，每个维度只给信号，不给总分：

#### 维度一：人 —— 有没有被当人看？

| 信号 | 含义 |
|---|---|
| 🟢 | 自然、尊重、有人情味 |
| 🟡 | 公事公办，略生硬，可改进 |
| 🔴 | 冷漠、推诿、让人难堪 |

#### 维度二：事 —— 问题有没有被认真处理？

| 信号 | 含义 |
|---|---|
| 🟢 | 清晰告知路径，尽力推进 |
| 🟡 | 处理中，但信息不透明 |
| 🔴 | 明显敷衍、踢皮球、不解决 |

#### 维度三：时 —— 时间和流程是否合理？

| 信号 | 含义 |
|---|---|
| 🟢 | 等待可接受，进度有说明 |
| 🟡 | 偏长，但能理解 |
| 🔴 | 过度拖延，无人说明 |

**核心规则**：
- 三个维度**不合并总分**，独立呈现；
- 一个🔴不决定整体，只触发“对话与改进”；
- 连续多个🟡才触发关注；
- 🟢是常态，不是表扬，不需要奖励。

### 4.3 容错机制

1. **单次异常不处罚**：任何一次🔴只触发回访和改进记录，不进入考核扣分；
2. **解释权利**：被评价方可在24小时内对异常反馈作出情况说明；
3. **情境权重**：明显恶意、重复刷评、非本人操作的反馈，经复核后不计入；
4. **改进优先**：连续三次同类🔴才启动帮扶机制，不是惩罚机制；
5. **正向容错**：主动暴露问题、主动改进的部门，给予真实度加分。

### 4.4 算法的仁慈性

龍魂算法的底层不是“优胜劣汰”，是**“真实、容错、共治”**。

- 数字根 dr=7 🟢 不是满分，是“可通行、可改进”；
- 三才评分 0.85 不是排名，是“三才齐备，可以继续走”；
- 颜色不是标签，是**方向指示**。

我们要的是：**问题暴露出来，人不被压垮，系统共同修复。**

### 4.5 对外卖、维修、移动服务等行业的延伸

这套评分机制不只适用于基层政府，也适用于所有“人对人服务”的场景：

| 场景 | 现行做法 | 替代做法 |
|---|---|---|
| 外卖骑手 | 一个差评扣钱 | 差评先对话，确认是否恶意，三次以上才介入 |
| 空调维修 | 强制五星好评 | 问“有没有乱收费、有没有讲清楚、有没有留保修方式” |
| 移动装机 | 装机后强推评分 | 问“师傅有没有为难你、有没有多跑一趟” |
| 乡镇窗口 | 满意度排名 | 三才三色真实度，无排名，只改进 |

**共同原则**：
- 不打总分；
- 不排名；
- 一个差评不决定命运；
- 服务方有解释权利；
- 数据由独立第三方维护；
- 改进比分数重要。

## 第五部分：四方责任与权利

### 5.1 派出所（执行与反馈方）

**责任**：
1. 执行服务真实性清单；
2. 为每位办事群众主动提供独立评价渠道；
3. 对跨部门事项必须生成工单并跟踪；
4. 配合县级匿名抽测和群众代表抽查。

**权利**：
1. 对不合理、不可操作的指标提出申诉；
2. 获得县级技术培训和系统支持；
3. 评分数据被篡改时可申请县级复核。

### 5.2 县级公安局（统筹与技术方）

**责任**：
1. 统一维护独立评分系统，确保数据不可被基层修改；
2. 组织实战导向的AI认知培训；
3. 每季度发布《基层窗口真实性审计报告》；
4. 对评分异常、数据造假启动核查。

**权利**：
1. 要求派出所接入统一平台；
2. 对连续不达标的单位启动帮扶；
3. 对恶意刷分、压差评行为提出处理建议。

### 5.3 跨部门协同小组

**成员**：派出所、退役军人事务站、民政办、司法所。

**责任**：
1. 每周固定时间联合坐班或线上联动；
2. 对任一部门受理的跨部门事项，其余部门同步收到通知；
3. 每月召开一次“真实性复盘会”，讨论被群众质疑或推诿的典型案例；
4. 共同维护并更新《职责边界公开手册》。

**权利**：
1. 联合申请专项经费；
2. 对上级不合理的职责划分提出联合调整建议；
3. 对协同效果突出的部门或个人推荐表彰。

### 5.4 群众（真实信息源与监督方）

**权利**：
1. 每次办事后通过独立渠道匿名评价；
2. 查阅《职责边界公开手册》；
3. 查询办事进度和跨部门流转记录；
4. 退伍军人享受标识明确的绿色通道。

**义务**：
1. 如实配合必要登记；
2. 客观评价，不恶意刷分；
3. 通过正规渠道反馈，不散布不实信息。

## 第六部分：实施路线图

### 第一阶段：基础搭建（1-2个月）

1. 成立四方协同小组；
2. 制定《职责边界公开手册》；
3. 部署独立真实反馈终端；

### 第二阶段：试运行（3-6个月）

1. 每周联合坐班；
2. 每月真实性复盘会；
3. 收集群众、民警双方反馈；
4. 不考核、不排名、只记录。

### 第三阶段：优化固化（7-12个月）

1. 根据试运行数据修订协议；
2. 将三才三色真实度纳入年度参考，但不纳入单一排名；
3. 对数据造假、删差评行为建立纪律红线；
4. 向其他乡镇推广。

## 第七部分：监督与迭代

### 7.1 独立监督

- 乡镇纪委：对服务态度和群众投诉进行独立调查；
- 县级公安局：对评分系统真实性和培训效果进行技术审计；
- 群众代表：每季度随机抽查服务细节，人数不少于3人。

### 7.2 季度迭代

每季度根据以下数据更新协议条款：
- 真实参评率与反馈闭环率；
- 跨部门协同响应率；
- 群众主动提出的改进建议；
- 民警和基层工作人员反馈的操作障碍。

### 7.3 版本控制

每次迭代生成新版本，旧版本归档，确保制度演进可追溯。
