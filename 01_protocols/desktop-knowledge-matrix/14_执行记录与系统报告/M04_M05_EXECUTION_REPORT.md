## 🎯 推演引擎的意義

### 為什麼需要這兩個引擎？

1. **易經 (M04)**: 檢驗決策的「正義性」
   - 動機是否純正（根本）
   - 決策是否符合「道」（方向）
   - 卦象是否指向吉利（預兆）

2. **五行 (M05)**: 檢驗決策的「平衡性」
   - 五個維度是否均衡（結構）
   - 相生相剋是否合理（邏輯）
   - 是否存在過度傾斜（風險）

### 易經 + 五行 = 完整的決策驗證

```
易經負責「是什麼」: 動機·方向·吉凶
五行負責「怎麼樣」: 平衡·結構·可行性

兩者合力 = 360° 決策審視
```
