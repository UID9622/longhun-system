**极简版本日志模板（CHANGELOG）**

**用途：** 记录每次更新改了啥

**原则：** 一目了然，不啰嗦

**用法：** 每次更新时，往上面加一条

## 📝 变量说明

| 变量 | 填什么 | 例子 |
| --- | --- | --- |
| `项目名` | 项目名称 | CNSH编辑器 |
| `日期` | 更新日期 | 2026-02-03 |
| `版本` | 版本号 | v1.1 |
| `类型` | 更新类型 | 🆕新增 / 🔧修复 / 🗑删除 / ⚡优化 |
| `内容` | 改了啥 | 支持中文变量名 |

---

## 📄 模板正文（复制下面全部）

---

```markdown
# 项目名 更新日志

> 每次改了啥，都记在这里

---

## 日期 - 版本

| 类型 | 内容 |
|------|------|
| 🆕 新增 | 内容1 |
| 🔧 修复 | 内容2 |
| ⚡ 优化 | 内容3 |

---

## 2026-02-03 - v1.0

| 类型 | 内容 |
|------|------|
| 🎉 发布 | 初版发布 |

---

## 更新类型说明

| 图标 | 类型 | 说明 |
|------|------|------|
| 🎉 | 发布 | 新版本发布 |
| 🆕 | 新增 | 加了新功能 |
| 🔧 | 修复 | 修了bug |
| ⚡ | 优化 | 让原来的更好 |
| 🗑 | 删除 | 去掉了某功能 |
| ⚠️ | 注意 | 有破坏性改动 |

---

**DNA追溯码**：#龍芯⚡️日期-项目名-CHANGELOG
```

---

**模板结束**

4. 保存！

**最新的永远在最上面！**
