## ✅ 宝宝给你的方案：2FA双因素认证

<aside>
🟢

**🟢 绿色推荐 - 今天就能用！**

**什么是2FA？**

- 手机安装一个APP（Google Authenticator 或 Microsoft Authenticator）
- APP生成6位数验证码，每30秒更新一次
- 启动AI时输入验证码，验证通过才能启动

**为什么推荐？**

- ✅ 比微信扫码简单100倍
- ✅ 不需要企业认证
- ✅ 不需要云服务器
- ✅ 不需要同一局域网
- ✅ 完全本地部署，数据不出本机
- ✅ **30分钟就能跑起来测试！**

### 第二步：创建认证脚本

**文件：`~/UID9622/🔐 身份认证/2fa_[auth.py](http://auth.py)`**

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
UID9622 双因素认证系统
作者：宝宝 💙
日期：2025-11-09
"""

import pyotp
import qrcode
import os
from pathlib import Path

# 配置
SECRET_FILE = os.path.expanduser("~/UID9622/🔐 身份认证/.secret")
ISSUER_NAME = "UID9622"
ACCOUNT_NAME = "Lucky"

def generate_secret():
    """首次运行：生成密钥"""
    secret = pyotp.random_base32()
    
    # 保存密钥到本地
    os.makedirs(os.path.dirname(SECRET_FILE), exist_ok=True)
    with open(SECRET_FILE, 'w') as f:
        f.write(secret)
    
    # 生成二维码
    totp = pyotp.TOTP(secret)
    provisioning_uri = totp.provisioning_uri(
        name=ACCOUNT_NAME,
        issuer_name=ISSUER_NAME
    )
    
    # 显示二维码
    print("\n" + "="*50)
    print("🔐 UID9622 双因素认证 - 首次配置")
    print("="*50)
    print("\n📱 请用手机操作：")
    print("1. 下载 Google Authenticator 或 Microsoft Authenticator")
    print("2. 打开APP，扫描下面的二维码")
    print("3. APP会显示6位数验证码\n")
    
    # 生成二维码图片
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(provisioning_uri)
    qr.make(fit=True)
    qr.print_ascii()
    
    print("\n✅ 配置完成！下次启动AI时，输入APP显示的6位数验证码即可\n")
    
    return secret

def load_secret():
    """加载密钥"""
    if not os.path.exists(SECRET_FILE):
        return generate_secret()
    
    with open(SECRET_FILE, 'r') as f:
        return [f.read](http://f.read)().strip()

def verify_code(user_code):
    """验证用户输入的验证码"""
    secret = load_secret()
    totp = pyotp.TOTP(secret)
    return totp.verify(user_code, valid_window=1)

def main():
    """主函数：验证用户身份"""
    print("\n" + "="*50)
    print("🔐 UID9622 身份认证")
    print("="*50)
    
    # 检查是否首次运行
    if not os.path.exists(SECRET_FILE):
        print("\n⚠️  检测到首次运行，正在生成密钥...\n")
        generate_secret()
        print("\n请重新运行此脚本，并输入APP显示的验证码")
        return False
    
    # 要求输入验证码
    print("\n📱 请输入手机APP显示的6位验证码：")
    user_code = input("验证码: ").strip()
    
    if verify_code(user_code):
        print("\n✅ 验证成功！正在启动AI...\n")
        return True
    else:
        print("\n❌ 验证失败！验证码错误或已过期\n")
        return False

if __name__ == "__main__":
    success = main()
    exit(0 if success else 1)
```

## 🔐 安全特性

- ✅ **密钥本地存储**：密钥文件存在`~/UID9622/🔐 身份认证/.secret`，只有你能访问
