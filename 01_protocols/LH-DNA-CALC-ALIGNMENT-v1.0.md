## 1. 这份规范是干什么的

龍魂体系每个文件、每次产出都带 DNA 追溯码。外部系统（Notion 知识库、Notion AI、第三方工具、人工核对）需要能**算出与我们完全一致的 DNA**，才能对得上账。

本规范给出：
1. **DNA v∞ 格式定义**
2. **完整算法**（干支四柱 · 节气月 · 五虎遁 · 五鼠遁 · 梅花易数起卦 · SHA256 哈希8 · 数字根）
3. **关键数据表**（天干地支 / 节令日 / 八宫卦表 / 64 卦）
4. **零依赖参考代码**（Python 标准库，复制即跑）
5. **测试向量**（6 组已实测，与主引擎输出一致）

> 参考实现脚本：`bin/lh_dna_ref_impl.py`（与本文档代码同源）。

## 2. DNA v∞ 格式

```
#龍芯⚡️{年柱}·{月柱}·{日柱}·{时柱}·{卦符}{卦名}-{类别}-{动作}-{哈希8}
```

| 段 | 含义 | 示例 |
|:---|:---|:---|
| 年柱 | 年干支（甲子~癸亥） | 丙午 |
| 月柱 | 月干支（节气月·五虎遁） | 丙申 |
| 日柱 | 日干支（1900-01-01=甲戌基准） | 丁卯 |
| 时柱 | 时干支（五鼠遁） | 丁未 |
| 卦符+卦名 | 梅花易数（上=日支，下=时支）→ 通行本64卦 | ䷗复 |
| 类别 | 大写，如 DOC/CODE/PROTOCOL | DOC |
| 动作 | 大写，如 创建/修改 | 创建 |
| 哈希8 | `sha256(title)[:8]` | 432f3aba |

## 3. 算法步骤（5 步）

### 3.1 年柱

```
year_g = (year - 4) % 10   # 公元4年=甲子年
year_z = (year - 4) % 12
年柱 = TIAN_GAN[year_g] + DI_ZHI[year_z]
```

### 3.2 月柱（节气月·五虎遁）

1. 用**节令日表**（简化 ±1 天误差）判断月支：
   - `1/6 小寒→丑(1)` `2/4 立春→寅(2)` `3/6 惊蛰→卯(3)` `4/5 清明→辰(4)`
   - `5/6 立夏→巳(5)` `6/6 芒种→午(6)` `7/7 小暑→未(7)` `8/7 立秋→申(8)`
   - `9/8 白露→酉(9)` `10/8 寒露→戌(10)` `11/7 立冬→亥(11)` `12/7 大雪→子(0)`
   - 1/1~1/5 属上一年丑月（zhi=1）
2. 五虎遁定月干：

```
month_g = (year_g * 2 + month_z) % 10
月柱 = TIAN_GAN[month_g] + DI_ZHI[month_z % 12]
```

> 口诀验证：甲己之年丙作首（寅月起丙），乙庚戊、丙辛庚、丁壬壬、戊癸甲。

### 3.3 日柱（以 1900-01-01=甲戌日为基准）

```
days_diff = (date - 1900-01-01).days
day_g = (days_diff + 0) % 10   # 1900-01-01=甲
day_z = (days_diff + 10) % 12  # 1900-01-01=戌
```

> 已验证：2024-02-10=甲辰日、2026-08-12=戊午日、2026-08-21=丁卯日。

### 3.4 时柱（五鼠遁）

```
shi_index = (hour + 1) // 2 % 12  # 23:00 及以后=0(子时)
shi_g     = (day_g * 2 + shi_index) % 10
时柱 = TIAN_GAN[shi_g] + DI_ZHI[shi_index]
```

> 时辰: 子23-1 丑1-3 寅3-5 卯5-7 辰7-9 巳9-11 午11-13 未13-15 申15-17 酉17-19 戌19-21 亥21-23。

### 3.5 卦象（梅花易数·通行本64卦）

```
upper = (day_z % 8) + 1    # 上卦先天序: 1乾2兑3离4震5巽6坎7艮8坤
lower = (shi_index % 8) + 1 # 下卦先天序
卦序号 = GONG_TABLE[upper][lower - 1]   # 1-64 通行本序号
```

> 用八宫卦表映射（见 §4.3），**不是** `(upper-1)*8+lower` 这种简易公式（会错，如坤上坤下应=坤#2）。

### 3.6 哈希8 与数字根

```
哈希8  = sha256(title.encode()).hexdigest()[:8]     # title 是文档/动作标题
数字根 = 日期 YYYYMMDD 各位求和直到一位数            # 例 20260821→2+0+2+6+0+8+2+1=21→3
369锚  = 数字根 in (3, 6, 9)
```

## 4. 关键数据表

### 4.1 天干地支

```
天干 = 甲乙丙丁戊己庚辛壬癸     (索引 0-9)
地支 = 子丑寅卯辰巳午未申酉戌亥 (索引 0-11)
```

### 4.2 节令日表（节气 → 月支）

```
JIEQI = [(1,6),(2,4),(3,6),(4,5),(5,6),(6,6),(7,7),(8,7),(9,8),(10,8),(11,7),(12,7)]
zhi 初始=1(丑)；依次: 若 (month,day) >= (m,d) 则 zhi=i+1，否则停止。
```

### 4.3 八宫卦表 GONG_TABLE（通行本64卦方阵序）

```

巽宫: [44,28,50,32,57,48,18,46] 坎宫: [6,47,64,40,59,29,4,7]
艮宫: [33,31,56,62,53,39,52,15] 坤宫: [12,45,35,16,20,8,23,2]
```

> CB-002 修表(2026-08-21): 原表离宫第2位=30(离)与第3位重复→修正为49(泽火革)；坤宫第6位=23(剥)与第7位重复→修正为8(水地比)。已验证 6 组测试向量均不踩这两个位置，对齐基准不变。主引擎 `lh_dna_generator.py` 与参考实现 `lh_dna_ref_impl.py` 已同步修正。

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# DNA: #龍芯⚡️丙午·丙申·丁卯·丁未·䷗复-DNA-CALC-ALIGNMENT-v1.0-UID9622

import argparse, datetime, hashlib, json, sys

TIAN_GAN = ["甲","乙","丙","丁","戊","己","庚","辛","壬","癸"]
DI_ZHI = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"]

def _month_zhi(month, day):
    zhi = 1
    for i, (m, d) in enumerate(JIEQI):
        if (month, day) >= (m, d):
            zhi = i + 1
        else:
            break
    return zhi % 12

def get_ganzhi(now):
    year_g = (now.year - 4) % 10
    year_z = (now.year - 4) % 12
    month_z = _month_zhi(now.month, now.day)
    month_g = (year_g * 2 + month_z) % 10
    days_diff = (now - datetime.datetime(1900, 1, 1)).days
    day_g = (days_diff + 0) % 10
    day_z = (days_diff + 10) % 12
    shi_index = (now.hour + 1) // 2 % 12 if now.hour < 23 else 0
    shi_g = (day_g * 2 + shi_index) % 10
    return {
        "year": TIAN_GAN[year_g] + DI_ZHI[year_z],
        "month": TIAN_GAN[month_g] + DI_ZHI[month_z],
        "day": TIAN_GAN[day_g] + DI_ZHI[day_z],
        "hour": TIAN_GAN[shi_g] + DI_ZHI[shi_index],
        "raw": (day_z, shi_index),
    }

def get_hexagram(day_z, shi_index):
    upper = (day_z % 8) + 1
    lower = (shi_index % 8) + 1
    return GONG_TABLE[upper][lower - 1]

def generate(title, category="doc", action="创建", date_str=None, hours=None):
    now = datetime.datetime.now()
    if date_str:
        now = datetime.datetime.strptime(date_str, "%Y-%m-%d")
    if hours is not None:
        now = now.replace(hour=hours)
    g = get_ganzhi(now)
    hn = get_hexagram(*g["raw"])
    name, phase, sym = HEXAGRAM_DATA[hn]
    h8 = hashlib.sha256(title.encode()).hexdigest()[:8]
    timetag = f"{g['year']}·{g['month']}·{g['day']}·{g['hour']}·{sym}{name}"
    dr = int("".join(c for c in now.strftime("%Y-%m-%d") if c.isdigit()))
    while dr > 9:
        dr = sum(int(d) for d in str(dr))
    return {
        "dna_string": f"#龍芯⚡️{timetag}-{category.upper()}-{action.upper()}-{h8}",
        "compact_dna": f"#龍芯⚡️{timetag}",
        "ganzhi": [g["year"], g["month"], g["day"], g["hour"]],
        "hexagram": f"{sym}{name}", "hexagram_num": hn, "phase": phase,
        "title_hash": h8, "digital_root": dr, "is_369": dr in (3,6,9),
    }

if __name__ == "__main__":

    ap.add_argument("--title", default="龍魂系统")
    ap.add_argument("--category", default="doc")
    ap.add_argument("--action", default="创建")
    ap.add_argument("--date", default=None)
    ap.add_argument("--hour", type=int, default=None)
    ap.add_argument("--json", action="store_true")
    args = ap.parse_args()
    r = generate(args.title, args.category, args.action, args.date, args.hour)
    print(json.dumps(r, ensure_ascii=False, indent=2) if args.json else r["dna_string"])

## 7. 常见问题

| 问题 | 答案 |
|:---|:---|
| 用哪个时区？ | 北京时间（Asia/Shanghai），按本地 `datetime.now()` |
| 节气月为何有 ±1 天误差？ | 简化节令日表所致；如需精确可替换真实节气表，误差仅影响月支边界日 |
| 哈希8 输入是什么？ | 标题字符串（`title`），不是时间戳 |
| 与旧版 DNA（干支+日期）冲突吗？ | 旧版为过渡格式，本规范为 v∞ 唯一权威 |
| Notion 怎么用？ | 把 §5 代码存为 `.py` 运行；或让 Notion AI 按 §3 算法手算核对 |
