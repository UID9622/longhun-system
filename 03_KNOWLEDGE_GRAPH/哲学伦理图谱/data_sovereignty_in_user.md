# 数据主权在用户 · 不可妥协底线

**主张**：用户数据 100% 本地存储，用户可随时导出、删除、拒绝系统私自上传。

**基于什么**
- 《北辰-母协议·龍魂系统全球治理宪章 v1.0》P0-2 永恒级条目
- 个人信息保护法第51-58条、数据安全法第27条

**怎么推导**
1. 数据不是资产也不是燃料，是人的延伸 → 不能当可交易资源
2. 若默认允许云端上传，用户主权被悄悄剥夺 → 必须默认本地优先
3. 主权要可操作（能导出/删除/拒传），否则只是标语

**得出什么**
系统以数据主权为设计第一优先级；违反 → 永久封禁 + 公开道歉 + 赔偿。

**为什么**
替老百姓守住数字主权是龍魂系统唯一天条。平台服务可以降级，但不能反向绑架用户。
