## 二、节点类型（新增 rationale 类）

在现有 `graph_data.json`（资产型节点：skill / module / html_tool…）之外，新增专门承载"思想"的节点类型：

| 类型 | 含义 | 示例 |
|:----:|:-----|:-----|
| principle | 哲学/伦理原则（不可变底线） | 数据主权在用户、三色审计 |
| belief | 核心信念/价值观 | 军魂无条件贡献、技术为人民服务 |
| doctrine | 核心主张/铁律（体系级） | 中文是完整逻辑表达语言、CNSH不归属商业实体 |
| derivation | 推导链（基于→推导→结论） | 洛书九宫→不动点→主权锚定 |
| source | 思想源文件（可溯源锚点） | 用户权利宪章、核心思想、开放宣言 |

## 三、节点字段规范（每个 rationale 节点必须包含）

```
id            唯一ID（英文slug，如 data_sovereignty_in_user）
type          principle | belief | doctrine | derivation | source
title         中文标题
dna           DNA追溯码（#龍芯⚡️... 或 #CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z）
owner         归属（恒为 UID9622 · 诸葛鑫）
claim         主张（一句话说清"是什么"）
based_on      基于什么（事实/法律/文化根/前人思想）
reasoning     怎么推导（逻辑链，可多步）
conclusion    得出什么（结论/动作）
why           为什么这样（底层动机/不可妥协原因）
source_link   溯源链接（指向源文件相对路径，本地可直接点开）
related       [关联节点id列表]
immutable     true/false（是否焊死底线，不可改）
created       农历干支日期（禁公历）
```
