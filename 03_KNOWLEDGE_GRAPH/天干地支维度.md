## 2. 时序编码

### 2.1 干支编码函数
```python
def ganzhi_encode(timestamp):
    """将时间戳编码为干支表示"""
    year = timestamp.year
    stem_idx = (year - 4) % 10      # 年天干（甲子起于公元4年）
    branch_idx = (year - 4) % 12     # 年地支
    jiazi_idx = (year - 4) % 60      # 60甲子序号
    return stem_idx, branch_idx, jiazi_idx
```
