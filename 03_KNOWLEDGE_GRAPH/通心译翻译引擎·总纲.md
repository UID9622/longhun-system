## 1. 定义

通心译 = 语义翻译而非字面翻译。不是"把A语言翻译成B语言"，而是"把A想表达的意思，用B理解的方式传达"。

## 2. 五层翻译架构

```
┌─────────────────────────────────────┐
│ L5 意图层：理解"说话人真正想说什么" │
├─────────────────────────────────────┤
│ L4 语境层：理解"在什么场景下说的"   │
├─────────────────────────────────────┤
│ L3 语义层：理解"这句话的含义"       │
├─────────────────────────────────────┤
│ L2 语法层：理解"这句话的结构"       │
├─────────────────────────────────────┤
│ L1 字面层：理解"每个字/词的意思"    │
└─────────────────────────────────────┘
```

传统机器翻译：L1-L2（字面→语法）。
通心译：L3-L5（语义→语境→意图）。

## 3. 核心公式

$$
T(M, R, C) = R^{-1} \circ S \circ M
$$

其中：
- $M$: 源消息（Message）
- $R$: 接收者模型（Receiver Model：对方的认知框架）
- $C$: 上下文（Context）
- $S$: 语义编码/解码器
- $T$: 通心译输出

翻译不是 $M \to T$ ，而是 $M \to M_{语义} \to T_{适配R的认知}$。

## 4. 双向不对称原则

| 方向 | 策略 | 示例 |
|:---|:---|:---|
| **下行**（专家→小白） | 术语→大白话·比喻·类比 | "LoRA微调" → "就像只换书里的注释，不动原文" |
| **上行**（小白→专家） | 白话→术语·结构化 | "机器学东西" → "模型训练/参数优化" |
| **平级**（同行→同行） | 术语保持·深入 | 直接使用领域术语 |
| **跨域**（A领域→B领域） | 映射到共同抽象 | 用数学/哲学做共同语言 |

## 5. 语义抽屉匹配

通心译在翻译前先执行语义抽屉匹配：

```
输入 → 情绪检测(喜/怒/哀/乐/严肃/玩笑)
     → 场景识别(工作/生活/学术/创作)
     → 对象建模(对方知识水平·文化背景)
     → 风格选择(直接/委婉/幽默/正式)
     → 输出
```
