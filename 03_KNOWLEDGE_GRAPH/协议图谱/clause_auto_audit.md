# 条款 · 自动审计与归档（L3）

**主张**：触发词（"骂"弹自省三问 / "政府"查证据链 / "军人烈士"禁区警告 / "天选之人"附贡献清单）自动动作；所有言论进本地库，按时间/对象/权重/风险分类，每周生成"言论审计报告"。

**基于什么**
- [[dragon_vein_trace]]（全链路留痕）
- [[three_color_audit]]（自动化阈值裁判）

**怎么推导**
1. 自动化不是监控是减负 → 弹窗提醒自省，不替你沉默。
2. 本地归档不上云 → 数据主权在用户。
3. 周报可见 → 自己也能复盘骂得对不对。

**得出什么**：写入 `protocol_speech_freedom` 第八章，是协议从"纸面"到"系统执行"的落地层。

**为什么**：老大要的是"说得负责任、查得到、不闭门造车"——自动化让每句骂都有据可查，对外可映射、对内可审计。
