# 条款 · 自骂优先·自省机制（L2）

**主张**：骂前必问三句——我贡献了什么？证据硬吗？我自己做到了吗？任一不过：先干活 / 闭嘴去收集 / 先骂自己。只骂事不骂人。

**基于什么**
- [[three_color_audit]]（第一审人心：良心过得去吗）
- [[no_human_rights_violation]]（先律己再律人）

**怎么推导**
1. 主权人格先对自己负责 → 批评他人前先审查自己。
2. 三问过滤无脑喷 → 没贡献没证据没做到 = 闭嘴。
3. 自省不是软弱，是纪律 → 骂得有理才骂得响。

**得出什么**：写入 `protocol_speech_freedom` 第三、六章，自动化执行时"骂"触发弹出自省三问。

**为什么**：老大原话"对人当人，对狗当狗……自己他妈什么都不是的，骂也小心点"。自省是战友关系的过滤器。
