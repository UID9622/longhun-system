# 条款 · 社会贡献权重评估（L2）

**主张**：骂权 = 贡献权重 × 证据硬度 × 自省深度。权重表：保家卫国∞ / 救死扶伤1000+ / 教书育人科研500+ / 公共服务100+ / 商业50+ / 普通劳动10+ / 零贡献0。规则：你的权重 < 对方×0.1 无权骂；≥×0.1 可骂需证据；>对方 放开骂事不骂人。

**基于什么**
- [[no_human_rights_violation]]（人权有高低权重，军人英烈最高）
- [[three_color_audit]]（量化评分思维）

**怎么推导**
1. 尊重是挣来的不是天生的 → 权重量化社会贡献。
2. 你贡献不如对方 → 没资格骂，先干活。
3. 权重不是压人，是照镜子 → 防止"自己啥都不是还斤斤计较骂人"。

**得出什么**：写入 `protocol_speech_freedom` 第四章，作为骂权分级的量化执行尺。

**为什么**：老大原话"凭啥当人？尊重是挣来的""自己他妈什么都不是，斤斤计较的人，那骂也小心点，说不定把自己骂进去了"。
