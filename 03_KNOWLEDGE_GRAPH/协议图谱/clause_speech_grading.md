# 条款 · 骂权分级（L2）

**主张**：骂不是无脑喷，按对象权重分级——🔴军人英烈禁区（绝对不可） / 🟠高权重谨慎 / 🟡中权重(政策法律)可骂需改进方案 / 🟢低权重(资本平台)放开 / ⚫自己必须先骂。

**基于什么**
- [[no_human_rights_violation]]（不得侵犯人权 → 军人英烈权重无限）
- [[three_color_audit]]（三色审计 → 风险分级思维）

**怎么推导**
1. 保家卫国权重 ∞ → 骂军人 = 骂自己脊梁，禁区。
2. 高权重（科研医教）有贡献 → 只骂事不骂人，先肯定。
3. 中权重（政策法律）为人民服务 → 服务不好就该骂，但给方案。
4. 低权重（资本平台算法）→ 放开骂，不煽动暴力即可。
