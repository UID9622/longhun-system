# 条款 · 主权撤回（随时插停）（L2）

**主张**：创作者说"不奉献了"就能停。插停后系统立即停止新训练/新分发，已分发版本标记"撤回"，后续结算停止计入。已结算不追回，不追责不降权。

**基于什么**
- [[data_sovereignty_in_user]]（数据主权在用户）
- [[dragon_vein_trace]]（留痕即主权）

**怎么推导**
1. 主权在用户 → 贡献是授权，授权可撤销。
2. 插停是主权行为，不是违约 → 不得降权封号。
3. 已分发标记撤回、已结算不追回 → 平衡"可追溯"与"可逆"。

**得出什么**：写入 `protocol_knowledge_sovereignty` 第三章，撤回动作本地生效、无需平台审批。

**为什么**：老大原话"创作者可以随时插停，你说不奉献了"——主权必须可逆，否则叫征用。
