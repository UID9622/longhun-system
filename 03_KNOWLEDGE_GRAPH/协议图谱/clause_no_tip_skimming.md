# 禁止打赏抽成收割 · v1.0

## 机制拆解

打赏抽成 = 单向财富转移：
- 用户花钱买虚拟存在感（不是实物）
- 主播拿小头，平台抽成 50%+
- 平台不创造价值，只做流量二传手

收割层级：观看(时间) → 分享(社交信用) → 打赏(金钱) → 成瘾(生活秩序) → 模仿开播(人格异化)。

## 龍魂替代

- 禁 打赏、礼物、嘉年华等抽成变现
- 创作者以**公共基金补贴 + 固定订阅**支撑，零抽成
- 企业赞助透明公示，不影响内容
- 经济模型：平台收益低（运营成本），用户损失零，社会价值正
