## 第一层：看得见的东西（前端）

### 1. 页面长什么样（HTML）
- **人话**：网页的骨架，告诉浏览器哪里放标题、哪里放图片、哪里放按钮
- **龍魂语义**：`骨架 = 人体的骨头，撑住所有肉`
- **核心标签**：
  - `<div>` = 一个盒子，装东西
  - `<button>` = 按钮，点了会动
  - `<img>` = 图片，显示图形
  - `<a>` = 链接，点了跳别的地方
  - `<input>` = 输入框，打字用的
  - `<video>` = 视频播放器
  - `<audio>` = 音频播放器

### 2. 长得好不好看（CSS）
- **人话**：网页的衣服，控制颜色、大小、位置、动画
- **龍魂语义**：`衣服 = 军装，统一规范，一眼认得出`
- **核心属性**：
  - `color` = 字什么颜色
  - `background` = 背景什么颜色
  - `width/height` = 多宽多高
  - `margin/padding` = 盒子外面/里面留多少空
  - `display` = 怎么排列（横着排/竖着排/隐藏）
  - `position` = 定在哪里（固定/相对/绝对）
  - `animation` = 动起来（淡入/滑动/旋转）
  - `flex/grid` = 自动排列布局

### 3. 点了会不会动（JavaScript）
- **人话**：网页的脑子，控制交互、逻辑、数据
- **龍魂语义**：`脑子 = 指挥官，按钮按了执行什么命令`
- **核心能力**：
  - 点击按钮 → 弹出窗口
  - 输入文字 → 实时检查对错
  - 滑动页面 → 加载更多内容
  - 提交表单 → 发送数据到后端
  - 获取数据 → 从后端拿回来显示

### 4. 前端框架（React/Vue/Angular）
- **人话**：别人写好的工具箱，不用从零造轮子
- **龍魂语义**：`工具箱 = 军用标准件，拧螺丝不用自己打铁`
- **React**：Facebook做的，组件化，像搭积木
- **Vue**：中国人做的，简单好学，文档中文
- **Angular**：Google做的，大而全，企业级

## 第二层：看不见的东西（后端）

### 1. 服务器是什么（Server）
- **人话**：一台24小时开着的电脑，专门处理请求、存数据
- **龍魂语义**：`服务器 = 军营，24小时站岗，谁来都接待`
- **类型**：
  - 物理服务器 = 真电脑，放机房
  - 云服务器 = 租别人的电脑（阿里云/华为云/AWS）
  - 本地服务器 = 你自己的电脑当服务器

### 2. 接口是什么（API）
- **人话**：前端和后端对话的规矩，像打电话的暗号
- **龍魂语义**：`接口 = 军用电台，发什么频率、收什么频率，对不上就乱套`
- **核心概念**：
  - `GET` = 要数据（查）
  - `POST` = 给数据（增）
  - `PUT` = 改数据（改）
  - `DELETE` = 删数据（删）
  - `JSON` = 数据格式，前后端都能读懂

### 3. 数据库是什么（Database）
- **人话**：存数据的地方，像档案柜
- **龍魂语义**：`数据库 = 档案室，每份文件有编号，找起来快`
- **类型**：
  - MySQL = 关系型，像Excel表格，有行有列
  - MongoDB = 文档型，像文件夹，灵活
  - Redis = 缓存型，像备忘录，快但不多

### 4. 后端语言
- **Python**：简单，AI友好，龍魂首选
- **Node.js**：JavaScript跑后端，前后端一套语言
- **Go**：快，并发强，微服务首选
- **Java**：企业级，银行政府用得多
- **PHP**：老派，WordPress/blog常用

## 第三层：连接层（网络）

### 1. IP地址
- **人话**：每台电脑的门牌号
- **龍魂语义**：`IP = 军营地址，找不到地方怎么送信`
- **公网IP**：全世界能找到你
- **内网IP**：局域网内能找到你
- **localhost/127.0.0.1**：自己找自己

### 2. 端口（Port）
- **人话**：门牌号后面的房间号
- **龍魂语义**：`端口 = 军营里的不同部门，前门/后门/侧门`
- **常用端口**：
  - 80 = HTTP网页
  - 443 = HTTPS加密网页
  - 22 = SSH远程登录
  - 3306 = MySQL数据库
  - 6379 = Redis缓存

### 3. 域名（Domain）
- **人话**：IP的别名，好记的名字
- **龍魂语义**：`域名 = 军营代号，不用记经纬度，记名字就行`
- 例：longhun888.com → 对应某个IP
- DNS = 翻译官，把名字翻译成IP

### 4. HTTP/HTTPS
- **人话**：浏览器和服务器对话的规矩
- **龍魂语义**：`HTTP = 明文电报，谁都能截获；HTTPS = 加密电报，截获也看不懂`
- **SSL证书**：让HTTP变成HTTPS的通行证

## 第四层：图形与资源

### 1. 图片格式
- **PNG**：透明背景，无损，图标/logo
- **JPG**：照片，有损压缩，体积小
- **SVG**：矢量，放大不模糊，图标/插画
- **GIF**：动图，表情包
- **WebP**：新一代，体积小质量好

### 2. 图标库（Icon Font）
- **FontAwesome**：最常用，几千个图标
- **Material Icons**：Google的，简洁
- **阿里图标库**：国内的，免费
- **使用方式**：像字体一样用，改颜色改大小

### 3. 图形搜索与使用
- **Unsplash**：免费高清照片
- **Pexels**：免费视频/照片
- **Pixabay**：免费插画/矢量图
- **Flaticon**：免费图标
- **龍魂规则**：用的时候标出处，不偷不抢

### 4. 嵌入方式
- **图片嵌入**：`<img src="图片地址">`
- **图标嵌入**：`<i class="fa fa-home"></i>`
- **视频嵌入**：`<video src="视频地址">`
- **音频嵌入**：`<audio src="音频地址">`
- **iframe嵌入**：把一个网页嵌到另一个网页里

- **cPanel**：国外老牌，功能全

- **Prometheus + Grafana**：专业监控，图表好看
- **Netdata**：实时，安装简单
- **龍魂语义**：`监控 = 哨兵，24小时盯着，有问题报警`

## 第六层：云与本地

### 1. 云服务（华为云/阿里云/AWS）
- **ECS**：弹性计算 = 租电脑
- **OSS**：对象存储 = 租硬盘存文件
- **RDS**：数据库服务 = 租数据库
- **CDN**：内容分发 = 在全国各地建小仓库，就近取货
- **龍魂语义**：`云 = 租别人的军营，不用自己盖`

### 2. 本地服务器
- **树莓派**：小电脑，几百块，家用
- **NAS**：网络硬盘，存资料
- **华为鲲鹏**：国产芯片，龙魂底座
- **龍魂语义**：`本地 = 自己的军营，数据在自己手里`

### 3. 部署方式
- **手动部署**：FTP上传文件，命令行配置
- **Git部署**：代码推送到Git，服务器自动拉
- **Docker部署**：打包成容器，哪里都能跑
- **CI/CD**：自动测试+自动部署，推代码就上线
- **龍魂语义**：`部署 = 部队开拔，从训练场到战场`
