## 1. 五行标签体系

### 1.1 概述

五行标签 = 5个基础元素 x 4种状态 = **20个变体**

| 元素 | Unicode | 颜色 | 英文 |
|------|---------|------|------|
| 金 | U+91D1 | #FFD700 (白/金) | Metal |
| 木 | U+6728 | #228B22 (青/绿) | Wood |
| 水 | U+6C34 | #1E90FF (黑/蓝) | Water |
| 火 | U+706B | #DC143C (赤/红) | Fire |
| 土 | U+571F | #8B4513 (黄/棕) | Earth |

### 1.2 五行生克关系

```
生(相乘): 金 -> 水 -> 木 -> 火 -> 土 -> 金
克(相侮): 金 -> 木 -> 土 -> 水 -> 火 -> 金
```

| 关系 | 组合 | 判定 |
|------|------|------|
| 金生水 | 金 + 水 | 吉，资源滋养 |
| 水生木 | 水 + 木 | 吉，数据生长 |
| 木生火 | 木 + 火 | 吉，功能激活 |
| 火生土 | 火 + 土 | 吉，产出沉淀 |
| 土生金 | 土 + 金 | 吉，基础变现 |
| 金克木 | 金 + 木 | 凶，资源压制 |
| 木克土 | 木 + 土 | 凶，增长过载 |
| 土克水 | 土 + 水 | 凶，存储阻塞 |
| 水克火 | 水 + 火 | 凶，安全灭火 |
| 火克金 | 火 + 金 | 凶，过载熔断 |

## 5. 组合标签规则

### 5.1 组合语法

```
标签 := 基础标签 ["·" 变体] ["·" 修饰符]

最多3层嵌套:
  第1层: 基础标签 (必选)       - 五行/八卦/甲骨文/星宿
  第2层: 状态变体 (可选)       - 生旺休囚 / 正反动 / 情绪功能
  第3层: 修饰符 (可选)         - 自定义描述

示例:
```
