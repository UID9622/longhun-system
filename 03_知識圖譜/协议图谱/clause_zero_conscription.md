# 条款 · 零征用原则（L2）

**主张**：系统绝不用别人的数据偷偷优化模型。用户数据只存本地，不上传、不分析、不画像、不参与任何模型迭代。

**基于什么**
- [[data_sovereignty_in_user]]（数据主权在用户）
- [[local_first]]（数据绝对本地化）
- [[no_human_rights_violation]]（不得侵犯人权）

**怎么推导**
1. 人民数据主权是 P0 焊死底线 → 数据归属用户，不在系统。
2. 模型优化若偷偷吃用户数据 = 征用 = 侵犯主权。
3. 因此系统默认零征用，跨墙出境需用户显式授权 + 确认码。

**得出什么**：零征用写入 `protocol_knowledge_sovereignty` 第一章，黑箱禁令禁止"悄悄改写后据为己有"。

**为什么**：直接回应"窝里横"——真开放是真不偷。系统不偷用户数据，才配谈科技共享、普惠全球。
