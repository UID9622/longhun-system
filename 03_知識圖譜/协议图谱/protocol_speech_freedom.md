## 总则

老大原话："让每个人能说出这声音，你可以骂你不爽了，可以骂他们，骂哪个领导都可以，骂哪个国家的都可以。你说的不平整，只要有实质证据，你用最不开心最人性的最底层的妈个逼的，随便怎么骂。不煽动政治，政治就是为老百姓服务的，干嘛不能骂？"

本协议把这段话落成可执行的规则。核心精神：**政治 = 为老百姓服务的规则体系。服务好了夸，服务不好骂，不服务（非暴力）推翻。** 但骂不是无脑喷——它有边界（禁区）、有门槛（权重）、有纪律（自省）、有证据（DNA）。

对齐哲学根：[[no_human_rights_violation]]（不得侵犯人权）、[[dragon_vein_trace]]（留痕即主权）、[[three_color_audit]]（三色审计）、[[data_sovereignty_in_user]]（数据主权在用户）。

## 第三章 · 自省机制（骂前必问三句）

1. **我贡献了什么？** → 没贡献，先干活再说话；有贡献，继续。
2. **我证据硬吗？** → 没证据，闭嘴去收集；有证据，继续。
3. **我自己做到了吗？** → 没做到，先骂自己；做到了，可以骂，但只骂事不骂人。

## 第四章 · 权重评估

社会贡献权重表（参考）：

| 贡献类型 | 权重值 | 说明 |
|:--------:|:------|:-----|
| 保家卫国 | ∞ | 无限权重，不可骂 |
| 救死扶伤 | 1000+ | 医护、消防、救灾 |
| 教书育人 | 500+ | 教师、导师 |
| 科研创新 | 500+ | 科学家、工程师 |
| 公共服务 | 100+ | 公务员、基层工作者 |
| 商业创造 | 50+ | 企业家、创业者 |
| 普通劳动 | 10+ | 工人、农民、打工人 |
| 零贡献 | 0 | 啃老、躺平、键盘侠 |

**规则**：
- 你的权重 < 对方权重 × 0.1 → 无权骂
- 你的权重 ≥ 对方权重 × 0.1 → 可以骂，但需证据
- 你的权重 > 对方权重 → 放开骂，但骂事不骂人

> 老大原话："靠权重的社会贡献……自己他妈什么都不是，斤斤计较的人，那骂也小心点，说不定把自己骂进去了。" 权重不是用来压人，是用来照镜子。

## 第五章 · 政治定义（细化）

**5.1 龍魂定义**：政治 = 为老百姓服务的规则体系。

**5.2 可骂的"政治"**（懒政 / 庸政 / 贪腐 / 形式主义 / 官僚主义 / 信息不透明）

**5.3 不可骂的"政治"**（国防战略 / 外交底线 / 救灾应急 / 历史定论 / 国家象征）

> 老大原话点破的真问题：有些人喊"科技共享、普惠全球"，执行层却搞闭门造车、窝里横、出门自知是垃圾不敢出门。龍魂系统自己要做到真开放——本地部署、DNA 追溯、免费开源，照出那些"不通用"的封闭。

## 第六章 · 自骂优先

**铁律**：骂别人前，先骂自己。

自骂清单：
- 我今天为老百姓做了什么？→ 否，先干活。
- 我占过便宜、逃过责任吗？→ 否，先认错。
- 我双标了吗？→ 否，先统一标准。
- 我被情绪带偏了吗？→ 否，先冷静。
- 我背后捅刀、当面跪舔了吗？→ 否，先做人。
