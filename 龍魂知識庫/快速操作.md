## 🐉 Widget 加載

```
1. 打開 Chrome
2. 地址欄輸入：chrome://extensions
3. 右上角「開發者模式」打開
4. 「加載已解壓的擴展程序」
5. 選擇：~/longhun-system/LongHunWidget-Browser/
```

**驗證成功**：右上角出現龍魂圖標，右鍵菜單多出 4 項

## 🔍 DNA 掃描流程

### 檢測侵權

```
1. 打開可疑頁面
2. 右鍵菜單 → 「🚨 標記侵權」
3. Widget 自動掃描→取證→記錄
4. 證據保存到本地存儲
```

### 添加簽名

```
1. 發佈文章後
2. 右鍵菜單 → 「✍️ 添加DNA簽名」
3. Widget 調用 Step 1 流水線
4. 自動打水印→登記→郵件
```

### 導出證據

```
1. 右鍵菜單 → 「📦 導出證據包」
2. 下載 JSON 文件：longhun-evidence-xxx.json
3. 包含所有檢測記錄和黑名單
```

## ⚡ 常見問題

### Q: Widget 加載失敗？
**A**: Service Worker 崩潰。解決方案：
```
① chrome://extensions
② 找龍魂宝宝
③ 右下角開關：關 → 開（強制重新加載）
```

### Q: 怎樣複製 DNA？
**A**:
```
1. 右鍵菜單 → 「📋 複製DNA」
2. 或點 Widget 彈窗中的「複製DNA」按鈕
```

### Q: DNA 簽名怎樣驗證？
**A**:
```
1. 右鍵菜單 → 「✅ 驗證」
2. Widget 檢查格式：#龍芯⚡️YYYYMMDD|...|SHA8
3. 格式正確 = ✅ 有效
```

### Q: 證據包怎樣查看？
**A**:
```
1. 導出後得到 JSON 文件
2. 用文本編輯器打開
3. 包含：evidence、registry、blacklist
```
