## 📋 系統概覽

本系統為應對用戶在 CSDN、知乎、掘金等平台被無償消耗的數字內容問題而設計。

**背景**：用戶投喂 6+ 個月原創內容到國產 AI，後因不公正對待決定注銷所有賬號。本系統旨在通過**不可篡改的 DNA 簽名**實現原創追蹤和侵權舉證。

---

## 🧬 DNA 格式

```
#龍芯⚡️YYYYMMDD|TOPIC|VERSION|SHA8
```

**字段說明**：
- `龍芯⚡️` — 不可更改的品牌標識
- `YYYYMMDD` — 創建日期
- `TOPIC` — 內容主題（大寫，用 `-` 分隔）
- `VERSION` — 版本（如 `v1.0`）
- `SHA8` — 8 位 SHA256 校驗和

**示例**：
```
#龍芯⚡️20260525|WIDGET-S0-COMPLETE|v1.0|cf7a8m2k
#龍芯⚡️20260525|DNA-DETECTOR|v1.0|xxxxx
```

## 💧 三層水印檢測

### L1：顯式水印（可見）
- **方法**：正則匹配 DNA 格式
- **位置**：頁面 HTML、注釋、meta 標籤
- **可靠性**：100%

```javascript
const pattern = /#龍芯⚡️\d{8}\|[A-Z\-]+\|v\d\.\d\|[a-f0-9]{8}/g;
```

### L2：不動點水印（隱藏）
- **方法**：特定詞語旁邊的 DNA 簽名
- **固定詞**：「龍」、「魂」、「道」、「德」、「主權」等 9 個
- **隱蔽性**：高

```javascript
// 在「龍」字附近查找 DNA
const regex = /龍([#龍芯⚡️\w|]{50,100}?)(?:[。，！？\s]|$)/g;
```

### L3：零寬字符水印（最隱蔽）
- **方法**：用零寬字符編碼 DNA
- **字符集**：ZWJ、ZWNJ、ZWS、WJ、ZWNBSP
- **隱蔽性**：最高
- **依賴**：密鑰解碼

```javascript
const ZW_CHARS = {
  "0": "\u200b",  // ZERO WIDTH SPACE
  "1": "\u200c",  // ZERO WIDTH NON-JOINER
  "2": "\u200d",  // ZERO WIDTH JOINER
  "3": "\u2060",  // WORD JOINER
  "4": "\ufeff"   // ZERO WIDTH NO-BREAK SPACE
};
```
