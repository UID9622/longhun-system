## 🎯 使用技巧

### 全局搜索

在 Obsidian 中：
```
Cmd+Shift+F (Mac) 或 Ctrl+Shift+F (Windows)

搜索詞：
- DNA → 所有 DNA 相關文檔
- Widget → 所有 Widget 文檔
- 流水線 → 自動化工具
- 證據 → 侵權記錄
```

### 快速跳轉

點擊方括號 `[[文檔名]]` 即可跳轉

### 標籤查詢

點擊任何 `#標籤` 查看相同主題的文檔
