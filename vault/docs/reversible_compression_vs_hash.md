# 可逆压缩 vs 哈希（SHA-256）

> DNA：#龍芯⚡️20260618191400-REVERSIBLE-VS-HASH

## 一句话区分

| | SHA-256 | 龍魂 DNA 压缩 |
|---|---|---|
| **方向** | 单向 | 双向 |
| **能否恢复原文** | ❌ 不能 | ✅ 能 |
| **本质** | 哈希 / 数字指纹 | 可逆压缩 + 可选加密 |
| **用途** | 校验完整性、防篡改 | 摘要展示 + 原文还原 |
| **安全依赖** | 抗碰撞性（数学上无法反推） | 密钥保密 + 压缩字典/算法 |

## 类比

- **SHA-256**：把文件烧成灰。你能确认“这把灰是这份文件烧出来的”，但无法把灰还原成文件。
- **DNA 压缩**：把文件压成 zip 包，再加一把锁。有钥匙（密钥/字典）就能完整解压出原文。

## 在龍魂系统里的应用

1. **DNA 追溯码**：不是 hash，是可解析的元数据签名。包含时间、操作类型、节点、版本等信息，可还原审计路径。
2. **记忆摘要**：把长文本压缩成“记忆胶囊”，需要时可由授权节点恢复原文。
3. **Vault 加密**：用 age 公钥加密后的 `.age` 文件是“可逆 + 加密”的，私钥持有者能完整恢复原文。

## 为什么普通人需要这个？

因为普通人看不懂 SHA-256 的一串十六进制，但能看懂：

- 当前卦象：坎☵
- 数字根：dr=4 🟢
- 三色状态：绿色通行
- 最近事件：清理缓存、清空回收站

这就是“把很多字压成几个摘要，还能复原原文”的价值：**让人安心，让机器可审计**。
