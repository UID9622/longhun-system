# 龍魂支付系统 · 一键启动
# 最简单的方案 - 只需3步

---

## 🚀 第1步：安装启动别名（只需一次）

```bash
# 复制这个命令到你的终端，然后按 Enter
bash /mnt/user-data/outputs/setup_longhun_alias.sh
```

**这会：**
- ✅ 创建快捷命令别名
- ✅ 配置你的Shell环境
- ✅ 自动重新加载配置

---

## 💡 第2步：启动龍魂系统（之后就只需要这一个命令）

```bash
# 只需要输入这一个单词，然后按 Enter
longhun
```

**或者使用缩写:**
```bash
lh
```

---

## 📋 第3步：选择你要做什么

菜单会出现，显示所有选项：

```
🐉 龍魂支付系统 · 启动菜单

请选择启动模式 (输入数字 1-8，然后按 Enter):

  【演示和测试】
    1) 🎬 演示模式          - 快速5秒演示，看系统运行
    2) 🧪 自动化焊接        - 创建7笔测试交易，生成DNA
    3) 📊 系统统计          - 查看交易数、金额、费用

  【交互操作】
    4) 💻 CLI命令行工具     - 手动创建交易、查询、导出
    5) 🌐 API服务器        - 启动Flask API (localhost:8888)
    6) 📜 启动脚本菜单      - 完整的交互式菜单

  【维护和日志】
    7) 📋 查看日志          - 实时监控系统日志
    8) 🔧 系统健康检查      - 检查数据库、文件、权限

  【其他】
    0) 🚪 退出              - 关闭菜单
```

**只需输入数字（1-8）按 Enter 就行。**

---

## 🎯 常用快捷命令

安装完别名以后，你可以随时使用这些：

```bash
# 启动主菜单
longhun

# 或者用缩写
lh

# 快速演示
lh-demo

# 启动API服务器
lh-api

# CLI交互工具
lh-cli

# 查看日志
lh-logs

# 查看统计
lh-stats
```

## ✅ 完整流程（从零开始）

### 你的第一次：

```bash
# 1️⃣ 安装别名（只需一次）
bash /mnt/user-data/outputs/setup_longhun_alias.sh

# 2️⃣ 启动菜单
longhun

# 3️⃣ 选择 "1" 看演示
# （按 Enter，等待5秒看演示）

# 4️⃣ 菜单自动返回，选择 "2" 自动焊接
# （按 Enter，等待自动创建7笔交易）

# 5️⃣ 选择 "3" 查看统计
# （看交易成功了没有）

# 6️⃣ 选择 "0" 退出
# （告别龍魂，但龍魂会记得你）
```
