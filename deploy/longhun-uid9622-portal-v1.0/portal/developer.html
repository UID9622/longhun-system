🔌 API 参考

龍魂系统提供 RESTful API 和 MCP (Model Context Protocol) 接口。

DNA 验证 API

POST /api/dna/verify 验证 DNA 追溯码 
curl -X POST http://localhost:7000/api/dna/verify \
  -H "Content-Type: application/json" \
  -d '{
    "dna": "#龍芯⚡️2026-...",
    "confirm": "#CONFIRM🌌9622-..."
  }'

三色审计 API

POST /api/audit/evaluate 提交行为进行审计评估 
curl -X POST http://localhost:9627/api/audit/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "action": "data_export",
    "context": { "user": "uid123", "target": "cloud" },
    "factors": [0.8, 0.3, 0.9, 0.2, 0.7, 0.5, 0.6]
  }'

返回: {"result": "🟡", "score": 0.57, "details": [...]}

系统健康 API

GET /health 系统健康状态 
curl http://localhost:9627/health

MCP Server 配置

让 AI 直接调用 CNSH 工具：

{
  "mcpServers": {
    "cnsh-syntax": {
      "command": "python3",
      "args": ["integrations/mcp/cnsh_syntax_mcp_server.py"],
      "env": { "PYTHONPATH": "/path/to/longhun-system" }
    }
  }
}

📦 SDK

Python SDK

from longhun import DNA, Audit, Persona

# 创建 DNA 锚定
dna = DNA.create(user="uid123")
print(dna.verify())  # True

# 三色审计
result = Audit.evaluate(action="export", context={})
print(result.status)  # 🟢 🟡 🔴

JavaScript SDK

import { DNA, Audit } from '@longhun/sdk';

const dna = DNA.create({ user: 'uid123' });
await dna.verify();
