## 网络拓扑（三层隔离）

```text
公网 (Internet)
   │ HTTPS/TLS 1.3
   ▼
[WAF 防火墙] → [CDN 加速·国内用阿里/华为CDN]
   │
   ▼
[API 网关 :9000] ← 唯一公网入口
   │ 内部网络（10.0.0.0/16）
   ├──→ [搜索服务 :8890]
   ├──→ [依赖隔离适配器 :5001]
   ├──→ [计量服务 :8897]
   └──→ [数据库 :5432] ← 绝不暴露公网
```

## 网络安全规则
- 入站：只开放 443(HTTPS) 和 22(SSH·限IP)
- 出站：只允许到国内已知服务（白名单）
- 内部：服务间通过内网域名通信，不走公网
