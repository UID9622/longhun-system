## 部署层级（三层）

### Layer 1：本地开发（零费用）
- Docker Compose 本地运行
- SQLite 本地数据库
- 无需任何云账号
- 适用：个人开发者·测试·学习

### Layer 2：单机云服务器（低费用）
- 华为云 ECS s6.small.1（约0.1元/小时 = 72元/月）
- 按量计费·不用即停·不产生费用
- 适用：小型项目·个人博客·小团队

### Layer 3：Kubernetes 集群（按需扩展）
- 华为云 CCE / 阿里云 ACK
- 自动扩缩容·只为实际流量付费
- 适用：中大型项目

## 容器化标准
- 所有服务必须容器化（Docker）
- 镜像必须使用多阶段构建（减小体积）
- 基础镜像优先：alpine > slim > 标准版
- 镜像仓库：华为 SWR（境内） / Docker Hub（境外）

## 存储选型（国产优先）
| 场景 | 推荐 | 备用 |
|---|---|---|
| 对象存储 | 华为 OBS | 阿里 OSS |
| 数据库 | PostgreSQL（自建） | MySQL（自建） |
| 缓存 | Redis（自建） | Memcached |
| 搜索 | SearXNG（自建） | MeiliSearch |
| 消息队列 | RabbitMQ（自建） | Kafka |
