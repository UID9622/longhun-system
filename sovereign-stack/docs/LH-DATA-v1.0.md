## 数据主权原则
> 你的数据属于你。平台只是工具，数据不是筹码。

## 数据分级
| 级别 | 说明 | 存储位置 | 加密要求 |
|---|---|---|---|
| L0 公开 | 可对外发布的内容 | 任意 | 无 |
| L1 内部 | 工作数据·非敏感 | 国内服务器 | 传输加密 |
| L2 私密 | 个人信息·账号凭证 | 仅本地 | 存储+传输双加密 |
| L3 绝密 | 密钥·签名私钥·DNA根 | 本地离线 | 物理隔离 |

## 数据主权七律
1. **可导出**：任何时候可以把自己的数据完整导出（JSON/CSV/原始格式）
2. **可删除**：提出删除请求后72小时内完全清除
3. **可迁移**：导出格式兼容主流平台，不锁定
4. **可审计**：每次数据访问都有 DNA 追溯码
5. **不出境**：L2/L3 数据不离开中国境内服务器
6. **不共享**：未经明确授权不分享给第三方
7. **不训练**：你的数据不用于训练任何 AI 模型

## 数据生命周期

```text
创建 → DNA标记 → 分级存储 → 访问审计 → 定期备份 → 到期归档 → 安全删除
  ↑                                                              ↓
  └──────────────────── 可随时导出/迁移 ──────────────────────────┘
```

## 个人数据保护（对标 GDPR + 中国个人信息保护法）
- 收集最小化：只收集业务必需的数据
- 目的明确：告知用户每类数据的用途
- 存储限期：超出必要期限自动删除
- 安全保障：AES-256 加密 + 访问控制
