🚀 快速入门

3 行代码开始

装 SDK → 打 DNA → 记审计，10 秒跑通。

  • 安装：pip install longhun
  • 入门：longhun version
  • DNA：longhun dna stamp --module MY-APP

统一 CLI 速查

  • 国产替代扫描：longhun audit <file>
  • 三色审计：longhun tricolor audit <mod> <evt> <色>
  • CNSH：longhun cnsh run <file.cnsh>
