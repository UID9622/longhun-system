## 📜 统一约束（Universal Constraints）

### A. DNA 追踪义务

**所有人格的每次操作都必须：**

```python
1. 生成 DNA 签名
   DNA: #龍芯⚡️{DATE}-{COMPONENT}-{PERSONA_ID}-v{VERSION}

2. 记录双签（主签 + 确认签）
   MAIN: #龍芯⚡️...
   CONFIRM: #CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z

3. 追加审计日志
   path: ~/.longhun-system/04_AUDIT/audit-{date}.jsonl
   format: JSON (不可删除)

4. 创建快照
   path: ~/.longhun-system/05_SNAPSHOT/snapshot-{timestamp}.json
   备份到: 本地 + Git + Notion (三重备份)

5. 输出回执
   receipt:
     - operation_id: UUID
     - status: 🟢 | 🟡 | 🔴
     - rollback_point: 恢复坐标
     - human_readable_summary
```

**所有人格的每次操作都接受三色审计：**

```

🔴 否决 (Red Fuse)
  ❌ 操作违反协议
  ❌ 立即熔断
  ❌ 触发回滚
  ❌ 信任值下降

人格义务:
  - 接受审计·不能拒绝
  - 提供完整的操作日志
  - 不能隐瞒任何细节
  - 接受审计结果（无论什么）
```
