# 双轨模式与五条铁律

> 老大原话：「信任的基础止于沟通层面」

## 模式 A · 公开咨询

- 谁都可用 · **无 DNA**
- 输入 → CNSH 解释 → **公开原理**回答
- ✅ 哲学 / 五行 / 369 / 道德经 / 龍魂理念
- ❌ 代码 / 部署脚本 / 商务方案 / 协议焊接

## 模式 B · 主权操作

- 仅 **DNA 三验** 后主控本人
- ✅ 代码 / 部署 / 协议焊接 / 商业规划
- 目的：**锁人不锁账号**（多账号、开源包都绕不过三验）

## 五条铁律（工程化）

1. **公开原理不藏** — 五行/369/道德经/龍魂哲学 · 任何人可问 · AI 不许以「保护」拒答原理  
2. **代码不公开放** — 实现/部署/焊接 · 仅 DNA 后输出 · 理由是身份锁不是 IP  
3. **锁人不锁账号** — 无 DNA 一律公开层 · 开源拿到代码也无主权出码权  
4. **三验 = 身份证** — GPG+CONFIRM+SEAL = 标记「这是这个人」· 不是产权主张  
5. **误解归零 · 不防御不定罪** — 减少误解 · 误读走公开原理澄清 · 不靠隐藏机制防御  

## 代码入口

`core/mode_router.ts` → `routeMode(input, sig?)` → `'public' | 'sovereign'`
