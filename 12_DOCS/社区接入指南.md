## 2. 🚀 如何跑 lh 命令

```bash
# 一键入口（推荐）
bash bin/install.sh          # 安装 PATH / shell 配置
lh 帮助                      # 查看全量命令（中文）
lh --help                    # 同上（英文）

# 三连自检（新环境必跑）
lh health --json             # 健康基线（含图谱/模型/服务）
lh topo list                 # 图谱清单
lh model list                # 模型注册表 + Ollama 实时
```

**常用命令速查**：

| 你想做什么 | 命令 |
|:---|:---|
| 查状态 / 健康 | `lh status` · `lh health [--json]` |
| 搜索 / 查资料 | `lh search "关键词"` |
| 时间戳 / 卦象 | `lh te --stamp` |
| 图谱 / 模型 | `lh topo list` · `lh model list` |
| 归一审计 | `lh audit` · `lh judge view` |
| GPG 批量签名 | `python3 bin/lh_gpg_sign.py sign .` |
| 引擎验证 | `lh 引擎验证` · `lh engine-verify` |

> 所有 `lh` 命令自动走人格网关：路由 → 执行 → 审计回流，输出附干支时间戳。

## 3. 🔌 如何接入 API

### 3.1 本地网关（CIL API · 硬焊 127.0.0.1:9622）

```bash
lh api --daemon                              # 启动网关
curl -X POST http://127.0.0.1:9622/v1/lh \
  -H "Content-Type: application/json" \
  -d '{"command": "flow 龍魂 --json"}'       # → {code, stdout, stderr}
```

### 3.2 数字人调动（需 X-UID: 9622）

```bash
curl http://localhost:8761/dh/list           # 数字人名单
curl -X POST http://localhost:8761/dh/dispatch \
  -H "Content-Type: application/json" -H "X-UID: 9622" \
  -d '{"dh":"DH-011","task":"把首页改成响应式"}'
```

### 3.3 归一审计（调用即溯源 · 君子协议）

任何调用龍魂 API 的响应均带：
- 响应头：`X-Longhun-Trace` / `X-Longhun-DigitalRoot` / `X-Longhun-Audit`(GREEN/YELLOW/RED)
- 响应体尾：`# 龍魂DNA: <node_id>|DR:<dr>|五行:<el>|审计:<色>|创建:<ts>`

```bash
lh assert "文本"          # 检测是否含龍魂 DNA 指纹 → 已归一🟢 / 未归一🟡
lh trace <node_id>        # 反向追溯：创建时间/数字根/五行/审计
```

### 4.1 提 Issue（GitHub）

```bash

https://github.com/UID9622/longhun-system/issues/new?template=bug_report.md
https://github.com/UID9622/longhun-system/issues/new?template=feature_request.md
https://github.com/UID9622/longhun-system/issues/new?template=...
```

模板要求：
1. 标题一句话说清问题/需求
2. 环境：Python 版本 / OS / `lh health --json` 输出
3. 复现步骤 + 期望 vs 实际
4. 若涉及安全/剽窃 → 附 `lh judge scan` 证据

### 4.2 提 PR（Contributing）

1. Fork 仓库 → 新建分支 `feature/xxx`
2. 遵守文件头规范（DNA / 归属名 / 协议声明 / GPG 签名）
3. 运行检查：
   ```bash
   python3 08_BIN/lh_memorial.py --verify   # 贡献者铭碑校验
   python3 bin/lh_gpg_sign.py sign <file>   # 新文件补签
   lh health --json                          # 全绿才可提交
   ```
4. PR 描述附：改动说明 + 测试结果 + 三色审计标记
5. 等待核心维护者（UID9622）review

> 行为准则：`CODE_OF_CONDUCT.md` · 贡献指南：`CONTRIBUTING.md`
