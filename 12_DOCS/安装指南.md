# 🐉 longhun-cli 安装指南

> 配套: `longhun-cli 4.0.0` · 快速上手见 `docs/快速开始.md` · 协议见 `docs/对外接口协议-v1.0.md`

## 环境要求

| 项 | 要求 |
|:---|:---|
| Python | ≥ 3.8（3.8 ~ 3.12 实测通过） |
| 操作系统 | macOS / Linux / Windows（纯 Python 标准库，跨平台） |
| 依赖 | **零依赖**（无任何第三方包） |
| 网络 | 仅安装时需要；运行全本地（数据不出设备） |

## 方式一 · pip 安装（推荐）

```bash
# 从 PyPI
pip install longhun-cli

# 指定版本
pip install longhun-cli==4.0.0

# 从本地构建产物（离线环境）
pip install dist/longhun_cli-4.0.0-py3-none-any.whl
```

> 国内镜像加速：`pip install longhun-cli -i https://mirrors.aliyun.com/pypi/simple/`

## 方式二 · 源码安装

```bash
# 克隆仓库
git clone https://github.com/UID9622/longhun-system.git
cd longhun-system/packaging/longhun_cli

# 开发模式安装（可编辑，适合二次开发）
pip install -e .

# 或构建后安装
pip install build
python -m build
pip install dist/longhun_cli-4.0.0-py3-none-any.whl
```

## 方式三 · Docker（可选）

```bash
# 基于 python:3.12-slim 构建
docker build -t longhun-cli:4.0.0 -f - . <<'EOF'
FROM python:3.12-slim
RUN pip install longhun-cli==4.0.0
ENTRYPOINT ["lh"]
CMD ["--help"]
EOF

# 运行
docker run --rm longhun-cli:4.0.0 version
docker run --rm longhun-cli:4.0.0 flow "龙魂对外首发" --json
```

## 方式四 · Docker 网关（完整网关容器 · 可选）

> 以容器方式运行龍魂 CIL API 网关（含 `POST /v1/lh` 与 `GET /health`），端口映射宿主机 9622，日志/PID 持久化到 `~/.longhun`。

```bash
# 1. 构建并启动（编排文件见 packaging/docker/docker-compose.yml）
cd longhun-system/packaging/docker
docker compose up -d --build

# 2. 查看状态
docker compose ps
# NAME               STATUS   PORTS
# longhun-gateway    Up       0.0.0.0:9622->9622/tcp

# 3. 健康检查（compose 内置 healthcheck 也会自检）
curl -s http://localhost:9622/health
# {"status":"ok","version":"v4.0","uptime":"..."}

# 4. 调用网关
curl -s -X POST http://localhost:9622/v1/lh \
  -H "Content-Type: application/json" \
  -d '{"command":"flow 龙魂对外首发 --json"}'

# 5. 停止
docker compose down
```

**说明**：
- 镜像基于 `python:3.12-slim`，复制 `bin/ 08_BIN/ packaging/ docs/` 到 `/app`，容器内 `LONGHUN_ROOT=/app`
- `~/.longhun`（日志 `logs/gateway.log` · PID `gateway.pid`）挂载持久化，容器重建不丢
- 容器内**不要**加 `--daemon`（双 fork 会让容器主进程退出）；宿主机裸跑才用 `lh api --daemon`
- 完整龍魂系统功能（模型/训练/门户等）建议宿主机或鲲鹏运行，容器只承载网关核心命令
- 换端口：修改 compose 的 `ports: "9623:9622"` 后 `docker compose up -d`

## 双态说明

| 状态 | 触发条件 | 可用能力 |
|:---|:---|:---|
| 外部态 | 未设 `LONGHUN_ROOT` | `version` / `health`(基础) / `flow` / `bazi` |
| 系统态 | `export LONGHUN_ROOT=~/longhun-system` | 上述全部 + `health`(全量15项) / `cil` / `doc-sync` |

```bash
# 进入系统态
export LONGHUN_ROOT=~/longhun-system
lh health --json   # 自动透传系统内全量健康检查
```

## 常见问题

| 问题 | 解决 |
|:---|:---|
| `lh: command not found` | 确认安装目录在 PATH：`python3 -m pip install longhun-cli` 后检查 `pip show -f longhun-cli` 的 bin 路径 |
| 安装慢/超时 | 换国内镜像（见方式一）；或直接下载 whl 本地安装 |
| `LONGHUN_ROOT` 无效 | 路径需指向含 `bin/lh.py` 的龍魂源码树；无效时自动回退外部态（不报错） |
| Windows 中文乱码 | 终端设置 UTF-8：`chcp 65001` |
| 想卸载 | `pip uninstall longhun-cli` |
