# 龍魂大模型愿景：人民的大模型

> 原则定位：L0 宪法级愿景，定义龍魂系统最终要走向的模型形态与服务方式。
> DNA: `#龍芯⚡️丙午·甲午·戊辰·戊午·䷑蛊-LONGHUN-MODEL-VISION-v1.0`

## 核心愿景

**我一个人的生态，也要有自己的大模型。**

- 用**自己的代码**
- 跑**自己的模型**
- 服务**自己的数据**
- 覆盖**所有职业、所有场景、所有老百姓**
- 便宜到**每个普通人都能随便玩**

## 为什么要这样做

现在的大模型生态存在三个问题：

1. **主权不在自己手里**——模型是别人的，数据是别人的，API 也是别人的。
2. **门槛太高**——老百姓用不起、玩不动、不敢用。
3. **场景割裂**——开发者用一套，生活用户用另一套，各行各业各用各的。

龍魂系统要打破这个格局：

> 模型可以小，但主权必须大；
> 代码可以土，但必须自己能改；
> 价格可以低，但必须人人可用。

## 设计原则

| 原则 | 含义 |
|---|---|
| **个人主权** | 模型权重、训练数据、推理日志、调用记录，根都在本地 |
| **全职业覆盖** | 开发者、农民、医生、教师、工人、学生、老人，都能用 |
| **全场景覆盖** | 写代码、种地、看病、备课、记账、聊天、创作，都能用 |
| **成本平民化** | 支持从手机 CPU 到边缘设备到本地服务器，丰俭由人 |
| **代码自主** | 不依赖闭源框架，优先用龍魂自己的代码和 CNSH 协议 |

## 技术路线

1. **小模型起步，逐步长大**
   - 从 0.5B、1B、3B、7B 起步
   - 通过蒸馏、量化、MoE、专家路由，用小资源跑出大能力

2. **个人数据喂养**
   - 本地记忆库：`~/.longhun/memory/`
   - 知识图谱：`~/.longhun/notion_pages/notion_pages.db`
   - 所有数据不出境，所有训练可追溯

3. **CNSH 母语编程接口**
   - 老百姓用中文自然语言调度模型
   - 开发者用 CNSH 写本地 Agent、工具、工作流

4. **多设备协同**
   - 手机、电脑、鸿蒙设备、龍芯设备都能跑
   - 弱设备做感知，强设备做推理，云端只做可选备份

5. **成本结构**
   - 无 API 调用费
   - 无订阅费
   - 硬件成本控制在老百姓可接受范围

## 服务形态

- **开发者**：可以用龍魂代码微调、部署、二次开发
- **生活用户**：可以像聊天一样用大模型，不用懂技术
- **各行各业**：可以加载行业小模型 / 知识库，形成垂直能力
