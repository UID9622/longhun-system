## 1. 数字根算法 DR(x)

**输入**: $x \in \{\text{str}, \text{int}, \text{float}\}$ —— 任意文本/数字/对象
**输出**: $dr \in \{0,1,\dots,9\}$ —— 数字根

### 公式
提取文本中所有数字位 $d_1,\dots,d_n$（含 Unicode 数字），迭代求和至个位：

$$DR(x) = \begin{cases} 0 & \text{无数字位} \\ s_k & s_0 = \sum_{i=1}^n d_i,\;\; s_{k+1} = \text{sum\_digits}(s_k),\;\; s_k \le 9 \end{cases}$$

### 伪代码
```
1. digits = [int(c) for c in str(x) if c.isdigit()]   # 含 unicodedata.digit
2. if not digits: return 0
3. s = sum(digits)
4. while s > 9: s = sum(int(c) for c in str(s))
5. return s
```

### 校验
- 空文本 → 0（边界）
- Unicode 数字（①②③）→ `unicodedata.digit()` 归一
- 负号/小数点不参与求和

### 可计算性
$O(n)$ 一次扫描 + $\le 19$ 次迭代（int 上限 10^19 各位和 ≤ 171），**确定性**、无随机分支。

### 示例
$DR(9622) = 9+6+2+2 = 19 \to 1+9 = 10 \to 1$ → **1**（水）

## 4. 五行强度权重计分 W

**输入**: 四柱 $P = \{\text{年,月,日,时}\}$，每柱天干/地支
**输出**: $W \in \mathbb{R}^+$ 五行强度分

### 公式
$$W = \sum_{c \in P} w_{\text{干},c} \cdot v_{\text{干},c} + w_{\text{支},c} \cdot v_{\text{支},c}$$

| 年 | 1.0 | 0.8 |

| 日 | 2.0 | 1.6 |
| 时 | 1.2 | 1.0 |

### 可计算性
$O(4)$ 固定四柱线性求和，确定性。

## 6. 均衡指数 E

**输入**: 观测值序列 $X = \{x_1,\dots,x_n\}$
**输出**: $E \in (-\infty, 1]$

### 公式
$$E = 1 - \frac{\sigma}{\mu},\quad \mu = \frac{1}{n}\sum x_i,\quad \sigma = \sqrt{\frac{1}{n}\sum (x_i-\mu)^2}$$

### 校验
$\mu = 0 \Rightarrow E = 1$（防御除零）；$\sigma > \mu \Rightarrow E < 0$（允许负值，代表失衡）

### 可计算性
$O(n)$ 两次遍历（均值→方差），确定性。

## 8. 剽窃置信度 C（lh_judge）

**输入**: 指纹集合 $F = \{f_1,\dots,f_n\}$，每指纹权重 $w_i$

## 10. 指纹匹配算法（lh_judge）

**输入**: 文本 $x$；**输出**: 指纹集合 $F$

### 公式
$$F = \bigcup_{p \in \mathcal{P}} \{ \text{type}(p) : \text{pattern}_p \text{ matches } x \}$$

模式集 $\mathcal{P}$（正则/关键词）:
- DNA: `#龍芯⚡️[0-9]{4}-[0-9]{2}-[0-9]{2}-[^\s]+`
- 节点: `(FLOW|BAZI|HEALTH|...)-9622-[0-9A-F]{8}`
- 品牌词: 词表包含（v1.1 多义降权 0.4）
- API 端点: URL 匹配 `9622|longhun|uid9622|lhun`（忽略大小写）

### 可计算性
$O(|x| \cdot |\mathcal{P}|)$ 正则线性扫描，确定性。

## 14. 年干支 G(y)

### 公式
$$G(y) = \text{天干}[(y-4) \bmod 10] + \text{地支}[(y-4) \bmod 12]$$

基准: 公元 4 年 = 甲子年。

### 示例
$y=2026$: 干 = (2022 mod 10)=2 → 丙；支 = (2022 mod 12)=6 → 午 → **丙午**

### 可计算性
$O(1)$，确定性。

## 16. 日干支（序数公式）D(y, m, d)
