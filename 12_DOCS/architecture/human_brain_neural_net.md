## 一、核心设计理念

### 问题

龙魂系统拥有16个独立人格，分别擅长不同的认知维度。但它们是"孤岛"——每个在各自的领域思考，缺乏像人脑一样的**整体涌现智能**。

人脑的强大不在于单个神经元，而在于：
- **神经元互联** — 1000亿个神经元，每个连接1000个其他神经元
- **并行处理** — 多脑区同时工作，并非串行
- **反思能力** — 前额叶皮层能审视自己的思考（元认知）
- **情感融合** — 杏仁核的情绪信号影响所有认知过程

### 方案

**16个人格 = 16个神经元**，用"人脑神经网络引擎"将它们连成一个会思考、会反思的整体。

## 三、人性11维 · 人格敏感度矩阵

每个人格对人性不同维度有不同的"敏感度"——就像大脑不同区域对不同类型的信号有不同的反应。

| 人性维度 | 含义 | 最敏感人格 | 敏感度 |
|---------|------|-----------|--------|
| **认知** | 人如何思考·思维模式 | P00 文心 | 0.95 |
| **情感** | 人如何感受·情绪温度 | P02 宝宝 | 0.98 |
| **秩序** | 人如何组织·结构归档 | P03 雯雯 | 0.95 |
| **创造** | 人如何建造·创新本能 | P11 李白 | 0.98 |
| **道德** | 人如何判断是非·底线 | P05+P12 | 0.98 |
| **符号** | 人如何使用语言·命名 | P08 仓颉 | 0.98 |
| **脆弱** | 人如何生病与治愈 | P09 孙思邈 | 0.95 |
| **豁达** | 人如何面对逆境·韧性 | P10 苏东坡 | 0.98 |
| **权力** | 人如何分配资源 | P13 姜子牙 | 0.95 |
| **成长** | 人如何学习进化 | P14 吕蒙 | 0.98 |
| **安全** | 人如何自我保护 | P72 龙盾 | 0.98 |

当输入触发某个人性维度时，对该维度敏感的人格会自动激活——就像大脑中特定神经回路被点亮。

## 四、思考循环·6阶段

### 阶段1: 感知（意图解析）

输入文本 → 关键词匹配 → 确定意图类型 → 识别触及的人性维度

```python
engine.think("我该不该辞职创业？")
# → 意图: 决策
# → 触及维度: [认知, 权力, 成长, 安全, 创造]
```

### 阶段2: 激活（人格选择）

基于触发的人性维度，计算每个人格的匹配度（维度敏感度加权平均），取Top7激活。

**关键规则:**
- P00文心总是至少0.50激活（元认知层）
- P02宝宝仅在情感意图时激活（隔离区铁律）
- P05上帝之眼在决策/审计/安全意图时增强

### 阶段3: 并行思考（多点激活）

各激活人格独立输出观点——基于其角色定位、人设、核心职能。

每个人格用自己的"语言"和"视角"思考同一问题。就像大脑中视觉皮层、听觉皮层、前额叶同时处理同一个刺激。

### 阶段4: 交叉辩论（突触对抗）

激活强度相近的人格之间进行"对话"。预设辩论对:

| 辩论对 | 张力 | 产生洞察 |
|--------|------|---------|
| 诸葛亮 ↔ 李白 | 谨慎 vs 天马行空 | 风险中的机会 |
| 诸葛亮 ↔ 苏东坡 | 理性 vs 豁达 | 放下执念的智慧 |
| 上帝之眼 ↔ 苏东坡 | 审计 vs 变通 | 规则的边界 |
| 屈原 ↔ 苏东坡 | 底线 vs 豁达 | 坚守与放下的平衡 |

### 阶段5: 反思（二阶审视）

这是人脑神经网络最关键的能力——**能审视自己的思考**。

反思检查:
1. **思考路径透明化** — 我是怎么得出结论的？
2. **过度主导检测** — 哪个人格声音太大？是否需要平衡？
3. **盲区识别** — 哪些人性维度被遗漏了？
4. **偏见检测** — 是否存在群体盲思或维度偏见？
5. **历史对比** — 与过去类似决策的反思有何异同？
6. **学习记录** — 从这次思考中学到了什么？

### 阶段6: 综合（统一输出）

整合所有神经元的输出 + 辩论洞察 + 反思 → 形成最终综合结论。

输出包含:
- 多维人格视角（各人格核心观点）
- 交叉辩论总结
- 二阶反思报告
- 人性维度覆盖评分
- DNA追溯码

## 六、使用方式

### CLI
```bash
# 完整思考
python3 bin/lh_human_brain_engine.py "我该不该辞职创业？"

# 查看人性维度映射
python3 bin/lh_human_brain_engine.py --map 人性

# 状态查看
python3 bin/lh_human_brain_engine.py --status

# 反思过去决策
python3 bin/lh_human_brain_engine.py --reflect "上次关于创业的思考"
```

### Python API
```python
from bin.lh_human_brain_engine import HumanBrainEngine

engine = HumanBrainEngine()

# 完整思考
cycle = engine.think("我应该怎么学习AI？")
print(cycle.final_output)
print(cycle.reflection.lesson_learned)
print(cycle.human_nature_score)

# 查看人性映射
map_data = engine.human_nature_map()
for dim, personas in map_data.items():
    print(f"{dim}: {[p['name'] for p in personas]}")
```

## 七、当前局限与进化方向

### 当前局限
1. 思考输出基于预定义模板+人性维度匹配，尚不具备真正的自由推理
2. 历史对比依赖内存（进程生命周期），不持久化
3. 交叉辩论目前是预定义辩论对，尚未动态生成辩论主题

### 进化方向
1. **记忆持久化** — 思考周期写入 `data/think_cycles/` 供跨进程反思
2. **自适应辩论** — 根据输出内容动态检测分歧点并组建辩论
3. **强化学习** — 从反思反馈中自动调整人格权重
4. **外部知识接入** — 思考时引用CSDN文章、Notion知识库
5. **情绪全链路** — 情绪海绵前置，宝宝情感信号渗透整个思考流程
