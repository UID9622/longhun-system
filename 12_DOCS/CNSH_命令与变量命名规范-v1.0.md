## 第一章：命令命名规范

### 1.1 命令前缀：`lh6` 与 `lh` 的关系

| 前缀 | 语义 | 适用场景 | 示例 |
|------|------|---------|------|
| `lh6` | 龍魂 v6 正式入口（完整版） | 开发/运维/管理 | `lh6 editor` / `lh6 fuse status` |
| `lh` | 龍魂通用别名（快捷版） | 用户快捷命令 | `lh 编辑器` / `lh 熔断` |

**铁律：**
- `lh` 是 `lh6` 的别名，指向同一个 bash 脚本
- `lh6` 支持完整英文+中文命令
- `lh` 优先匹配中文命令（从命令注册表查找），找不到时回退到 `lh6` 的路由

### 1.2 命令参数风格（强制统一）

**一律使用 GNU 风格：`--long-option`（双横线长选项）**

```
✅ 正确：
   lh6 audit-vars --detail        # 详细模式
   lh6 audit-vars --json          # JSON输出
   lh6 fuse block x.com --level SOFT --protocol ssh
   lh6 fuse override x.com --duration 1h

❌ 禁止：
   lh6 audit-vars -detail         # 单横线+长选项→混用
   lh6 fuse block x.com -level SOFT   # 同上
```

**短选项别名（可选）：**
```
--detail  →  -d
--json    →  -j
--level   →  -l
--duration→  -t
--help    →  -h
```

### 1.3 命令命名三原则

1. **中文命令（主）**：面向中国用户，直觉匹配 → `lh 编辑器` / `lh 熔断`
2. **英文命令（辅）**：技术兼容 + 国际惯例 → `lh6 editor` / `lh6 fuse`
3. **别名收束**：一个命令最多 3 个别名，再多就得砍 → 例如 `audit-vars` = `av` = `var-audit`

### 1.4 命令分类（八卦对齐）

| 卦象 | 分类 | 颜色 | 典型命令 |
|------|------|------|---------|
| ☰ 乾 | 启动 | 金 | `lh6 start` / `lh6 symbiote` |
| ☷ 坤 | 部署 | 土 | `lh6 validate plist` / `lh6 install-autostart` |

## 第二章：变量命名规范

### 2.1 命名空间前缀体系（河图洛书五层）

```
河图中五 → 龍_    (L0 系统核心·不动点)
河图东三 → 引擎_  (L1 核心引擎·木)
河图西四 → 数据_  (L2 数据域·金)
河图南二 → 模块_  (L2 功能模块·火)
河图北一 → 辅助_  (L3 辅助模块·水)
```

| 前缀 | 层级 | 权重 | 五行 | 用途 | 示例 |
|------|------|------|------|------|------|
| `龍_` | L0 不动点 | 100 | 中土 | 系统核心常量·DNA·签章 | `龍_DNA头` / `龍_编辑器版本` |
| `引擎_` | L1 核心 | 80 | 木 | 核心引擎枚举/状态 | `引擎_审计颜色` / `引擎_检查级别` |
| `数据_` | L2 数据 | 60 | 金 | 数据定义·语言集·关键字 | `数据_支持语言集` / `数据_CNSH关键字集` |
| `模块_` | L2 模块 | 60 | 火 | 模块类引用 | `模块_DNA模板` / `模块_语法高亮` |
| `系统_` | L1 核心 | 80 | 土 | 系统级配置 | `系统_端口` / `系统_日志目录` |
| `用户_` | L2 用户域 | 60 | 水 | 用户偏好/状态 | `用户_主题` / `用户_语言` |
| `辅助_` | L3 辅助 | 40 | 水 | 工具函数/缓存 | `辅助_缓存目录` |
| `临时_` | L3 临时 | 40 | 火 | 运行时暂存 | `临时_当前文件` |

### 2.2 下划线规范（强制）

**必须使用半角下划线 `_` (U+005F)，禁止使用全角下划线 `＿` (U+FF3F)**

```
✅ 正确：
   龍_DNA头           # 半角下划线
   引擎_审计颜色        # 半角下划线
   数据_支持语言集      # 半角下划线

❌ 禁止：
   龍＿DNA头           # 全角下划线→编译错误
   引擎＿审计颜色        # 全角下划线→编译错误
```

**原因：** Python/C/JavaScript 等全部编程语言只识别半角下划线 `_` 作为标识符的一部分。全角下划线 `＿` 会导致语法错误。

### 2.3 命名风格选择

```
场景1：纯中文系统变量
   ✅  龍_DNA头         # 命名空间中文 + 变量名中文
   ✅  引擎_审计颜色      # 清晰直观

场景2：英文缩写（仅限业界通用）
   ✅  龍_DNA头         # DNA 是业界通用缩写
   ✅  数据_GPG指纹      # GPG 是业界通用
   ❌  龍_DNATrace      # 驼峰混用→禁止

场景3：枚举/类引用
   ✅  引擎_审计颜色 = AuditColor    # 左边中文，右边Python类名
   ✅  模块_DNA模板 = DNATemplate     # 同上
```

**规则：变量名中如混用英文，仅允许全大写的业界通用缩写（DNA/GPG/API/CPU/IO），禁止驼峰命名。**

### 2.4 作用域声明

每个 CNSH 变量必须在其定义处标注作用域：

```python
# 全局常量（L0）
龍_编辑器版本 = VERSION               # 全局·只读

# 模块级变量（L1）
引擎_审计颜色 = AuditColor              # 模块级·可导入

# 实例级变量（L2+）
self.编辑器_当前语言 = "Python"         # 实例级·带self
```

## 第三章：A/B 架构分层规范

### 3.1 A层（资源层）：系统"是什么"

| 层级 | 定义 | 文件示例 |
|------|------|---------|
| A1 | L0 系统常量（前向安全） | `龍_编辑器版本` / `龍_DNA头` |
| A2 | L1 核心枚举/基类 | `引擎_审计颜色` / `引擎_检查级别` |
| A3 | L2 数据定义 | `数据_支持语言集` / `数据_语法模式库` |
| A4 | L2 模块类/实例 | `模块_DNA模板` / `模块_多光标` |
| A5 | 编辑器运行时状态 | `self.lines` / `self.modified` |

### 3.2 B层（行为层）：系统"能做什么"

| 层级 | 定义 | 权限 | 命令示例 |
|------|------|------|---------|
| B1 | 系统命令（基础设施） | 管理员 | `lh6 status` / `lh6 registry` / `lh6 gate` |
| B2 | 服务命令（业务能力） | 用户 | `lh6 editor` / `lh6 kimi` / `lh6 memory` |
| B3 | 快捷命令（模块注册） | 用户 | `lh6 编辑器` / `lh6 熔断` / `lh6 M262` |
| B4 | 审计命令（质量保障） | 只读 | `lh6 audit-vars` / `lh6 dna-gen` / `lh6 签名` |

## 第四章：审计插件架构（B4层）

### 4.1 可插拔审计插件基类

所有 B4 审计命令必须继承 `AuditPlugin` 基类：

```python
class AuditPlugin(ABC):
    """审计插件基类"""
    name: str           # 插件名称
    version: str        # 版本号
    dna: str           # DNA追溯码
    level: str         # 审计级别: "L0"|"L1"|"L2"

    @abstractmethod
    def audit(self, target: Any) -> AuditResult:
        """执行审计，返回审计结果"""
        ...

    @abstractmethod
    def get_report(self) -> str:
        """生成审计报告"""
        ...
```

### 4.2 已注册审计插件

| 插件名 | 命令 | 级别 | 说明 |
|--------|------|------|------|
| `var-auditor` | `lh6 audit-vars` | L1 | CNSH编辑变量左右互搏审计 |
| `dna-verifier` | `lh6 gate` | L0 | DNA主权完整性验证 |
| `rights-guard` | `lh6 rights` | L0 | 人民权益守门人 |
| `fuse-auditor` | `lh6 fuse audit` | L1 | 熔断操作审计链 |

## 第五章：帮助系统规范

### 5.1 帮助输出格式

每个命令必须支持 `--help` 并输出以下结构：

```
命令名（英文别名）

  简短描述（一行中文）

用法:
  lh6 <命令> <子命令> [选项]

选项:
  --option1, -o    选项1说明（中文）
  --option2        选项2说明（中文）

示例:
  lh6 <命令> --option1 value

分类: ☰ 启动  |  权重: L1·80
```

### 5.2 中文帮助优先级

当用户执行 `lh 帮助` 或 `lh6 help --zh` 时，全部输出为中文。
当用户执行 `lh6 help --en` 时，输出为英文。
