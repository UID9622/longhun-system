## 🛠 三、使用手册（检测引擎四维闭环）

```bash
lh fraud status                          # 引擎状态（人格网关 P05 自动回流·带时间戳）
lh fraud scan 某文件或小目录 --报告 r.json  # 单文件/小范围扫描（⚠ 忌全库·每文件 gpg 子进程）
python3 bin/lh_anti_fraud_detector.py   # 14 维弯绕检测（文本）
python3 bin/lh_semantic_lie_detector.py # 10 维测谎（跨会话）
python3 bin/lh_ai_anti_hype.py          # 反忽悠
lh_gpg_sign.py sign <产出>              # 一切反诈产出双签名
```

**铁律**：反诈引擎只用于识别与守护；不作假、不反向生产骗术话术、不抹来源（战后整顿协议：禁写去水印/洗来源工具）。
