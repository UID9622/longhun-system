## 三、命令清单

| 命令 | 功能 | 引擎 |
|:---|:---|:---|
| `lh topo verify 通心译` | 审计 19 条资产 vs Notion 结构完整性（19/19 全绿） | `lh_topo.py` |
| `lh topo sync 通心译` | 直连 Notion 拉取全量资产并落盘缓存（自动刷新 last_sync） | `lh_topo.py` |
| `lh topo list` | 列出全部图谱与节点统计 | `lh_topo.py` |
| `lh topo kb-status` | 数字人知识库加载状态（已加载 19 条 / last_sync / 根哈希） | `lh_topo.py` |
| `lh topo serve --port 8762` | 独立 HTML 开放服务（默认 127.0.0.1·对外 `--host 0.0.0.0`） | `lh_topo.py` |
| `lh judge topo-scan [--deep]` | 通心译内容审计（描述级；`--deep` 正文级抓 README/model card） | `lh_judge.py` |
| `lh dh-api` / `lh dh "…"` | 数字人调动（系统提示自动注入 19 条资产知识库） | `lh_dh_dispatch.py` |
| `lh health --json` | 全局健康（`knowledge_graph` 含 `kb_loaded/kb_entries/kb_last_load`） | `lh_health.py` |

## 四、对外接口端点

**A. `lh api`（统一 API 网关，Header `X-UID:9622`）**

| 方法 | 路由 | 返回 |
|:---|:---|:---|
| GET | `/v1/topo` | 全部图谱索引 JSON |
| GET | `/v1/topo/通心译` | 19 节点树 JSON（groups + root_hash） |
| GET | `/v1/topo/通心译/html` | 人类可读 HTML 页（树形 19 节点·DNA·状态·主权声明·根哈希） |

**B. `lh topo serve`（8762 端口·零中间层·纯标准库 http.server）**

| 路径 | 返回 |
|:---|:---|
| `/` | 默认图谱 HTML 开放页 |
| `/topo/<图谱名>/html` | 指定图谱 HTML（中文路径自动解码） |
| `/topo/<图谱名>` | 指定图谱 JSON 树 |
| `/health` | 存活 JSON（status/entries/root_hash） |

> 页面包含：树形 6 层 19 节点 · 节点名称/ID/DNA/状态徽章 · 页脚主权声明（诸葛鑫｜UID9622）+ GPG + 根哈希。

## 五、知识库注入声明（数字人引用规范）

数字人（龍慧/字灵等）每次调用时，系统提示自动注入以下声明（verbatim）：

> **知识库**：你有权访问通心译总台 19 条资产（6 层，🟢11/🟡8），
> 资产名/层级/状态/DNA 已注入上下文。**引用时须注明 DNA**。
> 知识库状态实时同步自 `lh topo sync`（缓存 `docs/topology/`），
> 注入失败自动降级「知识库加载失败」，不影响对话主链路。

- 注入实现：`lh_dh_dispatch.py` `load_topo_kb()` → `build_system()`
- 状态落盘：`~/.longhun/dh_kb_state.json`（`lh topo kb-status` / `lh health --json` 读取）
