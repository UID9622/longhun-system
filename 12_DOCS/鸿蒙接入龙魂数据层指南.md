## 1. 一句话

HarmonyOS NEXT 应用通过 **ArkTS SDK** 只读访问鲲鹏 **8768 镜像端点**，对 Notion 目录（id/标题/URL/更新时间）做秒搜——**正文主权留在 Mac 主控层**，鸿蒙端只见目录不见正文、不持 token。

## 2. 链路

```
鸿蒙 App (ArkTS)
   │  MCP JSON-RPC over HTTP (只读5工具)
   ▼
鲲鹏 8768 只读镜像端点 (lh_mcp_notion.py · 127.0.0.1)
   ▲
   │  rsync 目录快照 catalog.json（无正文·零 token）
Mac 主控层 (lh notion sync · 持 Notion token · 全量读写)
```

## 3. SDK 结构（packaging/harmony/notion-mcp-sdk）

```
index.ets                    统一出口（re-export 全部 API）
src/main/ets/
├── common/Config.ets        LhConfig: 端点/超时/归属名（只读开关）
├── models/McpModels.ets     JSON-RPC 2.0 结构 + parseRpcResponse/firstText
├── models/CatalogModels.ets 镜像返回模型（状态/搜索/列表/审计）+ text→模型
├── net/HttpInfo.ets         @ohos.net.http 薄桥接（零三方依赖·M77）
├── net/RpcClient.ets        通用客户端：listTools/callTool/send
└── client/
    ├── QueryClient.ets      高层只读 API（5 个方法与 8768 工具一一对应）
    └── NativeQuery.ets      裸 JSON-RPC 教学演示（不依赖模型类）
```

零三方依赖：只用系统 `@kit.NetworkKit`(`@ohos.net.http`)——符合 M77「不要任何生态依赖/中间层」。

## 4. 5 个只读方法（映射 8768 工具）

| SDK 方法 | 8768 工具 | 返回 |
|:---|:---|:---|
| `getMirrorStatus()` | `get_mirror_status` | 快照页数/同步时间/审计尾数 |
| `searchCatalog(q, limit)` | `search_catalog` | 目录命中列表 |
| `listCatalog(kind, limit)` | `list_catalog` | all/page/database 列表 |
| `recentAudit(limit)` | `recent_audit` | 审计链尾（ts/kind/agent） |
| `topoSync()` | `topo_snapshot` | 拓扑摘要文本 |

## 5. Demo（packaging/harmony/NotionMCPDemo）

单页：端点状态卡 + 关键词秒搜 + 裸调原文演示。UI 走深色卡片风，标题/图标留白让真机截图自行裁定。

**运行步骤**
1. 本机无 DevEco：`lh harmony check` 做结构自检（23 项全绿）；`lh harmony init --out ./my-h` 复制模板到任意位置。
2. 装有 DevEco Studio 的机器打开 `NotionMCPDemo/`（`entry` 通过 `file:../notion-mcp-sdk` 依赖本地 SDK，无需发布）。
3. 端点可达后（见 §6）改 `src/main/ets/common/Config.ets` 的 `LhConfig.ENDPOINT`。
4. 连真机/模拟器跑；断连 UI 会显示原因（只读·不会写坏任何东西）。

## 6. 端点连接方式（重要 · 数据主权三选一）

8768 默认绑鲲鹏 `127.0.0.1`，**不对公网裸奔**：

| 场景 | 方式 |
|:---|:---|
| 桌面/模拟器 | `ssh -i ~/.ssh/longhun_kunpeng_ed25519 -L 8768:127.0.0.1:8768 root@119.13.90.27 -N`，连 `http://127.0.0.1:8768/mcp` |
| 家庭受信网段真机 | 临时改 systemd `--host 0.0.0.0` + 安全组 IP 白名单，测完即还原 |
| 公网长期 | nginx 反代 `https://uid9622.cn/<path>` + token 鉴权（不直接暴露 8768） |

> 一般参考 `docs/鲲鹏MCP接入指南-v1.0.md` §3.3 开放三步（token+host+重签）。
