# 🐉 longhun-cli 快速开始 · 5 分钟跑通

> 配套: `longhun-cli 4.0.0` · 详细协议见 `docs/对外接口协议-v1.0.md` · API 见 `docs/API参考-v1.0.md`

| 分钟 | 动作 | 命令 |
|:---:|:---|:---|
| 0 | 安装 | `pip install longhun-cli` |
| 1 | 版本自检 | `lh version` |
| 2-3 | 流场 | `lh flow "龙魂对外首发" --json` |
| 4 | 健康 | `lh health --json` |
| 5 | 八字 | `lh bazi --date 1990-01-01 --time 08:00 --json` |

---

## 第 0 步 · 安装

```bash
pip install longhun-cli
# 或本地安装
pip install dist/longhun_cli-4.0.0-py3-none-any.whl
```

零依赖，Python ≥ 3.8 即装即用。安装验证:

```bash
lh version
# longhun-cli 4.0.0 (龍魂 CIL 对外分发弹头)
```

## 第 1 步 · 流场计算 `lh flow`

```bash
lh flow "龙魂对外首发"
```

```
🌀 流场 | 龙魂对外首发
  数字根: 7 · 五行: 火 · 八卦: 艮
  审计: 🟡 · 行为: stay
  节点: FLOW-9622-FE92BD84
```

JSON 可解析输出（机器对接用）:

```bash
lh flow "龙魂对外首发" --json
```

```json
{
  "node_id": "FLOW-9622-FE92BD84",
  "digital_root": 7,
  "element": "火",
  "gua": "艮",
  "audit": "🟡",
  "action": "stay",
  "timestamp": "2026-09-01T06:31:22+0800"
}
```

## 第 2 步 · 健康自检 `lh health`

```bash
lh health --json
```

外部态（未接系统树）返回基础自检:

```json
{
  "status": "ok",
  "service": "longhun-cli",
  "version": "4.0.0",
  "python": "3.12.13",
  "platform": "macOS-26.6.2-arm64-arm-64bit",
  "root_detected": false,
  "mode": "external",
  "message": "基础自检通过；设 LONGHUN_ROOT 可接入龙魂系统全量逻辑"
}
```

> 💡 **双态**：设置 `export LONGHUN_ROOT=~/longhun-system` 后，`lh health` 自动透传系统内 15 项全量健康检查。

## 第 3 步 · 八字排盘 `lh bazi`

```bash
lh bazi --date 1990-01-01 --time 08:00 --json
```

```json
{
  "status": "ok",
  "node_id": "BAZI-9622-619BCF08",
  "date": "1990-01-01",
  "time": "08:00",
  "bazi": "庚午 戊寅 丙寅 壬辰",
  "pillars": { "year": "庚午", "month": "戊寅", "day": "丙寅", "hour": "壬辰" },
  "wuxing_score": { "火": 2.8, "木": 2.8, "土": 2.5, "水": 1.2, "金": 1.0 },
  "dominant": "火",
  "weakest": "金",
  "digital_root": 6,
  "element": "水",
  "gua": "坎",
  "audit": "🟡",
  "action": "stay"
}
```

> 📌 口径：公历月近似排盘（立春/节气分界以系统干支历 `lh_time_engine.py` 为准）。五行强度 = 天干 1.0 / 地支 0.8 加权累计。
