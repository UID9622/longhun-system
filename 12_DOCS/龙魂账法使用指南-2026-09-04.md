## 一、这是什么

**龍魂账法 = 龍魂体系底层记账能力。** 不是普通账本——每笔交易自带：

| 要素 | 说明 | 示例 |
|:---|:---|:---|
| **DNA** | 干支/日期级追溯码 | `#龍帳⚡️2026-09-04-1001-3201-1条-001-UID9622` |
| **哈希** | SHA256 前 8 位·防篡改 | `8FB2B68C` |
| **见证人格** | 12 类交易 T1-T12 · 龍魂人格见证 | T1=🧠 P25 数字主权官 |
| **三色审计** | 每笔自动过 `quick_audit` | 🟢 入账 / 🟡 待审 / 🔴 熔断 |

入账即自动上耻辱墙（`ledger_tx` 事件），主权类/大额交易自动入超级大脑（`lh brain`），发票/收据/口述可通过多模态识别直接记账（`lh sense ledger-chain`）。

**铁律：零中间层·零依赖·全本地。** 数据只在 `~/.longhun/ledger/`，append-only，删改需显式指令。


## 三、核心概念

### 3.1 账法 DNA

```
#龍帳⚡️{YYYY-MM-DD}-{借方科目}-{贷方科目}-{量}-{序号3位}-UID9622
```

- 自动校验：科目代码必须存在（见 §3.4）、日期须 `YYYY-MM-DD`、序号自动三位补零
- 量支持中文量词：`1条 / 100元 / 3笔 / 0.5次`
- 手工生成：`lh ledger dna <dr> <cr> <amount> [--seq N] [--date]`

### 3.2 账法哈希

```
hash = SHA256(dna | dr_code | cr_code | amount | timestamp)[:8].upper()
```

- `timestamp` 用当前时间 → 实时哈希；用固定时间 → **可复现**（供 verify 复核）
- 每笔交易的 `hash_ts` 记录在 extra 字段，`verify` 据此重算比对
- 手工计算：`lh ledger hash <dna> --dr 1001 --cr 3201 --amount "1条" [--ts 时间戳]`

### 3.5 三色审计链

```
新交易 → quick_audit(摘要) ──🟢──> 写入 transactions.jsonl（GREEN·append-only）
                        ──🟡──> 写入 pending.jsonl（待审队列·耻辱墙草稿）
                        ──🔴──> 拒绝写入·耻辱墙 ledger_red_meltdown·熔断日志
```

- 🔴 审计引擎缺失时自动降级内置黑词扫描（注明降级来源，绝不装全量审计）
- 红色词实测：`技术无国界` 等一票否决词被拦（见命令参考示例）

## 四、命令参考

| 命令 | 说明 |
|:---|:---|
| `lh ledger dna <dr> <cr> <amount> [--seq N] [--date]` | 生成账法 DNA |
| `lh ledger hash <dna> --dr --cr --amount [--ts]` | 计算账法哈希（固定 ts 可复现） |
| `lh ledger add <T1-T12> <dr> <cr> <amount> [--note] [--date] [--skip-audit]` | 记账（自动三色审计） |
| `lh ledger list [--limit N] [--all] [--pending] [--json]` | 最近交易 / 待审队列 |
| `lh ledger verify [--full]` | 全量校验（哈希/DNA/科目/重复） |
| `lh ledger balance [--json]` | 资产负债权益 + 恒等式 |
| `lh ledger export --format csv\|json\|md` | 导出账本 |
| `lh ledger audit <seq>` | 某笔交易审计详情（含现行复核） |
| `lh ledger confirm <seq>` | 待审复核 → 重新审计入账 |
| `lh ledger wall [--limit N]` | 账本耻辱墙事件 |
| `lh ledger scan <图片/音频> [--dr] [--cr] [--amount] [--tx-type]` | 感知识别自动记账 |
| `lh ledger add-auto <文本> [--source]` | 识别文本自动记账（OCR/ASR 链后） |
| `lh ledger rpc '<json>'` | JSON-RPC 单发（供 MCP/数字人） |
| `lh ledger` | 默认最近 10 笔 |

## 六、感知识别记账（图片/音频）

```bash
# 图片发票/收据 → OCR → 解析金额/日期/科目线索 → 自动记账
lh ledger scan 发票.png --tx-type T4

# 音频口述 → ASR → 解析 → 自动记账（需 ollama/faster-whisper）
lh ledger scan 口述.wav --tx-type T9

# lh sense 链（发票 → 自动记账）
lh sense pipeline run ledger-chain 发票.png
```

识别纪律（实测 2026-09-04）：
- 识别出金额+科目 → 自动记账走三色审计
- **科目/金额无法判定 → 🟡 待审队列**（不瞎记·由老大补全后 `lh ledger confirm <seq>`）
- 图表等无票面要素 → 拒绝记账并提示

## 七、数据与主权

- 账簿：`~/.longhun/ledger/transactions.jsonl`（GREEN·append-only）
- 待审：`~/.longhun/ledger/pending.jsonl` · 熔断：`meltdown.log/.jsonl`
- 序号：`ledger_index.json`（防并发重号）
- 隐私：账本只存本地，**永不入云**；对外只经 JSON-RPC 显式调用
- 不删除只冻结：改账走 `lh ledger confirm` 重新审计链路，历史行保留
