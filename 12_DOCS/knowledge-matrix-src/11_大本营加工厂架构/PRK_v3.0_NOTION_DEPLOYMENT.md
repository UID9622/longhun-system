## 🔧 Notion公式和自动化

### 公式1: 自动路由规则匹配

**在"路由规则决策表"添加公式列**:

```
列名: 是否匹配当前输入

公式:
if(
  contains(
    prop("触发条件"),
    "task_type == '" + lower(prop("任务类型")) + "'"
  ),
  "✅ 匹配",
  "❌ 不匹配"
)
```

### 公式2: 自动权重计算

**在"人格内核花名册"添加公式列**:

```
列名: 选中概率(%)

公式:
round(
  (prop("当前权重") /
   max(
     map(
       dataBases("人格内核花名册"),
       prop("当前权重")
     )
   )) * 100,
  1
)
```

### 公式3: 自动审计判定

**在"执行日志记录表"添加公式列**:

```
列名: 审计理由(自动)

公式:
if(
  equal(prop("审计等级"), "🟢"),
  "✅ 所有验证通过: 无虚构常数 · 物理一致 · 逻辑无矛盾",
  if(
    equal(prop("审计等级"), "🟡"),

    "❌ 验证失败: 检查失败原因"
```

## 🎯 实际使用流程

### 步骤1: 创建新执行记录

1. 打开"执行日志记录表"
2. 点击"+新建"
3. 填写：
   - 执行ID: `EXEC-20260604-XXX` (自动)
   - 输入任务: 用户描述
   - 任务类型: 选择 (math/system/security/mixed)

### 步骤2: 自动路由

- Notion自动在"路由规则决策表"中匹配规则
- 显示推荐的主人格和副人格
- 显示执行模式(sequential/parallel/adversarial)

### 步骤3: 执行并记录

- 记录主执行人格和副执行人格
- 如果发生冲突，记录冲突ID
- 记录最终输出
- 记录审计等级

### 步骤4: 自动更新权重

```
成功 → 权重 +0.02
部分成功 → 权重 +0.01
失败 → 权重 -0.01
关键发现 → 权重 +0.05-0.10
```
