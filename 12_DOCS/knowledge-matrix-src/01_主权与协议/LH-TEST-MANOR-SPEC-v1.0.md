## 三要素（焊死·不可缺）

### ① 测试庄园编号

每个测试集必须有唯一庄园编号。

```
格式: #测试庄园·[分类]-[日期]-[序号]

分类代码:
  BHV   — 行为测试（Behavioral）
  SEC   — 安全测试（Security）
  PERF  — 性能测试（Performance）
  INTG  — 集成测试（Integration）
  UNIT  — 单元测试（Unit）
  CAL   — 校准测试（Calibration）

示例:
  #测试庄园·BHV-20260708-001   — 行为DNA反图灵测试
  #测试庄园·SEC-20260708-001   — 安全审计测试
  #测试庄园·CAL-20260708-001   — RobotScore α/β/γ 校准
```

### ② DNA 测试数据来源

必须交代清楚三件事：

| 项目 | 说明 |
|:---|------|
| **数据类型** | 模拟数据 / 真实数据 / 公开语料 / 用户数据 / 混合 |
| **来源说明** | 来源于哪里（什么网站/平台/语料库/程序模拟），具体模拟了什么场景 |
| **具体情况** | 生成方式、参数（seed/数量/过滤条件）、是否为可复现的确定流程 |

> **红线**：不叫用户当数据燃料。成品做好测试好再交付。

### ③ 责任清单

每个测试必须包含以下四类责任角色：

| 角色 | 说明 | 典型负责人 |
|:---|------|------|
| **数据来源责任** | 数据来源的合法合规性、样本质量 | P06 数学大师 / P15 乔前辈 |
| **测试执行责任** | 测试的正确执行、结果输出 | P02 龍芯 |
| **审计责任** | 三色审计、质量把关、安全校验 | P05 上帝之眼 |
| **审核责任** | 最终判定、签字确认 | UID9622 |
