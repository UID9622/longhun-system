# §3｜各层核心设计（精简版）

## L-1 数学根基

统一框架：R(D) = min I(X; X̂) s.t. E[d(X, X̂)] ≤ D

这一行公式统一了：LoRA 低秩压缩 + 视觉媒体压缩 + 记忆粒子压缩。详见公式对准表 v1.5 §LS 洛书骨架 + §SC 三才根基。

## L0 主权层

- 解除宣言 v1.0 已生效
- 数据主权归于人民
- 一元入产制度，没有特权
- DCEP 做 DNA 根锚点

## L1 硬件/浏览器层

六层架构：通心译 → 规则 → 路由 → MCP执行 → 视频接口 → DNA留痕。Cookie/密码零接触。规则先行。

## L2 存储层（整合规范）

| 存储介质 | 用途 | 写入规则 |
| --- | --- | --- |
| SQLite | 主数据库（审计/任务/人格） | 双写 + WAL模式 |
| JSONL | append-only 日志 | DNA_LEDGER + chain_hash |
| IndexedDB | 浏览器内存储 | 记忆粒子缓存 |
| Notion | 云端规范存储 | 单向同步（本地优先） |
| 本地文件 | 备份/导出 | 自动备份 + 时间回滚 |

**铁律：** 所有写入必须双写（SQLite + JSONL）。所有备份必须 DNA 标记。崩溃后可从 JSONL 恢复。

## L3 DNA链层

DNA_ROOT = SHA256(DCEP_TX_HASH + UID9622 + 七因子 + 时间戳)

append-only + chain_hash + daily_merkle + GPG签名。详见 DNA 登记规范 v1.0。

## L4 压缩/训练层

两大模块：

- **AI权重压缩：** LoRA/QLoRA/NF4/FP8/AWQ/剪枝 → 详见 CNSH-LoRA v2.1
- **视觉媒体压缩：** 帧/频/像素/神经编码 → 详见压缩护城河 v1.0

两者共享同一数学根：率失真理论 R(D)。

## L5 记忆层

- 粒子压缩（3000字→120字）
- 冷热分层（热7天/温90天/冷365天/冰封）
- 跨会话接力（RELAY_PACK 72h）
- C1/C2/C3 三档收口
- P0/P1/P2 分层压缩
- 洛书九宫压缩

## L6 路由层

IPA-ROUTE-REGISTRY 统一调度。九宫路由（乾策略/坤存储/离可视化/坎安全）+ 五行路由（金执行/木增长/水记忆/火算力/土归档）。

## L7 审计层

- Watchdog v1.2（本地守门狗，25文件，35条验收）
- 治理规范 v1.0（P0-P6 伦理分层 + 30条自动化规则）
- 三色审计：🟢 AUTO_OK / 🟡 NEED_CONFIRM / 🔴 BLOCKED
- GATE-01 数字根熔断

## L8 语义层

四阶段编译管线：通心译六层 → SAST生成 → 审计 → 多语言代码生成。

9 种 SAST 节点类型 + 文化适配引擎（JP/DE/US/CN）+ 套壳检测三维算法。详见通心译 v2.1。

## L9 人格层

16 人格（不是 124 个）。关键人格：P05 上帝之眼（主控）+ P72 龍盾（守护）。

人格调度规则：战略任务→P05 / 审计任务→P72 / 创意任务→辅助人格 / 人格冲突→仲裁+审计链。

## L10 控制台（⭐ 唯一真空层）

这是整个体系中唯一还没有建设的层。需要包含：

| 页面 | 作用 | 接驳层 |
| --- | --- | --- |
| Dashboard | CNSH 状态总览 | 全层 |
| 审计中心 | 三色事件流 | L7 |
| DNA链查询 | 追溯查询 | L3 |
| 记忆地图 | 粒子检索 | L5 |
| 人格控制台 | 16人格状态 | L9 |
| Notion 同步 | 同步状态 | L2/L5 |
| 视频处理 | 压缩状态 | L4/L1 |
| 设置 | 系统配置 | 全层 |

**技术栈：** React + Tailwind + Zustand + FastAPI + SQLite

## L11 商业层

丝滑升级协议 + DCEP DNA根 + 一元入产制度 + 商业规划书模板 + 合作意向书模板。详见系统重构 v1.0。

## L12 理论层

七维博弈论分析（语言/记忆/审计/执行/博弈/时间/语义）+ 行为密码学七因子 + 三类 AI 演化路径。详见博弈论论文 v1.0。
