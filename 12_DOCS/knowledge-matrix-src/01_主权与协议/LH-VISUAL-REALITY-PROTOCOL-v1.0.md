## 一、协议定位与精神

### 1.1 协议定性

**原色优先，真实为本。拒绝一切破坏视觉真实性的处理手段。**

本协议是龍魂系统在**视觉内容领域的真实性治理框架**。它不是技术建议，不是审美指导，不是"建议尽量不用美颜"——它是**不可逾越的系统规则**。

任何进入龍魂系统的视觉内容（图像、视频、3D渲染、AR/VR场景），必须遵守本协议。任何违反本协议的内容，系统自动拦截，不入库、不展示、不传播。

### 1.2 为什么需要这个协议

```
问题核心：
不是"美颜不好看"——
而是"美颜让人不知道什么是真的"。

当一张照片里的天比真实的天更蓝、
草比真实的草更绿、
脸比真实的脸更尖、
风景比真实的风景更"完美"——

你看到的已经不是这个世界，是算法给你编的梦。

龍魂不造梦。龍魂记录真实。
```

## 二、核心原则

### 2.1 三不原则

| # | 原则 | 含义 |
|:--:|------|------|
| 1 | **不欺骗** | 视觉内容不得通过任何技术手段改变原始真实信息 |
| 2 | **不粉饰** | 不做任何形式的"视觉美化"，不管对象是脸、风景还是产品 |
| 3 | **不伪造** | 不用AI生成/替换/增强任何视觉元素当真实内容展示 |

### 2.2 核心语义锚点

| 技术行为 | 龍魂判定 | 理由 |
|------|:--:|------|
| 磨皮/美白 | 🔴禁止 | 篡改肤质真实信息 |
| 瘦脸/大眼 | 🔴禁止 | 篡改面部几何真实信息 |
| AI换脸 | 🔴禁止 | 伪造身份视觉信息 |
| 风格化滤镜 | 🔴禁止 | 扭曲色彩真实感知 |
| 调整亮度/对比度 | 🟡有条件允许 | 还原拍摄时的真实光线条件（需标注） |
| 裁剪/旋转 | 🟢允许 | 不改变像素级别的真实信息 |
| 真实化妆/穿搭后拍摄 | 🟢鼓励 | 物理手段提升，不欺骗 |

## 三、白名单：允许的操作

### 3.1 原色保留（默认模式）

图像采集设备直出色彩，不做任何处理。这是龍魂视觉的**默认状态**。

```
允许的操作：
✅ 保留原始色相
✅ 保留原始饱和度
✅ 保留原始白平衡（设备直出）
✅ 保留原始曝光
✅ 保留原始锐度
```

### 3.2 经典底色切换（≤5套预设）

提供有限的预设底色模板，底色**仅作用于背景/边框区域**，不触及主体内容。

| 底色名 | 色值 | 用途 |
|------|------|------|
| 经典白 | #FFFFFF | 证件照/档案/正式文档 |
| 经典黑 | #000000 | 深色模式/艺术展示 |
| 经典灰 | #808080 | 中性展示/技术文档 |
| 经典蓝 | #1A3A5C | 龍魂品牌·文化展示 |
| 经典红 | #8B0000 | 警示/重要标记 |

**限制**：
- 不允许用户自定义底色色值
- 底色仅作用于CSS层或图像背景，不得进入图像像素
- 底色模板不允许超过5套

### 3.3 物理层面调整

以下操作属于**真实物理手段**，在龍魂系统中被鼓励：

| 操作 | 条件 |
|------|------|
| 换发型 | 必须是真实发型，非AI生成/替换 |
| 换衣服 | 必须是真实穿着拍摄，非虚拟换装 |
| 化妆 | 必须是真实妆容，现场完成 |
| 打光 | 必须是真实光源，现场布光 |
| 角度调整 | 必须实际移动设备/被摄对象 |

**标注要求**：物理调整后的内容应标注处理类型（如"真实妆容·2026-07-15"）。

### 3.4 基本校正（有标注要求）

| 操作 | 条件 | 标注 |
|------|------|------|
| 亮度调整 | 仅恢复拍摄时真实光线条件 | "亮度校正" |
| 对比度调整 | 仅恢复拍摄时真实对比度 | "对比度校正" |
| 裁剪 | 不改变像素信息 | "裁剪" |
| 旋转 | 纠正拍摄角度 | "旋转校正" |
| 水平翻转 | 镜像显示 | "镜像" |

## 四、黑名单：绝对禁止的操作

### 4.1 面部篡改（一级禁止）

```
🔴 绝对禁止：
- 磨皮（皮肤平滑化、柔焦、美肤）
- 美白（肤色提亮、肤色漂白）
- 祛痘、祛斑、祛痣
- 瘦脸（面部轮廓重塑）
- 大眼（眼部放大）
- 高鼻梁（鼻部重塑）
- 尖下巴（下颚重塑）
- 五官位置调整
- 脸型整体调整
- 肤质美化（任何形式）
- 皱纹消除/淡化
- 面部对称化处理
- 任何改变面部真实形态的AI处理
```

**理由**：面部是人最核心的身份信息。篡改面部 = 篡改身份 = 违反数据主权。

### 4.2 滤镜扭曲（二级禁止）

```
🔴 绝对禁止：
- 风格化滤镜（复古、胶片、日系、ins风、港风、油画等）
- 色彩滤镜（暖调、冷调、赛博朋克、电影调色、LUT套用等）
- 特效滤镜（动态模糊、光晕、星芒、漏光、颗粒等）
- 预设调色包（任何形式的预设色彩方案）
- 任何改变原色感知的自动/手动滤镜
```

**理由**：滤镜是对真实色彩的**系统性谎言**。一张加了暖调滤镜的照片，传递的不是"这个场景很温暖"，而是"这个场景被处理成看起来很温暖"——完全是两回事。

### 4.3 AI生成/增强（三级禁止）

```
🔴 绝对禁止：
- AI换脸（DeepFake、FaceSwap等）
- AI表情迁移
- AI背景替换
- AI场景生成
- AI画质增强（超分辨率、去噪、去模糊）
- AI补全（内容感知填充、外扩画幅）
- AI修复（老照片修复、损坏修复）
- AI上色（黑白转彩色）
- AI去水印
- AI人物生成（虚拟人像当真人展示）
- 生成式填充（Generative Fill）
```

**理由**：AI生成的视觉内容不是真实世界的映射，是概率模型的输出。当AI视觉混入真实视觉流，人类将失去辨别真实的能力。

### 4.4 几何变形（四级禁止）

```
🔴 绝对禁止：
- 拉伸（非等比缩放）
- 压缩（非等比缩放）
- 扭曲（液化工具、变形工具）
- 透视矫正（改变真实透视关系）
- 桶形/枕形畸变修正（除非还原镜头真实光路）
- 任何改变真实比例/形状的处理
```

## 五、检测与执行标准

### 5.1 图像真实性检测管线

```
输入图像
  ├─ 步骤1: EXIF完整性检查 → 缺失/篡改 → 🔴拦截
  ├─ 步骤2: ELA分析（Error Level Analysis）→ 异常区域 → 🔴拦截
  ├─ 步骤3: 面部关键点一致性检测 → 偏离Dlib/FaceMesh标准 → 🔴拦截
  ├─ 步骤4: 频域分析（FFT/DCT异常检测）→ AI生成痕迹 → 🔴拦截  
  ├─ 步骤5: 色彩直方图分析 → 非自然分布 → 🔴拦截
  ├─ 步骤6: 噪声一致性分析 → 不均匀噪声 → 🔴拦截
  ├─ 步骤7: AI生成检测（专用模型）→ 概率>阈值 → 🔴拦截
  └─ 步骤8: 白名单操作标注 → 打标 → 🟢放行
```

### 5.2 检测阈值

| 检测项 | 工具/方法 | 阈值 | 动作 |
|------|------|:--:|------|
| EXIF缺失/篡改 | exiftool/PIL | 任何不一致 | 🔴拦截 |
| ELA异常区域 | ELA算法 | >5%像素异常 | 🔴拦截 |
| 面部关键点偏移 | Dlib 68点/FaceMesh 468点 | >3%偏差 | 🔴拦截 |
| AI生成概率 | 专用检测模型(NPR/RGB高频) | >0.15 | 🔴拦截 |
| 肤色平滑度 | 局部方差分析 | 方差<自然范围下限 | 🔴拦截 |
| 色彩饱和度异常 | 直方图分析 | >3σ偏离 | 🔴拦截 |
| 液化痕迹 | 光流场分析 | 非零光流向量>1% | 🔴拦截 |

## 六、例外条款

### 6.1 允许例外的情况

以下场景**不受本协议黑名单约束**，但必须满足三项前置条件：

| 例外类型 | 定义 | 示例 |
|------|------|------|
| **艺术创作** | 明确标注为"艺术创作"的绘画、插画、CG、数字艺术 | 龙魂插画、CNSH图标设计、概念艺术 |
| **历史修复** | 明确标注为"历史影像修复"的档案资料 | 老照片数字化修复、历史文献图像处理 |
| **医疗用途** | 明确标注为"医疗影像"的临床诊断图片 | X光增强、CT重建、病理染色 |
| **科学可视化** | 明确标注为"数据可视化"的图表、模拟图、科学渲染 | 神经网络拓扑图、数据大屏、天文图像处理 |
| **安全取证** | 明确标注为"安全取证"的法医学图像 | 监控增强、指纹提取、证据固定 |

### 6.2 例外前置条件

三项必须**同时满足**：

1. **明确标注用途类型** — 在元数据中写入 `longhun.content_type`
2. **不用于社交展示/身份认证** — 不混入真实图像流
3. **隔离存储** — 例外内容与真实内容分库存储，不可交叉引用

## 七、违规处理

### 7.1 违规分级

| 等级 | 行为 | 检测方式 | 处理 |
|:--:|------|------|------|
| **一级** | 轻微美颜（磨皮强度<30%、美白色阶<1级） | 自动检测 | 警告 + 拒绝发布 + 提示使用物理手段 |
| **二级** | 明显修图（瘦脸>5%、大眼>10%、滤镜叠加） | 自动检测 | 删除内容 + 账号限流7天 |
| **三级** | AI换脸/深度伪造 | 自动检测+AI模型 | 永久封禁 + 证据固定 + 上报监管 |
| **四级** | 批量制造虚假视觉（工业化生产假图） | 自动检测+人工复核 | 永久封禁 + 全链证据固定 + 法律追责 |
| **五级** | 伪造他人视觉（冒充他人身份） | 自动检测+人工复核 | 永久封禁 + 证据移交公安机关 |

### 7.2 申诉机制

用户对检测结果有异议，可通过以下渠道申诉：

1. 提交原始RAW/DNG文件（如有）
2. 提交拍摄设备信息
3. 提交拍摄现场证明（第三方见证/时间戳/地点证明）
4. 系统72小时内完成人工复核
