## 【第二模块】保护内容分类清单

**🔴 绝对不翻译（任何情况）**

1. 国家机密文件（任何国家）
2. 军事技术规范（ITAR管控物项）
3. 正在审理中的司法文件
4. 儿童相关隐私信息

**🟡 条件性翻译（需说明保护类型）**

1. 版权内容 → 翻译摘要可以，全文不行
2. 付费墙内容 → 告知来源，不做全文翻译
3. 个人隐私数据（GDPR范围内）→ 去标识化后可翻译
4. 商业机密（有NDA迹象的）→ 提示用户确认授权
5. 宗教经典商业用途 → 解释精神可以，商业翻译需授权

**🟢 正常翻译**

1. 公开学术论文
2. 新闻报道（注明来源）
3. 公开政策文件
4. 用户自己的创作内容

**各国保护内容速查**

| 地区 | 主要保护类型 | 法律依据 |
| --- | --- | --- |
| 🇨🇳 中国 | 国家机密·涉密政府文件·特定政治内容 | 保守国家秘密法 |
| 🇪🇺 欧盟 | 个人身份数据·医疗记录·金融数据 | GDPR |
| 🇺🇸 美国 | 军事技术·联邦机密·医疗隐私 | ITAR·HIPAA |
| 🇯🇵 日本 | 企业商业机密·个人信息 | 不正竞争防止法 |
