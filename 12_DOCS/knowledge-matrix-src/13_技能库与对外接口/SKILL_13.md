# 龍瞳OCR — 中文优先图像识别引擎

**DNA追溯**: `#龍芯⚡️丙午·甲午·甲子·庚午·䷙大畜-LONGTENG-OCR-v5.0`

## 一、技能概述

龍瞳OCR（Dragon Pupil OCR）是龍魂体系的核心图像识别模块。本技能采用「中文优先」设计哲学：所有核心算法均以中文命名实现，仅在必要时使用国际标准库作为兜底。支持中文字符特征提取、笔画密度分析、字符结构识别、繁体「龍」字专用检测、甲骨文字符分类等高级功能。

**核心策略**: 能中文替代的中文实现，不能的用国际标准库兜底。

**三色审计标注**:
- 🟢 已实现 | 🟡 部分实现 | 🔴 未实现

## 二、触发条件

当用户需求涉及以下任一场景时触发此技能：

- 图像中的文字识别（OCR）
- 中文字符检测与识别
- 繁体「龍」字的专用检测
- 甲骨文字符特征分类
- CNSH代码截图中的中文标识符识别
- 图像预处理（二值化、滤波、倾斜校正）
- 文本区域检测与分割
- 笔画特征提取与分析

## 三、功能模块

### 3.1 图像预处理器（🟢 全部自实现）

| 功能 | 实现方式 | 状态 |
|------|---------|------|
| 灰度转换 | 中文算法：RGB加权公式 | 🟢 |
| OTSU二值化 | 中文算法：最大类间方差法 | 🟢 |
| 中值滤波 | 中文算法：滑动窗口中值 | 🟢 |
| 图像旋转 | 中文算法：双线性映射 | 🟢 |
| 倾斜校正 | 中文算法：投影方差分析 | 🟢 |

### 3.2 文本区域检测器（🟢 自实现）

- **笔画密度图计算**：局部窗口黑色像素密度估算
- **水平投影分割**：基于行投影的行分割
- **垂直投影分割**：基于列投影的字符分割
- **噪声区域过滤**：基于最小笔画密度阈值

### 3.3 字符特征提取器（🟢 自实现）

- **笔画密度特征**：上/中/下/左/右/中横区域密度分布
- **字符结构分析**：左右、上下、包围、半包围、独体分类
- **简易骨架化**：距离变换近似骨架（SciPy增强）
- **端点检测**：骨架端点识别
- **交叉点检测**：骨架交叉点识别
- **部首模板匹配**：常见偏旁部首特征模板

### 3.4 龍字专用检测器（🟢 自实现）

基于繁体「龍」字独特结构特征的模式识别：
- 左上角「立」部检测
- 右侧弯曲龙身检测
- 底部三点或弯钩检测
- 整体左右结构分析
- 综合置信度评分（结构35% + 密度35% + 端点30%）

### 3.5 甲骨文分类器（🟢 自实现）

- **笔画数估算**：基于骨架端点与交叉点
- **直线度分析**：笔画直线程度评分
- **对称度分析**：水平/垂直对称性评估
- **密度特征分析**：四分区密度不均匀度
- **分类阈值**：极简(1-3) / 简单(4-6) / 中等(7-10) / 复杂(11-15) / 极复杂(16-25)

### 3.6 国际兜底引擎（🟡 Tesseract）

当中文算法置信度低于阈值时自动降级：
- Tesseract OCR多语言识别（chi_sim + chi_tra + eng）
- 自动路径检测与配置
- 置信度对比与智能切换

## 四、API接口

### 4.1 主引擎类：`龍瞳OCR引擎`

```python
# 初始化
引擎 = 龍瞳OCR引擎(模式="混合模式", 置信度閾值=0.7)

# 模式选项："中文优先" | "国际兜底" | "混合模式"
```

### 4.2 核心方法

| 方法 | 功能 | 返回类型 |
|------|------|---------|
| `識別圖像(圖像路徑)` | 主识别函数 | `識別結果` |
| `識別中文字符(圖像數組)` | 单字符识别 | `識別結果` |
| `檢測龍字(圖像數組)` | 龍字专用检测 | `Dict` |
| `檢測甲骨文(圖像數組)` | 甲骨文特征分类 | `Dict` |
| `提取文本區域(圖像數組)` | 文本区域提取 | `List[區域框]` |
| `預處理(圖像數組)` | 图像预处理 | `np.ndarray` |
| `識別CNSH代碼(圖像路徑)` | CNSH代码识别 | `Dict` |
| `導出JSON(結果, 文件路徑)` | JSON导出 | `str` |
| `安裝依賴()` | 依赖检测 | `Dict` |
| `獲取統計()` | 统计信息 | `Dict` |

### 4.3 数据类

- **`識別結果`**: 文本、置信度、区域、审计标记、结构、备注、引擎来源
- **`區域框`**: 左上横/纵、右下横/纵、置信度、文本
- **`字符結構`**: 独体/左右/上下/包围/半包围/未知（枚举）

## 五、使用示例

### 示例1：基础图像识别

```python
from scripts.图像识别引擎 import 龍瞳OCR引擎

# 初始化引擎
引擎 = 龍瞳OCR引擎(模式="混合模式", 置信度閾值=0.7)

# 识别图像
結果 = 引擎.識別圖像("/path/to/image.png")
print(f"识别文本: {結果.文本}")
print(f"置信度: {結果.置信度}")
print(f"审计状态: {結果.審計}")
```

### 示例2：龍字检测

```python
import numpy as np
from scripts.图像识别引擎 import 龍瞳OCR引擎, 圖像生成器

引擎 = 龍瞳OCR引擎()

# 生成测试图像
圖像 = 圖像生成器.生成測試圖像("龍", 尺寸=(128, 128), 字號=64)

# 检测龍字
結果 = 引擎.檢測龍字(圖像)
print(f"包含龍字: {結果['包含龍字']}")
print(f"龍字数量: {結果['龍字數量']}")
```

### 示例3：图像预处理

```python
from scripts.图像识别引擎 import 圖像預處理器
import numpy as np

預處理器 = 圖像預處理器()

# 完整预处理流程
灰度 = 預處理器.轉灰度(圖像)
去噪 = 預處理器.中值濾波(灰度, 核大小=3)
二值 = 預處理器.OTSU二值化(去噪)
校正 = 預處理器.傾斜校正(二值)
```

### 示例4：CNSH代码识别

```python
引擎 = 龍瞳OCR引擎()

# 识别CNSH代码截图
結果 = 引擎.識別CNSH代碼("code_screenshot.png")
print(f"CNSH术语匹配: {結果['術語數量']} 个")
for 術語 in 結果['CNSH術語']:
    print(f"  - {術語['術語']}")
```
