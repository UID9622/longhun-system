## 触发条件

当用户说以下任意一种时调用本技能：

- "帮我排序"
- "按三色审计排优先级"
- "哪个先做"
- "优先、其次、最后"
- "安排个技能排序"

## 评分维度

每个任务从四个维度打分（0-100）：

1. **阻塞度 (blocker)**：不做会不会导致后续无法进行？
2. **风险度 (risk)**：安全、数据、稳定性风险有多高？
3. **影响面 (impact)**：影响多少用户/模块/功能？
4. **紧迫度 (urgency)**：时间窗口是否紧迫？

综合得分 = 加权平均：
- blocker 40%
- risk 30%
- impact 20%
- urgency 10%

## 颜色映射

| 综合得分 | 颜色 | 标签 |
|---|---|---|
| ≥ 70 | 🔴 阻断/最高 |
| 40 - 69 | 🟡 待审/中等 |
| < 40 | 🟢 通过/延后 |

## 使用方式

### 方式一：调用脚本

```bash
python3 ~/.kimi-code/skills/longhun-priority-sort/priority_sort.py \
  --tasks '[
    {"name": "修复 compile 挂起", "blocker": 90, "risk": 70, "impact": 60, "urgency": 50},
    {"name": "合并到 longhun-system", "blocker": 80, "risk": 40, "impact": 90, "urgency": 60},
    {"name": "安装完整依赖", "blocker": 30, "risk": 20, "impact": 40, "urgency": 30}
  ]'
```

### 方式二：Kimi 直接推理

Kimi 在收到任务列表后，自动调用本技能，按以下步骤输出：

1. 为每个任务打分
2. 标色
3. 按 🔴 > 🟡 > 🟢 排序
4. 给出执行建议

## 输出格式

```markdown
## 龍魂三色优先级排序

### 🔴 立即执行（最高优先级）
1. **任务A** — 得分 85
   - 阻塞度: 90 | 风险度: 80 | 影响面: 70 | 紧迫度: 60

### 🟡 其次执行（中等优先级）
1. **任务B** — 得分 65
   - ...

### 🟢 延后执行（最低优先级）
1. **任务C** — 得分 35
   - ...
```

## 规则

- 颜色只代表相对优先级，不代表任务本身好坏。
- 若多个任务同色，按得分从高到低排列。
- 用户可随时调整维度分数，重新排序。
