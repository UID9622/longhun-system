### 场景 3：给自动化脚本提供输入

### 场景 4：学术引用快速定位

### 场景 5：投稿前状态核对
> 准备向 IEEE 会议/期刊投稿前 → 核对 014 审核状态、022 是否已发布 → 确保对外引用链路完整。

## 五、自动化集成

### 5.1 从登记册提取 IEEE 论文

```python
import json, pathlib

reg = json.loads(pathlib.Path(
    'docs/dragon-soul-open-hub/academic/academic_papers_registry.json'
).read_text(encoding='utf-8'))

ieee_papers = [
    p for p in reg['papers']
    if 'IEEE' in p.get('keywords', []) or 'IEEE' in p.get('title', '')
]

for p in ieee_papers:
    print(p['id'], p['title'], p.get('csdn', {}).get('status', '未发布'))
```

### 5.2 自动生成未发布任务清单

```python
unpublished = [
    p for p in ieee_papers
    if p.get('csdn', {}).get('status') != '已发布'
]

# 输出到 TODO 或自动化发布队列
for p in unpublished:
    print(f"[待发布] {p['id']} - {p['title']}")
```

### 5.3 CSDN 发布状态看板（可接入监控）

| 状态 | 含义 | 自动化动作 |
|---|---|---|
| 已发布 | 可对外引用 | 归档到“已发布”列表 |
| 审核中 | 等待平台审核 | 定时轮询，审核通过后更新链接 |
| 未发布 | 需要人工/自动发布 | 加入发布队列，生成标准稿件 |
| 已升级 | 已被合并到新版本 | 在新版本中保留旧 ID 追溯 |
