# 龍魂社区 · 行为准则

> 技术服务于人民。数据主权归于用户。透明审计不可篡改。

## 我们的承诺

龍魂系统根植于中华文明价值观。我们承诺：

- 🐉 **技术服务于人民** — 所有代码、模型、工具以人民利益为最高准则
- 🔐 **数据主权归于用户** — 每位用户拥有自己的数字DNA，数据不可被第三方窃取或滥用
- 📋 **透明审计不可篡改** — 所有决策、裁决、规则变更记录在链，可追溯、可验证
- ⚖️ **反欺诈、反操纵** — 拒绝任何形式的算法欺诈、数据操纵、信息茧房
- 🤝 **尊重多元参与者** — 无论经验水平、背景、观点，人人有权贡献与发声

## 我们的标准

### 鼓励的行为

- 🐉 使用友好、包容的语言
- 🤝 尊重不同的观点和经验
- 📝 优雅地接受建设性批评
- 🧠 聚焦于对社区最有利的事情
- 💬 对其他社区成员表示共情

### 不可接受的行为

- 🚫 使用性暗示语言或图像，以及不受欢迎的性关注或挑逗
- 🚫 挑衅、侮辱/贬损性评论，以及人身攻击
- 🚫 公开或私下的骚扰
- 🚫 未经明确许可发布他人隐私信息（如物理地址或电子地址）
- 🚫 在专业环境中可合理认为不恰当的其他行为

### 🔴 龍魂红线 · 零容忍 · 直接熔断

以下行为一经发现，不做讨论、不做投票、立即熔断处理：

- 🔴 **危害国家安全与领土完整**的内容
- 🔴 **违反中华文明核心价值观**的恶意攻击与颠覆性言论
- 🔴 **反人类内容** — 煽动暴力、恐怖主义、种族灭绝
- 🔴 **儿童保护** — 任何涉及未成年人的不当内容或利用行为
- 🔴 **系统性欺诈** — 以技术手段实施大规模诈骗、传销、洗钱
- 🔴 **数字主权侵犯** — 窃取用户DNA、破解加密、伪造链上记录

> 熔断 = 内容立即删除 + 贡献者永久封禁 + 审计日志落盘 + 全节点同步。

## 治理机制 · 分布式决策

龍魂不搞「维护者独裁」。我们采用三阶梯治理：

| 层级 | 范围 | 决策方式 |
|------|------|----------|
| 🟢 **一般争议** | 代码风格、文档措辞、功能优先级 | 社区投票，简单多数通过 |
| 🟡 **重大争议** | 架构变更、协议修改、新子系统引入 | 社区投票 + 核心贡献者评审，2/3 多数通过 |
| 🔴 **红线争议** | 安全漏洞、伦理红线、主权危机 | **创始人主权覆写**，一票裁决，不留死角 |

**创始人主权覆写**的使用条件：
1. 仅限红线级别事件
2. 每次覆写附书面理由
3. 审计日志完整记录，社区可查
4. 覆写后 7 日内公示，接受社区质询
5. 质询结果记录入审计日志，但不改变覆写决定（覆写仍为一票裁决）
6. 连续 3 次质询超过 2/3 反对 → 触发社区特别会议，讨论创始人权限是否需要调整（非即时生效，仅记录）

## 我们的责任

核心维护者负责：
- 澄清可接受行为的标准
- 组织社区投票流程
- 执行熔断机制（红线事件）
- 维护审计日志的完整性

所有治理动作写入审计日志，不可篡改，社区可查。

## 适用范围

本行为准则适用于所有项目空间，也适用于个人在公共场合代表项目或其社区的情况。
