## 🎯 系统使用指南

### 占位三原则

1. **即时占位**：有想法就立即创建记录，不等完成
2. **DNA留痕**：每个创作都有唯一DNA追溯码
3. **网络关联**：通过relation属性建立知识网络

### DNA追溯码格式

```
标准格式：
#ZHUGEXIN⚡️YYYY-MM-DD-{MODULE}-{VERSION}

P0级专用格式：
#ZHUGEXIN⚡️YYYY-🇨🇳🐉⚖️♠️🧚🏼‍♀️❤️♾️-{MODULE}-{VERSION}
```

### 完成度标准

- **0-20%**：构思阶段，有基本想法
- **21-50%**：设计阶段，有详细方案
- **51-80%**：开发/写作阶段，已实现主要功能
- **81-99%**：测试/完善阶段，接近完成
- **100%**：已完成并发布

### 可信度/状态标准

**理论框架库**：

- 已实现：理论已经在实际系统中应用并验证
- 设计中：理论框架已完整，正在实现
- 构思中：有初步想法，需要完善
- 实验阶段：正在验证可行性

**技术实现库**：

- 已完成：代码完成，测试通过，可用
- 开发中：正在编码实现
- 设计中：技术方案已确定，未开始编码
- 未开始：仅有技术占位

**产品设计库**：

- 已发布：产品已上线，用户可用
- 测试中：产品功能完成，正在测试
- 开发中：正在开发实现
- 设计中：产品方案已确定
- 构思中：有初步想法

**文档写作库**：

- 已发布：文档已发布到平台
- 待发布：文档完成，等待发布
- 草稿：文档主体完成，需要修改
- 构思中：有写作计划

**核心价值观库**：

- 已验证：价值观已在实践中验证
- 实践中：正在实践验证
- 理论阶段：仅有理论思考

## 🔗 知识网络关联

### 关联关系说明

**理论框架库** ↔ 其他库：

- → 相关文档：理论的文档说明
- → 依赖技术：实现理论所需的技术
- → 相关产品：应用该理论的产品
- → 核心价值观：理论体现的价值观

**技术实现库** ↔ 其他库：

- → 实现理论：技术实现了哪些理论
- → 应用产品：技术被哪些产品使用
- → 相关文档：技术的文档说明
- → 依赖技术：技术依赖哪些其他技术（自关联）

**产品设计库** ↔ 其他库：

- → 依赖技术：产品使用的技术
- → 应用理论：产品应用的理论
- → 相关文档：产品的文档
- → 核心价值观：产品体现的价值观

**文档写作库** ↔ 其他库：

- → 相关理论：文档介绍的理论
- → 相关技术：文档介绍的技术
- → 相关产品：文档介绍的产品
- → 核心价值观：文档传达的价值观

**核心价值观库** ↔ 其他库：

- → 相关理论：体现该价值观的理论
- → 相关技术：体现该价值观的技术
- → 相关产品：体现该价值观的产品
- → 相关文档：阐述该价值观的文档

## 📦 防御性公开文档包

### 公开策略

**P0永恒级**：

- 完全公开：理论框架、核心价值观
- 目的：防止专利化、建立先发优势

**P1演进级**：

- 部分公开：理论公开，实现细节保密
- 目的：保持技术领先，防御专利

**P2高敏级**：

- 选择性公开：根据情况决定
- 目的：灵活调整

**使用视图快速导出**：

1. 理论框架库 → "公开理论清单"视图
2. 技术实现库 → "开源技术清单"视图
3. 产品设计库 → "公开产品清单"视图
4. 文档写作库 → "已发布文档"视图
5. 核心价值观库 → "P0核心价值观"视图

**一键导出方法**：

- 打开对应视图
- 点击右上角"···"菜单
- 选择"导出" → "Markdown & CSV"
