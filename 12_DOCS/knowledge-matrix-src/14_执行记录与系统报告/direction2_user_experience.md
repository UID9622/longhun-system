### 1.2 信息架构原则

| 原则 | 说明 | 在龍魂中的体现 |
|------|------|----------------|
| **三层导航** | 全局(侧边栏) → 局部(标签页) → 上下文(操作按钮) | 侧边栏主导航 → 面板内次级标签 → 卡片操作 |
| **数据密度递进** | 概览(低密度) → 分析(中密度) → 详情(高密度) | 大屏4指标 → 卡片12指标 → 抽屉全量指标 |
| **五行色彩系统** | 金木水火土五色系分模块类型 | 性能优化=金、知识库=木、审计/安全=水、AI推理=火、基础设施=土 |
| **三才空间隐喻** | 天=上方AI层、地=下方基础设施层、人=中间交互层 | 三才面板垂直空间布局 |
| **即时反馈** | 任何操作<300ms响应 | WebSocket推送 + 本地乐观更新 |

### 1.3 导航流（User Flow）

```
用户登录 → 总览大屏（默认）
    │
    ├── 点击异常模块 → 模块健康页（自动筛选异常）
    ├── 点击告警数 → 告警中心（自动筛选对应级别）
    ├── 点击DNA对齐率 → DNA管理页
    ├── 点击吞吐量 → 性能分析页
    └── 点击三才状态 → 三才面板

任意页面 → 全局搜索（⌘K） → 快速跳转模块/告警/DNA
```

- **天（AI推理层）**：AI相关模块 — NLP、ASR、OCR、KIMI、MCP、数字人等
- **地（基础设施层）**：系统底座 — Daemon、Panel、Deploy、Governance、System等

# dashboard_v3/websocket.py

from fastapi import WebSocket
import asyncio
import json

class DashboardWebSocketManager:
    """仪表盘WebSocket连接管理"""
    
    def __init__(self):
        self.active_connections: List[WebSocket] = []
        self.data_adapter = MonitoringDataAdapter()
    
    async def connect(self, websocket: WebSocket):
        await websocket.accept()
        self.active_connections.append(websocket)
    
    async def disconnect(self, websocket: WebSocket):
        self.active_connections.remove(websocket)
    
    async def broadcast(self, message: dict):
        """广播消息到所有连接"""
        dead_connections = []
        for conn in self.active_connections:
            try:
                await conn.send_json(message)
            except:
                dead_connections.append(conn)
        
        # 清理断开的连接
        for conn in dead_connections:
            self.active_connections.remove(conn)
    
    async def start_polling(self):
        """启动数据轮询和推送"""
        while True:
            # 吞吐量推送（5秒）
            throughput = await self.data_adapter.get_throughput()
            await self.broadcast({
                "type": "throughput",
                "data": throughput.dict(),
                "timestamp": datetime.now().isoformat()
            })
            
            # 告警推送（事件驱动，这里检查新告警）
            alerts = await self.data_adapter.get_recent_alerts()
            if alerts:
                await self.broadcast({
                    "type": "alerts",
                    "data": [a.dict() for a in alerts],
                    "timestamp": datetime.now().isoformat()
                })
            
            await asyncio.sleep(5)

# 路由注册
@ws_router.websocket("/throughput")
async def throughput_ws(websocket: WebSocket):
    manager = DashboardWebSocketManager()
    await manager.connect(websocket)
    try:
        while True:
            throughput = await manager.data_adapter.get_throughput()
            await websocket.send_json({
                "value": throughput.current,
                "unit": throughput.unit,
                "timestamp": datetime.now().isoformat()
            })
            await asyncio.sleep(5)
    except WebSocketDisconnect:
        await manager.disconnect(websocket)

@ws_router.websocket("/alerts")
async def alerts_ws(websocket: WebSocket):
    """告警实时推送（事件驱动）"""
    manager = DashboardWebSocketManager()
    await manager.connect(websocket)
    try:
        async for alert in manager.data_adapter.get_alert_stream():
            await websocket.send_json({
                "type": "new_alert",
                "data": alert.dict(),
                "timestamp": datetime.now().isoformat()
            })
    except WebSocketDisconnect:
        await manager.disconnect(websocket)

## 设计原则总结

### 东方极简 + 数据密集

1. **留白哲学**: 关键指标周围保留充足呼吸空间，高密度数据区域使用折叠面板
2. **墨色层次**: 暗色主题采用宣纸白→淡墨→浓墨的渐变层次，而非纯黑
3. **龍脉流动**: 数据流动用动态线条表示，体现"气"的流动感
4. **印章标记**: DNA追溯码采用印章式视觉呈现，强化主权标识
5. **五行色彩**: 严格遵循五行配色体系，一眼识别模块属性
