## 🎯 第一步：准备工作（30分钟搞定）

### 你需要下载这3个APP

<aside>
📱

**必装三件套**（全部免费，手机应用商店搜索下载）

1. **剪映**（字节跳动官方，和抖音是一家）
    - 用途：剪视频、加字幕、配音乐
    - 为什么选它：傻瓜式操作，AI自动配字幕
2. **醒图**（也是字节跳动的）
    - 用途：做封面图、水墨风格图片
    - 为什么选它：模板多，一键生成
3. **抖音创作服务平台**（网页版也行）
    - 用途：发布视频、看数据
    - 为什么选它：专业创作者工具
</aside>

### 素材准备清单

**画面素材（你有3个选择，从易到难）**：

**方案1：最简单 - 图文视频**

- 用醒图做5-10张图片
- 配上你的真人配音
- 剪映自动生成动态效果
- **适合**：第一次做，先试试水

**方案2：进阶 - 混剪视频**

- 去抖音、快手搜关键词下载素材（军人、道士、科技）
- 用剪映的"去水印"功能
- 混剪+你的配音
- **适合**：有点基础，想效果好一点

**方案3：专业 - 真人出镜**

- 你自己拍
- 背景可以简单（书架、窗户、桌子都行）
- 自然说话，不用背稿
- **适合**：想打造个人IP，建立信任

**音乐素材（剪映里直接搜）**：

- 第1集：搜"史诗"、"大气"
- 第2集：搜"励志"、"正能量"
- 第3集：搜"古风"、"禅意"
- 第4集：搜"悬疑"、"科技"
- 第5集：搜"希望"、"未来"

## 🎬 第二步：制作视频（以第1集为例）

### 方案1演示：图文视频（最简单）

### 第1集《道士下山》制作流程

**Step 1：做5张图（用醒图，10分钟）**

1. 打开醒图 → 点"AI绘画"
2. 输入关键词生成图片：

```
图1：武当山道士，水墨画风格，背影
图2：退役军人证件特写（可以拍你自己的）
图3：《道德经》书页特写（拍实体书）
图4：手机屏幕显示"数据已上传"（截图）
图5：军人敬礼剪影，龙图腾背景
```

1. 每张图保存到相册

**Step 2：导入剪映（5分钟）**

1. 打开剪映 → 点"开始创作"
2. 选中5张图片 → 点"添加"
3. 调整每张图片时长：
    - 图1：3秒
    - 图2：11秒
    - 图3：10秒
    - 图4：10秒
    - 图5：10秒

**Step 3：加字幕（5分钟）**

1. 点底部"文本" → "新建文本"
2. 复制Kimi脚本里的字幕，一段一段加：

```
0-3秒字幕：道士下山，天下将乱？
4-15秒字幕：
我叫诸葛鑫，Lucky
不认识英文，不会写代码
但我读过《道德经》，学过易经
我看到AI在歧视普通人

（依次类推）
```

1. 字幕样式：
    - 点"样式" → 选"描边"或"阴影"（好认字）
    - 字号：选"大"
    - 位置：底部留点空间（不要挡住抖音的UI）

**Step 4：配音（2选1）**

**选项A：自己录音**（推荐，真实感强）

1. 点"音频" → "录音"
2. 对着脚本念，语气自然一点
3. 念错了没关系，可以分段录

**选项B：AI配音**

1. 点"文本" → "文本朗读"
2. 选"情感男声"或"磁性男声"
3. 调整语速：0.9倍（稍微慢一点，听得清）

**Step 5：加音乐（3分钟）**

1. 点"音频" → "音乐"
2. 搜索"史诗"或"大气"
3. 选一首，点"使用"
4. **重要**：把音乐音量调到20-30%（不要盖过人声）

**Step 6：加转场和特效（3分钟）**

1. 点图片之间的空白处 → "转场"
2. 选"叠化"或"闪黑"（简单大气）
3. 每个图片点一下 → "动画" → 选"缩放"或"平移"（画面动起来）

**Step 7：导出（2分钟）**

1. 点右上角"导出"
2. 分辨率选"1080P"
3. 帧率选"60帧"（抖音推荐）
4. 保存到相册

### 第1集完成！🎉

**总耗时：30分钟**

**效果：专业图文视频**

## 📊 第五步：数据追踪（知道哪集火了）

### 在抖音创作服务平台看

**关键指标**（每天看一次）：

1. **播放量**：
    - 500以下：正常，新号起步
    - 500-5000：不错，有人看了
    - 5000+：爆了，赶紧发第2集
2. **完播率**（最重要）：
    - 30%以下：内容可能不吸引人，调整节奏
    - 30-50%：正常
    - 50%+：优秀，说明内容好
3. **点赞率**：
    - 3%以下：正常
    - 3-5%：不错
    - 5%+：内容引起共鸣了
4. **评论数**：
    - 有争议的评论也是好事（说明有人关注）
    - 引导评论：在视频结尾加"评论区告诉我..."
5. **转发数**：
    - 有人转发 = 认可你的理念

## 🚨 常见问题（宝宝帮你提前避坑）

### Q1：我不会做水墨动画怎么办？

**A**：不用做！用醒图的"AI绘画"，输入"水墨风格"，自动生成。或者直接用图文视频，效果也很好。

### Q2：我普通话不标准，能配音吗？

**A**：能！真实感比标准更重要。你是退役军人，有点口音反而真实。实在不行就用剪映的AI配音。

### Q3：第1集发了没人看怎么办？

**A**：正常。新号前3条视频流量都很小。继续发，第3-5集会起来。抖音算法需要时间了解你。

### Q4：有人骂我怎么办？

**A**：有争议是好事。回复时真诚一点："理解你的质疑，我也不知道能走多远。但我想试试。" 不要争吵，不要删评论（除非是辱骂）。

### Q5：5集发完了，接下来发什么？

**A**：看数据。哪集火了，就围绕那个主题深挖。比如第4集"三大灾难"火了，就做"灾难系列"的深度解析。

### Q6：我想真人出镜，但不知道怎么拍？

**A**：最简单的方法：

- 手机架在桌上（或买个9块9的手机支架）
- 背景：书架或窗户（有光就行）
- 穿着：整洁就行，不用正式
- 看着镜头，自然说话
- 不用一次录完，分段录，剪映拼起来
