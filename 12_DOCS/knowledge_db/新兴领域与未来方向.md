### 7. 漫反射 (Diffuse Reflection)

- **知识卡片ID**: 140 | **状态**: ❌ 未接入 | **核心**: 🔴 底座（必须） | **层级**: 🧱 Core（宇宙规则层）
- **dr·五行·宫位**: dr=4·木·巽宫 | **三色审计**: 🟢 通过 | **难度**: L1-L2 | **掌握**: - | **学习状态**: 学习中
- **人格路由**: P04·鲁班（技术落地） | **语境触发**: 漫反射 Lambert 余弦 法线 光照 磨砂
- **描述**: 📖 知识点概述
漫反射是计算机图形学中最基础的着色模型。当光线打到粗糙表面时，光向四面八方均匀散射，从任何角度看亮度都一样——这就是漫反射。它不依赖观察者位置，只取决于光线方向和表面法线的夹角。

🧠 核心原理
一句话记住：光越正对表面越亮——Lambert余弦定律：亮度=光强×cos(光线与法线夹角)

原理拆解：
第一层：Lambert漫反射模型——I_diffuse = k_d × I_light × max(0, N·L)
第二层：max(0, N·L)确保背面不受光——cos(θ)为负时取0
第三层：k_d是漫反射系数(0-1)，决定表面颜色
- **核心公式**: Lambert's Cosine Law: I = I₀ × cos(θ) = I₀ × max(0, N·L)
其中 N=表面法向量，L=指向光源的向量，θ=N与L的夹角
k_d=漫反射系数(RGB三个通道，[0,1])
最终颜色 = k_d × light_color × max(0, dot(N, L))
- **算法公式**: Lambert's Cosine Law: I = I₀ × cos(θ) = I₀ × max(0, N·L)
其中 N=表面法向量，L=指向光源的向量，θ=N与L的夹角
k_d=漫反射系数(RGB三个通道，[0,1])
最终颜色 = k_d × light_color × max(0, dot(N, L))
- **常见误区**: 误区1：漫反射=物体本身的颜色——不对，漫反射是光与表面交互的结果。同样红色球在蓝光下看起来是黑的（没有红色光可反射）
误区2：N·L不需要归一化——必须归一化！没归一化的点积不等于cos(θ)，会导致错误亮度
误区3：max(0, N·L)可省略——不能省，否则背面会'负亮度'导致黑斑或异常色块
- **实践项目**: 用Python+NumPy写一个简单球体渲染器，只使用漫反射模型，输出PPM图像——观察单光源下球体的明暗过渡
在Unity/Unreal中创建一个纯漫反射材质（金属度=0，高光=0），切换不同颜色光源观察效果
用Blender的Shader Editor连接Diffuse BSDF节点，理解N·L的可视化表达
- **DNA追溯**: #龍芯⚡️20260701063110641896-NOTION-6bd17241-7e50-4a2f-9286-299fe8a09178-FA953C6E
- **PY代码示例**:
```python
# 漫反射 (Diffuse Reflection) - Lambert 模型
import numpy as np

def lambert_diffuse(normal, light_dir, light_color, diffuse_coeff):
    """兰伯特漫反射计算"""
    N = normal / np.linalg.norm(normal)
    L = light_dir / np.linalg.norm(light_dir)
    NdotL = max(0.0, np.dot(N, L))
    return diffuse_coeff * light_color * NdotL

# 示例：红色表面，白光从正上方照射
normal = np.array([0.0, 1.0, 0.0])
light_dir = np.array([0.0, -1.0, 0.0])
light_color = np.array([1.0, 1.0, 1.0])
k_d = np.array([1.0, 0.0, 0.0])
result = lambert_diffuse(normal, light_dir, light_color, k_d)
print(f"漫反射: RGB({result[0]:.2f}, {result[1]:.2f}, {result[2]:.2f})")
```

- **知识卡片ID**: 134 | **状态**: ❌ 未接入 | **核心**: 🔴 底座（必须） | **层级**: 📦 Application（应用层）

- **描述**: 📖 知识点概述
灯光是3D渲染中模拟光源照射场景的技术。没有灯光，所有物体都是黑的。现实世界的光极其复杂（全局光照、焦散、散射），实时渲染中我们用简化的灯光模型来近似。

🧠 核心原理
一句话记住：灯光 = 环境光(ambient) + 漫反射(diffuse) + 镜面高光(specular) —— Phong模型三件套，几乎所有实时渲染灯光都基于这个框架

原理拆解：
第一层：环境光(Ambient)——模拟'到处都有一点点光'，防止阴影区全黑
第二层：漫反射(Diffuse)——光与粗糙表面的交互，Lambert定律
第三层：镜面反射(Specular)——光滑表面的高光点
- **核心公式**: Phong光照模型: I = ambient + diffuse + specular
  = k_a·I_a + Σ[k_d·I_light_i·max(0,N·L_i) + k_s·I_light_i·max(0,R_i·V)^n]

Blinn-Phong优化（用半角向量H代替反射向量R，更快）:
  specular = k_s·I_light·max(0, N·H)^n, H=normalize(L+V)

灯光类型：平行光(太阳)·点光源(灯泡)·聚光灯(手电筒)
- **算法公式**: Phong光照模型: I = ambient + diffuse + specular
  = k_a·I_a + Σ[k_d·I_light_i·max(0,N·L_i) + k_s·I_light_i·max(0,R_i·V)^n]

Blinn-Phong优化（用半角向量H代替反射向量R，更快）:
  specular = k_s·I_light·max(0, N·H)^n, H=normalize(L+V)

灯光类型：平行光(太阳)·点光源(灯泡)·聚光灯(手电筒)
- **常见误区**: 误区1：只看漫反射忘了环境光——没有环境光，背光面全黑，现实中光会弹射到暗面
误区2：Phong和Blinn-Phong分不清——Phong用反射向量R·V，Blinn-Phong用半角向量N·H，后者更快更常用
误区3：高光指数n随便设——n=1像橡胶，n=32像塑料，n=256像金属，选错材质质感全毁

- **DNA追溯**: #龍芯⚡️20260701063120326354-NOTION-9cb7cfa9-9c4b-4fe8-b6f7-43aa090da29c-6B1B5336

```python
# 灯光 (Lighting) - Phong 光照模型
import numpy as np

def phong_lighting(normal, view_dir, light, material):
    """Phong光照模型: ambient + diffuse + specular"""
    N = normal / np.linalg.norm(normal)
    V = view_dir / np.linalg.norm(view_dir)
    # 环境光
    ambient = material['ambient'] * light['ambient_color']
    # 漫反射
    L = light['dir'] / np.linalg.norm(light['dir'])
    NdotL = max(0.0, np.dot(N, L))
    diffuse = material['diffuse'] * light['color'] * NdotL
    # 镜面高光 (Phong)
    R = 2 * N * NdotL - L
    RdotV = max(0.0, np.dot(R/np.linalg.norm(R), V))
    specular = material['specular'] * light['color'] * (RdotV**material['shininess'])
    return ambient + diffuse + specular
```
