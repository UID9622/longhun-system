## 二、升级目标

**一个入口、一套逻辑、开机自动、状态可见。**

- 统一启动器管理所有常驻服务
- 开机自动只跑必要服务
- 双击桌面一个入口即可看状态/启动/停止
- 不删旧文件，但统一收口到新入口

---

## 三、核心交付物

### 1. 龍魂统一启动器
- **文件**: `bin/longhun-launcher.py`
- **功能**:
  - 注册所有常驻服务
  - 检测端口占用，避免重复启动
  - 按依赖顺序启动/停止
  - 生成 JSON 状态报告
  - 支持 `start` / `stop` / `restart` / `status`

### 2. 开机自启动脚本
- **文件**: `bin/longhun-autostart.sh`
- **作用**: 被 LaunchAgent 调用，统一交给 `longhun-launcher.py --autostart`

### 3. macOS LaunchAgent
- **文件**: `~/Library/LaunchAgents/com.uid9622.longhun.autostart.plist`
- **行为**: 用户登录时自动运行 `longhun-autostart.sh`
- **策略**: `KeepAlive` 仅在崩溃/异常退出时重启，避免无限重启

### 4. 状态看板
- **文件**: `bin/longhun-status.py`
- **桌面入口**: `Desktop/龍魂状态与启动.command`

### 5. 保留的原有入口
- `龍魂主开关.app` — 功能菜单（不变）
- `龍魂控制中心.app` — GUI 控制中心（不变）
- `龍碼中文編輯器.app` — 编辑器启动器（不变）

## 五、使用方法

### 1. 终端命令

```bash
cd ~/longhun-system

# 查看状态
python3 bin/longhun-status.py

# 启动全部常驻服务
python3 bin/longhun-launcher.py start

# 开机自动模式（只启动 autostart=True 的服务）
python3 bin/longhun-launcher.py start --autostart

# 停止全部
python3 bin/longhun-launcher.py stop

# 重启全部
python3 bin/longhun-launcher.py restart
```

### 2. 桌面双击

双击 `Desktop/龍魂状态与启动.command`，弹出菜单：
- 📊 查看状态
- ▶️ 启动服务
- 🔄 重启服务
- ⏹️ 停止服务
- 📜 查看启动日志
- 🧠 打开龍魂控制中心

### 3. 开机自动

由 `com.uid9622.longhun.autostart.plist` 管理，无需手动干预。

## 八、后续建议

1. **如需增加服务**：修改 `bin/longhun-launcher.py` 顶部的 `SERVICES` 列表即可
2. **如需取消开机自动**：
   ```bash
   launchctl unload ~/Library/LaunchAgents/com.uid9622.longhun.autostart.plist
   ```
3. **如需重新加载**：
   ```bash
   launchctl load ~/Library/LaunchAgents/com.uid9622.longhun.autostart.plist
   ```
4. **旧 `.disabled` plist 清理**：可手动删除 `~/Library/LaunchAgents/*.disabled` 中已废弃的条目
