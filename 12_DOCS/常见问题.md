# 🐉 longhun-cli 常见问题 FAQ

> 配套: `longhun-cli 4.0.0` · 协议: `docs/对外接口协议-v1.0.md` · 三色标记: 🟢已实测 / 🟡环境相关 / 🔴风险
> 本文持续维护：每次更新覆盖原有解决方案（保留最近一次有效解法）。

## 1. 安装时报 `command not found: lh` 🟢

**原因**: `lh` 可执行脚本不在 PATH 中。

**解决**:

```bash
# 查看安装位置
python3 -m pip show -f longhun-cli | grep -E "Location|lh"

# 把 bin 目录加入 PATH（临时）
export PATH="$HOME/.local/bin:$PATH"        # macOS/Linux
# Windows: C:\Users\<你>\AppData\Roaming\Python\Scripts

# 永久写入 shell 配置
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

# 或不用 PATH，直接模块调用（永远可用）
python3 -m longhun_cli.cli version
```

> 🔴 若 `pip show -f longhun-cli` 无结果 → 安装失败，重装：`pip install --force-reinstall longhun-cli`。

## 2. 运行时提示 `LONGHUN_ROOT not set` 🟡

**原因**: 薄壳双态设计——外部态（未设 `LONGHUN_ROOT`）只提供零依赖基础命令；需要系统全量逻辑时须指定源码树。

**解决**（二选一）:

```bash
# 方案 A：就够用 → 外部态直接跑
lh flow "龙魂对外首发" --json    # 零依赖可用
lh bazi --date 1990-01-01 --time 08:00 --json

# 方案 B：需要系统态 → 指向龍魂源码树
export LONGHUN_ROOT=~/longhun-system
lh health --json   # 自动透传系统内全量 15 项健康检查
```

> 说明: 未设置时 `health` 为基础自检（`root_detected: false`）；设置后为系统全量。路径必须含 `bin/lh.py` 才算有效。

## 3. 网关 9622 端口被占用 🟡

**原因**: 已有旧网关实例在运行，或其他进程占用。

**解决**:

```bash
# 1. 查占用
lsof -i :9622
# 2a. 若是旧网关 → 停掉
kill $(cat ~/.longhun/gateway.pid 2>/dev/null) || true
# 2b. 若其它进程占用 → 换端口启动
python3 08_BIN/lh_api.py --port 9623 --daemon
# 3. 验证
curl -s http://127.0.0.1:9623/health
```

> 换端口后，`/v1/lh` 地址同步变为 `http://127.0.0.1:9623/v1/lh`。

## 4. GPG 签名验证失败 🟡

**现象**: `gpg --verify xxx.asc xxx` 报 `No public key` 或 `BAD signature`。

**原因**: 公钥未导入本机（最常见）。

**解决**:

```bash
# 1. 导入龍魂公钥（发布物随附 lh_public_key.asc）
gpg --import lh_public_key.asc

# 2. 重新验证
gpg --verify dist/longhun_cli-4.0.0-py3-none-any.whl.asc dist/longhun_cli-4.0.0-py3-none-any.whl
# 应输出: 完好的签名，来自于 "诸葛鑫（UID9622）"

# 3. 临时跳过验证（仅信任来源时）
pip install dist/longhun_cli-4.0.0-py3-none-any.whl
```

> 🔴 若导入公钥后仍 `BAD signature` → 文件被篡改/下载不完整，**不要安装**，重新下载并核验 SHA256。

## 5. bazi 排盘结果与预期不符 🟢

**原因**: 多数为输入格式或排盘口径问题。

**解决**（逐项校验）:

```bash
# 1. 日期/时间格式必须严格 YYYY-MM-DD / HH:MM
lh bazi --date 1990-1-1 --time 8:00 --json     # ❌ 缺前导零
lh bazi --date 1990-01-01 --time 08:00 --json  # ✅ 正确

# 2. 确认当前时间（不传参时用当前时刻）
lh te --stamp

# 3. 口径说明（与系统 CIL v4.0 对齐）
#    · 年柱以公历年计（立春分界为近似，精确版用系统 lh_cil.py）
#    · 日柱基准 1900-01-01 = 甲戌
#    · 时支子时 = 23:00-01:00（23:30 算次日子时）

# 4. 对拍标准结果（此输入为基准样例）
lh bazi --date 1990-01-01 --time 08:00 --json | python3 -c "
import sys, json
d = json.load(sys.stdin)
assert d['bazi'] == '庚午 戊寅 丙寅 壬辰', d['bazi']
print('✅ 口径一致:', d['bazi'])"
```
