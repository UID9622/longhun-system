## ⚙️ 查询引擎
技术规格：Python 3.8+ | 零外部依赖 | 标准库only
### 5个kg命令
```bash
kg list [--type TYPE] [--layer LAYER]     # 列出节点
kg show <node_id>                          # 显示详情+关联
kg path <source> <target>                  # BFS路径查找
kg state <node_id>                         # 状态历史
kg export [--output PATH] [--layer LAYER]  # Mermaid导出
```
### Python API
```python
from queries.longhun_kg import LongHunGraph
g = LongHunGraph("~/.龍魂/knowledge-graph")
g.list_nodes(layer="sovereignty")
g.find_path("term_001", "audit_red")
g.export_mermaid("output.mmd")
```
