## 🖥️ 7.3 界面布局
### Notion页面设计规范
层级控制：
- 📄 顶层： 导航栏 + 标题 + 快速入口
- 📁 第二层： 折叠块（模块化内容）
- 📝 第三层： 详细内容（不再嵌套）
蜘蛛网状连接：
```javascript
中心节点（主页）
    ↓ ← → ↑
子节点1 ←→ 子节点2 ←→ 子节点3
    ↓ ← → ↑        ↓ ← → ↑
  详细页   ←→    详细页
```
避免树状结构：
❌ 不要：主页 → 分类 → 子分类 → 详细页（太深）
✅ 要：主页 ←→ 功能页（横向连接）

## 🎨 7.4 UI炼金术师指南
### 设计检查清单
每个页面必须满足：
- ✅ 视觉清晰（3秒内找到重点）
- ✅ 交互流畅（点击不超过3次）
- ✅ 色彩协调（不超过5种主色）
- ✅ 字体统一（标题/正文/代码）
- ✅ 留白充分（不要挤满屏幕）
- ✅ 移动友好（手机也能看）
