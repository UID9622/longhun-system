# 🚀 快速开始指南
---
## 📦 方式一：NPM安装（推荐）
### 1. 安装依赖
```bash
npm install @uid9622/notion-mcp
# 或
yarn add @uid9622/notion-mcp
```
### 2. 配置环境变量
```bash
# .env
NOTION_TOKEN=your_notion_integration_token
NOTION_DATABASE_ID=your_database_id
```
### 3. 第一个调用
```javascript
const { NotionMCP } = require('@uid9622/notion-mcp');

const client = new NotionMCP({
  token: process.env.NOTION_TOKEN
});

// 查询数据库
async function demo() {
  const pages = await client.databases.query({
    database_id: process.env.NOTION_DATABASE_ID,
    filter: {
      property: '状态',
      select: { equals: '进行中' }
    }
  });
  
  console.log('找到', pages.results.length, '条记录');
}

demo();
```
运行：
```bash
node demo.js
```
✅ 成功！ 如果看到输出，说明已经跑通了。

## 🆘 常见问题
### Q1: Token怎么获取？
1. 访问 https://www.notion.so/my-integrations
1. 创建新集成
1. 复制 Internal Integration Token
1. 在数据库页面右上角"..." → "Add connections" → 选择你的集成
### Q2: 为什么查询不到数据？
检查：
- ✅ 集成已添加到数据库
- ✅ database_id 正确（32位字符串）
- ✅ Token有效
### Q3: 中文分词不准确？
```javascript
// 使用自定义词典
client.nlp.loadDict([
  '龍魂价值观',
  '三层太极',
  'UID9622'
]);
```
