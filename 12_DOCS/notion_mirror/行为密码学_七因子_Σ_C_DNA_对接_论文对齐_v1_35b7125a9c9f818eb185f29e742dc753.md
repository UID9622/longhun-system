## Definition 3.2 — Behavioral Signature Σ(C)
内容制品 C 的行为签名为七元组：
```javascript
Σ(C) = (F1(C), F2(C), F3(C), F4(C), F5(C), F6(C), F7(C))
```
每个 Fi(C) ∈ [0, 1] 为第 i 个因子的置信度得分。
### 七因子（与论文表一致）
- F1 Identity DNA — Cryptographic identity binding — GPG signature, UID anchor
- F2 Temporal Anchor — Temporal consistency — Trusted timestamps, session logs
- F3 Rule Trace — Documented transformation rules — Rule logs, diff history
- F4 Persona Route — Authorial persona consistency — Persona spec, style baseline
- F5 Protected Lexicon — Creator-specific vocabulary — Private lexicon
- F6 Style Vector — Stylistic fingerprint — Syntactic patterns, structural habits
- F7 Mistake Ledger — Error pattern authenticity — Corrections, revision history
## Definition 3.3 — Verification Oracle V(Σ, E)
V(Σ, E) → (conf, evidence)，其中 conf ∈ [0,1]。
归一化权重 ∑w_i=1 时，加权几何平均：
```javascript
conf = ∏_{i=1}^{7} s_i^{w_i}
```
s_i = Fi(C) 若 Fi(C)>0；否则 hard failure 时 s_i = 0。
阈值 τ：标准 0.85 · 高安全 0.95（论文）。
## Definition 3.4 — Hard Failure
若 ∃i : Fi(C)=0，则 conf = 0（不可被其他因子补偿）。
