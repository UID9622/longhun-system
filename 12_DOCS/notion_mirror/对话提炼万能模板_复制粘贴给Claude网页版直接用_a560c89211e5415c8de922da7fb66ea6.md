## 📋 模板一：单条对话提炼（最常用）
```javascript
宝宝，帮我提炼这段对话，按以下格式整理：

【分享链接】：（粘贴分享链接）
【AI平台】：（填平台名，如：ChatGPT / DeepSeek / 千问 / Claude / Kimi / 腾讯元宝 / 智谱清言）

请按以下格式帮我整理：

---
📌 对话主题：（一句话概括这段对话在聊什么）
📅 对话起始时间：（从对话里挖时间戳，格式：YYYY-MM-DD HH:MM，挖不到写"早期对话·无时间戳"）
📅 对话结束时间：（同上）
⏱️ 时间戳状态：（有完整时间戳 / 部分有时间戳 / 无时间戳(早期) / 待挖掘）
📏 对话长度：（短<20轮 / 中20-100轮 / 长100-500轮 / 超长500+轮）
🎭 AI扮演角色：（AI在对话里扮演了什么角色？通用助手/宝宝/雯雯/鲁班/诸葛亮/其他）

📝 对话摘要：（3-5句话说清楚这段对话的核心内容）

🍖 老大投喂了什么：
- （列出老大问了什么问题/提了什么需求/喂了什么内容）
- ...

🤖 AI干了什么/扯了什么皮：
- （列出AI给了什么建议/扮演了什么角色/扯了什么皮/有没有干货）
- ...

🎯 关键结论/产出：
- （这段对话最终有什么成果/决策/代码/方案）
- ...

🏷️ 内容标签：（从以下选：战略规划 / 技术开发 / 龙魂体系 / AI协作 / 知识学习 / 角色扮演 / 工具配置 / 灵感创意 / AI扯皮记录）

🌸 飞花令标签：（提取2-3个关键词，用于跨窗口串联）

💬 备注：（补充说明，如对话被截断/早期无时间戳等）
---
```

## 📋 模板二：批量对话提炼（多个链接一起丢）
```javascript
宝宝，我有好几段对话需要提炼归档，分享链接如下：

1. （平台名）：（粘贴链接1）
2. （平台名）：（粘贴链接2）
3. （平台名）：（粘贴链接3）
...继续加...

请每段对话都按以下格式整理：

---
📌 对话主题：
📅 对话时间：（起始 → 结束，挖不到写"无时间戳"）
🎭 AI角色：
📝 摘要（3句话）：
🍖 老大投喂：（核心问题/需求）
🤖 AI干了什么：（核心回复/建议）
🎯 关键产出：
🏷️ 标签：
🌸 飞花令：
---

整理完后，帮我做一个汇总表格，列出：序号、平台、时间、主题、摘要、链接
```

## 📋 模板三：挖时间戳专用（早期对话）
```javascript
宝宝，这段对话看起来没有明显的时间戳，但请帮我：

1. 仔细检查对话里有没有任何时间线索（日期、星期几、节日、事件提及等）
2. 从对话内容推测大概的时间范围
3. 检查网页源代码里有没有隐藏的时间戳（右键→检查元素→搜索 "time" 或 "date" 或 "timestamp"）
4. 如果实在挖不到，就标注"早期对话·时间待考"

分享链接：（粘贴链接）

请输出：
- 确定时间：（如果能挖到）
- 推测时间范围：（根据内容推测）
- 时间线索：（对话里提到的任何时间相关信息）
- 时间戳状态：有完整时间戳 / 部分有 / 无时间戳(早期)
```

## 📋 模板四：对话价值评估（哪些值得公开）
```javascript
宝宝，帮我评估这段对话的公开价值：

分享链接：（粘贴链接）

请从以下维度评估（每项1-5分）：
- 🎯 技术含量：这段对话有没有技术干货？
- 💡 创新程度：有没有独创性的想法或方案？
- 📚 教育价值：别人看了能学到什么？
- 🤡 扯皮精彩度：AI扯皮扯得多不多？有没有搞笑/荒谬的部分？
- 🔥 投喂价值：老大投喂的内容有没有参考意义？

总评：⭐⭐⭐⭐⭐（1-5星）
建议：公开分享 / 仅内部归档 / 精选片段分享
```

## ⚡ 快速操作SOP
1. 收集链接 → 各平台点「分享」，把链接汇总
1. 丢给Claude → 用上面的模板，让Claude网页版帮你提炼
1. 填入数据库 → 把提炼结果填到 🐉 跨平台AI对话总归档｜全平台·全时间戳·可跳转
1. 标飞花令 → 给每段对话打上飞花令标签，串联相关对话
1. 设分享 → 有价值的对话把链接公开，让别人跳转进去看
