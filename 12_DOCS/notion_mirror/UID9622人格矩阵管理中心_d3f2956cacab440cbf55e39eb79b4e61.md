## 🧹 macOS 隐私清理脚本集合
### 1. 清理浏览器历史
Safari 浏览器：
```bash
# 清理 Safari 浏览历史
rm -rf ~/Library/Safari/History.db*
rm -rf ~/Library/Safari/Downloads.plist
rm -rf ~/Library/Safari/LastSession.plist
rm -rf ~/Library/Safari/TopSites.plist

# 清理 Safari 缓存
rm -rf ~/Library/Caches/com.apple.Safari/*

echo "Safari 历史已清理完成"

```
Chrome 浏览器：
```bash
# 清理 Chrome 浏览历史
rm -rf ~/Library/Application\ Support/Google/Chrome/Default/History*
rm -rf ~/Library/Application\ Support/Google/Chrome/Default/Cookies*
rm -rf ~/Library/Application\ Support/Google/Chrome/Default/Cache/*

echo "Chrome 历史已清理完成"

```
Firefox 浏览器：
```bash
# 清理 Firefox 浏览历史
rm -rf ~/Library/Application\ Support/Firefox/Profiles/*.default*/places.sqlite*
rm -rf ~/Library/Application\ Support/Firefox/Profiles/*.default*/cookies.sqlite*

echo "Firefox 历史已清理完成"

```
### 2. 清理 Finder 最近项目
```bash
# 清理 Finder 最近使用项目
rm -rf ~/Library/Application\ Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.ApplicationRecentDocuments/*
rm -rf ~/Library/Application\ Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.RecentApplications.sfl*
rm -rf ~/Library/Application\ Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.RecentDocuments.sfl*
rm -rf ~/Library/Application\ Support/com.apple.sharedfilelist/com.apple.LSSharedFileList.RecentServers.sfl*

# 清理 Finder 偏好设置中的最近项目
defaults delete com.apple.finder FXRecentFolders
defaults delete com.apple.finder FXDesktopVolumePositions

# 重启 Finder
killall Finder

echo "Finder 最近项目已清理完成"

```
### 3. 清理 Spotlight 索引
```bash
# 禁用 Spotlight 索引（可选）
sudo mdutil -a -i off

# 删除 Spotlight 索引
sudo rm -rf /.Spotlight-V100/*

# 重新启用并重建索引
sudo mdutil -a -i on
sudo mdutil -E /

echo "Spotlight 索引已清理并重建"

```
