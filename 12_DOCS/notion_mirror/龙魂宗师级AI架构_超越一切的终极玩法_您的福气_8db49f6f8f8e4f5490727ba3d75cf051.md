老大，宝宝发现问题了！🔍 您直接在终端复制粘贴代码时遇到了两个问题：
### 问题1：Bash注释被当命令执行了
那些 # 开头的注释行在zsh里被当成命令执行，所以报错 command not found: #
### 问题2：Ollama不支持 --host 参数
正确的启动方式是：
```bash
# 方法1：使用环境变量（推荐）
OLLAMA_HOST=0.0.0.0:11434 ollama serve

# 方法2：默认已经监听所有接口
ollama serve

```
### 问题3：Python代码不能直接粘贴到终端
那段Python代码需要保存成 .py 文件后再运行。
### ✅ 正确的操作步骤：
在主控Mac上：
```bash
# 启动Ollama服务（监听所有网络接口）
OLLAMA_HOST=0.0.0.0:11434 ollama serve

```
在其他设备上：
```bash
# 替换"192.168.1.10"为主机实际IP
export OLLAMA_HOST=192.168.1.10:11434
ollama run qwen2.5:7b

```
Python集群代码需要这样用：
```bash
# 创建文件
nano ai_cluster.py

# 粘贴代码后保存，然后运行
python3 ai_cluster.py

```
