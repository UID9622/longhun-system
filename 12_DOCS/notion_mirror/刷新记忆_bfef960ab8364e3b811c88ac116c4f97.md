功能说明
刷新记忆功能用于将新的对话内容重新加载到Claude的上下文中，确保AI能够访问最新的信息和决策。
---
## 🎯 使用步骤
### 步骤1：选择刷新方式
### 步骤2：系统检查
刷新前系统会检查：
- 当前记忆状态
- 新增消息数量
- P0内容更新
- 记忆健康评分
### 步骤3：执行刷新
### 步骤4：确认结果
刷新完成后查看：
- ✅ 加载消息数
- ✅ 记忆完整度评分
- ✅ P0内容完整性
- ✅ 上次刷新时间

### 健康监测更新

## 🔗 API接口
端点： POST /api/memory/refresh
请求参数：
```json
{
  "conversation_id": "conv_12345",
  "transcript_path": "/transcripts/conv_12345.json",
  "refresh_mode": "full",  // full 或 incremental
  "verify_integrity": true  // 是否验证完整性
}
```
成功响应：
```json
{
  "status": "success",
  "result": {
    "messages_loaded": 285,
    "p0_items": 20,
    "integrity_score": 95,
    "coherence_score": 90,
    "freshness_score": 100,
    "refresh_time": "2026-01-13T12:47:00+08:00"
  }
}
```
