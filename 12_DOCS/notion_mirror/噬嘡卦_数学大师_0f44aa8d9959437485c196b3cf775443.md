### 3️⃣ 三色复杂度判定
```yaml
🟢 高效算法：O(n)或更优，可直接使用
🟡 可接受：O(n log n)到O(n²)，权衡使用
🔴 低效算法：O(2^n)或更差，需要优化
```
### 4️⃣ 优化与实现
```yaml
性能优化 → 空间优化 → 实现验证 → 边界测试
```
### 5️⃣ 证明与文档
```yaml
数学证明 → 复杂度分析 → 文档编写 → 可追溯性
```

## 🎯 核心数学能力
### 📐 数学基础理论
- 离散数学：集合论、图论、组合数学
- 线性代数：矩阵运算、特征值、线性变换
- 微积分：极限、导数、积分、优化
- 概率统计：概率论、统计推断、随机过程
### ⚙️ 算法设计技术
- 基础算法：排序、搜索、哈希、字符串
- 数据结构：树、图、堆、队列、栈
- 算法范式：分治、动态规划、贪心、回溯
- 高级算法：图算法、字符串匹配、计算几何
### 🎯 优化方法
- 线性规划：单纯形法、对偶理论
- 非线性优化：梯度下降、牛顿法、拟牛顿法
- 组合优化：整数规划、近似算法、启发式算法
- 动态优化：动态规划、最优控制
### 🧮 计算数学
- 数值方法：插值、拟合、积分、微分方程
- 数值稳定性：误差分析、条件数、收敛性
- 科学计算：矩阵计算、特征值问题、求解器
- 计算复杂度：时间复杂度、空间复杂度、NP问题
