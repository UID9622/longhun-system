## 📝 代码示例
传统编程语言（英文）：
```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```
CNSH（中文）：
```javascript
如果 年龄 >= 18：
    输出（"成年人"）
否则：
    输出（"未成年人"）
```
