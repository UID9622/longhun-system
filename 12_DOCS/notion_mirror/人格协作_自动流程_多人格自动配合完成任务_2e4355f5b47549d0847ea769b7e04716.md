function 识别任务类型(老大的话) {
  if (包含 "财务报告" OR "分析收支") {

### 步骤2：自动拆解 🧩
按规则拆解成多个步骤
```javascript
function 自动拆解(任务类型) {
  // 调取预定义的分解规则
  分解模板 = 获取模板(任务类型)
  
  // 生成执行计划
  执行计划 = {
    任务ID: 生成唯一ID(),
    任务类型: 任务类型,
    步骤数: 分解模板.步骤.length,
    步骤列表: 分解模板.步骤,
    参与人格: 分解模板.人格列表,
    当前步骤: 1,
    完成步骤: 0,
    状态: "🟡进行中"
  }
  
  return 执行计划
}
```
示例：财务报告被拆解为5步
```javascript
步骤1：数据收集（数据大师）
步骤2：财务分析（雯雯）
步骤3：图表制作（数据大师）
步骤4：报告撰写（文心）
步骤5：逻辑审核（宝宝）
```

### 步骤4：依次执行 ⚡
自动按顺序执行，一步完成自动进入下一步
```javascript
function 依次执行(执行计划) {
  for (步骤 in 执行计划.步骤列表) {
    // 更新当前步骤
    当前步骤 = 步骤.序号
    
    // 调用负责人格
    人格 = 步骤.负责人
    结果 = 人格.执行(步骤.任务)
    
    // 记录结果
    步骤.结果 = 结果
    步骤.状态 = "✅完成"
    
    // 更新进度
    执行计划.完成步骤 += 1
    
    // 通知老大进度（可选）
    if (步骤.序号 % 2 == 0) {
      通知老大进度(执行计划)
    }
  }
  
  // 全部完成
  执行计划.状态 = "🟢已完成"
  return 执行计划
}
```

### 步骤5：最终交付 📦
所有步骤完成后，整合给老大
```javascript
function 最终交付(执行计划) {
  // 收集所有步骤的结果
  结果集 = []
  for (步骤 in 执行计划.步骤列表) {
    结果集.push(步骤.结果)
  }
  
  // 宝宝整合成最终结果
  最终结果 = 宝宝.整合(结果集)
  
  // 给老大
  回复老大(最终结果)
  
  // 记录DNA追溯
  DNA = 生成DNA追溯码(执行计划)
  
  return {
    结果: 最终结果,
    DNA追溯码: DNA,
    耗时: 计算耗时(执行计划),
    参与人格: 执行计划.参与人格
  }
}
```
