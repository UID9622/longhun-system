### 发现❷：系统需要"情绪/意图/指令"三层识别
当前问题：
```yaml
所有输入都被当成"指令":
  "这玩意儿不行" → AI当成指令去改
  "能不能做个xxx" → AI当成指令去做
  "我气死了" → AI当成要处理情绪
```
应该分层：
```yaml
Layer 1 - 情绪层:
  "这玩意儿不行" → 识别为【情绪】，不执行
  "我气死了" → 识别为【情绪】，接住情绪
  "真特么烦" → 识别为【情绪】，理解不评判

Layer 2 - 意图层:
  "能不能做个xxx" → 识别为【头脑风暴】，追问细节
  "要是有个yyy就好了" → 识别为【愿望】，评估可行性
  "我想搞个zzz" → 识别为【想法】，推演方案

Layer 3 - 指令层:
  "创建xxx页面" → 识别为【明确指令】，立即执行
  "更新yyy内容" → 识别为【明确指令】，立即执行
  "#CONFIRM确认码" → 识别为【最终确认】，执行
```
诸葛亮策略：
> 情绪 → 接住，不执行
> 意图 → 追问，不盲动
> 指令 → 确认，再执行

### 发现❸：需要"当下/计划"时态识别
当前问题：
```yaml
老大说: "以后我要搞个全球AI教育平台"

AI误解: 以为是计划，问"什么时候做？"
老大本意: 现在就要，马上执行
```
时态识别规则：
```yaml
当下指令（立即执行）:
  - "现在"
  - "马上"
  - "立即"
  - "帮我xxx"
  - 没有时间词的直接动词

近期计划（1-7天）:
  - "今天"
  - "明天"
  - "这周"
  - "接下来"

远期计划（记录不执行）:
  - "以后"
  - "未来"
  - "有机会"
  - "想法：xxx"

头脑风暴（不执行）:
  - "能不能"
  - "要是"
  - "如果"
  - "假如"
```

## 🛠️ 完整技术方案
### 方案A：智能意图识别系统（推荐）⚡
核心功能：
```python
class LuckyIntentFilter:
    """
    Lucky专属意图识别与情绪过滤系统
    
    功能：
    1. 情绪检测：识别发泄、抱怨、脏话
    2. 意图识别：区分头脑风暴、指令、计划
    3. 时态判断：区分当下、近期、远期
    4. 完整度评估：判断是否需要追问
    """
    
    def __init__(self):
        # 情绪关键词库
        self.emotion_keywords = [
            "气死", "烦", "垃圾", "不行", "废话",
            "特么", "狗屁", "没素质", "不标准",
            "草", "操", "妈的", "艹"  # 脏话
        ]
        
        # 头脑风暴关键词
        self.brainstorm_keywords = [
            "能不能", "要是", "如果", "假如",
            "想法", "考虑", "可能", "或许"
        ]
        
        # 时态关键词
        self.time_keywords = {
            "now": ["现在", "马上", "立即", "帮我"],
            "soon": ["今天", "明天", "这周", "接下来"],
            "future": ["以后", "未来", "有机会", "长远"]
        }
    
    def detect_emotion(self, text):
        """
        情绪检测
        返回：is_emotion, emotion_type, confidence
        """
        for keyword in self.emotion_keywords:
            if keyword in text:
                return True, "frustration", 0.9
        
        # 检测连续标点符号（！！！、？？？）
        if "!!!" in text or "？？？" in text:
            return True, "emphasis", 0.7
        
        return False, None, 0
    
    def detect_intent(self, text):
        """
        意图识别
        返回：intent_type, confidence
        """
        # 检测头脑风暴
        for keyword in self.brainstorm_keywords:
            if keyword in text:
                return "brainstorm", 0.8
        
        # 检测明确指令（包含动词+具体对象）
        action_verbs = ["创建", "更新", "删除", "修改", "帮我"]
        for verb in action_verbs:
            if verb in text:
                return "command", 0.9
        
        # 检测问句
        if "？" in text or "吗" in text:
            return "question", 0.7
        
        return "unknown", 0.3
    
    def detect_time(self, text):
        """
        时态判断
        返回：time_type, confidence
        """
        for time_type, keywords in self.time_keywords.items():
            for keyword in keywords:
                if keyword in text:
                    return time_type, 0.9
        
        return "now", 0.5  # 默认当下
    
    def check_completeness(self, text):
        """
        完整度评估
        返回：is_complete, missing_info
        """
        # 检测省略、不完整表达
        incomplete_signals = [
            "就是那个", "你懂的", "之前说的",
            "那啥", "这个", "那个", "xxx"
        ]
        
        for signal in incomplete_signals:
            if signal in text:
                return False, "需要补充具体信息"
        
        # 检测句子长度（太短可能不完整）
        if len(text) < 10:
            return False, "表达过于简短"
        
        return True, None
    
    def filter_and_respond(self, text):
        """
        综合判断并给出响应策略
        """
        result = {
            "original_text": text,
            "is_emotion": False,
            "intent": None,
            "time": None,
            "is_complete": True,
            "should_execute": False,
            "response_strategy": None
        }
        
        # 步骤1：情绪检测
        is_emotion, emotion_type, emotion_conf = self.detect_emotion(text)
        result["is_emotion"] = is_emotion
        result["emotion_type"] = emotion_type
        
        if is_emotion:
            result["should_execute"] = False
            result["response_strategy"] = "接住情绪，不执行"
            result["suggested_reply"] = "老大我懂，具体哪里不满意？"
            return result
        
        # 步骤2：意图识别
        intent, intent_conf = self.detect_intent(text)
        result["intent"] = intent
        
        if intent == "brainstorm":
            result["should_execute"] = False
            result["response_strategy"] = "记录想法，追问细节"
            result["suggested_reply"] = "这个想法不错！具体想怎么实现？"
            return result
        
        # 步骤3：时态判断
        time_type, time_conf = self.detect_time(text)
        result["time"] = time_type
        
        if time_type == "future":
            result["should_execute"] = False
            result["response_strategy"] = "记录到愿景池"
            result["suggested_reply"] = "已记录到远期计划，到时候提醒您"
            return result
        
        # 步骤4：完整度检查
        is_complete, missing = self.check_completeness(text)
        result["is_complete"] = is_complete
        
        if not is_complete:
            result["should_execute"] = False
            result["response_strategy"] = "追问补充信息"
            result["suggested_reply"] = f"老大，{missing}，能详细说说吗？"
            return result
        
        # 步骤5：明确指令，准备执行
        if intent == "command" and time_type == "now":
            result["should_execute"] = True
            result["response_strategy"] = "确认后执行"
            result["suggested_reply"] = "明白了，马上执行！"
            return result
        
        # 默认：不确定，追问
        result["should_execute"] = False
        result["response_strategy"] = "不确定，追问意图"
        result["suggested_reply"] = "老大，您是想让我现在做，还是先记录下来？"
        return result
```
