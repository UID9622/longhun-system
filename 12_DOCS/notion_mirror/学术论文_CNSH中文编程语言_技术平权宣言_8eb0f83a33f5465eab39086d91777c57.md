## 💻 代码示例
### Hello World 对比
C++版本：
```c++
#include <iostream>
int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```
CNSH版本：
```javascript
导入 <输出流>
函数 主程序() -> 整数 {
    输出 << "你好，世界！" << 换行;
    返回 0;
}
```
### 斐波那契对比
C++版本：
```c++
int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n-1) + fibonacci(n-2);
}
```
CNSH版本：
```javascript
函数 斐波那契(整数 数) -> 整数 {
    如果 (数 <= 1) 返回 数;
    返回 斐波那契(数-1) + 斐波那契(数-2);
}
```
### 面向对象编程
C++版本：
```c++
class Animal {
private:
    std::string name;
public:
    Animal(std::string n) : name(n) {}
    void speak() {
        std::cout << name << " makes a sound" << std::endl;
    }
};
```
CNSH版本：
```javascript
类 动物 {
私有:
    字符串 名字;
公开:
    构造(字符串 名) : 名字(名) {}
    函数 说话() {
        输出 << 名字 << " 发出声音" << 换行;
    }
};
```
