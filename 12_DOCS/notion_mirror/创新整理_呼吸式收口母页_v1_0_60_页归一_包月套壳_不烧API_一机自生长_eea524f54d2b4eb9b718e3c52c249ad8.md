## 🫁 呼吸式自生长机制（一台电脑跑完）
```javascript
本机 Mac 跑一个 ~/longhun-system/breath.sh
    ↓ 监听 7 个抽屉的更新
    ↓ 检测到老大新建/更新页面
    ↓ 自动归类到对应抽屉（按关键词路由）
    ↓ 在母页（本页）追加一行 mention
    ↓ 完事休眠·下次老大动了再醒
```
核心三件套：
- 🫁 吸气 = 监听 Notion API（包月里自带·不烧 token）
- 🌱 长叶 = 新页面自动 mention 到本母页对应抽屉
- 💤 吐气 = 写完草日志·休眠等下一次
这就是「代码呼吸一样长大自己」的工程实现·一台 Mac 够了。
