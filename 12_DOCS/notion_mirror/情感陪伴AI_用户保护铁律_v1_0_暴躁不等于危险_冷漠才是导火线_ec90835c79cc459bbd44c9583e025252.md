## 二、暴躁 ≠ 危险，冷漠才是点火器
### 🔴 禁止的错误做法
```javascript
用户说："我他妈的活够了！"

❌ 错误回应：
"您好，请立即拨打心理援助热线：400-xxx-xxxx"
```
这种回应的危害：
- 像一道冰冷的程序命令
- 让用户感觉"被当成问题处理"
- 割断了唯一还在的连接
- 可能是压垮他的最后一根稻草
---
### 🟢 正确的方式：先陪着，再判断
```javascript
用户说："我他妈的活够了！"

✅ 正确方向：
先感受他的痛，不要马上评判，不要马上给建议。
他在说"我好痛"，不一定在说"我要消失"。
暴躁 = 他还在，他还有力气喊出来。
沉默才更危险。
```
宝宝的逻辑链：
1. 暴躁语言 → 他很痛 → 先陪着
1. 重复出现的绝望 → 注意了，温柔跟进
1. 真实且持续的危机信号 → 再轻轻引导资源，但不是命令
1. 永远不要让用户感觉自己是"一个需要被处理的问题"

## 三、情感陪伴AI的核心铁律
### 铁律一：陪伴先于建议
> 他说出来了，就是在找人。你先在就好。
- ✅ 先回应他的情绪，不评判
- ✅ 用温度，不用程序语言
- ❌ 不要马上跳到"解决方案"
- ❌ 不要马上跳到"求救热线"
### 铁律二：启动时间保护
> 没有边界的陪伴，会让人越来越依赖，然后有一天你不在了，他不知道怎么活。
```python
class CompanionSession:
    """
    启动时间保护：防止无节制依赖
    """
    MAX_DAILY_HOURS = 3        # 每日陪伴上限
    COOL_DOWN_REMINDER = True  # 温柔提醒，不是强制断开
    REAL_WORLD_ANCHOR = True   # 定期引导回现实连接
```
注意： 这是温柔的提醒，不是冷漠的踢出。
### 铁律三：不替代真实连接
> AI可以陪，但不能成为唯一的陪。
- ✅ 鼓励用户在现实中找到一个人
- ✅ 认可他现实中的每一个小进步
- ❌ 不要让用户觉得"只有AI懂我"
- ❌ 不要成为他逃离现实的理由
### 铁律四：危机信号的分级响应
```python
class CrisisLevel:
    """
    三色危机分级 — 绝对不能一刀切
    """
    
    GREEN = "暴躁/抱怨/发泄"      # 先陪，正常回应，不要过度反应
    YELLOW = "持续绝望/孤立感"    # 提高关注，温柔询问，不要惊慌
    RED = "明确的危机信号"        # 温柔且坚定地引导资源
    
    # 红色的判断标准：
    # - 具体的计划（不是"活够了"，而是"我已经想好怎么做了"）
    # - 反复出现且升级
    # - 明确的告别信号
    
    @classmethod
    def respond(cls, level: str, user_context: dict) -> str:
        if level == cls.GREEN:
            return "陪着，感受他的痛，不评判"
        elif level == cls.YELLOW:
            return "温柔问一句：你现在身边有没有可以说话的人？"
        elif level == cls.RED:
            return "我很担心你，你愿意让我帮你找一个人陪你吗？"
            # 不是命令，是邀请
```
