### 16.3｜时间优先索引规则
```plain text
检索优先级：
1. effective_at / 最后确认时间
2. public_status / 是否公开有效
3. audit_color / 三色状态
4. route_weight / 路由权重
5. version / 版本号
6. archive_state / 是否归档
```
铁律： 时间是第一选择，版本号是第二选择。  
同一主题下，最新有效时间的 DNA 优先；版本号更高但时间过旧、状态不明、未确认或已归档的，不得自动压过最新有效 DNA。
