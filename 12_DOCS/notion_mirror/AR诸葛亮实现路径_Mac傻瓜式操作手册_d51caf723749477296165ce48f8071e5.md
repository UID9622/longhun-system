### Day 2-3: Mac开发环境搭建（2小时）
### 第一步：安装Homebrew（Mac的应用商店）
操作步骤：
1. 按 Command + 空格，输入"终端"，按回车
1. 复制下面这行代码（整行复制，一个字都不要漏）：
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
1. 粘贴到终端窗口，按回车
1. 会提示输入密码（就是你Mac的登录密码）
1. 输入密码时屏幕不会显示任何字符，这是正常的！输完按回车
1. 等待安装（大约5-10分钟）
✅ 验证成功：
- 终端最后显示"Installation successful!"
- 输入 brew --version 按回车，能看到版本号
### 第二步：安装Python（编程语言）
操作步骤：
1. 在终端输入：
```bash
brew install python3
```
1. 按回车，等待安装（3-5分钟）
✅ 验证成功：
- 输入 python3 --version 能看到类似 Python 3.11.x 的版本号
### 第三步：安装Unity Hub（AR开发工具）
操作步骤：
1. 打开浏览器，访问：https://unity.com/download
1. 点击绿色的"Download Unity Hub"按钮
1. 下载完成后，双击.dmg文件
1. 把Unity Hub拖到"应用程序"文件夹
1. 打开Unity Hub
1. 注册一个Unity账号（免费版就够用）
1. 在Unity Hub里安装Unity编辑器：
✅ 验证成功：
- Unity Hub里能看到已安装的Unity版本
- 点击"New Project"能创建新项目

### Step 3: 集成语音识别（1小时）
操作步骤：
1. 在Unity里，右键点击"Assets"文件夹
1. 选择"Create" > "C# Script"
1. 命名为 VoiceRecognition
1. 双击打开（会用VS Code或其他编辑器打开）
1. 删除里面所有内容
1. 复制下面的代码，粘贴进去：
```c#
using UnityEngine;
using System;
using System.Collections;

public class VoiceRecognition : MonoBehaviour
{
    // 这里填你的讯飞AppID（去讯飞控制台复制）
    public string appId = "你的AppID";
    public string apiKey = "你的APIKey";
    public string apiSecret = "你的APISecret";
    
    // 识别到的文字会显示在这里
    public string recognizedText = "";
    
    void Start()
    {
        Debug.Log("语音识别初始化完成");
    }
    
    // 按空格键开始录音
    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            StartListening();
        }
    }
    
    void StartListening()
    {
        Debug.Log("开始录音...");
        // 这里调用讯飞SDK（需要导入SDK后才能用）
        // 暂时先用模拟数据测试
        recognizedText = "老大说：诸葛亮，今天天气如何？";
        Debug.Log("识别结果：" + recognizedText);
    }
}
```
1. 保存文件（Command + S）
1. 回到Unity
1. 把这个脚本拖到诸葛亮模型上
✅ 验证成功：
- 点击Unity顶部的"Play"按钮
- 按空格键
- 下方Console窗口显示"开始录音..."

## 📅 Week 6-7: AR场景集成
### Step 1: 配置AR平面检测（30分钟）
操作步骤：
1. 在Unity顶部菜单，点击"Window" > "Package Manager"
1. 搜索"AR Foundation"
1. 点击"Install"
1. 再搜索"ARCore XR Plugin"（安卓）或"ARKit XR Plugin"（苹果）
1. 也点击"Install"
1. 在Hierarchy窗口（左侧），右键 > "XR" > "AR Session"
1. 再右键 > "XR" > "AR Session Origin"
✅ 验证成功：
- Hierarchy里有"AR Session"和"AR Session Origin"
- Console没有错误提示
### Step 2: 让诸葛亮跟随地面（1小时）
操作步骤：
1. 选中诸葛亮模型
1. 在右侧Inspector窗口，点击"Add Component"
1. 搜索"AR Placement"
1. 如果没有这个组件，创建新脚本 ARPlacement.cs：
```c#
using UnityEngine;
using UnityEngine.XR.ARFoundation;

public class ARPlacement : MonoBehaviour
{
    public GameObject zhugeLiangModel;
    private ARRaycastManager raycastManager;
    
    void Start()
    {
        raycastManager = FindObjectOfType<ARRaycastManager>();
    }
    
    void Update()
    {
        // 点击屏幕放置诸葛亮
        if (Input.touchCount > 0 && Input.GetTouch(0).phase == TouchPhase.Began)
        {
            Vector2 touchPosition = Input.GetTouch(0).position;
            // 检测平面
            List<ARRaycastHit> hits = new List<ARRaycastHit>();
            if (raycastManager.Raycast(touchPosition, hits))
            {
                // 在检测到的平面上放置模型
                Pose hitPose = hits[0].pose;
                zhugeLiangModel.transform.position = hitPose.position;
                zhugeLiangModel.SetActive(true);
            }
        }
    }
}
```
✅ 验证成功：
- 在AR预览模式下，点击地面能放置诸葛亮
### Step 3: 打包到AR眼镜（1小时）
操作步骤：
1. Unity顶部菜单，"File" > "Build Settings"
1. 选择"Android"或"iOS"（根据你的AR眼镜系统）
1. 点击"Switch Platform"
1. 连接AR眼镜到Mac（用USB线）
1. 点击"Build And Run"
1. 选择保存位置，命名 ZhugeAR.apk（安卓）或 ZhugeAR.ipa（iOS）
1. 等待打包完成（5-10分钟）
✅ 验证成功：
- AR眼镜上自动安装了应用
- 打开应用，能看到诸葛亮
