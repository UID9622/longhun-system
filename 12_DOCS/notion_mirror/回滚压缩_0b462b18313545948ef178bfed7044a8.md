功能说明
回滚压缩功能允许您撤销之前执行的压缩操作，完整恢复到压缩前的对话状态。这是压缩机制的安全保障。
---
## 🎯 使用步骤
### 步骤1：查看压缩历史
前往压缩历史记录页面，找到需要回滚的压缩记录：
### 步骤2：选择回滚目标
### 步骤3：确认回滚
点击【回滚】按钮后，系统会显示确认对话框：
### 步骤4：执行回滚
确认后系统会：
1. 从备份恢复原始对话
1. 合并压缩后新增的内容
1. 验证P0完整性
1. 更新压缩历史状态

## 🔗 API接口
端点： POST /api/compression/rollback
请求参数：
```json
{
  "compression_dna_code": "#ZHUGEXIN⚡️2026-01-12-COMPRESSION-001-v1.0",
  "verify_integrity": true,  // 是否验证完整性
  "merge_new_content": true  // 是否合并新内容
}
```
成功响应：
```json
{
  "status": "success",
  "result": {
    "restored_tokens": 150000,
    "restored_messages": 500,
    "new_content_merged": true,
    "p0_integrity": 1.0,
    "rollback_time": "2026-01-13T12:47:00+08:00"
  }
}
```
