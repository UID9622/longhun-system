### Python调用示例
```python
from longhun_tags import 五行标签, 八卦标签, 甲骨文标签, 星宿标签
from longhun_tags import 组合标签, 渲染标签, 按功能查标签, 验证组合

# 组合标签
print(组合标签("火", "旺"))        # → 火·旺
print(组合标签("乾", "正"))        # → 乾·正

# 渲染
print(渲染标签("火·旺", "HTML"))   # → <span style="color:#8B0000">火·旺</span>

# 查询
print(按功能查标签("启动"))         # → 5个匹配结果

# 验证生克
print(验证组合("火", "金"))         # → (False, "火克金，相克组合凶")
print(验证组合("木", "火"))         # → (True, "木生火，相生组合吉")
```
