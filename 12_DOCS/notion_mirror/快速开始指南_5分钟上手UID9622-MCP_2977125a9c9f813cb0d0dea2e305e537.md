## 📦 方式一：NPM安装（推荐）
### 1. 安装依赖
```bash
npm install @uid9622/notion-mcp
# 或
yarn add @uid9622/notion-mcp
```
### 2. 配置环境变量
```bash
# .env
NOTION_TOKEN=your_notion_integration_token
NOTION_DATABASE_ID=your_database_id
```
说明：
- NOTION_TOKEN: 从 https://www.notion.so/my-integrations 获取你的集成Token
- NOTION_DATABASE_ID: 从数据库URL中获取32位字符串ID（例如：https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...）
原理解释：
Notion的权限架构是这样的：
- 集成授权层级：当你在工作区添加集成时，只是给了它访问权限，但不代表它能看到所有内容
- 页面级权限：必须在每个具体数据库页面手动连接集成，它才能操作那个数据库
为什么需要Database ID？
- Notion API是基于资源ID设计的，每个数据库/页面都是独立资源
- 即使集成有工作区权限，API调用时仍需明确指定操作哪个具体数据库
- 这是安全设计：防止误操作其他数据库
有了Database ID能做什么？
- CRUD操作：创建/读取/更新/删除该数据库中的页面（记录）
- 查询过滤：按条件筛选数据（如"状态=进行中"）
- 属性操作：修改标题、状态、日期等字段
- 关系处理：操作数据库间的关联关系
实际应用场景：
假设你有3个数据库：
- 任务库（ID_A）- 用于日常任务管理
- 周卡库（ID_B）- 用于周计划
- 灵感库（ID_C）- 用于收集想法
你的代码可以：
- 从灵感库(ID_C)查询本周提交
- 筛选优质内容后创建到周卡库(ID_B)
- 同时在任务库(ID_A)给贡献者加分
每个操作都需要对应的Database ID，这样才能精确控制数据流向。
### 3. 第一个调用
```javascript
const { NotionMCP } = require('@uid9622/notion-mcp');

const client = new NotionMCP({
  token: process.env.NOTION_TOKEN
});

// 查询数据库
async function demo() {
  const pages = await client.databases.query({
    database_id: process.env.NOTION_DATABASE_ID,
    filter: {
      property: '状态',
      select: { equals: '进行中' }
    }
  });
  
  console.log('找到', pages.results.length, '条记录');
}

demo();
```
运行：
```bash
node demo.js
```
✅ 成功！ 如果看到输出，说明已经跑通了。

## 🆘 常见问题
### Q1: Token怎么获取？
1. 访问 https://www.notion.so/my-integrations
1. 创建新集成
1. 复制 Internal Integration Token
1. 在数据库页面右上角"..." → "Add connections" → 选择你的集成
### Q2: 为什么查询不到数据？
检查：
- ✅ 集成已添加到数据库
- ✅ database_id 正确（32位字符串）
- ✅ Token有效
### Q3: 中文分词不准确？
```javascript
// 使用自定义词典
client.nlp.loadDict([
  '龍魂价值观',
  '三层太极',
  'UID9622'
]);
```
