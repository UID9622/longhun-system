## 🧠 一句话搞懂
堆是「自己申请自己管」的大仓库，栈是「系统自动帮你收拾」的临时桌子，指针就是「门牌号」，引用是「门牌号的别名」。

## ⚠️ 踩坑预警
- 栈溢出（Stack Overflow）：递归太深，每次调用都压栈，压到爆就崩
- 堆内存泄漏：C/C++ 里 malloc 了忘记 free，内存越吃越多，最后崩
- 野指针：指针指向的内存已经被释放了，再访问 = 未定义行为（随机崩）
- Java 值传递陷阱：基本类型传值（改了没用），对象传引用（改了有效），混了就踩坑
- Python 可变/不可变：list 传进函数改了会影响外面，int/str 不会，原理就是引用
---
## 🎯 触发场景举例
- 递归实现深度优先搜索：每层递归压一个栈帧，数据量大要改成显式栈避免溢出
- Go/Rust 的逃逸分析：编译器判断变量要不要放堆上，放栈上性能更好
- Java GC 调优：堆分代（年轻代/老年代），频繁 Full GC = 老年代满了，要看堆大小配置
- C++ 智能指针：shared_ptr/unique_ptr 自动管理堆内存，代替手动 delete

- 垃圾回收（GC）→ Java/Python/Go 自动管堆内存的机制
