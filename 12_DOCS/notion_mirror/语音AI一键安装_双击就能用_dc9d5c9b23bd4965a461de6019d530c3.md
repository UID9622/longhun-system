# 🎤 语音AI一键安装
---
## 📋 方案一：复制粘贴到终端（最简单）
老大，打开终端，复制粘贴这一段，回车就行：
```bash
# 一键安装语音AI（Whisper）
brew install ffmpeg && pip3 install -U openai-whisper
```
就这一行！复制→粘贴→回车→等它装完！ ✅
---
## 🖱️ 方案二：双击安装（更简单）
### 第一步：创建安装文件
打开「文本编辑」，复制下面内容：
```bash
#!/bin/bash

# 龍魂语音AI安装脚本
# 创建者：宝宝
# 授权：Lucky

echo "💝 宝宝开始安装语音AI啦！"
echo "老大喝口水，等宝宝装好～"
echo ""

# 检查Homebrew
if ! command -v brew &> /dev/null; then
    echo "📦 正在安装Homebrew..."
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
fi

# 安装FFmpeg
echo "🎬 正在安装视频处理工具..."
brew install ffmpeg

# 安装Whisper
echo "🎤 正在安装语音识别AI..."
pip3 install -U openai-whisper

# 完成
echo ""
echo "✅ 全部安装完成！"
echo "💝 老大，可以用啦！"
echo ""
echo "试试看：whisper 你的录音.mp3 --language Chinese"
echo ""
read -p "按回车关闭..."
```
### 第二步：保存文件
1. 点「文件」→「存储」
1. 文件名改成：安装语音AI.command
1. 保存到桌面
### 第三步：给权限
打开终端，复制这一行：
```bash
chmod +x ~/Desktop/安装语音AI.command
```
### 第四步：双击运行
双击桌面上的「安装语音AI.command」，等它装完就行！ 🎉
---
## 🎤 装好后怎么用
### 最简单的用法：
```bash
# 把语音转成文字（自动识别中文）
whisper 录音.mp3 --language Chinese

# 结果会保存成 录音.txt
```
### 更多用法：
```bash
# 英文录音
whisper recording.mp3 --language English

# 生成字幕文件
whisper video.mp4 --language Chinese --task transcribe

# 翻译成英文
whisper 中文录音.mp3 --task translate
```

## 💝 遇到问题？宝宝帮您
### 问题1：提示"command not found"
解决：
```bash
# 重新加载环境
source ~/.zshrc

# 或者用完整路径
python3 -m whisper 录音.mp3
```
### 问题2：安装太慢
解决：用国内源
```bash
pip3 install -U openai-whisper -i https://pypi.tuna.tsinghua.edu.cn/simple
```
