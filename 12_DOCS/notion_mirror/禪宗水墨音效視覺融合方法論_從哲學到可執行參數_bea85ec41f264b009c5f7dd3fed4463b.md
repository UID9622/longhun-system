# 通心譯·大白話解讀
## 一句話核心
禪宗「留白、氣韻、頓悟」這些聽起來玄的概念，全部可以翻譯成視頻和音效裡能直接調的具體參數。
## 為什麼重要
大部分AI生成的視頻和音效有一個共同毛病：填滿每一秒每一幀。結果就是「看著熱鬧、聽著吵、心裡空」。學會用「以少勝多」，普通人也能做出有靈魂的內容。
## 大白話展開
### 1. 禪宗六大原則 → 可執行參數
### 2. 五場景五種音效類型（鯉魚躍龍門·龍魂版）
- 場景一·黃河之底（淡墨暈染型）：低頻水流 -28dB 打底 + 大量留白 + 古琴極輕長音
- 場景二·黑夜老兵（墨色層疊型）：孤燈嗡鳴 + 老兵呼吸聲（帶雜音侘寂）+ 手機輕觸 + 頓悟點突然靜默 3 秒
- 場景三·激流衝刺（筆觸飛白型）：短促破水聲（每次力度不同）+ 每段衝刺後留白 2-5 秒
- 場景四·躍門化龍（濃墨點苔型）：靜默 2.5 秒 → 古琴強音 + 金色粒子晶瑩聲爆發（峰值 -6dB，持續 1.2 秒）
- 場景五·龍飛九天（氣韻回歸型）：廣闊風聲 + 單一晶瑩「滴」聲 + 結尾 8 秒純無聲
### 3. 五大畫家風格 → Prompt 詞庫
- 黃公望式（平淡天真、氣韻蕭散）→ 沉穩升華場景
- 王蒙式（層疊雄強、氣勢磅礴）→ 激烈衝刺場景
- 倪瓚式（蕭散簡遠、冷逸禪意）→ 孤獨堅韌場景
- 梁楷式（潑墨頓悟、狂放簡練）→ 高潮頓悟場景
- 石濤式（筆墨當隨時代）→ 整體龍魂感（傳統+科技融合的精神內核）
### 4. TextRank 在 Prompt 裡的具體用法
從知識庫長文本 → TextRank 排序（帶使命+禪宗權重）→ 抽 Top 句子 → 包裝成 200-400 字 Prompt → 餵給 ComfyUI/FFmpeg。讓 Prompt 不再是手寫或隨機，而是從主權知識庫提煉出來的、有龍魂一致性的精華。
### 5. 音效素材本地化清單
- 底層淡墨類：黃河水流、孤燈嗡鳴、遠山風聲（手機自錄即可）
- 中層筆觸飛白類：浪擊聲、毛筆刮宣紙聲、古琴單音、木魚
- 高層粒子晶瑩類：玻璃棒敲水晶、乾淨水滴、輕微鍵盤聲
- 處理工具：Audacity 輕微 EQ + reverb，導出 16bit WAV

## 一句結論
視頻不是越滿越好，留白才是給觀眾心裡騰位置；聲音也不是越多越好，靜默才是讓人聽見靈魂的地方。
