## 🚀 快速上手
### 第一步：Fork仓库
1. 访问 https://github.com/uid9622/notion-mcp
1. 点击右上角 Fork
1. 克隆到本地：
```bash
git clone https://github.com/你的用户名/notion-mcp.git
cd notion-mcp
```
### 第二步：配置开发环境
```bash
# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑.env填入你的Notion token

# 运行测试（确保环境OK）
npm test
```
### 第三步：创建分支
```bash
# 功能分支
git checkout -b feature/你的功能名

# 修复分支
git checkout -b fix/Bug描述

# 文档分支
git checkout -b docs/文档改进
```
### 第四步：开发
```bash
# 启动开发服务器（热重载）
npm run dev

# 编写代码...

# 运行测试
npm test

# 代码检查
npm run lint
```
### 第五步：提交
```bash
# 提交前确保测试通过
npm test

# 提交代码（使用规范的commit信息）
git add .
git commit -m "feat: 添加中文关键词提取功能"

# 推送到你的fork
git push origin feature/你的功能名
```
### 第六步：提交PR
1. 在GitHub上打开你的fork
1. 点击 New Pull Request
1. 填写PR描述（见下方模板）
1. 等待审核

## 📋 Commit规范
我们使用 Conventional Commits 规范：
```bash
# 新功能
git commit -m "feat: 添加XX功能"

# Bug修复
git commit -m "fix: 修复XX问题"

# 文档
git commit -m "docs: 更新API文档"

# 样式（不影响代码功能）
git commit -m "style: 格式化代码"

# 重构
git commit -m "refactor: 重构XX模块"

# 性能优化
git commit -m "perf: 优化查询性能"

# 测试
git commit -m "test: 添加单元测试"

# 构建/工具
git commit -m "chore: 更新依赖"
```

## 🧪 参与沙盒灵感角
### 什么是沙盒灵感角？
每周五发布"周卡"，邀请社区成员提交1条：
- 易经智慧 - 一句古人的话
- 项目案例 - 如何应用到UID9622
- 一句话启发 - 你的理解
### 如何参与？
1. 访问 🧪 开源沙盒评估中心
1. 找到本周的周卡（例如：沙盒灵感角｜周卡 2025-10-31）
1. 在页面内按模板填写你的灵感
1. 周日18:00截止收集
1. 评委会选出前3名，获得贡献分
### 示例
```javascript
- 易经智慧："穷则变，变则通，通则久" —— 《易经》
- 项目案例：UID9622的"95%满意+5%进化"设计，正是这种
  "变通"思维的体现，系统永远保留进化空间，不追求僵化的完美。
- 一句话启发：真正的稳定来自持续的微调，而非一成不变。
```

## ❓ 常见问题
### Q1: 我不会写代码，能贡献吗？
能！ 你可以：
- 参与沙盒灵感角（每周提交智慧卡片）
- 改进文档（修正错别字、优化表述）
- 报告Bug（发现问题就是贡献）
- 分享使用心得（写博客、发推特）
### Q2: PR多久会被审核？
- 小改动（文档、typo）：1-2天
- 功能PR：3-7天
- 重大改动：需要社区讨论，可能更长
### Q3: 我的PR被拒绝了怎么办？
不要灰心！查看审核意见，改进后可以重新提交。
我们遵循"95%满意"原则，不追求完美，但要保证质量。
### Q4: 贡献分有什么用？
- 提升可信级别（L1→L5）
- 获得更多权限（投票、审核）
- 在贡献榜上展示
- 未来可能有实物奖励（T恤、贴纸）
