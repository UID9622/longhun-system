## 🚀 快速上手：3个实战案例
### 案例1：检查今天有多少任务准入天层
```python
from datetime import date

今天 = date.today().isoformat()

cursor.execute('''
    SELECT COUNT(*) 
    FROM ""
    WHERE 准入结果 = "✅准入天层"
    AND DATE(提交时间) = ?
''', (今天,))

今日准入数量 = cursor.fetchone()[0]
print(f"今天有 {今日准入数量} 个任务准入天层")
```
### 案例2：找出最需要补充的经验包标签
```python
# 找出使用次数少但很重要的标签
cursor.execute('''
    SELECT 场景标签, AVG(使用次数) as 平均使用
    FROM ""
    WHERE 是否激活 = "__YES__"
    GROUP BY 场景标签
    ORDER BY 平均使用 ASC
    LIMIT 3
''')

需要补充的标签 = cursor.fetchall()
print("这些标签需要多补充经验包：")
for 标签, 平均 in 需要补充的标签:
    print(f"- {标签}（平均使用{平均:.1f}次）")
```
### 案例3：查看哪些人格最近没激活（可能休眠太久）
```python
from datetime import datetime, timedelta

一周前 = (datetime.now() - timedelta(days=7)).isoformat()

cursor.execute('''
    SELECT 人格名称, 人格图标, 上次激活时间
    FROM ""
    WHERE 是否启用 = "__YES__"
    AND (上次激活时间 IS NULL OR 上次激活时间 < ?)
    ORDER BY 累计激活次数 DESC
''', (一周前,))

沉睡人格 = cursor.fetchall()
if 沉睡人格:
    print("⚠️ 这些人格一周没激活了：")
    for 行 in 沉睡人格:
        print(f"{行[1]} {行[0]}")
else:
    print("✅ 所有人格都很活跃！")
```
