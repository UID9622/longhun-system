# 第一部分：PHP基础语法

## 一、选择题（每题2分，共16分）

### 1. PHP 中用于输出一个或多个字符串的语句是？

A. print_r()
B. echo
C. var_dump()
D. sprintf()

**答案：B**

**解析：** echo 是语言结构，用于输出字符串；print_r 与 var_dump 用于调试输出变量结构。

### 2. 以下哪个变量名在 PHP 中是合法的？

A. $2name
B. $_name
C. $-name
D. $name-2

**答案：B**

**解析：** PHP 变量以 $ 开头，后跟字母或下划线，再跟字母、数字或下划线。

### 3. 执行 `var_dump((int)'0123');` 的输出是？

A. int(123)
B. int(0123)
C. string(4) "0123"
D. int(83)

**答案：A**

**解析：** 字符串转 int 时按十进制解析，前导零被忽略，结果为 123。

### 4. PHP 的 `==` 与 `===` 的区别是？

A. 没有区别
B. `==` 比较值，`===` 比较值和类型
C. `==` 比较类型，`===` 比较值
D. `===` 会自动类型转换

**答案：B**

**解析：** `==` 在比较前进行类型转换；`===` 要求值和类型都相同。

### 5. 以下代码的输出是？`<?php $a = '1'; $b = &$a; $b = '2'; echo $a; ?>`

A. 1
B. 2
C. 12
D. 报错

**答案：B**

**解析：** `&` 引用赋值，$b 与 $a 指向同一内存，修改 $b 即修改 $a。

### 6. 在 PHP 中，`empty()` 对以下哪个值返回 false？

A. 0
B. '0'
C. 'false'
D. null

**答案：C**

**解析：** 字符串 'false' 是非空非 '0' 字符串，empty 返回 false；0、'0'、null 视为空。

### 7. PHP 7 中合并空值的运算符是？

A. ??
B. ?:
C. ?: 与 ?? 相同
D. ||

**答案：A**

**解析：** `??` 是空合并运算符，仅在左侧为 null 时取右侧值；`?:` 对 falsy 值均生效。

### 8. 以下哪个是 PHP 中的 heredoc 语法正确写法？

A. `<<<EOF ... EOF;`
B. `<<EOF ... EOF;`
C. `<<<EOF ... EOF`
D. `<<'EOF' ... EOF;`

**答案：A**

**解析：** heredoc 以 `<<<标识符` 开始，以同名列结束并加分号；nowdoc 使用单引号包围标识符。

## 二、填空题（每题2分，共12分）

### 9. PHP 中定义常量的函数是 `________`。

**答案：define()**

**解析：** `define('NAME', value)` 用于定义全局常量；PHP 5.3+ 也可用 const 关键字。

### 10. 获取字符串长度的 PHP 函数是 `________`。

**答案：strlen()**

**解析：** strlen() 返回字符串的字节数；mb_strlen() 可按字符编码返回字符数。

### 11. PHP 中用于包含文件并在失败时产生致命错误的语句是 `________`。

**答案：require / require_once**

**解析：** require 失败产生 E_COMPILE_ERROR；include 失败只产生 E_WARNING。

### 12. `________` 运算符用于抑制 PHP 表达式产生的错误信息。

**答案：@**

**解析：** 错误控制运算符 @ 可临时抑制错误报告，但不建议在生产代码中滥用。

### 13. 在 PHP 中，使用 `________` 函数可以获取当前日期时间字符串。

**答案：date()**

**解析：** date('Y-m-d H:i:s') 返回格式化的本地日期时间，依赖默认时区设置。

### 14. PHP 中终止脚本执行的语句是 `________`。

**答案：exit / die**

**解析：** exit 与 die 等价，可输出一条消息并终止当前脚本。

## 三、判断题（每题1分，共8分）

### 15. PHP 是弱类型语言，变量类型在运行时可自动转换。

**答案：正确**

**解析：** PHP 支持自动类型转换，但自 PHP 7 起提供了更严格的标量类型声明。

### 16. `$a = 1 + '2abc';` 会报错。

**答案：错误**

**解析：** PHP 会将字符串 '2abc' 的数字前缀 2 转换为整数 2，结果为 3，并发出 E_WARNING。

### 17. `break` 语句只能用在 switch 结构中。

**答案：错误**

**解析：** break 可用于 for、foreach、while、do-while 和 switch，并可指定跳出层数。

### 18. 在 PHP 中，`0 == 'abc'` 返回 true。

**答案：正确**

**解析：** 字符串 'abc' 无数字前缀，转为整数 0，因此 0 == 0 为 true。

### 19. `unset()` 函数可以删除数组中的某个元素。

**答案：正确**

**解析：** unset($arr['key']) 可删除数组元素，但不会重建索引（对索引数组会留下空洞）。

### 20. `<?= $x ?>` 是 `<?php echo $x; ?>` 的简写。

**答案：正确**

**解析：** 短标签 `<?= ... ?>` 等效于输出表达式，自 PHP 5.4 起不受 short_open_tag 限制。

### 21. PHP 中 `foreach` 循环对数组进行修改不会影响原数组。

**答案：错误**

**解析：** 默认 foreach 操作的是数组副本，但使用引用 `foreach ($arr as &$v)` 会修改原数组。

### 22. `define('FOO', [1,2,3])` 在 PHP 7 中是合法的。

**答案：正确**

**解析：** 自 PHP 7 起，define() 允许定义数组常量。

# 第二部分：数据结构与容器

## 一、选择题（每题2分，共8分）

### 23. PHP 中索引数组与关联数组在底层都是？

A. 链表
B. 有序哈希表
C. 二叉树
D. 栈

**答案：B**

**解析：** PHP 数组本质上是有序哈希表（ordered hashmap），兼具列表和字典特性。

### 24. 执行 `$a = [1,2,3]; array_push($a, 4);` 后，`$a` 的值是？

A. [1,2,3,4]
B. [4,1,2,3]
C. [1,2,3]
D. 报错

**答案：A**

**解析：** array_push 在数组末尾添加一个或多个元素。

### 25. 要从关联数组中移除并返回最后一个元素，应使用？

A. array_shift
B. array_pop
C. array_slice
D. array_splice

**答案：B**

**解析：** array_pop 弹出并返回数组最后一个元素；array_shift 操作头部。

### 26. `array_map` 与 `array_filter` 的主要区别是？

A. 都用于过滤
B. array_map 转换元素，array_filter 过滤元素
C. 没有区别
D. array_filter 会改变键名

**答案：B**

**解析：** array_map 对每个元素应用回调并返回新数组；array_filter 根据回调保留满足条件的元素。

## 二、填空题（每题2分，共8分）

### 27. 合并两个数组的函数是 `________`。

**答案：array_merge()**

**解析：** array_merge 合并数组，数字键重新索引，字符串键后者覆盖前者；+ 运算符保留左侧键。

### 28. 检查数组中是否包含某个键的函数是 `________`。

**答案：array_key_exists()**

**解析：** array_key_exists('key', $arr) 检查键是否存在；in_array 检查值是否存在。

### 29. `________` 函数可以将数组元素用指定字符串连接成一个字符串。

**答案：implode()**

**解析：** implode(' ', $arr) 将数组元素连接为字符串；explode 是其反向操作。

### 30. `________` 函数用于对数组按键名升序排序。

**答案：ksort()**

**解析：** ksort 按键排序；asort 按值排序并保持键值关联；sort 按值排序并重建索引。

## 三、判断题（每题1分，共2分）

### 31. `count($arr)` 可以获取数组的元素个数。

**答案：正确**

**解析：** count() 或 sizeof() 返回数组元素数量；对 Countable 对象也有效。

### 32. `array_merge([1,2], [2,3])` 的结果是 `[1,2,2,3]`。

**答案：正确**

**解析：** 数字索引会重新索引，重复值不会被去重；结果为 [1,2,2,3]。

# 第三部分：函数/方法/模块

## 一、选择题（每题2分，共8分）

### 33. PHP 函数中，默认参数应放在参数列表的？

A. 最前面
B. 任意位置
C. 最右侧
D. 不支持默认参数

**答案：C**

**解析：** 默认参数必须放在非默认参数的右侧，否则会产生歧义。

### 34. 以下哪个符号用于定义可变数量参数？

A. ...$args
B. *args
C. func_get_args()
D. $args...

**答案：A**

**解析：** PHP 5.6+ 使用 `...$args` 定义可变参数，捕获所有剩余实参。

### 35. 函数内部访问全局变量应使用？

A. global $x
B. $GLOBALS['x']
C. A 和 B 都可以
D. 无法访问

**答案：C**

**解析：** `global $x` 与 `$GLOBALS['x']` 都可在函数内部访问全局变量。

### 36. 匿名函数在 PHP 中通过哪个关键字创建？

A. lambda
B. function
C. fn
D. B 和 C 都可以

**答案：D**

**解析：** `function(){}` 与箭头函数 `fn()=>` 都可创建匿名函数。

## 二、填空题（每题2分，共8分）

### 37. 用于获取函数所有实参的函数是 `________`。

**答案：func_get_args()**

**解析：** func_get_args() 返回包含所有传入参数的数组；func_num_args 返回参数数量。

### 38. 闭包使用 `________` 关键字从父作用域导入变量。

**答案：use**

**解析：** `function() use ($x) {}` 将外部变量 $x 导入闭包作用域。

### 39. PHP 中返回函数调用栈信息的函数是 `________`。

**答案：debug_backtrace()**

**解析：** debug_backtrace 返回调用链信息，常用于调试和日志。

### 40. 声明函数返回类型为 int 的语法是 `function foo(): ________`。

**答案：int**

**解析：** PHP 7+ 支持返回类型声明，如 `: int`、`: ?string`、`: void` 等。

## 三、判断题（每题1分，共2分）

### 41. PHP 支持函数重载。

**答案：错误**

**解析：** PHP 不支持同名函数不同签名的重载；可通过可变参数或类型检查模拟。

### 42. `call_user_func_array` 可以用数组参数调用回调函数。

**答案：正确**

**解析：** call_user_func_array('func', [$arg1, $arg2]) 动态调用函数并传入参数数组。

# 第四部分：面向对象/类型系统

## 一、选择题（每题2分，共8分）

### 43. PHP 中定义类的关键字是？

A. class
B. object
C. struct
D. type

**答案：A**

**解析：** PHP 使用 class 关键字定义类。

### 44. 以下哪个访问修饰符表示仅在本类内部可访问？

A. public
B. protected
C. private
D. static

**答案：C**

**解析：** private 成员只能在声明它的类内部访问。

### 45. `self::` 与 `static::` 的关键区别是？

A. 没有区别
B. self 指向当前类，static 指向运行时实际类（后期静态绑定）
C. static 只能用于静态方法
D. self 支持继承

**答案：B**

**解析：** static:: 使用后期静态绑定，指向调用该方法的具体子类。

### 46. PHP 接口中定义的方法默认是？

A. private
B. protected
C. public
D. abstract

**答案：C**

**解析：** 接口中方法默认 public；自 PHP 8.0 起可在接口中定义受保护/私有方法（极少见）。

## 二、填空题（每题2分，共8分）

### 47. 实现接口的关键字是 `________`。

**答案：implements**

**解析：** 类使用 implements 实现接口；使用 extends 继承类。

### 48. 定义抽象类的关键字是 `________`。

**答案：abstract**

**解析：** 抽象类使用 abstract class 声明，可包含抽象方法。

### 49. 在类内部调用静态方法的语法是 `self::________()`。

**答案：methodName**

**解析：** 静态方法通过 `类名::方法名()` 或 `self::方法名()` 调用。

### 50. PHP 中用于代码复用的水平扩展机制是 `________`。

**答案：trait**

**解析：** trait 可在多个类之间复用方法，解决 PHP 单继承的限制。

## 三、判断题（每题1分，共5分）

### 51. PHP 只支持单继承，一个类只能直接继承一个父类。

**答案：正确**

**解析：** PHP 类只能 extends 一个类，但可通过接口和 trait 实现多态与代码复用。

### 52. 构造函数的名称必须是 `__construct`。

**答案：错误**

**解析：** PHP 5 引入 __construct；旧版 PHP 4 风格使用与类同名方法，仍向后兼容。

### 53. `final` 关键字修饰的类不能被继承。

**答案：正确**

**解析：** final class 禁止继承；final 方法禁止子类重写。

### 54. `__get` 魔术方法在访问不可访问属性时触发。

**答案：正确**

**解析：** __get/__set 等魔术方法用于拦截对不可见或不存在的属性访问。

### 55. 命名空间使用 `namespace` 关键字声明，且必须放在文件最开头。

**答案：正确**

**解析：** namespace 声明前除 declare 外不能有任何代码，且应置于文件顶部。

## 四、简答题（每题5分，共5分）

### 56. 简述 PHP 中 `public`、`protected`、`private` 三种访问修饰符的区别。

**答案：public 可在任意位置访问；protected 可在类内部及子类中访问；private 仅在声明它的类内部访问。**

**解析：** 这是面向对象封装的基础，决定了成员的可访问范围。

# 第五部分：高级特性

## 一、选择题（每题2分，共2分）

### 57. `declare(strict_types=1);` 的作用是？

A. 开启严格模式，禁用自动类型转换
B. 关闭错误报告
C. 启用命名空间
D. 定义常量

**答案：A**

**解析：** 严格类型声明要求函数参数和返回值类型必须完全匹配，不执行弱类型转换。

## 三、填空题（每题2分，共4分）

### 58. PHP 8 引入的匹配表达式关键字是 `________`。

**答案：match**

**解析：** match 表达式是 switch 的严格比较替代，具有返回值且无需 break。

### 59. 表示参数或返回类型可为 null 的符号是 `________`。

**答案：?**

**解析：** `?string` 表示 string 或 null；PHP 8 也可用联合类型 `string|null`。

## 二、判断题（每题1分，共7分）

### 60. PHP 7 引入的标量类型声明中，array 不是标量类型。

**答案：正确**

**解析：** 标量类型包括 int、float、string、bool；array 是复合类型。

### 61. PHP 8 支持命名参数（named arguments）。

**答案：正确**

**解析：** PHP 8 允许按参数名传值，如 array_fill(start_index: 0, count: 100, value: 0)。

### 62. `yield` 关键字用于定义生成器函数。

**答案：正确**

**解析：** 生成器使用 yield 按需产生值，可显著降低大集合的内存占用。

### 63. Trait 之间发生冲突时，可以使用 `insteadof` 和 `as` 解决。

**答案：正确**

**解析：** `A::method insteadof B` 使用 A 的方法；`B::method as newMethod` 起别名。

### 64. PHP 中 `spl_autoload_register` 可以注册多个自动加载器。

**答案：正确**

**解析：** spl_autoload_register 支持注册多个回调，按注册顺序依次尝试加载。

### 65. `ReflectionClass` 用于在运行时检查类的结构。

**答案：正确**

**解析：** 反射 API 允许运行时获取类、方法、属性的元数据并动态调用。

### 77. 有一个无序数组 `[3,1,4,1,5,9,2,6]`，要求只遍历一次找出第二大的数。请描述核心思路（无需写完整代码）。

**答案：维护两个变量 max 和 secondMax；遍历数组时，若当前元素大于 max，则 secondMax=max，max=当前元素；否则若当前元素大于 secondMax 且不等于 max，则更新 secondMax。**

**解析：** 一次遍历即可，时间复杂度 O(n)，空间复杂度 O(1)。

### 80. 有四个水壶，分别可盛 5 升、3 升、2 升、1 升。如何利用 5 升和 3 升的水壶准确量出 4 升水？

**答案：```php
function isAnagram(string $a, string $b): bool {
    if (strlen($a) !== strlen($b)) return false;
    return count_chars($a, 1) === count_chars($b, 1);
}
```**

**解析：** count_chars($str, 1) 返回每个字节出现次数的数组；比较两者是否相等即可判断变位词。

## 二、程序分析题（每题5分，共5分）

### 87. 阅读以下代码，写出输出结果并说明原因。
```php
<?php
function makeCounter() {
    $count = 0;
    return function() use (&$count) {
        return ++$count;
    };
}
$c = makeCounter();
echo $c();
echo $c();
```

**答案：输出 `12`。makeCounter 返回的闭包通过引用 use (&$count) 捕获了外部变量，每次调用都会修改同一个 $count。**

**解析：** use 默认按值捕获，加 & 后按引用捕获，闭包状态得以保留。

### 88. 设计一个基于 Session 的用户登录校验流程，要求：① 登录成功后设置 session；② 每个受保护页面校验登录状态；③ 提供注销功能。请用文字或伪代码/PHP 代码描述关键步骤。

**答案：① login.php：验证用户名密码后 `session_start(); $_SESSION['user_id'] = $id;`；② protected.php：`session_start(); if (empty($_SESSION['user_id'])) { header('Location: login.php'); exit; }`；③ logout.php：`session_start(); session_destroy(); header('Location: login.php');`。**

**解析：** Session 依赖服务端存储标识，配合重定向实现登录态管理；应启用安全标志并再生会话 ID 防止固定攻击。

## 三、代码调试题（每题5分，共5分）

### 89. 以下 PDO 代码存在潜在问题，请指出并修正。
```php
$pdo = new PDO('mysql:host=localhost;dbname=test', 'root', '');
$id = $_GET['id'];
$stmt = $pdo->query("SELECT * FROM users WHERE id = $id");
$user = $stmt->fetch();
```

**答案：直接使用 $_GET['id'] 拼接 SQL 存在 SQL 注入。应使用预处理语句：
```php
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = ?');
$stmt->execute([$id]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);
```**

**解析：** 预处理语句将用户输入作为数据绑定，避免 SQL 注入；同时建议设置 PDO::ATTR_ERRMODE。
