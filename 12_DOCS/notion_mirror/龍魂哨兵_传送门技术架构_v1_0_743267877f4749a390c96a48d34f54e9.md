## 🧱 四层架构详解
### 第一层：CNSH洗坑机
目的： 把脏东西洗掉，输出干净的文本
技术实现：
```javascript
function cnshClean(input) {
  let text = input;
  
  // 1. 强制UTF-8
  text = forceUTF8(text);
  
  // 2. 统一换行为LF
  text = text.replace(/\r\n/g, '\n').replace(/\r/g, '\n');
  
  // 3. 去除不可见字符（保留必要的）
  text = removeInvisibleChars(text);
  
  // 4. 语义结构标准化
  text = normalizeStructure(text);
  
  return text;
}
```
输入输出示例：
```javascript
输入："Hello\r\nWorld\u200B"  （含CRLF和零宽空格）
输出："Hello\nWorld"          （干净）
```

技术实现：
```javascript
function culturalEncrypt(text, mappingTable) {
  let encrypted = text;
  for (const [original, cultural] of Object.entries(mappingTable)) {
    encrypted = encrypted.replaceAll(original, cultural);
  }
  return encrypted;
}

function culturalDecrypt(text, mappingTable) {
  let decrypted = text;
  for (const [original, cultural] of Object.entries(mappingTable)) {
    decrypted = decrypted.replaceAll(cultural, original);
  }
  return decrypted;
}
```

- 没有映射表的人 → 看到："𒀀𒀁𒀂☰☷"
- 有映射表的人 → 看到："日月人开始结束"

### 第三层：GPG签名（点对点开放）
目的： 数学级别的身份证明，指定的人才能解密
使用 OpenPGP.js（纯前端，无需服务器）：
```javascript
import * as openpgp from 'openpgp';

// 签名
async function signText(text, privateKey) {
  const message = await openpgp.createMessage({ text });
  const signed = await openpgp.sign({
    message,
    signingKeys: privateKey
  });
  return signed;
}

// 验证
async function verifySignature(signedText, publicKey) {
  const message = await openpgp.readMessage({ armoredMessage: signedText });
  const verified = await openpgp.verify({
    message,
    verificationKeys: publicKey
  });
  return verified.signatures[0].verified;
}

// 点对点加密
async function encryptForRecipient(text, recipientPublicKey, senderPrivateKey) {
  const message = await openpgp.createMessage({ text });
  const encrypted = await openpgp.encrypt({
    message,
    encryptionKeys: recipientPublicKey,
    signingKeys: senderPrivateKey
  });
  return encrypted;
}
```
效果：
- 没有私钥 → 解不开
- 有私钥 → 一眼明白
- 伪造签名 → 数学上不可能

### 第四层：DNA追溯
目的： 改一个字都能发现
DNA追溯码结构：
```javascript
#龍芯⚡️{日期}-{主题}-{版本}-{语义哈希前8位}
```
技术实现：
```javascript
async function generateDNA(text, author, topic, version) {
  // 1. 生成语义哈希（SHA-256）
  const encoder = new TextEncoder();
  const data = encoder.encode(text);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
  
  // 2. 生成时间戳
  const now = new Date();
  const dateStr = now.toISOString().split('T')[0];
  
  // 3. 组合DNA追溯码
  const dnaCode = `#龍芯⚡️${dateStr}-${topic}-${version}-${hashHex.slice(0, 8)}`;
  
  return {
    dnaCode,
    fullHash: hashHex,
    timestamp: now.toISOString(),
    author
  };
}
```
效果：
- 原文："Hello World" → DNA：#龍芯⚡️2026-02-03-测试-v1.0-a591a6d4
- 改成："Hello World!" → DNA：#龍芯⚡️2026-02-03-测试-v1.0-943a702d
- 哈希完全不同 → 立刻暴露
