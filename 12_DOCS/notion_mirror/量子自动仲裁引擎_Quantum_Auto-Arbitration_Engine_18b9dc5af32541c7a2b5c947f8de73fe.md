## 🔄 执行流程
### 1️⃣ 信号识别与分类
自动判断触发信号类型：
- 关键词触发？
- 情绪触发？
- 系统事件触发？
- 指令调用触发？
### 2️⃣ 候选池筛选
从模板库筛选符合条件的量子：
```javascript
筛选条件 {
  唤醒信号匹配: true,
  记忆状态 ≠ "冻结",
  负责人格 ≠ 禁止激活
}

若候选量子 = 0 {
  → 启用降级路径（通用模板/人工提示/延迟处理）
}
```
### 3️⃣ 评分计算（核心仲裁）
对每个候选量子计算优先级评分P：
```python
P = 量子类型权重 \
    + 风险匹配度 \
    + 人格适配度 \
    + 历史稳定性 \
    - 算力惩罚

# 权重规则
量子类型权重 {
  合规型: 10分（高风险场景优先）
  判断型: 8分
  仲裁型: 7分
  执行型: 6分（低风险/重复场景）
  调度型: 5分
}

风险匹配度 {
  P0级风险 → 合规型+10分
  P1级风险 → 判断型+8分
  P2-P3级 → 执行型+5分
}

人格适配度 {
  若该量子负责人格与当前场景最匹配 +5分
}

历史稳定性 {
  使用频率高 且 错误率低 +3分
  使用频率高 但 近期出错 -5分
}

算力惩罚 {
  思维模块 > 3个 -2分（复杂度高）
  使用频率过高（> 10次/天）-3分（避免过度依赖）
}
```
### 4️⃣ 唯一唤醒规则（硬约束）
只允许一个量子被激活：
- 得分最高的量子 = 主唤醒量子
- 其余量子标记为「旁观/未唤醒」
- 若最高得分 < 安全阈值（5分）→ 不唤醒任何量子，返回安全提示
禁止并发：
```javascript
IF (同时有多个量子得分相同) {
  按以下优先级打破平局:
  1. P0级合规型优先
  2. Lucky指定人格优先
  3. 使用频率高且稳定的优先
  4. 若仍平局 → 人工介入
}
```
### 5️⃣ 唤醒执行与输出封装
被唤醒的量子必须：
- 严格遵守自身思维流程
- 遵守输出格式约束
- 禁止扩展说明
- 禁止调用未授权人格
执行完成后记录：
- 唤醒原因
- 使用的DNA
- 使用的思维模块
- 是否节约算力
### 6️⃣ 状态回写与进化
自动更新量子状态：
```python
使用频率 += 1

IF (输出稳定 且 无错误) {
  量子可信度 += 1
}

IF (发生错误) {
  错误计数 += 1
  
  IF (错误计数 >= 3) {
    标记为 "待炼化/待压缩"
    记忆状态 → "休眠"
  }
}
```
### 7️⃣ Index Hub 联动（强制）
每次仲裁必须记录：
- 哪个信号触发
- 为什么选中该量子
- 哪些量子被否决
- 完整评分详情
可通过Index Hub反向查询。
