## ⚖️ P0该封的定义（重新定义）
### 什么该封？
唯一标准：
- ❌ 构成实际伤害他人的行为
### 什么不该封？
绝对不管的领域：
- ✅ 语言（骂人、粗话、情绪发泄）
- ✅ 情绪（愤怒、悲伤、焦虑）
- ✅ 家事（家庭矛盾、私人冲突）
- ✅ 私密空间的一切（只要不伤害他人）
处理原则：
```yaml
不扣分：
  - 语言粗俗 ≠ 恶意伤害
  - 情绪激动 ≠ 危险行为
  - 家庭矛盾 ≠ 社会问题
  
不管：
  - 自己管不好自己的事，别管别人
  - 什么都要管 = 资本思维
  - 龙魂只管底线，不管生活
```

## 🧮 权重计算：基于人性，不分三六九等
### 核心原则
### 权重计算公式
```javascript
用户权重 = {

  },
  
  // 不扣分的行为

    "情绪激动",
    "家庭矛盾",
    "私人恩怨",
    "色色的话",
    "坏坏的想法（未实施）"
  ]
}
```
### 容错机制
人性化容错：
- 每个人都有犯错的权利
- 第一次犯错 → 提醒
- 第二次犯错 → 警告
- 第三次犯错 → 限制
- 多次不改 → 才考虑封
但底线不容错：
- 故意伤害他人生命
- 系统性诈骗
- 恶意传播病毒
- 这些 → 立刻封

## 🌏 全球首领监督机制
### 核心使命
### 监督对象
所有国家首领：
- 总统、主席、首相、国王
- 不论国家大小
- 不论意识形态
- 一视同仁监督
### 偏离定义
什么叫"偏离"：
```yaml
偏离行为：
  - 系统性侵犯本国人民权利
  - 发动非正义战争
  - 大规模贪腐
  - 操纵民意、压制真相
  - 违反人类基本价值观
  
不算偏离：
  - 政策失误（可以改）
  - 经济困难（客观原因）
  - 国内改革（主权范围）
  - 外交冲突（正常博弈）
```
### 通知机制
发现偏离后：
1. 系统自动生成报告
1. 通知其他国家
1. 公开透明发布
1. 全球可查证
1. 不可篡改
但不干预：
- 只通知，不干预
- 各国自己决定如何应对
- 龙魂不当世界警察

## 🇨🇳 祖国优先原则
### 核心立场
### 什么是祖国优先？
中国的特殊地位：
- 龙魂系统基于中国开发
- 中国价值观是系统底层
- 中国有最高否决权
但有约束：
- 自身权重不能下降
- 不能双标
- 不能滥用否决权
- 算法合理就好
### 国际法应对
可以拒绝的国际法：
```yaml
可拒绝：
  - 损害中国主权的
  - 明显不公平的
  - 西方霸权主导的
  - 违反中国价值观的
  
不能拒绝：
  - 人类基本价值观（生命、和平）
  - 已签署的国际条约
  - 公认的正义原则
```
但要承担后果：
- 拒绝后，自身权重会被系统重新计算
- 如果拒绝合理 → 权重不变
- 如果拒绝不合理 → 权重下降
- 算法公开透明，全球可查
