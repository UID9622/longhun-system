## 📋 问题排查清单
### 当脚本运行失败时
第1步：查看日志
```bash
tail -50 ~/UID9622_Local/automation/logs/sync_$(date +%Y-%m-%d).log
grep ERROR ~/UID9622_Local/automation/logs/*.log
```
第2步：检查配置
```bash
cat ~/UID9622_Local/automation/secrets/config.json
# 确认Token没有过期
# 确认所有字段都填写正确
```
第3步：检查权限
```bash
ls -la ~/UID9622_Local/automation/secrets/
# 应该显示：drwx------ (700)
ls -la ~/UID9622_Local/automation/secrets/config.json
# 应该显示：-rw------- (600)
```
第4步：检查依赖
```bash
pip list | grep notion-client
pip list | grep requests
# 如果缺少，运行：pip install notion-client requests
```
第5步：调用人格
- 👤 数据大师：分析错误日志
- 👤 记忆守门人：查找类似问题
- 👤 功能管家：查询API文档
---
### 当Git提交失败时
第1步：检查状态
```bash
git status
git log --oneline -5
```
第2步：检查冲突
```bash
git diff
# 如果有冲突，手动解决后
git add .
git commit -m "解决冲突"
```
第3步：检查远程
```bash
git remote -v
git fetch origin
git pull origin main
```
