### ✅ 可以闭眼用的字体
这些字体，完全免费商用，放心用：
### 中文字体
1. 思源黑体（Source Han Sans）
- 来源： Adobe + Google联合开发
- 授权： SIL Open Font License（完全开源）
- 字重： 7个（ExtraLight到Black）
- 支持： 简体中文、繁体中文、日文、韩文
- 下载： GitHub - adobe-fonts/source-han-sans
- 适用场景： 99%的场景，闭眼用
2. 思源宋体（Source Han Serif）
- 风格： 宋体，适合正文阅读
- 授权： SIL（完全开源）
- 适用： 文章、书籍、正式文档
3. 阿里巴巴普惠体
- 来源： 阿里巴巴集团
- 授权： 免费商用（建议署名）
- 风格： 现代、友好、易读
- 下载： 阿里巴巴普惠体官网
- 适用： UI界面、海报、品牌设计
4. 站酷字体系列
- 来源： 站酷（ZCOOL）设计师社区
- 授权： 全部免费商用
- 品种： 站酷高端黑、站酷快乐体、站酷酷黑等
- 下载： 站酷字体官网
- 适用： 创意设计、海报、标题
5. OPPO Sans
- 来源： OPPO官方
- 授权： 免费商用
- 风格： 极简、现代、屏幕优化
- 适用： UI界面、移动端
6. 鸿蒙字体（HarmonyOS Sans）
- 来源： 华为
- 授权： 免费商用
- 特点： 可变字体，多平台优化
- 适用： 跨平台项目
### 英文字体
Roboto / Open Sans / Lato
- 授权： Apache / SIL

### 工具3：字体瘦身
场景： 网页用了字体文件，加载太慢怎么办？
工具： 字蛛（font-spider）
原理： 扫描网页，只保留用到的字，其他字删掉
效果： 10MB字体 → 100KB
操作：
```bash
# 安装字蛛
npm install font-spider -g

# 在HTML中引用字体
<style>
@font-face {
  font-family: 'SourceHanSans';
  src: url('SourceHanSansSC-Regular.otf');
}
h1 { font-family: 'SourceHanSans'; }
</style>

# 运行字蛛
font-spider index.html

# 字蛛会自动生成精简版字体
```
### 工具4：快速检查字体授权
操作流程：
1. 找到字体文件（.ttf / .otf）
1. 右键 → 属性 → 查看是否有License信息
1. 搜索"字体名 + 商用授权"
1. 查看字体官网的授权说明
1. 还是不确定？别用，换白名单字体

## 第四部分：常见问题速查
### Q1：我下载了字体，能用在公司项目里吗？
答： 看授权！白名单字体（思源/阿里/站酷）→ 闭眼用。其他字体 → 搜"字体名 + 商用授权"确认。找不到授权说明 → 别用。
### Q2：微软雅黑不是Windows自带的吗？怎么不能商用？
答： Windows自带 = 你电脑上能用（个人使用）。商用 = 你用它赚钱（网站、海报、客户项目）。微软授权你个人用，没授权你商用。想商用？换思源黑体。
### Q3：客户给的设计稿用了方正字体，我该怎么办？
答：
- 方案A：让客户买授权（他们付钱）
- 方案B：换成思源黑体/宋体（跟客户说明风险）
- 方案C：找相似的开源字体替代
- 不要直接用！会炸！
### Q4：字体厂商怎么发现我用了他们的字体？
答：
1. 他们有爬虫扫描网站
1. 他们监控设计平台（站酷、花瓣等）
1. 有人举报（竞争对手）
1. 随机抽查
别心存侥幸，他们专业找这个。
### Q5：我用字体做logo，算不算商用？
答： 算！做logo、海报、包装、网站、APP，都算商用。只有自己电脑上写文档、做笔记，才算个人使用。

## 第五部分：终极避坑指南
### 黄金法则
1. 只用白名单字体（思源、阿里、站酷、OPPO、鸿蒙）
1. 遇到不认识的字体，默认它是商业字体
1. 不确定就别用，换白名单字体
1. 保存字体授权证明（截图官网授权说明）
1. 定期检查项目字体（防止别人乱加）
### 企业级方案
如果你是公司负责人、技术leader：
建立公司字体白名单制度：
1. 列出允许使用的字体清单（只用开源字体）
1. 禁止员工随意下载使用其他字体
1. 所有设计稿交付前检查字体
1. 外包项目合同注明"不得使用商业字体"
1. 定期审计项目字体使用情况
一劳永逸，避免被坑。
