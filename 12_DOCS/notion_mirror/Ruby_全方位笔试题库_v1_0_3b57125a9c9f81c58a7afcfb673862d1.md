# 第一部分：Ruby基础语法

### 1. 在 Ruby 的条件判断中，以下哪些值会被视为 `false`？
A. `0`  
B. `""`  
C. `nil`  
D. `[]`

**答案：C**  
**解析：** Ruby 中只有 `nil` 和 `false` 为假，其余包括 `0`、空字符串、空数组等均为真。这与 C、Python 等语言不同，体现了 Ruby 的“一切皆真”哲学。

### 2. 以下代码执行后 `x` 的值是什么？
```ruby
x = "hello"
x.freeze
x << " world"
```
A. `"hello world"`  
B. `"hello"`  
C. 抛出 `FrozenError`  
D. 抛出 `NoMethodError`

**答案：C**  
**解析：** `freeze` 将对象冻结，任何修改操作都会抛出 `FrozenError`。字符串、数组、哈希等对象均可冻结，用于保证不可变性。

### 3. 请填写：`Ruby` 中用于创建符号（Symbol）的字面量语法是 `:name`，符号与字符串的核心区别是符号是______________。

**答案：** `不可变的、唯一的内部标识符（interned，同一符号内存地址相同）`  
**解析：** 符号不可变且全局唯一，适合作为方法名、哈希键等身份标识；字符串可变且每次创建新对象，更适合作数据内容。

### 4. 以下代码的输出是什么？
```ruby
p (1..5).to_a
p (1...5).to_a
```

**答案：** `[1, 2, 3, 4, 5]` 与 `[1, 2, 3, 4]`  
**解析：** `..` 表示闭区间，`...` 表示左闭右开区间。`Range` 是 Ruby 中表达区间范围的重要对象，常与 `case`、`Enumerable` 配合使用。

### 5. 关于 Ruby 的 `case/when` 语句，下列说法正确的是？
A. 每个 `when` 分支结束后必须写 `break`  
B. `when` 使用 `===` 进行匹配  
C. `case` 后的表达式不可省略  
D. `when` 只能比较数值类型

**答案：B**  
**解析：** Ruby 的 `case/when` 没有“穿透”行为，不需要 `break`；`when` 通过 `===` 匹配，因此支持正则、Range、Class 等范围/类型判断。

### 6. 请补全代码，使变量 `a` 和 `b` 的值互换：`a, b = ________`。

**答案：** `b, a`  
**解析：** Ruby 支持并行赋值（parallel assignment），右侧表达式会先求值再统一赋给左侧变量，因此可以无需临时变量完成交换。

### 7. 判断：`%w[foo bar baz]` 等价于 `["foo", "bar", "baz"]`，`%i[foo bar]` 等价于 `[:foo, :bar]`。

**答案：** ✅正确  
**解析：** `%w` 生成字符串数组，`%i` 生成符号数组，二者都是 Ruby 提供的数组字面量简写，能减少引号和逗号的书写。

### 8. 以下代码的输出是？
```ruby
s = "Ruby"
puts "#{s.downcase}" == 'ruby'
```
A. `true`  
B. `false`  
C. 抛出异常  
D. 无输出

**答案：A**  
**解析：** 字符串插值 `#{...}` 会在双引号字符串中执行 Ruby 表达式。`"ruby" == 'ruby'` 比较的是字符串内容，结果相等，返回 `true`。

### 9. 请填写：在 Ruby 中，`BEGIN {}` 块在程序______________执行，`END {}` 块在程序______________执行。

**答案：** `开始之前（加载时）`、`结束之后`  
**解析：** `BEGIN`/`END` 用于在程序生命周期的起点和终点执行一次性代码，常用于初始化或收尾。`BEGIN` 块按出现顺序执行，`END` 块按出现顺序的逆序执行。

### 10. 关于 Ruby 的异常处理，下列说法错误的是？
A. `rescue` 默认捕获 `StandardError` 及其子类  
B. `ensure` 块无论是否异常都会执行  
C. `raise` 不带参数会重新抛出最近一次捕获的异常  
D. `else` 块在发生异常时执行

**答案：D**  
**解析：** `else` 块仅在 `begin` 块没有发生异常时执行，用于放置正常流程代码；异常流程由 `rescue` 处理，`ensure` 保证资源释放。

# 第二部分：数据结构与容器

### 11. 以下代码的输出是？
```ruby
arr = [1, 2, 3]
arr.map { |x| x * 2 }
puts arr.inspect
```
A. `[2, 4, 6]`  
B. `[1, 2, 3]`  
C. `nil`  
D. 抛出异常

**答案：B**  
**解析：** `map` 返回新数组，不会修改原数组。若需原地修改应使用 `map!`。注意区分非破坏性与破坏性方法，这是 Ruby 命名约定之一。

### 12. 以下代码的输出是？
```ruby
h = Hash.new(0)
h[:a] += 1
p h
```
A. `{}`  
B. `{:a=>1}`  
C. `{:a=>0}`  
D. 抛出 `KeyError`

**答案：B**  
**解析：** `Hash.new(0)` 指定了默认值 `0`，访问不存在的键时返回默认值但不写入哈希。`h[:a] += 1` 先读取默认值 `0`，加 `1` 后赋值，最终 `:a` 的值为 `1`。

### 13. 请补全：使用 `inject`/`reduce` 计算数组 `[1,2,3,4]` 的乘积，应写为 `[1,2,3,4].reduce(____) { |acc, n| acc * n }`。

**答案：** `1`  
**解析：** `reduce` 的初值参数决定累加器的初始值。乘法初始值为 `1`（加法为 `0`），若省略初值则使用集合的第一个元素作为初值。

### 14. 请补全：在 Ruby 中读取哈希键 `:x` 并在不存在时返回 `10`，可使用 `hash.fetch(:x, ________)`。

**答案：** `10`  
**解析：** `Hash#fetch(key, default)` 在键存在时返回值，不存在时返回给定的默认值；与 `hash[:x] || 10` 不同，`fetch` 仅在键缺失时生效，而不会因为值为 `nil`/`false` 而返回默认值。

### 15. 程序分析：阅读以下代码，写出输出结果。
```ruby
a = [1, 2, 3, 4, 5]
b = a.select(&:even?).reject { |x| x > 4 }
c = b.map { |x| x ** 2 }
puts c.inspect
```

**答案：** `[4, 16]`  
**解析：** `select(&:even?)` 筛选偶数得到 `[2, 4]`；`reject { |x| x > 4 }` 移除大于 `4` 的元素，仍为 `[2, 4]`；`map` 求平方得到 `[4, 16]`。`&:even?` 是 `Symbol#to_proc` 的语法糖。

### 16. 关于 `Set` 与 `Array`，下列说法正确的是？
A. `Set` 可以包含重复元素  
B. `Array#include?` 在大型集合中通常比 `Set#include?` 更快  
C. `Set` 基于哈希实现，因此成员判断平均时间复杂度为 O(1)  
D. `Set` 中的元素顺序始终固定不变

**答案：C**  
**解析：** `Set` 基于哈希表实现，不允许重复，成员判断为 O(1)；`Array#include?` 为 O(n)。Ruby 3.2+ 的 `Set` 保持插入顺序，但旧版本不一定。

### 17. 判断：在 Ruby 中，使用可变对象（如未冻结的字符串）作为哈希键可能导致不可预期的行为，因为哈希键通过 `hash` 和 `eql?` 确定桶位置。

**答案：** ✅正确  
**解析：** 若对象在作为哈希键后被修改，其 `hash` 值可能改变，导致后续无法找到该键。通常应使用符号或冻结字符串作为键。

### 18. 请补全：将两个数组 `[1, 2, 3]` 与 `["a", "b", "c"]` 按索引配对，应写为 `[1,2,3].________(["a","b","c"])`。

**答案：** `zip`  
**解析：** `Array#zip` 将多个数组按索引位置组合成二元组，返回 `[[1, "a"], [2, "b"], [3, "c"]]`，常用于并行遍历多个集合。

### 19. 程序分析：阅读以下代码，写出输出结果。
```ruby
words = %w[apple banana apricot blueberry]
result = words.group_by { |w| w[0] }
puts result.inspect
```

**答案：** `{"a"=>["apple", "apricot"], "b"=>["banana", "blueberry"]}`  
**解析：** `Enumerable#group_by` 按照块返回值将元素分组，返回一个以块返回值为键、原元素数组为值的哈希。这里按单词首字母分组。

### 20. 关于 `Hash#merge` 和 `Hash#merge!`，下列说法正确的是？
A. 二者都会修改原哈希  
B. `merge` 返回新哈希，`merge!` 原地修改  
C. `merge` 不能接受块参数处理键冲突  
D. `merge!` 是 `merge` 的别名

**答案：B**  
**解析：** 带 `!` 的方法通常表示破坏性/原地修改。`merge` 返回合并后的新哈希；`merge!` 修改接收者。二者都支持块参数处理重复键。

### 21. 请补全：对数组 `[1, 2, 2, 3, 3, 3]` 按奇偶性去重，应写为 `[1,2,2,3,3,3].uniq { |x| x % 2 }`，结果为________。

**答案：** `[1, 2]`  
**解析：** `Array#uniq` 可接收块，按块返回值去重。`1 % 2 == 1`，`2 % 2 == 0`，`3 % 2 == 1`，因此保留第一个 `1` 和第一个 `2`，结果为 `[1, 2]`。

# 第三部分：函数/方法/模块

### 23. 关于 Block、Proc 与 Lambda，下列说法正确的是？
A. Lambda 对参数数量不敏感，Proc 严格检查参数数量  
B. `return` 在 Lambda 中会从整个方法返回  
C. Lambda 是 Proc 的一种，可通过 `lambda?` 判断  
D. Block 可以脱离方法单独作为对象存在

**答案：C**  
**解析：** Lambda 是特殊的 Proc，`lambda?` 返回 `true`。Lambda 严格检查参数数量，`return` 只从 Lambda 返回；Proc 对参数较宽松，`return` 会从定义它的方法返回。Block 本身不是独立对象，需 `&block` 或 `Proc.new` 捕获。

### 24. 以下代码的输出是？
```ruby
def demo
  puts yield(3) if block_given?
end
demo { |x| x * x }
```
A. `9`  
B. `3`  
C. 无输出  
D. 抛出 `LocalJumpError`

**答案：A**  
**解析：** `block_given?` 判断调用时是否传入块，`yield` 调用块并传递参数 `3`，块返回 `3*3=9`。若未传块而直接 `yield` 会抛出 `LocalJumpError`。

### 25. 请补全：在方法参数中使用 `&` 前缀可将调用者传入的块转换为 Proc 对象，例如 `def foo(&block); block.call; end`。在方法内部，也可通过 `________` 将 Proc 还原为块并传给另一个方法。

**答案：** `&proc`（将 Proc/Method 对象前加 `&` 作为块传递）  
**解析：** `&` 运算符在参数位置将块转为 Proc，在调用位置将可调用对象转为块。例如 `arr.map(&method(:foo))` 将方法对象作为块传入 `map`。

### 26. 请补全：判断一个 Proc 对象 `p` 是否为 Lambda，应调用 `p.________`。

**答案：** `lambda?`  
**解析：** `Proc#lambda?` 返回 `true` 表示该 Proc 是通过 `lambda` 或 `->` 创建的 Lambda。Lambda 在参数检查和 `return` 语义上与普通过程对象不同。

### 27. 程序分析：阅读以下代码，写出输出结果。
```ruby
def multiplier(factor)
  ->(x) { x * factor }
end
triple = multiplier(3)
puts triple.call(4)
```

**答案：** `12`  
**解析：** Lambda 创建时捕获了外部局部变量 `factor`，形成闭包。即使 `multiplier` 方法已返回，`triple` 仍然能访问 `factor` 的值 `3`，因此 `triple.call(4)` 输出 `12`。

### 28. 程序分析：阅读以下代码，写出输出结果。
```ruby
def test
  p = Proc.new { return 10 }
  p.call
  20
end
def test2
  l = -> { return 10 }
  l.call
  20
end
puts test
puts test2
```

**答案：**
```
10
20
```
**解析：** Proc 中的 `return` 会从定义它的方法中返回，因此 `test` 返回 `10`，后续 `20` 不执行；Lambda 中的 `return` 只从 Lambda 自身返回，`test2` 继续执行并返回 `20`。

### 29. 简答题：简述 Ruby 中 `include`、`extend` 与 `prepend` 三者的区别与典型使用场景。

**参考答案：**
- `include`：将模块的实例方法混入到类的实例方法查找链中，模块位于类上方（祖先链中类在前）。
- `extend`：将模块的方法作为单例方法添加到接收者，常用于给对象添加类方法或单例方法。
- `prepend`：将模块插入到类之前（祖先链中模块在类前），使得模块方法可以调用 `super` 覆盖类中的同名方法，常用于 AOP 或装饰器。

### 30. 以下代码执行后，`Foo.bar` 和 `Foo.new.baz` 的行为分别是？
```ruby
module M
  def bar; "module bar"; end
  def baz; "module baz"; end
end
class Foo
  extend M
  include M
end
```
A. `Foo.bar` 可用，`Foo.new.baz` 可用  
B. `Foo.bar` 可用，`Foo.new.baz` 不可用  
C. `Foo.bar` 不可用，`Foo.new.baz` 可用  
D. 均不可用

**答案：A**  
**解析：** `extend M` 将模块方法加入 `Foo` 的单例类，因此 `Foo.bar` 可用；`include M` 将模块方法加入实例方法查找链，因此 `Foo.new.baz` 可用。

### 31. 判断：Ruby 的模块（Module）不能直接实例化，也不能被继承，但可以被类 `include` 或 `extend`。

**答案：** ✅正确  
**解析：** Module 没有 `new` 方法，也不能作为 superclass。它的主要作用是封装可复用方法和常量，通过 `include`/`extend`/`prepend` 混入到类或对象中。

### 32. 请补全：使用元编程在类 `C` 中动态定义名为 `greet` 的实例方法，可写为 `C.class_eval { define_method(:greet) { "hello" } }`，也可以写为 `C.send(:________, :greet) { "hello" }`。

**答案：** `define_method`  
**解析：** `define_method` 是 `Module` 的私有方法，因此调用时通常使用 `send` 或 `class_eval`/`module_eval` 来绕过私有性限制，动态生成方法。

### 33. 以下代码的输出是？
```ruby
def append(x, arr = [])
  arr << x
  arr
end
p append(1)
p append(2)
```
A. `[1]` 然后 `[2]`  
B. `[1]` 然后 `[1, 2]`  
C. 抛出异常  
D. `[2]` 然后 `[1, 2]`

**答案：B**  
**解析：** Ruby 的方法默认参数在方法定义时只计算一次，因此可变默认参数（如空数组）会在多次调用间共享，导致副作用。应改为 `arr = nil; arr ||= []`。

### 34. 简答题：简述 `method_missing` 的使用场景及为什么通常需要同时实现 `respond_to_missing?`。

**参考答案：**
- `method_missing` 在对象收到未定义消息时触发，常用于动态代理、DSL、ORM（如 ActiveRecord 的动态查找器）。
- 仅实现 `method_missing` 会导致 `respond_to?` 返回 `false`，破坏多态和接口约定。同步实现 `respond_to_missing?` 可让 `respond_to?` 正确反映动态方法的存在，提升代码健壮性。

### 35. 判断：在模块中使用 `super` 时，Ruby 会沿着祖先链查找下一个定义同名方法的位置；如果模块被 `prepend`，`super` 会调用到被前置类中的实现。

**答案：** ✅正确  
**解析：** `prepend` 将模块插入到类之前，祖先链变为 `[M, C, Object, ...]`。因此模块中的方法先被调用，其 `super` 再调用类 `C` 中的同名方法，这是 AOP 实现的关键。

### 36. 以下代码的输出是？
```ruby
def capture(&b)
  b
end
p = capture { |x| x + 1 }
puts p.call(5)
```
A. `5`  
B. `6`  
C. 抛出异常  
D. `nil`

**答案：B**

### 45. 简答题：解释 Ruby 中的“鸭子类型”（Duck Typing），并给出一个代码示例。

**参考答案：**
鸭子类型指不关注对象的具体类，而关注它是否实现了所需的方法。

### 47. 判断：Ruby 允许重新打开已定义的类或模块并添加、修改方法，这种特性被称为类的“重新开放”（Class Reopening）。

**答案：** ✅正确  
**解析：** Ruby 的类定义不是一次性封闭的，可以随时重新打开补充方法。这也是猴子补丁（Monkey Patching）和标准库扩展的基础。

### 48. 请补全：调用 `obj.freeze` 后，`obj` 的对象状态变为________，试图修改会抛出 `FrozenError`。

### 50. 简答题：简述 Ruby 的方法查找路径（Method Lookup Path），并说明 `prepend` 如何影响该路径。

**参考答案：**
Ruby 方法查找从对象的单例类开始，沿 `ancestors` 链向上搜索：
`[singleton_class, prepend_modules, class, include_modules, superclass, ...]`。
`prepend` 将模块插入到类之前，使模块方法优先于类方法被调用；`include` 将模块插入到类之后。祖先链顺序决定 `super` 的跳转目标。

### 64. 编程题：使用元编程为一个类动态添加 `attr_checked` 宏，要求生成属性读取器和带校验的写入器，校验规则由块指定。

**参考答案：**
```ruby
module CheckedAttributes
  def attr_checked(name, &validation)
    define_method(name) do
      instance_variable_get("@#{name}")
    end
    define_method("#{name}=") do |value|
      raise ArgumentError, "invalid value for #{name}" unless validation.call(value)
      instance_variable_set("@#{name}", value)
    end
  end
end

class Person
  extend CheckedAttributes
  attr_checked(:age) { |v| v.is_a?(Integer) && v >= 0 }
end

p = Person.new
p.age = 30
puts p.age
```
**解析：** 通过 `extend` 引入模块方法到类中，模块内的 `define_method` 定义实例方法，块被保存为校验逻辑，体现了宏与元编程的结合。

### 66. 编程题：实现一个极简 DSL，用于描述配置文件，使其支持如下写法并输出最终哈希。

```ruby
def sieve(limit)
  flags = Array.new(limit + 1, true)
  flags[0] = flags[1] = false
  (2..Math.sqrt(limit)).each do |i|
    next unless flags[i]
    (i * i..limit).step(i) { |j| flags[j] = false }
  end
  (2..limit).select { |i| flags[i] }
end

```
**解析：** 用布尔数组标记合数，从 `i*i` 开始以步长 `i` 筛除，避免重复工作。时间复杂度 O(n log log n)。

### 82. 智力与逻辑题：给定一个只包含 `(`、`)`、`{`、`}`、`[`、`]` 的字符串，判断括号是否有效匹配。

**参考答案：**
```ruby
def valid_parentheses?(s)
  stack = []
  pairs = { ')' => '(', '}' => '{', ']' => '[' }
  s.each_char do |c|
    if pairs.values.include?(c)
      stack.push(c)
    elsif pairs.key?(c)
      return false if stack.empty? || stack.pop != pairs[c]
    end
  end
  stack.empty?
end

puts valid_parentheses?("({[]})")
puts valid_parentheses?("([)]")
```
**解析：** 使用栈结构，遇到左括号入栈，遇到右括号检查栈顶是否匹配。最终栈为空表示全部匹配。

### 83. 智力与逻辑题：将罗马数字字符串转换为整数。例如 `"MCMXCIV"` → `1994`。

**参考答案：**
```ruby
ROMAN = { 'I' => 1, 'V' => 5, 'X' => 10, 'L' => 50,
          'C' => 100, 'D' => 500, 'M' => 1000 }.freeze

def roman_to_int(s)
  total = 0
  prev = 0
  s.reverse.each_char do |c|
    value = ROMAN[c]
    if value < prev
      total -= value
    else
      total += value
    end
    prev = value
  end
  total
end

puts roman_to_int("MCMXCIV")
```
**解析：** 从右向左遍历，当前值小于前一个值时相减（如 `IV` 中的 `I`），否则相加。利用常量哈希和冻结保证不可变性。

### 85. 综合应用题：设计并实现一个 `Pipeline` 类，支持通过 `add` 方法注册处理步骤（Proc/Lambda），并通过 `call` 按顺序处理输入数据。要求支持 `|>` 风格的链式调用。

**参考答案：**
```ruby
class Pipeline
  include Enumerable

  def initialize
    @steps = []
  end

  def add(&block)
    @steps << block
    self
  end

  def call(input)
    @steps.reduce(input) { |data, step| step.call(data) }
  end

  alias_method :>>, :add

  def each(&block)
    @steps.each(&block)
  end
end

pipeline = Pipeline.new
  .add { |x| x + 1 }
  .add { |x| x * 2 }
puts pipeline.call(3)
```
**解析：** 使用 `reduce` 依次传递数据给每个步骤；通过 `alias_method` 为 `add` 创建别名 `>>`，实现链式 DSL。`Enumerable` 混入后可直接迭代步骤。

### 89. 系统设计题：设计一个基于 Ruby Module 的插件系统，使主应用可以在不修改核心代码的情况下加载、启用和禁用插件。请描述关键类和模块，并给出核心代码片段。

**参考答案：**
- **Plugin 模块约定**：每个插件是一个 Module，实现 `self.configure(app)` 和可选的 `self.enabled?`。
- **PluginRegistry**：负责注册、加载、启用/禁用插件。
- **Application**：提供扩展点（hooks），在生命周期中调用插件。

```ruby
module PluginSystem
  class Registry
    def initialize
      @plugins = {}
    end

    def register(name, mod)
      @plugins[name] = mod
    end

    def enable(name, app)
      @plugins[name]&.configure(app)
    end

    def disable(name)
      @plugins.delete(name)
    end
  end

  class Application
    attr_reader :hooks

    def initialize
      @hooks = Hash.new { |h, k| h[k] = [] }
    end

    def on(event, &block)
      @hooks[event] << block
    end

    def trigger(event)
      @hooks[event].each { |b| b.call(self) }
    end
  end
end

module LoggingPlugin
  def self.configure(app)
    app.on(:start) { |a| puts "App started" }
    app.on(:stop)  { |a| puts "App stopped" }
  end
end

app = PluginSystem::Application.new
registry = PluginSystem::Registry.new
registry.register(:logging, LoggingPlugin)
registry.enable(:logging, app)
app.trigger(:start)
```
**解析：** 插件系统通过模块约定、注册表和事件钩子解耦核心与扩展。Module 的 `self.configure` 作为入口，Application 暴露生命周期事件供插件订阅。

### 90. 编程题：实现一个自定义集合类 `BoundedQueue`，支持 `enqueue`、`dequeue` 和 `each`，并混入 `Enumerable` 使其支持 `map`、`select` 等标准方法。

**参考答案：**
```ruby
class BoundedQueue
  include Enumerable

  def initialize(capacity)
    @capacity = capacity
    @items = []
  end

  def enqueue(item)
    raise "Queue full" if @items.size >= @capacity
    @items << item
    self
  end

  def dequeue
    @items.shift
  end

  def each(&block)
    @items.each(&block)
  end

  def size
    @items.size
  end
end

q = BoundedQueue.new(3)
q.enqueue(1).enqueue(2).enqueue(3)
p q.map { |x| x * 10 }
p q.select(&:odd?)
```
**解析：** 只要实现 `each` 方法并 `include Enumerable`，集合即可自动获得 `map`、`select`、`reduce` 等大量迭代方法。`BoundedQueue` 还限制了容量，体现面向对象封装。
