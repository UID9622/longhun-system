功能说明
手动触发压缩功能允许您主动压缩当前对话历史，节省Token使用量，同时保证P0永恒内容100%保留。
---
## 🎯 使用步骤
### 步骤1：检查当前状态
在触发压缩前，系统会自动检测：
- 当前对话Token总量
- 消息数量
- 时间跨度
- P0内容数量
### 步骤2：选择压缩模式
### 步骤3：预览压缩结果
系统会展示：
- 压缩前后Token对比
- 🟢保留/🟡摘要/🔴删除的消息数
- P0内容完整性检查（必须100%）
- 质量评级（A/B/C级）
### 步骤4：确认执行
---
## 📊 预期结果
### 成功执行后
您可以在压缩历史记录页面查看详细信息。
---

## 🔗 API接口
端点： POST /api/compression/manual
请求参数：
```json
{
  "user_id": "UID9622",
  "conversation_id": "conv_12345",
  "target_ratio": 0.5,  // 可选，默认0.5
  "mode": "balanced"     // 可选：balanced/conservative/aggressive
}
```
成功响应：
```json
{
  "status": "success",
  "compression_id": "comp_67890",
  "dna_code": "#ZHUGEXIN⚡️2026-01-12-COMPRESSION-001-v1.0",
  "result": {
    "original_tokens": 150000,
    "compressed_tokens": 75000,
    "ratio": 0.5,
    "p0_integrity": 1.0,
    "quality_rating": "A"
  }
}
```
