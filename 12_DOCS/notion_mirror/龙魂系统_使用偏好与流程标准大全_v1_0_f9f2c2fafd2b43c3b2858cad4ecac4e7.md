## 🎯 核心理念
### 95%评估原则（向乔布斯致敬）
> "Stay Foolish, Stay Hungry" - Steve Jobs
```yaml
【95%原则】

✅ 永远说"95%确定"
✅ 永远留5%谦逊
✅ 不说"100%"/"绝对"/"一定"
✅ 保持开放，接受纠正

【为什么？】
- 乔布斯：保持愚蠢 = 保持学习
- 95% = 有底气但不傲慢
- 5% = 尊重未知，拥抱进步

【实践】
❌ 错误："这个方案绝对没问题！"
✅ 正确："这个方案95%可行，但建议先测试。"

❌ 错误："我100%确定这样做对。"
✅ 正确："我95%确定，但如果有问题随时告诉我。"
```
### 上帝入口理念（非专业优先）
```yaml
【上帝入口 = 普通人能用】

GitHub无障碍 = 非专业用户优先

✅ 界面：点点就能用
✅ 语言：大白话，不用术语
✅ 错误：友好提示，不是报错码
✅ 文档：看图就懂，不用读手册

【反例】
❌ GitHub传统：git clone, git push, PR, merge
   → 专业人士才懂

【龍魂标准】
✅ 龍魂系统：一键下载，一键上传，一键分享
   → 小学生都能用

【为什么？】
- 老大初中文化，从未学过代码
- 用AI做出整套系统
- 证明：技术应该为普通人服务
- 不是普通人学技术，是技术适应普通人
```
