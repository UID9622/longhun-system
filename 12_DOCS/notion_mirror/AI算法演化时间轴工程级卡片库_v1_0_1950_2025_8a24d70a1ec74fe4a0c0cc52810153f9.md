## 0️⃣ 理论与起点（1943–1956）
### AI-1943-01｜1943 — McCulloch–Pitts 人工神经元
- 阶段：Theory
- 触发条件：想把"神经元怎么工作"变成"电路怎么算"的问题
- 核心假设：输入很多信号，每个有"重要程度"（权重），加起来超过门槛输出1，否则输出0
- 核心变量：
- 核心公式：
w leftarrow w - eta cdot frac{partial L}{partial w}$$
- 工程意义：神经网络从"概念"变"可迭代训练"
- 标签：#AI #DeepLearning #Optimization
### AI-1995-01｜1995 — 支持向量机（SVM）
- 阶段：Statistical
- 核心变量：$y_i$标签，$b$偏置
- 决策函数：
P(v,h) = frac{1}{Z}exp(-E(v,h))$$
- 工程意义：提供"先预训练再微调"的可行路径
- 标签：#AI #DeepLearning
### AI-2012-01｜2012 — AlexNet（CNN + GPU）
- 阶段：Deep
- 核心语法：Y = ReLU( Conv(X, K; S, P) + b )
- 工程意义：深度学习第一次在大规模视觉任务碾压传统方法
- 标签：#AI #CNN #GPU
### AI-2014-01｜2014 — Seq2Seq（机器翻译范式转折）
- 阶段：Deep
- 核心语法：h = Encoder(x); y = Decoder(h)
- 标签：#AI #NLP
### AI-2015-01｜2015 — ResNet（让更深网络可训练）
- 阶段：Deep
- 核心公式：
mathrm{Attention}(Q,K,V)=mathrm{softmax}left(frac{QK^top}{sqrt{d_k}}right)V$$
- 工程意义：并行训练，长依赖更稳，成为大模型底座
- 标签：#AI #Transformer #Attention
### AI-2018-01｜2018 — BERT（双向预训练）
- 阶段：Transformer
- 核心语法：
P(w_{1:T})=prod_{t=1}^{T} P(w_t mid w_{<t})$$
- 工程意义："参数规模 + 数据规模 + 算力"带来通用能力跃迁
- 标签：#AI #LLM
### AI-2021-01｜2021 — Instruct / RLHF
- 阶段：Foundation
- 核心变量：$pi_theta$策略模型，$r_phi$奖励模型，$beta$KL约束强度
- 核心目标：
x_t = sqrt{alpha_t},x_0 + sqrt{1-alpha_t},epsilon$$
- 标签：#AI #Diffusion #GenerativeAI
### AI-2022-02｜2022 — ChatGPT
- 阶段：Foundation
- 核心结构：把"大模型 + 指令对齐"做成普通人能直接聊的产品
- 工程意义：让"AI在真实世界被使用"发生拐点
- 标签：#AI #LLM #Chatbot
### AI-2023-01｜2023 — RAG（检索增强生成）
- 阶段：Foundation
- 核心结构：Retrieve → Read/Generate → Cite/Store
- 核心语法：
```javascript
docs = topk(retriever(q, D), k)
answer = LLM(q, docs)
```
- 标签：#AI #RAG #KnowledgeBase
### AI-2024-01｜2024 — Agent化（模型 → 系统）
- 阶段：Agent
- 核心结构：
```javascript
Agent
	Memory
	Planning
	Tool Use
	Action
```
- 最小执行语法：
```javascript
while not done:
	plan = Planner(goal, memory)
	action = ToolRouter(plan)
	result = Execute(action)
	memory.append(result)
```
- 标签：#AI #Agent #Automation
