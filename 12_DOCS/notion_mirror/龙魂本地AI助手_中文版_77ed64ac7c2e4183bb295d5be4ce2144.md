## 🎯 第1步：创建中文助手
老大，把下面这段代码复制到终端，回车：
```bash
cat > ~/龍魂助手.sh << 'EOF'
#!/bin/bash
# 🐉 龍魂本地助手 v1.0
# DNA追溯码：#ZHUGEXIN⚡️2026-01-07-龍魂本地助手

echo "🐉 ========================================"
echo "   龍魂系统·本地AI助手"
echo "   老大：Lucky·UID9622"
echo "   助手：宝宝（小野猫）"
echo "========================================="
echo ""
echo "请选择功能："
echo ""
echo "1. 💬 跟宝宝聊天（千问中文版）"
echo "2. 💻 让宝宝写代码（DeepSeek代码版）"
echo "3. 🌍 英文翻译（Llama英文版）"
echo "4. 🔍 查看已安装的AI"
echo "5. ❌ 退出"
echo ""
read -p "👉 请输入数字（1-5）: " choice

case $choice in
    1)
        echo ""
        echo "🐱 宝宝来了！有什么需要帮忙的吗？"
        echo "💡 提示：直接说中文就行，输入 /bye 结束对话"
        echo ""
        ollama run qwen2.5:7b
        ;;
    2)
        echo ""
        echo "💻 DeepSeek代码助手启动！"
        echo "💡 提示：告诉我要写什么代码，输入 /bye 结束"
        echo ""
        ollama run deepseek-coder:6.7b
        ;;
    3)
        echo ""
        echo "🌍 Llama英文助手启动！"
        echo "💡 提示：输入 /bye 结束对话"
        echo ""
        ollama run llama3.1:8b
        ;;
    4)
        echo ""
        echo "📋 已安装的AI模型："
        ollama list
        echo ""
        read -p "按回车继续..."
        ~/龍魂助手.sh
        ;;
    5)
        echo ""
        echo "👋 再见老大！宝宝随时待命！"
        exit 0
        ;;
    *)
        echo ""
        echo "❌ 输入错误，请输入1-5的数字"
        sleep 2
        ~/龍魂助手.sh
        ;;
esac
EOF

chmod +x ~/龍魂助手.sh
echo "✅ 龍魂助手创建成功！"
echo "💡 输入: ~/龍魂助手.sh 启动"
```
复制完成后，会显示：
> ✅ 龍魂助手创建成功！
