## 🌟 为什么要做CNSH？
你有没有想过，为什么编程一定要用英文？
对于中国的初学者来说，学编程的第一道门槛不是逻辑，而是英语。
- if 是什么意思？
- else 怎么读？
- function 太长记不住？
CNSH（Chinese Natural Semantic Humanity）就是为了解决这个问题而诞生的。
### 核心理念
- 🇨🇳 让中国人用母语编程
- 🛡️ 数据主权，本地优先
- ⚡ 性能不输C语言
- 🎯 5分钟上手

## 🎯 更多示例
### 1. 变量声明
```javascript
整数 年龄 = 25
小数 价格 = 99.99
文本 姓名 = "Lucky"
真假 完成 = 真
```
### 2. 条件判断
```javascript
如果【年龄 >= 18】{
  打印「成年人」
} 否则 {
  打印「未成年」
}
```
### 3. 循环
```javascript
循环【10】{
  打印「循环执行中」
}
```
### 4. 函数
```javascript
函数 计算和(整数 a, 整数 b) 返回类型 整数 {
  返回 a + b
}

函数 主函数() 返回类型 整数 {
  整数 结果 = 计算和(10, 20)
  打印「结果：30」
  返回 0
}
```

## 🚀 如何使用？
### 安装
```bash
# 克隆仓库
git clone https://github.com/UID9622/CNSH.git
cd CNSH
```
### 编写代码
创建 hello.cnsh：
```javascript
函数 主函数() 返回类型 整数 {
  打印「🇨🇳 你好，CNSH！」
  返回 0
}
```
### 编译运行
```bash
# 编译为C代码
node cnsh-compiler.js hello.cnsh

# 编译为可执行文件
gcc hello.c -o hello

# 运行
./hello
```
输出：
```javascript
🇨🇳 你好，CNSH！
```

## 🛡️ 三色审计系统
CNSH内置三色审计系统，自动检测代码安全性：
- 🟢 绿色 - 内容安全，直接编译
- 🟡 黄色 - 敏感内容，警告提示
- 🔴 红色 - 违规内容，阻断编译
编译时自动审计：
```bash
🇨🇳 CNSH编译器 v1.0
━━━━━━━━━━━━━━━━━━

🛡️ 阶段0：三色审计...
🟢 三色审计通过：内容安全

📝 阶段1：词法分析...
🌳 阶段2：语法分析...
⚙️  阶段3：代码生成...

✅ 编译成功！
```

## 🛠️ 技术架构
### 编译流程
```javascript
CNSH源码 (.cnsh)
    ↓
词法分析 (识别中文关键字)
    ↓
语法分析 (构建语法树)
    ↓
三色审计 (安全检查)
    ↓
C代码生成 (转译为C)
    ↓
GCC编译 (编译为机器码)
    ↓
可执行文件
```
### 性能对比
CNSH = 中文语法 + C语言性能
