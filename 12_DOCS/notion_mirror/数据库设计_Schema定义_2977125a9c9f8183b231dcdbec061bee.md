## 📊 Notion数据库
### 1. 开源沙盒评估中心
用途： 管理提案、评估题库、周卡收集
属性设计：
视图设计：
```javascript
1. 全部数据（Table）- 默认视图
2. 公共评估题库（Table）- 过滤：类型=评估题库 AND 开放程度=公开
3. 提案收件箱（Table）- 过滤：类型=提案 AND 状态=待审查
4. 进行中（Board）- 按状态分组
5. 历史归档（Table）- 过滤：状态=已通过，按截止日期降序
6. 贡献榜（Table）- 按贡献分降序
7. 灵感角周卡（Table）- 过滤：标题包含"沙盒灵感角｜周卡"，按截止日期升序
```

## 🗄️ MongoDB本地数据库
### Collection: users
用途： 存储用户信息和权限
```javascript
{
  _id: ObjectId,
  notionUserId: String,          // Notion用户ID
  email: String,                 // 邮箱
  name: String,                  // 姓名
  avatar: String,                // 头像URL
  level: String,                 // L1-L5
  contributionScore: Number,     // 贡献分
  permissions: [String],         // 权限列表
  votingPower: Number,           // 投票权重
  createdAt: Date,
  updatedAt: Date,
  
  // 索引
  indexes: [
    { notionUserId: 1 },
    { email: 1 },
    { level: 1, contributionScore: -1 }
  ]
}
```
---
### Collection: contribution_logs
用途： 记录所有贡献行为
```javascript
{
  _id: ObjectId,
  userId: ObjectId,              // 用户ID
  type: String,                  // 贡献类型：code/doc/sandbox/bug
  action: String,                // 具体动作：pr_merged/doc_updated/weekly_selected
  score: Number,                 // 本次得分
  metadata: {
    notionPageId: String,        // 关联的Notion页面
    prUrl: String,               // GitHub PR链接
    rank: Number,                // 排名（如果是周卡）
  },
  createdAt: Date,
  
  // 索引
  indexes: [
    { userId: 1, createdAt: -1 },
    { type: 1 },
    { createdAt: -1 }
  ]
}
```

### Collection: nlp_cache
用途： 缓存中文NLP结果
```javascript
{
  _id: ObjectId,
```

## 🔴 Redis缓存设计
### 键命名规范
```javascript
{namespace}:{entity}:{id}:{field}

示例：
uid9622:db:abc123:schema        # 数据库结构
uid9622:page:xyz789:content     # 页面内容
uid9622:user:user-uuid:profile  # 用户资料
uid9622:nlp:hash123:result      # NLP结果
```
### 常用缓存键
```javascript
# 数据库结构（1小时）
SET uid9622:db:{db_id}:schema '{json}' EX 3600

# 页面内容（5分钟）
SET uid9622:page:{page_id}:content '{json}' EX 300

# 用户资料（30分钟）
SET uid9622:user:{user_id}:profile '{json}' EX 1800

# NLP结果（1天）
SET uid9622:nlp:{text_hash}:tokens '["token1","token2"]' EX 86400

# 限流计数器（1秒）
INCR uid9622:ratelimit:{ip}:count
EXPIRE uid9622:ratelimit:{ip}:count 1

# 分布式锁（10秒）
SET uid9622:lock:{resource} '{owner}' NX EX 10
```

## 🔄 数据同步策略
### Notion → MongoDB
```typescript
// 定时同步（每小时）
cron.schedule('0 * * * *', async () => {
  // 1. 查询Notion贡献榜
  const contributors = await notion.databases.query({
    database_id: SANDBOX_DB_ID,
    sorts: [{ property: '贡献分', direction: 'descending' }]
  });
  
  // 2. 更新MongoDB用户表
  for (const page of contributors.results) {
    const userId = page.properties['提案人'].people[0]?.id;
    const score = page.properties['贡献分'].number;
    
    await db.collection('users').updateOne(
      { notionUserId: userId },
      { 
        $set: { 
          contributionScore: score,
          updatedAt: new Date()
        }
      },
      { upsert: true }
    );
  }
});
```
### MongoDB → Redis
```typescript
// 热数据预热
async function warmupCache() {
  // 前100名贡献者
  const topContributors = await db.collection('users')
    .find({})
    .sort({ contributionScore: -1 })
    .limit(100)
    .toArray();
  
  for (const user of topContributors) {
    await redis.set(
      `uid9622:user:${user.notionUserId}:profile`,
      JSON.stringify(user),
      'EX', 1800
    );
  }
}
```

## 📈 数据统计查询
### 1. 用户贡献排行
```javascript
// MongoDB聚合
db.contribution_logs.aggregate([
  // 按用户分组
  {
    $group: {
      _id: '$userId',
      totalScore: { $sum: '$score' },
      codeContributions: {
        $sum: { $cond: [{ $eq: ['$type', 'code'] }, 1, 0] }
      },
      docContributions: {
        $sum: { $cond: [{ $eq: ['$type', 'doc'] }, 1, 0] }
      },
      sandboxWins: {
        $sum: { $cond: [{ $eq: ['$action', 'weekly_selected'] }, 1, 0] }
      }
    }
  },
  // 关联用户信息
  {
    $lookup: {
      from: 'users',
      localField: '_id',
      foreignField: '_id',
      as: 'user'
    }
  },
  // 排序
  { $sort: { totalScore: -1 } },
  // 限制
  { $limit: 20 }
]);
```
### 2. 周度贡献趋势
```javascript
// MongoDB聚合
db.contribution_logs.aggregate([
  // 最近12周
  {
    $match: {
      createdAt: { $gte: new Date(Date.now() - 12 * 7 * 24 * 3600000) }
    }
  },
  // 按周分组
  {
    $group: {
      _id: {
        week: { $week: '$createdAt' },
        year: { $year: '$createdAt' }
      },
      totalScore: { $sum: '$score' },
      contributors: { $addToSet: '$userId' }
    }
  },
  // 计算活跃贡献者数
  {
    $addFields: {
      activeContributors: { $size: '$contributors' }
    }
  },
  { $sort: { '_id.year': 1, '_id.week': 1 } }
]);
```
