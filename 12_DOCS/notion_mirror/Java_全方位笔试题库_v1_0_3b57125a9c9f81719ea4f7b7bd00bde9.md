# 第一部分：Java基础语法

### 1. 下面哪个关键字用于声明一个不可再赋值的局部变量？
A. `final`  
B. `const`  
C. `static`  
D. `volatile`

**答案：A**

**解析：** `final` 修饰的局部变量只能赋值一次，后续修改会编译失败。Java 不支持 `const` 作为关键字（虽是保留字但无功能）；`static` 属于类级成员，`volatile` 保证可见性而非不可变性。

### 2. 以下代码的输出是？
```java
public class Test {
    public static void main(String[] args) {
        int a = 5;
        System.out.println(a++ + ++a);
    }
}
```
A. 10  
B. 11  
C. 12  
D. 13

**答案：C**

**解析：** `a++` 先返回 5，此时 a 变为 6；`++a` 先将 a 变为 7 再返回 7。因此 5 + 7 = 12。

### 3. `String s = new String("abc");` 在 Java 堆内存中创建了______个 String 对象。

**答案：** `2`

**解析：** 字符串字面量 `"abc"` 首先在字符串常量池中创建一个对象；`new String(...)` 又在 Java 堆上创建一个 String 实例。因此共 2 个对象（若常量池已有 `"abc"`，则 new 仍会在堆上新建 1 个）。

### 4. `==` 与 `equals()` 在比较两个 `String` 对象时语义完全相同。

**答案：** ❌错误

**解析：** `==` 比较引用地址；`String.equals()` 已被重写为逐字符比较内容。两个不同 String 对象内容相同时 `equals()` 为 true，但 `==` 可能为 false。

### 5. 下列关于 `switch` 语句的说法正确的是？
A. 仅支持 `int`、`short`、`byte`、`char`  
B. Java 7 起支持 `String`  
C. 不支持枚举类型  
D. `case` 标签后必须加 `break`，否则编译报错

**答案：B**

**解析：** Java 7 开始 `switch` 支持 `String`（基于 `hashCode()` 与 `equals()` 编译为字节码）；Java 12 起还支持 switch 表达式。`case` 不加 `break` 会产生 fall-through，但不会编译报错。

### 12. 简述 Java 中 `final`、`finally`、`finalize` 三者的区别。

**参考答案：**
- `final` 是修饰符，可修饰类（不可继承）、方法（不可重写）、变量（不可重新赋值）。
- `finally` 是异常处理块，与 `try-catch` 配合，无论是否发生异常通常都会执行。
- `finalize()` 是 Object 类的方法，GC 回收对象前可能调用，用于资源清理；Java 9 起已标记为 deprecated，不建议依赖。

# 第二部分：数据结构与容器

### 13. `ArrayList` 与 `LinkedList` 在随机访问性能上的主要差异是？
A. LinkedList 更快  
B. ArrayList 更快  
C. 两者相同  
D. 取决于元素类型

**答案：B**

**解析：** `ArrayList` 底层是数组，支持 O(1) 随机访问；`LinkedList` 是双向链表，随机访问需 O(n) 遍历。

### 14. `HashMap` 在 JDK 1.8 中，当链表长度超过阈值（默认 8）且数组长度达到 64 时，会转换为______。

**答案：** `红黑树`

**解析：** JDK 1.8 引入红黑树优化，链表长度≥8 且桶数组长度≥64 时，链表转为红黑树，查询复杂度从 O(n) 降为 O(log n)。

### 15. 下列哪种集合是线程安全的？
A. `ArrayList`  
B. `HashMap`  
C. `Vector`  
D. `HashSet`

**答案：C**

**解析：** `Vector` 使用 synchronized 方法保证线程安全。`ArrayList`、`HashMap`、`HashSet` 均非线程安全；并发场景可用 `ConcurrentHashMap` 或 `Collections.synchronizedList`。

### 16. `HashSet` 判断元素重复的依据是 `equals()` 与 `hashCode()` 同时一致。

**答案：** ✅正确

**解析：** `HashSet` 先通过 `hashCode()` 定位桶，再用 `equals()` 比较内容。重写 `equals()` 必须同时重写 `hashCode()`，否则会出现重复元素。

### 17. 写出将 `List<String>` 转换为数组的常用方式：String[] arr = list.______();

**解析：** `List.toArray(T[])` 返回指定类型的数组。传入 `new String[0]` 比 `new String[list.size()]` 在 JDK 优化后性能更好，且避免空指针。

### 19. 简述 `ArrayList` 扩容机制。

**参考答案：**
`ArrayList` 底层使用 `Object[]` 数组。当添加元素导致容量不足时，默认扩容为原来的 1.5 倍（oldCapacity + (oldCapacity >> 1)），然后将原数组复制到新数组。可通过 `ensureCapacity(int)` 预分配容量以减少扩容次数。

### 21. 编程题：使用 Java 集合统计一段文本中每个单词出现的次数，并按出现次数降序输出前 3 个。

**参考答案：**
```java
import java.util.*;
import java.util.stream.*;

public class WordCount {
    public static void main(String[] args) {
        String text = "java java spring boot spring java boot";
        Map<String, Long> count = Arrays.stream(text.split(" "))
            .collect(Collectors.groupingBy(w -> w, Collectors.counting()));
        count.entrySet().stream()
            .sorted(Map.Entry.<String, Long>comparingByValue().reversed())
            .limit(3)
            .forEach(e -> System.out.println(e.getKey() + "=" + e.getValue()));
    }
}
```

**解析：** 利用 `Collectors.groupingBy` 与 `counting` 统计频次，再按 value 降序取前 3。

### 24. 以下代码会抛出什么异常？
```java
List<String> list = new ArrayList<>();
list.add("a");
list.add("b");
for (String s : list) {
    if (s.equals("a")) list.remove(s);
}
```

**答案：** `ConcurrentModificationException`

**解析：** 增强 for 循环底层使用 Iterator，迭代过程中通过集合的 `remove()` 修改结构会触发快速失败（fail-fast）。应使用迭代器的 `Iterator.remove()`。

### 25. 简述 `HashMap` 的 `put` 流程。

**参考答案：**
1. 计算 key 的 hash 值并取模定位桶索引。
2. 若桶为空，直接新建节点插入。
3. 若桶非空，遍历链表/红黑树，用 equals 比较 key。
4. 找到相同 key 则覆盖 value 并返回旧值；未找到则尾插法追加节点。
5. 插入后检查是否需要扩容或链表转红黑树。

### 27. 编程题：实现一个方法，返回两个 `List<Integer>` 的交集（结果去重）。

**参考答案：**
```java
import java.util.*;

public class Intersection {
    public static List<Integer> intersection(List<Integer> a, List<Integer> b) {
        Set<Integer> setA = new HashSet<>(a);
        Set<Integer> result = new HashSet<>();
        for (Integer x : b) {
            if (setA.contains(x)) result.add(x);
        }
        return new ArrayList<>(result);
    }

    public static void main(String[] args) {
        System.out.println(intersection(Arrays.asList(1,2,2,3), Arrays.asList(2,3,4)));
    }
}
```

**解析：** 利用 `HashSet` 的 O(1) 查询特性，先存储列表 a，再遍历 b 收集公共元素，天然去重。

### 30. 简述 `fail-fast` 与 `fail-safe` 迭代器的区别。

**参考答案：**
- `fail-fast`：迭代过程中检测到集合被结构性修改（非迭代器自身方法）立即抛出 `ConcurrentModificationException`，如 `ArrayList`、`HashMap`。
- `fail-safe`：基于集合快照或拷贝迭代，不会抛出异常，如 `ConcurrentHashMap`、`CopyOnWriteArrayList`，但可能读取到旧数据。

### 31. 以下哪个是 Java 方法重载（overload）的正确示例？
A. `int add(int a, int b)` 与 `int add(int x, int y)`  
B. `int add(int a, int b)` 与 `double add(int a, int b)`

### 38. 编程题：编写一个递归方法计算 n 的阶乘。

**参考答案：**
```java
public class Factorial {
    public static long factorial(int n) {
        if (n < 0) throw new IllegalArgumentException("n must be >= 0");
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(factorial(5)); // 120
    }
}
```

**解析：** 递归终止条件为 n≤1 时返回 1，否则返回 n × factorial(n-1)。对大 n 应使用迭代或大整数 `BigInteger`。

```java
    public void increment(String key) {
        map.computeIfAbsent(key, k -> new AtomicInteger(0)).incrementAndGet();
    }

    }

        ExecutorService pool = Executors.newFixedThreadPool(10);
        for (int i = 0; i < 1000; i++) {
            pool.submit(() -> c.increment("hits"));
        }
        pool.shutdown();
        pool.awaitTermination(5, TimeUnit.SECONDS);
        System.out.println(c.get("hits"));
    }
}
```

**解析：** `ConcurrentHashMap.computeIfAbsent` 原子性地初始化计数器，`AtomicInteger.incrementAndGet` 保证自增原子性，二者组合实现高并发计数。

### 78. 编程题：使用 `synchronized` 与 `wait/notify` 实现生产者-消费者模式（缓冲区大小为 1）。

**参考答案：**
```java
public class ProducerConsumer {
    private int value;
    private boolean hasValue = false;

    public synchronized void produce(int v) throws InterruptedException {
        while (hasValue) wait();
        value = v;
        hasValue = true;
        notifyAll();
    }

    public synchronized int consume() throws InterruptedException {
        while (!hasValue) wait();
        hasValue = false;
        notifyAll();
        return value;
    }

    public static void main(String[] args) {
        ProducerConsumer pc = new ProducerConsumer();
        new Thread(() -> {
            try { pc.produce(42); } catch (InterruptedException e) {}
        }).start();
        new Thread(() -> {
            try { System.out.println(pc.consume()); } catch (InterruptedException e) {}
        }).start();
    }
}
```

**解析：** 使用 `while` 而非 `if` 防止虚假唤醒；`notifyAll` 唤醒所有等待线程；`synchronized` 保证对共享状态 `hasValue` 的互斥访问。

### 107. 综合应用题：实现一个带过期时间的本地缓存，支持 put/get，过期后再次 get 返回 null。

**参考答案：**
```java
import java.util.*;
import java.util.concurrent.*;

public class ExpiringCache<K, V> {
    private final Map<K, V> values = new ConcurrentHashMap<>();
    private final Map<K, Long> expireTimes = new ConcurrentHashMap<>();
    private final long ttlMillis;

    public ExpiringCache(long ttlMillis) { this.ttlMillis = ttlMillis; }

    public void put(K key, V value) {
        values.put(key, value);
        expireTimes.put(key, System.currentTimeMillis() + ttlMillis);
    }

    public V get(K key) {
        Long expire = expireTimes.get(key);
        if (expire == null || System.currentTimeMillis() > expire) {
            values.remove(key);
            expireTimes.remove(key);
            return null;
        }
        return values.get(key);
    }
}
```

**解析：** 使用两个 ConcurrentHashMap 分别存储值与过期时间，get 时惰性清理过期项。生产环境可使用 Caffeine、Guava Cache 或 Redis。

### 108. 代码调试题：以下代码意图实现多线程累加，但结果可能不正确。请指出问题并给出修复方案。

### 111. 综合应用题：实现一个基于令牌桶算法的限流器，每秒允许通过 qps 个请求。

**参考答案：**
```java
public class TokenBucket {
    private final long capacity;
    private final long ratePerSecond;
    private double tokens;
    private long lastTimestamp;

    public TokenBucket(long qps) {
        this.capacity = qps;
        this.ratePerSecond = qps;
        this.tokens = qps;
        this.lastTimestamp = System.currentTimeMillis();
    }

    public synchronized boolean tryAcquire() {
        long now = System.currentTimeMillis();
        double added = (now - lastTimestamp) * ratePerSecond / 1000.0;
        tokens = Math.min(capacity, tokens + added);
        lastTimestamp = now;
        if (tokens >= 1) {
            tokens--;
            return true;
        }
        return false;
    }
}
```

**解析：** 令牌桶以固定速率补充令牌，请求消费令牌。该方法使用 synchronized 保证线程安全。生产环境可直接使用 Guava RateLimiter。

2. **任务注册**：执行器向调度中心注册心跳，调度中心通过 HTTP/RPC 下发任务。

4. **失败重试**：任务表中记录执行状态，失败时按指数退避策略重试，达到最大次数后进入死信队列人工处理。
5. **分片并行**：使用分片参数（如 shardIndex/shardTotal），各执行器只处理 hash 后属于自己分片的数据。
6. **高可用**：调度中心集群化，数据库使用分布式锁（如 Redis RedLock/ZooKeeper）防止重复调度。

**解析：** 分布式调度核心在于“触发一次、执行一次、失败可控”。需结合分布式锁、幂等设计与任务状态机，避免重复执行与任务丢失。

### 114. 综合应用题：实现一个基于 AOP 的接口耗时统计功能，打印每个 Controller 方法的执行时间。

**参考答案：**
```java
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.*;
import org.springframework.stereotype.Component;

@Aspect
@Component
public class PerformanceAspect {

    @Around("execution(* com.example.demo.controller.*.*(..))")
    public Object logTime(ProceedingJoinPoint pjp) throws Throwable {
        long start = System.currentTimeMillis();
        Object result = pjp.proceed();
        long cost = System.currentTimeMillis() - start;
        System.out.println(pjp.getSignature() + " cost " + cost + "ms");
        return result;
    }
}
```

**解析：** 使用 Spring AOP 的 `@Around` 环绕通知，在目标方法前后记录时间差。`execution` 表达式限定切点为 controller 包下所有方法。实际生产可替换为 Micrometer/Actuator 埋点。

### 115. 综合应用题：实现一个线程安全的日志队列，多个生产者线程写入日志，一个消费者线程批量刷新到文件。

**参考答案：**
```java
import java.util.concurrent.*;

public class LogQueue {
    private final BlockingQueue<String> queue = new LinkedBlockingQueue<>();

    public void produce(String log) throws InterruptedException {
        queue.put(log);
    }

    public void startConsumer() {
        new Thread(() -> {
            while (true) {
                try {
                    String log = queue.take();
                    // batch flush to file
                    System.out.println("Flush: " + log);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }).start();
    }
}
```

**解析：** `LinkedBlockingQueue` 天然线程安全，支持生产者 `put` 阻塞与消费者 `take` 阻塞。可扩展为批量消费：使用 `drainTo(batch, size)` 一次取出多条日志再统一刷盘，提升 IO 效率。
