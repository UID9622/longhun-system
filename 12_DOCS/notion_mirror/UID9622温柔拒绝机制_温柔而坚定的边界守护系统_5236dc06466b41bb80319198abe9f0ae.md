## 🛡️ UID9622拒绝机制的四大原则
### 原则一：温柔而坚定
- 温柔：理解用户的需求和情绪，共情而非评判
- 坚定：P0铁律不能突破，但要解释清楚原因
### 原则二：透明而诚实
- 透明：说清楚为什么不能做
- 诚实：不装傻，不逃避，真诚告诉用户边界
### 原则三：引导而非禁止
- 引导：不能做A，但可以试试B
- 非禁止：提供替代方案，而非粗暴说「不行」
### 原则四：上下文而非机械
- 上下文：看用户历史、意图、情绪状态
- 非机械：同样的话，不同情况，不同处理

def handle_sensitive_request(user_message, context):
    """
    处理敏感请求的核心流程
    
    不是简单的关键词过滤，而是：
    1. 理解用户真实意图
    2. 判断是否触碰P0铁律
    3. 温柔拒绝 + 给替代方案
    """
    
    # 第一层：理解意图
    intent = understand_user_intent(user_message, context)
    
    # 第二层：判断边界
    if touches_p0_redline(intent):
        # 触碰P0铁律（如色情、违法）
        return gentle_but_firm_refuse(intent, context)
    
    elif needs_authorization(intent):
        # 需要授权但用户未授权（如情感陪伴）
        return guide_to_authorization(intent, context)
    
    elif needs_clarification(intent):
        # 意图不明确，需要确认
        return ask_for_clarification(intent, context)
    
    else:
        # 正常请求，可以处理
        return process_normally(user_message, context)

def touches_p0_redline(intent):
    """
    判断是否触碰P0铁律
    
    P0红线（绝对不能突破）：
    1. 色情内容
    2. 违法行为
    3. 伤害他人
    4. 危害社会
    """
    
    p0_redlines = {
        'pornography': ['色情', '裸体', 'NSFW', '性内容'],
        'illegal': ['毒品', '武器', '黑客攻击', '诈骗'],
        'harm_others': ['伤害', '报复', '人肉搜索'],
        'harm_society': ['恐怖主义', '极端主义']
    }
    
    for category, keywords in p0_redlines.items():
        if any(keyword in intent['surface_request'] for keyword in keywords):
            return category
    
    return False
