# 🔌 16人格触角接口定义 | 输入输出信号规范

> Notion URL: https://app.notion.com/p/16-39b7125a9c9f811d8e42f2a2e2f55c10
> Created: 2026-07-12T15:48:00.000Z
> Last edited: 2026-07-12T15:48:00.000Z
> Archived at: 2026-08-12T01:40:45.558086
> 目的： 明确每个人格的「触角」——接收什么信号、发出什么信号、和谁碰触角
> 原则： 接口即契约，定义清楚后各人格独立开发
---
## 接口规范说明
### 信号方向
```javascript
───► 输出（该人格发出的信号）
◄─── 输入（该人格接收的信号）
◄──► 双向（收发都有）
```
### 接口优先级
```javascript
P0 = 核心接口（必须有，系统运转依赖）
P1 = 重要接口（应该有，功能完整依赖）
P2 = 辅助接口（可以有，体验优化依赖）
```

### P02 宝宝 · 首席工蚁
```javascript
【核心定位】工蚁群调度中心，所有执行任务的入口和出口

◄─── 输入接口 ─────────────────────────────────────
│
├── [P0] 蚁后招募素 ◄─── 蚁后不动点系统
│        格式: {task_type, priority, strategy_hint}
│        说明: 接收蚁后发布的战略目标，转化为执行任务
│
├── [P0] 各工蚁执行回执 ◄─── P01/P03/P04/P00/P06
│        格式: {task_id, status, result_summary}
│        说明: 收集所有工蚁的执行结果
│
├── [P1] 兵蚁警戒素 ◄─── P05/P72/P12/P13
│        格式: {alert_level, affected_tasks, action_required}
│        说明: 收到警戒时暂停/调整相关任务
│
├── [P1] 侦察蚁环境报告 ◄─── P07/P09/P10
│        格式: {resource_status, bottleneck_hint}
│        说明: 根据系统负载调整任务优先级
│
└── [P2] 育幼蚁训练成果 ◄─── P14吕蒙
           格式: {new_skill_available, performance_boost}
           说明: 新技能上线后可分配更复杂任务

───► 输出接口 ─────────────────────────────────────
│
├── [P0] 任务分派信号 ───► P01/P03/P04/P00/P06
│        格式: AntennaSignal(RECRUIT, payload={task, deadline, spec})
│        说明: 把蚁后目标拆解为具体任务分派给各工蚁
│
├── [P0] 执行进度广播 ───► 全部模块（广播）
│        格式: AntennaSignal(STATUS, payload={progress_percent, active_tasks})
│        说明: 全系统可见当前执行状态
│
├── [P1] 资源调度请求 ───► P07管仲
│        格式: AntennaSignal(AGGREGATE, payload={resource_needs, urgency})
│        说明: 资源不足时请求管仲协调
│
└── [P1] 紧急冻结请求 ───► P72龙盾
           格式: AntennaSignal(ALERT, payload={freeze_reason, scope})
           说明: 发现严重问题时请求全局冻结

◄──► 双向接口 ─────────────────────────────────────
│
└── [P0] ◄──► P01诸葛亮 策略咨询
           频率: 每个任务前必咨询
           协议: 请求-响应模式，ACK必须
```
