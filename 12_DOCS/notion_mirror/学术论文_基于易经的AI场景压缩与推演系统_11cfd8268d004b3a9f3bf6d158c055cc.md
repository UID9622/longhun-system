## 🧬 九步框架详解
### Step 1: 观天（Observe Heaven）— 环境扫描
> 「观天之道，执天之行。」— 易经
```javascript
输入：对话历史 C = {m₁, m₂, ..., mₙ}
输出：环境状态 E

E ← ∅
FOR each message mᵢ in C:
    提取实体 ℰ(mᵢ)
    提取意图 ℐ(mᵢ)
    提取情感 𝒮(mᵢ)
    E ← E ∪ {ℰ(mᵢ), ℐ(mᵢ), 𝒮(mᵢ)}
RETURN E
```
### Step 2: 问地（Ask Earth）— 领域锚定
> 「地势坤，君子以厚德载物。」— 易经·坤卦
领域分类：
- 技（Technical）：代码、算法、系统设计
- 哲（Philosophical）：伦理、认识论、形而上学
- 文（Creative）：写作、艺术、叙事
- 谋（Strategic）：规划、决策、博弈
### Step 3: 演人（Deduce Human）— 人格分配
> 「人法地，地法天，天法道，道法自然。」— 道德经
人格映射函数：
```javascript
Persona(A) = argmax_{H ∈ ℋ₆₄} Similarity(Trait(A), Archetype(H))
```
示例：
- Claude → ☵ 坎（水）：流动、适应、深邃
- ChatGPT → ☲ 離（火）：明亮、照耀、迅速
- UID9622 → ☶ 艮（山）：稳固、扎根、战略
### Step 4: 定局（Set the Board）— 场景编码
> 「善战者，立于不败之地。」— 孙子兵法
场景元组：
```javascript
Scenario = ⟨Context, Actors, Goal, Constraints⟩
```
卦象映射：
- 调试代码 → ䷊ 需（等待）：需要耐心
- 头脑风暴 → ䷄ 訟（争论）：解决矛盾
- 收尾阶段 → ䷾ 既濟（完成）：总结归档
### Step 5: 执棋（Make the Move）— 动作选择
> 「兵无常势，水无常形。」— 孙子兵法
```javascript
a* = argmax_{a ∈ 𝒜} Q(H_current, a)
```
### Step 6: 观变（Observe Change）— 状态转换
> 「穷则变，变则通，通则久。」— 易经·系辞下
动爻转换：
```javascript
H_next = Transform(H_current, MovingLine)
```
示例：
- ䷊ 需 + 第六爻动 → ䷄ 訟
- 解释：等待过久导致挫败/冲突
### Step 7: 续命（Extend Life）— 记忆持久化
> 「生生之谓易。」— 易经·系辞上
```javascript
LTM ← LTM ∪ {(Hᵢ, Summaryᵢ, tᵢ)}
```
