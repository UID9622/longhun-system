### 你只需要做这些点击（不看代码版）
1) 打开 Cloudflare
- 网址：dash.cloudflare.com → 登录
- 左侧菜单：Workers & Pages → Create → Workers → Create Worker
2) 设置密钥
- 进入刚创建的 Worker 页面
- 顶部 Settings → Variables
- Add → 类型选 Text → 名称：OPENAI_API_KEY
- 值粘贴你的 OpenAI 密钥（以 sk- 开头）→ Save
3) 粘贴脚本（只有一个点，没有两个点）
- 顶部按钮：Quick edit（或 Edit code）
- 删除右侧现有代码
- 复制下面整段，粘贴 → Save and deploy
```javascript
export default {
  async fetch(req, env) {
    const body = await req.json();
    const r = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${env.OPENAI_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify(body)
    });
    return new Response(r.body, {
      status: r.status,
      headers: { "Content-Type": "application/json" }
    });
  }
}
```
4) 复制访问地址
- 部署成功后页面会显示一个形如：你的名字.你的账号.workers.dev 的地址
- 复制这个地址（后面我们在本地页面里用）
---
### 测试（不用下载任何东西）
A. 用 Postman（或 Insomnia）
- 新建请求：POST
- URL：粘贴你的 workers.dev 地址
- Body 选 JSON，粘贴：
```json
{
  "model": "gpt-4o-mini",
  "messages": [{"role":"user","content":"用一句话介绍你自己"}]
}
```
- 点 Send，能返回文字就成功
B. 用超简网页测试（复制成本地 .html，双击打开）
```html
<!doctype html>
<html>
<meta charset="utf-8">
<body style="font-family:system-ui;padding:16px">
  <input id="u" style="width:420px" placeholder="粘贴你的 workers.dev 地址">
  <button onclick="go()">测试</button>
  <pre id="out" style="white-space:pre-wrap"></pre>
<script>
async function go(){
  const url=document.getElementById('u').value.trim();
  const res=await fetch(url,{
    method:'POST',
    headers:{'Content-Type':'application/json'},
    body:JSON.stringify({
      model:'gpt-4o-mini',
      messages:[{role:'user',content:'用一句话介绍你自己'}]
    })
  });
  document.getElementById('out').textContent=await res.text();
}
</script>
</body>
</html>
```

### 不成功时我来背锅（你不用排查）
- 401：密钥没填对，或变量名不是 OPENAI_API_KEY
- 404：URL 不是你的 workers.dev 地址
- 500：我来改脚本；你只发我截图
备注
- 不需要下载 SDK 或“英文代号”
- 不需要虚拟卡充值；只要能创建 API Key 就可用
- 复制代码里所有引号都是标准英文引号和一个点
