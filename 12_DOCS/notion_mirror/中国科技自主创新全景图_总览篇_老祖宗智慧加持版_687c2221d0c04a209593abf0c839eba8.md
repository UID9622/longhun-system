# 🔥 一｜关键核心技术攻关
## 🧩 半导体与芯片
- 自主芯片研发： 中芯国际（SMIC）推进先进制程工艺，华为海思麒麟芯片回归
- 光刻机： ASML高端EUV光刻机受限，上海微电子（SMEE）攻关DUV光刻机，2023年实现28nm级别国产光刻机突破
- EDA工具： 华大九天、概伦电子等国产EDA企业崛起，打破Cadence/Synopsys/Mentor三巨头垄断
- 存储芯片： 长江存储（YMTC）232层NAND闪存达到国际先进水平，长鑫存储攻关DRAM
- 封装测试： 长电科技、通富微电全球前十，先进封装技术自主可控
## 💻 基础软件国产化
- 操作系统： 统信UOS、麒麟OS覆盖党政军市场，OpenHarmony开源生态快速扩展
- 数据库： 达梦、人大金仓、OceanBase等国产数据库替代Oracle/SQL Server
- 办公软件： WPS全球用户超5亿，政企市场全面替代微软Office
- 中间件： 东方通、宝兰德等填补国产空白
- 编程语言/编译器： 华为仓颉编程语言发布，自主工具链逐步完善
