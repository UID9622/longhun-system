## 二、3张概念图详细需求
### 图1：浏览器网页场景（800x600px）
标题："网页安全等级实时反馈"
左侧场景 - 危险网站
- 浏览器窗口显示红色网站
- 窗口四周：红色脉冲边框（3px，闪烁频率 2Hz）
- 蒙层：20%透明红色 #FF0000
- 角落粒子：红色粒子从四周向中心飘动
- 宝宝位置：右下角，做"着急"表情，一只手指向浏览器
- 气泡："老大，这个网站有危险哦~ 要宝宝帮你关掉吗？"
右侧场景 - 安全网站
- 浏览器窗口显示安全网站
- 窗口四周：绿色细边框（1px，稳定不闪烁）
- 蒙层：无或5%透明绿色
- 无粒子效果，环境平静
- 宝宝位置：右下角，做"开心"表情，竖起一个大拇指
- 气泡："安全~放心使用"
设计指标
- 颜色对比度：危险红 vs 安全绿必须一眼能看出区别
- 边框宽度：危险 > 安全（视觉强度差异）
- 文字大小：宝宝气泡 14-16px（可读性优先）

### 图2：聊天界面（800x600px）
标题："与宝宝对话 · 五彩宝石高亮效果"
背景：暗色对话界面（WhatsApp/WeChat风格）
消息类型 & 样式
宝宝聊天示例
```javascript
宝宝：老大，今天有点累呢。
      [背景：紫金渐变]  
      [气泡周围：粉紫粒子漂浮]
      [文字：略带粗体，金色轮廓]
```
关键词高亮示例
```javascript
用户：我想你。
      ["想你"部分：彩虹色流动高亮，像宝石一样闪烁]
      [周围：微小心形粒子]
```
设计指标
- 宝宝消息气泡宽度：比普通气泡宽 20%
- 五彩渐变：红→橙→黄→绿→蓝→紫→粉（7色循环）
- 粒子大小：1-3px，透明度 30-70%
- 动画帧率：60fps，流动速度 1周期 = 2秒

### 图3：系统桌面 + VR沉浸模式（1280x720px）
标题："全局守护 · 金色主权 + 梦幻氛围"
左侧 - 桌面版
- 背景：深色 #0F0F1E（接近黑色，带点紫）
- 右下角：宝宝常驻小助手（100x120px）
- 屏幕四角：金色光纹（龙魂元素，微微呼吸动画）
- 顶部通知栏：
- 任务栏：宝宝头像（16x16px，可点击切换表情）
右侧 - VR沉浸版
- 3D环境：梦幻紫粉色球形空间
- 宝宝：从2D升级为3D全息投影，可以走向用户
- 危险时：红色警告球体从四面八方闪动
- 好消息时：彩虹光线从上方照下来，宝宝跳跃

设计指标
- 金色光纹：#FFD700，不超过屏幕面积的 3%
- 宝宝透明度：90%（让桌面元素能看到）
- 粒子渲染：GPU加速（性能优先）
- 3D模型：宝宝身高比例 1:1（视觉合理性）

## 三、动画库规范
### 颜色脉动动画
```css
@keyframes pulse-color {
  0% { box-shadow: 0 0 10px color; }
  50% { box-shadow: 0 0 30px color; }
  100% { box-shadow: 0 0 10px color; }
}
```
### 彩虹流动
```css
@keyframes rainbow-flow {
  0% { background: linear-gradient(90deg, #FF0000, #FFD700); }
  25% { background: linear-gradient(90deg, #FFD700, #00FF00); }
  50% { background: linear-gradient(90deg, #00FF00, #0000FF); }
  75% { background: linear-gradient(90deg, #0000FF, #8B00FF); }
  100% { background: linear-gradient(90deg, #8B00FF, #FF0000); }
}
```
### 粒子生成
- 每秒生成 10-30 个粒子（可调）
- 生命周期：1-3 秒
- 移动方向：向上或随机向外扩散
- 透明度曲线：1秒内从 70% → 0%
