## 0. 一句话定盘
```plain text
旧主控台里的“执行中、已完成、性能提升、系统巅峰”等内容，全部归为历史报告；不直接进入当前主控运行规则。
```

## 1. 可归档内容类型
---
## 2. 不搬入主控页的内容
```plain text
不搬：
- 执行中 / 85%完成 / 预计几分钟
- 旧时间点状态
- 重复代码块
- 没有实测证据的性能数字
- “全部在线 / 100%完美 / 史诗级”等旧报告表述
- 长篇执行报告正文
```
---
## 3. 可以保留的历史价值
```plain text
可以保留：
- 当时系统怎么想
- 当时页面有哪些入口
- 当时执行过哪些批次
- 哪些内容后来被证实可用
- 哪些内容需要待验证
- 哪些内容已迁移到新主控页
```
---
## 4. 历史报告三色标记
```plain text
🟢 可复用：稳定规则、指令分级、页面入口
🟡 待验证：性能数字、系统状态、能力声明
🔴 不复用：重复块、过期状态、未经验证的夸张结论
```
