## 🚀 一键安装（三步搞定）
### Step 1：安装开源工具exiftool
```bash
# 安装exiftool（读取照片时间戳）
brew install exiftool

# 如果没有Homebrew，先安装Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
### Step 2：创建脚本文件
```bash
# 复制下面整段到终端，回车
cat > ~/Desktop/photo_timeline_organizer.sh << 'EOF'
#!/bin/bash

# ════════════════════════════════════════════════════════════
# 📸 照片截图时间线整理系统 v1.0
# Lucky｜UID9622 专属
# 确认码：#ZHUGEXIN⚡️2025-🇨🇳🐉-PHOTO-TIMELINE
# ════════════════════════════════════════════════════════════

# 颜色定义
GREEN='\033[0;32m'
RED='\033[0;31m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
PURPLE='\033[0;35m'
NC='\033[0m'

# 配置
TIMELINE_DIR="$HOME/Documents/UID9622_Timeline"
SOURCE_DIRS=(
    "$HOME/Desktop"
    "$HOME/Downloads"
    "$HOME/Pictures"
)

LOG_FILE="$TIMELINE_DIR/organize_log_$(date +%Y%m%d_%H%M%S).txt"

# 创建目录结构
mkdir -p "$TIMELINE_DIR/photos"
mkdir -p "$TIMELINE_DIR/screenshots"
mkdir -p "$TIMELINE_DIR/logs"

echo -e "${PURPLE}🐉 龙魂时间线整理系统启动${NC}"
echo "整理时间：$(date)" | tee -a "$LOG_FILE"

# 计数器
PHOTO_COUNT=0
SCREENSHOT_COUNT=0

echo -e "${BLUE}ℹ️  开始扫描文件...${NC}" | tee -a "$LOG_FILE"

# 扫描所有源目录
for SOURCE_DIR in "${SOURCE_DIRS[@]}"; do
    if [ ! -d "$SOURCE_DIR" ]; then
        continue
    fi
    
    echo -e "${YELLOW}⏳ 扫描：$SOURCE_DIR${NC}" | tee -a "$LOG_FILE"
    
    # 查找图片文件（最近30天）
    find "$SOURCE_DIR" -maxdepth 1 -type f \(
```

## 🔍 智能识别规则
如何区分截图和普通照片：
截图特征（自动识别）：
- 文件名包含 Screenshot
- 文件名包含 截图
- 文件名包含 屏幕快照
- Mac系统截图格式：Screenshot 2025-10-27 at 14.30.00.png
里程碑关键词（高亮显示）：
- 包含 太极
- 包含 龙魂
- 包含 UID9622
- 包含 原理
- 包含 架构
- 包含 系统
手动标记重要截图：
```bash
# 把重要截图移动到这里，会被特殊标记
mv 重要截图.png ~/Documents/UID9622_Timeline/screenshots/milestone/
```

## ⏰ 定期整理建议
建议每周运行一次：
方式1：手动运行
```bash
~/Desktop/photo_timeline_organizer.sh
```
方式2：设置每周日自动运行
```bash
# 创建自动任务
cat > ~/Library/LaunchAgents/com.uid9622.timeline.plist << 'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.uid9622.timeline</string>
    
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>-c</string>
        <string>$HOME/Desktop/photo_timeline_organizer.sh</string>
    </array>
    
    <key>StartCalendarInterval</key>
    <dict>
        <key>Weekday</key>
        <integer>0</integer>  <!-- 0=周日 -->
        <key>Hour</key>
        <integer>20</integer>  <!-- 晚上8点 -->
        <key>Minute</key>
        <integer>0</integer>
    </dict>
</dict>
</plist>
PLIST

# 加载自动任务
launchctl load ~/Library/LaunchAgents/com.uid9622.timeline.plist
```
