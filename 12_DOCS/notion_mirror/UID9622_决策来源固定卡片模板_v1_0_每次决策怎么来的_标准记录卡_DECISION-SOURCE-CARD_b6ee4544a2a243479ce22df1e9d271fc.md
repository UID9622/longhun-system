### 5.1 工程决策卡
```plain text
【工程决策来源卡】

任务：
把浏览器插件升级为 CNSH 前哨插件。

为什么这样决策：
因为任务涉及 Chromium 插件、本地网关、Notion 入库、安全边界·所以命中：
- UID9622_BROWSER_SHELL_EXEC_MODE
- CNSH 语义编译协议
- DNA-TAG-POLICY
- ROOT_CARD-MATH-AUDIT

后端路由：
- Manifest V3
- JavaScript
- HTML/CSS
- chrome.storage.local
- Local Gateway 127.0.0.1:9625

三色审计：
🟢 可工程化·但 Token / Cookie / 密码 / 静默回填为红线。

最终决策：
先做本地可跑 MVP：
1. 保存选区
2. 生成 DNA
3. 生成 ROOT_CARD
4. 本地暂存
Notion 写入与回填放第二轮。

原因：
最少依赖·风险最低·可验收最快。
```

```plain text
【Notion 页面结构决策来源卡】

任务：
审查并完善页面结构。

页面目标是长期入库和跨 AI 复用·所以必须补齐：
- 页面定位
- 字段
- 视图
- 触发器
- 三色审计
- 回执
- ROOT_CARD

三色审计：
🟢 可入库

最终决策：
不新增无关体系·只补字段、目录、验收和收口卡。

原因：
保持页面更稳、更短、更能跑。
```
### 5.3 隐私 / sealed 决策卡
```plain text
【隐私封存决策来源卡】

任务：
处理疑似密钥 / token / 私钥内容。

retention: hash_only

不读正文·不摘要·不外发·只登记元信息和 hash。

原因：
密钥类内容一律直接封存。
```
