# §6｜失败后的复原协议
## 6.1 三层降级
```javascript
Level 1 — 单刀失败:
  → 减半容量 + 重试 1 次

Level 2 — 二次失败:
  → 拆成 3 刀最小单元 + 串行

Level 3 — 三次失败:
  → 立轻骨架 + 老大确认 + 后续 updatePage 填
  → 同时草日志记 mistake
```
## 6.2 失败也要留痕
- 即使刀失败，也要在草日志写一条 callout：「失败原因 + 重试方案」
