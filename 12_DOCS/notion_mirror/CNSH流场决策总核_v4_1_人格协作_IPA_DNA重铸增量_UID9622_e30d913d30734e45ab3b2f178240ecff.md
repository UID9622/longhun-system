## 3｜DNA追溯·重铸（多标签 + 父子链 + 四源数字根）
### 3.1 DNA从「码」升级为「处理命令」
- 旧版（≤v3.0）： #龍芯⚡️YYYY-MM-DD-标题-vX.X（仅标识）
- 新版（v4.1）： DNA = 标识 + 多标签处理指令 + 父子链链接
### 3.2 DNA多标签字段表（10个字段·写在 DNA 后面）
### 3.3 数字根·四源优先级（v4.1 修正·不动点不丢）
```javascript
1. explicit_dr   用户显式给定（最高优先级）
2. dna_digits    从 DNA 字符串提取数字
3. content_hash  内容 hash 前 8 位转数值
4. raw_digits    原文中所有数字
5. fallback_zero 无数字归 0 为土（最低优先级）
```
### 3.4 DNA父子链结构
```javascript
[祖父DNA]   parent_of_parent
    ↓
[父DNA]     parent_dna
    ↓
[当前DNA]   current_dna
    ↓
[子DNA]     child_dna = current_dna + "-CHILD-" + hash8
    ↓
[孙DNA]     continues...
```
每条 DNA 落档必填： parent_dna（首条则为空字符串）+ current_dna + child_dna（衍生时）
### 3.5 销毁/封存证明
- 销毁证明（burn）： burn_proof:sha256:[content_hash]+timestamp+operator
- 封存证明（sealed）： seal_proof:sha256:[content_hash]+timestamp+operator+P72签字
### 3.6 DNA铁律（6条）
1. 🔴 confirm_code 缺失 → DNA 无效，熔断。
1. 🔴 eternal_seal 被改写 → DNA 无效，熔断。
1. 🔴 parent_dna 引用了不存在的 DNA → 链断裂，熔断。
1. 🟡 child_dna 重复 → 待审。
1. 🟢 完整链路（祖父 → 父 → 子）+ 全字段 → 通过。
1. 🔴 sealed/burn 节点的 raw_body_allowed=true → 矛盾，强制 sealed 优先，熔断写盾日志。
