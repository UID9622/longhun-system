## 1. 模型定位 | Model Positioning
通心译v2.0是一个语义心意映射引擎，不是传统翻译模型。核心差异：
核心公式:
```javascript
Translation = f(Source, Cultural_Context, Intention_Map)
Quality = Σ(w_i × Dim_i) + Creativity_Bonus
```
设计哲学: 基于20条语义观察，将"断章取义"问题转化为可训练的特征空间，使模型学会在翻译中保持语义完整性、文化适应性和心意传递的三重约束。

## 3. 三层语义传递v2.0
```javascript
┌─────────────────────────────────────────────────────┐
│  输入: 源文本 + 文化语境 + 意图映射                    │
└─────────────┬───────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────────┐
│  L层·字面层 (Literal)                                │
│  词汇对应 + 术语映射                                  │
│  confidence: 0.9-0.95                                │
└─────────────┬───────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────────┐
│  G层·逻辑层 (Logical)                                │
│  句法结构映射 + 语义蕴含关系                           │
│  confidence: 0.8-0.92                                │
└─────────────┬───────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────────┐
│  I层·心意层 (Intentional)                            │
│  文化意图传递 + 情感等价                              │
│  confidence: 0.6-0.85                                │
└─────────────────────────────────────────────────────┘
```
层间交互协议:
- L→G: 术语映射表驱动句法重组
- G→I: 语义蕴含关系驱动文化意图提取
- I→L: 心意层反馈修正字面选择（闭环）

## 5. 训练Pipeline（5步）
```javascript
Step 1: 数据准备 → 收集源文本+上下文+文化注释
Step 2: 人工标注 → 三层翻译+七维评分（至少3人标注取平均）
Step 3: 模型训练 → 七维独立训练→联合优化
Step 4: 评估验证 → R-Score计算+质量报告
Step 5: 哲学迭代 → 新观察融入→维度权重调参
```
---
## 6. 评估指标体系
### R-Score计算公式
```javascript
R_score = Σ(w_i × D_i) + α × Creativity_Bonus − β × Safety_Penalty

其中:
  w_i: 维度权重（见上表）
  D_i: 维度得分 [0, 1]
  α = 0.1: 创造性奖励系数
  β = 0.5: 安全惩罚系数
  Safety_Penalty: 当D5 < 0.95时触发
```
