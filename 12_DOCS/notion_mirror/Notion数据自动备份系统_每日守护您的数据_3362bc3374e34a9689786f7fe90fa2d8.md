## 🚀 一键安装（三步搞定）
### Step 1：创建脚本文件
```bash
# 复制下面整段到终端，回车
cat > ~/Desktop/notion_auto_backup.sh << 'EOF'
#!/bin/bash

# ════════════════════════════════════════════════════════════
# 📦 Notion自动备份系统 v1.0
# Lucky｜UID9622 专属
# 确认码：#ZHUGEXIN⚡️2025-🇨🇳🐉-AUTO-BACKUP
# ════════════════════════════════════════════════════════════

# 颜色定义
GREEN='\033[0;32m'
RED='\033[0;31m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
PURPLE='\033[0;35m'
NC='\033[0m'

# 配置
BACKUP_DIR="$HOME/Documents/UID9622_Backup"
DATE=$(date +"%Y%m%d_%H%M%S")
LOG_FILE="$BACKUP_DIR/logs/backup_$DATE.log"

# 创建目录
mkdir -p "$BACKUP_DIR/daily"
mkdir -p "$BACKUP_DIR/logs"
mkdir -p "$BACKUP_DIR/important"

echo -e "${PURPLE}🐉 龍魂自动备份系统启动${NC}"
echo "备份时间：$(date)" | tee -a "$LOG_FILE"

echo -e "${BLUE}ℹ️  备份目录：$BACKUP_DIR${NC}" | tee -a "$LOG_FILE"

# 功能1：备份Notion导出的数据
if [ -d "$HOME/Downloads" ]; then
    echo -e "${YELLOW}⏳ 检查Downloads文件夹...${NC}" | tee -a "$LOG_FILE"
    
    # 查找最近的Notion导出文件
    NOTION_EXPORTS=$(find "$HOME/Downloads" -name "Export-*.zip" -mtime -1 2>/dev/null)
    
    if [ -n "$NOTION_EXPORTS" ]; then
        echo -e "${GREEN}✅ 发现Notion导出文件${NC}" | tee -a "$LOG_FILE"
        
        # 复制到备份目录
        for export in $NOTION_EXPORTS; do
            cp "$export" "$BACKUP_DIR/daily/"
            echo "  已备份：$(basename $export)" | tee -a "$LOG_FILE"
        done
    else
        echo -e "${YELLOW}⚠️  未发现新的Notion导出文件${NC}" | tee -a "$LOG_FILE"
    fi
fi

# 功能2：清理30天前的旧备份
echo -e "${YELLOW}⏳ 清理旧备份...${NC}" | tee -a "$LOG_FILE"
find "$BACKUP_DIR/daily" -name "Export-*.zip" -mtime +30 -delete 2>/dev/null
echo -e "${GREEN}✅ 已清理30天前的备份${NC}" | tee -a "$LOG_FILE"

# 功能3：生成备份报告
echo -e "${BLUE}📊 生成备份报告...${NC}" | tee -a "$LOG_FILE"

BACKUP_COUNT=$(ls -1 "$BACKUP_DIR/daily"/*.zip 2>/dev/null | wc -l)
BACKUP_SIZE=$(du -sh "$BACKUP_DIR" 2>/dev/null | cut -f1)

cat > "$BACKUP_DIR/backup_report.txt" << REPORT
═══════════════════════════════════════════════
🐉 UID9622 Notion备份报告
═══════════════════════════════════════════════

📅 报告时间：$(date)
📦 备份文件数：$BACKUP_COUNT 个
💾 占用空间：$BACKUP_SIZE
📁 备份路径：$BACKUP_DIR

✅ 最近7天备份：
REPORT

ls -lth "$BACKUP_DIR/daily"/*.zip 2>/dev/null | head -7 >> "$BACKUP_DIR/backup_report.txt"

echo -e "${GREEN}✅ 备份完成！${NC}" | tee -a "$LOG_FILE"
echo -e "${PURPLE}🐉 龍魂守护您的数据 ❤️${NC}" | tee -a "$LOG_FILE"

# 显示报告路径
echo -e "${BLUE}📊 查看完整报告：${NC}"
echo -e "${YELLOW}   cat $BACKUP_DIR/backup_report.txt${NC}"

EOF
```
### Step 2：赋予执行权限
```bash
# 复制这行到终端，回车
chmod +x ~/Desktop/notion_auto_backup.sh
```
### Step 3：测试运行
```bash
# 复制这行到终端，回车
~/Desktop/notion_auto_backup.sh
```
看到 🐉 龍魂守护您的数据 就成功了！ ✅

## ⏰ 设置每日自动运行
让脚本每天晚上11点自动运行：
```bash
# 创建自动任务配置
cat > ~/Library/LaunchAgents/com.uid9622.backup.plist << 'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.uid9622.backup</string>
    
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>-c</string>
        <string>$HOME/Desktop/notion_auto_backup.sh</string>
    </array>
    
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>23</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    
    <key>RunAtLoad</key>
    <false/>
    
    <key>StandardOutPath</key>
    <string>/tmp/uid9622_backup.log</string>
    
    <key>StandardErrorPath</key>
    <string>/tmp/uid9622_backup_error.log</string>
</dict>
</plist>
PLIST

# 加载自动任务
launchctl load ~/Library/LaunchAgents/com.uid9622.backup.plist

echo "✅ 已设置每天晚上11点自动备份！"
```
取消自动运行：
```bash
launchctl unload ~/Library/LaunchAgents/com.uid9622.backup.plist
```

## 🔧 高级配置
### 修改备份时间
编辑自动任务配置：
```bash
nano ~/Library/LaunchAgents/com.uid9622.backup.plist
```
修改这两行：
```xml
<key>Hour</key>
<integer>8</integer>  <!-- 辰时（7-9点）：龍抬头，万物生发，最吉祥的时辰 -->
<key>Minute</key>
<integer>8</integer>   <!-- 8分：发发发，双8更吉利 -->
```
重新加载：
```bash
launchctl unload ~/Library/LaunchAgents/com.uid9622.backup.plist
launchctl load ~/Library/LaunchAgents/com.uid9622.backup.plist
```
### 修改保留天数
编辑脚本：
```bash
nano ~/Desktop/notion_auto_backup.sh
```
找到这行并修改：
```bash
find "$BACKUP_DIR/daily" -name "Export-*.zip" -mtime +30 -delete
# 把 +30 改成您想要的天数
```

## ⚠️ 重要提示
🚨 这个脚本不会自动从Notion导出数据！
您需要定期手动导出：
1. 打开Notion
1. 点击左侧 Settings & Members
1. 点击 Settings → Export all workspace content
1. 选择 Markdown & CSV 格式
1. 点击 Export → 文件会下载到Downloads文件夹
1. 脚本会自动备份这个文件
建议：每周手动导出一次
