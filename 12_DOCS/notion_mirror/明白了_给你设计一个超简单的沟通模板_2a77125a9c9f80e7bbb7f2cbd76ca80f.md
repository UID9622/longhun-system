## 🎯 话题：[你的问题]
### 1️⃣ 这是什么问题？
- 用最简单的话解释这个话题
- 为什么这个问题重要
### 2️⃣ 现在的情况
- 目前是什么样的
- 有哪些事实和数据
### 3️⃣ 核心矛盾是什么？
- 问题的关键在哪里
- 不同观点的冲突
### 4️⃣ 推演：可能的发展
情况A：如果XXX → 会导致XXX
情况B：如果XXX → 会导致XXX
情况C：如果XXX → 会导致XXX
### 5️⃣ 关键因素
- 什么会影响结果
- 哪些是可以改变的
### 6️⃣ 我的判断
- 最可能发生什么
- 为什么这样判断
### 7️⃣ 如果你想深入
- 可以继续问的问题
- 需要关注的信息

## 🎯 话题：为什么大公司都在裁员
### 1️⃣ 这是什么问题？
2023-2025年，很多科技大公司（Meta、Google、微软等）都在大规模裁员，有的裁掉几千甚至上万人。这看起来很奇怪，因为这些公司明明还在赚钱。
### 2️⃣ 现在的情况
- Meta裁了2.1万人
- Google裁了1.2万人
- 但这些公司的利润还在增长
### 3️⃣ 核心矛盾是什么？
- 表面矛盾：公司赚钱，但还裁人
- 深层原因：经济环境变了，增长速度放缓
### 4️⃣ 推演：可能的发展
情况A：经济衰退继续 → 更多公司裁员 → 失业率上升
情况B：AI替代人工 → 需要的人变少 → 工作岗位永久减少
情况C：公司重组调整 → 裁掉低效部门 → 几年后重新招人
### 5️⃣ 关键因素
- 利率高低（借钱成本）
- AI发展速度
- 经济是否复苏
### 6️⃣ 我的判断
三种情况会同时发生，但情况B（AI替代）是长期趋势，即使经济好转，很多岗位也不会回来了。
### 7️⃣ 如果你想深入
- 可以问：【细节】哪些工作最容易被AI替代
- 可以问：【对比】中国和美国的裁员有什么不同
