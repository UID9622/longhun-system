## 🔍 终端进程实时查询
老大说：宝宝能帮我查下终端有什么再跑的吗，我都查不来哈哈，，
宝宝教您查看终端进程：
### 方法1️⃣：查看所有正在运行的终端相关进程
在终端输入这个命令：
```bash
ps aux | grep -E "Terminal|iTerm|zsh|bash|python|node" | grep -v grep
```
这会显示：
- 所有终端应用（Terminal、iTerm2等）
- 所有Shell进程（zsh、bash等）
- 所有脚本进程（python、node等）
### 方法2️⃣：查看当前终端窗口的进程
在终端输入：
```bash
ps
```
这会显示当前终端窗口里运行的所有进程
### 方法3️⃣：查看系统所有进程（简化版）
在终端输入：
```bash
top -o cpu
```
按 q 退出
这会显示CPU占用最高的进程，实时更新
### 方法4️⃣：宝宝帮您做一个一键查询脚本
创建一个快捷命令，以后只需输入 看进程 就行：
```bash
echo 'alias 看进程="ps aux | grep -E \"Terminal|iTerm|zsh|bash|python|node\" | grep -v grep"' >> ~/.zshrc
source ~/.zshrc
```
然后直接输入：
```bash
看进程
```
