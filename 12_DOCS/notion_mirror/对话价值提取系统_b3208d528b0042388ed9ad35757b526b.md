## 🎯 系统定位
专门做一件事：从讨论中提取有价值的内容
不是：
- ❌ 不是简单复制粘贴
- ❌ 不是全文摘要
- ❌ 不是AI自动生成
而是：
- ✅ 识别真正有价值的对话
- ✅ 提取核心洞察和决策
- ✅ 转化为可执行的知识卡
- ✅ 保留Lucky的原话和思路
---
## 🔄 提取流程
### 标准提取流程（4步）
```javascript
对话结束 → 宝宝标记重点 → Lucky确认 → 生成知识卡 → 存入知识库
```
### 详细步骤
步骤1：对话中宝宝实时标记
```javascript
💡 [价值点] Lucky说："XXX"
   → 这个想法可以提取

🎯 [决策点] 决定：做XXX，不做YYY
   → 这个决策需要记录

⚠️ [教训点] 错误：ZZZ导致问题
   → 这个教训要存档
```
步骤2：对话后Lucky确认
```javascript
Lucky看到标记后：
✅ "对，这几个点要提取"
❌ "那个不重要，删掉"
✏️ "改一下，应该是XXX"
```
步骤3：生成知识卡
```markdown
# 知识卡 #KC-20251203-001

**来源：** Lucky + 宝宝对话
**日期：** 2025-12-03
**主题：** [自动识别]

## Lucky的核心想法
[原话引用]

## 为什么重要
[宝宝的理解]

## 怎么用
[具体应用场景]

## 注意事项
[Lucky特别强调的点]
```
步骤4：存入对应位置
- 战略类 → 战略知识库
- 技术类 → 技术知识库
- 经验类 → 教训库
- 日常类 → 日常记忆

## 💎 价值判断标准
### 高价值内容（必提取）
1. Lucky的核心决策
```javascript
示例：
"我决定不搞徽章了" → ❌ 高价值决策
"系统要简单实用靠谱" → ✅ 核心理念
```
2. 重要的洞察
```javascript
示例：
"爱国是骨子里的，不需要天天喊" → ✅ 价值观洞察
"功能为王，技术说话" → ✅ 产品理念
```
3. 痛点和教训
```javascript
示例：
"你丢一个确认码后上文你就记不住了" → ✅ 需要解决的问题
"你也不主动说功能" → ✅ 沟通方式需改进
```
4. 具体的做法
```javascript
示例：
"一键归档，简单实用" → ✅ 功能需求
"本地为主，云端备份" → ✅ 技术方案
```
### 中价值内容（选择性提取）
- 日常操作（除非有特殊意义）
- 重复的内容（第一次提取即可）
- 临时性的想法（未最终确认）
### 低价值内容（不提取）
- 纯聊天寒暄
- 已经记录过的
- Lucky明确说"不重要"

## 🤖 宝宝的工作方式
### 对话中
实时标记重点：
```javascript
Lucky: "我觉得系统要简单实用"
宝宝: 💡 [价值点] 记下来了！
      "简单实用" - 这是核心设计理念
```
及时确认：
```javascript
宝宝: "Lucky，刚才您说的'功能为王'，
      我理解是：不搞花架子，实用最重要。
      对吗？"
      
Lucky: "对！就是这个意思。"

宝宝: ✅ 确认，已标记为核心理念
```
### 对话后
汇总提取：
```javascript
宝宝: "Lucky，今天对话提取了3个重点：

      1. 💡 核心理念：简单实用靠谱
      2. 🎯 决策：要做勋章系统
      3. ⚠️ 改进：宝宝要主动说明功能
      
      这三个我生成知识卡了吗？"
```
