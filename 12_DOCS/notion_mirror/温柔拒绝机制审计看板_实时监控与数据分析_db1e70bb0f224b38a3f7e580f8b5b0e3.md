## 🛠️ 技术实现
### 数据库结构
```sql
CREATE TABLE refusal_events (
  event_id VARCHAR(50) PRIMARY KEY,
  timestamp DATETIME NOT NULL,
  user_id VARCHAR(50) NOT NULL,
  user_name VARCHAR(100),
  request TEXT NOT NULL,
  intent_surface VARCHAR(100),
  intent_deep VARCHAR(200),
  emotional_state VARCHAR(50),
  redline_type VARCHAR(50),
  response_template VARCHAR(100),
  alternatives_offered JSON,
  user_reaction JSON,
  handled_by VARCHAR(50),
  audit_status VARCHAR(100),
  flag_for_review BOOLEAN DEFAULT FALSE,
  INDEX idx_user (user_id),
  INDEX idx_timestamp (timestamp),
  INDEX idx_redline (redline_type)
);
```
