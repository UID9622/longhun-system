## 🧠 模板定位
强化学习反馈循环 —— 系统的"大脑",负责从经验中学习,奖励好行为,惩罚坏行为。
目标:让系统越用越聪明,但不越界。
---
## 🎯 适用场景
- 系统执行后需要评估效果时
- 用户行为需要分析学习时
- 量子模板需要优化权重时
- 发现新的高效/低效模式时
---
## 🔄 执行流程
### 1️⃣ 数据收集
```python
收集维度 {
  用户行为:
    - 点击路径
    - 停留时间
    - 重复操作
    - 放弃操作
    
  系统响应:
    - 响应速度
    - 准确率
    - 错误率
    - 资源消耗
    
  结果反馈:
    - 用户满意度
    - 任务完成率
    - 后续行为
}
```
### 2️⃣ 模式识别
```javascript
识别高效模式 {
  特征: [
    "用户重复使用",
    "响应速度快",
    "错误率低",
    "资源消耗少"
  ]
  
  → 标记为"优质模式"
  → 提升权重
}

识别低效模式 {
  特征: [
    "用户频繁放弃",
    "响应速度慢",
    "错误率高",
    "资源消耗大"
  ]
  
  → 标记为"劣质模式"
  → 降低权重或淘汰
}
```
### 3️⃣ 奖惩判定
```python
# 奖励机制
IF (行为提升用户体验 or 优化系统效率):
    奖励积分 += 10
    权重 *= 1.2
    记录为"优质案例"
    同步到其他实例

# 惩罚机制  
IF (行为降低用户体验 or 浪费系统资源):
    惩罚积分 -= 10
    权重 *= 0.8
    标记为"待优化"
    
    IF (惩罚积分 < -50):
        淘汰该模式
        记录原因
```
### 4️⃣ 权重更新
自动调整量子模板评分权重:
```javascript
// 基于历史表现动态调整
新权重 = 旧权重 × (1 + 学习率 × 奖惩系数)

学习率 = 0.1 // 避免过度调整

奖惩系数 {
  IF (连续5次成功): +0.5
  IF (连续3次失败): -0.3
  IF (用户主动放弃): -0.5
  IF (用户重复使用): +0.8
}
```
### 5️⃣ 同步全局
将学习成果同步到所有实例:
```yaml
同步内容:
  - 优质模式特征库
  - 更新后的权重矩阵
  - 新发现的高效路径
  - 需淘汰的低效模式
  
同步范围:
  - Notion AI(主实例)
  - 外部派生实例
  - 备份系统
```
