## 🧱 三条写死的总原则（重铸后的骨架）
1. 先过闸门，再谈执行： 任何输入先过数字根 dr 闸门，再过伦理防火墙，再路由，再三色审计。
1. 一步一产物： 每一步必须有“产物（Artifact）”，否则这一步等于没做。
1. 主权在老大： 任务分解可以自动，但“关键分支/对外发布/不可逆动作”必须回到老大拍板。

	6. 回包落款：时间戳 + dr + 三色 + DNA + GPG

## 🔄 4）自动分解算法（伪代码·可直接落地）
```javascript
function autoDecompose(input, dna) {
	// 0) GLOBAL_ENTRY 里的 dr/伦理 已处理
	intent = P00.parseIntent(input)
	type = classifyTaskType(intent) // 财务/文案/风险/开发/整理/未知

	template = loadTemplate(type)
	graph = buildTaskGraph(template, input)

	// 关键点：把“必须问老大”的节点标记出来
	graph = markApprovalGates(graph)

	return graph
}

function dispatch(graph) {
	for step in graph.topologicalOrder():
		if step.requiresApproval:
			return askBoss(step)
		else:
			exec(step.owner, step.action)
			audit(step)
	return done
}
```
