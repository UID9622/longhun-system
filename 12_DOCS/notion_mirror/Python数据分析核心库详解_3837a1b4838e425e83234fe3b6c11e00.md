# 🔧 Python数据分析核心库完全指南
## 🔢 NumPy - 数值计算基础
### 核心概念
```python
import numpy as np

# 创建数组
arr = np.array([1, 2, 3, 4, 5])
matrix = np.array([[1, 2], [3, 4]])

# 常用函数
np.zeros((3, 3))     # 零矩阵
np.ones((2, 4))      # 全一矩阵
np.random.rand(3, 3) # 随机矩阵
```
### 数组操作
- 形状操作：reshape、flatten、transpose
- 索引切片：布尔索引、花式索引
- 数学运算：向量化操作、广播机制
- 统计函数：mean、std、max、min、sum
## 🐼 Pandas - 数据处理神器
### DataFrame基础
```python
import pandas as pd

# 创建DataFrame
df = pd.DataFrame({
    'name': ['张三', '李四', '王五'],
    'age': [25, 30, 35],
    'salary': [8000, 12000, 15000]
})

# 基本信息
df.head()        # 前5行
df.info()        # 数据信息
df.describe()    # 统计描述
```
### 数据清洗
- 缺失值处理：dropna()、fillna()、interpolate()
- 重复值处理：drop_duplicates()、duplicated()
- 数据类型转换：astype()、to_datetime()、to_numeric()
- 异常值检测：IQR方法、Z-score标准化
### 数据变换
```python
# 分组聚合
df.groupby('category').agg({
    'sales': ['sum', 'mean'],
    'profit': 'max'
})

# 透视表
pd.pivot_table(df, 
               values='sales', 
               index='region', 
               columns='month')

# 数据合并
pd.merge(df1, df2, on='key', how='left')
```

## 📊 Matplotlib - 数据可视化
### 基础绘图
```python
import matplotlib.pyplot as plt

# 折线图
plt.plot(x, y)
plt.title('标题')
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.show()

# 柱状图
plt.bar(categories, values)

# 散点图
plt.scatter(x, y, c=colors, s=sizes)
```
### 高级可视化
- 子图布局：subplot、subplots
- 样式设置：颜色、线型、标记
- 图例标注：legend、annotation
- 保存图片：savefig、dpi设置
## 🎨 Seaborn - 统计可视化
### 统计图表
```python
import seaborn as sns

# 分布图
sns.histplot(data=df, x='column')
sns.boxplot(data=df, x='category', y='value')

# 关系图
sns.scatterplot(data=df, x='x', y='y', hue='category')
sns.regplot(data=df, x='x', y='y')

# 热力图
corr_matrix = df.corr()
sns.heatmap(corr_matrix, annot=True)
```
