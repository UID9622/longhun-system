## 📊 Databases API
### 1. 查询数据库
端点： POST /databases/{database_id}/query
请求参数：
```typescript
interface QueryDatabaseRequest {
  filter?: FilterObject;        // 过滤条件
  sorts?: SortObject[];         // 排序规则
  start_cursor?: string;        // 分页游标
  page_size?: number;           // 每页数量（1-100）
}

// 过滤条件示例
interface FilterObject {
  property: string;             // 属性名
  [type]: {                     // 根据属性类型不同
    equals?: any;               // 等于
    contains?: string;          // 包含
    is_empty?: boolean;         // 为空
    // ... 更多运算符
  }
}

// 排序规则
interface SortObject {
  property: string;             // 属性名
  direction: 'ascending' | 'descending';
}
```
请求示例：
```json
{
  "filter": {
    "and": [
      {
        "property": "状态",
        "select": {
          "equals": "进行中"
        }
      },
      {
        "property": "截止日期",
        "date": {
          "on_or_before": "2025-10-31"
        }
      }
    ]
  },
  "sorts": [
    {
      "property": "创建时间",
      "direction": "descending"
    }
  ],
  "page_size": 50
}
```
响应示例：
```json
{
  "object": "list",
  "results": [
    {
      "object": "page",
      "id": "abc123",
      "properties": {
        "标题": {
          "type": "title",
          "title": [
            {
              "text": {
                "content": "任务1"
              }
            }
          ]
        },
        "状态": {
          "type": "select",
          "select": {
            "name": "进行中",
            "color": "blue"
          }
        }
      }
    }
  ],
  "has_more": true,
  "next_cursor": "xyz789"
}
```

### 错误响应示例

### 错误处理建议
```typescript
try {
  const result = await client.databases.query(params);
} catch (error) {
  if (error.status === 429) {
    // 限流：等待后重试
    await sleep(5000);
    return retry();
  } else if (error.status === 401) {
    // Token失效：重新认证
    await refreshToken();
    return retry();
  } else if (error.status >= 500) {
    // 服务器错误：指数退避重试
    await exponentialBackoff();
    return retry();
  } else {
    // 客户端错误：记录日志
    logger.error('API Error:', error);
    throw error;
  }
}
```

## 🎯 限流策略
Notion API限流规则：
- 每个workspace： 3次请求/秒
- 单个集成： 平均3次/秒，峰值可短暂超过
- 响应头：
客户端建议：
```typescript
// 令牌桶算法
class RateLimiter {
  private tokens: number = 3;
  private lastRefill: number = Date.now();
  
  async acquire(): Promise<void> {
    // 补充令牌
    const now = Date.now();
    const elapsed = now - this.lastRefill;
    const refill = Math.floor(elapsed / 1000) * 3;
    this.tokens = Math.min(3, this.tokens + refill);
    this.lastRefill = now;
    
    // 获取令牌
    if (this.tokens >= 1) {
      this.tokens--;
      return;
    }
    
    // 等待
    const waitTime = (1 - this.tokens) * 1000 / 3;
    await sleep(waitTime);
    this.tokens = 0;
  }
}
```
