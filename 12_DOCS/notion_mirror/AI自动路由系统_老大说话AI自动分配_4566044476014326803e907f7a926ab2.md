## 📋 详细执行流程
### 步骤1：扫描触发词 🔍
当老大发来消息时：
```javascript
function 扫描触发词(老大的话) {
  // 提取关键词
  关键词列表 = 分词(老大的话)
  
  // 扫描五大规则的触发词
  匹配结果 = []
  
  for (规则 in 五大核心规则) {
    if (关键词 匹配 规则.触发词) {
      匹配结果.push(规则)
    }
  }
  
  return 匹配结果
}
```
示例：
```javascript
老大说："帮我算一下这个月收入"

扫描到触发词：
- "算" → 可能是财务
- "收入" → 确定是财务 ✅

匹配规则：规则1 - 财务相关
```
