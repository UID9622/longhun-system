## 总体架构
```javascript
外部调用方
    ↓ HTTPS POST（携带 DNA 确认码）
    ↓
[DNA主权门关（第一道）]
    · 校验确认码格式
    · 校验 UID 归属
    · 校验请求签名
    ↓ 通过
[熔断检测（第二道）]
    · 红线拦截 / 黄线留痕放行
    ↓ 通过
[通心译处理核心（第三道）]
    · 路由判断
    ↓
[DNA追加日志（永不跳过）]
    ↓
[响应返回]
```

## 第一节 · DNA 主权门关
认证方式： 所有外部请求必须在 HTTP Header 中携带：
```javascript
X-DNA-Confirm: #CONFIRM🌌9622-ONLY-ONCE🧬 LK9X-772Z
X-UID: 9622
X-Request-DNA: #龍芯⚡️{YYYY-MM-DD}-EXT-REQ-{8位大写HEX}
Content-Type: application/json
```
认证规则：
> 令牌即令牌，没有令牌就是没有。这不是傲慢，是主权。

## 第五节 · Chrome 插件调用示例
这段加进 cnsh-chrome-plugin 的选中文字处理逻辑里：
```javascript
async function sendToTongxinyi(selectedText) {
    const today = new Date().toISOString().slice(0, 10);
    const hex = Math.random().toString(16).slice(2, 10).toUpperCase();
    
    const response = await fetch("http://localhost:9622/api/tongxinyi/v1/translate", {
        method: "POST",
        headers: {
            "X-DNA-Confirm": "#CONFIRM🌌9622-ONLY-ONCE🧬 LK9X-772Z",
            "X-UID": "9622",
            "X-Request-DNA": `#龍芯⚡️${today}-EXT-REQ-${hex}`,
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            request_id: `REQ-${crypto.randomUUID()}`,
            caller: {
                uid: "9622",
                agent_id: "cnsh-chrome-plugin",
                context: "browser_capture"
            },
            content: {
                text: selectedText,
                lang_hint: "auto",
                audience: "general"
            },
            options: {
                write_to_notion: true,
                output_target: "auto"
            }
        })
    });
    return response.json();
}
```
