# §1 五重属性·焊死定义
## §1.1 身份属性（Identity）
- 含义： 一个 DNA = 一个唯一身份·不可伪造·不可重复
- 技术： Ed25519 公私钥对 + GPG 指纹 + 龍芯命名前缀 #龍芯⚡️YYYY-MM-DD-XXX-vN.N
- 隐喻： 身份证
- 铁律 DNA-1： 私钥永远本地保管·云端永不出现·丢失需助记词 + 五行碎片化恢复
## §1.2 入场属性（Admission）
- 含义： DNA = 沙盒钥匙·有 DNA 才有沙盒
- 技术： 私钥签名挂载 sandbox.lock 文件·校验通过才打开沙盒
- 隐喻： 门票
- 铁律 DNA-2： 一 DNA 一沙盒·禁多 DNA 共用沙盒·禁单 DNA 跨沙盒
## §1.3 心跳属性（Heartbeat）
- 含义： 月活回调 = 证明人还活着
- 技术： 微信支付 / 支付宝 / Apple Pay / 银联月扣 1 元 + DNA 时间戳更新
- 隐喻： 体检报告
- 铁律 DNA-3： 90 天无心跳回调 → DNA 转「冬眠态」·不删·只是不签发新动作
## §1.4 记忆属性（Memory）
- 含义： DNA 回溯链不可删·用户数据主权
- 技术： 区块链 hash 链 + Notion 留痕 + IPFS 冷备·三处镜像
- 隐喻： 海马体
- 铁律 DNA-5： 平台不得单方删除·删除需用户私钥签名授权·法律责任切到用户侧
## §1.5 上不封顶属性（Unbounded）
- 含义： 企业 DNA = 用户 DNA 的派生子链·上不封顶
- 技术： DNA-Parent → DNA-Child 树形 hash·Merkle Tree 时间戳
- 隐喻： 家族族谱
- 铁律 DNA-6： 企业不拥有用户 DNA·企业 DNA 是用户 DNA 的临时授权子链·授权可随时撤回
- 铁律 DNA-7： 抄袭方时间戳必晚于原创·DNA 签名链 = 铁证防伪
