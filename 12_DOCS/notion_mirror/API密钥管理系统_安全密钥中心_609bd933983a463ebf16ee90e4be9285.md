## ⚡ 使用指南
### 📖 集成示例
```javascript
// JavaScript集成示例
const apiKey = 'uid9622_sk_your_key_here';
const headers = {
  'Authorization': `Bearer ${apiKey}`,
  'Content-Type': 'application/json'
};

// 使用密钥调用API
fetch('https://api.uid9622.com/v1/chat/completions', {
  method: 'POST',
  headers: headers,
  body: JSON.stringify({
    model: 'uid9622-pro',
    messages: [{role: 'user', content: 'Hello!'}]
  })
});
```
### 🔧 最佳实践
1. 环境变量存储: 永远不要在代码中硬编码密钥
1. 定期轮转: 建议30天轮转一次密钥
1. 权限最小化: 只给予必需的最小权限
1. 监控使用: 定期检查密钥使用情况
1. 及时清理: 删除不再使用的密钥
