### 10. 导入素材｜字段说明 .md（拷贝为独立 Markdown 页）
```markdown
# CSV 字段说明（UID9622 架构）

## layers.csv（六层架构表）
- layer_id: 层级唯一 ID（L1…L6）
- layer_name: 层名称（核心架构层/人格协作层/太极进化系统/知识管理层/数据管理层/安全保护层）
- description: 层职责简述
- default_bucket: 默认入口桶（系统规则/知识派系/操作日志/灵感碎片）
- slo: 该层 SLO 描述
- map_rules: 该层常见匹配关键词

## map_rules.csv（四类→六层映射规则表）
- rule_id: 规则唯一 ID（R1…）
- from_bucket: 入口桶（四类）
- to_layer: 映射到的层（六层名称）
- match_keywords: 匹配关键词清单（逗号分隔）
- examples: 示例标题
- confidence: 置信度（0-100）
- enabled: 是否启用（TRUE/FALSE）

## content_items.csv（内容主表）
- item_id: 内容唯一 ID（C1…）
- title: 标题
- summary: 摘要或规则体
- source_window: 来源窗口或上下文
- bucket_4: 入口桶（四类）
- layer_6: 目标层（六层名称）
- status: 状态（草稿/待映射/进行中/已执行/归档）
- priority: 优先级（1-4）
- owner: 责任人/人格
- next_action: 下一步动作
- tags: 话题标签（空格分隔）

## 导入与关联
- 将三表分别导入为数据库后：
  - content_items.layer_6 → 关联 layers.layer_id 或 layer_name（二选一，推荐 layer_id）
  - map_rules.to_layer → 关联 layers.layer_id 或 layer_name
  - content_items.bucket_4 → 设为枚举（系统规则/知识派系/操作日志/灵感碎片）
- 视图建议：
  - content_items：按 layer_6 → Board 视图；按 status → Kanban
  - map_rules：按 enabled 过滤，confidence 降序
  - layers：Gallery 展示层简介与 SLO
```
