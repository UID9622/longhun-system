# 📖 CNSH编译器使用说明
DNA追溯码： #ZHUGEXIN⚡️2025-12-31-CNSH语言-V1.0
---
## 🚀 快速开始
### 第1步：安装依赖
```bash
# 需要Node.js环境
node --version  # 确认已安装
```
### 第2步：编写CNSH程序
创建 hello.cnsh：
```javascript
函数 主函数() 返回类型 整数 {
  打印「你好，CNSH！」
  返回 0
}
```
### 第3步：编译
```bash
# CNSH → C
node cnsh-compiler.js hello.cnsh

# C → 可执行文件
gcc hello.c -o hello

# 运行
./hello
```
