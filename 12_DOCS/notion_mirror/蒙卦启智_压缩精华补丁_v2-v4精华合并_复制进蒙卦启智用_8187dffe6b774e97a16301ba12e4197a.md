## 📦 模块3：盘点现状三步法（来自v4·压缩版）
### ✅ 第1步：系统里已经有这个了吗？
- 不知道 → 先查！
- 已经有 → 不新建，用已有的
- 确定没有 → 可以继续
### ✅ 第2步：这样做会不会搞乱现有结构？
- 不确定 → 先看结构！
- 会搞乱 → 改方案
- 不会乱 → 可以继续
### ✅ 第3步：有没有更简单的方式？
- 不知道 → 先盘点现有资源！
- 有更好的 → 用更好的
- 没有 → 可以执行
> 三关全过 = 执行。任何一关没过 = 停，重新想。
