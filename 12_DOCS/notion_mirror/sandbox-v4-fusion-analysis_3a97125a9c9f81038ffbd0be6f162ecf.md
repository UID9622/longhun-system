## §4. 融合方案
### 4.1 立即创建：沙盒推演统一入口
```plain text
bin/lh_sandbox_console.py  ← 新建·沙盒推演控制台统一入口
```
功能：
- `/推演 [主题]` → 路由到太极引擎
- `/博弈 [对手]` → 路由到双脑引擎
- `/宇宙 [决策]` → 路由到平行宇宙模拟器
- `/学习 [主题]` → 路由到学习管线
- `/H武器 [问题]` → 四引擎全开
- `--mode 守/中/攻` → 太极三模式
### 4.2 新建：平行宇宙模拟器
```plain text
bin/lh_parallel_universe.py  ← 新建·平行宇宙蒙特卡洛模拟器
```
基于：
- `lh_quantum_persona_antenna.py` 的量子态叠加
- `lh_mod9_runtime_engine.py` 的369不动点
- 蒙特卡洛采样 + 龍魂价值观筛选
- 10000宇宙并行推演
### 4.3 新建：信息标签系统
```plain text
bin/lh_info_labeler.py  ← 新建·信息溯源标签系统
```
五类标签：`[真实]` `[推理]` `[模拟]` `[引用]` `[假设]`
