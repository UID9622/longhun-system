### 输入 → 五行引擎选择
```javascript
IF 任务类型 == "判断/决策" → 金引擎
IF 任务类型 == "创作/生成" → 木引擎
IF 任务类型 == "整理/优化" → 水引擎
IF 任务类型 == "执行/推进" → 火引擎
```

### 引擎 → Worker分配
```javascript
金引擎 → W1-W3（分析组）
木引擎 → W4-W6（构建组）
水引擎 → W7-W9（清理组）
火引擎 → W10-W11（推进组）
土引擎 → W12+伏地魔层（固化组）
```
