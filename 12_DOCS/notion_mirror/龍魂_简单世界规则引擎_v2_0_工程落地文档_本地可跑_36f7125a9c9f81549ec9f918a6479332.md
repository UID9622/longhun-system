## 🔢 三色闸门·数字根算法
```python
# 龍魂标准：数字根决定三色
dr ∈ {1,2,4,5,7,8}  →  🟢 通行
dr = 6              →  🟡 待审
dr ∈ {3,9}          →  🔴 熔断
score = 0           →  🔴 熔断
```

## 🧬 DNA 链·账本防篡改机制
```javascript
每笔账生成：
  dna         = #龍芯⚡️YYYYMMDD-HHMMSS-EVT-{sha256[:8]}
  prev_hash   = 上一条的 chain_hash
  chain_hash  = sha256(event_id + person + action + timestamp + dna + prev_hash)[:16]

验证时：
  对每条重新算 chain_hash
  和存储的对比
  任何一条被改 → 立刻发现
```

## 🔌 接入龍魂系统
### 方式1：直接调用（推荐）
```python
from longhun_rules_engine_v2 import ScoreEngine, Event

engine = ScoreEngine()  # 自动加载账本

evt = Event(
    event_id="MY-001",
    person="张三",
    action="把合同搞错了",
    mistake=True,
    owned=True,
    stood_up=True,
    threat=False,
    compensated=True,
)

result = engine.judge(evt)
print(result["tricolor"], result["score_after"])
```
### 方式2：接入通心译·自动判断对话行为
```python
# 通心译输出 persona 路由后·可以直接把行为记录进规则引擎
from longhun_rules_engine_v2 import ScoreEngine, Event
import uuid

def record_behavior(person, action, is_threat=False):
    engine = ScoreEngine()
    evt = Event(
        event_id=f"TXY-{uuid.uuid4().hex[:8].upper()}",
        person=person,
        action=action,
        mistake=False,
        owned=False,
        stood_up=False,
        threat=is_threat,
    )
    return engine.judge(evt)
```
