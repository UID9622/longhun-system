### 🎯 进阶级
### 3. 计算器
```javascript
函数 加法(整数 a, 整数 b) 返回类型 整数 {
  返回 a + b
}

函数 主函数() 返回类型 整数 {
  整数 结果 = 加法(10, 20)
  打印「10 + 20 = {结果}」
  返回 0
}
```
### 4. 循环示例
```javascript
函数 主函数() 返回类型 整数 {
  整数 i = 1
  循环【i <= 10】{
    打印「这是第 {i} 次循环」
    i = i + 1
  }
  返回 0
}
```
---
### 🚀 实战级
### 5. 九九乘法表
```javascript
函数 主函数() 返回类型 整数 {
  整数 i = 1
  循环【i <= 9】{
    整数 j = 1
    循环【j <= i】{
      整数 结果 = i * j
      打印「{j} × {i} = {结果}」
      j = j + 1
    }
    i = i + 1
  }
  返回 0
}
```
