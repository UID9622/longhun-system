## 🎯 如何使用这些示例
### 1. 保存代码
将任意示例保存为 .cnsh 文件，例如：
```bash
# 保存示例1
vim hello.cnsh
# 复制示例1的代码
```
### 2. 编译
```bash
node cnsh-compiler.js hello.cnsh
```
### 3. 编译为可执行文件
```bash
gcc hello.c -o hello
```
### 4. 运行
```bash
./hello
```

## 💡 对比：CNSH vs C
### CNSH代码：
```javascript
函数 主函数() 返回类型 整数 {
  整数 数字 = 100
  
  如果【数字 > 50】{
    打印「数字很大」
  }
  
  返回 0
}
```
### 对应的C代码：
```c
int 主函数() {
    int 数字 = 100;
    
    if ((数字 > 50)) {
        printf("%s\n", "数字很大");
    }
    
    return 0;
}

int main() {
    主函数();
    return 0;
}
```
