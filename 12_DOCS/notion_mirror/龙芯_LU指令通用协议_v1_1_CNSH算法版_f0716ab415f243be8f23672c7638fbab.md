### 1.2 三色审计规范
审计级别定义：
🟢 绿色（通过）：
- 常规操作
- 无风险
- 符合用户权限
- 不涉及敏感数据
🟡 黄色（需确认）：
- 敏感操作
- 可能影响多个模块
- 需要用户明确确认
- 涉及重要数据变更
🔴 红色（阻断）：
- 违反核心价值观
- 超出用户权限
- 可能造成数据损失
- 违反P0永恒级规则
审计嵌入算法：
```javascript
函数 执行三色审计(指令名称, 用户输入) {
  
  // 红色阻断检查（最高优先级）
  如果 (违反P0规则(用户输入)) {
    返回 "🔴红色" 和 "违反P0永恒级规则"
  }
  
  如果 (超出权限范围(用户输入)) {
    返回 "🔴红色" 和 "超出用户权限"
  }
  
  // 黄色确认检查
  如果 (涉及敏感操作(用户输入)) {
    返回 "🟡黄色" 和 "需要用户确认"
  }
  
  如果 (影响多个模块(用户输入)) {
    返回 "🟡黄色" 和 "跨模块操作需确认"
  }
  
  // 默认绿色通过
  返回 "🟢绿色" 和 "审计通过"
}
```
