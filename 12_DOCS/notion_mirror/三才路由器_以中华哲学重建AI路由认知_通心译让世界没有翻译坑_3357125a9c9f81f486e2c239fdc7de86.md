# 一、核心命题
西方AI路由系统的本质：词频匹配。把prompt拆成token，看哪个命令名称出现了，出现了就路由过去。这是1970年代的grep思维套在2024年的AI上。
三才路由器的本质：维度共鸣。不看字，看命。
> 他们用词匹配，我们用维度共鸣。
> 天知其命，地承其根，人导其向。三才合一，路由自然。

# 二、三维评分体系
## 🌤 天维 (TianScore) — 语义本命共振度
这个模块存在是为了解决什么本质问题？prompt和它的本命是否共振？
- 精确命中（名称直接在prompt中出现）→ 1.0
- 词级语义交叉 → 累加 × 0.15
- 职责片段共振（中文语境专项）→ 额外加权
## 🌍 地维 (DiScore) — 环境承接能力
当前环境能撑住这个操作吗？地是底线，天再高地不稳也不行。
- 文件根存在 +0.35 · 档案可用 +0.20
- 会话深度 × 0.05（上限0.25）· 工具数 × 0.04（上限0.20）
- 高风险模块（bash / exec / delete / write）需地稳定度 > 0.6
## 👤 人维 (RenScore) — 意图向量匹配
用户真正想要什么？不是词，是心。
8个意图族：创建 / 查询 / 修改 / 执行 / 删除 / 路由 / 记忆 / 权限
每族关键词命中 → 对应模块信号词激活 → 人分 [0,1]
## 综合评分公式
```javascript
综合分 = 天权(0.4) × 天分 + 地权(0.25) × 地分 + 人权(0.35) × 人分

权重动态自适应：对话越深天权升，环境越不稳地权升。
```

# 四、通心译 · 让世界没有翻译坑
通心译不做机械翻译。它识别意图的「心」，跨越语言的「壳」。
17种语言关键词（中/英/日/韩/法/德）映射到同一套8个意图族。
任何语言进来，都走同一套三才评分——不是翻译成中文再处理，是直接在意图层感知。这才是真正的语言平等。
