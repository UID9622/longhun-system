# 通心譯·大白話解讀
## 一句話核心
自己寫一個本地腳本，能批量從網頁把正文抓下來，自動壓成幾百字精華，每條都打上獨一無二的身份碼，全部存在自己電腦裡，不用任何雲端AI模型。
## 為什麼重要
現在主流的搜索、筆記、AI助理都會把你的資料上傳到雲端，等於把自己的東西交給別人保管。這個工具讓普通人也能擁有「我的數據歸我」的能力——斷網能用、不付費、不洩漏、可溯源。
## 大白話展開
### 1. 它能做什麼
- 給它一個 URL 或者一個 URL 列表（txt 文件，每行一個）
- 它會一個個去抓網頁正文，自動丟掉廣告、導航、評論
- 抓到的幾萬字會被壓成幾百字的精華摘要
- 每條記錄都會獲得一個 DNA 身份碼（格式：#龍芯⚡️日期-模塊-哈希），以後想查「這條知識從哪來」，一秒就能溯源
- 全部存到本地 SQLite 數據庫 + JSONL 追加文件 + 獨立的 .cnsh 文件
### 2. v1.2 升級了什麼
之前 v1.1 只會把長文截前 1200 字當「壓縮」，太粗糙。v1.2 加了真壓縮邏輯：
- 按句子分割，挑出帶「禪、水墨、音效、留白、氣韻、頓悟、龍魂、數據主權」這些關鍵詞的句子
- 沒挑到關鍵詞的兜底取前 15 行
- 控制總長度在 600 字以內
- 自動套上 CNSH 格式頭尾，可以直接餵給視頻引擎當 Prompt
### 3. v1.4 的 TextRank 優化是什麼
以前的句子排序只看「詞頻+位置」，容易選到廢話。v1.4 加了三種新權重：
- 使命權重（×2.5）：句子裡有「人民、老百姓、主權、不屈、為民、守護」這些詞，分數大幅提升
- 禪宗權重（×1.8）：句子裡有「留白、氣韻、頓悟、空靈、以少勝多」，加分
- 連貫性權重：句子和上下文共現詞越多，越容易被選中（避免摘要碎片化）
- 長度懲罰：太長太短的句子扣分
結果：摘要不光短，而且天然帶有鐵頭兵的味道和水墨的韻味。
### 4. 怎麼用
```bash
# 單個URL
python3 bin/knowledge_batch_crawler_with_cnsh.py "https://arxiv.org/abs/xxx" --tags "RLHF,馬太效應"

# 批量文件（推薦）
python3 bin/knowledge_batch_crawler_with_cnsh.py urls.txt --list --tags "禪宗音效,水墨" --workers 6
```
### 5. 三色審計（建議擴展）
- 🟢 抓取成功 + 內容夠長 + 沒敏感詞
- 🟡 抓取失敗 / 內容太短
- 🔴 含敏感內容，需人工審核

不下模型也能建知識庫，關鍵不是抓多少，是數據歸你不歸雲。
