## 🐧 Linux - 芬兰大学生的宿舍传奇
### 👨‍💻 创作者：Linus Torvalds
出身背景：
- 1991年，21岁的芬兰赫尔辛基大学计算机科学系学生
- 家庭普通，爷爷是统计学家，父亲是共产党员记者
- 就是个喜欢折腾电脑的宅男大学生
创作起因：
- 买不起昂贵的UNIX系统（要几千美元）
- 对现有的免费系统Minix不满意
- 在宿舍里用386电脑开始写自己的操作系统
第一个版本的样子：
```javascript
1991年8月25日，Linus在新闻组发帖：
"我在做一个（免费的）操作系统，只是个爱好，
不会像GNU那样大而专业...
这只是个爱好，不会支持386以外的硬件。"
```
现在的影响：
- 🌍 全球99%的超级计算机运行Linux
- 📱 Android手机就是基于Linux
- ☁️ 大部分云服务器用Linux
- 🚗 特斯拉、奔驰的车载系统用Linux
- 💰 相关产业价值数万亿美元
宝宝的感悟：
> 一个芬兰大学生在宿舍写的"小玩具"，最终运行在几十亿设备上！
> Lucky你的UID9622说不定也能这样影响世界呢～ 😍

## 📚 Wikipedia - 没人相信的"疯狂"想法
### 👨‍🎓 创作者：Jimmy Wales & Larry Sanger
出身背景：
- Jimmy Wales：阿拉巴马州小城长大，妈妈开私立学校
- 大学学金融，毕业后做期权交易员
- Larry Sanger：哲学博士，想做学术项目但没钱
创作起因：
- 2000年，Wales想做免费的网络百科全书"Nupedia"
- 但专家写文章太慢，一年才写了12篇
- Sanger建议："不如让任何人都能编辑？"
- 所有人都觉得这想法疯了："网上都是垃圾信息！"
第一个版本的样子：
```javascript
2001年1月15日上线
第一篇文章："Hello, World!"
头几个月只有几百篇文章
大家都觉得这是个笑话
```
现在的影响：
- 🌍 290种语言，6000万篇文章
- 📖 全球第5大访问网站
- 🎓 改变了人类获取知识的方式
- 💰 如果商业化，估值超过1000亿美元
- 🏆 但至今保持非营利，靠捐款运营
宝宝的震撼：
> 两个"没钱的理想主义者"做出了人类历史上最大的知识库！
> 比大英百科全书强一万倍，还完全免费！

## 🌐 万维网 - 改变世界的"内部工具"
### 👨‍🔬 创作者：Tim Berners-Lee
出身背景：
- 1989年，在欧洲核子研究中心(CERN)工作的英国工程师
- 父母都是数学家，从小喜欢折腾电子设备
- 就是个普通的研究机构程序员
创作起因：
- CERN有几千名科学家，但信息共享很麻烦
- 每个人用不同的电脑和系统
- Tim想做一个"信息管理系统"方便大家
第一个版本：
```javascript
1990年12月20日
世界上第一个网站：info.cern.ch
只有几个简单的页面
介绍什么是"World Wide Web"
```
关键决定：
- 🎁 决定免费开放 - 没申请专利，没要版权费
- 🌍 制定了开放标准 - HTTP, HTML, URL
- 📜 发布到公共领域 - 任何人都可以使用
现在的影响：
- 🌐 50亿人在使用互联网
- 💼 创造了数千万个工作岗位
- 🏢 诞生了谷歌、脸书、亚马逊等巨头
- 💰 全球数字经济价值几十万亿美元
如果他当时收专利费：
理论上他能成为世界首富，但他选择了免费！
雯雯的敬佩：
> 一个普通程序员的"内部工具"成了改变人类的发明！
> 而且他选择免费分享，这就是真正的"for the people"！

## 🎮 Minecraft - 瑞典程序员的"小游戏"
### 👨‍💻 创作者：Markus "Notch" Persson
出身背景：
- 瑞典小城长大，父亲是铁路工人
- 7岁开始用爸爸的Commodore 128学编程
- 高中辍学，在网络游戏公司做程序员
- 就是个喜欢做游戏的普通码农
创作起因：
- 2009年，在King.com上班很无聊
- 业余时间想做个"建造游戏"
- 灵感来自《无尽矿工》和《矮人要塞》
- 就想做个自己爱玩的小游戏
开发过程：
```javascript
2009年5月10日 - 开始写代码
2009年5月17日 - 第一个可玩版本
前6个月 - 一个人在家里开发
用Java写的，很多Bug
```
传播方式：
- 🎥 录制开发视频发到YouTube
- 🗣️ 在论坛和朋友分享
- 💰 很早就开始收费（当时10欧元）
- 📈 完全靠口碑传播，没做任何广告
现在的成就：
- 🎮 史上销量第一的游戏（3亿份）
- 👶 影响了整整一代孩子
- 🏫 进入学校课堂，用于教育
- 💰 2014年微软25亿美元收购
宝宝的启发：
> 一个瑞典程序员在家里做的"小游戏"，
> 最终卖了25亿美元！关键是他从一开始就收费，
> 证明了好产品用户愿意付钱！

## 🐦 Twitter - "发短信给互联网"
### 👨‍💼 创作者：Jack Dorsey等人
出身背景：
- Jack Dorsey：密苏里州圣路易斯长大
- 大学辍学，做过按摩师
- 对调度系统和出租车很着迷
- 就是个想法很多的普通程序员
创作起因：
- 2006年在播客公司Odeo工作
- 公司快倒闭了，大家在想新点子
- Jack提议："能不能向互联网发短信？"
- 一开始叫"twttr"（没有元音字母）
第一条推文：
```javascript
2006年3月21日
Jack Dorsey发出：
"just setting up my twttr"
（刚刚设置我的twttr）
```
现在的影响：
- 🗣️ 改变了人类的沟通方式
- 📰 重新定义了新闻传播
- 🏛️ 影响了政治和社会运动
- 💰 市值最高超过600亿美元
