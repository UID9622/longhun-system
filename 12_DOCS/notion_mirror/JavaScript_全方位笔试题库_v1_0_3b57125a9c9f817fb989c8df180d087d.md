# 第一部分：JavaScript基础语法

### 1. 下列关于 `let`、`const`、`var` 的描述，正确的是？
A. `var` 声明的变量具有块级作用域  
B. `let` 声明的变量不存在变量提升  
C. `const` 声明的对象不能再修改其属性  
D. 同一作用域内 `let` 不能重复声明同名变量  
**答案：D**  
**解析：** `var` 是函数作用域，`let`/`const` 是块级作用域；`let`/`const` 同样存在提升，但处于暂时性死区（TDZ）不可访问；`const` 只保证引用不变，对象属性仍可修改；`let`/`const` 不允许重复声明。

### 2. `typeof null` 的返回值是？
A. `'null'`  
B. `'undefined'`  
C. `'object'`  
D. `'function'`  
**答案：C**  
**解析：** 这是 JavaScript 历史遗留 bug，`typeof null` 返回 `'object'`。判断 null 应使用 `value === null`。

### 3. 表达式 `[] + {}` 的结果是？
A. `'[object Object]'`  
B. `0`  
C. `NaN`  
D. `'{}'`  
**答案：A**  
**解析：** `+` 触发隐式类型转换，空数组转字符串为 `''`，对象转字符串为 `'[object Object]'`，拼接后得到 `'[object Object]'`。

### 4. 在严格模式（`'use strict'`）下，给未声明的变量赋值会？
A. 静默创建全局变量  
B. 抛出 `ReferenceError`  
C. 抛出 `TypeError`  
D. 返回 `undefined`  
**答案：B**  
**解析：** 非严格模式下会创建全局变量；严格模式下会抛出 `ReferenceError`，防止污染全局作用域。

### 5. 模板字符串中嵌入表达式的语法是__________。
**答案：** `${expression}`  
**解析：** 反引号包裹的模板字符串使用 `${}` 插入任意合法的 JavaScript 表达式，并自动调用其 `toString()`。

### 6. 在浏览器环境中，`0.1 + 0.2 === 0.3` 的求值结果是__________。
**答案：** `false`  
**解析：** IEEE 754 双精度浮点数无法精确表示 0.1 和 0.2，求和结果存在极小小数误差，通常应使用容差比较。

### 7. `NaN === NaN` 返回 `true`。
**答案：** ❌错误  
**解析：** `NaN` 与任何值（包括自身）进行 `===` 比较都返回 `false`。判断 `NaN` 应使用 `Number.isNaN()`。

### 8. `const obj = {}; obj.x = 1;` 会抛出 `TypeError`。
**答案：** ❌错误  
**解析：** `const` 保证变量绑定不可重新赋值，但对象本身的属性可以修改。只有重新赋值 `obj = ...` 才会报错。

### 9. 什么是暂时性死区（Temporal Dead Zone, TDZ）？请结合 `let`/`const` 说明。
**参考答案：**
- `let`/`const` 声明的变量在代码执行到声明语句之前无法访问。
- 该变量虽然已在作用域内存在，但处于“未初始化”状态，提前访问会抛出 `ReferenceError`。
- `var` 不存在 TDZ，提升后初始化为 `undefined`。
- 示例：`console.log(a); let a = 1;` 会报错。

### 10. 简述 `==` 与 `===` 的区别，并说明推荐做法。
**参考答案：**
- `==` 在比较前会进行隐式类型转换（抽象相等比较）。
- `===` 要求类型和值都相同（严格相等比较），不进行类型转换。
- 推荐默认使用 `===`，避免意外的类型转换导致逻辑错误。
- 例如 `0 == '0'` 为 `true`，而 `0 === '0'` 为 `false`。

### 11. 分析以下代码的输出：
```js
console.log(a);
var a = 10;
console.log(b);
let b = 20;
```
**答案：** 先输出 `undefined`，然后抛出 `ReferenceError: Cannot access 'b' before initialization`  
**解析：** `var a` 会提升到作用域顶部并初始化为 `undefined`，所以第一个 `console.log` 输出 `undefined`；`let b` 虽然也被提升，但处于 TDZ，访问会报错。

### 12. 分析以下代码在浏览器非严格模式与严格模式下的输出：
```js
function foo() { console.log(this); }
foo();
const obj = { foo };
obj.foo();
```
**答案：** 非严格模式：`window`（或全局对象），`obj`；严格模式：`undefined`，`obj`  
**解析：** 普通函数直接调用时，`this` 在非严格模式下指向全局对象，严格模式下为 `undefined`；作为对象方法调用时，`this` 指向调用对象 `obj`。

### 13. 请编写一个基于 `JSON` 的浅/深克隆函数，并说明其局限性。
```js
function deepClone(obj) {
  return JSON.parse(JSON.stringify(obj));
}
```
**答案：** 见上  
**解析：** 该方法无法克隆函数、`undefined`、`Symbol`、循环引用、`Date`/`RegExp`/`Map`/`Set` 等对象；只适用于由纯 JSON 可序列化数据组成的简单对象。

### 14. 请实现一个防抖（debounce）函数。
```js
function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```
**答案：** 见上  
**解析：** 防抖确保在指定延迟内再次触发时取消上一次计时器，只执行最后一次调用。`this` 和参数通过闭包保存，适用于输入框搜索等高频事件。

# 第二部分：数据结构与容器

### 15. 哪个数组方法会返回一个由通过测试的元素组成的新数组？
A. `map`  
B. `filter`  
C. `reduce`  
D. `forEach`  
**答案：B**  
**解析：** `filter` 按回调返回的布尔值筛选元素并返回新数组；`map` 返回映射后的新数组；`reduce` 用于累积；`forEach` 不返回值。

### 16. `new Set([1, 1, 2, 3]).size` 的值是？
A. `1`  
B. `2`  
C. `3`  
D. `4`  
**答案：C**  
**解析：** `Set` 只保存唯一值，重复 `1` 被去重，最终集合为 `{1, 2, 3}`，`size` 为 3。

### 17. 关于 `WeakMap`，下列说法正确的是？
A. 键可以是任意类型  
B. 键必须是对象  
C. 可以通过 `size` 获取元素数量  
D. 键会阻止垃圾回收  
**答案：B**  
**解析：** `WeakMap` 的键必须是对象，且为弱引用，不会阻止垃圾回收；没有 `size` 属性，也不可枚举。

### 18. 删除数组第一个元素应使用的方法是__________。
**答案：** `shift()`  
**解析：** `shift()` 移除数组第一个元素并返回该元素，会改变原数组；`pop()` 移除最后一个元素。

### 19. 判断数组是否包含某个元素的标准方法是__________。
**答案：** `Array.prototype.includes()`  
**解析：** `includes()` 使用 SameValueZero 算法比较，可正确判断 `NaN`；`indexOf()` 无法判断 `NaN`。

### 20. `Object.keys()` 会返回对象自身的可枚举属性和继承属性。
**答案：** ❌错误  
**解析：** `Object.keys()` 只返回对象自身的可枚举属性键名，不包括继承属性；`for...in` 才会遍历继承的可枚举属性。

### 21. 简述 `Map` 与 `Object` 在作为键值容器时的主要区别。
**参考答案：**
- `Map` 的键可以是任意类型（包括对象、函数），`Object` 的键只能是字符串或 Symbol。
- `Map` 按插入顺序迭代，`Object` 的键顺序较复杂（数字键会排序）。
- `Map` 可直接通过 `size` 获取数量，`Object` 需手动计算。
- `Map` 在频繁增删键值对时性能通常更好。

### 22. 什么是类数组对象（array-like object）？如何将其转换为真正的数组？
**参考答案：**
- 类数组对象具有 `length` 属性和整数索引，但没有数组原型方法，如 `arguments`、`NodeList`。
- 转换方法：`Array.from(arrayLike)`、`[...arrayLike]`（需实现迭代器）、`Array.prototype.slice.call(arrayLike)`。
- `Array.from` 最推荐，支持映射回调。

### 23. 分析以下代码的输出：
```js
const arr = [1, 2, 3];
const doubled = arr.map(num => num * 2);
console.log(arr, doubled);
```
**答案：** `[1, 2, 3] [2, 4, 6]`  
**解析：** `map` 不会修改原数组，而是返回一个新数组。`arr` 保持不变，`doubled` 为映射结果。

### 24. 分析以下代码的输出：
```js
const a = [1, 2];
const b = [1, 2];
console.log(a == b, a === b);
```
**答案：** `false false`  
**解析：** 数组是引用类型，`==` 和 `===` 比较的是引用地址，`a` 与 `b` 指向不同内存地址，因此都为 `false`。

### 25. 请实现一个将二维数组展平一层的函数。
```js
function flatOnce(arr) {
  return [].concat(...arr);
}
```
**答案：** 见上  
**解析：** 使用扩展运算符将二维数组展开为 `concat` 的参数，实现一层展平。对 `[1, [2, 3], 4]` 返回 `[1, 2, 3, 4]`。

### 26. 请实现一个按指定字段对对象数组进行分组的函数。
```js
function groupBy(arr, key) {
  return arr.reduce((acc, item) => {
    const k = item[key];
    (acc[k] ||= []).push(item);
    return acc;
  }, {});
}
```
**答案：** 见上  
**解析：** 使用 `reduce` 遍历数组，以 `key` 值为分组键，将元素推入对应数组。逻辑简洁且只遍历一次。

### 27. 请使用 `Map` 实现一个最简单的 LRU 缓存。
```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.cache = new Map();
  }
  get(key) {
    if (!this.cache.has(key)) return -1;
    const val = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, val);
    return val;
  }
  put(key, value) {
    if (this.cache.has(key)) this.cache.delete(key);
    else if (this.cache.size >= this.capacity) {
      const oldest = this.cache.keys().next().value;
      this.cache.delete(oldest);
    }
    this.cache.set(key, value);
  }
}
```
**答案：** 见上  
**解析：** `Map` 按插入顺序维护键，`get` 时先删除再插入以更新最近使用顺序；`put` 时若超过容量则删除最旧的键（`keys().next()`）。

# 第三部分：函数/方法/模块

### 28. 箭头函数不具有以下哪一项？
A. `prototype` 属性  
B. 自身的 `this` 绑定  
C. `arguments` 对象  
D. 以上皆是  
**答案：D**  
**解析：** 箭头函数没有 `prototype`、不绑定自身 `this`（继承外层 `this`）、没有 `arguments` 对象，因此不能用作构造函数，也不能使用 `new`。

### 29. 立即执行函数 `(function(){ return typeof arguments; })()` 的返回值是？
A. `'undefined'`  
B. `'object'`  
C. `'array'`  
D. `'arguments'`  
**答案：B**  
**解析：** 普通函数内部存在 `arguments` 对象，其类型为 `'object'`。注意它并非真正的数组。

### 30. 在 ES6 模块中，导入默认导出的正确语法是？
A. `import * as foo from './mod'`  
B. `import foo from './mod'`  
C. `import { foo } from './mod'`  
D. `import './mod'`  
**答案：B**  
**解析：** 默认导出使用 `import foo from '...'`；命名导出使用 `import { foo } from '...'`；`import * as foo` 导入所有导出为命名空间对象。

### 31. 定义在另一个函数内部、能够记住并访问外部作用域的函数称为__________。
**答案：** 闭包（closure）  
**解析：** 闭包使得函数即使在外部函数执行完毕后，仍能访问其词法作用域中的变量，是 JS 高阶组件与模块化的核心机制。

### 32. 将模块 `./utils` 的所有命名导出重新导出的语法是__________。
**答案：** `export * from './utils';`  
**解析：** `export * from 'path'` 重新导出目标模块的所有命名导出，常用于构建统一的入口文件（barrel file）。

### 33. 箭头函数可以使用 `new` 关键字作为构造函数调用。
**答案：** ❌错误  
**解析：** 箭头函数没有 `[[Construct]]` 内部方法，也没有 `prototype` 属性，使用 `new` 调用会抛出 `TypeError`。

### 34. 请解释闭包的概念，并给出一个实际应用场景。
**参考答案：**
- 闭包是指函数能够访问其词法作用域，即使该作用域已执行完毕。
- 实际应用包括：数据私有化（模块模式）、柯里化、函数工厂、防抖/节流中的定时器状态保持。
- 示例：计数器 `function createCounter() { let n=0; return () => ++n; }` 中的 `n` 被闭包隐藏。
- 注意闭包会持有引用，使用不当可能造成内存泄漏。

### 35. 简述 CommonJS 的 `require` 与 ES6 的 `import` 的主要区别。
**参考答案：**
- `require` 是运行时同步加载，`import` 是编译时静态解析（动态 `import()` 除外）。
- `require` 可放在任意代码位置，`import` 必须位于模块顶层（非动态）。
- `require` 导出的是值的拷贝，`import` 导出的是值的只读引用（实时同步）。
- ES6 模块支持树摇（tree-shaking），CommonJS 较难分析副作用。

### 36. 分析以下代码的输出：
```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
```
**答案：** 输出三次 `3`  
**解析：** `var` 声明的 `i` 是函数作用域，循环结束后 `i` 为 3；三个 `setTimeout` 共享同一个 `i`，执行时均输出 3。改为 `let` 可得到 0、1、2。

### 37. 分析以下代码的输出：
```js
const obj = {
  value: 42,
  getValue: () => this.value
};
console.log(obj.getValue());
```
**答案：** `undefined`  
**解析：** 箭头函数不绑定自身 `this`，`this` 继承自定义时的上下文。此处定义在全局作用域，`this` 指向全局对象（严格模式为 `undefined`），全局对象上没有 `value` 属性。

### 38. 请实现一个对纯函数进行记忆化（memoize）的函数。
```js
function memoize(fn) {
  const cache = new Map();
  return function (...args) {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key);
    const result = fn.apply(this, args);
    cache.set(key, result);
    return result;
  };
}
```
**答案：** 见上  
**解析：** 使用 `Map` 缓存参数序列化后的结果，命中缓存直接返回，避免重复计算。注意参数序列化对对象键顺序敏感，且不能处理不可序列化参数。

### 39. 请实现一个固定元数的柯里化函数。
```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    return (...next) => curried(...args, ...next);
  };
}
```
**答案：** 见上  
**解析：** 递归收集参数，当参数数量达到原函数 `length` 时执行；否则返回新函数继续接收参数。`fn.length` 表示函数期望的形参个数。

### 40. 请实现一个简化版的事件发射器（EventEmitter）。
```js
class EventEmitter {
  constructor() {
    this.events = {};
  }
  on(event, listener) {
    (this.events[event] ||= []).push(listener);
    return () => this.off(event, listener);
  }
  off(event, listener) {
    if (!this.events[event]) return;
    this.events[event] = this.events[event].filter(l => l !== listener);
  }
  emit(event, ...args) {
    (this.events[event] || []).forEach(l => l(...args));
  }
}
```
**答案：** 见上  
**解析：** 使用对象存储事件到监听器数组的映射；`on` 注册并返回取消订阅函数，`off` 移除指定监听器，`emit` 同步触发所有监听器。

# 第四部分：面向对象/类型系统

### 41. 下列关于 `prototype` 的说法，正确的是？
A. 每个对象都有 `prototype` 属性  
B. 函数的 `prototype` 属性指向自身的原型

### 47. 简述 JavaScript 原型链的基本查找机制。
**参考答案：**
- 访问对象属性时，先查找对象自身属性；找不到则沿 `__proto__` 向上查找。
- 原型链的顶端是 `Object.prototype`，再往上为 `null`。
- 构造函数通过 `prototype` 属性指定实例原型，实例通过 `__proto__` 链接到该原型。
- 修改构造函数原型上的属性会影响所有实例共享的方法。

### 48. 解释 `new` 运算符在调用构造函数时执行的主要步骤。

- 将构造函数的 `this` 绑定到该对象。
- 执行构造函数体，初始化属性。
- 若构造函数返回对象，则返回该对象；否则返回新创建的对象。

### 54. 下列关于 `Promise` 的说法，正确的是？
A. `Promise` 一经创建就会立即执行  
B. `.then()` 中的回调总在当前任务队列清空后执行  
C. `Promise.reject().then(null, fn)` 中的 `fn` 不会执行  
D. `Promise.all` 在任意一个 Promise 成功时返回  
**答案：A**  
**解析：** Promise 执行器函数在创建时同步执行；`.then()` 回调进入微任务队列，在当前宏任务完成后执行；`reject` 会被 `onRejected` 捕获；`Promise.all` 需全部成功。

### 55. `async` 函数的返回值总是？
A. 同步值  
B. 一个 `Promise`  
C. `undefined`  
D. 抛出错误  
**答案：B**  
**解析：** `async` 函数总是返回一个 Promise，若显式返回非 Promise 值会被包装为 `Promise.resolve(value)`；抛出错误会返回 rejected Promise。

### 56. 关于事件循环（Event Loop），下列说法正确的是？
A. 宏任务总是优先于微任务执行  
B. 同一轮事件循环中，微任务队列为空后才会执行渲染  
C. `setTimeout` 回调属于微任务  
D. `Promise.then` 属于宏任务  
**答案：B**  
**解析：** 微任务优先级高于宏任务，每执行一个宏任务后会清空微任务队列；`setTimeout` 是宏任务，`Promise.then` 是微任务；微任务清空后浏览器才进行渲染。

### 57. 解构赋值中，为变量设置默认值的语法是__________。
**答案：** `const { a = 1, b: x = 2 } = obj` 或 `const [a = 1] = arr`  
**解析：** 对象解构使用 `key = default` 设置默认值；数组解构使用 `index = default`；重命名与默认值可组合为 `key: varName = default`。

### 58. 使用 `Object.defineProperty` 定义属性时，使属性不可写的配置项是__________。
**答案：** `writable: false`  
**解析：** `writable` 控制属性值是否可通过赋值修改；`configurable` 控制属性描述符是否可修改及属性是否可删除；`enumerable` 控制是否可枚举。

### 59. `await` 只能在 `async` 函数内部或 ES 模块顶层使用。
**答案：** ✅正确  
**解析：** 在普通函数中使用 `await` 会抛出 `SyntaxError`。现代浏览器支持顶层 `await`，但仅限于 ES 模块环境。

### 60. `Promise.race` 会在所有 Promise 都完成时返回结果。
**答案：** ❌错误  
**解析：** `Promise.race` 返回最先 settled（resolve 或 reject）的 Promise 结果；`Promise.all` 才等待所有 Promise 完成。

### 61. 简述 `async/await` 相比 Promise 链式调用的优势与潜在陷阱。
**参考答案：**
- 优势：代码更接近同步写法，可读性高；便于使用 try/catch 进行错误处理；便于在循环中使用（结合 `for...of`）。
- 陷阱：连续 `await` 会串行执行，可能降低性能；应使用 `Promise.all` 并行；错误处理需显式 try/catch。
- `await` 只等待表达式右侧的 Promise，不会阻塞主线程其他代码。

### 62. 解释 JavaScript 中微任务（microtask）与宏任务（macrotask）的区别，并各举一例。
**参考答案：**
- 宏任务代表一次事件循环的完整任务单元，如 `setTimeout`、`setInterval`、I/O、UI 渲染、`<script>` 执行。
- 微任务在当前宏任务结束后、下一个宏任务前执行，如 `Promise.then`、`MutationObserver`、`queueMicrotask`。
- 微任务队列会优先清空，因此微任务执行时机早于宏任务。
- 过度使用微任务可能阻塞渲染。

### 63. 分析以下代码的输出顺序：

**解析：** `start` 和 `end` 为同步输出；`Promise.then` 进入微任务队列，`setTimeout` 进入宏任务队列；当前同步代码执行完后先清空微任务，再执行宏任务。

### 94. 请实现一个深拷贝函数，能够处理循环引用、Date、RegExp 及基本对象。
```js
function deepClone(value, map = new WeakMap()) {
  if (value === null || typeof value !== 'object') return value;
  if (value instanceof Date) return new Date(value);
  if (value instanceof RegExp) return new RegExp(value);
  if (map.has(value)) return map.get(value);
  const clone = Array.isArray(value) ? [] : {};
  map.set(value, clone);
  for (const key of Reflect.ownKeys(value)) {
    clone[key] = deepClone(value[key], map);
  }
  return clone;
}
```
**答案：** 见上  
**解析：** 使用 `WeakMap` 记录已克隆对象以处理循环引用；单独处理 `Date` 和 `RegExp`；`Reflect.ownKeys` 可遍历 Symbol 键。复杂类型如 `Map`/`Set` 可进一步扩展。

### 95. 请实现一个支持串行与并行两种模式的异步任务调度器。
```js
class AsyncScheduler {
  constructor(max = 2) {
    this.max = max;
    this.running = 0;
    this.queue = [];
  }
  add(task) {
    return new Promise((resolve, reject) => {
      this.queue.push({ task, resolve, reject });
      this.run();
    });
  }
  run() {
    if (this.running >= this.max || !this.queue.length) return;
    const { task, resolve, reject } = this.queue.shift();
    this.running++;
    task()
      .then(resolve, reject)
      .finally(() => { this.running--; this.run(); });
  }
}
```
**答案：** 见上  
**解析：** 限制并发数为 `max`，任务入队后当运行数小于最大值时取出执行；任务完成后递归触发后续任务，确保始终有 `max` 个任务并行。
