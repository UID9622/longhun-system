> Mac专用 | 自动安装Python依赖库
---
## 📝 完整代码
创建文件：一键安装.command
```bash
#!/bin/bash
# UID9622 一键安装脚本

clear
echo "=================================================="
echo "🔐 UID9622 加密工具 - 一键安装"
echo "=================================================="
echo ""
echo "💝 正在检查系统环境..."
echo ""

# 检查Python3
if ! command -v python3 &> /dev/null; then
    echo "❌ 未检测到Python3"
    echo ""
    echo "💡 请先安装Python3："
    echo "   访问 python.org"
    echo "   下载最新版Python3并安装"
    echo ""
    read -p "按回车键退出..."
    exit 1
fi

echo "✅ Python3 已安装"
PYTHON_VERSION=$(python3 --version)
echo "   版本：$PYTHON_VERSION"
echo ""

# 检查pip3
if ! command -v pip3 &> /dev/null; then
    echo "❌ 未检测到pip3"
    echo "💡 正在尝试安装pip3..."
    python3 -m ensurepip --default-pip
fi

echo "✅ pip3 已就绪"
echo ""

# 安装加密库
echo "📦 正在安装加密库（cryptography）..."
echo "   这可能需要1-2分钟，请耐心等待..."
echo ""

pip3 install cryptography --quiet

if [ $? -eq 0 ]; then
    echo ""
    echo "=================================================="
    echo "✅ 安装完成！"
    echo "=================================================="
    echo ""
    echo "📂 已安装的组件："
    echo "   • Python3: $PYTHON_VERSION"
    echo "   • cryptography: 最新版"
    echo ""
    echo "🚀 下一步："
    echo "   双击运行「加密工具.command」开始加密文件"
    echo ""
else
    echo ""
    echo "❌ 安装失败"
    echo "💡 请检查网络连接后重试"
    echo ""
fi

read -p "按回车键退出..."
```

## 🛠️ 创建步骤
### 方法1：文本编辑器（推荐小白）
1. 打开「文本编辑」（在应用程序里）
1. 菜单「格式」→「制作纯文本」
1. 复制上面的代码
1. 粘贴到文本编辑
1. 保存文件名为：一键安装.command
1. 关闭文件
### 方法2：终端命令（推荐高手）
```bash
# 在终端运行
cat > 一键安装.command << 'EOF'
[粘贴上面的完整代码]
EOF

chmod +x 一键安装.command
```
