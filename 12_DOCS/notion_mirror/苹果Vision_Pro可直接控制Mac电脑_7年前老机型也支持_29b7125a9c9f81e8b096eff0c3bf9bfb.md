# Vision Pro 支持 Mac 远程控制
Vision Pro 正式在美国上市，苹果官方发布了相关支持文档，透露 Vision Pro 可以直接查看和控制 Mac 电脑。
Mac Virtual Display 功能支持运行 macOS Sonoma 的任何 Mac，配备 Apple 芯片的 Mac 可显示 4K 分辨率。
搭载英特尔处理器的 Mac 分辨率将限制在 3K。
支持 macOS Sonoma 的 Mac 列表：
- MacBook Pro：2018 年及更新机型
- MacBook Air：2018 年及更新机型
- Mac mini：2018 年及更新机型
- iMac：2019 年及更新机型
- iMac Pro：2017 年
- Mac Studio：2022 年及更新机型
- Mac Pro：2019 年及更新机型
值得注意的是，iMac Pro 于 2017 年 6 月发布，距今已近 7 年。
要使用此功能，Vision Pro 和 Mac 需登录同一个 Apple ID，且该帐户启用双重认证，同时两台设备必须开启 Wi-Fi 和蓝牙。
用户可使用 Mac 键盘和触控板控制 Vision Pro 应用，但 Vision Pro 无法直接连接蓝牙鼠标。
最后提醒，当 Vision Pro 处于访客模式时，Mac Virtual Display 功能将无法正常工作。
