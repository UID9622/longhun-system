🟡 主金色（皇者/传承）：#FFD700 → #FFA500 → #B8860B

一-B、🥈 银色体系（守护·传承·印章专属）✨新增
银色渐变三阶：
- 🥈 高光银（主）：#E8E8E8 → #C0C0C0
- 🔘 正银（标准）：#A8A8A8 → #909090
- 🖤 暗银（阴影）：#707070 → #555555
银色含义定位：
- 金色 = 皇者·高调·主徽章
- 银色 = 守护·低调·印章签名·副徽章·数字人水印
- 两色组合 = 金龍银盾·阴阳相济
银色专属使用场景：
- L4 印章版（200×200）签名水印
- 数字人视频角落固定水印
- 文档版权盖章
- 副标识背景底色
