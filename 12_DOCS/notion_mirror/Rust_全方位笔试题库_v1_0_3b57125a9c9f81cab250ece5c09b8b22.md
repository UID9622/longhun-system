# 第一部分：Rust 基础语法

### 1. 以下哪个是 Rust 中合法的变量声明？
A. `let mut x = 5; x = "hello";`  
B. `let x = 5; x = 6;`  
C. `let mut x = 5; x = 6;`  
D. `const x: i32 = 5; x = 6;`  
**答案：C**  
**解析：** `let mut` 声明可变变量，允许重新赋值。A 会触发类型不匹配；B 中 `x` 不可变；D 中 `const` 为编译期常量不可重新赋值。

### 2. 填空：在 Rust 中，语句 `let x = 5;` 默认将 `x` 绑定为 ______ 变量。  
**答案：** `不可变`  
**解析：** Rust 默认通过 `let` 创建的绑定是不可变的，必须使用 `mut` 关键字显式声明可变性。

### 3. 判断：`let x = 5; let x = x + 1;` 在 Rust 中会产生编译错误，因为 x 不可变。  
**答案：** ❌错误  
**解析：** 这是变量遮蔽（shadowing），允许用同名新变量覆盖旧变量，不是对同一变量重新赋值，因此合法。

### 4. Rust 的所有权规则不包括下列哪一项？  
A. 每个值有且仅有一个所有者  
B. 当所有者离开作用域，值被丢弃  
C. 值可以拥有多个可变所有者  
D. 所有权可以转移  
**答案：C**  
**解析：** Rust 的所有权核心规则禁止同时存在多个可变引用，也不允许可变与不可变引用共存。

### 5. 填空：Rust 通过 ______ 和 ______ 两个主要机制在编译期保证内存安全。  
**答案：** `所有权`、`借用`  
**解析：** 所有权系统负责管理内存生命周期，借用检查器则在编译期验证引用合法性，二者共同避免悬垂指针和数据竞争。

### 6. 判断：`String` 类型存储在栈上，而 `&str` 类型存储在堆上。  
**答案：** ❌错误  
**解析：** `String` 的数据体存储在堆上，其元数据（指针、长度、容量）在栈上；`&str` 是字符串切片引用，指向的字符串数据可能在堆或静态存储区。

### 7. 以下代码的输出是什么？  
```rust
fn main() {
    let s = String::from("hello");
    let r1 = &s;
    let r2 = &s;
    println!("{} {}", r1, r2);
}
```  
A. 编译错误  
B. 运行时 panic  
C. 输出 `hello hello`  
D. 未定义行为  
**答案：C**  
**解析：** 多个不可变引用可以同时存在，只要没有可变引用即可，因此能正常打印两次 `hello`。

### 8. 简答题：解释 Rust 中 `Copy` trait 与 `Clone` trait 的区别，并各举一个适用类型。  
**参考答案：**  
- `Copy` 标记按位复制语义，赋值时隐式复制原值仍可用，适用于栈上小类型如 `i32`、`bool`。  
- `Clone` 提供显式 `.clone()` 方法，常用于堆分配类型如 `String`、`Vec<T>`，需要深拷贝时手动调用。  
**解析：** `Copy` 是隐式、廉价的复制；`Clone` 是显式、可能昂贵的深拷贝，且 `Copy` 要求类型实现 `Clone`。

### 9. 填空：Rust 中的模式匹配主要通过 ______ 关键字实现。  
**答案：** `match`  
**解析：** `match` 用于对枚举、元组、结构体等值进行穷尽式分支匹配，是 Rust 表达控制流的核心工具。

### 10. 程序分析题：下面的代码能否通过编译？如果不能，请说明原因并给出最小修复方案。  
```rust
fn main() {
    let s = String::from("Rust");
    let r = &s;
    let t = s;
    println!("{}", r);
}
```  
**答案：** 不能编译。  
**解析：** `s` 被移动到 `t` 后，不可变引用 `r` 继续指向已失效的 `s`，违反借用规则。修复方案是先使用引用再移动，或克隆：`let t = s.clone();`。

### 11. 选择题：关于 Rust 引用，下列说法正确的是？  
A. 可以同时存在多个可变引用  
B. 可变引用与不可变引用不能同时存在  
C. 引用的生命周期在运行时检查  
D. 引用会转移原值的所有权  
**答案：B**  
**解析：** Rust 借用规则：要么一个可变引用，要么任意多个不可变引用；生命周期在编译期检查；引用不会转移所有权。

### 12. 编程题：编写一个 Rust 函数 `is_palindrome(s: &str) -> bool`，判断字符串是否为回文，要求不分配新的 `String`。  
```rust
fn is_palindrome(s: &str) -> bool {
    s.chars().eq(s.chars().rev())
}

fn main() {
    assert!(is_palindrome("racecar"));
    assert!(!is_palindrome("rust"));
}
```  
**答案：** 见上。  
**解析：** 利用 `chars()` 迭代器与其反转迭代器逐字符比较，无需堆分配，充分利用 Rust 的字符串切片和迭代器机制。


# 第二部分：数据结构与容器

### 13. `Vec<T>` 在 Rust 中的默认容量增长策略通常是什么？  
A. 每次 push 增加 1  
B. 按 2 的幂次倍增  
C. 固定 16 个元素  
D. 永不扩容  
**答案：B**  
**解析：** Rust 的 `Vec` 在容量不足时通常按近似 2 倍策略扩容，以均摊 `push` 操作的时间复杂度为 O(1)。

### 14. 填空：要从 `Vec<i32>` 中删除所有满足条件的元素，应使用迭代器方法 ______。  
**答案：** `retain`  
**解析：** `Vec::retain` 原地保留满足谓词的元素并丢弃其余元素，无需新建容器，时间复杂度 O(n)。

### 15. 判断：`HashMap<K, V>` 的键类型 K 必须实现 `Eq` 和 `Hash` trait。  
**答案：** ✅正确  
**解析：** `HashMap` 依赖等价性判断和哈希计算，`K` 需要实现 `Eq`（或 `PartialEq`）与 `Hash`。

### 16. 程序分析题：下面代码的输出是什么？  
```rust
use std::collections::HashSet;
fn main() {
    let mut s = HashSet::new();
    s.insert(1);
    s.insert(1);
    s.insert(2);
    println!("{}", s.len());
}
```  
A. 1  
B. 2  
C. 3  
D. 编译错误  
**答案：B**  
**解析：** `HashSet` 不允许重复元素，两次插入 `1` 只保留一个，因此长度为 2。

### 17. 选择题：关于 `Option<T>`，下列哪个转换会在值为 `None` 时 panic？  
A. `opt.unwrap_or(0)`  
B. `opt.unwrap()`  
C. `opt.unwrap_or_default()`  
D. `opt.unwrap_or_else(|| 0)`  
**答案：B**  
**解析：** `unwrap()` 在 `None` 时 panic；其余方法都提供安全默认值或生成函数。

### 18. 填空：`Result<T, E>` 中表示操作成功的变体是 ______，失败变体是 ______。  
**答案：** `Ok`、`Err`  
**解析：** `Ok(T)` 承载成功值，`Err(E)` 承载错误值，Rust 通过这两个枚举变体强制显式错误处理。

### 19. 编程题：使用 `HashMap` 统计一段文本中每个单词出现的次数（忽略大小写）。  
```rust
use std::collections::HashMap;

fn word_count(text: &str) -> HashMap<String, u32> {
    let mut map = HashMap::new();
    for word in text.to_lowercase().split_whitespace() {
        *map.entry(word.to_string()).or_insert(0) += 1;
    }
    map
}

fn main() {
    let text = "Rust is great and Rust is fast";
    let counts = word_count(text);
    assert_eq!(counts["rust"], 2);
}
```  
**答案：** 见上。  
**解析：** 使用 `to_lowercase()` 统一大小写，`split_whitespace()` 分词，`entry().or_insert()` 简洁地处理键不存在的情况。

### 20. 判断：`Vec::remove(0)` 的时间复杂度是 O(1)。  
**答案：** ❌错误  
**解析：** 从 `Vec` 头部删除元素需要将所有后续元素前移，时间复杂度为 O(n)；尾部删除 `pop()` 才是 O(1)。

### 21. 简答题：比较 `Vec<T>`、`LinkedList<T>` 和 `VecDeque<T>` 的适用场景。  
**参考答案：**  
- `Vec<T>`：随机访问和尾部追加频繁，内存连续缓存友好。  
- `LinkedList<T>`：频繁在两端或中间插入删除，但缓存不友好，日常使用较少。  
- `VecDeque<T>`：需要在两端高效 push/pop 时使用。  
**解析：** Rust 标准库容器根据访问模式和内存局部性选择，`Vec` 通常是默认首选。

### 22. 程序分析题：指出下面代码的编译错误并修正。  
```rust
fn main() {
    let v = vec![1, 2, 3];
    let first = &v[0];
    v.push(4);
    println!("{}", first);
}
```  
**答案：** 不能编译。  
**解析：** `first` 是不可变引用，随后 `v.push(4)` 需要可变引用，违反借用规则。应在使用 `first` 之后再 push，或先克隆所需值。

### 23. 选择题：下列哪个类型实现了 `Copy` trait？  
A. `String`  
B. `Vec<i32>`  
C. `(i32, i32)`  
D. `Box<i32>`  
**答案：C**  
**解析：** 仅当所有成员都实现 `Copy` 时，元组才实现 `Copy`。`String`、`Vec`、`Box` 因管理堆内存不实现 `Copy`。

### 24. 填空：`BTreeMap` 与 `HashMap` 的主要区别在于 `BTreeMap` 按键的 ______ 顺序存储元素。  
**答案：** `有序`  
**解析：** `BTreeMap` 基于 B 树实现，按键排序，支持范围查询；`HashMap` 基于哈希表，平均 O(1) 访问但无序。

### 25. 编程题：实现一个函数，接收 `&[i32]` 并返回其中第二大的数（不存在则返回 `None`），要求只遍历一次。  
```rust
fn second_largest(nums: &[i32]) -> Option<i32> {
    let mut max = None;
    let mut second = None;
    for &n in nums {
        if Some(n) > max {
            second = max;
            max = Some(n);
        } else if Some(n) != max && Some(n) > second {
            second = Some(n);
        }
    }
    second
}

fn main() {
    assert_eq!(second_largest(&[3, 1, 4, 1, 5, 9]), Some(5));
    assert_eq!(second_largest(&[2, 2]), None);
}
```  
**答案：** 见上。  
**解析：** 维护两个 `Option` 跟踪最大和次大值，遇到新的最大值时把旧最大值降级为次大值。


# 第三部分：函数/方法/模块

### 26. Rust 函数参数默认是传值还是传引用？  
A. 传引用  
B. 传值（按所有权移动或 Copy）  
C. 传指针  
D. 传可变引用  
**答案：B**  
**解析：** Rust 函数参数按值传递，对于实现 `Copy` 的类型是复制，否则是所有权移动；需要引用时必须显式使用 `&` 或 `&mut`。

### 27. 填空：在 Rust 中，使用 ______ 关键字将模块中的项公开给外部使用。  
**答案：** `pub`  
**解析：** `pub` 是 Rust 的可见性修饰符，默认模块内所有项都是私有的，只有标记 `pub` 才能被外部访问。

### 28. 判断：Rust 支持函数重载（同一个作用域中同名函数不同参数）。  
**答案：** ❌错误  
**解析：** Rust 不支持传统意义上的函数重载；不同参数类型需要不同的函数名或泛型函数来实现类似能力。

### 29. 程序分析题：下面代码的输出是什么？  
```rust
fn main() {
    let s = String::from("hello");
    takes_ownership(s);
    // println!("{}", s); // 若取消注释会怎样？
}

fn takes_ownership(s: String) {
    println!("{}", s);
}
```  
**答案：** 先输出 `hello`；若取消注释 `println!("{}", s)` 则编译错误。  
**解析：** `s` 被移动到 `takes_ownership` 中，函数结束后被丢弃，主函数中 `s` 不再有效。

### 30. 简答题：解释 Rust 中 `self`、`&self`、`&mut self` 在方法参数中的区别。  
**参考答案：**  
- `self`：获取对象所有权，调用后原对象不可用。  
- `&self`：借用不可变引用，方法内只读。  
- `&mut self`：借用可变引用，方法内可修改对象。  
**解析：** 这是 Rust 方法签名中控制所有权的三种形式，决定了调用后对象是否还能继续使用以及能否修改。

### 31. 填空：Rust 模块系统通过 `mod` 声明模块，使用 ______ 关键字引入其他模块或 crate 的公开项。  
**答案：** `use`  
**解析：** `use` 将路径引入当前作用域，简化后续调用，例如 `use std::collections::HashMap;`。

### 32. 选择题：下面哪个函数签名最可能用于返回一个所有权，而不借用输入？  
A. `fn foo(s: &str) -> &str`  
B. `fn foo(s: String) -> String`  
C. `fn foo(s: &String)`  
D. `fn foo(mut s: &str) -> &str`  
**答案：B**  
**解析：** B 接收 `String` 的所有权并返回 `String` 的所有权，不涉及生命周期借用；A 和 D 涉及引用与生命周期，C 没有返回值。

### 33. 判断：在 impl 块中，关联函数（不接收 self）通过 `TypeName::func()` 调用。  
**答案：** ✅正确  
**解析：** 关联函数如 `String::from` 不作用于实例，使用类型名加双冒号调用，常用于构造函数。

### 34. 程序分析题：找出下面代码的问题并修正。  
```rust
fn append_world(s: String) -> String {
    s.push_str(" world");
    s
}
```  
**答案：** 代码实际上可以编译运行。  
**解析：** `push_str` 修改原字符串并返回 `()`，函数返回修改后的 `s`，所有权一并移出。若希望原地修改并让调用者继续使用原变量，应使用 `&mut String`。

### 35. 编程题：编写一个泛型函数 `largest<T: PartialOrd>(list: &[T]) -> &T`，返回切片中最大元素的引用。  
```rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut max = &list[0];
    for item in list.iter() {
        if item > max {
            max = item;
        }
    }
    max
}

fn main() {
    let nums = vec![3, 1, 4, 1, 5];
    assert_eq!(*largest(&nums), 5);
}
```  
**答案：** 见上。  
**解析：** 泛型约束 `T: PartialOrd` 保证元素可比较，返回引用避免所有权转移。

### 36. 填空：`crate` 是 Rust 编译的 ______，而 `package` 可以包含多个 crate。  
**答案：** `最小单位`（或基本单元）  
**解析：** 一个 `crate` 对应一个编译单元（二进制或库），一个 `package` 由 `Cargo.toml` 管理，可包含多个 crate。

### 37. 简答题：描述 `pub use` 与 `use` 的区别。  
**参考答案：**  
- `use` 只在当前模块的作用域内引入路径。  
- `pub use` 引入路径的同时对外重新导出，使外部代码可以通过当前模块访问该路径，常用于 API 结构重导出。  
**解析：** `pub use` 是 Rust 中常见的 API 封装手段，能把内部模块的项暴露到更友好的公共路径。

### 38. 程序分析题：下面代码能否编译？说明原因。  
```rust
fn main() {
    let mut s = String::from("hi");
    let r1 = &mut s;
    let r2 = &mut s;
    r1.push('!');
    r2.push('?');
}
```  
**答案：** 不能编译。  
**解析：** Rust 不允许同时存在两个活跃的可变引用 `r1` 和 `r2` 指向同一数据，这是为了防止数据竞争。应将两次修改顺序化或使用不同作用域。


# 第四部分：面向对象/类型系统

### 39. Rust 中实现多态的主要机制是？  
A. 类继承  
B. trait 对象与泛型约束  
C. 虚函数表手动管理  
D. 全局函数重载  
**答案：B**

        });
        handles.push(handle);

}

### 94. 综合应用题：实现一个简易的 LRU Cache，支持 `get` 和 `put` 操作。  
```rust
use std::collections::HashMap;
use std::collections::VecDeque;

struct LruCache<K, V> {
    capacity: usize,
    map: HashMap<K, V>,
    order: VecDeque<K>,
}

impl<K: Clone + Eq + std::hash::Hash, V> LruCache<K, V> {
    fn new(capacity: usize) -> Self {
        Self {
            capacity,
            map: HashMap::new(),
            order: VecDeque::new(),
        }
    }

    fn get(&mut self, key: &K) -> Option<&V> {
        if self.map.contains_key(key) {
            self.order.retain(|k| k != key);
            self.order.push_back(key.clone());
        }
        self.map.get(key)
    }

    fn put(&mut self, key: K, value: V) {
        if self.map.contains_key(&key) {
            self.order.retain(|k| k != &key);
        } else if self.order.len() >= self.capacity {
            if let Some(oldest) = self.order.pop_front() {
                self.map.remove(&oldest);
            }
        }
        self.order.push_back(key.clone());
        self.map.insert(key, value);
    }
}

fn main() {
    let mut cache = LruCache::new(2);
    cache.put(1, "a");
    cache.put(2, "b");
    cache.put(3, "c");
    assert_eq!(cache.get(&1), None);
    assert_eq!(cache.get(&2), Some(&"b"));
}
```  
**答案：** 见上。  
**解析：** 使用 `HashMap` 提供 O(1) 查找，`VecDeque` 维护访问顺序，超过容量时淘汰队首最久未使用项。

### 100. 编程题：实现一个函数 `group_by<T, K, F>(items: Vec<T>, key_fn: F) -> HashMap<K, Vec<T>>`，按自定义键分组。  
```rust

use std::hash::Hash;

    items: Vec<T>,
    mut key_fn: F,
) -> HashMap<K, Vec<T>> {
    let mut map: HashMap<K, Vec<T>> = HashMap::new();
    for item in items {
        let key = key_fn(&item);
        map.entry(key).or_default().push(item);
    }
    map
}

fn main() {

    let grouped = group_by(nums, |n| n % 2);
    println!("{:?}", grouped);
}
```

**解析：** 泛型 `K` 需要 `Eq + Hash` 以作为 `HashMap` 键，`or_default()` 在键不存在时插入空向量。
