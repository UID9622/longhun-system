## 🚦 三色分级规则
### 🟢 绿色 - 直接通过
处理： 直接执行，不打扰你
---
### 🟡 黄色 - 提醒确认
处理： 弹个提示，你点确认再执行
---
### 🔴 红色 - 绝对禁止
处理： 立即阻断 + 记录日志 + 触发熔断
---
## 💻 代码实现（复制就能用）
### 基础版（Shell）
```bash
# ═══════════════════════════════════════════════════════════════
# 🧬 CNSH三色审计 - 基础版
# DNA追溯码: #龙芯⚡️2026-01-24-三色审计-基础版
# 复制这段到你的 ~/.zshrc 就能用
# ═══════════════════════════════════════════════════════════════

# 三色审计函数
function 三色审计() {
    local 命令="$1"
    
    # 🔴 红色规则（绝对禁止）
    case "$命令" in
        *"rm -rf /"*|*"rm -rf /*"*|*"mkfs"*|*"dd if=/dev/zero"*)
            echo "🔴 【红色阻断】危险命令已被拦截: $命令"
            echo "$(date '+%Y-%m-%d %H:%M:%S') 🔴 阻断: $命令" >> ~/.cnsh/logs/audit.log
            return 1
            ;;
    esac
    
    # 🟡 黄色规则（需确认）
    case "$命令" in
        *"sudo"*|*"chmod"*|*"chown"*|*"curl"*|*"wget"*)
            echo "🟡 【黄色警告】敏感操作: $命令"
            echo -n "确认执行？(y/n): "
            read 确认
            if [[ "$确认" != "y" ]]; then
                echo "已取消"
                return 1
            fi
            ;;
    esac
    
    # 🟢 绿色（直接通过）
    echo "🟢 【绿色通过】"
    return 0
}

# 命令执行前自动审计
function preexec() {
    三色审计 "$1" || return 1
}
```

## 📋 快速使用
### 安装（复制粘贴）
```bash
# 1. 创建目录
mkdir -p ~/.cnsh/logs

# 2. 把上面的代码复制到 ~/.zshrc
echo '# CNSH三色审计已启用' >> ~/.zshrc

# 3. 重新加载
source ~/.zshrc

# 4. 测试
三色审计 "ls -la"  # 应该显示绿色通过
三色审计 "sudo rm -rf /"  # 应该显示红色阻断
```
### 日常使用
```bash
# 手动审计
三色审计 "你要执行的命令"

# 查看审计日志
cat ~/.cnsh/logs/audit.log

# 清理30天前的日志
find ~/.cnsh/logs -name "*.log" -mtime +30 -delete
```
