# 第一部分：C#基础语法

**题型分布：** 选择题×6、填空题×4、判断题×3、简答题×1、程序分析题×1

### 1. [难度：⭐⭐] 下列关于 `var` 关键字的说法，正确的是？
A. `var` 声明的变量是动态类型，运行时可以改变类型。
B. `var` 只能用于局部变量，编译器会根据右侧表达式推断类型。
C. `var x = null;` 是合法的 C# 语句。
D. `var` 与 `dynamic` 在语义上完全相同。

**答案：B**

**解析：** `var` 是编译期类型推断，变量类型在编译时确定且不可变。A 错误，它并非动态类型；C 错误，`null` 没有类型信息，编译器无法推断；D 错误，`dynamic` 是运行期类型绑定，绕过编译器检查。

### 2. [难度：⭐⭐] 以下哪个是 C# 中合法的字符串插值写法？
A. `string s = "x = {x}";`
B. `string s = $"x = {x}";`
C. `string s = @"x = {x}";`
D. `string s = #"x = {x}";`

**答案：B**

**解析：** `$"..."` 是字符串插值语法，花括号内可嵌入表达式。A 是普通字符串，花括号原样输出；C 是逐字字符串，不处理转义也不插值；D 不是合法的字符串前缀。

### 3. [难度：⭐⭐] 关于 `switch` 表达式（switch expression）和模式匹配，以下说法正确的是？
A. `switch` 表达式必须使用 `break` 结束每个分支。
B. `switch` 表达式可以使用 `_` 作为默认分支。
C. `switch` 表达式只能返回整数类型。
D. `switch` 表达式不支持元组模式。

**答案：B**

**解析：** `switch` 表达式是 C# 8+ 引入的表达式级 switch，使用 `=>` 连接分支，`_` 表示默认分支。A 错误，不需要 `break`；C 错误，可返回任意类型；D 错误，支持元组、属性、关系等多种模式。

### 4. [难度：⭐⭐] 以下代码的输出是？
```csharp
int a = 5;
int b = a++ + ++a;
Console.WriteLine(b);
```
A. 10
B. 11
C. 12
D. 13

**答案：C**

**解析：** `a++` 先返回 5，然后 `a` 变为 6；`++a` 先将 `a` 变为 7，再返回 7。因此 `b = 5 + 7 = 12`。注意 `a++` 与 `++a` 的副作用发生时机不同。

### 5. [难度：⭐⭐] 在 C# 中，`const` 与 `readonly` 的主要区别是？
A. `const` 在运行期解析，`readonly` 在编译期解析。
B. `const` 只能修饰值类型，`readonly` 只能修饰引用类型。
C. `const` 是编译期常量，其值直接嵌入调用处；`readonly` 可在构造器中赋值，运行期确定。
D. 两者没有任何区别。

**答案：C**

**解析：** `const` 必须在声明时初始化且为编译期可计算的表达式，值会嵌入 IL。`readonly` 字段可在声明时或实例/静态构造器中赋值，运行期才确定。A、B、D 均错误。

### 6. [难度：⭐⭐] 关于 `default` 关键字，下列代码中 `default(int)` 与 `default(string)` 的值分别是？
A. `0` 与 `""`
B. `null` 与 `null`
C. `0` 与 `null`
D. `false` 与 `null`

**答案：C**

**解析：** `default(T)` 返回类型 `T` 的默认值。值类型 `int` 的默认值为 `0`，引用类型 `string` 的默认值为 `null`。空字符串 `""` 不是默认值。

### 7. [难度：⭐] C# 中用于声明一个不可变局部变量的关键字是 ________。

**答案：** `readonly`

**解析：** 在 C# 7.3+ 中，`readonly` 可用于修饰局部变量（通常与 `ref`/`ref readonly` 一起使用）或字段，表示不可重新赋值。对于局部变量直接不可变，更常见的是使用 `const`（编译期常量）或 `readonly` 字段。

### 8. [难度：⭐] 使用 `?.` 运算符可以在访问成员前检查对象是否为 ________。

**答案：** `null`

**解析：** `?.` 是空条件运算符（null-conditional operator），当左侧对象为 `null` 时整个表达式返回 `null`，不会抛出 `NullReferenceException`。

### 9. [难度：⭐] 在 C# 中，`using` 语句用于确保实现了 ________ 接口的对象被正确释放。

**答案：** `IDisposable`

**解析：** `using` 语句在离开作用域时自动调用对象的 `Dispose()` 方法，适用于实现 `IDisposable` 的资源，如文件流、数据库连接等。

### 10. [难度：⭐] 要将一个字符串转换为整数，可以使用 `int` 结构体的 ________ 方法或 `int.Parse`。

**答案：** `TryParse`

**解析：** `int.TryParse(string, out int result)` 在转换失败时返回 `false` 而不抛出异常，比 `int.Parse` 更安全。

### 11. [难度：⭐] `int? x = null;` 中的 `?` 表示 `x` 是可空值类型。

**答案：** ✅正确

**解析：** `int?` 是 `Nullable<int>` 的简写，允许值类型存储 `null`。该语法正确。

### 12. [难度：⭐] 在 C# 中，所有类型都直接或间接继承自 `System.Type`。

**答案：** ❌错误

**解析：** 所有类型都继承自 `System.Object`（或 `object`），`System.Type` 是反射中用于表示类型元数据的类，不是根基类。

### 13. [难度：⭐] `break` 语句只能用于 `switch` 语句中。

**答案：** ❌错误

**解析：** `break` 可用于 `switch`、`for`、`foreach`、`while`、`do-while` 等循环或分支语句中，用于跳出当前结构。

### 14. [难度：⭐⭐] 简述 C# 中 `is` 与 `as` 运算符的区别及适用场景。

**参考答案：**
- `is` 用于检查对象是否是某个类型，返回 `bool`，C# 7+ 支持模式匹配并赋值，如 `if (obj is string s)`。
- `as` 用于将对象转换为指定引用类型或可空值类型，转换失败时返回 `null`，不会抛出异常。
- 适用场景：需要安全类型判断时用 `is`；需要安全向下转换引用类型时用 `as`，避免 `InvalidCastException`。

**解析：** `is` 重在“判断”，`as` 重在“转换”。对引用类型优先使用 `as`，因为它更高效且安全；对值类型应使用 `(T)obj` 或 `is T` 后强制转换。

### 15. [难度：⭐⭐] 阅读以下代码，写出输出结果。
```csharp
string s1 = "hello";
string s2 = s1;
s1 += " world";
Console.WriteLine(s2);
```

**答案：** `hello`

**解析：** `string` 在 C# 中是不可变的引用类型。`s2 = s1` 让 `s2` 引用与 `s1` 相同的字符串对象；`s1 += " world"` 会创建新的字符串对象并让 `s1` 指向它，`s2` 仍指向原来的 `"hello"`。因此输出 `hello`。

### 16. [难度：⭐⭐] 关于 `List<T>` 与 `Dictionary<TKey, TValue>`，下列说法正确的是？
A. `List<T>` 基于哈希表实现，查找元素时间复杂度为 O(1)。
B. `Dictionary<TKey, TValue>` 基于动态数组实现，按键查找为 O(n)。
C. `List<T>` 按索引访问为 O(1)，但查找值为 O(n)。
D. `Dictionary<TKey, TValue>` 允许存储重复的键。

**答案：C**

**解析：** `List<T>` 基于动态数组，索引访问 O(1)，值查找 O(n)。A 错误；`Dictionary` 基于哈希表，按键查找平均 O(1)，不允许重复键，B、D 错误。

### 17. [难度：⭐⭐] 在 C# 中，`HashSet<T>` 最适合用于以下哪种场景？
A. 需要按键快速查找对应值。
B. 需要存储有序且不重复的元素。
C. 需要判断元素是否存在的集合，且元素唯一。
D. 需要频繁按索引插入和删除元素。

**答案：C**

**解析：** `HashSet<T>` 是无序、不重复的哈希集合，主要用于去重和存在性判断。A 适合 `Dictionary`；B 适合 `SortedSet`；D 适合 `List` 或链表结构。

### 18. [难度：⭐⭐] 关于 `Queue<T>` 与 `Stack<T>`，下列说法正确的是？
A. `Queue<T>` 是后进先出（LIFO），`Stack<T>` 是先进先出（FIFO）。
B. `Queue<T>` 的 `Enqueue` 用于出队，`Dequeue` 用于入队。
C. `Stack<T>` 的 `Pop` 移除并返回栈顶元素。
D. 两者都继承自 `List<T>`。

**答案：C**

**解析：** `Queue<T>` 是 FIFO，`Stack<T>` 是 LIFO；`Enqueue` 入队，`Dequeue` 出队；两者都独立实现，不继承 `List<T>`。只有 C 正确。

### 19. [难度：⭐⭐⭐] 以下代码运行后，`count` 的值是？
```csharp
var list = new List<int> { 1, 2, 2, 3, 3, 3 };
var set = new HashSet<int>(list);
int count = set.Count;
```
A. 6
B. 3
C. 1
D. 0

**答案：B**

**解析：** `HashSet<int>` 会自动去重。原列表有 1、2、3 三个不同值，因此 `set.Count = 3`。

### 20. [难度：⭐⭐⭐] 关于 `Span<T>` 与 `Memory<T>`，下列说法正确的是？
A. `Span<T>` 只能用于托管堆内存。
B. `Memory<T>` 可以在异步方法中安全使用。
C. `Span<T>` 是引用结构，可存储于类字段中。
D. `Memory<T>` 不支持切片操作。

**答案：B**

**解析：** `Span<T>` 是 `ref struct`，只能存在于栈上，不能作为类字段或异步状态机字段。`Memory<T>` 可跨异步边界使用，也支持 `Slice`/`Span` 转换。因此 B 正确，A、C、D 错误。

### 21. [难度：⭐] `Dictionary<TKey, TValue>` 使用 ________ 结构存储键值对。

**答案：** `KeyValuePair<TKey, TValue>`

**解析：** 遍历 `Dictionary<TKey, TValue>` 时，每个元素是 `KeyValuePair<TKey, TValue>`，包含 `Key` 和 `Value` 两个属性。

### 22. [难度：⭐] `Stack<T>` 中用于查看栈顶元素但不移除的方法是 ________。

**答案：** `Peek`

**解析：** `Peek()` 返回栈顶元素但不移除，`Pop()` 返回并移除栈顶元素，`Push(T)` 将元素压入栈顶。

### 23. [难度：⭐⭐] `SortedDictionary<TKey, TValue>` 内部按键的 ________ 顺序维护元素。

**答案：** 排序（或自然/升序）

**解析：** `SortedDictionary` 基于红黑树实现，按键的默认比较器或自定义 `IComparer<TKey>` 排序，插入、删除、查找均为 O(log n)。

### 24. [难度：⭐] `Array.Sort` 方法默认对数组进行升序排序。

**答案：** ✅正确

**解析：** `Array.Sort` 使用默认比较器（或元素实现的 `IComparable`）按升序排列数组元素。如需降序，可传入自定义比较器或调用 `Reverse()`。

### 25. [难度：⭐] `LinkedList<T>` 不支持在任意节点处进行 O(1) 的插入和删除。

**答案：** ❌错误

**解析：** `LinkedList<T>` 提供 `AddAfter`、`AddBefore`、`Remove` 等方法，只要持有 `LinkedListNode<T>` 引用，插入和删除都是 O(1)。

### 26. [难度：⭐⭐] 简述 `IEnumerable<T>` 与 `IEnumerator<T>` 的区别。

**参考答案：**
- `IEnumerable<T>` 表示一个可枚举集合，提供 `GetEnumerator()` 方法返回迭代器。
- `IEnumerator<T>` 是迭代器本身，负责维护当前遍历状态，包含 `Current`、`MoveNext()`、`Reset()`（通常不推荐）。
- `foreach` 循环会调用 `GetEnumerator()` 获取迭代器，然后通过 `MoveNext()`/`Current` 遍历。

**解析：** 一个集合实现 `IEnumerable<T>` 即可被 `foreach` 遍历；`IEnumerator<T>` 负责实际的遍历状态机。LINQ 的延迟执行也依赖于 `IEnumerable<T>` 的惰性求值。

### 27. [难度：⭐⭐] 阅读以下代码，写出输出结果。
```csharp
var dict = new Dictionary<string, int>
{
    ["a"] = 1,
    ["b"] = 2
};
dict["a"] = 10;
if (!dict.ContainsKey("c"))
    dict["c"] = 3;
Console.WriteLine(dict.Count);
```

**答案：** `3`

**解析：** 字典初始有两个键。`dict["a"] = 10` 修改已有键的值，不增加数量。`ContainsKey("c")` 为 `false`，因此新增 `"c"`，最终 `Count` 为 3。

# 第三部分：函数/方法/模块

**题型分布：** 选择题×2、填空题×2、判断题×2、简答题×1、编程题×3

### 28. [难度：⭐⭐] 关于 C# 方法参数修饰符，下列说法错误的是？
A. `ref` 参数要求调用前必须初始化。
B. `out` 参数在方法返回前必须赋值。
C. `in` 参数允许在方法内部修改参数值。
D. `params` 允许传入可变数量的同类型参数。

**答案：C**

**解析：** `in` 参数按引用传递但只读，方法内部不能修改。A、B、D 描述均正确。

### 29. [难度：⭐⭐⭐] 以下代码的输出是？
```csharp
void Modify(ref int x) => x *= 2;
int a = 5;
Modify(ref a);
Console.WriteLine(a);
```
A. 5
B. 10
C. 编译错误
D. 运行时异常

**答案：B**

**解析：** `ref` 按引用传递，`Modify` 方法内修改会反映到外部变量。`a` 初始为 5，调用后变为 10。

### 30. [难度：⭐] 在 C# 中，使用 ________ 关键字可以定义一个扩展方法。

**答案：** `this`

**解析：** 扩展方法的第一个参数使用 `this` 修饰，如 `public static void Foo(this string s)`。扩展方法必须定义在静态类中。

### 31. [难度：⭐] 局部函数（local function）只能在 ________ 内部声明。

**答案：** 方法（或属性/构造器/代码块）

**解析：** 局部函数是 C# 7 引入的特性，可以在另一个方法、属性访问器、构造器等成员内部声明，具有闭包捕获能力。

### 32. [难度：⭐] C# 支持方法重载（overload），即同一个类中可以有多个同名但参数列表不同的方法。

**答案：** ✅正确

**解析：** 方法重载通过参数数量、类型或顺序区分，与返回类型无关。

### 33. [难度：⭐] `out` 参数在调用方法之前不需要初始化。

**答案：** ✅正确

**解析：** `out` 参数按引用传递，方法内部必须赋值，调用前可以不初始化。与 `ref` 不同，`ref` 要求调用前已初始化。

### 34. [难度：⭐⭐] 简述 C# 中 `static` 方法与普通实例方法的区别。

**参考答案：**
- `static` 方法属于类型本身，不依赖实例，不能访问实例成员（除非通过对象引用）。
- 实例方法属于对象实例，可以访问该实例的实例字段、属性和其他实例方法。
- `static` 方法在类型加载时即可调用，不需要 `new` 创建对象。

**解析：** 静态成员在内存中只有一份，由所有实例共享；实例成员每个对象独立一份。静态方法常用于工具类、工厂方法等。

### 35. [难度：⭐⭐] 编程题：编写一个扩展方法 `IsPalindrome`，判断一个字符串是否为回文（忽略大小写和非字母数字字符）。

**参考答案：**
```csharp
using System;
using System.Linq;

public static class StringExtensions
{
    public static bool IsPalindrome(this string input)
    {
        if (string.IsNullOrEmpty(input)) return true;
        var filtered = new string(input.Where(char.IsLetterOrDigit).ToArray());
        var lower = filtered.ToLowerInvariant();
        return lower.SequenceEqual(lower.Reverse());
    }
}

// 使用示例
class Program
{
    static void Main()
    {
        Console.WriteLine("A man, a plan, a canal: Panama".IsPalindrome()); // True
        Console.WriteLine("hello".IsPalindrome()); // False
    }
}
```

**解析：** 扩展方法定义在静态类中，第一个参数加 `this`。本例先过滤掉非字母数字字符，再转小写，最后正序与倒序比较。

### 37. [难度：⭐⭐⭐] 编程题：编写一个递归方法计算第 n 个斐波那契数，并附加记忆化优化。

**参考答案：**
```csharp
using System;
using System.Collections.Generic;

class Program
{
    private static Dictionary<int, long> memo = new Dictionary<int, long>();

    static long Fib(int n)
    {
        if (n <= 1) return n;
        if (memo.TryGetValue(n, out var value)) return value;
        memo[n] = Fib(n - 1) + Fib(n - 2);
        return memo[n];
    }

    static void Main()
    {
        Console.WriteLine(Fib(10)); // 55
        Console.WriteLine(Fib(50)); // 12586269025
    }
}
```

**解析：** 递归直接计算斐波那契会有大量重复子问题，时间复杂度 O(2^n)。使用 `Dictionary` 记忆化后降为 O(n)，空间 O(n)。也可使用迭代法进一步优化空间。

```csharp
        }
    }
}

class Program
{
    static void Main()
    {
        var thermostat = new Thermostat();
        thermostat.TemperatureChanged += (s, t) =>
            Console.WriteLine($"温度变化为：{t}");
        thermostat.Temperature = 20.5;
        thermostat.Temperature = 21.0;
    }
}
```

**解析：** `EventHandler<double>` 是泛型事件委托，订阅者通过 `+=` 注册。使用 `?.Invoke` 避免无订阅者时触发空引用异常。

### 89. [难度：⭐⭐⭐] 综合应用题：设计一个 C# 类 `BankAccount`，支持存款、取款和查询余额，要求线程安全。

**参考答案：**
```csharp
using System;

public class BankAccount
{
    private readonly object _lock = new object();
    private decimal _balance;

    public decimal Balance
    {
        get
        {
            lock (_lock) return _balance;
        }
    }

    public void Deposit(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("存款金额必须大于零");
        lock (_lock)
        {
            _balance += amount;
        }
    }

    public bool Withdraw(decimal amount)
    {
        if (amount <= 0) throw new ArgumentException("取款金额必须大于零");
        lock (_lock)
        {
            if (_balance < amount) return false;
            _balance -= amount;
            return true;
        }
    }
}
```

**解析：** 使用 `lock` 语句确保对余额的读写互斥，避免并发导致的竞态条件。更现代的实现可使用 `Interlocked` 或 `SemaphoreSlim`，但对于复杂业务逻辑 `lock` 更直观。

```csharp
using Microsoft.AspNetCore.Http;
using System.Diagnostics;
using System.Threading.Tasks;

public class RequestTimingMiddleware
{
    private readonly RequestDelegate _next;

    public RequestTimingMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        var stopwatch = Stopwatch.StartNew();
        try
        {
            await _next(context);
        }
        finally
        {
            stopwatch.Stop();
            var statusCode = context.Response.StatusCode;
            // 记录日志
            Console.WriteLine($"{context.Request.Path} - {statusCode} - {stopwatch.ElapsedMilliseconds}ms");
        }
    }
}
```

**解析：** 自定义中间件接收 `RequestDelegate`，在调用 `next` 前后记录时间。`finally` 确保即使发生异常也会记录耗时。

### 100. [难度：⭐⭐⭐⭐] 系统设计题：设计一个基于 EF Core 的仓储模式（Repository Pattern），并说明其优缺点。

**参考答案：**
- 定义 `IRepository<T>` 接口，包含 `GetByIdAsync`、`GetAllAsync`、`AddAsync`、`Update`、`Delete`、`SaveChangesAsync` 等方法。
- 实现 `EfRepository<T>`，注入 `DbContext`。
- 在 ASP.NET Core 中注册 `IRepository<T>` 为 Scoped 服务。
- 优点：解耦业务逻辑与数据访问、便于单元测试、统一数据访问语义。
- 缺点：对于简单 CRUD 可能增加抽象层，复杂查询时 `IQueryable` 泄露问题需谨慎设计。

**解析：** 仓储模式适合大中型项目。可与工作单元（Unit of Work）模式结合，多个仓储共享一个 `DbContext` 统一提交事务。

### 101. [难度：⭐⭐⭐⭐] 系统设计题：设计一个基于发布-订阅模式的消息总线，支持多订阅者和异步处理。

**解析：** 消息总线降低发布者与订阅者耦合。生产环境可考虑 MediatR、MassTransit 或 RabbitMQ 等成熟方案。

### 104. [难度：⭐⭐⭐⭐⭐] 系统设计题：设计一个实时数据流处理管道，使用 `System.IO.Pipelines` 和 `Channel<T>`，说明背压处理策略。

**参考答案：**
- 使用 `PipeReader`/`PipeWriter` 高效读取网络或文件字节流，减少内存分配。
- 解析后的数据放入 `Channel<T>` 进行生产者-消费者解耦。
- `Channel<T>` 可配置有界容量，当缓冲区满时生产者等待，实现背压（backpressure）。
- 消费者端使用 `await foreach` 异步读取并处理数据。
- 背压策略：有界通道阻塞/丢弃旧数据/降级采样；结合 `CancellationToken` 优雅停止。

**解析：** `System.IO.Pipelines` 提供高性能内存管理，`Channel<T>` 提供线程安全的数据交换。背压防止消费者跟不上生产者时内存无限增长。

### 105. [难度：⭐⭐⭐⭐] 编程题：实现一个简单的表达式求值器，支持加减乘除和括号，输入字符串如 `"3+(2*4)-5/2"`。

**参考答案：**
```csharp
using System;
using System.Data;

class Program
{
    static double Evaluate(string expression)
    {
        // 使用 DataTable.Compute 进行快速表达式求值
        var result = new DataTable().Compute(expression, null);
        return Convert.ToDouble(result);
    }

    static void Main()
    {
        Console.WriteLine(Evaluate("3+(2*4)-5/2")); // 9.5
    }
}
```

**解析：** `DataTable.Compute` 是 .NET 内置的表达式计算引擎，支持四则运算和括号。对于面试场景，也可要求手写栈实现（调度场算法/Shunting-yard），但本例展示标准库的高效用法。
