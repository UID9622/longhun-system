# 七、路由優先級（衝突解決）
```javascript
// 優先級從高到低
1. 🔴 熔斷觸發 → 無條件接管·所有路由暫停
2. 🔴 確認碼驗證 → P0級權限提升
3. 🟡 指令觸發（/前綴）→ 確定性路由
4. 🟡 語義觸發（任務型）→ 執行層路由
5. 🟢 語義觸發（情感型）→ 宝宝默認路由
6. 🟢 無法識別 → P00宝宝兜底·不猜測·直接問清楚

// 衝突規則
同時觸發多個路由時：高優先級覆蓋低優先級
同優先級衝突時：情感型讓位給任務型
任何路由觸發熔斷時：全部路由暫停
```
