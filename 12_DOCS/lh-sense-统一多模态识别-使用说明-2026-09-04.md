## 一、为什么做这个

老大指令：「识别图片声音视频的功能早就有，怎么没集成在系统里？重新搜索，全部用起来。」

摸底结论：**底层引擎一直躺在机器上，从未接到统一入口**——
- `moondream`（视觉模型）在 ollama 已有 → 没人调用
- `whisper` / `faster-whisper` 已装 → 没接入 CLI
- `tesseract` OCR 已装 → 没接入 CLI
- `ffmpeg`/`ffprobe` 已装 → 没接入 CLI
- `lh_vision_parser.py`/`lh_audio_parser.py`/`lh_asr_api.py`/`lh_ocr_api.py` 是**接口壳/占位符**，依赖云端 key 或未接通

**一次装配，四通道全开。全本地推理，数据不出机。**

## 二、能力一览（已实测）

| 通道 | 底层引擎 | 实测结果 |
|:---|:---|:---|
| 🖼️ 图片识别 | moondream VLM (ollama·1.7GB) + tesseract OCR | 图表/截图描述 + 中文OCR文字提取 ✅ |
| 🎙️ 语音转写 | faster-whisper small (464M·本地缓存) | 46.5s 中文 8.5s 转完·分段时间戳 ✅ |
| 🎬 视频分析 | ffmpeg 抽帧 → moondream 逐帧 + 音轨 → whisper | 帧描述 + TTS 语音转写 ✅ |
| 📂 目录批量 | --scan | 自动遍历目录内全部媒体 ✅ |

## 三、用法

```
lh sense <文件>                     # 自动路由：图片/音频/视频
lh sense <文件> --prompt "图中文字？"  # 自定义提问(VLM)
lh sense <文件> --json               # 结构化 JSON 输出（脚本/管道用）
lh sense <文件> --no-ocr             # 跳过 OCR（只认图不读字）
lh sense <视频> --frames 6           # 视频抽帧数（默认4）
lh sense <目录> --scan               # 批量扫描目录内媒体
```

等价直调：`python3 bin/lh_sense.py <文件>`

## 四、技术要点（焊点）

1. **全本地·零云端**：moondream 走 `127.0.0.1:11434` ollama API；whisper 模型缓存在 `~/.cache/longhun-whisper/`（已复制 464M small）；tesseract/ffmpeg 走系统 PATH。数据不出机，符合 P0 主权。
2. **视频管线**：ffprobe 取时长 → 均匀抽帧（缩放 640px 省算力）→ 逐帧 moondream → ffmpeg 提 16kHz 单声道音轨 → whisper 转写。图文声三通道 JSON 合一。
3. **前置**：ollama 需运行（`brew services start ollama`）；whisper small 首跑自动下载（模型已预置缓存即秒起）。
4. **局限诚实标注**：moondream 为 1.7GB 小视觉模型，描述偏简单（实测柱状图仅输出基本结构）；需深度图像理解时叠加 OCR 文字提取补强。中/英 OCR 需 tesseract 语言包 `chi_sim+eng`。
5. 经 `lh` 网关（P05 上帝之眼）自动走人格网关+审计回流+复盘钩子，`lh doc-sync` 已同步 372 命令索引。
