> 文化主权命令行接口 · 对外分发标准

## 1. 概述

`longhun-cli` 是龍魂系统的**对外分发弹头**：零依赖、可 `pip install`，
安装后即可使用 `lh` 命令。设 `LONGHUN_ROOT` 指向龍魂源码树时，自动接入
系统内全量逻辑（CIL 终端、健康自检、文档同步等）。

**双态设计**：

| 状态 | 触发条件 | 可用能力 |
|---|---|---|
| 外部态 | 未设 `LONGHUN_ROOT` 且无源码树 | `version` / `health`(基础自检) / `flow` |
| 系统态 | `LONGHUN_ROOT` 指向龍魂源码树（如 `~/longhun-system`） | 上述全部 + `health`(全量) / `cil` / `doc-sync` |

## 2. 安装

```bash
pip install longhun-cli
# 或本地安装
pip install dist/longhun_cli-4.0.0-py3-none-any.whl
```

## 3. CLI 调用协议

所有命令支持 `--json`，输出**标准 Node JSON**（UTF-8，可程序解析）。

| 命令 | 说明 | JSON 字段 |
|---|---|---|
| `lh version` | 版本信息 | `service` `version` `protocol` |
| `lh health [--json]` | 健康自检（外部态基础 / 系统态全量） | 系统态: `tool` `checks[]` |
| `lh flow "<文本>" [--json]` | 流场计算（数字根/五行/八卦） | 见 §4 |
| `lh logs [--tail 100] [--json]` | 外部调用记录（归一审计·只记非本机） | §7 |
| `lh assert <文本> [--json]` | 归一断言（检测龍魂 DNA 指纹） | §7 |
| `lh trace <node_id> [--json]` | 反向追溯（node_id → 创建时间/数字根/五行/审计） | §7 |
| `lh cil [--json]` | CIL 交互终端（需系统态） | 透传系统内行为 |
| `lh doc-sync [--json]` | 文档同步（需系统态） | 透传系统内行为 |

系统态命令行为与系统内 `lh` 完全一致（透传），外部态 `health`/`flow`/`version`
为薄壳本地实现，保证"装了就能用、输出必可解析"。

## 4. Node JSON 标准结构

`lh flow "<文本>" --json` 返回文化主权节点标准结构：

```json
{
  "node_id": "FLOW-9622-47720A8E",
  "digital_root": 5,
  "element": "土",
  "gua": "巽",
  "audit": "🟢",
  "action": "stay",
  "timestamp": "2026-09-01T05:54:25+0800"
}
```

| 字段 | 含义 | 口径 |
|---|---|---|
| `node_id` | 节点标识 | `FLOW-9622-<SHA256前8位>` |
| `digital_root` | 数字根 1-9 | 洛书369 · 字符码点和迭代至个位 |
| `element` | 五行 | 水1/火2/木3/金4/土5（6-9循环） |
| `gua` | 八卦 | 乾1 兑2 离3 震4 巽5 坎6 艮7 坤8 离9 |
| `audit` | 审计色 | 生数(1-5)→🟢 · 成数(6-9)→🟡 |
| `action` | 行为建议 | enter(生数1-4) / stay(成数5-9) |
| `timestamp` | 时间戳 | ISO 8601 含时区 |

> 深度流场引擎（细粒度推演）需系统态接入 `bin/lh_flow_engine.py`。

## 7. 归一审计（v1.1 焊死 · 2026-09-01）

> **声明：调用龍魂 API = 接受审计 = 同意溯源。**
> 任何不带龍魂协议的「剽窃」行为，将在溯源时被识别为「未归一」。

### 7.1 归一回流（HTTP 网关 `lh api`）

所有响应（含 `/health` 与 `/v1/lh`）自动携带三重 DNA 指纹：

| 位置 | 内容 | 样例 |
|---|---|---|
| 响应头 `X-Longhun-Trace` | 节点标识 | `FLOW-9622-47720A8E` |
| 响应头 `X-Longhun-DigitalRoot` | 数字根 | `5` |
| 响应头 `X-Longhun-Audit` | 审计色（ASCII·HTTP 头限 latin-1） | `GREEN` / `YELLOW` / `RED` |
| body 末尾 DNA 行 | 完整溯源指纹（审计色保留 emoji） | `# 龍魂DNA: FLOW-9622-47720A8E\|DR:5\|五行:土\|审计:🟢\|创建:2026-09-01T05:54:25+0800` |

> body 末尾 DNA 行位于 JSON 之后（换行分隔）；程序解析时先 `split('\n', 1)[0]` 取纯 JSON。

### 7.2 外部调用审计

- 网关对外开放（`lh api --host 0.0.0.0`）时，**非本机调用**（非 127.0.0.1）自动写入
  `~/.longhun/logs/external_calls.log`（append-only）：时间/IP/命令/返回值摘要/耗时/审计色。
- 全部调用写入节点注册表 `~/.longhun/nodes_registry.jsonl`（上限 1 万条），供反向追溯。

### 7.3 归一判定

```bash
lh assert "<任意文本>"   # 含龍魂DNA指纹 → "已归一 - 属龍魂系统"(🟢)
                        # 不含指纹     → "未归一 - 建议接入"(🟡)
lh trace FLOW-9622-47720A8E   # 反向追溯：创建时间/数字根/五行/审计/原始输入
lh logs --tail 100            # 查看外部调用记录
```

指纹口径：`# 龍魂DNA` / `#龍芯⚡️` / `<前缀>-9622-<sha8>` / `digital_root` / `五行` / `审计色`。
