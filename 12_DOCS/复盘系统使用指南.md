## 一、这是什么

每次执行 lh 命令后，系统自动生成一份「执行复盘」：思维导图、决策与状态图、执行链路图、时间线（全部 Mermaid 图，GitHub/GitLab/Notion/本地均可渲染），盖上 DNA 追溯码 + 天干地支时间戳，记录系统快照（图谱哈希/铭碑根/耻辱墙计数）与代码锚点。

**核心价值：做完 → 复盘 → 可查 → 可改 → 可追。** 复盘本身也是知识库的一部分。

## 二、自动触发规则（默认）

| 情形 | 行为 |
|:---|:---|
| 复杂命令（白名单 generate_for：topo/bench/publish/agent/dh/brain/model/github/codeql/fork/evolve/memory/military/skill/search/mcp/cnsh/fast-index） | 无论多快，**必复盘** |
| 执行失败（rc≠0） | **必复盘** |
| 其他命令且成功且 < min_duration_ms(800) | 静默跳过（节能） |
| 简单命令（skip_for：health/status/stats/prstate/list/view/help/recap） | 永不生成 |

自动复盘为**异步后台进程**，不阻塞主命令。复盘生成后终端静默；手动查看用 `lh recap view`。

## 三、命令速查

| 命令 | 说明 |
|:---|:---|
| `lh recap view [id]` | 查看复盘（默认最近一条），含三图+一句话总结 |
| `lh recap list [--limit N]` | 复盘清单 |
| `lh recap generate --cmd topo --rc 0 [--dur 2340] [--nodes a,b]` | 手动生成 |
| `lh recap locate <关键词>` | 定位：复盘文档路径 + 代码锚点（实时 rg 文件:行）+ 上下文 |
| `lh recap codemap <id>` | 该次执行的代码调用链路图（引擎 import 链·Mermaid） |
| `lh recap snapshot <id>` | 执行后系统快照（topo 根哈希/铭碑根/耻辱墙/复盘数） |
| `lh recap diff <id1> <id2>` | 两次执行系统状态差异（只列差异字段） |
| `lh recap rollback <id> --dry-run` | 回滚预览（漂移检测+影响清单·不实际回滚） |
| `lh recap export <id> --format html\|md\|json` | 导出：HTML 可折叠+搜索高亮（交互页）/md/json 程序化读取 |
| `lh recap search <关键词>` | 全库搜索·相关度排序（CJK 分词） |
| `lh recap timeline [--from][--to][--mermaid]` | 执行时间线（默认近 7 天） |
| `lh recap stats` | 统计：总数/成功率/平均耗时/最常节点 |
| `lh recap diagnose <id>` | AI 规则诊断：瓶颈(>2x均值)/异常/风险决策/下一步建议 |
| `lh recap suggest <描述>` | 基于历史复盘推荐相似执行模式 |
| `lh recap template list\|show <名>\|use <名>` | 模板系统（自定义放 `~/.longhun/recap/templates/<名>.md`） |
| `lh recap config [--set k=v]` | 查看/修改配置（enabled/auto_always/min_duration_ms/generate_for/skip_for/keep_days/template/html_on_generate/brain_save/qr_on_generate） |
| `lh recap protect <id>` / `unprotect` | 永久保留（清理豁免） |
| `lh recap archive [--dry-run]` | 季度归档（`archive/2026-QN/`）+ 过期清理（keep_days） |
| `lh recap qr <id>` | 生成二维码（含 DNA 可扫码查看） |
| `lh recap share <id> [--port N]` | 一键分享：本地 HTML 短链 + 二维码（停止: `lsof -nP -i :PORT \| grep LISTEN \| awk '{print $2}' \| xargs kill`） |
| `lh recap anchor <cmd> <file[:line]>` | 手动登记代码锚点 |

## 四、模板变量（自定义模板可用）

`{{EXEC_ID}} {{DNA}} {{TIMESTAMP}} {{COLOR}} {{TEMPLATE}} {{MODE}} {{COMMAND}} {{ARGS}} {{DURATION}} {{RC}} {{SUMMARY}} {{ROOT_CMD}} {{ARGS_TXT}} {{NODES_MM}} {{DECISIONS_SD}} {{CHAIN_FL}} {{TIMELINE_TL}} {{SNAP_TOPO}} {{SNAP_MEMORIAL}} {{SNAP_SHAME}} {{SNAP_RECAP_COUNT}} {{CODE_ANCHORS}} {{DIAGNOSE}} {{DECISIONS}} {{OUTPUT}}`

若自定义模板缺失核心图，引擎自动在文末补全三图，保证复盘永远有图。

## 五、数据布局

```
~/.longhun/recap/
  config.json            触发/保留/模板配置
  index.json             复盘索引（去重·搜索·统计数据源）
  recaps/<id>.md         复盘文档（三图+DNA+锚点）
  recaps/<id>.json       结构化数据（AI 程序化读取）
  recaps/<id>.html       可交互导出（export 生成）
  templates/             模板（default/minimal/自定义）
  archive/YYYY-QN/       季度归档（ARCHIVE-SUMMARY.md 摘要）
  qr/<id>.png            二维码
  protect.json           永久保留清单
  kg_nodes.jsonl         知识图谱桥接节点（每复盘一行 JSON）
```

## 六、代码锚定与定位

- 复盘「执行链路图」中每个节点标注 `文件`（内建锚点映射 CMD_ANCHOR，如 topo→lh_topo.py）
- `lh recap locate 关键词`：先查复盘库命中，再实时 rg `08_BIN/` 返回 `文件:行` 与上下文
- `lh recap codemap <id>`：从 lh.py 触发 → 引擎 → 其 import 链，生成调用链路 Mermaid
- AI 可直接 `lh recap locate` 定位问题代码

## 七、快照与回滚

快照字段：`topo_root`（`~/.longhun/topo/topo_index.json` 根哈希）、`memorial_root`（铭碑 Merkle）、`shame_count`（耻辱墙计数）、`recap_count`。
`diff` 只显示差异；`rollback --dry-run` 输出漂移清单与建议动作——遵循龍魂「不删除只冻结」原则，回滚以复核/校正替代物理回滚。

## 八、知识库集成

复盘完成后自动：
1. 追加节点到 `kg_nodes.jsonl`（type=recap·含 DNA/命令/rc）
2. 静默存入超级大脑记忆（`lh brain save --source recap`，可 `lh brain search recap` 召回）

耻辱墙检查：复盘决策命中风险词（临时/绕过/风险/降级等）→ 诊断报告标 🟡「已登记供人工复核」；**终审权保留在 `lh judge`**（自动上墙会误伤，人工终审判定）。

## 九、验证样例

```bash
lh topo verify              # 自动复盘（后台）
lh recap view               # 最近复盘 · 三图+一句话总结
lh recap locate "决策"      # 定位到决策节点与代码行
lh recap diagnose <id>      # 诊断报告
lh recap export <id> --format html   # 可交互页
lh recap timeline           # 本周时间线
lh recap stats              # 统计
```

## 十、注意事项

- Mermaid 图在 GitHub/Notion/GitLab 原生渲染；本地 HTML 用 CDN mermaid（需联网，离线时图显示为源码文本）
- 复盘数据全本地，主权归用户；不上传任何平台
- 删除复盘 = `lh recap archive --dry-run` 预览后真归档；`protect` 可豁免
- 二维码依赖 `qrcode` 库（已装）；缺库时自动降级为文本链接
