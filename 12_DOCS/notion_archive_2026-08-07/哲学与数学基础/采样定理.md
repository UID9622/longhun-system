## 1. 奈奎斯特-香农采样定理

$$
f_s \ge 2 \cdot f_{max}
$$

采样频率必须至少是信号最高频率的2倍，才能无失真地重建原始信号。

## 5. 批次内的采样策略

```python
def stratified_wuxing_sample(data, batch_size=32):
    """五行分层采样·确保每批覆盖五元素"""
    samples_per_element = batch_size // 5
    batch = []
    for element in ['金','木','水','火','土']:
        batch.extend(random.sample(data[element], samples_per_element))
    batch.extend(random.sample(data['all'], batch_size - len(batch)))
    return batch
```

## 6. 知识蒸馏中的温度采样

$$
q_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

- T=1: 标准softmax·硬标签
- T=2: 软标签·更多"暗知识"
- T=3.69: 龍魂默认·接近369的采样温度
