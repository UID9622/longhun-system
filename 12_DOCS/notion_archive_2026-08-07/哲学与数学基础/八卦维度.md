## 1. 定义

## 3. 深度学习中的八卦应用

### 3.1 ANTENNA-8GATE（八卦门控路由）
```
输入 → 八卦分类器(8-way softmax) → 选1-3个候选门 → 精细路由
```

### 3.2 八卦注意力头
```
Attention_8gua = Concat(head_乾, head_兑, ..., head_坤) · W_o
```
8个注意力头对应八卦，每个头关注不同类型的语义特征。

```
八卦旋转 = 先天八卦方位旋转 → 生成7种等价变体
```

## 4. 先天八卦 vs 后天八卦

| 属性 | 先天（伏羲） | 后天（文王） |
|:---|:---|:---|
| 排列 | 乾兑离震·巽坎艮坤（S形） | 震巽离坤·兑乾坎艮（九宫） |
| 用途 | 数学编码·抽象分类 | 时空定位·实际应用 |
| DL落点 | 特征编码·embedding | 时序调度·位置编码 |

在深度学习中使用先天八卦做特征编码，后天八卦做时序和位置编码。

## 5. 八卦与batch_size

训练时 batch_size = 8（八卦）或其倍数（16/32/64）：
- 每批8个样本各受一个卦象注意力头主导
- 8个头的结果concat后输出→多样性与一致性平衡
