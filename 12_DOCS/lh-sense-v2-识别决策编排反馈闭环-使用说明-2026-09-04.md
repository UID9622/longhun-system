## 二、用法速查

```
lh sense <文件> --auto                    # 方向一：识别+自动三色审计
lh sense <文件> --pipeline asr-chain      # 方向二：走技能链
lh sense <文件> --feedback                # 方向三：置信度+疑似记录
lh sense monitor --watch-dir <目录> --once  # 目录监听（--interval 秒 / 不带 --once 持续）
lh sense pipeline list                    # 列出可用技能链
lh sense pipeline run <链名> <文件>       # 执行技能链
lh sense feedback list                    # 待纠正记录
lh sense feedback correct <id> --text "正确内容"
lh sense feedback export --format jsonl|csv [--out 路径]
lh sense config get|set <key> <value>     # 三方向统一配置
lh health --json                          # 输出含 sense_audit 统计字段
```

### 内置技能链（方向二）

| 链名 | 步骤 | 落点 |
|:---|:---|:---|
| `ocr-chain` | 图片OCR→提取文字 | `lh topo` 图谱(图 sense-media) |
| `asr-chain` | 音频转写→自动摘要 | `lh brain` 记忆 |
| `vision-chain` | 图片识别→自动标签 | `lh topo` 图谱 |

### 三方向统一配置（~/.longhun/sense_config.json）

```json
{
  "auto": false,                    // 方向一默认开?
  "default_pipeline": "",           // 方向二默认链(空=不自动)
  "feedback": false,                // 方向三默认开?
  "confidence_threshold": 0.7,      // 置信度阈值
  "watch_dir": "",                  // 方向一监控目录
  "audit_verbose": true,
  "pipeline_brain_after_audit": true // 🟢通过后同步入 brain
}
```

配置示例设置：`lh sense config set auto true` / `set default_pipeline ocr-chain` / `set watch_dir /path`

## 三、方向间联动（已落地）

## 五、技术要点（焊点）

1. **whisper 置信度**：faster-whisper 的 `info` 不暴露 avg_logprob，须逐 segment 聚合 → 线性映射 `conf = 1 + avg_logprob/2`（-0.37→0.82 实测）。no_speech>0.5 封顶 0.2。
2. **多通道置信度保守取低**：但只统计**有实质文本(≥10字)**的通道——VLM 短描述(5字)不拖累 OCR 长文本(198字/conf0.9)。
3. **VLM 启发置信度**：moondream 无原生置信度 → `0.45+len/200` 启发(文本越长越可信)，诚实标注启发式非模型概率。
4. **三色审计引擎**：优先接 P05 `lh_three_color_audit.quick_audit`(0.16s 轻量)，异常降级内置规则。
5. **brain/topo 用子进程隔离**调用(lh_brain.py save / lh_topo.py register+node)，防 import 副作用。
6. **pipeline 执行链会注册 sense-media 图谱**：首次 `register`(已存在自动跳过) 再 `node` 入库。
7. 经 `lh` 网关(P05 回流)+P15 签章，`lh doc-sync` 命令表已含 sense 子命令组。
