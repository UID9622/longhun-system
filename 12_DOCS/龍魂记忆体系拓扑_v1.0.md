## 四、日常记忆三问速查

| 要做什么 | 用哪个 |
|:---|:---|
| 我上次干到哪了/当前任务 | `lh session status` / `cat ~/.longhun/session_context.json`（启动自动恢复） |
| 记住一句话/一个决策 | `lh brain remember "…"`（=decision）或 `lh calmem note [date] "…"`（日历锚定） |
| 查某天干了什么/跨日检索 | `lh calmem day 2026-09-05` / `lh calmem search 关键词` |
| 断点续接任务 | `lh checkpoint list` → `resume` |
| 这步执行复盘记录 | 自动（`_recap_hook_post`），手动看 `~/.longhun/recap/recaps/` |

**铁律**：全本地零三方·append-only 不删除只冻结·哈希链(calmem)不可抹去·MEMORY.md 精简 v70 权威。
