## 0. 一句话定位

CNSH 是"写给机器看的自然语言"——既能被中文母语者读懂，又能被解析器稳定还原。
本规范回答一个问题：**什么样的 CNSH 写法，让解析器永远不会猜错？**

## 1. 解析失败来源分类

任何一次解析失败，先归入四类之一，再对症下药：

| 类别 | 代号 | 根因 | 典型症状 | 处置 |
|------|:---:|------|------|------|
| 歧义 | P-AMB | 一句话有多个合法结构 | 同一输入两次解析结果不同 | 改写为 §2 稳定写法之一 |
| 依赖缺失 | P-DEP | 引用了未定义的符号/上下文 | "未定义变量"·"找不到模块" | 显式声明或先定义后引用 |
| 边界冲突 | P-BND | 中文与保留字/分隔符撞车 | 变量名含"输出"等保留词 | 遵守保留关键字表 + 加引号 |
| 格式违规 | P-FMT | 缩进/分隔/块结构不合规 | 缩进不一致·块未闭合 | 按 §5 固定写作约定重排 |

> 原则：**先分类，再修写**。不分类就改 = 病根未除。

## 2. 通用 10 条稳定写法

这 10 条是"怎么写都不会错"的保底写法，解析器对此零歧义。

1. **动宾完整**：每句必须"动词 + 宾语"齐全。
   ```cnsh
   输出 "结果"        # ✅
   "结果"              # ❌ 没有动词
   ```

2. **一字一义**：一个词只承担一个语义，不搞一词多义。
   `输出`只做输出，`打印`只做打印，不混用。

3. **字面量加引号**：所有字符串用双引号包裹。
   ```cnsh
   读取 "config.yaml"    # ✅
   读取 config.yaml      # ❌ 会被当成标识符
   ```

4. **修饰语显式前置**：修饰语用 `在/用/从/到` 等显式介词开头，不省略。
   ```cnsh
   保存 数据 到 "/tmp/a.json"   # ✅
   保存 数据 "/tmp/a.json"      # ❌ 介词缺失，结构不明
   ```

5. **块用缩进，不混 Tab/空格**：一个文件内缩进单位统一（建议 2 空格），禁用 Tab。

6. **条件/循环写全关键字**：不省略 `如果/否则/循环`。
   ```cnsh
   如果 x 大于 5 输出 "大"    # ✅
   x 大于 5 → 输出 "大"       # ❌ 箭头不是标准结构
   ```

7. **DNA 行独立成行**：`DNA:` 必须独占一行，前面不加缩进。

8. **注释只做说明**：`#` 开头注释不参与解析，禁止把可执行逻辑藏进注释。

9. **一句话一个动作**：用管道 `|` 连接多步，不塞进一句话。
   ```cnsh
   读取 "a.txt" | 解析 | 输出    # ✅
   读取并解析并输出 "a.txt"      # ❌ 动词堆叠
   ```

10. **文件名/路径必带扩展名**：路径一律写完整。
    ```cnsh
    执行 "bin/lh_time_engine.py"   # ✅
    执行 "lh_time_engine"          # ❌ 无法判定是否脚本
    ```

## 3. 清坑规范（遇到坑怎么办）

| 坑 | 现象 | 清坑动作 |
|------|------|------|
| 保留字撞名 | 变量叫"输出" | 改名 + 查 `reserved_keywords.txt` |
| 缩进漂移 | 粘贴后空格变 Tab | 统一转 2 空格 |
| 引号丢失 | 字符串裸奔 | 全量补双引号 |
| 中英标点混用 | 中文与 ASCII 标点混排 | 字符串外只用 ASCII 标点 |
| 报错看不懂 | 错误信息含代码位置 | 按 §1 分类表对号入座 |

## 4. 说实话模式（解析器不猜，只说真话）

解析器对"猜不出来"的结构，**禁止强行猜测**，必须输出说实话报告：

```cnsh
解析 "宝宝 输出"
# 输出:
#   [P-AMB] 歧义: "宝宝" 是主语还是对象?
#   建议: 写全 "宝宝 输出 \"Hello\"" 或 "输出 宝宝的问候"
```

| 说实话动作 | 说明 |
|------|------|
| 报分类号 | 必须带 P-AMB / P-DEP / P-BND / P-FMT |
| 报位置 | 行号 + 列号 + 原文片段 |
| 给建议 | 给出 1-2 条符合 §2 稳定写法的改写 |
| 不猜 | 宁可报错，不可猜错 |

## 5. 固定写作约定（全仓库统一）

1. 文件头三件套：`DNA:` + `创建者:` + `协议:`（缺一即 P-FMT）
2. 代码块语言标记固定为 `cnsh`
3. 表格是唯一的分隔工具，不用裸分隔线
4. 示例永远给"✅ 对 / ❌ 错"对照
5. 章节号用 `N.M` 递进，禁止跳号
