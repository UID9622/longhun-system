## A.1 全部保留关键字

以下关键字不可用作变量名、函数名、模块名。

### 指令类

```
输出 打印 回显 读取 接收 获取 执行 运行 调用
启动 初始化 停止 恢复 查询 状态 同步 归档 部署 发布
```

### 控制类

```
如果 否则 否则如果 循环 当 在 次 停止 跳过 返回
尝试 捕获 最终 抛出 熔断 降级 回退
```

### 声明类

```
函数 模块 导入 变量 常量 全局 局部 上下文 环境 会话
```

### 类型类

```
字符串 整数 小数 布尔 真 假 无 列表 映射
```

### 审计类

```
审计 检查 验证 判定 三色 通过 待核 拒绝
生成DNA 验证DNA 数字根 GPG签名 校验SHA
```

### 八卦类（保留字）

```
乾 坤 震 巽 坎 离 艮 兑
```

### 其他

```
加密 解密 转换 解析 执行Python 执行Shell 脚本
管道 确认 密钥 记录 输出摘要
```
