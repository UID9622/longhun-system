## C.1 核心边界

| 场景 | 用 CNSH | 用自然语言 |
|------|---------|------------|
| 给 AI 下确定性指令 | ✅ | ❌ |
| 写可执行逻辑 | ✅ | ❌ |
| 审计/追溯 | ✅ | ❌ |
| 讨论需求/意图 | ❌ | ✅ |
| 描述背景/情感 | ❌ | ✅ |
| 头脑风暴 | ❌ | ✅ |

**一句话**：CNSH 是"给机器看的规则"，自然语言是"给人看的想法"。两者不是替代关系，是分工关系。

## C.2 为什么不能全用自然语言

| 自然语言问题 | 例子 |
|--------------|------|
| 歧义 | "把那个东西处理一下" — 哪个？怎么处理？ |
| 不可复现 | 每次解释不同，结果不同 |
| 不可审计 | 无法追溯谁写了什么 |
| 不可验证 | 无法自动判定对错 |

## C.3 CNSH 如何保留自然语言可读性

```cnsh
# 一眼能看懂（中文自然语序）
如果 文件不存在
  创建 文件
  写入 "初始内容" 到 文件
否则
  输出 "文件已存在"
```

CNSH 选择**结构化中文**而非纯自然语言，既保留了可读性，又获得了确定性。

## C.4 混合使用模式

```cnsh
# 注释用自然语言说明"为什么"
# 这段逻辑是为了防止重复写入导致数据覆盖
如果 文件存在
  追加 "新内容" 到 文件
```

## C.5 判断标准

写 CNSH 前问自己三问：

1. 这句话机器能无歧义执行吗？
2. 这句话能自动验证对错吗？
3. 这句话能追溯到创建者吗？

三个都是 ✅ → 用 CNSH。否则 → 用自然语言。
