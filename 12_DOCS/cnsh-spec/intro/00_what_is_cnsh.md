## 0.1 一句话定义

> **CNSH（Chinese Natural Shell）** 是一种面向人机协作的中文结构化语法，兼具自然语言可读性与机器可解析性，覆盖 **AI 指令、审计追溯、脚本执行** 三个层次。

## 0.2 CNSH 是什么

| 特性 | 说明 |
|------|------|
| 中文原生 | 关键字、操作符、语法结构全部基于中文自然语言 |
| 结构化 | 可被机器解析，可编译为 Python/Shell 执行 |
| 可审计 | 每行可追溯 DNA，支持三色判定（🟢 通过 / 🟡 待核 / 🔴 红线） |
| 零门槛 | 会写中文句子就能写 CNSH |

## 0.3 CNSH 不是什么

| 误解 | 纠正 |
|------|------|
| 提示词工程 | ❌ CNSH 是**语法规范**，不是 Prompt 模板 |
| 自然语言处理 | ❌ CNSH 是**编程语言规范**，不是 NLP 库 |
| JSON/YAML 替代品 | ❌ CNSH 是**人机协作语言**，互补而非替代 |
| Python 中文版 | ❌ CNSH 是**指令层**，Python 是执行层 |

## 0.4 设计原则

1. **中文第一**：关键字、语法、错误信息全部中文
2. **机器可读**：结构化解析，不依赖语义理解
3. **可追溯**：每行代码可绑定 DNA
4. **零门槛**：会写中文的人 10 分钟上手

## 0.5 体系定位

CNSH 在龍魂体系中对应两种扩展名：

| 语境 | 全称 | 层次 |
|------|------|------|
| 人机交互语法（本规范） | Chinese **Natural Shell** | 对外语法呈现 |
| 数学语义液压（内部论文 v3.1） | Chinese Native Semantic **Hydraulics** | 底层算法内核 |

> 两者同属 CNSH 体系：**Shell 是 Hydraulics 的对外语法层**。本规范只定义 Shell 语法，不涉及内部算法细节。
