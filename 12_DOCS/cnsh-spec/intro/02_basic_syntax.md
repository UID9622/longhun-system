## 2.1 语法单元总览

CNSH 的基本语法单元共 5 类：

| 单元 | 示例 | 用途 |
|------|------|------|
| 关键字 | `输出` `读取` `执行` `审计` | 固定指令词 |
| 标识符 | `龍_系统` `数据_用户` | 变量/模块名称 |
| 字面量 | `"字符串"` `123` `3.14` | 值 |
| 操作符 | `=` `+` `如果` `否则` | 运算与控制 |
| 分隔符 | 空格、换行、`:`、`:` | 结构切分 |

## 2.2 注释

```cnsh
# 单行注释
# 支持中文注释，说明"为什么"而非"是什么"

# 多行说明用连续 #
# 关键阈值注明出处（哪条协议哪个公式）
```

## 2.3 字面量

```cnsh
字符串 "龍魂"
整数 42
小数 3.14
布尔 真 / 假
空值 无
```

## 2.4 标识符规则

| 规则 | 示例 | 说明 |
|------|------|------|
| 系统级前缀 | `龍_系统` | 龍魂保留命名空间 |
| 数据级前缀 | `数据_用户` | 用户数据处理 |
| 全中文 | `文件_路径` | 中文优先 |
| 禁英文缩写 | ~~`usr_dt`~~ | 拒绝英文缩写污染 |

> 命名规范对齐 `CNSH_命令与变量命名规范-v2.0.md`：品牌/核心类名用繁体「龍」，通用工程变量用中文蛇形。

## 2.5 指令行基本结构

```cnsh
# 结构：[主语] [谓语] [宾语] [修饰语]
宝宝 输出 "Hello" 在控制台
系统 审计 本次操作 用三色判定
```

- **主语**：执行主体（可省略，默认 `系统`）
- **谓语**：动作（`输出` `读取` `执行` `审计`）
- **宾语**：操作对象
- **修饰语**：条件/参数（`在路径下` `用三色判定`）

## 2.6 五行校验（龍魂特色）

```cnsh
属性 校验 "木" # 金水木火土
```

| 属性 | 用途 | 映射 |
|------|------|------|
| 金 | 审计/安全 | 巽·坎 |
| 水 | 数据/主权 | 坎 |
| 木 | 成长/扩展 | 震 |
| 火 | 执行/部署 | 离·兑 |
| 土 | 稳定/存储 | 坤·艮 |

## 2.7 本章小结

- 5 类基本语法单元：关键字/标识符/字面量/操作符/分隔符
- 注释用 `#`，说明"为什么"
- 标识符中文优先，系统级带 `龍_` 前缀
- 指令行 = 主语+谓语+宾语+修饰语
