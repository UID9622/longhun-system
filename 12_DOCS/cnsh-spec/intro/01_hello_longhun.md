## 1.1 第一个程序

创建一个文件 `hello.cnsh`，写入：

```cnsh
输出 "Hello, 龍魂"
```

执行：

```bash
lh6 run hello.cnsh
```

输出：

```
Hello, 龍魂
```

## 1.2 加一句中文注释

```cnsh
# 这是注释：以井号开头，会被解析器忽略
输出 "Hello, 龍魂"
输出 "欢迎来到 CNSH"
```

## 1.3 带 DNA 的完整程序

```cnsh
DNA: #龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-CNSH-HELLO-v1.0-UID9622-A7B8C9D0
创建者: 诸葛鑫
输出 "Hello, 龍魂"
确认: ✅
```

`lh6 run` 执行时校验 DNA 格式合法性（详见第9章）。

## 1.4 三色确认

CNSH 程序执行后可以附加三色判定：

```cnsh
输出 "Hello, 龍魂"
审计: 🟢 通过
```

| 色 | 含义 | 场景 |
|----|------|------|
| 🟢 | 通过 | 全检查点通过，放行 |
| 🟡 | 待核 | 推演/待实测，需注明待核什么 |
| 🔴 | 红线 | 安全风险，立即停止 |

## 1.5 常见错误

```cnsh
# 错误：英文关键字不被识别
print "Hello"     # ❌

# 正确：中文关键字
输出 "Hello"      # ✅
```

| 错误信息 | 原因 |
|----------|------|
| `未知关键字: print` | 使用了非 CNSH 关键字 |
| `缺少 DNA` | 文件头缺少 DNA 声明 |
| `未闭合字符串` | 引号不配对 |

## 1.6 本章小结

- CNSH 程序 = 中文指令行 + 可选 DNA/注释/审计标记
- 用 `lh6 run` 执行 `.cnsh` 文件
- 三色审计是龍魂体系判定标准，贯穿所有 CNSH 程序

## 1.7 练习

1. 修改 `hello.cnsh` 输出你的名字
2. 给程序加上 DNA 和 🟢 审计标记
3. 故意写错一个英文关键字，观察报错
