## 4.1 基本类型

| 类型 | 关键字 | 示例 | 说明 |
|------|--------|------|------|
| 字符串 | `字符串` | `"龍魂"` | 中文双引号 |
| 整数 | `整数` | `42` | 十进制 |
| 小数 | `小数` | `3.14` | 浮点 |
| 布尔 | `真` `假` | `真` | 逻辑值 |
| 空值 | `无` | `无` | 空 |
| 列表 | `列表` | `[1, 2, 3]` | 有序集合 |
| 映射 | `映射` | `{名称: 值}` | 键值对 |

## 4.2 类型声明

```cnsh
整数 龙年 = 2026
字符串 欢迎词 = "欢迎来到龙魂"
小数 圆周率 = 3.14159
布尔 是否开启 = 真
列表 数字 = [1, 2, 3, 5, 8]
映射 配置 = {引擎: "CNSH", 版本: "1.0"}
```

## 4.3 类型推断

```cnsh
# 声明时省略类型，由解析器推断
龙年 = 2026          # 整数
名称 = "龍魂"         # 字符串
```

## 4.4 类型转换

```cnsh
转换 数字 = 文本转整数 "2026"     # 2026
转换 文本 = 整数转文本 2026        # "2026"
```

| 转换函数 | 说明 |
|----------|------|
| `文本转整数` | 字符串 → 整数 |
| `整数转文本` | 整数 → 字符串 |
| `文本转小数` | 字符串 → 小数 |
| `转布尔` | 值 → 布尔 |

## 4.5 类型检查

```cnsh
检查类型 "龍魂"         # 字符串
检查类型 42             # 整数
检查类型 [1,2,3]        # 列表

类型一致 42 整数        # 真
```

## 4.6 数字根校验（龍魂特色）

龍魂体系的核心数学锚点是**洛书369不动点**：`sn=369, log369=5.911, perm369=108`。CNSH 提供数字根校验：

```cnsh
数字根 2026    # 2+0+2+6 = 10 → 1+0 = 1
数字根 369     # 3+6+9 = 18 → 1+8 = 9
```

| 用途 | 说明 |
|------|------|
| 权重校验 | 关键参数用数字根交叉验证 |
| 决策闸门 | 三闸门决策流场（数字根→身份→伦理） |
| 数据一致性 | 两条记录数字根一致 → 强关联 |

## 4.7 本章小结

- 7 种基本类型：字符串/整数/小数/布尔/空值/列表/映射
- 支持类型声明、推断、转换、检查
- 数字根校验是龍魂特有的数值验证手段
