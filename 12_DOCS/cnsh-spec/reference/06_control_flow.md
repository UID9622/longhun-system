## 6.1 条件判断

CNSH 用中文条件字：

```cnsh
如果 条件
  指令1
否则 如果 条件2
  指令2
否则
  指令3
```

```cnsh
整数 分数 = 85
如果 分数 >= 90
  输出 "优秀"
否则 如果 分数 >= 60
  输出 "及格"
否则
  输出 "加油"
```

## 6.2 条件操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `等于` | == | `分数 等于 85` |
| `不等于` | != | `分数 不等于 60` |
| `大于` | > | `分数 大于 80` |
| `小于` | < | `分数 小于 60` |
| `大于等于` | >= | `分数 大于等于 90` |
| `小于等于` | <= | `分数 小于等于 100` |
| `并且` | and | `A 并且 B` |
| `或者` | or | `A 或者 B` |
| `非` | not | `非 条件` |

## 6.3 循环

```cnsh
循环 数字 在 [1,2,3,4,5]
  输出 数字

# 次数循环
循环 5 次
  输出 "第几次"
```

| 循环类型 | 语法 | 说明 |
|----------|------|------|
| 遍历列表 | `循环 X 在 [列表]` | 遍历元素 |
| 次数循环 | `循环 N 次` | 固定次数 |
| 条件循环 | `循环 当 条件` | 条件满足持续 |

## 6.4 中断与继续

```cnsh
循环 数字 在 [1,2,3,4,5]
  如果 数字 等于 3
    跳过          # continue
  如果 数字 等于 5
    停止          # break
  输出 数字
```

## 6.5 三色分支（龍魂特色）

审计场景专用分支：

```cnsh
三色 判定 审计结果
  🟢 输出 "通过，放行"
  🟡 输出 "待核，标记"
  🔴 输出 "红线，熔断"
```

## 6.6 熔断条件分支

```cnsh
如果 触发P0
  熔断 执行         # 立即停止，L0/∞ 级
否则 如果 触发L1
  熔断 数据         # 拒绝请求 + MELTDOWN
否则 如果 触发L2
  熔断 人格         # 禁用当前人格
否则 如果 触发L3
  熔断 行为         # 锁定当前任务
否则
  继续 执行
```

## 6.7 本章小结

- 条件：`如果 / 否则如果 / 否则`
- 条件操作符全中文：等于/大于/并且/或者/非
- 循环：遍历 / 次数 / 条件
- 三色分支直接内建审计判定
- 四级熔断（∞L0/L1/L2/L3）可写为控制流

2. 用循环输出 1-10 的偶数
3. 写一个三色审计：分数>=60 🟢，>=50 🟡，否则 🔴
