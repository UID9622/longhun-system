## 5.1 核心概念

CNSH 指令遵循**中文自然语序**：

```
[主语] [谓语] [宾语] [修饰语]
```

| 成分 | 说明 | 示例 |
|------|------|------|
| 主语 | 执行主体 | `宝宝` `系统` `用户` |
| 谓语 | 动作/操作 | `输出` `读取` `执行` `审计` |
| 宾语 | 操作对象 | `文件` `数据` `命令` |
| 修饰语 | 条件/参数 | `在路径下` `用三色判定` |

## 5.2 基本指令

```cnsh
# 最简单的指令
输出 "Hello"

# 完整结构
宝宝 输出 "Hello" 在控制台

# 带审计
系统 审计 本次操作 用三色判定
```

## 5.3 指令类型

| 类型 | 谓语示例 | 用途 |
|------|----------|------|
| 输出类 | `输出` `打印` `回显` | 输出信息 |
| 输入类 | `读取` `接收` `获取` | 获取输入 |
| 执行类 | `执行` `运行` `调用` | 执行命令 |
| 审计类 | `审计` `检查` `验证` | 审计追溯 |
| 控制类 | `如果` `否则` `循环` | 控制流 |

## 5.4 八类指令与八卦对应（龍魂特色）

龍魂体系以八卦分类命令（`lh6` 命令总目），CNSH 指令同样映射：

| 卦 | 指令域 | 谓语示例 |
|----|--------|----------|
| 乾（启动） | 启动/初始化 | `启动` `初始化` |
| 坤（状态） | 状态/查询 | `查询` `状态` |
| 震（审计） | 审计/追溯 | `审计` `检查` |
| 巽（安全） | 安全/加密 | `加密` `校验` |
| 坎（主权） | 主权/身份 | `验证身份` `授权` |
| 离（技能） | 技能/引擎 | `调用` `运行` |
| 艮（同步） | 同步/归档 | `同步` `归档` |
| 兑（部署） | 部署/发布 | `部署` `发布` |

## 5.5 实战示例

```cnsh
# 从 README.md 读取 DNA
读取 "README.md" 提取 DNA

# 如果提取成功则审计
如果 DNA存在
  审计 该DNA 用三色判定
否则
  输出 "未找到DNA"
```

## 5.7 本章小结

- 指令 = 主语 + 谓语 + 宾语 + 修饰语，中文自然语序
- 5 类指令类型：输出/输入/执行/审计/控制
- 8 类指令域对应八卦：乾启动 · 坤状态 · 震审计 · 巽安全 · 坎主权 · 离技能 · 艮同步 · 兑部署
