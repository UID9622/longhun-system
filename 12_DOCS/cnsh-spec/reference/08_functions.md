## 8.1 函数定义

```cnsh
函数 计算面积(半径)
  返回 3.14159 * 半径 * 半径

# 调用
面积 = 调用 计算面积(10)
输出 面积    # 314.159
```

## 8.2 参数

```cnsh
函数 问候(名称, 语气 = "友好")
  输出 "你好，" + 名称 + "，语气：" + 语气

调用 问候("龍魂")              # 用默认语气
调用 问候("龍魂", 语气="正式")  # 覆盖默认
```

## 8.3 返回值

```cnsh
函数 计算(左, 右, 操作)
  如果 操作 等于 "加"
    返回 左 + 右
  否则
    返回 左 * 右

结果 = 调用 计算(3, 4, "加")     # 7
```

## 8.4 模块

CNSH 程序可以按模块组织：

```cnsh
模块 文件处理
  函数 读取文件(路径)
    返回 读取 路径

  函数 写入文件(路径, 内容)
    写入 内容 到 路径

# 导入使用
导入 文件处理
调用 文件处理.读取文件("README.md")
```

## 8.5 系统函数库（内建）

| 函数 | 说明 |
|------|------|
| `输出` | 输出到控制台 |
| `读取` | 读取文件/输入 |
| `审计` | 三色审计 |
| `生成DNA` | 生成 DNA 追溯码 |
| `验证DNA` | 校验 DNA 格式 |
| `加密` `解密` | 国密/AES 加密 |
| `数字根` | 洛书369 数字根计算 |
| `同步` `归档` | 数据同步与归档 |

## 8.6 函数与 DNA

每个函数体建议绑定 DNA，形成可追溯单元：

```cnsh
函数 关键计算
  DNA: #龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-引擎-计算-v1.0-UID9622-ABCD1234
  返回 数字根(369)
```

## 8.7 本章小结

- 函数 = `函数 名称(参数)` + `返回`
- 支持默认参数、命名参数
- 模块化组织：`模块` + `导入`
- 内建系统函数库覆盖 IO/审计/DNA/加密/数理
