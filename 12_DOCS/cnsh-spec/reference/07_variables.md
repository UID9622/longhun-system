## 7.1 变量声明

```cnsh
整数 计数 = 0
字符串 名称 = "龍魂"
列表 任务 = []
映射 配置 = {}
```

## 7.2 命名规范（龍魂二元体系）

对齐 `CNSH_命令与变量命名规范-v2.0.md`：

| 前缀 | 层级 | 用途 | 示例 |
|------|------|------|------|
| `龍_` | 系统级 | 龍魂保留命名空间 | `龍_系统` `龍_引擎` `龍_用户` |
| `数据_` | 数据级 | 用户数据处理 | `数据_用户` `数据_日志` |
| 无前缀 | 局部级 | 临时变量 | `计数` `名称` |

> **铁律**：系统核心变量禁止用英文缩写；品牌/核心类名繁体「龍」永存（如 `龍_系统`），兼容性通用变量中文蛇形。

## 7.3 赋值

```cnsh
# 直接赋值
计数 = 计数 + 1

# 复合赋值
计数 加 1
计数 减 1
计数 乘 2
计数 除 2
```

| 复合操作符 | 含义 |
|------------|------|
| `加` | += |
| `减` | -= |
| `乘` | *= |
| `除` | /= |
| `连接` | 字符串拼接 |

## 7.4 作用域

```cnsh
全局: 龍_系统 = "在线"

函数 处理任务
  局部: 临时值 = 100    # 函数内可见
  输出 龍_系统           # 全局可见

输出 临时值              # ❌ 超出作用域
```

| 作用域 | 声明 | 可见范围 |
|--------|------|----------|
| 全局 | `全局: 名称 = 值` | 整个程序 |
| 局部 | `局部: 名称 = 值` | 当前块/函数 |
| 默认 | `名称 = 值` | 当前块 |

## 7.5 常量

```cnsh
常量 圆周率 = 3.14159
常量 系统版本 = "v1.0"
# 常量不可重新赋值
```

## 7.6 敏感数据处理（龍魂数据铁律）

```cnsh
# 敏感数据端侧加密
数据_用户 = 加密 "手机号内容" 用国密算法
# 云上只存密文，日志只打哈希指纹
记录 日志 数据_用户 的 哈希指纹
```

| 数据级别 | 处理 |
|----------|------|
| D1 绝密 | 永不入云，请求即熔断 |
| D2 机密 | 端侧国密加密，云上只存密文 |
| D3 内部 | 日志脱敏 |
| D4 公开 | 自由流动 |

## 7.7 本章小结

- 变量 = `名称 = 值`，类型可选
- 命名：`龍_` 系统级 / `数据_` 数据级 / 无前缀局部级
- 复合赋值：加/减/乘/除/连接
- 作用域：全局/局部/当前块
- 敏感数据端侧加密，日志只存哈希指纹
