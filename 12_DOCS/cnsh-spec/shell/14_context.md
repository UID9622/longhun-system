## 14.1 环境变量

```cnsh
环境 设置 龙魂环境 = "prod"
环境 读取 龙魂环境
# 输出: prod
```

| 环境 | 用途 |
|------|------|
| `本地` | Mac 本地（launchd 44 服务） |
| `鲲鹏` | 华为云 119.13.90.27（systemd） |
| `prod` | 生产 |
| `dev` | 开发 |

## 14.3 敏感环境变量

```cnsh
# 密钥读取必须走统一出口
密钥 读取 "GPG_KEY_ID" 从 安全存储
# 禁止：明文硬编码、打印到日志
```

| ❌ 禁止 | ✅ 推荐 |
|---------|---------|
| 密钥硬编码进代码 | `lh keys` 统一密钥出口 |
| 密钥打印日志 | 只打哈希指纹 |
| 密钥提交 git | 环境变量 + 忽略文件 |

```cnsh

调用 处理任务({用户: "UID9622", 环境: "prod"})
```

## 14.6 本章小结

- 环境变量：`环境 设置/读取`
- 上下文携带用户/模块/环境/时区
- 密钥必须走统一出口，禁止硬编码
- 会话上下文可追溯
