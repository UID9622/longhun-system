## 15.1 错误捕获

```cnsh
尝试
  读取 "不存在.md"
捕获 错误
  输出 "文件不存在: " + 错误.信息
```

| 关键字 | 用途 |
|--------|------|
| `尝试` | 尝试执行（try） |
| `捕获` | 捕获错误（except） |
| `最终` | 无论对错都执行（finally） |
| `抛出` | 主动抛出错误（raise） |

## 15.2 完整错误处理

```cnsh
尝试
  读取 文件 = "data.jsonl"
  解析 JSON
捕获 文件未找到
  输出 "文件不存在，使用默认数据"
  读取 文件 = "default.jsonl"
捕获 解析错误
  输出 "JSON 格式错误"
  修复 格式
最终
  输出 "处理完成"
```

## 15.3 错误类型

| 错误 | 触发场景 |
|------|----------|
| `文件未找到` | 文件不存在 |
| `解析错误` | 语法/格式错误 |
| `验证失败` | DNA/签名校验失败 |
| `权限不足` | 未授权访问 |
| `网络错误` | 连接失败 |
| `熔断触发` | 熔断机制激活 |

## 15.4 回退（Fallback）

```cnsh
尝试 读取 远端数据
捕获 网络错误
  回退 读取 本地缓存
  输出 "远端不可达，使用本地缓存"
```

## 15.5 降级（龍魂特色）

```cnsh
尝试 调用 主力引擎
捕获 引擎故障
  降级 调用 备用引擎
  记录: 降级事件 + DNA
```

## 15.6 错误日志规范

```cnsh
捕获 错误
  记录日志
    级别: 错误
    错误: 错误.信息
    时间: 当前时间
    敏感字段: 哈希指纹 (禁止原文)
```

## 15.7 本章小结

- 错误处理：`尝试 / 捕获 / 最终 / 抛出`
- 7 种内建错误类型
- 回退：远端失败 → 本地缓存
- 降级：主力引擎 → 备用引擎
- 错误日志：敏感字段只存哈希
