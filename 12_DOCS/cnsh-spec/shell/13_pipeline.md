## 13.1 什么是管道

管道 = 上一个命令的输出直接作为下一个命令的输入。

```
输入 → [命令1] → [命令2] → [命令3] → 输出
```

## 13.2 管道语法

```cnsh
读取 "data.jsonl" | 提取 DNA | 去重 | 输出
```

| 符号 | 含义 |
|------|------|
| `\|` | 管道符，前一输出接后一输入 |
| `→` | 同管道符（可读性写法） |
| `;` | 顺序执行（不传数据） |

## 13.3 实战示例

```cnsh
# 读取数据集 → 筛选 rejected → 计数
读取 "audit.jsonl" | 筛选 verdict=rejected | 计数 → 输出

# 读取文件 → 校验DNA → 三色审计
读取 "README.md" | 提取DNA | 验证DNA | 审计
```

## 13.4 管道与审计链

龍魂体系最强场景：采集 → 校验 → 审计 → 发布 全链路：

```cnsh
管道 对抗测试
  执行 采集器 | 筛选 拒绝 | 人工复核 | GPG签名 | 发布
  每个环节 记录 DNA + 三色标记
```

## 13.5 序列执行

不传数据、只按顺序执行用分号：

```cnsh
启动 引擎; 检查 状态; 输出 "就绪"
```

## 13.6 管道中断条件

```cnsh
管道 读取 | 处理 | 输出
  熔断条件: 任一环节 verdict=rejected → 停止后续
```

## 13.7 本章小结

- 管道 `\|` 传数据流，序列 `;` 只排顺序
- 管道天然适合"采集→校验→审计→发布"链路
- 每个环节可绑定 DNA + 三色
- 支持熔断条件，任一环节拒绝即停

## 13.8 练习

1. 写一条管道：读取文件 → 提取 DNA → 验证
2. 写一条序列：启动 → 检查 → 输出
3. 给管道加熔断条件
