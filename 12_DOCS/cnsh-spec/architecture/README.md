## 0. 一句话定位

CNSH（Chinese Natural Shell，中文神经符号混合语言）不是"又一个编程语言"，
而是一整套**从语言到主权**的完整技术栈。本文件给出全景图与演进路线。

## 1. 六层全景图

从下往上六层，底层是地基，顶层是主权：

```
L5 主权层  ── 数据主权 / 部署主权 / 本地盾 Local Shield
L4 网络层  ── API 网关 / 分布式执行 / 跨机协作
L3 平台层  ── CNSH Hub / 插件市场 / 包管理 / 社区
L2 服务层  ── Algorithm Runtime / 算法路由器 / 插件注册表
L1 应用层  ── 编译器 / IDE / CLI / 调试器
L0 语言层  ── CNSH 语法 / 解析器 / BNF / 保留字表
```

| 层 | 代号 | 职责 | 关键产物 | 现状 |
|:---|:---|------|------|:---:|
| L0 语言层 | LANG | 定义语法与解析规则 | 16 章规范 + `cnsh_grammar.bnf` + `reserved_keywords.txt` | ✅ 已落地 |
| L1 应用层 | APP | 把语言变成工具 | 编译器 `cnsh_compiler.py`、IDE、CLI | 🟡 编译器已有·IDE 规划中 |
| L2 服务层 | SRV | 运行时与路由 | Algorithm Runtime、Algorithm Router、Plugin Registry | 🟡 规格已定·实现中 |
| L3 平台层 | PLT | 生态与分发 | CNSH Hub、插件市场、包管理 | 🔴 规划中 |
| L4 网络层 | NET | 连接与协作 | API 网关、分布式执行 | 🔴 规划中 |
| L5 主权层 | SOV | 主权保护 | Local Shield（本地盾） | 🔴 规划中 |

> 原则：**下层不稳，上层不建**。每一层必须先有规格、再谈实现。

## 3. 设计铁律

1. **中文母语者零门槛**：L0 层设计目标，其余各层不可破坏。
2. **解析器永不猜**：见 `docs/spec/parse_rules.md` v2.0 说实话模式。
3. **双视角封装**：`M::` 机器视角 + `CNSH::` 路由视角，见 `docs/spec/dual_perspective.md` v1.0。
4. **数据主权不可让渡**：L5 主权层是最终目的，不是附加功能。
5. **签名链守住**：每个产出文件必须 GPG 分离签名，缺签不上线。
