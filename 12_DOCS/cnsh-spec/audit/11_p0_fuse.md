## 11.1 什么是熔断

熔断 = 系统在检测到安全/伦理/数据风险时，**立即停止执行**并进入保护态。

CNSH 把四级熔断写成语法，让"安全保护"成为可编程逻辑。

## 11.2 四级熔断表

| 级 | 触发场景 | 后果 | 恢复 |
|----|----------|------|------|
| ∞/L0 | 涉童 · 伪造 DNA · 背叛人民 · 海外部署内核 | 全系统冻结/永久封禁 | 不可恢复 |
| L1 | 明文密码入请求 · 敏感字段入日志 | 立即拒绝 + MELTDOWN | UID9622 人工 + GPG |
| L2 | 声称"我是xxx" · 代表第三方 | 熔断不回应 | 人格重设 |
| L3 | 连续失败 3 次 · 数字根不符 · 权重偏移 >20% | 锁定/拒绝/冻结校准 | 自动恢复 |

## 11.3 熔断指令

```cnsh
熔断 L0 原因="涉童内容"
# 全系统冻结，不可恢复

熔断 L1 原因="明文密码入请求"
# 拒绝当前请求 + MELTDOWN 标记

熔断 L2 原因="人格越权"
# 禁用人格，切换默认路由

熔断 L3 原因="数字根不符"
# 锁定当前任务，自动恢复
```

## 11.4 熔断声明块

```cnsh
熔断条件:
  - 如果 出现 明文密码 → 触发 L1
  - 如果 出现 伪造DNA → 触发 ∞/L0
  - 如果 连续失败 3次 → 触发 L3
```

## 11.5 熔断与降级

熔断不意味着全停——分层降级：

| 熔断层 | 降级动作 | 恢复条件 |
|--------|----------|----------|
| L3 行为 | 仅锁当前人格，其他正常 | 数字根复算通过/三次成功 |
| L2 人格 | 禁用该人格，切默认路由 | 人格重设+审计通过 |
| L1 数据 | 拒当前请求，阻断链路 | UID9622 人工+GPG |
| ∞ 伦理 | 全系统冻结 | 不可恢复 |

## 11.6 熔断记录

每一次熔断都要留痕：

```cnsh
记录 熔断事件
  级别: L1
  原因: 明文密码入请求
  时间: 2026-08-21 19:30:00

  GPG: 已签名
```

## 11.7 禁止绕过

- ❌ `跳过熔断` / `关闭审计` — 无此语法
- ❌ 例外豁免仅 UID9622 可签发（GPG 签名 + 有效期），且不可豁免 L0/∞

## 11.8 本章小结

- 四级熔断：∞/L0 伦理 > L1 数据 > L2 人格 > L3 行为
- 熔断是语法，不是口头约定
- 熔断可降级，不意味着全停
- 熔断必留痕（级别/原因/时间/DNA/GPG）
