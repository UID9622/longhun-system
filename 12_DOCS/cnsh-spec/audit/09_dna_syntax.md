## 9.1 DNA 格式定义

```
#龍芯⚡️{日期}-{时辰}-{模块}-{动作}-{版本}-{UID}-{哈希8位}
```

| 字段 | 说明 | 示例 |
|------|------|------|
| 前缀 | 固定标识 | `#龍芯⚡️` |
| 日期 | YYYY-MM-DD | `2026-08-21` |
| 时辰 | 子丑寅卯… | `申时` |
| 模块 | 大写+下划线 | `CNSH-SPEC` |
| 动作 | 动作类型 | `DEPLOY` |
| 版本 | vX.X | `v1.0` |
| UID | 固定标识 | `UID9622` |
| 哈希 | SHA-256 前 8 位 | `A7B8C9D0` |

> 兼容说明：龍魂体系 DNA 亦支持干支四柱格式（`#龍芯⚡️丙午·丙申·癸酉·亥时-模块-动作-哈希8`），两种格式均合法，工具自动识别。

## 9.2 生成规则

```cnsh
生成DNA 模块="CNSH-SPEC" 动作="DEPLOY"
# 输出: #龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-申时-CNSH-SPEC-DEPLOY-v1.0-UID9622-A7B8C9D0
```

哈希由内容计算：`SHA256(模块 + 动作 + 内容摘要)` 前 8 位。

## 9.3 验证规则

```cnsh
验证DNA "#龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-申时-CNSH-SPEC-DEPLOY-v1.0-UID9622-A7B8C9D0"
# 返回：✅ 有效 / ❌ 无效
```

| 验证项 | 规则 |
|--------|------|
| 前缀 | 必须以 `#龍芯⚡️` 开头 |
| 日期 | 必须是有效日期 |
| 时辰 | 必须在 12 时辰列表（子丑寅卯辰巳午未申酉戌亥） |
| 哈希 | 必须为 8 位十六进制 |
| UID | 必须匹配 `UID9622` |

## 9.4 DNA 链追溯

```cnsh
DNA链:
  - #龍芯⚡️丙午·丙申·丙寅·甲午·䷕贲-未时-CNSH-DRAFT-v0.1-UID9622-12345678
  - #龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-申时-CNSH-DEPLOY-v1.0-UID9622-A7B8C9D0
  - #龍芯⚡️丙午·丙申·丁卯·丙午·䷚颐-酉时-CNSH-PUBLISH-v1.1-UID9622-B8C9D0E1
```

规则：
- 每个节点必须有父节点引用（第一个除外）
- 子节点哈希必须包含父节点哈希作为输入
- 断链 = 伪造嫌疑，审计即拒

## 9.5 GPG 签名联动

DNA 负责身份与追溯，GPG 负责完整性验证：

```cnsh
GPG签名 文件="09_dna_syntax.md" 密钥="A2D0092CEE2E5BA87035600924C3704A8CC26D5F"
GPG验证 文件="09_dna_syntax.md"
# 🟢 签名有效 · 密钥: A2D0092CEE2E5BA87035600924C3704A8CC26D5F
```

| 组合 | 保证 |
|------|------|
| DNA | 谁 · 何时 · 哪个模块 · 什么动作 |
| GPG | 文件是否被篡改（完整性） |
| 确认码 | 一次性确权（`#CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z`） |
