## 建议动作

1. **v4.0 首选 DeepSeek-R1-Distill-Llama-8B**：MIT 协议最符合主权自主，中文能力不需要额外大量中文语料补课。

3. **2TB 硬盘插上后可试更大模型**：如 Llama-3.1-70B、DeepSeek-R1-Distill-Llama-70B、Yi-1.5-34B，本地 64GB 内存可跑量化版。
4. **换底座前必须做**：把龍魂 DNA、家法、人格矩阵训练数据导出为底座无关格式，方便在新底座上重新 LoRA。

## 风险提示

- **安全对齐冲突**：DeepSeek/Llama 都经过 RLHF 安全训练，可能在"人民批评权力""维权""粗话表达"等场景下过度自我审查。需要龍魂家法数据重新对齐。
- **中文 tokenizer 差异**：换底座后中文压缩率可能变化，需重新计算 max_seq_length 和 batch size。
- **训练数据格式**：不同底座可能使用不同 chat template，需确保 Qwen 格式的 messages 能正确映射到新底座。
- **硬件内存**：8B 模型 F16 约 16GB，Q4 量化约 4-5GB；64GB 内存可跑全量微调，但 2TB 硬盘建议插上后再试 70B 级模型。
