## 二、命令速查（六命令）

### 1. 视觉：`lh render` / `lh wuwu`

```
lh wuwu wuxing '{"金":80,"木":65,"水":70,"火":90,"土":55}'   # 五行雷达图
lh wuwu audit  '{"🔴":1,"🟡":132,"🟢":1}'                    # 三色审计仪表盘
lh wuwu flow   '{"nodes":[{"id":"a","label":"节点"}],"edges":[["a","b"]]}'  # 流场节点图
lh wuwu health                                              # 健康看板（自动联动 lh health --json）
lh wuwu wuxing '{...}' --format svg --output /tmp/x.svg     # 指定格式与输出
lh wuwu --self-test                                         # 自测：三类图各出一张（8文件全过）
```

- `lh render` 为 M75 渲染引擎总入口，可视化类型（wuxing/audit/flow/health）自动转发女娲引擎
- 数据支持 dict / list / JSON 字符串 / 文件路径
- 默认输出 `data/renders/`

### 2. 听觉：`lh speak`

```
lh speak "龍魂归一"                          # say 中文 TTS → WAV（真实发声校验，防静音）
lh speak "你好" --voice Tingting --format mp3 # 指定声音与格式
lh speak "你好" --engine tts                 # 走 .venv_tts Coqui 引擎
```

- 中文语音包缺失时明确报错并给安装指引（不造假音频）
- DNA 追溯码嵌入音频元数据（WAV LIST/INFO · MP3 ID3 comment）
- 输出 `<1024B` 视为合成失败并报错

### 3. 听觉：`lh fingerprint`（音频指纹）

```
lh fingerprint 音频.wav
```

- Goertzel 算法 10 频点（200Hz–4kHz）分帧能量 → 二值化位串 → SHA-256 哈希
- 输出 JSON：`{bits, hash, meta}`，DNA 嵌入
- 纯标准库实现

### 4. 听觉：`lh voice-cmp`（声纹比对）

```
lh voice-cmp 音频A.wav 音频B.wav
```

- 汉明距离相似度判定，输出 0–100%
- 自测实测：同源 100.0% · 异源 58.8%

### 5. 视频：`lh video`

```
lh video "龍魂系统宣传片"                       # 文本 → 帧动画视频
lh video 图片目录/                               # 图片序列 → 视频
lh video "文本" --template intro               # 龍魂片头模板
lh video "文本" --template outro               # 片尾致谢归属模板
lh video "文本" --format webm                  # WebM 输出
lh video "文本" --fps 24                        # 帧率
```

- 每帧时间戳水印 + UID9622 归属 + DNA 追溯码嵌入元数据
- 自动生成 GPG 签名 sidecar（.asc）
- 旧 `lh video`（studio）改名为 `lh video-studio`

## 三、统一媒体网关 API（T4）

> 网关端口 8092（配置见 `08_BIN/gateway/config.yaml`），五锁鉴权：
> `X-Api-Key` + `X-API-Key-Secret`（明文模式）或 HMAC-SHA256 签名模式。

全部 POST 路由响应带 **`X-Longhun-Trace`** 追溯头（`LH-<hex16>`，after_request 统一注入）。

| 路由 | body | 返回 |
|:---|:---|:---|
| `POST /v1/render` | `{"type":"wuxing","data":{...},"format":"png"}` | 图像流（png/svg/html） |
| `POST /v1/speak` | `{"text":"龍魂归一","format":"wav","voice":"Tingting","engine":"say"}` | 音频流（wav/mp3） |
| `POST /v1/video` | `{"input":"文本","template":"intro","format":"mp4"}` | 视频流（mp4/webm） |

错误响应：`{"error": "...", "trace": "<hex16>"}` + 400/401/500。

示例：

```bash
curl -X POST http://127.0.0.1:8092/v1/render \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: <KEY>" -H "X-API-Key-Secret: <SECRET>" \
  -d '{"type":"wuxing","data":{"金":80,"木":65,"水":70,"火":90,"土":55}}' \
  -o wuxing.png
```

## 四、音频指纹原理（Goertzel 频带能量指纹）

1. **分帧**：音频按窗长/步长切帧
2. **频带能量**：每帧对 10 个频点（200Hz–4kHz 对数分布）跑 Goertzel 算法，得各频带能量
3. **二值化**：各频点能量 > 帧均值 → 1，否则 0 → 得到位串指纹
4. **哈希**：位串 → SHA-256（内容指纹，可追溯篡改）
5. **比对**：两指纹位串汉明距离 → 相似度百分比

特征：纯标准库（无 numpy/无三方依赖）· 抗格式转换（WAV/MP3 均可）· 同源稳定。
