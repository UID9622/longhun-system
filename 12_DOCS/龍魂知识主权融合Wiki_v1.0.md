## 🤖 领域一：人工智能

**CS底座**：神经网络·Transformer·强化学习·大模型训练·推理优化·幻觉检测
**创新落地**：国产大模型（文心/混元/通义）·AI芯片（昇腾/寒武纪）·自主AI训练框架（MindSpore/飞桨）
**交叉锚点**：算法自主 → 芯片自主 → 框架自主 → 应用自主·四级不动点
**学习路径**：`基础理论(L1) → 机器学习(L2) → 深度学习(L3) → 大模型(L4) → 幻觉检测/安全(L4)`

## 🔐 领域三：安全·密码·国防科技

**CS底座**：密码学(对称/非对称/哈希)·PKI体系·国密算法(SM2/SM3/SM4)·零信任架构·漏洞原理
**创新落地**：国密标准全球推广·量子密钥分发·北斗导航加密·自主可控网络安全体系
