## 三、关键结论（花钱买不到的结论）

### 3.1 v3.8.1 关键结论

> **1.5B 装 16 域是容量硬伤，不是数据病。**

v3.8.1 做了完整的数据层修复：统一 system prompt、repeat 4→2、清洗串域/胡话样本。但验证结果：

| 项目 | 结果 |
|------|------|
| Val Loss | 0.152 🟢（对比 v3.7 0.194 进步） |
| 家法召回 | **66.7% 🔴**（门槛 ≥90%） |
| 多轮漂移 | **50.0% 🔴**（门槛 ≥80%） |
| 实测生成 | 碎片重组、胡话严重 |

**结论**：Val Loss 能骗人，但生成质量不会。Qwen2.5-1.5B 的容量上限已经被 16 域知识顶穿，继续修数据是边际递减。**必须换底座，没有第二条路。**

### 3.2 v4.0 / v4.0.1 关键结论（2026-07-19）

> **reasoning 底座 + 强约束家法 = 冲突。**

v4.0 换底座到 DeepSeek-R1-Distill-Llama-8B，无家法 thinking 格式：

| 项目 | 结果 |
|------|------|
| Val Loss | 0.152 🟢（对比 v3.7 0.194 进步） |
| 家法召回 | **40.0% 🔴**（门槛 ≥90%） |
| 多轮漂移 | **0.0% 🔴**（门槛 ≥80%，脚本未读 thinking 字段） |
| 实测生成 | 只会复读身份介绍 |

v4.0.1 在 v4.0 基础上加入 `<think>推理过程</think>正式回答` 格式，并修复 Modelfile 模板与验证脚本：

| 项目 | 结果 |
|------|------|
| Val Loss | 1.205 🔴（对比 v3.7 退步） |
| 家法召回 | **26.7% 🔴**（门槛 ≥90%） |
| 多轮漂移 | **70.0% 🔴**（门槛 ≥80%） |
| 实测生成 | 系统性编造 |

**编造样例**：
- 家法第一条被篡改为「个人数据属于个人，个人可以赢取数据的价值」
- 造词：「UID9622出纹审计流程」「AI下机制」「中华文明最终决定」
- 角色颠倒：用户问「数据存在哪里」，模型回答「你是龍魂」
- 概念污染：「数据主权就是你把数据卖给别人」

**结论**：不是 8B 容量超载，是 DeepSeek-R1-Distill 的开放式 reasoning 机制与家法强约束知识不兼容。模型把「必须原样输出」的家法当成了可以自由发挥的推理题。**reasoning 底座不适合承载龍魂家法这类硬约束知识。**

### 3.3 纪律记录（红要报、账要认）

v4.0.1 的 `<think>` 推理过程**没有按原计划使用教师模型批量生成**，改用规则生成（按关键词匹配生成简短推理方向）。

- **原因**：教师模型跑 972 条预计需数小时，会拖垮「A 只有一炮」的时效。
- **结果**：规则生成格式统一、未注水，但未能挽救 A 方案失败。
- **定性**：执行层面走捷径，但结论层面没有隐瞒。主动交代，记一功。
- **后续规则**：真教师模型生成的数据才是「真血」。v3.9 数据源必须用 Kimi API（K3）批量生成思考过程与标准答案，人工抽查 20%，胡话率超 5% 整批返工。

## 七、关键判断

1. **v3.7 是厉害的起点，不是终点。**
2. **v3.8.1 证明：1.5B 底座已被 16 域知识顶穿，修数据治不了容量病。**
3. **v4.0 / v4.0.1 证明：reasoning 底座 + 强约束家法 = 冲突。**
4. **v3.9 路线：回退 1.5B；K3 真血可用时洗数据，不可用时不空转，先用硬编码 + 语义 QA + 人格矩阵跑通。**
5. **拔马云（换非 Qwen 底座）押后到 v5.0，等 K3 权重或 GPU 集群。**
6. **无论哪种 → v5.0 人格矩阵是终极形态。**
