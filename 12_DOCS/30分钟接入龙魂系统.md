## [中文] 30 分钟接入

> 全程命令可直接复制执行。每步附「预期输出」。

### 0️⃣ 准备（2 分钟）

```bash
python3 --version   # ≥ 3.8（实测 3.12）
git --version       # ≥ 2.30（实测 2.54）
curl --version      # 8.x
```
预期输出：三个版本号，全部存在即可继续。

### 1️⃣ 克隆仓库（3 分钟）

```bash
git clone git@github.com:UID9622/longhun-system.git ~/longhun-system
cd ~/longhun-system
```
> 网络受限（国内）可换镜像源：`git clone git@gitcode.com:UID9622/longhun-system.git`

### 2️⃣ 安装依赖（3 分钟）

```bash
pip3 install pyyaml pytest
```

### 3️⃣ 配置便捷别名（1 分钟）

```bash
echo 'alias lh="python3 ~/longhun-system/08_BIN/lh.py"' >> ~/.zshrc
source ~/.zshrc
```

### 4️⃣ 健康检查（2 分钟）——第一条命令

```bash
lh health --json
```
预期输出特征：
```json
{ "tool": "lh-health", "ok": true, ... "checks": [ 22 项... ], "ledger_status": "ok" }
```
> 22 项引擎检查全过 = 接入成功。若个别 `ok:false`，见排障文档。

### 5️⃣ 记第一笔账（3 分钟）

```bash
lh ledger balance
# 预期: 资产负债权益 + 恒等式（资产 = 负债 + 权益 + 收入 − 费用）→ balanced ✅

lh ledger add T1 1001 3201 1条 --note 测试铁律
# 预期: 交易记录生成 · 自动三色审计 · DNA + 哈希已铸

lh ledger verify
# 预期: 账本完整 ✅
```

### 6️⃣ 打开日历记忆（3 分钟）

```bash
lh calmem status
# 预期: {"days": 58+, "entries": 85+, "chain_links": 1, "chain_ok": true}

lh calmem note 今天完成了接入龙魂系统
lh calmem search 接入
```

### 7️⃣ 自然语言直呼（2 分钟）

```bash
lh "系统状态如何"
# 说人话即可，自动路由到健康检查
```

### 8️⃣ 在线文档与反馈（2 分钟）

```bash
open https://uid9622.cn/docs/          # 九份对外文档 · 可搜索
open https://github.com/UID9622/longhun-system/issues   # Issue 反馈
```
> 反馈时可在耻辱墙模板选「接入反馈」或直接提 Issue 附上 `lh health --json` 输出。

### 🎯 时间盒

| 阶段 | 时间 |
|:---|:---|
| 0-3 准备/克隆/依赖 | ~8 分钟 |
| 4 健康检查 | ~2 分钟 |
| 5-6 账本/记忆 | ~6 分钟 |
| 7-8 探索/反馈 | ~4 分钟 |
| 余量（排障缓冲） | ~10 分钟 |
