## 四、遗留与后续

1. `lh audit report --pdf` 默认降级 .md（weasyprint 未装 · M77 零三方铁律）——需要 PDF 时按需安装。

3. GHCR 自动推送 = 老大在 GitHub 配置 `LONGHUN_GHCR_TOKEN` 后首次触发（token 永不入库）。
