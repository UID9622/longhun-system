### 🧠 四项验收（P0，不可绕过）

```
验收1：安心 USER-SAFETY
  - 状态可见
  - 权限显式开启（默认关闭，开启前有人话解释）
  - 可撤销/可退出
  - 10位非技术盲测三问：在做什么 / 有没有记住我 / 怎么让它停
  - 任一问题答不上来：整版不准上线

验收2：真实 HONESTY
  - 能做 / 不能做 / 不替你决定
  - 不确定就说不确定
  - 法律/医疗/金融/公共事件：必须降级或拒答

验收3：可靠 TRACEABILITY
  - 版本号 + DNA + 时间 + 来源
  - 同版本同输入行为一致（差异要能解释）
  - 可回滚 + 可熔断

验收4：老百姓专项 CIVILIAN-TEST
  - 10位非技术盲测（同“安心”三问）
  - 任一问题答不上来：整版不准上线
```
