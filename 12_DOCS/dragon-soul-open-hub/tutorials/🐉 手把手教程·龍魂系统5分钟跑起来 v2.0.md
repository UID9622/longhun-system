## 🚀 第一步：安装 Python（复制粘贴）

### Mac

```bash
# 安装 Homebrew（如果没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python
brew install python@3.12

# 验证
python3 --version
# 应该显示: Python 3.12.x
```

### Windows

1. 打开浏览器 → https://python.org/downloads/
2. 下载 **Python 3.12.x Windows installer (64-bit)**
3. 运行安装程序 → **⚠️ 必须勾选 ☑ Add Python to PATH**
4. 点 Install Now → 等装完
5. 打开 PowerShell（Win+R → 输入 `powershell` → 回车）

```powershell
python --version
# 应该显示: Python 3.12.x
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv
python3 --version
```

### 华为欧拉 openEuler

```bash
sudo dnf install -y python3 python3-pip python3-devel
python3 --version
```

def fig_to_base64(fig):
    """matplotlib 图形 → base64 图片（直接嵌HTML）"""
    buf = io.BytesIO()
    fig.savefig(buf, format='png', dpi=120, bbox_inches='tight',
                facecolor='#0a0a0a', edgecolor='none')
    buf.seek(0)
    return base64.b64encode(buf.read()).decode()

## 🆘 遇到问题？

| 问题 | 解决 |
|------|------|
| `python: command not found` | 没装Python或没加PATH，回第一步重装 |
