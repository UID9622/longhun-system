## 四、🧬 与花名册71+人格的映射说明

花名册（Notion数据库）是71+人格的唯一权威源。本注册表是「不动点规范层」，把花名册里每个人格的字段映射到统一模板：

| 花名册字段 | 本注册表字段 | 说明 |
|------|------|------|
| 是谁 | `layer` + `level` | 老大→L0；数字人格→L1/L2；家人→L0.5（待扩展） |
| 人格层级 | `fixpoint_id` + `layer` | P00-P20/P72→L1；DH-xxx→L2 |
| 信任等级 | `trust_level` | L5元老/L4战略/L3核心/L2正式/L1见习 |
| 人格名称 | `persona_name` + `badge` | 名称与徽章锁定 |
| 输出风格 | `output_style` + `tone_system` | 语气系统五层参数化 |
| 权限清单 | `permissions` | 按花名册+Mac终端配置合并 |
| 关联意图 | `trigger_words` | 召唤词与意图路由词 |
| DNA追溯码 | `dna`（注册表级）+ 各人格扩展 | 保持追溯 |

> **扩展规则**: 花名册新增人格时，按本模板补全字段即可。`voice_anchor` 或 `face_anchor` 缺失可先标 `draft`，激活后补全。
