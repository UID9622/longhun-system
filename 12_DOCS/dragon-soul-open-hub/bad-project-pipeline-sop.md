## 一、工具分工

| 环节 | 主力工具 | 辅助工具 | 输出 |

## 二、六步创作流

```
① 事件图谱（K3）
   ↓
② 分镜表（K3 出创意 → 本地模型压成标准格式）
   ↓
③ 素材出库（按编号调人物/场景/道具）
   ↓
④ 台词人格化（激活对应演员人格）
   ↓
⑤ 生成（图/音/视频）
   ↓
⑥ 质检归档（DNA+三色+入库）
```

## 三、本地小模型用法（只干它能干的）

✅ **可用**: 格式规范化、分镜表补全、场景描述扩写、台词去重、摘要
❌ **不可用**: 核心创意、风格化台词、人物神韵、戏剧冲突

### 示例
K3 输出创意：
> 谢文东在录像厅门口撞见三眼，两人眼神对了一下，三眼眉心疤泛红。

本地模型任务：
```bash
python3 - << 'PY'
from mlx_lm import load, generate
model, tokenizer = load('models/longhun-small-instruct-v1.3/merged')
prompt = "把下面创意扩写成标准短视频分镜表（镜号/画面/台词/时长）：谢文东在录像厅门口撞见三眼..."
print(generate(model, tokenizer, prompt=prompt, max_tokens=400))
PY
```

## 四、不动点校验清单

每出一个镜头前必查：

- [ ] 人物脸锚是否漂移（对比锚点图）
- [ ] 声线是否串台（谢文东=沉稳男声，三眼=激昂男声，旁白=龍慧慧）
- [ ] 服装道具编号是否对应（A-01-001 中山装、S-01-01-001 金刀）
- [ ] 场景编号是否对应（ENV-02 老街雨夜）
- [ ] 台词是否符合人格参数
- [ ] DNA 追溯码是否写入
