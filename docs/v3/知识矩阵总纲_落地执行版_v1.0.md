## 三、四引擎×技能联动

龍魂四大核心引擎（河图洛书DNA/六十四卦路由/五行权限校验/技能扩展）之间的依赖关系：

```
河图洛书DNA引擎 (hetu_luoshu_dna.py)
    ├── 被六十四卦路由调用（生成命令DNA+数字根）
    ├── 被五行权限校验调用（数字根dr熔断判定）
    ├── 被DNA生成器技能调用（用户面DNA生成）
    └── 被技能扩展层调用（技能/算法DNA生成）

六十四卦路由引擎 (bagua_router.py)
    ├── 调用河图洛书DNA（执行时生成审计DNA）
    └── 被五行权限校验前置拦截

五行权限校验层 (wuxing_guard.py)
    ├── 调用河图洛书DNA（数字根dr+DNA生成）
    ├── 拦截所有lh6命令（金水木火土五步）
    └── 被技能扩展层前置调用

技能扩展层 (skill_extension.py)
    ├── 调用五行权限校验（添加/执行技能前置）
    ├── 调用河图洛书DNA（执行DNA生成）
    └── 通过六十四卦路由入口（lh6 离 skill/algo）
```
