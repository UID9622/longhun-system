## 一、引擎宣言

> **通心译** = 通晓人心之翻译

通心译双语引擎 v3.0 是龍魂体系中所有**对外输出**的唯一合法语言转换层。它不追求字面翻译的精确，而追求**意图传递的完整**与**文化语境的适配**。

在通心译的框架下，每一段输出都同时承载两套语义：
- **内层（中文心）**：忠(0.5) > 孝(0.3) > 义(0.2) 的价值排序
- **外层（外文壳）**：目标语言的文化适配表达

**核心原则：心不可译，壳必适配。**
