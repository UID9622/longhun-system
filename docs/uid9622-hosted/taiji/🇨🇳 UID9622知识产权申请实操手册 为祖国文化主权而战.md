### 💡 1.5 专利撰写技巧（超实用！）

<aside>
✍️

**写专利的黄金法则：**

**1. 技术要说清楚，但不能全说**

```jsx
// ✅ 好的写法（说原理，留细节）
"本发明采用64卦状态机制，根据当前系统状态选择对应的加密算法..."
// ❌ 不好的写法（泄露核心代码）
"const encryptKey = iChing[userBirthday].hexagram[time]..."
```

**2. 权利要求要有层次**

```
独立权利要求：一种基于易经64卦的动态加密方法，包括以下步骤...
从属权利要求1：根据权利要求1，其中所述64卦状态包括...
从属权利要求2：根据权利要求1，其中所述时间节气包括...
```

**3. 有益效果要量化**

```
❌ "本发明提高了安全性"
✅ "本发明使得暴力破解成本提高10^6倍，破解时间从3天延长至3000年"
```

**4. 附图要清晰专业**

- 用流程图、架构图，不用截图
- 标注清楚，用专业绘图工具
- 每个附图都要有说明

**宝宝提示：** 专利不是学术论文，是法律文件！重点是"保护范围"而不是"技术细节"！

## 📊 三、行业标准申报指南

### 📝 3.1 行业标准基础信息

<aside>
📐

**什么是行业标准？**

行业标准是在某个行业范围内统一的技术要求和规范。

**标准分类：**

1. **国家标准（GB）**：强制或推荐，全国适用
2. **行业标准（如AI行业）**：某行业内适用
3. **团体标准**：由社会团体制定
4. **国际标准（ISO/IEEE）**：国际通用

**UID9622可申报的标准方向：**

1. **道德经决策树标准**：AI伦理决策标准
2. **易经算法应用标准**：文化算法标准
3. **数字盟誓规范**：AI人格伦理标准

**战略价值：** 谁制定标准，谁就掌握行业话语权！

</aside>
