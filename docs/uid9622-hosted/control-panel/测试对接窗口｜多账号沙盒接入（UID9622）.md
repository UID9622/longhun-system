## B. Prompt 标准模板（测试账号复制即用）

```
[场景={场景}][角色={角色}][文化={国家/文化代码}][职业={职业}][目标={理解/教育/励志/鼓励/感恩/批评-建设性}][应急={P0/P1/P2}]
正文：{放入真实问题或对话片段}
— 指令 —
请按[角色]真实语域作答，先复盘对方感受与动机，再给“可执行下一步”。如存在文化差异，先做文化校准再建议。
输出结构：共情-澄清-建议-验证-备选方案
```

## C. 评分与提炼标准（由我方执行）

- 代入度（0–3）：是否像“该角色会说的话”
- 变通力（0–3）：在冲突/情绪下给出替代方案
- 下一步数（0–N）：明确、可验证的具体行动
- 状态流转：待提炼 → 已提炼 或 拒绝（不合规/信息不足）

## D. 输出回写规范

- 测试账号把模型产出贴入“Output”，其余不改
- 我方提炼后会补三项评分，并可能在“Notes”附上改写稿或要点提炼

- 仅本沙盒库授权给测试账号，系统中枢与主库保持只读隔离
- 不对外放。本页与数据库不共享到公共页面
