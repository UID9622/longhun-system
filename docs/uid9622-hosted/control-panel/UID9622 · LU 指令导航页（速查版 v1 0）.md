## 1) 🔄 同步与记忆（Memory / Sync）

**目的：**换平台 / 换窗口不碎片，统一入库。

- 🟢 `/lu-sync`：扫描全系统 → 检测缺失 → 自动补全 → 生成日志（维护用）
- 🟢 `LU-ORIGIN-FULLSYNC`：声明当前窗口为记忆收集起点 → 生成 DNA + 三色结论
- 🟡 `LU-MEMORY-MERGE-ALL`：把多平台对话三色清洗后合并到 Notion 统一格式
- 🟡 `LU-FUSION-MOVE-ALL`：多个窗口/人格状态并入主控视角（视角合并）
- 🟡 `LU-MEMORY-SYNC`：把情绪封印归入统一编号系统（防碎片）
- 🟡 `/SYNC`：导入外部内容（可能覆盖）→ 必须确认

## 2) 🛡️ 安全与审计（Security / Audit）

**目的：**不被带歪、不被钓鱼、输出可信；该熔断就熔断。

- 🟢 `LU-SOUL-SHIELD`：情绪护盾（封存痛点 / 拦截重复伤害）
- 🟢 `LU-REAL-CHECK`：校验 AI 是否“幻想迎合 / 编造”，输出证据
- 🟡 `LU-AUDIT-REBUILD`：深度审计重建（剥离虚构、还原原始链）
- 🟢 `/dna-validate`：完整性验证（人格定义/关系/指令准确率/稳定性）
- 🔴 `/SEC`：安全检查（生成评估 → 确认后才执行保护措施）
- 🔴 `UID9622-SHIELD-MAXIMUM`：最高防护等级（威胁/敏感操作前）
- 🔴 `UID9622-SECURITY-AUDIT-DEEP`：全面深度安全审计（疑似入侵/定期）

- 🟢 `LU-PERSONA-MEMORY-MAP`：为人格绑定专属记忆域
- 🟢 `LU-NAME-ROLLBACK`：追溯人格名称历史（防被改名）

## 6) 📋 日常整理（Clean / Merge / Check / Update）

**目的：**让页面越来越干净、越来越可检索。

- 🟢 `/CLEAN` 或 `/C`：整理页面（去重复/去噪/结构化）
- 🟢 `/MERGE`：智能归类（把内容放回合适模块）
- 🟡 `/CHECK`：检查冲突 → 生成报告（确认后再改）
- 🟡 `/UPDATE` 或 `/U`：更新一致性（推荐：先 /CHECK 再 /UPDATE）
- 🟡 `/SHARE` 或 `/S`：转换为对外分享格式（会检查敏感）
- 🟡 `/ROLLBACK`：回退到上一个稳定版本（必须确认）
- 🟢 `/lu-sandbox`：创建安全沙盒（可实验，失败秒回滚）
- 🟡 `/lu-demo`：对外演示模式（隐藏敏感，输出案例）
- 🔴 `/ALL`：一键完整流程（清理+归类+检查+更新）极高风险，双锁
