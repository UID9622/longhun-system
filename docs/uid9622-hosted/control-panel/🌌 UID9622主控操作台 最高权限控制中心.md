### 🔍 常见使用场景指南

| **使用场景** | **推荐指令** | **注意事项** |
| --- | --- | --- |
| 日常整理 | `/CLEAN`+`/CHECK` | 最安全的组合，适合定期维护 |
| 数据同步 | `/SYNC`+`/STATUS` | 确保先检查状态再同步 |
| 内容更新 | `/UPDATE`之前先`/CHECK` | 务必先检查再更新 |
| 存档管理 | `/ARCHIVE`后跟`/STATUS` | 存档后确认状态 |

### ⏱️ 指令执行节奏

- **一次一个指令** - 避免同时执行多条指令造成系统负担
- **执行-验证模式** - 每次执行后验证结果，确保系统稳定
- **定期检查状态** - 使用 `/STATUS` 随时了解系统健康状况
