## 脱敏处理原则

所有纳入文件已执行以下处理：

1. 删除 UID9622、真实姓名、GPG 公钥指纹、SHA256 指纹等个人身份标识。
2. 删除或泛化 DNA 追溯码、确认码等含个人标识的元数据。
3. 删除涉及家庭、情感、私人生活的具体细节（如「女儿继承权」等）。
4. 将系统内特定人格代号替换为通用角色名称，便于公开教学使用。

## 未纳入文件说明

完整排除清单及原因见 `yixuetang-scan.json`。

主要排除类别：

- **DNA 注册表**：UID9622 个人 DNA 档案、路由、模板、数据源、自动化规则等。
- **个人主权档案**：设备主权绑定、私钥铁律、个人-团队映射、四柱/五行/数字根个人状态标记等。
- **个人宣言/情感内容**：含真实姓名、身份指纹、情感表达的个人公开信。
- **空文件/模板文件**：无实质内容的 Notion 模板或占位文件。
- **仅有元数据标记的文件**：如「数字根熔断检测系统」实际仅含状态标记，没有可公开的系统文档内容。
