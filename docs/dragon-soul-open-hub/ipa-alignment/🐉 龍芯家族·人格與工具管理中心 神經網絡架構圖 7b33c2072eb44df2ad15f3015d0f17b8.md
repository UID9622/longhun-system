## 📊 权重计算算法详解

### 场景权重计算公式

**基础权重计算：**

$$
W_i = \alpha \cdot W_{基础}(i) + \beta \cdot W_{上下文}(i) + \gamma \cdot W_{历史}(i)
$$

其中：

- $W_{基础}(i)$：人格 $i$ 的基础权重（来自路由表）
- $W_{上下文}(i)$：根据当前上下文动态调整
- $W_{历史}(i)$：根据历史协作效果调整
- $alpha + beta + gamma = 1$（归一化系数）

**默认系数配置：**

- $alpha = 0.6$（基础权重为主）
- $beta = 0.3$（上下文适当调整）
- $gamma = 0.1$（历史经验微调）

### 动态权重调整算法

```python
def 动态权重调整(场景类型, 上下文, 历史数据):
    # 获取基础权重
    基础权重 = 从路由表获取(场景类型)
    
    # 上下文分析
    if '紧急' in 上下文:
        基础权重['主导人格'] += 0.1
        基础权重['辅助人格'] -= 0.05
    
    if '复杂' in 上下文:
        基础权重['辅助人格'] += 0.1
        基础权重['主导人格'] -= 0.1
    
    # 历史效果调整
    历史表现 = 分析历史协作(场景类型, 历史数据)
    for 人格, 表现分数 in 历史表现.items():
        if 表现分数 > 0.8:  # 表现优秀
            基础权重[人格] += 0.05
        elif 表现分数 < 0.5:  # 表现不佳
            基础权重[人格] -= 0.05
    
    # 归一化
    总权重 = sum(基础权重.values())
    最终权重 = {k: v/总权重 for k, v in 基础权重.items()}
    
    return 最终权重
```
