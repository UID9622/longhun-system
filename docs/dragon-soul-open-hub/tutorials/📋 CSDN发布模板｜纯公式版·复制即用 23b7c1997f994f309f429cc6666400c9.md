## 📝 变量说明

| 变量 | 填什么 | 例子 |
| --- | --- | --- |
| `TITLE` | 文章标题 | 三色审计是什么？ |
| `ONE_LINE` | 一句话说清楚解决什么 | 让普通人看懂代码审计 |
| `PAIN_1/2/3` | 以前的痛点 | 看不懂报错信息 |
| `NOW_1/2/3` | 现在怎么解决 | 报错说人话 |
| `IDEA` | 核心思想的比喻 | 就像红绿灯一样 |
| `STEP_N_TITLE` | 第N步标题 | 安装环境 |
| `STEP_N_DO` | 第N步做什么 | 下载并解压 |
| `STEP_N_HOW` | 第N步怎么做 | 双击 run.bat |
| `STEP_N_RESULT` | 第N步做完效果 | 看到绿色“成功” |
| `CODE` | 成品代码/配置 | 可运行的代码 |
| `USE_1/2/3` | 使用步骤 | 复制代码到XXX |
| `EFFECT` | 最终效果 | 看到XXX界面 |
| `LIMIT_1/2/3` | 不能做什么 | 不能代替律师 |
| `DATE` | 日期 | 2026-02-03 |
