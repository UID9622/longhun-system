## 📋 模板结构说明

| 板块 | 作用 | 说人话 |
| --- | --- | --- |
| **1️⃣ 一句话说清楚** | 让人3秒知道这篇文章干啥的 | “我要解决XXX问题” |
| **2️⃣ 问题是什么** | 让人知道“为什么要做这个” | “以前怎么难受” |
| **3️⃣ 解决思路** | 把算法用生活比喻说清楚 | “就像 XXX 一样” |
| **4️⃣ 一步一步来** | 拆解每一步，跟着做就行 | “第一步→第二步→…” |
| **5️⃣ 成品展示** | 直接给结果，能用 | “复制这段就能跑” |
| **6️⃣ 算法明细** | 想深入的人可以看 | “数学公式在这里” |
| **7️⃣ 缺点与边界** | 说清楚这东西不能干什么 | “不是万能的” |
| **8️⃣ 署名溢源** | 谁做的、哪里来的、怎么联系 | “不匿名、可查证” |
