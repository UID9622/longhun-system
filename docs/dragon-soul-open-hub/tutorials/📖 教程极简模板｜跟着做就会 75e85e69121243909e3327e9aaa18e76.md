**极简教程模板**

**用途：** 教别人用某个功能

## 📝 变量说明

| 变量 | 填什么 | 例子 |
| --- | --- | --- |
| `教程名` | 教程标题 | 怎么安装CNSH编辑器 |
| `目标` | 学完能干啥 | 在本地跑CNSH |
| `准备X` | 需要准备什么 | 一台电脑 |
| `步骤X标题` | 第X步标题 | 下载 |
| `步骤X做法` | 第X步怎么做 | 点击下载按钮 |
| `步骤X结果` | 第X步做完什么样 | 看到下载完成 |
| `日期` | 日期 | 2026-02-03 |
