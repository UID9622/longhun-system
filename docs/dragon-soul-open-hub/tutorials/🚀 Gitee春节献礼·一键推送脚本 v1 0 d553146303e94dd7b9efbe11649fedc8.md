## 🐛 常见问题解决

### 问题1：权限被拒绝（Permission denied）

**原因：** SSH密钥未配置或过期

**解决：**

```bash
# 检查SSH密钥
ls -la ~/.ssh

# 如果没有id_rsa.pub，生成新密钥
ssh-keygen -t rsa -C "fireroot.lad@outlook.com"

# 复制公钥
cat ~/.ssh/id_rsa.pub

# 添加到Gitee：设置 → SSH公钥 → 粘贴
```

### 问题2：文件不存在（No such file or directory）

**原因：** 源文件路径不对

**解决：**

```bash
# 检查源文件目录是否存在
ls ~/Desktop/打包待命/CNSH\ 军人的编辑器/CNSH-v1.0-完整实现/

# 如果路径不对，修改脚本中的SOURCE_DIR变量
```

### 问题3：推送冲突（Conflict）

**原因：** 远程仓库有新提交

**解决：**

```bash
# 先拉取最新代码
git pull origin main --rebase

# 再推送
git push origin main
```

### 问题4：中文文件名乱码

**原因：** Git编码设置问题

**解决：**

```bash
# 配置Git支持中文
git config --global core.quotepath false
```
