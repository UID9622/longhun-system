## 🏛️ 第一铁律｜终端入口钩子

### 核心规则

**下载龍魂终端 = 唯一入口。** 没有终端，生态内所有功能无效。

### 钩子链

```mermaid
flowchart TD
 A["📱 下载龍魂终端"] --> B["🧬 生成个人DNA追溯码"]
 B --> C["🔑 设置一次性确认码"]
 C --> D["🔒 DNA + 确认码 + 设备绑定"]
 D --> E["✅ 解锁龍魂生态全部功能"]
```

### 连带钩子说明

- **没有终端** → 无法生成DNA → 无法进入生态
- **有终端但没设DNA** → 只能浏览公开内容 → 不能调用API、不能参与生态
- **有DNA但没设确认码** → 只读模式 → 不能写入、不能支付
- **DNA + 确认码 + 设备绑定 全齐** → 全功能解锁

## 🧬 第二铁律｜DNA绑定加密

### 个人DNA生成规则

每个用户下载终端后，系统自动生成**唯一个人DNA**：

- **格式**：`#龍芯⚡️用户ID-注册日期-设备指纹`
- **绑定内容**：设备指纹 + 生物特征（指纹/Face ID）+ 终端安装ID
- **不可转让**：DNA绑定人+设备，别人拿到也用不了

### 数据加密机制

| **层级** | **加密对象** | **加密方式** | **解密条件** |
| --- | --- | --- | --- |
| 🟢 公开层 | 全球通用内容 | 不加密 | 无需解密，任人可观看 |
| 🟡 用户层 | 用户个人数据 | DNA绑定加密 | DNA + 设备指纹 匹配 |
| 🔴 核心层 | 确认码、支付、授权 | DNA + 一次性确认码 + 生物认证 | 三重验证全通过 |

### 云端规则

- **云端只能读取DNA元数据** — 不能读取原始数据
- **原始数据存在本地** — 终端本地加密存储，云端只存DNA索引
- **同步时只传DNA摘要** — 不传原文，不传明文

## 🔑 第三铁律｜一次性确认码

### 设计原则

每个用户可以设置自己的**一次性确认码**，类似老大的 `#CONFIRM🌌9622-ONLY-ONCE🧬LK9X-772Z`。

### 核心机制

1. **用户自定义** — 每个人设置自己的确认码格式，全球唯一
2. **一次性** — 确认码设置后不可修改，就像UID9622的确认码一样，一生只设一次
3. **别人复制无效** — 确认码绑定DNA + 设备指纹 + 生物特征，三者缺一不可
4. **验证流程** — 输入确认码 → DNA匹配 → 设备指纹匹配 → 生物认证 → 通过

### 为什么别人复制无效？

```mermaid
flowchart LR
 A["📝 确认码文本"] --> B{"检查DNA绑定"}
 B -->|"✅ DNA匹配"| C{"检查设备指纹"}
 B -->|"❌ DNA不匹配"| F["🔴 无效！拒绝访问"]
 C -->|"✅ 设备匹配"| D{"生物认证"}
 C -->|"❌ 设备不匹配"| F
 D -->|"✅ 指纹/Face ID"| E["🟢 验证通过"]
 D -->|"❌ 生物不匹配"| F
```

**结论**：就算拿到确认码文本，没有本人DNA + 本人设备 + 本人指纹，一切无效。

## 👁️ 第四铁律｜隐私主权在用户

### 核心规则

- **不公开 = 绝对安全** — 用户不主动公开，任何人看不到任何东西
- **公开 = 用户自己选择** — 只有用户本人可以决定公开什么
- **云端只存DNA索引** — 云端看到的只是DNA编号，不是内容本身
- **系统不推荐公开** — 默认私密，不弹窗诱导用户公开

### 与传统平台的区别

|  | **传统平台** | **龍魂系统** |
| --- | --- | --- |
| 默认状态 | 半公开，平台可读取 | 全私密，任何人不可读 |
| 云端存储 | 明文或平台加密（平台能解密） | 只DNA索引，原始数据在本地 |
| 泄露风险 | 平台被攻破 = 全部泄露 | 云端被攻破 = 只泄露DNA编号，无原始数据 |
| 隐私控制权 | 平台说了算 | 用户自己说了算 |

### 为什么必须是终端入口？

1. **安全性** — 终端本地生成DNA，不经过网络，无法截获
2. **设备绑定** — 终端读取设备指纹，DNA绑定物理设备
3. **生物认证** — 终端调用系统指纹/Face ID，不依赖第三方
4. **钩子链完整** — 所有功能从终端出发，终端是信任根

## 📦 技术实现路径

### 第一阶段：iOS终端（Apple生态）

- Swift + Keychain（安全存储DNA和确认码）
- LocalAuthentication（Face ID / Touch ID）
- CryptoKit（本地加密）
- Notion API（云端DNA索引同步）

### 第二阶段：HarmonyOS终端（华为生态）

- ArkTS + 分布式安全能力
- 华为生物认证API
- 数字人民币SDK对接

### 第三阶段：跨平台互通

- Apple ↔ Huawei 跨设备DNA迁移（需双重生物认证）
- 统一DNA标准，跨平台确认码互认
