# 📋 Part 1｜产品定位与核心价值

## 产品名称

**通心译 · Heart-to-Heart Translate**

- 通 = 无障碍，无国界，全通
- 心 = 有温度，有爱，有人性
- 译 = 翻译，但翻的是关系不是文字

## 一句话定位

**全球首个基于Notion知识库引擎的“易经自适应·关系感知”翻译插件**

## 核心差异化（为什么不会有第二个）

| 维度 | 传统翻译（Google/DeepL） | 通心译 |
| --- | --- | --- |
| 翻译对象 | 文字→文字 | 关系+场景+情绪→文字+表情+语气 |
| 语境理解 | 单句级别 | 对话级别+关系级别+文化级别 |

# 🧠 Part 2｜Notion知识库引擎·核心架构

> 《易经·系辞》："形而上者谓之道，形而下者谓之器" —— 通心译的“道”是理解人心，“器”是Notion知识库。
> 

## 为什么选Notion做引擎

1. **数据主权** — 用户的关系图谱、对话记忆、文化词典全部存在用户自己的Notion里，不上传第三方
2. **结构化知识** — Notion的数据库天然支持多维度标签（关系类型、场景、语气、文化背景）
3. **API生态** — Notion API 2026-03-11版本已支持多源数据库、Webhook、Integration全套能力
4. **协作基因** — 用户可以邀请伴侣、朋友一起维护关系词典，通心译越用越懂你
5. **永久存档** — 翻译记录+语境记录永久留存，数字永生的一部分

# 🎯 Part 3｜核心功能详解

## 功能一：语境识别引擎

> 《易经·蒙卦》："匪我求童蒙，童蒙求我" —— 不是用户告诉通心译该怎么翻，是通心译自己看懂语境。
> 

**自动识别6大语境：**

| 语境 | 触发信号 | 翻译策略 | 示例 |
| --- | --- | --- | --- |
| 💕 打情骂俏 | 亲昵词+关系图谱=恋人/配偶 | 柔·亲·进 | "小傻瓜"→"you little goofball 😄" |
| 🤝 商务正式 | 敬语+关系图谱=客户/上司 | 中和·礼·稳 | "麻烦您了"→"I appreciate your kind assistance 🤝" |
| 👋 初次见面 | 无关系记录+陌生词汇 | 中和·礼·谨 | "你好"→"It's a pleasure to meet you" |
| 🔥 吵架降温 | 攻击性词汇+情绪激动信号 | 柔·退·化 | "你有病吧"→"I think there might be a misunderstanding 🙏" |
| 🫂 安慰模式 | 负面情绪词+关系亲密 | 柔·亲·守 | "没事的"→"Everything will be okay, I'm here for you 💛" |
| 😄 调侃幽默 | 网络用语+轻松语气 | 刚柔并济·进 | "你真是个人才"→"You're something else 😂" |

## 功能二：易经阴阳判断引擎

每一句话进来，通心译都会做三个判断：

1. **这句话是刚还是柔？** → 决定翻译的力度
2. **这句话是进还是退？** → 决定翻译的方向
3. **这句话的卦象是什么？** → 决定翻译的策略

**判断矩阵（简化版）：**

```
输入："你去死吧"

判断1：刚（攻击性词汇）
判断2：看关系
  → 如果是恋人说的 → 实际是撒娇 → 翻为柔
  → 如果是陌生人说的 → 实际是攻击 → 保持刚
  → 如果是朋友说的 → 实际是调侃 → 翻为幽默

恋人版翻译："Oh stop it, you~ 😤💕"
陌生人版翻译："That's quite harsh."
朋友版翻译："Get outta here 😂"
```

**同一句中文，三种完全不同的英文。这就是通心译。**

## 功能三：表情包自动配引擎

| 语境 | 默认表情包风格 | 示例 |
| --- | --- | --- |
| 打情骂俏 | 甜蜜系 | 😄🤗💕😘🥰 |
| 商务正式 | 专业系 | 🤝📋✅👍📊 |
| 吵架降温 | 和平系 | 🙏☘️🕊️💭🫂 |
| 安慰 | 温暖系 | 💛🫂🌸☀️🍵 |
| 调侃幽默 | 搞笑系 | 😂🤣💀👀🫠 |
| 初次见面 | 礼貌系 | 😊🙂👋🌟✨ |

用户可以在习惯偏好库里自定义自己的表情包风格。

## 功能四：Notion内嵌交互（用户怎么用）

**方式1：斜杠命令**

在Notion任意页面输入 `/通心译` 或 `/heart`

→ 弹出翻译框 → 粘贴文字 → 选择对象（从关系图谱库选）→ 一键翻译

**方式2：选中翻译**

选中任意文字 → 右键菜单 → 通心译 → 自动识别语境 → 翻译结果替换或并列显示

**方式3：侧边栏对话**

打开通心译侧边栏 → 像聊天一样输入 → 实时翻译 → 翻译记录自动存入对话记忆库

**方式4：数据库批量翻译**

选中数据库 → 通心译AI Autofill → 批量翻译指定列 → 自动适配每行的语境标签

# 👥 Part 4｜用户画像

## 核心用户群

**用户A：跨国情侣/夫妻**

- 痛点：和外国伴侣沟通，翻译软件总是翻出冰冷的直译，丢失了亲密感
- 场景：微信/WhatsApp聊天内容需要翻译，打情骂俏的话被翻成冒犯
- 通心译价值：关系感知翻译，越用越懂你们的沟通方式

**用户B：海外华人家庭**

- 痛点：和第二代/第三代用不同语言沟通，文化代沟+语言代沟
- 场景：父母说中文，孩子回英文，文化梗互相听不懂
- 通心译价值：文化桥梁，不只翻文字还翻文化背景

**用户C：跨国商务人士**

- 痛点：商务邮件/会议纪要翻译缺乏专业语气和文化礼仪适配
- 场景：给日本客户写邮件，需要敬语层级；给美国客户要直接
- 通心译价值：自动适配商务文化差异，避免社交失礼

**用户D：内容创作者/自媒体**

- 痛点：文章要多语言发布，但每种语言的读者文化不同
- 场景：同一篇文章发中文知乎和英文Medium，需要不同的语气和文化锚点
- 通心译价值：同一内容，多文化版本自动生成

**用户E：语言学习者**

- 痛点：学的都是课本翻译，实际沟通时不知道怎么说自然的话
- 场景：想知道"这句话地道怎么说"而不是"这句话语法正确怎么说"
- 通心译价值：教你说人话，不是教你考试

# 🔐 Part 9｜数据安全与隐私

>

- ✅ 用户随时可以删除所有数据，通心译不保留任何痕迹
- ✅ Integration权限最小化：只读取用户授权的页面/数据库
- ✅ 不收集用户行为数据，不做用户画像，不卖数据
- ❌ 绝对不把用户的关系图谱、对话记忆上传到任何第三方
