# 🔗 公式联动逻辑

## 自动分层规则

```jsx
// R×I → DNA层级自动判定
R=∞ ∨ I=100 → L0 永恒
R≥1000 ∨ I≥90 → L1 百年
R≥100 ∨ I≥60 → L2 十年
R≥10 → L3 日常
else → L4 瞬时
```

## 三色审计自动判定

```jsx
// 风险评分 → 三色
if(风险评分 ≤ 30) → 🟢 通过
if(风险评分 31-69) → 🟡 待审
if(风险评分 ≥ 70) → 🔴 阻断
```

## 熔断级别联动

```jsx
// 红线触碰 → ∞级
if(红线触碰 == true) → ∞ 伦理红线（全系统冻结）
if(风险评分 ≥ 90) → P0 核心阻断
if(风险评分 ≥ 60) → P1 原则偏离
if(风险评分 ≥ 30) → P2 预警
else → 🟢 正常
```

## 三才校验

```jsx
// 天地人三维全通过 = 可执行
SC = 天(道·规律) ∧ 地(结构·资源) ∧ 人(意志·选择)
SC = true → ✅ 天地人合一·可执行
SC = false → 🔴 缺维·阻断
```
