### 🔽 **核心操作按钮**

**📥 收集阶段**

- 【收集素材 → Intake】
    - 预填：来源类型=公开
    - 原始敏感级别=绝密
    - 状态=待初筛
- 【导入外部资料 → Intake】
    - 预填：来源类型=外部
    - 处理优先级=高
    - 需要验证=是
        
        

**🔄 处理阶段**

- 【脱敏工单 → Redaction】
    - 预填：审核状态=待审
    - 脱敏级别=标准
    - 处理人=Lucky主控
- 【快速脱敏 → Redaction】
    - 预填：脱敏级别=快速
    - 自动处理=开启
    - 质量检查=待确认
        
        

**📝 输出阶段**

- 【提炼要点 → PromoExtracts】
    - 预填：许可状态=公开
    - 安全级别=内部
    - 上线状态=草稿
    - 审核状态=待审
- 【发布排期 → PublishingQueue】
    - 预填：QA状态=待检
    - 上线日期=今天+1
    - 发布渠道=待定
        
        

### 📋 **审计操作**

<aside>

**重要提醒**: 每次导出操作都必须进行审计留痕

</aside>

    - 预填：动作=导出
    - 对象类型=DB

- 【导出完成 → AuditLog】
    - 预填：动作=完成导出
