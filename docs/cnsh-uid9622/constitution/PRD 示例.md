# 👀 问题

> **要回答的问题示例：**我们要解决什么问题？为谁？他们什么时候遇到这个问题？我们有哪些数据、研究和反馈可以解释这个问题？为了更好地了解这个问题，我们正在与哪些客户合作或听取哪些客户的意见？为什么迫切需要解决这个问题？为什么如此重要？
> 

---

# 💭 建议

> **要回答的问题示例：**我们如何解决这个问题？我们考虑了哪些替代方案？我们为什么会用这个方法？这个解决方案的一般形式是什么？你有市场上的任何模型、原型、相关比较吗？我们怎么知道我们已经解决了这个问题？我们的衡量因素有哪些？我们是否考虑过如何将其搭建为快速、高性能、可扩展和/或相对低成本的服务？
> 

---

# 🛫 计划

> **要回答的问题示例：**我们在搭建什么内容？它是如何工作的？我们怎么知道它有效？我们要衡量哪些内容？什么时候能准备就绪？**然后，回答以下问题：**
> 
> - 问题 1：大家知道我们要发布的内容吗？
>     - [ ]  **内部调整**
>         - [ ]  我们能解释一下这种变化的内容吗？
>         - [ ]  你是否与其他职能部门共享了此变化的详细信息？
>     - [ ]  **外部消息传递**
>         - [ ]  我们将如何向客户传达我们的发布信息？
>         - [ ]  客户将如何理解此次发布带来的变化？
> - 问题 2：我们确定这会奏效吗？
>     - [ ]  **质量**
>         - [ ]  该产品是否经过适当测试？
>         - [ ]  我们是否检查过对其他产品的影响？
>         - [ ]  我们是否进行了容量规划？
>         - [ ]  如果发布不顺利，我们是否有应急计划？
>     - [ ]  **衡量**
>         - [ ]  我们是否知道如何判断这次发布是否成功？
>         - [ ]  其他人是否可以看到这次发布的进展情况？
> - 问题 3：我们的发布步骤是什么？
>     - [ ]  **计划**
>         - [ ]  你是否同意 PMM 的发布受众？
>         - [ ]  我们是否与 PMM 就发布步骤达成一致？
> 
> *🚀 开始了！*
