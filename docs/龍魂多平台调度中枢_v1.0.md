## 一、核心原则

1. **本地主控**：Kimi 是总控，所有外平台只作为能力扩展，结果必须落盘到本地。
2. **密钥不落地明文**：所有 API key 从 `~/.longhun/vault/keys/*.age` 或环境变量读取，配置文件中只放 URL/ID/模型。
3. **先本地，后云端；先国产，后国外**：优先 Kimi/DeepSeek/Ollama，复杂英文任务走 Claude，实时信息走 Grok。
4. **每个动作都有 DNA**：所有平台调用生成 DNA 追溯码，来源可查。
5. **隐私分级**：生活/家庭/敏感内容不进外网；公开知识/代码/论文可外发。

## 五、配置说明

### 5.1 密钥来源优先级

1. **Vault 文件**（推荐）：`~/.longhun/vault/keys/<平台>.age`，用 `~/.cnsh/age.key` 解密
2. **CNSH 环境变量**：`CNSH_<平台>_API_KEY`
3. **通用环境变量**：如 `KIMI_API_KEY`、`DEEPSEEK_API_KEY`、`NOTION_TOKEN`
4. **TOML 配置**：302ai 从 `~/.kimi-code/config.toml` 读取

### 5.2 当前 `~/.longhun/multi-ai-gateway/config.yaml` 配置

```yaml
vault:
  mapping:
    kimi:     {file: kimi.age,     env: KIMI_API_KEY}
    deepseek: {file: deepseek.age, env: DEEPSEEK_API_KEY}
    notion:   {file: notion.age,   env: NOTION_TOKEN}
    claude:   {file: null,          env: ANTHROPIC_API_KEY}
    grok:     {file: null,          env: XAI_API_KEY}
    302ai:    {toml: ~/.kimi-code/config.toml, path: providers.302ai.api_key}
```

### 5.3 你需要补的 Key

| Key | 获取地址 | 用途 |
|-----|---------|------|
| `ANTHROPIC_API_KEY` | https://console.anthropic.com/ | Claude 直连 |
| `XAI_API_KEY` | https://console.x.ai/ | Grok 直连 |
| `NOTION_TOKEN` | https://www.notion.so/my-integrations | Notion 同步 |

如果暂时不想申请，Claude 和 Grok 可以通过 **302ai 聚合网关** 调用。

Claude Code 客户端已经焊接到本地龍魂上下文。但首次使用需要老大本人在终端里点 OAuth 授权，Kimi 替不了。

### 操作步骤

```bash
cd ~/longhun-system
claude
```

进去后输入：

```text
/login
```

浏览器会弹出 Claude 授权页，登录你的账号。授权成功后 403 消失，之后在该目录启动 Claude Code 会自动加载龍魂上下文。

### 已落地的 Claude 配置

- `~/longhun-system/CLAUDE.md`：项目级上下文
- `~/.claude/settings.json`：默认模型、环境变量、DNA 偏好
- `~/.bashrc`：注入 `LONGHUN_ROOT`、`DNA_PREFIX`、`UID9622` 等环境变量
- 快捷指令：`!压缩`、`!还原`、`!投喂`、`!记忆`、`!审计`

## 十、故障排查

### 10.1 `lh 平台 list` 显示 Grok/Claude 🔴

原因：没有配置 API Key。  
解决：申请 Key 并设置环境变量，或通过 302ai 网关调用。

### 10.2 `lh notion-list` 报 401

原因：Notion Token 无效，或 Integration 未共享数据库。  
解决：检查 `NOTION_TOKEN` / `LONGHUN_NOTION_API_KEY`，并在 Notion 中共享页面。

### 10.3 `lh grok "xxx"` 连接被拒绝

原因：当前网络无法访问 302ai 或 xAI。  
解决：检查网络；如需代理，在 `~/.longhun/multi-ai-gateway/config.yaml` 中配置代理。

### 10.4 `VaultLoader` 报错

原因：`~/.cnsh/age.key` 不存在或 vault 文件损坏。  
解决：运行 `age-keygen -o ~/.cnsh/age.key` 重新生成 age 密钥，或改用环境变量。
