本目录中每条记录遵循以下统一模板，AI可通过 `dna` 字段精确引用：

```yaml

  path: "<仓库内相对路径>"

  platform: "<发布平台: wechat/csdn/github/ieee/internal>"
  version: "<版本号>"

  tags: ["<标签1>", "<标签2>", ...]

### 字段说明

| 字段 | 必需 | 说明 | 示例 |
|------|:---:|------|------|
| `id` | ✅ | 全局唯一编号，永不重复 | `WECHAT-001` |

| `dna` | ✅ | DNA追溯码，格式 `#龍芯⚡️年干支·月干支·主题-版本` | `#龍芯⚡️丙午·辛未·LAZY-PRISON-v1.0` |
| `path` | ✅ | 仓库内文件路径 | `outputs/wechat_懒的牢房_..._v1.0.md` |
| `category` | ✅ | 二级分类 | `文化输出/懒的牢房系列` |
| `platform` | ✅ | 发布平台 | `wechat` / `csdn` / `github` / `ieee` / `internal` |
| `version` | ✅ | 语义化版本号 | `v1.0` |
| `date` | ✅ | 发布日期 | `2026-07-14` |
| `tags` | ✅ | 搜索标签，3-8个 | `["信息主权", "算法批判", "认知牢笼"]` |
| `summary` | ✅ | 一句话摘要（≤50字） | `拆解外卖/短视频/电商的假选择机制...` |
| `status` | ✅ | 状态 | `终稿` / `已发布` / `草稿` / `待发布` |

## 附录一：DNA格式规范

本仓库所有文章、论文、文档统一使用DNA追溯码，格式如下来自 `PROTO-001`：

### 格式定义

```
#龍芯⚡️<年干支>·<月干支>·<日干支>·<时辰>·<卦名>-<模块>-<动作>-<哈希8位>
```

### 简化版（推荐用于文章）

```
#龍芯⚡️<年干支>·<月干支>·<主题英文>-v<版本号>
```

### 字段说明

| 字段 | 格式 | 示例 | 必需 |
|------|------|------|:---:|
| 前缀 | `#龍芯⚡️` | `#龍芯⚡️` | ✅ |
| 年干支 | 天干+地支 | `丙午` | ✅ |
| 月干支 | 天干+地支 | `辛未` | ✅ |
| 日干支 | 天干+地支（可选） | `丙戌` | ❌ |
| 时辰 | 十二时辰（可选） | `未时` | ❌ |
| 卦名 | 六十四卦（可选） | `需` | ❌ |
| 模块 | 英文大写+连字符 | `LAZY-PRISON` | ✅ |
| 版本 | `v`+语义化版本 | `v1.0` | ✅ |
| 哈希 | 8位十六进制（可选） | `61FFC4E5` | ❌ |

### 示例

```
# 完整版
#龍芯⚡️丙午·丙申·丙辰·巳时·姤-TOUWEI-93PERSONA-ALIGN-v1.0

# 文章推荐版

#龍芯⚡️丙午·辛未·乙酉·需-NOTION-PHILOSOPHY-MATH-FUSION-v1.0

# 兼容格里历（过渡期）

1. **确定分类**: 从上述 A-F 六大类中选择
