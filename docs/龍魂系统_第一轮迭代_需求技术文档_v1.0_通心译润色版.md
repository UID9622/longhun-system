## 一、项目概述

龍魂系统第一轮迭代目标：**把河图洛书、道德经、易经 64 卦、人格矩阵、三色审计五个模块串成一条可调用、可路由、可审计的执行流水线。**

当前状态：每个模块都有独立文档或概念，但未形成统一入口。本轮任务是把它们变成可执行代码，并让它们互相调用。

## 二、架构总览

```
用户输入
    ↓
【道德经场景匹配器】 → 识别场景 → 命中 81 章对应金句
    ↓
【64 卦状态机】 → 根据输入特征 → 映射到 64 卦 → 输出状态码
    ↓
【人格矩阵路由器】 → 根据状态码+场景 → 选择执行人格
    ↓
【河图洛书熔断器】 → 检查决策链数字根 → dr∈{3,9} 熔断，dr=6 待审
    ↓
【64 卦审计矩阵】 → 输出 8 维审计评分
    ↓
【三色审计执行层】 → 🟢/🟡/🔴
    ↓
【输出】 → 返回用户 + DNA + 审计日志
```
