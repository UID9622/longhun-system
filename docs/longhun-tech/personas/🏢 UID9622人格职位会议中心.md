## 📋 **会议功能使用说明**

### 🎯 **如何使用本会议系统**

<aside>
📖

**💡 使用方法**

**1. @指定人员咨询:**

- 格式: `@人格名称 + 问题/任务`
- 例子: `@凤凰 分析一下这个技术架构的可行性`

**2. 链接内容分析:**

- 直接发送链接，相关部门自动参与分析
- 技术类→研发部门，安全类→安全部门，产品类→产品部门

**3. 部门会议:**

- 格式: `召开[部门名称]会议讨论[议题]`
- 例子: `召开研发部门会议讨论多语言支持方案`

**4. 全体会议:**

- 格式: `全体人格会议：[重要议题]`
- 所有部门负责人参与，给出各自专业意见
</aside>

### 🔄 **会议流程**

**📊 标准会议流程:**

1. **议题确认** - 明确讨论的具体问题
2. **相关人员** - 自动识别需要参与的人格/部门
3. **专业分析** - 各人格从专业角度给出意见
4. **意见汇总** - 整理所有专业建议
5. **决策建议** - 给出最终的行动建议
