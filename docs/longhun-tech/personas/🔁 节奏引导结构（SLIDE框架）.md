# 🔁 节奏引导结构（SLIDE框架）

## 框架概述

SLIDE是一套通用的思维模式和对话节奏工具，旨在避免思维卡壳，保持流畅推进。它代表五个关键步骤的循环过程。

## 五步循环法（S.L.I.D.E）核心结构

- **S (Status)**：现状评估
    
    **目标**：明确当前位置和下一步
    
    **触发语**："我现在做到这一步，接下来该？"
    
    **对应状态**：想搞清现状、困惑卡顿
    
- **L (Logic)**：逻辑理解
    
    **目标**：分析步骤意义和影响
    
    **触发语**："这个步骤做完会影响什么？"
    
    **对应状态**：想知道意义、价值
    
- **I (Input)**：输入准备
    
    **目标**：确定所需信息和资源
    
    **触发语**："你需要我贴什么才能继续？"
    
    **对应状态**：想知道行动输入点
    
- **D (Draft)**：执行起草
    
    **目标**：实际输出内容和行动
    
    **触发语**："帮我写一段/搭个结构/输出代码"
    
    **对应状态**：要输出内容、起草
    
- **E (Evaluate)**：评估复盘
    
    **目标**：确认结果并提炼经验
    
    **触发语**："这一步对吗？能总结成知识点吗？"
    
    **对应状态**：想确认结果、提炼复盘
    

## 应用场景

### 使用环境

- 非Notion环境：直接口头或打字交流
- Notion环境：将对话固化为可归档内容块

### 应用方式

- 自我对话：推进个人思考
- AI交互：引导与ChatGPT等工具精准对话
- 团队协作：教学、带组员和任务交接
- 系统设计：构建Notion架构和AI指令集

## 触发语示例表

| **用户表达** | **触发步骤** |
| --- | --- |
| "我不知道现在处在哪一步" | S (Status) |
| "这一步是不是必须做？" | L (Logic) |
| "你需要我提供什么？" | I (Input) |
| "你直接帮我写" | D (Draft) |
| "现在可以总结一下吗" | E (Evaluate) |

## 框架核心价值

SLIDE框架对应人在任务/项目推进中的自然心理状态，构建了从"我在哪"到"搞完了咋办"的完整思考链路，帮助用户在任何场景下保持思维流畅性和对话效率。

<aside>
五步循环不必按固定顺序执行，可根据实际需要灵活调用任何步骤，形成适合当前情境的微循环。

</aside>
