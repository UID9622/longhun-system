### 第三步：梦幻度评分

**评分维度：**

- 📊 **真实性**（0-100分）
- 🌟 **创新性**（0-100分）
- 🎯 **相关性**（0-100分）
- 🐉 **龙魂对齐度**（0-100分）

**梦幻度公式：**

```
梦幻度 = (真实性 × 0.4) + (创新性 × 0.3) + (相关性 × 0.2) + (龙魂对齐度 × 0.1)
```

**阈值：**

- 🟢 ≥ 80分：高质量，直接采纳
- 🟡 60-79分：中等质量，人工复核
- 🔴 < 60分：低质量，自动过滤
