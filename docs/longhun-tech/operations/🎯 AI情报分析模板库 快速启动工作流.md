## ⚡ 快速启动工具包

### 📝 一键生成报告模板

<aside>
🎨

**使用方法**:

1. 在对应数据库中选择目标记录

2. 点击"生成分析报告"按钮

3. 系统自动填充基础信息

4. 按模板补充分析内容

5. 一键导出或分享
</aside>

### 🔄 自动化工作流触发器

**高优先级触发条件**:

- AI动态: 影响评级≥"重大影响" + 来源机构为核心关注
- 竞品分析: 威胁等级≥"高威胁" + 学习价值≥"核心借鉴"
- 社会反馈: 问题严重程度≥"严重" + 解决优先级≥"极高"

**自动执行动作**:

1. 📧 相关人员邮件通知
2. 📅 跟进任务自动创建
3. 📊 分析模板自动生成
4. 🔔 系统仪表板高亮显示

```mermaid

    A[新信息检测] --> B{信息类型判断}
```
