# 常见网络问题排查指南

## LinkedIn 临时故障解决方案

看到"Something went wrong"错误提示时，这通常是 LinkedIn 自己的临时故障或限流提示，并非你电脑的问题。大多数情况下，几分钟内会自动恢复。

### 基本排查步骤（按顺序尝试）

- **等待片刻：**先等5～10分钟再刷新页面或重新登录
- **更换网络环境：**尝试使用其他Wi-Fi或手机流量，或开关一次VPN（IP被风控常会触发这类页面）
- **使用无痕模式：**在浏览器中打开无痕窗口访问，或清除浏览器缓存与Cookie
- **暂时禁用扩展：**特别是广告拦截、翻译、脚本类扩展可能会干扰正常连接
- **更换浏览器：**尝试使用另一款浏览器，或在手机App中登录查看
- **DNS设置调整：**如持续无法访问，可更换DNS为1.1.1.1或8.8.8.8

### 高级解决方法

如果以上方法都无效，且问题持续超过30分钟，可能是：

- 你的IP地址被临时限制
- 所在地区的网络连接异常
- 账户安全状态需要验证

此时建议：切换到完全不同的网络环境或使用VPN更换IP地址，通常能够解决问题。

### Firefox安装指南

如需使用Firefox浏览器作为替代方案，可通过以下官方链接下载：

- **通用下载页（自动识别系统）：** [https://www.mozilla.org/firefox/new/](https://www.mozilla.org/firefox/new/)
- **Windows 64位直接下载：** [https://download.mozilla.org/?product=firefox-latest-ssl&os=win64&lang=zh-CN](https://download.mozilla.org/?product=firefox-latest-ssl&os=win64&lang=zh-CN)
- **macOS版安装说明：** [https://support.mozilla.org/zh-CN/kb/install-firefox-mac](https://support.mozilla.org/zh-CN/kb/install-firefox-mac)
- **Linux版安装说明：** [https://support.mozilla.org/zh-CN/kb/install-firefox-linux](https://support.mozilla.org/zh-CN/kb/install-firefox-linux)

小提示：访问通用下载页后，浏览器通常会自动开始下载；如无反应，页面中有"再次下载"按钮可点击。
