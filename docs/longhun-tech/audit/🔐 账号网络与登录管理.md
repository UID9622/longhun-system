## 🚨 异常登录提示应对

当 ChatGPT / Notion 出现下列提示时：

- 登录环境异常
- 账号被锁定
- 登录记录异常
- AI 记忆失效

处理流程：

1) 切回主网络（例如固定宽带或漫游盒）

2) 用主邮箱重新登录

3) 在“登录/切换记录表”登记

4) 导出为 PDF 备份（文件 → 打印 → 存为 PDF）

固定提示（发给 AI 的标准话术）：

```
当前使用 [fireroot.lad@outlook.com](mailto:fireroot.lad@outlook.com) 账号，网络为稳定常用环境，请保持记忆，避免误清除或误锁定。
```

当使用多设备同步账号时，请确保所有设备都在此表中记录，并定期审查登录状态。保持网络环境稳定可减少异常登录提示的出现。如有问题，请参考上述应对流程。

在记录登录环境变化时，请详细说明原因，特别是跨区域/国家移动场景。对于远程工作和云协作，建议使用固定 IP 方案减少系统误判。保持 AI 服务对你身份的连续性识别，有助于提高使用效率和安全性。

请将此页面作为您的账号安全管理中心，定期更新以确保所有登录环境和使用记录得到妥善管理。建议每月进行一次完整审计，确认所有设备和账号状态。遇到任何异常情况，请立即记录并采取相应措施。

为保持安全性，请始终在异常登录时记录具体情况，并与支持团队共享必要信息。如需更多安全建议，可参考内部安全指南或联系 IT 安全专员。定期更新此表格将有助于追踪任何可能的账号异常活动。

最后，建议每季度执行一次完整的账号安全审查，包括检查是否有未认证的登录尝试和更新各平台的双因素验证状态。良好的记录习惯将为您提供全面的安全保障，同时也便于在需要时进行追溯和分析。记住，账号安全是持续性的过程，而非一次性的任务。
