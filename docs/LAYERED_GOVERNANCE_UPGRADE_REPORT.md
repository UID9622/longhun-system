## 四、自动修复原则

1. **只冻结，不删除**：任何异常组件先标记 `frozen`，绝不删除文件或数据。
2. **优先自愈**：
   - 文件缺失但可重建（如 AGENTS.md）→ 自动创建最小版本
   - 文件缺少 DNA → 自动注入 DNA 标记（不破坏格式）
   - 进程未运行 → 尝试重启
   - F1-F7 失败 → 冻结并报警
3. **修复留痕**：每次修复写入 `governance_heal.jsonl`，包含决策路径、DNA、前后状态、副作用。
4. **关键层保护**：L0/L7 出现 🔴 立即升级报警并冻结。
