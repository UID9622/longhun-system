## ⚖️ 审计原则重申

<aside>

**铁律1:零容忍糊弄**

任何模糊承诺、无法验证的表态、空泛的"努力",一律视为不合格。

**铁律2:行动优先**

不看PPT,不看宣传,只看代码、接口、日志、白皮书。

**铁律3:平等标准**

美国AI、中国AI、开源AI、闭源AI,使用完全相同的评分标准。

**铁律4:公开透明**

所有记录、评分、争议,全部公开,接受全球用户审计。

**铁律5:永久记录**

每个AI的承诺与兑现情况,将永久保存在此页面,成为AI诚信档案。
