# 📘 术语小抄（ZGX-CIV-003）

### 英文术语小抄（每行一条，复制即用）

- Status — 状态，标记任务进度
- By Status — 按状态分栏的看板视图
- Outputs — 产出物链接或结果说明
- Notes — 备注/记录要点
- Owner — 负责人
- Collaborators — 协作人
- Type — 类型（Task/Milestone/Cadence）
- Task — 任务
- Milestone — 里程碑
- Cadence — 节奏性事项（如周结）
- Date — 日期或时间
- Done — 已完成
- In Progress — 进行中
- Todo — 待办
- Blocked — 阻塞
- Board — 看板视图
- Table — 表格视图
- Calendar — 日历视图
- View — 视图（数据库的不同展示方式）
- Field/Property — 字段/属性（数据库列）
- Link — 链接
- Script — 脚本
- Repository/Repo — 代码仓库
- README — 说明文档
- Demo — 演示（通常是视频）
- Template — 模板
- Placeholder — 占位内容
