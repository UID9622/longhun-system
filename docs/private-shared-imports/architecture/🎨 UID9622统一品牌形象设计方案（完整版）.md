    - 适合：头像生成

    - 网址：[`canva.com`](http://canva.com)
    - 优点：在线编辑，有模板
    - 适合：背景墙、签名图

### 付费工具（更好）

1. **Midjourney**
    - 效果最好
    - 适合所有设计

Midjourney 不是下载软件，而是通过 Discord 使用的在线服务。使用步骤：

1. **注册 Discord 账号**
    - 访问 [discord.com](https://discord.com) 注册
2. **加入 Midjourney**
    - 访问 [midjourney.com](https://midjourney.com)
    - 点击 "Join the Beta" 加入他们的 Discord 服务器
3. **订阅付费计划**
    - 在 Discord 中输入 `/subscribe` 命令
    - 选择合适的订阅计划（基础版约 $10/月）
4. **开始使用**
    - 在 Discord 频道中输入 `/imagine` 命令
