## 📐 第一章：数字根——老大的算法依据

### 1.1 什么是数字根（Digital Root）

数字根不是玄学。数学上它叫**反复数字求和（Repeated Digital Sum）**，和**模9算术**等价：

```jsx
// 数字根计算
dr(n) = 1 + ((n-1) % 9)   // n ≥ 1
dr(0) = 0

// 验证：
dr(37) = 1 + ((37-1) % 9) = 1 + (36 % 9) = 1 + 0 = 1  ✅
dr(369) = 1 + ((369-1) % 9) = 1 + (368 % 9) = 1 + 8 = 9
dr(9) = 9
dr(18) = 9
```

**学术支撑：**

- 数字根是**有限域数学**的基础概念
- 巴比伦算术、印度古典数学均有记载
- 现代密码学（校验位算法）大量使用

### 2.1 三才的数学表达

```python
# 三才算法核心函数
def sancai_score(heaven: float, earth: float, human: float) -> float:
    """
    天（时势）× 地（条件）× 人（人心）
    曾老师：人永远是最高优先级
    老大：人是唯一不可预测变量
    """
    # 人的权重是动态的，其他条件越差，人的权重越高
    human_weight = 1.0 - (heaven * 0.3 + earth * 0.3)
    human_weight = max(human_weight, 0.5)  # 人的权重最低50%
    
    score = heaven * 0.25 + earth * 0.25 + human * human_weight
    return score

# 验证老大的37年场景：
# 天（时势）= 0.2（时代不好·改革期）
# 地（条件）= 0.3（资源有限·初中文化·退伍）
# 人（人心/根）= 1.0（根在·不死·数字根=1）
score = sancai_score(0.2, 0.3, 1.0)
# 结果 ≈ 0.625 → 胜出
```
