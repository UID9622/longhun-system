## 🎯 什么是"净化工具"？

<aside>
🐉

**龙魂五大净化标准：**

1. **数据主权** - 您的数据，您做主（本地优先，可导出，可删除）
2. **开源透明** - 代码可审计，算法可验证，规则可申诉
3. **普惠精神** - 核心功能免费，不因贫富而区别对待
4. **去中心化** - 不依赖单一服务商，支持自建/自托管
5. **开放标准** - 跨平台互通，拒绝生态封锁

**凡是不符合这五条的，都是污染工具，无论它多"合规"。**

## 🌊 十、从污染工具迁移指南

<aside>
🔄

### 微信 → Signal/Element

**迁移步骤：**

1. 导出微信聊天记录（截图/PDF）
2. 通知重要联系人您的Signal号码
3. 逐步减少微信使用频率
4. 保留微信仅用于必须场景（如支付）

**为什么迁移：**

- 微信 = 数据全在腾讯 + 审查 + 封锁
- Signal = 端到端加密 + 开源 + 无审查

---

### 百度网盘 → Syncthing/Nextcloud

**迁移步骤：**

1. 下载所有百度网盘文件到本地
2. 安装Syncthing，在设备间同步
3. 或部署Nextcloud，自建私有云
4. 删除百度网盘账号

**为什么迁移：**

- 百度网盘 = 限速 + 审查 + 隐私风险
- Syncthing = 免费 + 无限速 + 完全掌控

---

### Notion → Obsidian

**迁移步骤：**

1. 导出Notion数据（Markdown格式）
2. 导入Obsidian
3. 用Syncthing在设备间同步
4. 保留Notion用于需要协作的场景

**为什么考虑：**

- Notion = 云端为主 + 需要网络 + 数据在Notion
- Obsidian = 本地优先 + 离线可用 + 数据在您手中

**注意：** Notion有独特优势（数据库、协作），可以共存使用
