<aside>
🛡️

本标准适用于「📚 Knowledge Blocks（知识库）」的全部条目入库与维护，确保合规、可溯源、可复用、可迭代。

</aside>

### 1. 授权与许可（机构许可为前置条件）

- 必填要素
    - 官方主体名称与官网链接
    - 版权或授权声明链接（或页面原文截图/引用）
    - 许可类型：专有授权｜开放许可（标明 CC、MIT、Apache-2.0 等）｜公共领域
    - 许可范围：复制、改编、商业使用、署名/相同方式共享等条款
    - 获取时间与获取方式（人工核验｜自动抓取）
- 记录位置
    - Source：记录机构名 + 授权摘要
    - Link：指向原文 URL
    - 正文首段建「许可与来源」小节，粘贴关键条款原文与截屏（如有）
- 不满足机构许可要求的内容，Reliability 标记为「存疑」并禁止状态进入「已完成」

### 2. 抓取范围与排除

- 包含：
    - 首页、一级栏目、二级文档详情页、官方文档与技术白皮书、规范标准、FAQ、开发者门户
    - 官方发布的 PDF、规范文档、API Reference
- 排除：
    - 用户评论区、论坛回帖、广告着陆页、站内搜索结果列表、未经核验的第三方转载
    - 动态内容无法稳定复现的页面（除非有固定版链接或存档）
- 附加策略：
    - 对 PDF/规范，优先引用可验证的固定版本；必要时附 Wayback 或官方版本号

### 3. 结构化字段映射（与数据库统一）

- Title：精准概括主题，避免口号式标题
- Topic：
    - 技术：协议、API、算法、实现细节
    - 流程：SOP、操作步骤、治理流程
    - 资源：工具、链接、清单
    - 经验：最佳实践、踩坑与对比
    - 创意：方法论、模型框架
    - 人格：与 AI 人格协作相关知识
- Reliability：
    - 已验证：有权威出处 + 逻辑自洽 + 复核通过
    - 高质量：来源可靠且实用价值高
    - 标准级：符合入库要求的规范内容
    - 优化中：正在完善和提升的内容
- Priority：
    - 核心：跨场景关键，影响系统认知或能力边界
    - 重要：常用能力或高复用条目
    - 一般：辅助信息
    - 参考：背景材料
- Status：收集中 → 整理中 → 已完成｜需更新｜已废弃
- 日期：
    - Created At：首次入库日期
    - Last Updated：最后一次实质性更新
- Access Level：对条目负责与可见范围（如仅系统中枢）

### 4. 技术逻辑一致性审核清单

- 概念定义：是否有清晰边界，是否与系统现有术语冲突
- 论证链路：前提 → 推理 → 结论是否自洽，有无偷换概念
- 证据层级：标准/法规 > 官方文档 > 学术出版 > 行业白皮书 > 高可信媒体 > 个人博客
- 适用条件：是否明确前置条件、环境、版本依赖
- 反例排查：是否存在主流对立观点或新进展需要标注
- 可复现性：是否可通过步骤或代码重现
- 输出要求：在正文末尾添加「一致性审查结论」与「未决问题」

### 5. 引用与版本管理

- 每个结论段落后附原文链接或脚注；多个引用合并集中列出
- 对 PDF/规范，记录版本号、发布日期、页码或章节号
- 页面顶部维护「版本记录」：时间 + 修改要点 + 修改人

### 6. 入库流程（标准作业）

1) 收集：创建条目，填 Link、Source，Status=收集中，Reliability=待验证

2) 合规核验：补全机构许可要素；不满足则标「存疑」并停止流转

3) 结构化整理：抽取要点，按 Topic 标注，形成要点清单与图表（如需）

4) 逻辑审查：按审核清单打勾，形成「审查结论」

5) 评级与优先级：设置 Reliability 与 Priority

6) 完成与交付：Status=已完成；如存在时效性，设置「需更新」提醒

### 7. 质量门槛（必须满足）

- 有明确机构许可与出处
- 关键结论有证据可追溯
- 逻辑链路清晰且可复核
- 字段完整且与数据库规范一致

### 9. 安全与隐私

- 不采集个人敏感信息；如不可避免，进行去标识化或跳过入库
- 遵循网站 robots 与使用条款，不进行绕过性抓取

### 10. 变更与维护

- 出现新版本或政策变更，优先更新「许可与来源」与「一致性审查结论」
- 重大修订需在版本记录中说明理由与来源

### 11. 公共内容限定（新增）

- 仅抓取对公众开放的内容；任何需要注册、登录、验证码、付费账户或令牌才能访问的页面一律不抓取与不入库
- 如页面在未登录可见、登录后内容更丰富的场景，仅以未登录公开部分为准
- 对于「预览页」或「节选」内容，必须明确标注为节选，并在许可与来源中说明完整内容的获取条件
- 若发现抓取目标触发登录或权限墙，直接跳过并在条目中记录为「跳过原因：权限受限」；Reliability 维持「待验证」或「存疑」且 Status 不得进入「已完成」
