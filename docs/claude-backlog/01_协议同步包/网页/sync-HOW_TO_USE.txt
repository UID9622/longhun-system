[关于"被渲染了读取不到"的问题]

老大原话: "不要被渲染了读取不到"

这个问题的根源:
  - Notion 用富文本 + emoji + 特殊 Unicode
  - markdown 渲染器把 emoji 转换或丢失
  - 终端 (zsh) 显示 emoji 不全或乱码
  - 复制粘贴时 emoji 变成 ??? 或被吃掉

本包的解决方案:
  1. 全部用纯文本 .txt · 不靠 markdown 渲染
  2. 徽记同时提供两版:
     原版: #CONFIRM_9622-ONLY-ONCE_LK9X-772Z (带 emoji)
     ASCII 版: #CONFIRM_9622-ONLY-ONCE_LK9X-772Z (纯文本)
  3. 五色用字母代号: G/Y/R/K/AU (不依赖 emoji)
  4. 龍 字保留繁体 (这个必须 · 是字符律)

终端如果连繁体龍都显示不出来 · 用 LONG (拼音) 临时替代
但 markdown 母稿里必须仍是繁体龍
