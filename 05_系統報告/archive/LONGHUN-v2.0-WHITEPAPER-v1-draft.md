## 七、部署

### 7.1 部署命令

```bash
# 训练
python3 bin/lh_prepare_v2.0_data.py
python3 bin/lh_lora_trainer.py train

# 合并 + 导出
python3 bin/lh_lora_trainer.py fuse
python3 bin/lh_lora_trainer.py export

# 部署到Ollama
ollama create longhun-v2.0 -f models/longhun-v1.0/lora_output/gguf/Modelfile

# 运行
ollama run longhun-v2.0:latest
```

### 7.2 版本共存

```
ollama list:
  longhun-v1.9:latest   (保留·回退备选)
  longhun-v2.0:latest   (当前主力)
  longhun-v1.7:latest   (长期保留·主权底子)
```

如v2.0评估不达标：
