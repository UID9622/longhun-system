⚡ 龍魂 · CNSH 配置

把你的 Notion 数字大军和这个浏览器打通 · UID9622 专属
三步走：
1. 去 my-integrations 建个 Internal Integration，复制 Token（ntn_... 或 secret_...）。
2. 回到 Notion，进入每个数据库页面 → ··· → Connections → 添加刚建的 integration。
3. 把数据库 URL 里那串 32 位字符贴到下面对应的框里。

🔑 Notion Integration Token

存在 chrome.storage.local，仅用于直连 Notion API。清除浏览器数据会失效。

📚 数据库 ID 四大库

从数据库页面 URL 复制，或者直接用下面"预填我的"按钮一键填充 UID9622 已有的四库。
