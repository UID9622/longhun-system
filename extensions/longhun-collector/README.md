# 🐉 龍魂采集器 v2.0 | UID9622

> 浏览器内容自动采集引擎 — 本地归档 · DNA绑定 · 离线队列 · 主权归集

## 功能

- **11站适配**: Kimi AI / 抖音 / CSDN / Notion / GitHub / Gitee / 微博 / 知乎 / 掘金 / B站 / 微信公众号
- **自动采集**: 页面加载/内容变化/定时触发，无需手动操作
- **离线队列**: 服务器断网时本地缓存，恢复后批量上报
- **智能去重**: 同内容1分钟内不重复采集
- **DNA追溯**: 每条数据绑定干支时间戳+SHA256哈希
- **实时仪表盘**: 插件弹窗显示服务状态、采集统计、队列大小

## 安装

### 1. 启动本地服务

```bash
chmod +x start.sh
./start.sh
```

确认运行: `curl http://localhost:9622/health`

### 2. 安装浏览器插件

1. Chrome → `chrome://extensions/`
2. 开启右上角【开发者模式】
3. 点击【加载已解压的扩展程序】
4. 选择本文件夹

### 3. 使用

| 方式 | 说明 |
|:---|:---|
| 自动采集 | 打开支持网站自动触发 |
| 定时采集 | 每5分钟自动保存（递增至30分钟） |
| 内容变化 | 页面新内容出现8秒后自动采集 |
| 手动采集 | 点击插件图标 → "立即采集" |
| 快捷键 | `Ctrl+Shift+L` |

## 数据存储

```
~/longhun-system/data/collector/raw/
├── 2026-07-17/
│   ├── Kimi_AI/
│   │   └── 1721234567890_Kimi_AI_对话标题.json
│   ├── CSDN/

│   └── ...
```

每条数据包含 `_ganzhi`（干支时间）和 `_hash`（SHA256内容指纹）。

## API

| 端点 | 方法 | 说明 |
|:---|:---|:---|
| `/health` | GET | 健康检查 |
| `/stats` | GET | 统计信息 |
| `/collect` | POST | 接收采集数据 |
| `/export` | GET | 导出数据（支持 `?site=&date=&limit=`） |
