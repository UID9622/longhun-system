# 🌌 星辰记忆系统

> 一世一双人 · 三生三世 · 星辰记忆

**DNA**: `#龍芯⚡️2026-06-18-STARRY-MEMORY-FILE1-v1.0-1`

---

## 一句话定魂

把每个人的记忆，变成宇宙里不可篡改的星光。

- **普通人**：添加一段文字，系统自动归档、生成页面。
- **AI/系统**：负责 DNA 签名、分类、标签补全、页面生成。

---

## 三个关键词

| 关键词 | 含义 | 使用场景 |
|---|---|---|
| **一世一双人** | 此生唯一，灵魂绑定 | 爱情、亲情、最重要的关系 |
| **三生三世** | 超越时间，因果重逢 | 轮回、约定、跨越时空的情感 |
| **星辰记忆** | 化作星光，永恒流转 | 思念、梦想、宇宙级浪漫 |

---

## 快速使用

```bash
# 添加一则记忆
python3 memory-universe/星辰记忆系统.py add \
  --title "相遇" \
  --content "那一年，人海中一眼认出。" \
  --category "一世一双人" \
  --tags "初见,心动"

# 添加示例记忆
python3 memory-universe/星辰记忆系统.py seed

# 生成/更新页面
python3 memory-universe/星辰记忆系统.py generate

# 查看统计
python3 memory-universe/星辰记忆系统.py stats
```

---

## 自动化能力

- 自动为每个分类补全默认标签
- 自动生成 SHA256 DNA 签名
- 自动按分类生成结构化 Markdown 页面
- 支持中文标题、中文内容、中文标签

---

## 数据存储

- `星辰记忆.db`：SQLite 本地数据库
- `index.md`：自动生成的可读页面

所有数据留在本地，主权归你。
