## 这是什么？

龍魂系统是一套**中国人制造、中文原生、公开透明、不跪资本**的智能生态。

它不是某个公司的产品，也不是为了融资上市。它是为普通人服务的工具：**你不用懂英文、不用懂代码，也能用上 AI。**

---

## 核心特点

| 特点 | 说明 |
|---|---|
| **中文原生** | 从协议到代码到界面，全部中文优先 |
| **全透明** | 源代码开放，每次改动都有操作日志 |
| **不跪** | 不向科技巨头低头，数据归用户自己 |
| **普惠** | 为老人、农民、工人、退伍老兵等普通人设计 |
| **多模态** | 语音、图像、文字都能处理 |
| **可追溯** | 每个文件、每次操作都有 DNA 编号 |

---

## 本版新增功能

### v5.1 自主版

1. **龍魂生态实时仪表盘**
   - 可视化系统架构图
   - 实时显示 CPU、内存、磁盘消耗
   - 自动发现所有可运行模块

2. **龍魂协议（大白话版）**
   - 不用法律术语，普通人看得懂
   - 明确数据主权、透明、不跪、普惠

3. **多模态能力**
   - 语音合成（文字转语音）
   - 图像文字识别（OCR）
   - 语音转文字（需安装 whisper）

4. **龍魂操作日志**
   - 每次改动来源、去向、逻辑、责任全部留痕
   - 无黑箱，不免责，可追溯

## 怎么用？

### macOS 用户

1. 双击桌面上的 `龍魂主开关.app`
2. 在菜单里选择想用的功能
3. 点一下即可启动

### 其他用户

1. 确保已安装 Python 3.10+
2. 进入对应模块目录
3. 按各模块 README 说明启动
