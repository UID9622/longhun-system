## What is this?

LongHun System is an intelligent ecosystem **made in China, native to the Chinese language, fully transparent, and independent of big-tech control**.

It is not a corporate product. It is not built for fundraising or IPO. It is a tool for ordinary people: **you do not need to know English or code to use AI.**

## How to use

### macOS users

1. Double-click `龍魂主开关.app` on the desktop
2. Choose a function from the menu
3. Click once to launch

### Other users

1. Make sure Python 3.10+ is installed
2. Enter the module directory
3. Follow the README in each module
