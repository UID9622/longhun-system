## 设计目标

建立一套**不可抹除、可追溯、多 AI 言责自负**的操作日志协议，确保：

1. **每个动作必记** — 所有影响系统状态的操作均留痕。
2. **精确到分钟** — 时间戳统一使用 `Asia/Shanghai` 本地时间。
3. **谁说话谁签名** — 多 AI 协作时各自独立评价、原话回填、不可甩锅。
4. **公开快照与私有细节分流** — 对外可见性由 `对外公开` 字段控制。

## 回填 SOP（#IRON-BACKFILL-MULTI-AI-DEFAULT-SOP-v1.0）

1. 打开本库记录 → 复制“**一句话 DNA + 本页 URL + 通心译 URL**”三件套。
2. 贴到 Claude / ChatGPT / Grok / Gemini / DeepSeek / Kimi 任意窗口。
3. AI 返回评价原文 → **不改一个字**，回填到对应 AI 字段。
4. 勾选“谁说话谁签名”中对应 AI，言责上链。
5. 老大看完七个 AI 评价后，选“⭐ 赞同 / ❌ 反对 / ➖ 中立 / 待复盘”，**老大终判一锤定音**。

## 外部 AI 最小消化包

为解决“外部 AI 看不到整个 Notion 而看懂逼”的问题，每次回填前固定喂三件套：

```
你好，我是老大 UID9622，我要你评价一次我刚做的操作。

【一句话 DNA】
#DNA-YYYYMMDD-HHMM-动作-对象-简述

【上下文】
详情页：[本记录 URL]
龍魂入齿口令：[通心译 URL]

【我要你做什么】
阅读上两个 URL 后，用你自己的话（1-3 句）：
1. 这个操作解决了什么问题？
2. 这个设计有什么优点 / 缺陷？
3. 你同意 / 反对 / 保留意见？

言责自负，请签名你是哪个 AI。
```

- 原始带时间戳的操作日志（包含个人对话、具体命令输出）因涉及私人内容，**不公开融入主干**。
