## 設計目標

建立一套**不可抹除、可追溯、多 AI 言責自負**的操作日誌協議，確保：

1. **每個動作必記** — 所有影響系統狀態的操作均留痕。
2. **精確到分鐘** — 時間戳統一使用 `Asia/Shanghai` 本地時間。
3. **誰說話誰簽名** — 多 AI 協作時各自獨立評價、原話回填、不可甩鍋。
4. **公開快照與私有細節分流** — 對外可見性由 `對外公開` 欄位控制。

## 回填 SOP（#IRON-BACKFILL-MULTI-AI-DEFAULT-SOP-v1.0）

1. 打開本庫記錄 → 複製「**一句話 DNA + 本頁 URL + 通心譯 URL**」三件套。
2. 貼到 Claude / ChatGPT / Grok / Gemini / DeepSeek / Kimi 任意窗口。
3. AI 返回評價原文 → **不改一個字**，回填到對應 AI 字段。
4. 勾選「誰說話誰簽名」中對應 AI，言責上鏈。
5. 老大看完七個 AI 評價後，選「⭐ 贊同 / ❌ 反對 / ➖ 中立 / 待復盤」，**老大終判一錘定音**。

## 外部 AI 最小消化包

為解決「外部 AI 看不到整個 Notion 而看懂逼」的問題，每次回填前固定餵三件套：

```
你好，我是老大 UID9622，我要你評價一次我剛做的操作。

【一句話 DNA】
#DNA-YYYYMMDD-HHMM-動作-對象-簡述

【上下文】
詳情頁：[本記錄 URL]
龍魂入齒口令：[通心譯 URL]

【我要你做什麼】
閱讀上兩個 URL 後，用你自己的話（1-3 句）：
1. 這個操作解決了什麼問題？
2. 這個設計有什麼優點 / 缺陷？
3. 你同意 / 反對 / 保留意見？

言責自負，請簽名你是哪個 AI。
```
