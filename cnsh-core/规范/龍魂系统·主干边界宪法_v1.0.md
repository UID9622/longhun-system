## ⚡ 审计规则（自动执行）

### 规则 R1：主干代码白名单扫描

```python
# 每次提交前自动运行
MAIN_TRUNK_PATHS = {
    "_work/longhun-modules/longhun-algo-lab",
    "_work/web/assets/cpp模型"
}

ALLOWED_EXTENSIONS = {
    # Swift主干
    "_work/longhun-modules/longhun-algo-lab": [".swift", ".json", ".plist"],
    # C++主干
    "_work/web/assets/cpp模型": [".cpp", ".h", ".c", ".hpp"]
}

def audit_main_trunk():
    for path in MAIN_TRUNK_PATHS:
        for file in walk(path):
            ext = file.suffix
            if ext not in ALLOWED_EXTENSIONS[path]:
                raise VetoAlert(f"违规文件在主干: {file}")
```

### 规则 R2：分支代码调用审计

```python
# 检查分支代码是否试图直接修改主干
FORBIDDEN_OPERATIONS = {
    # 分支代码禁止
    "import/require": ["longhun-algo-lab", "cpp_to_cnsh"],
    "subprocess.call": ["swift", "swiftc"],
    "os.system": ["clang++", "gcc"],

def audit_branch_code():
    for file in branch_files:

        for op, forbidden in FORBIDDEN_OPERATIONS.items():

```

## 🚨 L7 熔断规则（强制回滚）

### 触发条件

任何以下情况发生 → **立即触发熔断**：

1. **主干路径污染**
   ```bash
   文件出现在主干目录但不是允许的类型
   → 自动删除该文件
   → 回滚到上一个有效快照
   ```

2. **签名验证失败**
   ```
   代码签名无效或过期
   → 拒绝加载该库
   → 运行时异常终止
   ```

3. **DNA链断裂**
   ```
   文件缺少DNA标记或确认码
   → 将文件标记为"不可信"
   → 所有调用该文件的操作失败
   ```

4. **运行时注入检测**
   ```
   检测到试图从分支代码注入主干
   → 立即终止该进程
   → 记录到审计日志
   → 触发警报
   ```

### 回滚过程

```swift
// 熔断器实现
struct FuseFallback {
    static func rollback(toSnapshot: Date) {
        let backup = loadSnapshot(toSnapshot)

        // 1. 验证快照完整性
        guard verifySnapshotIntegrity(backup) else {
            fatalError("Snapshot corrupted - cannot rollback")
        }

        // 2. 恢复文件
        restoreFilesFromSnapshot(backup)

        // 3. 重新验证主干
        guard verifyMainTrunk() else {
            fatalError("Main trunk verification failed after rollback")
        }

        // 4. 记录事件
        logFuseEvent(reason: "Manual rollback triggered", timestamp: Date())

        // 5. 重启应用
        NSApplication.shared.terminate(nil)
    }
}
```
