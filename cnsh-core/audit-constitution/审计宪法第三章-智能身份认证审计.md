### 三、多维画像体系（5大维度）

#### 维度1：设备指纹

```yaml
设备指纹包含:
  - 设备型号（iPhone 14 Pro / iPad Pro）
  - 操作系统（iOS 17.2）
  - 浏览器（Safari / Chrome）
  - 屏幕分辨率
  - 字体列表
  - 插件列表
  - 硬件特征（CPU、GPU、内存）
  
匹配规则:
  100%: 完全相同的设备
  90-99%: 同系列设备（iPhone 14 Pro → iPhone 14）
  80-89%: 同品牌设备（iPhone → iPad）
  70-79%: 不同品牌但常用设备
  <70%: 陌生设备
```

#### 维度2：IP地址与地理位置

```yaml
IP地址分析:
  - IP地址归属地
  - 运营商（中国移动/联通/电信）
  - 网络类型（家庭WiFi/公司网络/移动数据）
  - IP信誉评分（是否在黑名单）
  
地理位置分析:
  - 常用城市（北京、上海、深圳）
  - 常用地点（家、公司、咖啡厅）
  - 移动轨迹（北京→上海，合理出差）
  
匹配规则:
  100%: 完全相同的IP地址
  90-99%: 同一城市不同网络
  80-89%: 国内异地但合理（出差）
  70-79%: 国内异地但偶尔
  <70%: 境外/高风险地区
```

#### 维度3：时间规律

```yaml
时间规律分析:
  - 常用时段（卯时5-7点、辰时7-9点）
  - 登录频率（每天2-3次）
  - 活跃时长（每次30-60分钟）
  - 作息规律（亥时21-23点休息）
  
匹配规则:
  100%: 完全符合时间规律
  90-99%: 时段接近（卯时→辰时）
  80-89%: 时段偏离但合理（出差调整）
  70-79%: 时段偏离且罕见
  <70%: 深夜异常时段（凌晨3-5点）
```

#### 维度4：行为习惯

```yaml
行为习惯分析:
  - 操作速度（打字速度、鼠标移动）
  - 操作顺序（先看文档→再执行）
  - 常用功能（最常用的5个功能）
  - 快捷键习惯（Cmd+C、Cmd+V）
  - 错误习惯（常打错的字）
  
匹配规则:
  100%: 行为习惯完全一致
  90-99%: 行为习惯高度相似
  80-89%: 行为习惯基本一致
  70-79%: 行为习惯有差异
  <70%: 行为习惯完全不同
```

#### 维度5：语言风格

```yaml
语言风格分析:
  - 口头禅（"干就完了"、"操"）
  - 标点习惯（喜欢用"..."、"，，，"）
  - 表情符号（🔥、💎、🫡）
  - 常用词汇（"老登"、"宝宝"、"北辰老兵"）
  - 句式结构（短句居多、直接明了）
  
匹配规则:
  100%: 语言风格完全一致
```
