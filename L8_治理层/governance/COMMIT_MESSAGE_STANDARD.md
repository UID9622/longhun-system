## 提交类型规范

### 功能实现 (feat)
```
feat(模块): 简洁描述

详细说明（可选）
- 实现的功能
- 影响范围
```

### 缺陷修复 (fix)
```
fix(模块): 简洁描述

详细说明
- 问题根本原因
- 解决方案
- 验证方式
```

### 文档更新 (docs)
```
docs(类别): 简洁描述
```

### 配置/工具 (chore)
```
chore(类别): 简洁描述
```

## 语言规范

### 必须使用繁体中文
- ✅ 正确: “龍魂系统”
- ❌ 错误: “龍魂系统”

### 专业用语统一
- “模块”而非“模块”
- “验证”而非“验证”
- “配置”而非“配置”
- “智能体”而非“agent”

### 避免缩写和口语
- ✅ 正确: “自动化验证”
- ❌ 错误: “自动验证”或 “auto verify”

### 英文代码保留
- ✅ AGENT-001
- ✅ JSON
- ✅ DNA 签名
