# 🐉 龍魂系統 · 一鍵啟動指南 v1.0

## 📌 快速開始

### 方式 1️⃣：互動菜單（推薦）
```bash
~/longhun-system/bin/一键启动.sh
# 或使用別名
启动
龙启
```
🎯 **優點**：視覺化菜單，無需記住命令

---

### 方式 2️⃣：直接啟動（跳過菜單）
```bash
# 人格代理
人格启动

# 全系統啟動
全启

# 系統健康檢查
体检

# IP 偽裝
IP伪装 light    # VPN 輕度
IP伪装 medium   # 中度（Anthropic 註冊）
IP伪装 off      # 關閉

# Fish Audio
鱼音
```

---

### 方式 3️⃣：快速啟動腳本
```bash
~/longhun-system/bin/快速启动.sh [service]

# 可用服務
./快速启动.sh persona       # 人格代理
./快速启动.sh services      # 龍魂操作台
./快速启动.sh gateway       # 網關
./快速启动.sh benchmark     # 測試
./快速启动.sh report        # 報告
./快速启动.sh full          # 全啟動
./快速启动.sh health        # 檢查
```

| 服務 | 命令 | 說明 |
| --- | --- | --- |
| 人格代理 | `人格启动` | 啟動 12 大人格 CNSH 身份 |

| 評分報告 | `./快速启动.sh report` | 生成報告 |
| 全啟動 | `全启` | 一鍵啟動所有核心服務 |
| 健康檢查 | `体检` | 系統狀態 |

## 💡 進階用法

### 在後台啟動（不阻塞終端）
```bash
全启 &
```

### 查看運行中的服務進程
```bash
ps aux | grep -E "mcp-mini|api-gateway|Fish"
```

### 停止所有龍魂服務
```bash
services stop-all
# 或手動
pkill -f "mcp-mini|api-gateway"
```

### 清空日誌重新開始
```bash
rm -rf ~/.cnsh/logs/*
```

## 🐛 故障排除

### 問題：別名 (`龙启` 等) 無法使用
**解決**：
```bash
source ~/.zshrc
# 或重啟終端
```

### 問題：`services` 命令不存在
**解決**：
```bash
# 檢查是否安裝
which services

# 如未安裝，手動啟動
python3 ~/longhun-system/server/mcp-mini.py &
python3 ~/longhun-system/server/api-gateway.py &
```

### 問題：API 網關未響應 (localhost:8080)
**解決**：
```bash
# 檢查進程
ps aux | grep api-gateway

# 查看日誌
tail -f ~/.cnsh/logs/api-gateway.log
```
