```markdown
## 中文贡献指南

### 🚀 快速开始

1. **Fork** 本仓库
2. **克隆**到本地：`git clone https://github.com/你的用户名/项目名.git`
3. **安装依赖**：
```

pip install -e ".[dev]"  # Python项目


# 或

npm install              # Node.js项目


```javascript
4. **创建分支**：`git checkout -b feature/你的功能名`
5. **开发·测试·提交**
6. **发起 Pull Request**

### 📋 分支命名规范

| 类型 | 格式 | 示例 |
|---|---|---|
| 新功能 | `feature/功能名` | `feature/add-wuxing-api` |
| Bug修复 | `fix/问题描述` | `fix/calculation-overflow` |
| 文档 | `docs/文档名` | `docs/update-readme-cn` |
| 性能优化 | `perf/优化描述` | `perf/reduce-memory-usage` |
| 重构 | `refactor/模块名` | `refactor/core-algorithm` |

### 💬 Commit 规范（Conventional Commits）

```

类型(范围): 简短描述（50字以内）

[可选详细描述]

[可选关联Issue: Closes #123]


```javascript

**类型说明：**
- `feat`: 新功能
- `fix`: 修复Bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `test`: 测试相关
- `chore`: 构建/工具配置

**示例：**
```

feat(wuxing): 添加五行对冲指数H计算

实现显性对冲公式：H = 克制衡×0.30 + 疏导×0.25 + ...

三色阈值：🟢≥0.80 / 🟡0.50-0.80 / 🔴<0.50

Closes #42


```javascript

## English Contributing Guide

### 🚀 Quick Start

1. **Fork** this repository
2. **Clone** locally: `git clone https://github.com/your-username/project.git`
3. **Install dependencies**: `pip install -e ".[dev]"`
4. **Create branch**: `git checkout -b feature/your-feature-name`
5. **Develop · Test · Commit**
6. **Open a Pull Request**

### 💬 Commit Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):
```

type(scope): short description

[optional body]

[optional footer: Closes #123]


```javascript

### 🌍 Language Policy

- **Code & Comments**: English preferred for international accessibility
- **Issues & PR**: Any language welcome (we'll translate if needed)
- **Documentation**: Bilingual (Chinese + English) encouraged

### 📜 Code of Conduct

We are committed to providing a welcoming and inclusive environment.
All contributors are expected to be respectful and constructive.
```

## 🌍 新手友好提示（Beginner-Friendly Notes）
