## 模板说明

- **适用**：部署脚本、Docker/Podman 配置、监控设置、备份恢复
- **部署入口**：`deploy/scripts/DEPLOY.md` — 鲲鹏从零到跑起十步法
- **监控脚本**：`deploy/scripts/monitor_setup.sh` — systemd+cron+告警
- **健康检查**：`deploy/scripts/health_check.sh` — Bark推送+飞书备用+自愈
- **环境模板**：`deploy/.env.kunpeng.example` — 含Bark Key + 飞书Webhook
- **Bark推送双模式**：
  | 模式 | 地址 | 状态 |
  |------|------|:---:|
  | 自建华为云 | 119.13.90.27:8080 | 主力 |
  | 官方 | api.day.app | 备用 |
- **安全原则**：
  - `.env` → .gitignore 覆盖
  - API密钥 → 环境变量，不硬编码
  - 部署 → GPG签名验证
  - 数据库 → S3国密加密

## 命令模板

```bash
# 部署前检查
python3 bin/lh_memory_load.py
bash deploy/scripts/health_check.sh --pre-deploy

# 部署
bash deploy/scripts/deploy.sh --env kunpeng

# 部署后验证
bash deploy/scripts/health_check.sh --verify

# 回滚（如需要）
bash deploy/scripts/rollback.sh --version v1.0
```
