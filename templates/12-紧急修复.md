## 模板说明

- **适用**：紧急Bug修复、安全漏洞修补、服务崩溃恢复、数据修复
- **紧急级别分类**：

| 级别 | 符号 | 定义 | 响应时间 | 审批 |
|:---:|:---:|------|:---:|:---:|
| 🟡 警告 | WARNING | 功能异常但核心可用 | 4小时 | 自决 |
| 🟠 严重 | CRITICAL | 核心功能受损 | 1小时 | 自决 |
| 🔴 灾难 | CATASTROPHIC | 系统不可用/数据泄露 | 立即 | 自决 |

- **修复原则**：
  1. 最小改动 — 能改1行不改10行
  2. 精准定位 — 不改无关代码
  3. 先止血 — 快速恢复服务再排查根因
  4. 留后路 — 修复前保留原始内容便于回滚
  5. 不跨线 — 紧急也不能绕过底座锚点和三色审计

- **修复后检查清单**：
  - [ ] 原问题是否解决
  - [ ] 是否引入新问题 (回归)
  - [ ] 三色审计是否通过
  - [ ] 底座锚点是否完整
  - [ ] Git diff 是否仅含必要改动
  - [ ] 审计日志是否记录
  - [ ] Bark 通知是否推送

- **回滚命令**：
  ```bash
  # 单文件回滚
  git checkout <commit> -- <file>
  
  # 全量回滚
  git revert <commit>
  ```
