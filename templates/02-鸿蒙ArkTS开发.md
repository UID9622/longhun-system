## 模板说明

- **适用**：鸿蒙 HarmonyOS NEXT ArkTS 应用开发
- **项目路径规范**：`integrations/harmonyos/<项目名>/entry/src/main/ets/`
- **目录结构约定**：
  ```
  entry/src/main/ets/
  ├── models/          # 数据模型 + @Observed 全局状态
  ├── engines/         # 业务引擎 (可选)
  ├── components/      # 可复用组件
  ├── pages/           # @Entry 页面
  ├── database/        # 数据库单例
  ├── entryability/    # UIAbility 生命周期
  ├── navigation/      # 导航控制
  └── router/          # 路由配置
  ```
- **数据本地**：不依赖云端 API · 端侧优先
- **暗色主题标准**：
  - 背景: `#0a0a0a` / 卡片: `#1a1a1a` / 次级: `#262626`
  - 主色: `#c41e3a` (龍魂红) / 成功: `#00cc66` / 警告: `#ff6600`
