## 三种使用方式

### 方式一：合订版一键使用（推荐）
- **桌面文件**：`~/Desktop/龍魂会话模板库_完整版.md`
- **项目文件**：`templates/ALL-IN-ONE.md`
- 12套模板合在一个文件里，带目录、带快捷标题映射，直接复制即可用。

### 方式二：标题自动命中
只发送一个标题，AI 根据关键词自动选择对应模板并执行。  
标题关键词映射见 `ALL-IN-ONE.md` 第 2 章「快捷标题映射」。

### 方式三：系统内自动路由
```bash
# 查看命中哪个模板
python3 bin/lh_template_match.py "鸿蒙 ArkTS 实战：项目里程碑时间线"

# 输出可直接复制给 AI 的完整提示
python3 bin/lh_template_match.py "鸿蒙 ArkTS 实战：项目里程碑时间线" --copy
```

### 方式四：单文件复制（传统）
复制 `01-通用开发.md` ~ `12-紧急修复.md` 中任意一个，在「当前任务」区填需求。

## 使用规范

1. **发送给外部 AI 时**：复制完整模板，在「当前任务」区域填写具体需求
2. **AI 收到后强制执行**：DNA锚定→身份验证→契约遵守→格式对齐
3. **输出必须包含**：DNA标识 + UID + 确认码 + 时间 + 模块计数
4. **禁止行为**：教学式说明、炫技推理、无价值展开、情绪带动
