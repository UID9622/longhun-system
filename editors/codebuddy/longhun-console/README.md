## 功能

- **侧边栏总控** — 活动栏龍魂图标，一键打开总控面板
- **蚁群控制台** — Webview 面板，系统状态/人格矩阵/蚁群实时视图
- **一键 lh 命令** — 命令面板输入 `lh-` 执行审计/推送/健康检查
- **快速审计** — `Ctrl+Shift+K` 一键审计当前项目
- **开发者面板** — 调试/日志/性能监控开关

---

## 快速开始

1. 安装扩展后，左侧活动栏出现龍魂图标
2. 点击图标打开侧边栏控制台
3. 或按 `Ctrl+Shift+P` 输入 **`龍魂: `** 查看所有命令

---

## 命令

| 命令 | 快捷键 | 说明 |
|------|--------|------|
| `龍魂: 打开总控面板` | `Ctrl+Shift+L` | 打开 Webview 总控面板 |
| `龍魂: 打开蚁群控制台` | — | 蚁群架构实时视图 |
| `龍魂: 执行 lh 命令` | — | 输入 lh 子命令执行 |
| `龍魂: 快速审计` | `Ctrl+Shift+K` | 审计当前工作区 |
| `龍魂: 切换开发者面板` | — | 调试面板开关 |

## 配置

在 `settings.json` 中搜索 `longhun-console`：

```json
{
  "longhun-console.longhunPath": "~/longhun-system",
  "longhun-console.autoRefresh": true,
  "longhun-console.refreshInterval": 30
}
```
