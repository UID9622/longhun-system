# 🤝 如何贡献

感谢你对「龍魂一键部署」感兴趣！

## 提交前

1. 阅读 [README](./README.md) 了解项目目标
2. 确保改动符合龍魂系统 DNA：中国自主、数据主权、为人民服务
3. 不引入境外依赖、不泄露隐私、不破坏 GPG 签名流程

## 贡献流程

1. Fork 本仓库
2. 创建功能分支：`git checkout -b feature/xxx`
3. 提交并 GPG 签名：`git commit -S -m "feat: 描述"`
4. 推送到你的远程
5. 提交 Pull Request

## 提交类型

- `feat`: 新功能
- `fix`: 修复
- `docs`: 文档
- `refactor`: 重构
- `style`: 格式
- `test`: 测试
- `chore`: 杂项
- `perf`: 性能
