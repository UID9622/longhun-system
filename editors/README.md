# 龍码中文编辑器 v1.0

> 没有黑箱，代码全部公开。中文就是变量名，中文就是注释，中文就是逻辑。

**DNA**: `#龍芯⚡️2026-06-18-LONGHUN-CHINESE-EDITOR-FILE1-FILE1-v1.0-1`

---

## 为什么要做中文编辑器

国外的编辑器再好，也是国外语境长出来的。
龍码中文编辑器只做一件事：让中国人用中文思维写代码。

- 中文变量名
- 中文注释
- 中文菜单
- 中文运行日志

每个国家的语言都能跑在计算机里面，那才叫牛逼。

---

## 功能

- 新建 / 打开 / 保存 / 另存为
- 撤销 / 重做 / 剪切 / 复制 / 粘贴
- 运行 Python 脚本（F5）
- 运行选中的 Shell 命令
- 输出面板与状态栏
- 自动保存提示

---

## 启动方式

### 桌面 App

`~/Desktop/龍码中文编辑器.app`

双击即可启动。

### 命令行

```bash
cd ~/longhun-system
python3 editor/龍码编辑器.py
```

---

## 快捷键

| 快捷键 | 功能 |
|---|---|
| Cmd+N | 新建 |
| Cmd+O | 打开 |
| Cmd+S | 保存 |
| Cmd+Z | 撤销 |
| Cmd+Shift+Z | 重做 |
| F5 | 运行 Python |

---

## 技术说明

- 使用 Python 标准库 `tkinter`，无外部依赖。
- 字型使用 macOS 内建 `PingFang SC`，中英文等宽体验良好。
- 代码语法仍是 Python，但变量名、函数名、注释全部支持中文。
