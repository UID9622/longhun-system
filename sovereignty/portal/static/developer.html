📚 API 文档

龍魂系统对外提供三类能力：身份认证、模型路由、知识库与图谱。所有接口均通过 https://longhun888.com 访问，返回 JSON。模型 API 密钥由服务器端持有，前端无需也不应暴露密钥。

快速开始

curl https://longhun888.com/health curl https://longhun888.com/api/docs curl https://longhun888.com/api/models

身份认证

POST/issue
签发魂灵ID通行令牌。请求体 {"身份证编号":"...","有效期小时":24}。身份证编号在本地哈希，服务端不保存原始编号。
POST/verify
服务商验证令牌。请求体 {"令牌":{...},"服务商名称":"...","服务类型":"..."}。
POST/register
服务商接入注册。

模型路由

GET/api/models
列出本地 Ollama、Kimi API、Azure OpenAI 的在线状态与模型列表。
POST/api/chat
统一对话入口。默认策略：本地 Ollama → DeepSeek → Kimi → Azure。可显式指定 provider 或 privacy=strict 强制本地。
POST/api/embed
文本嵌入，本地优先。

知识库与图谱

GET/api/archive/docs?q=...&category=...&element=...&audit=...
中央藏经阁公开文档列表，支持关键词、类别、五行、审计等级过滤。
GET/api/knowledge/search?q=...
检索 dragon_knowledge.db 代码收割记录。
GET/api/graph/nodes
知识图谱全部节点。
POST/api/graph/query
节点子图查询。请求体 {"node_id":"doc:...","depth":1}。
