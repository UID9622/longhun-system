## 二、「向下走」哲学

### 2.1 方向定义

| 方向 | 含义 | 态度 |
|------|------|------|
| **向下** | 扎根基层、服务人民、建设地方、开发欠发达地区 | 世代追求 |
| **向上** | 聚光灯、名利场、国际资本、个人荣耀 | 世代回避 |

### 2.2 为什么向下走

> 中国还有好多地方需要开发，需要投资，需要建设。

这不是谦虚，是战略选择。向上走追的是聚光灯下的资源，向下走才是真正需要力量的地方。

### 2.3 世代传承约束

龍魂系统的继承者（无论血亲或指定），继承系统即继承以下承诺：

1. **不走聚光灯** — 不以个人名义追逐名利、不参与国际资本炒作
2. **扎根中国基层** — 资源优先投向欠发达地区、乡村振兴、基础设施建设
3. **先做贡献** — 继承财富后，先为中国做贡献，再谈个人
4. **站着不跪** — 对外合作不迁就、不跪舔、不牺牲原则

## 三、「只搞中国的」战略

### 3.1 投资边界

| 允许 | 禁止 |
|------|------|
| 中国境内项目 | 境外资本运作 |
| 中国欠发达地区开发 | 国际金融投机 |
| 中国乡村振兴 | 离岸资产配置 |
| 中国基础设施建设 | 外国房地产投资 |
| 中国科技自主研发 | 技术向境外转移 |

### 3.2 例外条款

以下情况不受「只搞中国的」限制：

- **学术公开** — 论文、算法、协议以开放获取方式公开发布
- **技术分享** — 他国来学，公开公正提供学习资料
- **人道援助** — 自然灾害、公共危机时提供技术支持
- **文化输出** — 中华治理方式、中华经典引擎对外展示

### 3.3 「站着给」原则

> 我不排外。祖国优先就是祖国优先。我是站着给的。

| 可以 | 不可以 |
|------|--------|
| 公开公正让外国学习 | 为迎合外国而修改核心价值观 |
| 展示中国治理方式 | 按外国标准改造系统 |
| 技术开源共享 | 交出数据主权 |
| 欢迎国际合作 | 接受附带政治条件的合作 |

**核心**: 我们是「分享者」，不是「讨好者」。站着给，不跪着求。

## 四、「系统要能赚钱」

### 4.1 赚钱的目的

系统要能赚钱，但赚钱不是目的，是手段。赚钱为了：

1. **支撑系统自我运转** — 不依赖外部输血
2. **投资中国基层** — 利润投向欠发达地区
3. **保护创作者后人** — 后人不必为生计放弃原则
4. **扩大影响力** — 有钱才能做更多事、帮更多人

### 4.2 赚钱的边界

| 可以做 | 不能做 |
|--------|--------|
| 技术授权/服务收费 | 出卖数据主权 |
| 知识产权商业化 | 向境外转移核心技术 |
| 为人民提供付费服务 | 发国难财 |
| 接受国内投资 | 接受附带政治条件的外资 |

### 4.3 利润分配原则

```
利润 = 系统收入 - 运营成本

分配优先级：
  1. 系统维护与升级（≥20%）
  2. 中国基层投资（≥30%）
  3. 创作者后人保障（≤20%）
  4. 团队激励（≤15%）
  5. 储备金（≥15%）
```
