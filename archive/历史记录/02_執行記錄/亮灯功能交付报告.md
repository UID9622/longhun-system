## 二、Web 操作台集成

在 `control-panel` 中新增了一套 REST API：

| 方法 | 路径 | 说明 | 请求示例 |
|------|------|------|----------|
| GET | `/api/behavior/{uid}/profile` | 获取用户六大维度画像 | — |
| GET | `/api/behavior/{uid}/display` | 获取对外亮灯展示 | — |
| POST | `/api/behavior/{uid}/record` | 记录一条行为 | `{"类型":"服务","名称":"帮邻居修水管","权重":4.0}` |
| POST | `/api/behavior/{uid}/light` | 设置维度亮灯开关 | `{"维度":"服务分","开关":true}` |

### 新增/修改文件

- `control-panel/api/behavior_wrappers.py` — 操作台业务封装
- `control-panel/main.py` — 注册 4 个行为 API 路由

### 本地接口测试通过


## 三、Notion 同步集成

新增同步脚本：

- **文件**：`brain/behavior_notion_sync.py`
- **功能**：读取本地所有行为数据，把每个用户的六大维度分数、行为总数、亮灯维度同步到 Notion 数据库
- **模式**：
  - `python3 behavior_notion_sync.py` — 单次同步
  - `python3 behavior_notion_sync.py --watch` — 每 5 分钟轮询
  - `python3 behavior_notion_sync.py --status` — 查看本地数据状态

### Notion 数据库属性要求

脚本会自动写入以下属性，建议在 Notion 中创建对应数据库：

| 属性名 | 类型 |
|--------|------|
| 用户ID | Title |
| 环保贡献 | Number |
| 信誉分 | Number |
| 互动质量 | Number |
| 服务分 | Number |
| 习惯分 | Number |
| 真实度加权总分 | Number |
| 行为总数 | Number |
| 亮灯维度 | Multi-select |
| 同步时间 | Date |

### 环境变量

```bash
export NOTION_TOKEN="your_integration_token"
export BEHAVIOR_DB_ID="your_database_id"
```

### 同步逻辑

- 已存在用户页面 → `PATCH` 更新
- 不存在 → `POST` 新建
- 带指数退避重试与 3 req/s 限流
