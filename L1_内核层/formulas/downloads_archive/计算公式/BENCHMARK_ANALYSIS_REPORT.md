## 💡 性能优化与审计的权衡

### v2.0 的设计哲学

```
核心目标：审计完整性 > 绝对性能

理由：
  1. 龍魂系统需要完整可追踪性
  2. DNA 链签章不可省略
  3. 性能已充分（< 0.01ms/决策）
  4. 审计成本 < 优化收益

如需最大性能：
  → set_config("enable_audit_log", False)
  → 牺牲可追踪性
  → 性能提升 400x+（某些场景）
```
