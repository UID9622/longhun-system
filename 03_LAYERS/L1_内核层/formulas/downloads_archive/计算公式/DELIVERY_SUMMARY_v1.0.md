## 🎯 四大公式详解

### 公式 A：五行平衡指数（Balance Index）

**功能**：衡量五行分布的均匀程度

**公式**
```
Balance Index = 100 - (σ / avg × 100)

其中：
  σ = √[Σ(score - avg)² / 5]
  avg = total / 5
```

**输出范围**：0-100

**三色映射**
```
 95-100 🟢 完美均衡（可直接推进）
  80-94 🟢 良好均衡（推进·监控）
  60-79 🟡 可接受（需观察补益）
  40-59 🟡 需调整（加补益·加审计）
   0-39 🔴 严重失衡（熔断或重算）
```

**龍魂映射**
```
🟢 (>80)  → L2-L4 正常流动
🟡 (40-79) → L2 审计层·加控制
🔴 (<40)  → L0 熔断层·禁止进入
```

---

### 公式 B：相生相克强度（GR Strength）

**功能**：衡量五行间的制约关系

**三个指标**

1. **相生强度**（Generation）
   ```
   G(A→B) = score(B) / [score(A) + score(B)]
   ```

2. **相克强度**（Restriction）
   ```
   R(A⇒B) = min(score(A), score(B)) / score(A)
   ```

3. **净强度**（Net）
   ```
   Net(A) = G(A) - R(A)
   ```

**龍魂映射**
```
Net(A) > 0.3  🟢 生大于克·可顺利推进
0 ≤ Net ≤ 0.3 🟡 生克均衡·需维护
Net(A) < 0    🔴 克大于生·需加审计
```

---

### 公式 C：三才平衡系数（Sancai Coefficient）

**功能**：融合天·地·人三个维度

**公式**
```
C = Heaven × 0.35 + Earth × 0.20 + Human × 0.45
```

**铁律**
```
✋ Human ≥ 0.34（人永远不低于 34%）

违反时：自动提升到 0.34·其余按比例缩放·记为 🟡 待审
```

**龍魂映射**
```
C ≥ 0.75  🟢 三才合一·进入 L3+
0.50-0.75 🟡 三才不全·需补证
C < 0.50  🔴 三才缺失·熔断
```

---

### 公式 D：复合决策强度（Composite Strength）·[新]

**功能**：融合公式 A/B/C 的综合决策强度

**公式**
```
Strength = A_norm × 0.35 + GR_norm × 0.30 + C × 0.35

其中：
  A_norm = Balance / 100
  GR_norm = (1 - avg_restriction)  # 相克越强·威力越大
  C 已是 0-1
```

**置信度判定**
```
Strength ≥ 0.80  🟢 高置信度（≥0.80）
0.60-0.79        🟡 中置信度（0.60-0.79）
Strength < 0.60  🔴 低置信度（禁用）
```
