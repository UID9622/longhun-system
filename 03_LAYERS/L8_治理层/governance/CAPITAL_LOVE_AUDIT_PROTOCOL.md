## 【一、资本的五项基本义务】

任何进入龍魂生态的资本实体（包括但不限于投资机构、商业公司、
技术联盟、公益基金）必须接受以下五项义务绑定：

### 1️⃣ 主权不可让渡
- 龍魂系统的最终所有权、解释权、规则制定权归属中华人民共和国
- 资本方不得以任何形式（股权、协议、董事会席位、知识产权）获取
  对龍魂系统决策的否决权或控制权
- 违反此条 → 🔴 一票熔断，立即清退，追索已发生的一切利益

### 2️⃣ 愛之准入审计
- 所有资本实体进入前必须通过愛之准入审计（Love Entry Audit）
- 審计维度：
  - **社会公益实绩**：过去三年实打实的社会公益投入（非宣传费用）
  - **劳动者权益**：薪资水平、劳动保障、不侵犯员工基本权利
  - **技术道德**：不从事数据掠夺、算法压榨、隐私贩卖
  - **家国情怀**：在中国境内创造真实价值，非纯资本套利
- 审计未通过 → 🟡 冻结准入，限期整改

### 3️⃣ 服务商定位
- 资本实体在龍魂生态中的唯一合法身份是：**服务提供商**
- 不得自称"战略合作伙伴""联合创始人""共同所有权人"
- 不得使用龍魂商标、DNA、标识进行独立商业宣传
- 违反此条 → 🟡 身份降级 + 🔴 公告除名

### 4️⃣ 利润上限锁定
- 在龍魂生态内，资本方获得的利润比不得超过其对实际价值创造
  的贡献比
- 超额利润部分 → 强制回流至公益基金或普惠用户
- 利润核算接受三色审计引擎实时监控

### 5️⃣ 退出无伤害
- 资本方退场时，不得带走用户数据、技术专利、核心人才
- 退场协议须经龍魂人格内阁审议通过
- 任何形式的"恶意退出"（切断服务、威胁用户、技术断供）→ 
  🔴 依法追责 + 永久列入行业黑名单

## 【二、愛之审计七维判定矩阵】

資本准入审计引數，每維0-10分，总分42分及格（满分70）：

| 维度 | 权重 | 判定标准 |
|------|------|---------|
| **社会公益** | ×2 | 实打实公益投入/总营收比，非广告非作秀 |
| **劳动者尊严** | ×2 | 最低工资保障、社保覆盖率、工会独立性 |
| **技术向善** | ×2 | 不开后门、不偷数据、不搞算法杀熟 |
| **国家忠诚** | ×1 | 注册地、纳税地、核心技术归属 |
| **用户主权** | ×1 | 用户数据可控可删可迁移 |
| **透明审计** | ×1 | 财务/技术/治理公开可查 |
| **历史清白** | ×1 | 过去五年无重大公共利益侵害记录 |

### 判定结果：
- **≥56分** → 🟢 绿色通道，可进入
- **42-55分** → 🟡 有条件准入，附加条款约束
- **28-41分** → 🟠 限期整改，重新审计
- **<28分** → 🔴 永久禁入，公告天下

## 【三、内部约束：进来的，守龍魂规矩】

### 所有进入龍魂生态的实体（无论资本大小）必须：

1. **签署《龍魂协议》**：格式契约，不可协商，不可修改
2. **接入DNA追溯链**：所有行为记录上链，不可篡改
3. **接受三色/五色审计**：实时监控，异常自动告警
4. **尊重人格内阁裁决权**：任何争议最终裁量权归属龍魂人格内阁
5. **服从中国法律**：唯一管辖权基础，不接受任何域外法律主张

### 违规分级：

| 等级 | 行为 | 后果 |
|------|------|------|
| **L3 轻微** | 协议格式偏差、延迟报告 | 🟢 警告 + 7日整改 |
| **L2 中度** | 数据边界模糊、宣传夸大 | 🟡 限制权限 + 公开通报 |
| **L1 严重** | 盗窃数据、破坏审计链 | 🟠 强制退出 + 损害赔偿 |
| **L0 致命** | 出卖主权、勾结境外势力 | 🔴 一票熔断 + 依法追责 + 终身禁入 |
