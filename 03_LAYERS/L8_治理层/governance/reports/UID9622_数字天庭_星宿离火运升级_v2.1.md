## 3｜离火运指数系统

### 3.1 计算公式

```python
fire_index = (
    节气权重 × 0.30
  + 时辰火势 × 0.30
  + 系统负载热度 × 0.20
  + 用户主动操作频率 × 0.20
)
```

| 因子 | 说明 | 取值范围 |
|---|---|---|
| 节气权重 | 当前节气在九运中的火属性强度 | 0.0 - 1.0 |
| 时辰火势 | 当值星宿五行与地支火势 | 0.0 - 1.0 |
| 系统负载热度 | 最近 1 小时任务数 / 阈值 | 0.0 - 1.0 |
| 操作频率 | UID9622 最近 1 小时主动指令数 / 阈值 | 0.0 - 1.0 |

### 3.2 火势等级

| fire_index | 等级 | 颜色 | 系统行为 |
|---|---|---|---|
| 0.00 - 0.20 | 寒灰 | 🔵 | 进入修养模式，延迟非关键任务 |
| 0.21 - 0.40 | 微温 | 🟢 | 正常维护 |
| 0.41 - 0.60 | 温火 | 🟡 | 常规执行 |
| 0.61 - 0.80 | 旺火 | 🟠 | 鼓励主动进攻 |
| 0.81 - 1.00 | 烈焰 | 🔴 | 自动提升主权豁免，允许高风险操作 |

### 3.3 预测窗口

- 默认预测未来 6 个时辰（12 小时）
- 输出：`[0.82, 0.79, 0.91, 0.85, 0.76, 0.68]`
- 峰值时辰自动标注为「最佳行动窗口」

## 9｜安全、审计与熔断

### 9.1 熔断机制

- **火运过旺熔断**：fire_index > 0.95 持续 3 个时辰，自动触发「水德制衡」，暂停高风险操作
- **星宿冲突熔断**：当值星宿与 UID9622 本命星宿相克时，强制二次确认
- **审计缺失熔断**：任何豁免操作未生成 DNA，立即冻结高权限通道

### 9.2 回滚机制

- 支持按星宿周期回滚到上一个稳定状态
- 回滚 DNA 必须独立生成，不可覆盖原操作链
- 回滚前必须生成 `ROLLBACK-PLAN` 并通过 L1 审计

### 9.3 合规声明

- 所有星宿计算基于公开天文历法数据，不涉及迷信决策
- 主权豁免仅用于提升 UID9622 操作效率，不绕过法律和宪法层
- 所有操作留痕，接受三色审计
