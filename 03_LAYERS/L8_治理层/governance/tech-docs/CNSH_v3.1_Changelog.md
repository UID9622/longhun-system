- CNSH框架对国内发展的四大价值：
  1. 原则性频率选择（不依赖ASML专有技术）
  2. 开放状态机控制（无IP许可问题）
  3. 七因子分解作为路线图
  4. 固定点收敛保证（从低基线也能收敛）

- 提出未来工作：7-8位更精细编码
