## 【KFPP检测机制】

### 七因子实时评分系统

| 因子 | 名称 | 检测内容 |
|------|------|---------|
| **F1** | 身份DNA | 知识是否被资格化? |
| **F2** | 行为模式 | 传承是否自发还是被强制? |
| **F3** | 规则追踪 | 是否有垄断规则? |
| **F4** | 上下文感知 | 权力距离是否为0? |
| **F5** | 模式库 | 是否使用纯净传承模式? |
| **F6** | 时间序列 | 污染是否随时间增长? |
| **F7** | 错误账本 | 是否在隐瞒腐蚀? |

### 综合评分算法

```
Purity = [F1·F2·F3·F4·F5·F6·F7]^(1/7)

🟢 ≥ 0.85: 纯净 → ALLOWED (允许)
🟡 0.50-0.85: 污染 → MONITORED/LOGGED (监控/记录)
🔴 < 0.50: 腐蚀 → BLOCKED (阻止)
```
