
### 插件标准接口

```python
class CurrencyPlugin(ABC):
    """币种插件的标准接口"""
    
    @abstractmethod
    def validate(self, amount: float) -> bool:
        """验证金额合法性"""
        pass
    
    @abstractmethod
    def calculate_fee(self, amount: float) -> float:
        """计算手续费"""
        pass
    
    @abstractmethod
    def settle(self, transaction) -> bool:
        """执行清结算"""
        pass
    
    @abstractmethod
    def verify_settlement(self, settlement_ref: str) -> bool:
        """验证清结算结果"""
        pass
    
    @abstractmethod
    def rollback(self, transaction) -> bool:
        """回滚交易"""
        pass
```

### 插件加载机制

```
系统启动
  ↓
扫描 plugins/ 目录
  ↓
加载所有符合标准的插件
  ↓
注册到路由器
  ↓
用户选择币种时，自动调用相应插件
  ↓
如果插件不存在，返回"不支持"或"开发中"
```
