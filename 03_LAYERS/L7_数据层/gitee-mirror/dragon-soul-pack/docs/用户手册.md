# DragonSoulPack 用户手册

## 1. 安装

```bash
git clone https://gitee.com/uid9622/dragon-soul-pack.git
cd dragon-soul-pack
bash scripts/install.sh
```

## 2. 启动

```bash
bash scripts/start_all.sh
```

## 3. 使用 CNSH 编写第一个程序

创建 `hello.cnsh`：

```cnsh
// #龍芯⚡️丙午·丙申·乙卯·丙戌·䷷旅-CNSH-HELLO-v1.0
定义 主函数() {
  打印("你好，鸿蒙！")
  返回 0
}
```

编译为 C：

```bash
node CNSH编译器/cnsh-compiler.js hello.cnsh
```

## 4. VS Code 插件使用

1. 打开 VS Code
2. 文件 → 打开文件夹 → 选择 `CNSH编辑器避坑插件/`
3. 按 F5 启动调试窗口
4. 在调试窗口中打开任意 `.cnsh` 文件
5. 保存时自动审计变量命名

## 5. 本地服务器

启动后，浏览器打开：

```
file://<你的路径>/UID9622本地服务器/index_v2.1.html
```

可查看龍魂控制台、智能中枢、鸿蒙入口。

## 6. 字体安装

### macOS

```bash
bash 字体支持/install_macos.sh
```

### Windows

双击 `字体支持/assets/LonghunFont-Regular.otf` 安装。

## 7. 常见问题

**Q: 编译报错找不到 Node.js？**  
A: 安装 Node.js 18+。

**Q: 插件没有语法高亮？**  
A: 确认文件扩展名为 `.cnsh`，且插件已激活。

**Q: 如何关闭服务器？**  
A: 在终端按 Ctrl+C，或执行 `kill <PID>`。
