# CNSH 编辑器避坑插件

为 CNSH 中文编程语言（.cnsh）提供 VS Code 支持：语法高亮、关键字补全、变量命名审计、一键编译为 C。

## 功能

- 语法高亮：中文关键字、注释、字符串、DNA 追溯码
- 智能补全：输入时提示 CNSH 关键字
- 变量命名审计：自动提醒「建议用中文语义命名，少用英文缩写」
- 一键编译：右键 → CNSH: 编译为 C

## 安装

```bash
# 本地调试
code --install-extension ./cnsh-editor-vscode-1.0.0.vsix
```

## 使用

1. 新建文件 `hello.cnsh`
2. 编写 CNSH 代码
3. 保存时自动审计变量命名
4. 右键 → CNSH: 编译为 C

