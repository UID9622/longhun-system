## 一、用途

龍魂协议图书馆（`library/protocols/`）是龍魂系统的**统一协议归集中心**。  
所有进入本馆的协议文件，无论来自 `01_protocols/`、`docs/private-shared-imports/` 还是其他历史目录，一经入馆即视为龍魂系统的**规范级文件**，受宪法层保护。

本馆承担以下职责：

1. **去重归一**：清除历史目录中重复、碎片化的协议版本；
2. **分层治理**：按 L0–L8 层级归档，便于检索与执行；
3. **DNA 统一追溯**：所有文件必须携带 `#龍芯⚡️` 系列 DNA 码；
4. **使用条款公示**：明确“可用、可引、不可擅自修改演绎”的原则。
