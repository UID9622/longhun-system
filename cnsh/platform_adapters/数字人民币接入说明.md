# 数字人民币 (e-CNY) 接入说明

**DNA**: `#龍芯⚡️2026-06-21-CNSH-eCNY-INTEGRATION-v1.0`

---

## 一、核心认知：数字人民币没有统一的公共 API

数字人民币由中国人民银行发行，采用“央行-指定运营机构”双层运营体系：

- **第一层**：人民银行对指定运营机构（商业银行、支付宝、微信支付等）
- **第二层**：运营机构面向个人/商户提供钱包服务

因此，作为普通开发者或商户，**无法直接调用人民银行的接口**，必须通过持牌运营机构接入。

---

## 二、可接入的持牌机构类型

| 类型 | 代表机构 | 适用场景 |
|------|----------|----------|
| 国有大型银行 | 工商银行、建设银行、农业银行、中国银行、邮储银行、交通银行 | 企业商户、对公账户 |
| 股份制银行 | 招商银行、兴业银行、微众银行、网商银行 | 互联网商户 |
| 第三方支付 | 支付宝、微信支付 | 已有这些渠道的小微商户 |
| 清算组织 | 银联、网联 | 聚合支付、跨机构清算 |

---

## 三、接入流程

### 步骤 1：成为签约商户

1. 准备营业执照、法人身份证、对公账户等资料
2. 选择一家支持数字人民币的银行或支付机构
3. 提交商户入驻申请，签署《数字人民币商户服务协议》
4. 通过 KYC/反洗钱审核

### 步骤 2：获取生产凭证

审核通过后，运营机构会提供：

- `APPID` / `商户号`
- `API网关地址`
- `商户私钥` + `平台公钥`（用于签名验签）
- `钱包编号` 或 `子钱包编号`

### 步骤 3：配置本系统

在 `数字人民币适配器` 中填入生产参数：

```python
from cnsh.platform_adapters.适配器管理器 import 适配器管理器

管理器 = 适配器管理器(模式="生产")
适配器 = 管理器.获取适配器("数字人民币")

# 切换到生产模式并设置密钥
适配器.切换到生产模式("你的商户私钥或API密钥")
```

同时修改 `_调用生产API` 方法，替换为真实机构的接口调用（HTTP + 国密 SM2/SM3 签名）。

### 步骤 4：对接具体能力

| 能力 | 本系统操作名 | 生产侧常见接口 |
|------|-------------|---------------|
| 查询余额 | `查询余额` | 钱包余额查询 |
| 绑定钱包 | `绑定钱包` | 子钱包绑定/开户 |
| 充值 | `充值` | 银行账户→数币钱包兑出 |
| 支付 | `支付` | 数币支付/退款 |
| 查询交易 | `查询交易` | 交易流水查询 |

## 四、与现有 XPay 网关的关系

当前系统已有两个支付相关组件：

- `~/.龍魂/xpay/` — 龍魂 XPay 本地支付网关（JSON 账本 + Flask API）
- `cnsh/platform_adapters/` — 平台适配器层（支付宝、微信、数字人民币等）

### 推荐架构

```
用户 / 前端
   ↓
龍魂 Web 控制台 / bin/龍魂体系v5-一键启动.py
   ↓
XPay 网关（统一订单、路由、对账）
   ↓
平台适配器管理器
   ↓
├── 支付宝适配器
├── 微信适配器
└── 数字人民币适配器  ← 你刚接入的
        ↓
    e-CNY 运营机构 API
```

即：XPay 负责“订单层”，适配器负责“渠道层”。

## 五、充值与支付流程示例

### 充值

1. 用户发起“充值 ¥500”
2. XPay 创建充值订单
3. 调用 `数字人民币适配器.执行操作("充值", {"金额": 500}, DNA令牌)`
4. 适配器先做 e-CNY 合规检查（限额、KYC、反洗钱）
5. 生产模式：调用银行“兑出”接口，从绑定银行卡扣款到 e-CNY 钱包
6. 返回流水号，XPay 更新用户余额

### 支付

1. 用户发起“支付 ¥88.88”
2. XPay 创建支付订单
3. 调用 `数字人民币适配器.执行操作("支付", {"金额": 88.88, "商户": "...", "订单号": "..."}, DNA令牌)`
4. 适配器检查余额充足 + 合规检查
5. 生产模式：调用运营机构“付款”接口
6. 返回交易流水号，XPay 标记订单已支付

## 六、合规要点

系统已内置 `cnsh/compliance_china/compliance_china/eCNY合规检查器.py`，每笔充值/支付前会自动校验：

- 实名认证与可控匿名原则
- 钱包类型对应的交易限额
- 反洗钱/KYC 要求
- 大额交易报告（≥ ¥50,000）
- 跨境交易央行审批
- 可疑交易上报

**注意**：合规检查器提供的是技术层面的规则校验，不能替代持牌机构的合规审核与法律意见。
