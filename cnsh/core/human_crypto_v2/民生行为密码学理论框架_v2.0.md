## 一、理論概述與核心原則

### 1.1 定義

**民生行為密碼學（Livelihood Behavior Cryptography, LBC）** 是一套基於社區自治的行為記錄與激勵框架。它不評價人，只記錄行為；不貼標籤，只積累信任；不用於金融授信，只用於社區治理。

### 1.2 五大核心原則

| 原則 | 說明 | 狀態 |
|------|------|------|
| **民生治理 ≠ 個人徵信** | 不記錄金融信用、不評分人格、不用於貸款/就業 | 🟢 |
| **只看行為，不看身份** | 行為歸因於事實，不關聯個人身份背景 | 🟢 |
| **只記善意，不記惡名** | 只記錄正向貢獻行為，負向行為不計入 | 🟢 |
| **自願參與權重高** | 強制行為V=0，自願行為V=1，半自願V=0.5~0.7 | 🟢 |
| **言論自由絕對保護** | 任何表達觀點、批評、建議均不計入行為檔案 | 🟢 |

### 1.3 與舊版公民畫像引擎的關係

舊版六大維度（環保貢獻15%/信譽分25%/互動質量15%/服務分30%/習慣分15%）過於簡單且易與徵信混淆。**LBC v2.0 完全取代舊體系**，引入：

- 五大行為分類（替代舊維度）
- 六大調節係數（V/C/T/F/R/D）
- 民生熔斷線機制（明確什麼不算）
- 社區自治導向（服務社區提案，而非個人評級）

## 二、民生行為五大分類

### 2.1 分類總表

```
┌──────────────┬─────────────────────────────────────────────────────────┐
│   分類代碼    │  分類名稱  │  核心定義  │  計分原則                    │
├──────────────┼─────────────────────────────────────────────────────────┤
│      A       │ 主動善意類  │ 無償幫助他人、主動提醒安全 │ 自發性越高，權重越高        │
│      B       │ 社區參與類  │ 組織/參與社區公共活動      │ 組織者得分高於參與者        │
│      C       │ 公共服務類  │ 以服務姿態提供公共職能      │ 超越職責標準才有得分        │
│      D       │ 文化共建類  │ 傳承傳統、文化普及、技藝傳授 │ 無償分享才有得分           │
│      E       │ 環境維護類  │ 環保行為、公共環境改善      │ 實際效果優於形式            │
└──────────────┴─────────────────────────────────────────────────────────┘
```

### 2.2 A_主動善意類

| 行為項 | 代碼 | 基礎權重 | 計分規則 |
|--------|------|----------|----------|
| 幫助弱勢群體 | A1 | 8.0 | 幫助老人/兒童/殘障人士，需受益者或第三方確認 |
| 安全提醒 | A2 | 6.0 | 主動提醒他人安全隱患，如交警碎碎念模式 |
| 失物歸還 | A3 | 7.0 | 拾金不昧、歸還失物，有接收方確認即可 |
| 緊急援助 | A4 | 10.0 | 突發事件中主動施救，最高權重，需多方見證 |
| 鄰里互助 | A5 | 5.0 | 日常鄰里間無償幫助，如代收快遞、照看孩子 |

**特別說明**：
- 所有A類行為必須是**自發的**，職責範圍內的行為不計入（如物業幫業主屬職責）
- 安全提醒（A2）特別保護：**即使是批評式的提醒也計分**，只要出發點是善意

### 2.3 B_社區參與類

| 行為項 | 代碼 | 基礎權重 | 計分規則 |
|--------|------|----------|----------|
| 公共活動組織 | B1 | 9.0 | 自發組織社區文化活動，如村口唱歌 |
| 公共活動參與 | B2 | 4.0 | 積極參與社區公共活動 |
| 社區議事參與 | B3 | 6.0 | 參與社區議事/聽證會，發言與否不影響得分 |
| 志願者服務 | B4 | 7.0 | 註冊志願者服務時長，按小時折算 |
| 社區調解 | B5 | 8.0 | 參與鄰里糾紛調解，成功與否不影響基礎分 |

**特別說明**：
- 組織者（B1）得分遠高於參與者（B2），鼓勵主動承擔
- 村口唱歌 → B1（組織者）+ D1（文化傳承，疊加）
- 參與社區議事時，**表達的觀點內容不計分，參與行為本身計分**

### 2.4 C_公共服務類

| 行為項 | 代碼 | 基礎權重 | 計分規則 |
|--------|------|----------|----------|
| 服務型執法 | C1 | 9.0 | 以服務態度執行公務，超越標準執法模式 |
| 公益服務 | C2 | 7.0 | 無償提供專業服務，如醫生義診、律師義諮 |
| 應急服務 | C3 | 10.0 | 應急救援/消防/醫療，非職責內的額外付出 |
| 交通疏導 | C4 | 6.0 | 非職責內主動疏導交通 |
| 知識普及 | C5 | 5.0 | 向公眾無償普及專業知識 |

**特別說明**：
- 交警碎碎念 → C1（服務型執法）+ A2（安全提醒，疊加）
- **職責內的標準服務V=0.3，超越標準的服務V=0.7，義務服務V=1.0**
- 服務型執法的核心是「選擇權留給對方」，非強制

### 2.5 D_文化共建類

| 行為項 | 代碼 | 基礎權重 | 計分規則 |
|--------|------|----------|----------|
| 文化傳承活動 | D1 | 8.0 | 組織傳統文化傳承活動 |
| 文化創作分享 | D2 | 6.0 | 創作並無償分享文化內容 |
| 技藝傳授 | D3 | 7.0 | 無償傳授傳統技藝 |
| 文化教育 | D4 | 6.0 | 開展文化教育活動 |
| 社區文化建設 | D5 | 8.0 | 推動社區文化品牌建設 |

**特別說明**：
- 村口唱歌的主分類是B1（組織），但可疊加D1（文化傳承）
- 文化創作分享的內容審查：**只確認「分享」行為，不審查內容觀點**

### 2.6 E_環境維護類

| 行為項 | 代碼 | 基礎權重 | 計分規則 |
|--------|------|----------|----------|
| 環保行動 | E1 | 7.0 | 參與環保公益活動 |
| 環境改善 | E2 | 8.0 | 實際改善公共環境質量 |
| 資源節約 | E3 | 5.0 | 踐行並推廣節約行為 |
| 生態保護 | E4 | 9.0 | 參與生態保護行動 |
| 綠色創新 | E5 | 8.0 | 提出環保創新方案並實踐 |

**特別說明**：
- 個人垃圾分類（無推廣）→ **不計分**，屬個人選擇
- 帶動鄰里一起垃圾分類 → E3（資源節約推廣）

## 三、核心計算公式（升級版）

### 3.1 符號體系

| 符號 | 名稱 | 取值範圍 | 說明 |
|------|------|----------|------|
| B | 基礎權重 | 3 ~ 10 | 由行為分類表確定 |
| V | 自願係數 | 0 ~ 1 | 強制=0，完全自願=1 |
| C | 社區驗證係數 | 0 ~ 1 | 多方見證=1，自說自話=0.1 |
| T(t) | 時間衰減函數 | 0.1 ~ 1 | 半衰期2年 |
| F(n) | 頻率調節因子 | 0 ~ 1 | 防止刷分 |
| R | 社區反響係數 | 0.8 ~ 1.2 | 受益人反饋微調 |
| S | 民生行為總積分 | 0 ~ ∞ | 所有有效行為加權和 |
| Θ | 社區信任度 | 0 ~ 1 | 非線性增長 |
| P | 提案優先級 | 0 ~ ∞ | 用於社區提案排序 |

---

### 3.2 公式一：民生行為權重公式 W

**核心公式**：

```
W_i = B_i × V_i × C_i × T(t_i) × F(n_i) × R_i
```

**民生行為總積分**：

```
S_total = Σ W_i  （對所有有效行為i求和）
```

#### 3.2.1 時間衰減函數 T(t)

```
T(t) = max(0.1, e^(-λt))，其中 λ = ln(2)/2 ≈ 0.347
```

半衰期 = 2年（2年後權重衰減為50%），最低保留10%。

| 時間 | T(t) |
|------|------|
| 0.5年 | 0.841 |
| 1年 | 0.707 |
| 2年 | 0.500 |
| 3年 | 0.353 |
| 5年 | 0.176 |
| 7年及以上 | 0.100（保底） |

#### 3.2.2 自願係數 V

| 類型 | V值 | 說明 |
|------|-----|------|
| 完全自願 | 1.0 | 無任何組織要求，純粹個人自發 |
| 半自願 | 0.7 | 有組織號召但不強制，可自由選擇 |
| 單位要求 | 0.3 | 單位/組織安排，但非強制性質 |
| 強制 | 0.0 | 法律/行政強制要求的行為 |

#### 3.2.3 社區驗證係數 C

| 證據等級 | C值 | 說明 |
|----------|-----|------|
| 多方見證+影像 | 1.0 | 多個獨立第三方+照片/視頻記錄 |
| 多方見證 | 0.8 | 多個獨立第三方口頭確認 |
| 單方+第三方確認 | 0.6 | 行為人申報+至少1個第三方確認 |
| 單方申報 | 0.3 | 僅行為人自己申報 |
| 自說自話 | 0.1 | 無任何佐證，孤證不立 |

#### 3.2.4 頻率調節因子 F(n)

```
F(n) = 1.0                    當 n ≤ 4
F(n) = min(1.0, 2/√n)       當 n > 4
```

| 年頻次 | F(n) | 說明 |
|--------|------|------|
| 1~4次 | 1.000 | 正常計分 |
| 6次 | 0.816 | 輕微遞減 |
| 8次 | 0.707 | 中等遞減 |
| 12次 | 0.577 | 明顯遞減 |
| 20次 | 0.447 | 大幅遞減 |
| 50次 | 0.283 | 嚴重遞減（疑似刷分） |

#### 3.2.5 社區反響係數 R

```
R = 1.0 + δ，其中 δ ∈ [-0.2, +0.2]
```

| 反饋情況 | R值 | 說明 |
|----------|-----|------|
| 廣泛好評 | 1.2 | 大量受益者正面反饋 |
| 一般好評 | 1.1 | 少數受益者正面反饋 |
| 無反饋 | 1.0 | 默認值 |
| 一般爭議 | 0.9 | 有爭議但不影響善意性質 |
| 較大爭議 | 0.8 | 爭議較大，需社區評議 |

#### 3.2.6 民生熔斷線（W_i = 0的絕對阻斷）

以下行為**絕對不計分**（W_i ≡ 0）：

| 熔斷類型 | 具體說明 | 狀態 |
|----------|----------|------|
| 強制行為 | V = 0 時，無論其他係數如何，W = 0 | 🔴 |
| 言論表達 | 任何觀點表達、批評、建議、演講、寫作 | 🔴 |
| 個人消費選擇 | 購買什麼、吃什麼、穿什麼、住哪裡 | 🔴 |
| 監督公權力 | 批評政府、監督官員、舉報腐敗 | 🔴 |
| 無法驗證 | C < 0.1（自說自話） | 🔴 |
| 商業行為 | 以營利為目的的服務 | 🔴 |
| 違法行為 | 任何違反法律的行為 | 🔴 |

### 3.3 公式二：社區信任度公式 Θ

```
              Θ = (1 - e^(-α·S_total)) × (1 + β·D) × γ
```

| 符號 | 說明 | 默認值 |
|------|------|--------|
| α | 靈敏度參數 | 0.05 |
| S_total | 民生行為總積分 | — |
| β | 多樣性權重 | 0.3 |
| D | 多樣性指數 = 有效行為類別數 / 5 | — |
| γ | 社區調節因子 | 0.8 ~ 1.0 |

#### 特性分析

1. **邊際遞減**：前期積分增長快，後期趨緩。積分10時Θ≈0.46，積分30時Θ≈0.92，積分50時達到上限
2. **多樣性激勵**：參與3類行為 → D=0.6 → 加成18%；參與5類 → D=1.0 → 加成30%
3. **社區調節**：由社區自治委員會評定γ值，異常情況可下調至0.8
4. **上限截斷**：Θ > 1.0 時截斷為1.0

#### 信任度對照表

| S_total | D=1/5 | D=3/5 | D=5/5 | 信任等級 |
|---------|-------|-------|-------|----------|
| 10 | 0.39 | 0.46 | 0.51 | 新人 |
| 30 | 0.78 | 0.92 | 1.00 | 活躍 |
| 50 | 0.92 | 1.00 | 1.00 | 資深 |
| 100 | 0.99 | 1.00 | 1.00 | 核心 |

### 3.4 公式三：提案優先級公式 P

```
              P_j = Θ_j × Q_j × (1 + ln(1 + S_relevant))
```

| 符號 | 說明 | 取值範圍 |
|------|------|----------|
| Θ_j | 提案人社區信任度 | 0 ~ 1 |
| Q_j | 提案質量分 | 0 ~ 1 |
| S_relevant | 提案人在該領域的相關行為積分 | 0 ~ ∞ |

#### 優先級分級

| 級別 | P值範圍 | 處理方式 | 狀態 |
|------|---------|----------|------|
| 高優先級 | P ≥ 0.8 | 快速通道，優先審議 | 🔴 |
| 中優先級 | 0.5 ≤ P < 0.8 | 標準審議流程 | 🟡 |
| 低優先級 | 0.2 ≤ P < 0.5 | 儲備池，定期回顧 | 🟢 |
| 不予立項 | P < 0.2 | 需積累信任或完善提案 | — |

#### 社區自治規則

1. **無門檻提交**：任何人都可以提交提案，不信任度門檻
2. **只影響排序**：優先級只影響審議速度和資源分配，不通過審批
3. **質量獨立**：Q_j由社區評審團獨立評定，不受Θ影響
4. **領域匹配**：S_relevant鼓勵「在自己做過的領域提建議」

### 4.2 道德綁架防護機制

| 防護層 | 機制 | 效果 |
|--------|------|------|
| **不排名** | 不公開個人積分排名，只顯示信任等級區間 | 防止攀比 |
| **不貼標籤** | 沒有「好人」「壞人」標籤，只有「活躍」「新人」等中性描述 | 防止標籤化 |
| **不強制** | 參與完全自願，不參與不影響任何權益 | 防止脅迫 |
| **不評價人格** | 只記錄行為，不推斷品格、動機、價值觀 | 防止道德審判 |
| **熔斷保護** | 批評、異議、表達觀點絕對不計入 | 防止言論歸因 |

### 4.3 言論自由保護條款

**第零條款：表達絕對自由**

以下行為**在任何情況下都不計入行為檔案**，無論內容是正面還是負面：

- 批評政府、政策、官員
- 發表政治觀點
- 在社交媒體發言
- 參與公共辯論
- 寫作、出版、藝術創作（無論內容）
- 舉報、投訴、上訪
- 參與遊行、集會、請願
- 宗教信仰表達

**核心原則**：LBC只看「做了什麼好事」，不看「說了什麼」。一個可以批評政府的人，同時可以是社區裡幫助老人的好人。這兩件事**完全獨立**。

### 4.4 數據使用範圍限制

| 使用範圍 | 是否允許 | 說明 |
|----------|----------|------|
| 社區提案排序 | ✅ 允許 | 核心用途 |
| 社區自治激勵 | ✅ 允許 | 如公共活動優先參與權 |

## 五、案例映射

### 5.1 案例一：村口夏日唱歌

#### 行為定性

| 維度 | 判定 |
|------|------|
| 主分類 | B1_公共活動組織（基礎權重 9.0） |
| 副分類 | D1_文化傳承活動（疊加權重 8.0×0.3） |
| 行為性質 | 完全自發、無償、開放參與 |

#### 參數取值

| 參數 | 取值 | 理由 |
|------|------|------|
| B | 9.0（主）+ 2.4（副） | 組織露天唱歌=公共活動，夏季休閒=文化傳承 |
| V | 1.0 | 完全自發，無任何組織攤派 |
| C | 0.8 | 村民多方見證，但無正式影像記錄 |
| T | 0.8407 | 假設半年內記錄 |
| F | 1.0 | 夏季每月約1次，年約4次，不觸發遞減 |
| R | 1.1 | 村民積極參與，氛圍良好 |

#### 計算過程

```
主項 W₁(主) = 9.0 × 1.0 × 0.8 × 0.8407 × 1.0 × 1.1
            = 6.6585

副項 W₁(副) = 8.0 × 0.3 × 1.0 × 0.8 × 0.8407 × 1.0 × 1.1
            = 1.7756

案例1總分 S₁ = 6.6585 + 1.7756 = 8.4341
```

#### 社區治理意義

- 村口唱歌是典型的**社區自組織行為**，體現了居民的主動性和凝聚力
- 通過LBC記錄，組織者獲得社區信任積累，未來提出相關文化提案時優先級更高
- 不強制要求記錄，但社區可以設立「好事登記點」方便村民主動登記

### 5.2 案例二：交警深夜碎碎念

#### 行為定性

| 維度 | 判定 |
|------|------|
| 主分類 | C1_服務型執法（基礎權重 9.0） |
| 副分類 | A2_安全提醒（疊加權重 6.0×0.3） |
| 行為性質 | 職責內行為，但方式超越標準 |

#### 參數取值

| 參數 | 取值 | 理由 |
|------|------|------|
| B | 9.0（主）+ 1.8（副） | 碎碎念執法=服務型執法，平和提醒=安全提醒 |
| V | 0.7 | 巡邏是職責（V=0.3基礎），但「碎碎念」方式超出標準，體現服務姿態 |
| C | 1.0 | 網絡廣泛傳播，多方見證+影像記錄 |
| T | 0.9659 | 近期事件 |
| F | 1.0 | 單次事件 |
| R | 1.2 | 網友廣泛點讚，被稱為「暖心執法」 |

#### 計算過程

```
主項 W₂(主) = 9.0 × 0.7 × 1.0 × 0.9659 × 1.0 × 1.2
            = 7.3022

副項 W₂(副) = 6.0 × 0.3 × 0.7 × 1.0 × 0.9659 × 1.0 × 1.2
            = 1.4604

案例2總分 S₂ = 7.3022 + 1.4604 = 8.7626
```

#### 社區治理意義

- 交警碎碎念是**公共服務的典範**，體現了「選擇權留給對方」的服務哲學
- 雖然是職責行為，但服務方式的超越標準獲得了V=0.7的認可
- 這類行為的記錄有助於形成「服務導向」的社區文化

### 5.3 兩案例對比分析

| 對比維度 | 村口唱歌 | 交警碎碎念 |
|----------|----------|------------|
| **行為分類** | B社區參與 + D文化共建 | C公共服務 + A主動善意 |
| **基礎權重B** | 9.0 + 8.0×0.3 = 11.4 | 9.0 + 6.0×0.3 = 10.8 |
| **自願係數V** | 1.0（完全自發） | 0.7（職責內超越） |
| **驗證係數C** | 0.8（村民見證） | 1.0（網絡影像） |
| **時間衰減T** | 0.8407 | 0.9659 |
| **頻率調節F** | 1.0000 | 1.0000 |
| **社區反響R** | 1.1 | 1.2 |
| **最終得分** | **8.4341** | **8.7626** |

#### 關鍵洞察

1. **分差原因**：交警碎碎念得分略高，主要因為C=1.0（網絡驗證）vs C=0.8（村民見證）。這說明社區驗證機制需要完善，鼓勵村民對「村口唱歌」這類好事進行簡易記錄。

2. **自願係數正確發揮作用**：完全自發（V=1.0）的村口唱歌在V項上勝過職責超越（V=0.7）的交警碎碎念，體現了「自願參與權重高」的設計哲學。

3. **兩者都是民生行為**：無論是村民自發的娛樂活動，還是公職人員的服務行為，只要體現了對社區的善意貢獻，都應被記錄和認可。

4. **言論自由保護驗證**：如果有人在村口唱歌時批評村委會工作，這個批評言論**絕對不計入**行為檔案。LBC只看「組織唱歌」這個行為，不看「說了什麼」。

### 7.2 實施流程

**第一步：行為發生**
- 居民做出善意行為（如組織村口唱歌）
- 行為自然發生，無需刻意「刷分」

**第二步：行為記錄（可選）**
- 行為人自行申報 或 第三方推薦
- 民生記錄站協助收集見證信息
- 記錄最小單元：時間、地點、行為類型、見證人

**第三步：社區驗證**
- 記錄站聯繫見證人確認
- 影像證據可提升C值
- 驗證周期：7個工作日

**第四步：積分計算**
- 系統自動按公式計算W_i
- 實時更新S_total和Θ
- 個人可查詢自己的積分（僅本人）

**第五步：提案應用**
- 居民提交社區改善提案
- 系統自動計算P_j優先級
- 評審團獨立評定Q_j
- 按優先級進入審議流程

### 7.3 隱私保護規範

| 保護項 | 措施 |
|--------|------|
| 數據所有權 | 行為數據歸本人所有，社區只代為記錄 |
| 查詢權限 | 本人可查詢全部，他人不可查詢個人積分 |
| 刪除權 | 本人可隨時要求刪除任何行為記錄 |
| 導出權 | 本人可導出全部行為記錄 |
| 轉移權 | 跨社區遷移時，可導出但不可直接轉入（各社區獨立） |
| 匿名統計 | 社區公開報告只顯示聚合數據，不顯示個人信息 |

```python
def calculate_behavior_weight(B, V, C, years, n_per_year, R=1.0):
    """計算單項行為權重"""
    # 民生熔斷檢查
    if V == 0 or C < 0.1:
        return 0.0
    
    # 時間衰減（半衰期2年）
    T = max(0.1, math.exp(-0.347 * years))
    
    # 頻率調節
    F = 1.0 if n_per_year <= 4 else min(1.0, 2.0 / math.sqrt(n_per_year))
    
    # 核心公式
    W = B * V * C * T * F * R
    return W

def calculate_trust_score(S_total, categories_active, gamma=1.0):
    """計算社區信任度"""
    alpha = 0.05
    beta = 0.3
    D = min(1.0, categories_active / 5.0)
    theta = (1 - math.exp(-alpha * S_total)) * (1 + beta * D) * gamma
    return min(1.0, theta)

def calculate_proposal_priority(theta, Q, S_relevant):
    """計算提案優先級"""
    P = theta * Q * (1 + math.log(1 + S_relevant))
    return P
```
