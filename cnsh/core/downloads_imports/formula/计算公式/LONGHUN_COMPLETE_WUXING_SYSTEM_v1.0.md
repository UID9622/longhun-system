## 三大公式

### 公式 A：五行平衡指数（Balance Index）

**定义**：衡量五行分布的均匀程度

**公式**
```
Balance Index = 100 - (σ / avg × 100)
```

其中：
- `avg` = 五行总分 / 5
- `σ` = √[ Σ(score - avg)² / 5 ]

**输出范围**：0-100

**三色映射**
```
95-100  → 🟢 完美均衡（dr 6-9）
80-94   → 🟢 良好均衡
60-79   → 🟡 可接受（需观察）
40-59   → 🟡 需调整（加补益）
0-39    → 🔴 严重失衡（熔断或重算）
```

**龍魂映射**
```
🟢 (80-100) → L2-L4 正常流动
🟡 (40-79)  → L2 审计层·需加控制
🔴 (0-39)   → L0 熔断层·不可进入
```

---

### 公式 B：相生相克强度（GR Strength）

**定义**：衡量某五行对整体系统的制约程度

**三个指标**

1. **相生强度**（Generation Strength）
   ```
   G(A→B) = score(B) / (score(A) + score(B))
   ```
   解释：A 生 B 的强度·范围 0-1

2. **相克强度**（Restriction Strength）
   ```
   R(A⇒B) = min(score(A), score(B)) / score(A)
   ```
   解释：A 克 B 的强度·范围 0-1

3. **净强度**（Net Strength）
   ```
   Net(A) = G(A) - R(A)
   ```
   解释：综合影响·可为正或负

**相生相克表**
```
相生链（五行轮回）：金 → 水 → 木 → 火 → 土 → 金

相克链（五行制约）：
  金 克 木
  木 克 土
  土 克 水
  水 克 火
  火 克 金
```

**龍魂映射**
```
Net(A) > 0.3  → 🟢 生大于克·可顺利推进
0 ≤ Net(A) ≤ 0.3 → 🟡 生克均衡·需维护
Net(A) < 0    → 🔴 克大于生·需加审计或熔断
```

---

### 公式 C：三才平衡系数（Sancai Coefficient）

**定义**：融合天·地·人三个维度的配合度

**公式**
```
C = Heaven × 0.35 + Earth × 0.20 + Human × 0.45
```

其中：
- **天** (Heaven, 0-1) = 环境·时机·大势
- **地** (Earth, 0-1) = 资源·条件·基础
- **人** (Human, 0-1) = 意志·初心·价值观

**铁律**
```
✋ 人 (Human) 永远 ≥ 0.34

若 Human < 0.34：
  1. 强制设定 Human = 0.34
  2. 其余按比例缩放
  3. 记录为 🟡 待审
```

**输出范围**：0-1

**龍魂映射**
```
C ≥ 0.75 → 🟢 三才合一·直接进入 L3+
0.50 ≤ C < 0.75 → 🟡 三才不全·需补证
C < 0.50 → 🔴 三才缺失·熔断
```

---

### 公式 D：复合决策强度（Composite Decision Strength）·[新]

**定义**：融合公式 A/B/C 的综合决策强度

**公式**
```
Strength = A(平衡) × 0.35 + B(相克) × 0.30 + C(三才) × 0.35
```

其中：
- A 归一化到 0-1：`A_norm = Balance / 100`
- B 归一化到 0-1：`B_norm = (Net + 1) / 2`（防止负数）
- C 已是 0-1

**置信度判定**
```
Strength ≥ 0.80 → 置信度 🟢 高（≥0.80）
0.60 ≤ Strength < 0.80 → 置信度 🟡 中（0.60-0.79）
Strength < 0.60 → 置信度 🔴 低（禁止直接使用）
```
