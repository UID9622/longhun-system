## 🏗️ 系统架构

### 三层架构
```
Layer 1: 操作日记系统
  ├─ OperationLedger (append-only 日记 + SHA-256 链)
  ├─ DNAParticleGenerator (DNA 粒子生成)
  ├─ HabitFingerprintManager (习惯指纹·基线·信心度)
  └─ CrossDeviceIdentifier (跨设备识别)
      ↓
Layer 2: 同步验证层
  ├─ SyncEngine (USB 同步 + 3 层冲突检测)
  └─ MultisigGate (3/3 本地验证 + 敏感操作拦截)
      ↓
Layer 3: 查询审计层
  └─ QueryTool (8 大查询模组 + 完整审计 + 合规检查)
      ↓
最终成果: 可见·可查·可审计的去中心化身份系统
```

### 核心特性

#### 1. F8 习惯不动点 (Phase 2.1)
```
拼音错别字 (得/的, 哪/那)
+ 口头禅 (嘿嘿, 焊死, 宝宝)
+ 多音字偏好 (中/zhōng/zhòng)
+ 数字根计算 (dr ∈ {3,9})
= 数学上不可伪造的身份证

SI ≥ 0.85 → ✅ 自动认人
```

#### 2. 三层冲突检测 (Phase 2.2)
```
hash_mismatch → 数据完整性检查
timestamp_anomaly → 时间顺序检查
duplicate_id → 操作唯一性检查

任何一层失败 → 冲突记录 + 人工审查
无单点故障·三重保险
```

#### 3. 3/3 多签门 (Phase 2.2)
```
Layer 1: UID 验证 (设备 seal 格式)
Layer 2: GPG 验证 (签名和密钥)
Layer 3: 时间戳验证 (ISO8601 + shichen + dr)

任何一层失败 = 整体失败 (一票否决)
零成本·毫秒级·无需区块链
```

#### 4. 完整审计系统 (Phase 2.3)
```
8 大查询模组:
  ├─ 操作日记查询 (时间·类型·设备)
  ├─ DNA 粒子检索 (信心度·风险·类型)
  ├─ 习惯分析 (拼音·短语·多音·趋势)
  ├─ 设备统计 (摘要·操作列表)
  ├─ 同步历史 (追踪)
  ├─ 冲突和验证 (记录·审计)
  ├─ 安全警报 (风险等级)
  └─ 系统统计和审计 (聚合·合规)

3 层合规检查:
  ├─ SHA-256 hash 链完整性
  ├─ 操作 ID 唯一性
  └─ 时间戳递增性
```
