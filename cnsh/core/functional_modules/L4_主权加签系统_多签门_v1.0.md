## 🎯 核心目标

### 目标1: 本地多签验证门 (3/3 Threshold)

**精纯定义**:
```
多签 ≠ M-of-N(2/3OK)
而是: 3/3全过才生效(UID + GPG + 时间戳全检)

单点失败 = 整体拒绝·无例外
目标: 主权从“单密钥”→“三层独立验证”
```

**三签架构**:
```
签名1: UID验证
  ├─ UID9622硬编码检查
  ├─ 设备绑定校验(DEVICE_SEAL)
  └─ 失败→🔴拒绝

签名2: GPG密钥验证
  ├─ GPG指纹: A2D0092CEE2E5BA87035600924C3704A8CC26D5F
  ├─ 本地签名完整性检查
  └─ 失败→🔴拒绝

签名3: 时间锚验证
  ├─ ISO8601时间戳
  ├─ 时辰+数字根一致性
  └─ 失败→🔴拒绝

结果: ALL通过→🟢|ANY失败→🔴
```

**工程包**:
```python
# ~/longhun-system/cnsh-core/security/multisig/
├── uid_verifier.py
│   ├── verify_uid_hardcode()      # UID9622 == config
│   ├── verify_device_seal()       # 设备绑定验证
│   └── check_uid_tampering()      # 检测篡改迹象
│
├── gpg_verifier.py
│   ├── load_gpg_key()             # 加载本地GPG key
│   ├── verify_signature()         # 验证签名
│   ├── extract_fingerprint()      # 提取指纹
│   └── detect_key_rotation()      # 检测密钥轮换
│
├── temporal_verifier.py
│   ├── verify_iso8601()           # 时间格式校验
│   ├── verify_shichen()           # 时辰一致性
│   ├── verify_digital_root()      # 数字根一致性
│   ├── check_clock_drift()        # 检测时钟偏差
│   └── verify_no_rewind()         # 检测时间倒退
│
└── multisig_gate.py
    ├── class MultiSigGate:
    │   ├── verify_all_three()     # 3/3检查
    │   ├── verify_uid()           # 委托给uid_verifier
    │   ├── verify_gpg()           # 委托给gpg_verifier
    │   ├── verify_temporal()      # 委托给temporal_verifier
    │   ├── log_verification()     # 记录每步验证
    │   └── return_verdict()       # 🟢通过或🔴拒绝
    │
    └── def gate_operation():
        ├─ input: operation_data
        ├─ call: multisig.verify_all_three()
        ├─ if PASS: 允许执行·记录
        └─ if FAIL: 拒绝·告警·留痕
```

**验收标准**:
```
✅ UID验证: 100% 准确(不认识陌生人)
✅ GPG验证: 100% 完整(指纹匹配)
✅ 时间验证: 毫秒级精度 + 时辰准确
✅ 拒绝准确: 任一失败立即拒绝·无延迟
✅ 日志完整: 每次验证过程留痕
```
