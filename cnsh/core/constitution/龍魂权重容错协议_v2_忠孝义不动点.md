## 二、核心原则：有弹性的制度，不是软弱的制度

1. **默认信任，记录不判决**  
   初始权重不为零，而是基于「人是善意的」假设。记录是证据，不是判决书。

2. **动态权重，非一次性烙印**  
   权重随行为波动，但不会因一次错误永久钉死。制度要给人改正的路。

3. **贡献可抵消，但不是赎罪券**  
   有效贡献可以降低权重惩罚，但不能抵消 L0 不动点违规（忠孝义红线）。

4. **弱者权重天然高**  
   资源最少的一方，在系统中拥有最高的被保护权重。这是防止「强者通吃」的算法表达。

5. **透明可审计**  
   每一次权重变更、抵消、熔断、恢复，必须带 DNA 追溯码，写入 Notion 公开仪表盘。

## 三、状态机

```
            首次违规
[默认信任] ──────────→ [待观察] ───────┐
     ↑                                  │ 30天内无新违规
     │                                  ▼

     ▲
     │ 完成贡献任务 + 手动申请
 [熔断态] ←──────────── [低信任]
     │
     └── L0 不动点违规 → [永久熔断]（仅 UID9622 可解）
```

| 状态 | 权重区间 | 行为限制 | 恢复路径 |
|------|----------|----------|----------|
| 高信任 | 90-100 | 无额外限制 | — |
| 信任 | 70-89 | 无额外限制 | — |
| 需注意 | 50-69 | 开启记录跟踪 | 自然行为修正 |

| 低信任 | 30-49 | 人工复核后才能执行敏感操作 | 贡献抵消 + 人工确认 |

## 四、权重计算公式 v2.0

### 4.1 基础参数

```python
BASE_WEIGHT = 60            # 默认信任基线
MAX_WEIGHT = 100            # 封顶
MIN_WEIGHT = 0              # 底线
VIOLATION_PENALTY = -10     # 每次违规扣分
CONTRIBUTION_BONUS = +12    # 每次贡献加分
OBSERVATION_GRACE_DAYS = 30 # 观察期
RESET_CYCLE_DAYS = 90       # 弹性重置周期
```

### 4.2 动态权重公式

```
行为分数 = Σ(违规记录 × -10) + Σ(贡献记录 × +12)
时间衰减因子 = max(0.3, 1 - 已过天数 / 90)
动态权重 = clamp(基础权重 + 行为分数 × 时间衰减因子, 0, 100)
```

**说明**：
- 贡献与违规可以部分抵消，但**不能抵消 L0 不动点违规**。
- 时间衰减因子让旧记录自然贬值，但永远不会完全归零（保留 0.3 底噪，供审计追溯）。
- 每 90 天自动重置到基线 60，但 L0 红线记录保留并单独计算。

### 4.3 首次违规处理

```
IF 首次违规 AND NOT L0违规:
    状态 = 待观察
    权重不变（仍按 BASE_WEIGHT 计算）
    启动 30 天观察期
ELSE IF 再次违规:
    状态 = 需注意 或 低信任（按权重落点）
    权重 = BASE_WEIGHT + (-10) × 累计违规次数 × 衰减因子
ELSE IF L0违规:
    状态 = 永久熔断
    权重 = 0
```

### 4.4 贡献抵消规则

| 贡献类型 | 示例 | 加分 |
|----------|------|------|
| 帮助弱者 | 解答真实问题、提供有效援助 | +12 |
| 举报属实 | 发现并上报系统风险/攻击 | +12 |
| 提交有效代码/规则 | 被合并进主干 | +12 |
| 有效反馈 | 提出并被采纳的改进建议 | +8 |
| 公开透明行为 | 主动公开自己的操作记录 | +5 |

**抵消上限**：一次贡献只能抵消一次非 L0 违规记录，不能囤贡献换「免罪金牌」。

## 五、熔断与恢复

### 5.1 熔断条件

| 条件 | 结果 |
|------|------|
| 权重 ≤ 29 | 自动熔断 |
| 权重 30-49 连续 30 天且无贡献 | 进入待熔断预警 |
| 触发 L0 不动点违规 | 永久熔断 |
| 同一维度累计 5 次非 L0 违规 | 强制人工复核 |

### 5.2 解除熔断

1. 完成至少一次有效贡献（由系统或 UID9622 认定）。
2. 提交「解除熔断申请」，说明改进行为。
3. 系统重新计算权重：
   ```
   新权重 = max(30, BASE_WEIGHT + 行为分数 × 衰减因子)
   ```
4. 若新权重 ≥ 30，自动恢复为「低信任」状态，进入 30 天观察期。
5. 观察期内无新违规，恢复为「信任」状态。

### 5.3 永久熔断的例外

L0 不动点违规**原则上不解除**。但在 UID9622 确认对方已真正改正、并公开道歉/补偿后，可手动恢复。所有手动恢复必须：
- 带 `#CONFIRM🌌9622-ONLY-ONCE🧬CODE-NNN` 确认码
- 写入 Notion 审计登记 DB
- 追加新的 DNA 追溯码

## 六、「滥竽充数」识别

### 6.1 判定标准

同时满足以下两条，系统标记为「低贡献低信任」：

1. 权重长期 ≤ 30 超过 30 天。
2. 期间无任何有效贡献记录。

### 6.2 处置方式

| 阶段 | 系统行为 | 可见范围 |
|------|----------|----------|
| 标记 | 内部标注「低贡献低信任」 | 团队内部可见 |
| 熔断 | 权重 ≤ 29 自动熔断 | 公开仪表盘显示熔断事件（不含个人隐私） |
| 90 天警示 | 系统在团队内提示「贡献行为不足」 | 团队内部 |
| 不直接移除 | 不封禁、不删号，保留改正通道 | — |

> 原则：给人机会，但不纵容消耗。公开透明，但不羞辱个人。
