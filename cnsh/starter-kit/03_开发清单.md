## 一、龙魂五大净化标准

1. 数据主权 —— 您的数据，您做主（本地优先，可导出，可删除）
2. 开源透明 —— 代码可审计，算法可验证，规则可申诉
3. 普惠精神 —— 核心功能免费，不因贫富而区别对待
4. 去中心化 —— 不依赖单一服务商，支持自建/自托管
5. 开放标准 —— 跨平台互通，拒绝生态封锁

凡是不符合这五条的，都是污染工具，无论它多"合规"。

## 二、推荐净化工具清单

### 开发者工具类（Mac 优先）
- Visual Studio Code（VSCode）—— 开源，不强制登录 Microsoft 账号，数据本地存储；替代：VSCodium（纯净版，去除微软遥测）
- Cursor（AI 编程助手）—— 基于 VSCode，支持本地模型，代码不上传（隐私模式）
- Git —— 去中心化版本控制，可自建 Git 服务器（Gitea/GitLab）
- Docker Desktop / Orbstack —— 本地部署应用，完全掌控，可自建私有镜像库
- iTerm2 —— 开源、强大、支持分屏和自定义

### 文件管理与存储
- Finder 替代品：Forklift / Path Finder / Commander One —— 双窗口、本地优先
- Syncthing —— 完全去中心化、点对点同步、开源免费、无需服务器（100% 净化）
- Nextcloud —— 自建私有云，开源自托管、完全掌控
- Restic / Duplicacy —— 开源、加密、增量备份

### 通讯工具（替代微信）
- Signal —— 开源、端到端加密、无广告无跟踪（100% 最佳实践）
- Element（基于 Matrix 协议）—— 去中心化、可自建服务器、联邦式架构（100%）
- Telegram —— 功能强大但默认非端到端加密（需手动开启秘密聊天）

### 笔记与知识管理
- Obsidian —— 完全本地存储（Markdown）、数据永远属于您（100% 最符合理念）
- Logseq —— 开源、本地优先、双向链接
- Joplin —— 开源、端到端加密、支持 WebDAV 同步

### 浏览器与隐私工具
- Firefox / Brave —— 开源、隐私保护
- uBlock Origin / Privacy Badger —— 开源广告拦截与跟踪拦截（100%）

### 设计与多媒体
- GIMP / Krita —— 开源图像与绘画（100%）
- DaVinci Resolve（免费版）/ Shotcut —— 视频剪辑，Shotcut 开源（100%）

### 安全与加密
- Bitwarden —— 开源、端到端加密、可自建服务器（100%）
- KeePassXC —— 完全本地、开源、无云同步
- Cryptomator / VeraCrypt —— 开源文件与磁盘加密（100%）

### 生产力工具
- Vikunja（自建）/ ActivityWatch —— 开源、自托管、隐私优先（100%）
