## ✅ **数学签章和验证标准**

### **三级签章系统**

```
✅ 数学可验证签章 (Math-Verifiable)
   ├─ 条件: 有可计算公式 + 有可运行代码 + 有出处引用
   ├─ 表示: ✅🧮 #MATH-PROVEN-龍芯⚡️
   └─ 意义: 所有关键指标都能复算·错一条就报错

🟡 有公式·结果待验证 (Formula-OK-Result-TBV)
   ├─ 条件: 公式可计算但实验数据未复现
   ├─ 表示: 🟡📊 #TBV-RESULT-PENDING
   └─ 意义: 公式没问题·但数据还要跑

🔖 概念框架·待补公式 (Concept-Formula-TBD)
   ├─ 条件: 还没有可计算的数学公式
   ├─ 表示: 🔖📝 #FORMULA-TODO
   └─ 意义: 逻辑清楚·公式待补·不混进可验证
```
