## 方案A：一键导入（推荐）

### 1. 在 iPhone/iPad 上打开此链接（Safari）：
```
https://www.icloud.com/shortcuts/  ← 等UID9622上传后填入实际链接
```

### 2. 点击"获取快捷指令" → "添加快捷指令"

### 3. 使用方法：
- 复制任意文本 → 打开快捷指令 App → 点击"CNSH翻译"
- 或添加到主屏幕 → 一键触发
- 或设置"轻点背面"触发（设置→辅助功能→触控→轻点背面）

## 方案C：自动化弹出（任何时候复制都弹）

iOS 16+ 支持剪贴板自动化：

```
快捷指令 App → 底部"自动化"标签 → 右上角 + → "App"
→ 选择任意常用 App（如微信/备忘录/浏览器）→ "已打开"
→ 添加操作 → 搜索"运行快捷指令" → 选择"CNSH翻译"
→ 关闭"运行前询问" → 完成
```

**效果**：打开微信/备忘录时，如果剪贴板有新内容，自动弹出CNSH翻译结果。

> ⚠️ iOS隐私限制：无法在后台持续监听剪贴板，只能通过App打开事件触发。
> 但在快捷指令内手动点击不需要任何权限。

## 方案D：共享表单触发（最佳体验）

```
快捷指令设置 → 点击顶部名称旁的 ⓘ
→ 开启"在共享表单中显示"
→ 接收内容类型：文本、URL、图像
```

**效果**：在任何App选中文字→共享→CNSH翻译，直接弹出翻译结果。

## 多设备同步

开启 iCloud 同步后，iPad/Mac/Apple Watch 自动可用：
- **Mac**: 菜单栏快捷指令或右键→服务→CNSH翻译
- **iPad**: 侧拉窗口或共享表单
- **Apple Watch**: Siri说"CNSH翻译"即可触发
- **Vision Pro**: 通过 Siri 触发

## 自定义服务器地址

如果你部署到不同服务器，修改第[3]步的URL：

| 部署位置 | URL |
|---------|-----|
| 本地Mac | `http://127.0.0.1:9622/api/cnsh/clipboard-translate` |
| 鲲鹏服务器 | `http://<鲲鹏IP>:8777/api/cnsh/clipboard-translate` |
| 公网服务器 | `https://<域名>/api/cnsh/clipboard-translate` |

确保 iOS 设备和服务器在同一网络（或配置端口转发）。
