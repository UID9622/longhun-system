## 🔍 理解五层架构

### L0 · 宣言守卫（绝不动摇）
- **职责**: 保护系统身份文档完整
- **特点**: 永远不能关闭，永远不能睡眠
- **一旦失败**: 整个系统立即熔断
- **指标**: MD5 指纹校验，权限检查

### L1 · 铁律执行（母法层）
- **职责**: 执行 8 条永恒铁律
- **特点**: 不可违反，零容忍
- **8 条铁律**:
  1. 不欺 - 说真话
  2. 不骗 - 不收割
  3. 不商业 - 永远开源
  4. 不站队 - 只对人民负责
  5. 只为守护 - 守护言论自由
  6. 后人不从军
  7. 后人不从政·不移民
  8. 后人不做企业标杆

### L2 · 焊死协议（核心规则）
- **职责**: 审计、验证、计算权重、监控防护
- **特点**: 一次生成，永不修改
- **4 个模块**:
  1. 协议审计 - 检测篡改
  2. DNA 验证 - 追溯身份
  3. 权重计算 - 动态优先级
  4. 屏障监控 - 防护盾状态

### L3 · 动态治理（日常运作）
- **职责**: 处理冲突、倾听反馈、管理状态
- **特点**: 灵活但不突破母法
- **3 个模块**:
  1. 治理解决器 - 处理冲突
  2. 公民反馈 - 倾听声音
  3. 状态机 - 管理生命周期

### L4 · 超级补充（周边生态）
- **职责**: 发布内容、危机恢复
- **特点**: 重要但不是核心
- **2 个模块**:
  1. 补充发布器 - 发布新闻、讨论、合作
  2. 危机恢复 - 备份、快照、回滚

## ⚙️ 配置调整

### 修改权重优先级
编辑 `config/protocol_weights.json`:
```json
{
  "L0": 1.0,
  "L1": 0.95,
  "L2": 0.90,
  "L3": 0.85,
  "L4": 0.80

```

### 修改权限矩阵
编辑 `config/tier_permissions.json`，针对各层定义可执行操作

### 设置熔断阈值
编辑 `config/fuse_thresholds.json`，当威胁评分超过阈值时自动熔断

### 启用/禁用防护盾
编辑 `config/shield_rules.json`，控制五道防护盾的启用状态

## 🆘 故障排查

### 系统无法启动
1. 检查 Python 版本: `python3 --version`
2. 检查日志: `tail -f ~/.龍魂/logs/longhun_error.log`
3. 检查目录权限: `ls -la ~/longhun-system/scripts/`

### 日志缺失
1. 创建日志目录: `mkdir -p ~/.龍魂/logs`
2. 检查权限: `chmod 755 ~/.龍魂/logs`

### 配置文件找不到
1. 确认位置: `ls ~/longhun-system/scripts/config/`
2. 重新初始化: `bash setup.sh`
