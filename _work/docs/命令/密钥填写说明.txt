════════════════════════════════════════

文件位置（只改这一个）：
  ~/longhun-system/engine/.env

填好后保存，关掉 TextEdit，然后终端复制：
  bash ~/longhun-system/bin/帮你检查全部

────────────────────────────────────────
① Notion（花名册 / 同步用）
────────────────────────────────────────
1. 浏览器打开：https://www.notion.so/my-integrations
2. 新建集成 → 复制「Internal Integration Token」
3. 在 .env 里找到 NOTION_TOKEN=  贴在等号后面（不要引号，不要空格）

────────────────────────────────────────
② DeepSeek（便宜·中文好用）
────────────────────────────────────────
1. 打开 DeepSeek 开放平台 → API Keys
2. 复制密钥
3. .env 里 DEEPSEEK_API_KEY= 后面贴上

────────────────────────────────────────
③ Claude（可选·没有可先空着）
────────────────────────────────────────
.env 里 ANTHROPIC_API_KEY= 后面贴上

────────────────────────────────────────
注意
────────────────────────────────────────
· 密钥只存在你本机 .env，不会进 git
· 不要把密钥贴在微信/群里；只贴在本机文件
· 本地 DNA 控制台 / 滑条 不需要密钥也能用
· 填完运行：bash ~/longhun-system/bin/帮你检查全部
