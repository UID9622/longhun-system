# §2｜概率行为体模型

## 2.1 基本公式

传统伦理学把人分为善人/恶人。本文主张人是环境驱动的概率体：

```
P(善行 | 环境) = P₀(个人基率) × [reward(善行) / risk(善行)]ˣ

其中 x 为环境压力系数，取值范围 [0.5, 3.0]。
```

**推论：**

- 当 risk(善行) > reward(善行) 且 x 足够大时，P(善行) → 0
- 当 reward(善行) > risk(善行) 时，P(善行) → 1
- 未扪黑白点：P₀×r/risk = 1 → 这是文明的临界平衡点

## 4.3 责任塌缩状态的系统性定义

一个群体/社会的责任状态定义为：

```
S_责任 = Σ(i=1..N) P_i(承担) × W_i(影响力)

其中 N 为群体规模。

当 S_责任 / N < 0.3 时：系统进入「责任塌缩态」。
当 S_责任 / N < 0.15 时：系统不可逆失温。
```

原文未打的点：互联网为什么会加速责任塌缩？数学上需要三个变量：

```
risk(善行)_线下 = constant
risk(善行)_线上 = constant × α(传播系数) × β(匿名系数) × γ(算法放大)

当三个系数都趋近 10 时：
risk_线上 ≈ 1000 × risk_线下
```

同一个善行在互联网上面临的风险是线下的 1000 倍。个体依然"以同一道德标准"能行动，是概率上不可能的。

```
黑箱 AI 的本质 = 责任外部化
```
