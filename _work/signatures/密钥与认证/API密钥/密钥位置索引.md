## 如何填写密钥

### Notion Token
1. 访问 https://www.notion.so/my-integrations
2. 创建集成，复制 secret_xxx
3. 填到 ~/.longhun/secrets.env 的 NOTION_TOKEN=

### GitHub PAT
1. 访问 https://github.com/settings/tokens
2. 创建 Fine-grained token
3. 填到 ~/.uid9622/git-tokens.sh
