## 🔧 首次啟動前的準備

### 步驟 1: 安裝缺失的依賴

```bash
pip install --user fastapi uvicorn
```

### 步驟 2: 清理被佔用的端口 (如果有)

```bash
# 查看佔用 5000 端口的進程
sudo lsof -i :5000

# 殺死該進程 (例如進程 ID 是 12345)
kill -9 12345
```

### 步驟 3: 運行診斷確認一切就緒

```bash
python3 系统诊断.py
# 應該顯示所有檢查都通過
```

### 步驟 4: 啟動系統

```bash
./启动.sh
# 或
python3 龍魂統一控制臺.py
```
