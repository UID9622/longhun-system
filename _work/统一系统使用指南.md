## 📋 5 個服務詳解

### 1️⃣ CNSH 翻譯系統

**什麼是**: 多語言翻譯 + Notion 看板 + AI 處理
**命令**: `1`
**特點**:
- 後台無限監聽隊列
- 自動翻譯和質量評分
- 優先級管理
- **不需要訪問網址（後台服務）**

---

### 2️⃣ CNSH FastAPI 任務提交接口

**什麼是**: 外部系統 → 提交 JSON 任務 → 自動入隊
**命令**: `2`
**端口**: 8000
**訪問**:
```bash
# API 文檔 (含互動測試)
http://localhost:8000/docs

# 直接 curl 提交任務
curl -X POST http://localhost:8000/submit_task \
  -H 'Content-Type: application/json' \
  -d '{
    "source_text": "你好",
    "source_language": "中文",
    "target_language": "英文"
  }'
```

---

### 3️⃣ 三系統 API 服務器 (排序算法)

**什麼是**: 6 種排序算法 + PoW 記賬 + 3D 可視化
**命令**: `3`
**端口**: 5000
**訪問**:
```bash
# 移動控制面板 (手機也能訪問)
http://localhost:5000/control

# API 文檔
http://localhost:5000/docs
```

---

### 4️⃣ DNA 識別鎖

**什麼是**: 驗證龍魂簽名和 Tier 分級
**類型**: 代碼庫（不需要單獨啟動）
**用途**: 內部驗證，自動調用

---

### 5️⃣ 意圖翻譯官

**什麼是**: 自然語言 → 系統指令
**類型**: 代碼庫（不需要單獨啟動）
**用途**: 內部路由，自動調用

---

## 🎯 實際使用場景

### 場景 1: 翻譯工作流

```
1. 啟動: 輸入 "all"
2. 提交任務: 訪問 http://localhost:8000/docs
3. 查詢進度: GET /task/{task_id}
4. 查看統計: GET /stats
5. 查詢完成: 翻譯 ✅ 完成
```

### 場景 2: 排序算法展示

```
1. 啟動: 輸入 "all"
2. 打開面板: 訪問 http://localhost:5000/control
3. 選擇算法: 從下拉菜單選擇
4. 調整大小: 拖動滑塊 (10-500)
5. 執行排序: 點擊「執行排序」
6. 查看結果: PoW 哈希 + 質量評分
```

### 場景 3: 遠程訪問 (其他電腦)

```
1. 在本機啟動: 輸入 "all"
2. 在其他電腦上:
   http://192.168.1.100:8000/docs  (用你的 Mac IP)
   http://192.168.1.100:5000/control

或使用 ngrok 全球訪問:
   ngrok http 8000
   ngrok http 5000
   # 複製給出的 URL
```

## ❌ 故障排除

### 問題 1: "連接被拒絕"

```bash
# 確認啟動了 "all"
status

# 檢查端口是否被佔用
lsof -i :8000
lsof -i :5000
```

### 問題 2: "找不到模塊"

```bash
# 安裝依賴
pip install --user fastapi uvicorn pydantic requests

# 運行測試驗證
test
```

### 問題 3: 某個服務啟動失敗

```bash
# 查看狀態
status

# 單獨啟動該服務 (例如服務 2)
輸入: 2

# 查看錯誤消息
```

### 問題 4: 無法從其他電腦訪問

```bash
# 1. 檢查防火墻
系統偏好設置 → 安全性和隱私 → 防火墻選項
允許 Python 通過防火墻

# 2. 確認 IP 地址
ipconfig getifaddr en0

# 3. 在其他電腦上訪問
http://192.168.x.x:8000
```

## 🔧 高級配置

### 修改端口

編輯 `龍魂統一控制臺.py` 第 40-42 行:

```python
"2": {
    "port": "8000",  # ← 改這裡
    ...
}
```

### 修改後台進程數量

如果你想啟動多個 CNSH 翻譯系統實例:

```python
# 在服務字典中複製一份並改名
"2a": {
    "name": "🌐 CNSH 翻譯系統 #2",
    "command": "python3 cnsh_translator_complete.py",
    ...
}
```

### 添加自定義服務

```python
SERVICES = {
    ...
    "9": {
        "name": "🎮 自定義服務",
        "command": "python3 my_service.py",
        "port": "9000",
    }
}
```
