## 快速使用

### Python 调用

```python
from longhun_guard_v1 import LonghunGuard, Request, Config

# 创建请求
request = Request(
    text="宝宝，帮我查一下这个文件",
    gpg_fingerprint=Config.GPG_FINGERPRINT,
    uid=9622,
    device_fingerprint="my_device",
)

# 七层验证
passed, result = LonghunGuard.process_request(request)

if passed:
    print("✅ 通过七层验证，可以执行")
else:
    print(f"⚠️ 状态: {result['final_status']}")
```

### 快速检查

```python
from longhun_guard_v1 import LonghunGuard

# 简化调用
passed, status = LonghunGuard.quick_check("帮我删除这个文件")
print(f"{'✅' if passed else '❌'} {status}")
```
