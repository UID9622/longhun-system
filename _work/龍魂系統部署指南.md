# 🐉 龍魂系統部署指南

## ✅ 核心功能（必須可用）

### 1. 配置讀取器
```
配置读取器.py ✅ （純 Python，無依賴）
```

### 2. 本地 API 服務器（stdlib 版本）
```
longhun_api_server_stdlib.py ✅ （使用 http.server，無依賴）
```

### 3. 統一控制臺
```
龍魂統一控制臺.py ✅ （無外部依賴）
```

**這些是系統的核心，必須 100% 可用。**

---

## ⚠️ 可選功能（需要額外安裝）

### 4. CNSH FastAPI 接口
```
cnsh_fastapi_interface.py ⚠️ （需要 pip install fastapi uvicorn）
```

**什麼時候需要？**
- 你想用 Web 界面提交任務
- 你想在其他機器上調用 API

**安裝方式**：
```bash
# 方式 1：Homebrew（推薦，避免 PEP 668 問題）
brew install python@3.12-venv
python3 -m venv ~/.longhun-venv
source ~/.longhun-venv/bin/activate
pip install fastapi uvicorn

# 方式 2：使用系統 Python（可能失敗）
pip install --user fastapi uvicorn
```

## 🚀 快速啟動（只用核心功能）

```bash
# 1. 進入目錄
cd ~/longhun-system/_work

# 2. 驗證系統（不需要 FastAPI）
python3 test_unified_config.py

# 3. 啟動系統
python3 龍魂統一控制臺.py

# 4. 選項說明
# 輸入 1：啟動翻譯系統（本地隊列）✅
# 輸入 2：啟動 FastAPI（需要先安裝）⚠️
# 輸入 3：啟動 API 服務器（stdlib，總是可用）✅
# 輸入 all：啟動全部（如果 FastAPI 失敗會跳過）
```

## ⚡ 故障排除

**問題 1：啟動 FastAPI 失敗**
```
❌ ModuleNotFoundError: No module named 'fastapi'

解決：
  brew install python@3.12-venv
  python3 -m venv ~/.longhun-venv
  source ~/.longhun-venv/bin/activate
  pip install fastapi uvicorn
```

**問題 2：pip 說 "externally-managed-environment"**
```
❌ error: externally-managed-environment

解決（推薦順序）：
  1. 使用 Homebrew 安裝的 Python venv（最安全）
  2. 使用 --break-system-packages（不推薦，可能損壞系統）
  3. 使用 pipx 安裝（隔離應用）
```

**問題 3：API Server 不能啟動**
```
❌ Address already in use

解決：
  lsof -i :5000
  kill -9 <PID>
  或修改配置：nano .longhunsystemconfig
  改成：THREE_SYSTEM_API_PORT=5001
```
