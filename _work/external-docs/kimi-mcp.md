        - paragraph [ref=e514]:
          - link "Model Context Protocol (MCP)" [ref=e515] [cursor=pointer]:
            - /url: https://modelcontextprotocol.io/
          - text: 是一个开放协议，让 AI 模型可以安全地与外部工具和数据源交互。Kimi Code CLI 支持连接 MCP 服务器，扩展 AI 的能力。
        - heading "MCP 是什么 Permalink to “MCP 是什么”" [level=2] [ref=e516]:
          - text: MCP 是什么
          - link "Permalink to “MCP 是什么”" [ref=e517] [cursor=pointer]:
            - /url: "#mcp-是什么"
            - text: "#"
        - paragraph [ref=e518]: MCP 服务器提供「工具」给 AI 使用。例如，一个数据库 MCP 服务器可以提供查询工具，让 AI 能够执行 SQL 查询；一个浏览器 MCP 服务器可以让 AI 控制浏览器进行自动化操作。
        - paragraph [ref=e519]: Kimi Code CLI 内置了一些工具（文件读写、Shell 命令、网页抓取等），通过 MCP 你可以添加更多工具，比如：
        - list [ref=e520]:
          - listitem [ref=e521]: 访问特定 API 或数据库
          - listitem [ref=e522]: 控制浏览器或其他应用
          - listitem [ref=e523]: 与第三方服务集成（GitHub、Linear、Notion 等）
        - heading "MCP 服务器管理 Permalink to “MCP 服务器管理”" [level=2] [ref=e524]:

        - heading "加载状态 Permalink to “加载状态”" [level=2] [ref=e630]:
          - text: 加载状态
          - link "Permalink to “加载状态”" [ref=e631] [cursor=pointer]:
            - /url: "#加载状态"
            - text: "#"
        - paragraph [ref=e632]: MCP 服务器在 Shell UI 启动后异步初始化，不会阻塞界面的使用。Shell 底部状态栏会实时显示连接进度，连接完成后自动切换为就绪状态。Web 界面也会同步显示各服务器的连接状态。
        - paragraph [ref=e633]: 如果配置了多个 MCP 服务器，加载时间可能较长，状态栏的进度指示可以帮助你了解当前连接情况。
        - heading "安全性 Permalink to “安全性”" [level=2] [ref=e634]:
          - text: 安全性
          - link "Permalink to “安全性”" [ref=e635] [cursor=pointer]:
            - /url: "#安全性"
            - text: "#"
        - paragraph [ref=e636]: MCP 工具可能会访问和操作外部系统，需要注意安全风险。
        - paragraph [ref=e637]:
          - strong [ref=e638]: 审批机制
        - paragraph [ref=e639]: Kimi Code CLI 对敏感操作（如文件修改、命令执行）会请求用户确认。MCP 工具也遵循同样的审批机制，所有 MCP 工具调用都会弹出确认提示。
        - paragraph [ref=e640]:
          - strong [ref=e641]: 提示词注入风险
        - paragraph [ref=e642]: MCP 工具返回的内容可能包含恶意指令，试图诱导 AI 执行危险操作。Kimi Code CLI 会对工具返回内容进行标记，帮助 AI 区分工具输出和用户指令，但你仍应：
        - list [ref=e643]:
          - listitem [ref=e644]: 只使用可信来源的 MCP 服务器
          - listitem [ref=e645]: 检查 AI 提议的操作是否合理
          - listitem [ref=e646]: 对于高风险操作保持手动审批
        - blockquote [ref=e647]:
          - paragraph [ref=e648]: 注意：在 YOLO 模式下，MCP 工具的操作也会被自动批准。建议仅在完全信任 MCP 服务器的情况下使用 YOLO 模式。
