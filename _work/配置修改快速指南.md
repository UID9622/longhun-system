## 🎯 快速開始 (3 步)

### 第 1 步: 打開配置文件

```bash
nano .longhunsystemconfig
# 或用其他編輯器: vim, code, TextEdit 等
```

### 第 2 步: 找到要改的參數，修改它

示例：改 FastAPI 端口
```
舊: CNSH_FASTAPI_PORT=8000
新: CNSH_FASTAPI_PORT=9000
```

### 第 3 步: 保存並重啟服務

```bash
killall -9 python3              # 關閉舊服務
python3 龍魂統一控制臺.py      # 重新啟動
# 輸入 all
```

**完成！** 新配置立即生效 ✅

## 📖 所有可修改的參數

### ⭐ 最重要（通常不要改）

```ini
# 統一入口 - 所有外部請求都走這個門
MAIN_API_HOST=0.0.0.0    # 監聽地址（通常不改）
MAIN_API_PORT=8888       # 統一入口端口（可改，但要確保沒被佔用）
```

**何時改**:
- 8888 已被其他程序佔用
- 需要特定的端口號
- 在特定網絡環境中

**不要改**:
- 如果不知道為什麼要改

---

### 內部服務端口

```ini
# CNSH 翻譯系統的 API 端口
CNSH_FASTAPI_PORT=8000  # 可改（確保 1024-65535 範圍）

# 三系統 API 端口（排序、PoW、3D 可視化）
THREE_SYSTEM_API_PORT=5000  # 可改（確保 1024-65535 範圍）
```

**何時改**:
- 與其他程序端口衝突
- 需要在多個服務器上運行

**改法**:
```
CNSH_FASTAPI_PORT=9000     # ✅ 有效（在 1024-65535 範圍內）
CNSH_FASTAPI_PORT=80       # ❌ 不行（需要 sudo，容易衝突）
CNSH_FASTAPI_PORT=888      # ✅ 有效
```

---

### 本地存儲路徑

```ini
# 本地任務數據庫（SQLite）
LOCAL_DB_PATH=~/.longhun/work_records.db

# Notion 緩存（如果連接 Notion）
NOTION_CACHE_PATH=~/.notion_cache

# 日誌文件
LOG_PATH=~/.longhun/logs
```

**何時改**:
- 想把數據放在不同位置
- 磁盤空間有限，要用外接硬盤
- 多用戶環境，每個用戶有自己的數據

**改法**:
```
# 改成外接硬盤
LOCAL_DB_PATH=/Volumes/MyDrive/longhun/data.db

# 改成網絡路徑 (macOS)
LOCAL_DB_PATH=/Volumes/SharedDrive/longhun/data.db

# ✓ 確保路徑存在（否則服務啟動時會自動創建）
```

---

### Notion 集成 (可選)

```ini
# 你的 Notion API 密鑰
NOTION_API_KEY=

# 你的 Notion 數據庫 ID
NOTION_DATABASE_ID=
```

**何時改**:
- 想把工作記錄同步到 Notion
- 有 Notion 的高級計劃和集成權限

**如何獲得**:
1. 訪問 https://www.notion.so/my-integrations
2. 創建 "Internal Integration"
3. 複製 "Internal Integration Token" → 粘貼到 `NOTION_API_KEY=`
4. 在 Notion 中創建數據庫，複製共享連接中的 ID → 粘貼到 `NOTION_DATABASE_ID=`

**改法**:
```
NOTION_API_KEY=secret_123abc456def789xyz
NOTION_DATABASE_ID=abc123def456789xyz000
```

### 服務控制

```ini
# 是否自動啟動 CNSH 翻譯系統
AUTO_START_CNSH_TRANSLATOR=true    # true/false

# 是否自動啟動 FastAPI
AUTO_START_FASTAPI=true            # true/false

# 是否自動啟動三系統 API
AUTO_START_THREE_SYSTEM=true       # true/false
```

**何時改**:
- 只想啟動某些服務，不要全部
- 調試特定服務時

**改法**:
```
# 只啟動翻譯系統，不啟動 API
AUTO_START_CNSH_TRANSLATOR=true
AUTO_START_FASTAPI=false
AUTO_START_THREE_SYSTEM=false
```

---

### 日誌設置

```ini
# 日誌級別：DEBUG, INFO, WARNING, ERROR, CRITICAL
LOG_LEVEL=INFO             # 推薦 INFO

# 是否保存日誌到文件
SAVE_LOG_TO_FILE=true      # true/false
```

**何時改**:
- 調試問題，需要詳細日誌 → 改成 DEBUG
- 日誌太多，只要重要信息 → 改成 WARNING
- 磁盤空間有限 → 改成 false

---

### 隊列和性能設置

```ini
# CNSH 翻譯隊列檢查間隔（秒）
QUEUE_CHECK_INTERVAL=0.5   # 越小越快反應，越耗 CPU

# 任務重試次數
MAX_RETRIES=3              # 任務失敗重試多少次

# 最多同時處理的任務數
MAX_CONCURRENT_TASKS=5     # 越多越快，越耗內存

# 隊列最大長度（超過就停止接收）
MAX_QUEUE_LENGTH=1000      # 越大越能接收，越耗內存
```

**何時改**:
- 系統慢了 → 增大 `MAX_CONCURRENT_TASKS`
- 內存不足 → 減小 `MAX_CONCURRENT_TASKS` 或 `MAX_QUEUE_LENGTH`
- 任務經常失敗 → 增大 `MAX_RETRIES`

**推薦設置**:
```
# 對於高性能機器（Mac Pro）
MAX_CONCURRENT_TASKS=20
MAX_QUEUE_LENGTH=5000

# 對於普通機器（MacBook Air）
MAX_CONCURRENT_TASKS=5
MAX_QUEUE_LENGTH=1000

# 對於低端機器
MAX_CONCURRENT_TASKS=2
MAX_QUEUE_LENGTH=500
```

### 安全設置

```ini
# CORS 允許的源（跨域請求）
CORS_ORIGINS=*             # * = 允許所有

# API 認證令牌
API_AUTH_TOKEN=            # 留空表示不需要認證
```

**何時改**:
- 在公網上運行 → 限制 `CORS_ORIGINS`
- 需要 API 認證 → 設置 `API_AUTH_TOKEN`

**改法**:
```
# 只允許本地和特定域名
CORS_ORIGINS=http://localhost:3000,https://myapp.com

# 設置認證令牌
API_AUTH_TOKEN=my-secret-token-123456
```

## 🔧 常見修改場景

### 場景 1: 解決端口衝突

**問題**: 啟動時顯示 "Address already in use: ('0.0.0.0', 8000)"

**解決**:
1. 編輯 `.longhunsystemconfig`
2. 改 `CNSH_FASTAPI_PORT=8000` → `CNSH_FASTAPI_PORT=9000`
3. 保存
4. 重啟服務

---

### 場景 2: 在多台機器上運行

**問題**: 有多台電腦，要在不同端口上運行

**解決**:
```
# 機器 1
MAIN_API_PORT=8888
CNSH_FASTAPI_PORT=8000
THREE_SYSTEM_API_PORT=5000

# 機器 2（改成不同的端口）
MAIN_API_PORT=8889
CNSH_FASTAPI_PORT=8001
THREE_SYSTEM_API_PORT=5001
```

---

### 場景 3: 只啟動某些服務

**問題**: 只想用翻譯系統，不用 API

**解決**:
```
AUTO_START_CNSH_TRANSLATOR=true
AUTO_START_FASTAPI=false
AUTO_START_THREE_SYSTEM=false
```

---

### 場景 4: 提高系統性能

**問題**: 系統處理速度太慢

**解決** (按順序試):
1. 增大 `MAX_CONCURRENT_TASKS` (5 → 10)
2. 增大 `MAX_QUEUE_LENGTH` (1000 → 5000)
3. 減小 `QUEUE_CHECK_INTERVAL` (0.5 → 0.1)

```
MAX_CONCURRENT_TASKS=10      # ↑ 增大
MAX_QUEUE_LENGTH=5000        # ↑ 增大
QUEUE_CHECK_INTERVAL=0.1     # ↓ 減小
```

## ⚠️ 常見錯誤

### ❌ 錯誤 1: 端口號超出範圍

```
CNSH_FASTAPI_PORT=99999     # ❌ 太大（max 65535）
CNSH_FASTAPI_PORT=80        # ❌ 太小（需要 sudo）
```

✅ 正確:
```
CNSH_FASTAPI_PORT=8000      # 在 1024-65535 之間
```

---

### ❌ 錯誤 2: 路徑不存在

```
LOCAL_DB_PATH=/nonexistent/path/data.db  # ❌ 目錄不存在
```

✅ 正確:
```
LOCAL_DB_PATH=~/.longhun/work_records.db  # ✓ 會自動創建
```

---

### ❌ 錯誤 3: 重複的端口

```
CNSH_FASTAPI_PORT=8000      # 端口 8000
THREE_SYSTEM_API_PORT=8000  # ❌ 也是 8000
```

✅ 正確:
```
CNSH_FASTAPI_PORT=8000      # 不同
THREE_SYSTEM_API_PORT=5000  # 不同
```

---

### ❌ 錯誤 4: 語法錯誤

```
CNSH_FASTAPI_PORT 8000      # ❌ 少了 =
CNSH_FASTAPI_PORT= 8000     # ❌ 多了空格
CNSH_FASTAPI_PORT=8000x     # ❌ 非數字
```

✅ 正確:
```
CNSH_FASTAPI_PORT=8000      # 格式: KEY=VALUE
```
