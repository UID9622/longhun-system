【最快開始】

1. 打開終端
2. 進入目錄: cd ~/longhun-system/_work
3. 運行: python3 龍魂統一控制臺.py
4. 輸入: all (啟動所有服務)

完成！ ✅

================================================================================

【5 個服務】

1️⃣ CNSH 翻譯系統
   後台無限監聽，自動翻譯
   (無需訪問網址)

2️⃣ CNSH FastAPI
   外部提交任務的接口
   訪問: http://localhost:8000/docs

3️⃣ 三系統 API
   6 種排序算法
   訪問: http://localhost:5000/control

4️⃣ DNA 識別鎖
   自動驗證簽名
   (內部使用)

5️⃣ 意圖翻譯官
   自然語言→指令
   (內部使用)

================================================================================

【常用命令】

all     啟動所有服務 ⭐ 最常用
stop    停止所有服務
status  查看狀態
test    運行測試
clear   清理緩存
help    幫助
exit    退出

================================================================================

【訪問地址】

CNSH 任務提交:
  http://localhost:8000/docs

三系統 API:
  http://localhost:5000/control

狀態查詢:
  輸入: status

================================================================================

【故障排除】

無法連接?
  → 檢查是否輸入了 "all"
  → 運行 "status" 查看服務是否啟動

找不到模塊?
  → pip install fastapi uvicorn pydantic requests

端口被佔用?
  → 輸入 "stop" 停止所有服務

================================================================================

【重要】

不要分散運行各個服務！
用這個統一控制臺，一鍵管理所有東西。

有多個服務器和操作台?
用控制臺的 "status" 查看全部狀態。

簡單易用 = 龍魂系統的宗旨
