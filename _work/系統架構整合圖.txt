【配置文件內容結構】
================================================================================

.longhunsystemconfig (單一源)
│
├─ 統一入口配置 ⭐
│  ├─ MAIN_API_HOST=0.0.0.0     ← 監聽地址
│  └─ MAIN_API_PORT=8888        ← 統一入口端口
│
├─ 內部服務端口
│  ├─ CNSH_FASTAPI_PORT=8000    ← FastAPI 端口
│  └─ THREE_SYSTEM_API_PORT=5000 ← API 服務器端口
│
├─ 本地存儲路徑
│  ├─ LOCAL_DB_PATH=~/.longhun/work_records.db
│  ├─ NOTION_CACHE_PATH=~/.notion_cache
│  └─ LOG_PATH=~/.longhun/logs
│
├─ Notion 集成（可選）
│  ├─ NOTION_API_KEY=
│  └─ NOTION_DATABASE_ID=
│
├─ 服務控制
│  ├─ AUTO_START_CNSH_TRANSLATOR=true
│  ├─ AUTO_START_FASTAPI=true
│  └─ AUTO_START_THREE_SYSTEM=true
│
├─ 日誌設置
│  ├─ LOG_LEVEL=INFO
│  └─ SAVE_LOG_TO_FILE=true
│
├─ 隊列和性能
│  ├─ QUEUE_CHECK_INTERVAL=0.5
│  ├─ MAX_RETRIES=3
│  ├─ MAX_CONCURRENT_TASKS=5
│  └─ MAX_QUEUE_LENGTH=1000
│
└─ 安全設置
   ├─ CORS_ORIGINS=*
   └─ API_AUTH_TOKEN=

【文件修改總結】
================================================================================

修改的文件:
  ✅ cnsh_fastapi_interface.py
     - 添加: from 配置读取器 import CONFIG
     - 改變: port = 8000  →  port = CONFIG.get('CNSH_FASTAPI_PORT', 8000)
     - 改變: host = "0.0.0.0"  →  host = CONFIG.get('MAIN_API_HOST', '0.0.0.0')
     - 改變: run(..., port=8000, ...)  →  run(..., port=port, ...)

  ✅ longhun_api_server_stdlib.py
     - 添加: from 配置读取器 import CONFIG
     - 改變: PORT = 5000  →  PORT = CONFIG.get('THREE_SYSTEM_API_PORT', 5000)
     - 改變: HOST = "0.0.0.0"  →  HOST = CONFIG.get('MAIN_API_HOST', '0.0.0.0')

  ✅ 龍魂統一控制臺.py
     - 添加: from 配置读取器 import CONFIG
     - 改變: SERVICES 硬編碼  →  SERVICES = get_services()（動態生成）
     - 改變: 端口打印 "8000"  →  使用 SERVICES['2']['port']（動態）

新建的文件:
  ✅ .longhunsystemconfig - 統一配置文件
  ✅ 配置读取器.py - 配置讀取器模塊
  ✅ test_unified_config.py - 配置整合測試
