# 通心译 · 引用规范 v0.1
归属: 龍魂系统 UID9622 · 2026-08-03

## 一、定位
通心译 = 中文意图 → 机器指令 的翻译层。语义库是它的词典，语义抽屉是词典的分层书架。
没有语义库的通心译是空壳；没有抽屉的语义库是乱麻。

## 二、三层结构
```
通心译 (引擎)
  └─引用→ 语义库总账 (账本/路由表)
            └─索引→ 语义抽屉 D01~D08 (词元实体)
```

## 三、引用语法
| 语法 | 含义 | 例 |
|---|---|---|
| `@{抽屉}.{词元}` | 显式引用，score=1.0 | `@D03.铸码` |
| 自然语言 | 四级匹配 | "帮我铸造DNA" → @D03.铸码 |
| `@{抽屉}.*` | 整抽屉展开 | `@D07.*` 列出文化映射全部词元 |

## 四、解析流水线（已实现: bin/lh_tongxinyi_resolver.py）
```
输入 → 去噪 → ①显式引用 → ②精确词元 → ③别名 → ④模糊(编辑距离≥0.5) → ⑤抽屉路由
     → 命中: 输出 {en, cnsh, gua, note} + score + via
     → 未命中: 提示"增补词元进对应抽屉"（未命中日志=语义库生长点）
```

## 五、词元实体（七字段焊死）
```yaml
term: 铸码          # 中文词元（主键）
alias: [铸造DNA]     # 别名阵列
en: dna generate     # 英文/命令映射
cnsh: 铸码           # CNSH 中文原生指令
gua: ䷱鼎            # 卦象标签（王弼序）
status: 种子         # 种子→审核→焊死
note: 调用DNA生成器   # 一句话语义
```

## 六、生长协议（自动化）
1. 通心译每次未命中 → 自动写入 `未命中日志`
2. 每周巡检: 未命中 Top10 → 人工/AI 增补进抽屉（status=种子）
3. 词元被实战引用 ≥3 次 → 审核 → 焊死（P0: 不删除只冻结）
4. 每次变更铸 DNA: `lh_dna_generator.py generate --action SEMLIB-UPDATE`
5. 自检: 每个词元 resolve(自身term) 必须 score≥0.95 命中自己，否则报警

## 七、与既有系统的接口
- DNA 生成器: `bin/lh_dna_generator.py`（本包上级 longhun-dna-generator/）
- 人格运行时: 抽屉 D04/D05/D06 默认人格=审计师，D07=哲人（见总账 persona 字段）
- 官网啟動AI: knowledge.ts 可批量导入本库词元作为问答知识
- CNSH 论文: 本库即论文的"词汇表"实证附件
