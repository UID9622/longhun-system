P0 · 立法原意

短视频时代，「本片纯属虚构」只出现在片头一行小字，观众三秒后遗忘，长期浸泡在演绎内容中，把剧场当现实。龍魂真实性标识协议规定：真实性标识必须常驻于每一个内容单元——每一段文字、每一句台词、每一个画面出现时即带标识，不可剥离、不可翻页即失。

P1 · 三色定义（焊死）

标识视觉定义判定标准
实高亮金色 · 实色 · 发光真实层真实采访、可验证数据、专业知识讲解、有来源的真实对话记录。必须附来源。
演灰色 · 半透明 · 虚线框演绎层情景剧场、虚构剧情、模拟对话、AI 生成场景、艺术加工。
疑红色 · 呼吸闪烁存疑层未经验证的断言、网传信息、无来源引用、AI 幻觉风险内容。

P2 · 标注语法

脚本层使用行首标签，机器可解析，视频流水线与知识图谱共用同一套规则：

  • [实|来源:央视采访2026-07] 后接真实内容，来源必填，缺来源自动降级为 [疑]
  • [演] 后接演绎内容
  • [疑] 后接存疑内容
  • [混] 真实事件改编的演绎，主标识为 [演]，其中引用真实片段处内嵌 [实]

P3 · 渲染规则

  1. 常驻：角标随内容单元同生同灭，禁止仅在片头/片尾声明。
  2. 同级：标识视觉权重不得低于内容文字本身的 20%。
  3. 降级自动：声称「实」但无来源 → 系统自动改判「疑」并红闪。
  4. 不删除只冻结：历史标注错误不改写，追加更正记录（龍魂 P0 原则）。

P4 · 集成接口（预留）

  • 视频流水线：标注脚本 → 字幕轨道生成三色字幕 + 常驻角标图层
  • 知识图谱：节点 color=实/演/疑，边线标注「来源：实证/演绎/存疑」
  • 龍魂民生审计层：商业宣传内容强制打标，演绎广告冒充真实案例即触发审计记录
