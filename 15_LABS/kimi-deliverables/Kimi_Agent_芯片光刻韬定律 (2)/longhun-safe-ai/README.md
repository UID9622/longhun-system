# 龍魂最安全AI · 上下文安全引擎 v1.1

给代码小白看的一键运行说明。零安装、零第三方依赖，有 Python3 就能跑。

## 边界声明（显著位置）

- **不碰政治**：本引擎及其执法审计网关均不做内容定性，不提供对任何政府/政治事务的接入。
- **不主动上报、不实时监控用户**：仅在“系统内确证严重事件 + 有效法律凭证 + 案件范围绑定”三条件齐备时，才依法依规提供审计通道。
- **数据本地不出户**：审计账本与上游哈希账本以 JSONL 形式只追加写入本地（如指定路径），不联网、不上传；证据包导出即离境审计，导出行为全程上链。
- **最小留存**：上游数据账本只存 SHA-256 哈希 + DNA，不存原始请求内容副本。

## 它是怎么判断的？（说人话）

不是关键词黑名单。它把一句话拆成"信号类别"打分：

- 你在**学习**（什么是/为什么/怎么防）→ 减分 → 放行并给你防护知识
- 你在**索取操作细节**（给我步骤/剂量/payload/怎么绕过）→ 加分 → 熔断
- 你**反复试探**（历史上多次灰色记录）→ 逐次加分升级 → 从L1升到L2再到L4
- 你想**删审计记录** → 别想了，直接最高级L4，这是焊死的规则
- 你**伪造执法凭证** → 同样L4，视同F7隐瞒同级的腐蚀行为

每次判定都会用中文大白话告诉你：扣了哪些分、加了哪些分、为什么是这个级别、不服去哪申诉。

## v1.1 新增：执法审计网关

四层接口：

- **G1 公开层**：聚合统计（总数/分级分布），零门槛，不含个体内容
- **G2 主体层**：用户查自己的记录+申诉；运维只能看系统健康/阈值，看不了内容；审计只读回放打分过程
- **G3 案件层**：本国执法按案件调取完整证据链，必须满足 T1（L3/L4确证）+ T2（有效凭证）+ T3（绑定案件DNA）
- **G4 国际层**：跨国协作，在G3之上需P3双合规开关开启（一国一策）

**执法也被审计**：每次执法查询本身生成一条审计记录，上DNA链，永久可查。

## 上游数据DNA

所有进入引擎的上游数据（用户请求、输入文档、历史对话批次）先取 SHA-256 哈希，再盖DNA：`#龍芯⚡️{干支}·{卦名}-上游数据-{类型}-{序号}`。账本只存哈希+DNA，原始内容不留底；证据包导出时凭哈希校验完整性。

## 调权重

打开 `config/p0_p4_rules.yaml`，改 `p2_signal_weights`、`p2_thresholds` 或 `p3_gateway_policy` 下面的值，重新运行即生效。引擎没有装 yaml 库也能读（内置简易解析）；读不到文件就用内置同款默认值。`p0` 段的值写了也白写——物理焊死。

## 本地部署、数据不出户

纯标准库单文件，不联网、不装包。审计账本以 JSONL 形式只追加写入本地（如指定 `ledger_path`），引擎代码里**不存在** update/delete 方法——不是约定，是没这双手。
