## 对设计稿的实测修复（设计稿直接跑会错的地方）

| # | 设计稿缺陷 | 本版修复 |
|---|---|---|
| R1 | 笛卡尔积抽取，同句多实体乱配 | 位置就近配对：主语→其后最近谓语→其后最近宾语 |
| R2 | 无极性概念，"不得存储"vs"应存储"被判一致 | 否定词窗口检测（不得/禁止/不/未…），同值不同极性=🔴 |
| R3 | 冲突按 AI 对 O(n²) 刷屏 | 按(主语,谓语)聚合成取值阵营，一条说清"用户(龍魂/kimi) vs 国家(deepseek)" |
| R4 | sentence_transformers 未装则辅助信号整体缺失 | 自动降级纯stdlib词袋余弦，辅助信号永远可用 |
| R5 | `generate_dna` 用 md5+日期，且文档手写干支 | 全部走 `dna_trace.生成DNA()` 干支算法签名 |
| R6 | 谓词表缺"归"，"数据主权归用户所有"整条漏抽取 | 补入并归一化到"归属" |

另新增**覆盖率信号**（设计稿没有）：仅单个 AI 对某事实作证 → 🟡 提示"无交叉验证"，这是漏报的主要来源。
