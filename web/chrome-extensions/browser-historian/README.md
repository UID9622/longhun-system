# 龍魂·浏览器史官 v1.1

> Chrome 浏览器历史分类扫描器 · 全本地运行 · 数据不出设备

## 安装

❗ **必须先开 Chrome 开发者模式**：`chrome://extensions` → 右上角开启「开发者模式」

1. 打开 `chrome://extensions`
2. 点击「加载已解压的扩展程序」
3. **选中 `browser-historian` 文件夹本身，不是打开文件夹**
4. 确认扩展列表中看到「龍魂·浏览器史官」

> 🚫 常见错误：选成了上层目录 → 报错「清单文件缺失」。请确保选的是 `browser-historian/` 这个目录本身。

## 使用

1. 点击 Chrome 工具栏上的龍魂图标
2. 点击「🔍 扫描历史」扫描
3. 点击「📥 导出 JSON」导出分类数据

## 权限说明

| 权限 | 用途 |
|:---|:---|
| `history` | 读取浏览器历史记录（用于扫描和分类） |
| `storage` | 在本地存储扫描结果（不用每次重扫） |
| `downloads` | 导出 JSON 时弹出系统保存对话框（自选目录/U盘） |
| `host_permissions` | **空** — 不注入任何网页 |

## 数据安全

- ✅ 所有数据存储在 **Chrome 本地 storage.local**
- ✅ 数据 **不出浏览器，不传云端，不上传任何服务器**
- ✅ 导出为本地 JSON 文件，你自选保存位置（下载/桌面/U盘）
- ✅ CSP 仅允许 `'self'`，不加载外部资源
- ✅ `host_permissions: []`，不注入、不拦截任何网页

## 故障排查

| 问题 | 解决 |
|:---|:---|
| 「清单文件缺失」 | 确认选的是 `browser-historian/` 文件夹本身，不是上层目录 |
| 点击没反应 | 确定开了开发者模式 + 选对了目录 |
| 扫描很慢 | 正常，取决于历史记录数量（通常几千条） |
| 导出报「请先扫描」 | 先点「扫描历史」再导出 |
