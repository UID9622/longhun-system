## 三、收益公式

**单期贡献值**：

```
Contribution_i = ActivityCount_i × QualityScore_i × FieldWeight_i × TimeDecayCoefficient
```

**个人当期 merit**：

```
Merit_i = Σ Contribution_i
```

**月度收益分配**：

```
MonthlyRevenue_i = (Merit_i / TotalMerit) × DistributablePool
```

其中：

- `ActivityCount_i`：该领域当期有效活动次数。
- `QualityScore_i`：经社区与算法审计后的质量分，范围 [0, 1]。
- `FieldWeight_i`：该贡献领域的权重（见白皮书第五章）。
- `TimeDecayCoefficient`：时间衰减系数，鼓励持续贡献。
- `DistributablePool`：当月可分配收益池。
- `TotalMerit`：当期所有合格贡献者的 merit 总和。

1. **质量审计**：社区评分 + AI 辅助审计，低质量贡献被降权或标记。
2. **领域多样性奖励**：鼓励跨领域贡献，避免单一行为刷分。
3. **时间衰减**：历史贡献持续衰减，抑制“躺分”。
4. **举报与申诉**：同行举报机制 + 反作弊委员会复核；只冻结、不删除。
