## 二、老大只需要做一件事（2 分钟）

1. 手机装 **TronLink** 钱包（官方：tronlink.org · 或 App Store 搜 TronLink）
2. 创建钱包 → 备份助记词（**抄在纸上，永不拍照/永不发网**）
3. 点"接收" → 复制 **TRC20 USDT 地址**（T 开头 34 位）
4. 把地址填进 `config/usdt_receive.json` 的 `wallet` 字段
5. 告诉我，我把地址填进官网 → 官网自动显示收款地址+复制按钮

## 四、对账用法

```bash
python3 bin/lh_usdt_monitor.py --check    # 配置是否就绪
python3 bin/lh_usdt_monitor.py            # 拉取新入账（写台账）
python3 bin/lh_usdt_monitor.py --ledger   # 查看台账
```

数据流：只读查询波场公开链（TronGrid/Tronscan）→ 匹配入账 → 写本地台账。
**全程不上传任何用户数据**：只传公开钱包地址（本就公开在官网上）。

## 五、合规提示（事实·不劝不拦）

- 中国法律禁止虚拟货币交易平台业务；**个人间打赏/捐赠/持有属灰色地带，不直接违法**

- 收款性质若是"打赏/赞助"，建议官网注明"自愿支持，非商品交易"
