- [ ] 所有代码通过 `lh_anti_tamper.py` 防篡改扫描

- [ ] 鸿蒙 API 交付标准 7 项检查通过

## 2. 版本号规则

采用 `主.次.修订`：

- 主版本：架构级变更
- 次版本：新组件加入
- 修订：bug 修复、文档更新

## 3. 发布步骤

### 3.1 本地归档

```bash
python3 bin/lh_gitee_push.sh dragon-soul-pack
```

### 3.2 推送 Gitee（主仓）

```bash
cd L7_数据层/gitee-mirror/dragon-soul-pack
git init
git remote add origin https://gitee.com/uid9622/dragon-soul-pack.git
git add .
git commit -m "release v1.0.0"
git push -u origin master
```

### 3.3 同步 GitHub（镜像）

```bash
git remote add github https://github.com/UID9622/dragon-soul-pack.git
git push github master
```

> 同步方向：Gitee → GitHub，不可逆。
