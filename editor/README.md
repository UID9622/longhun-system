# 龍碼中文編輯器 v1.0

> 沒有黑箱，代碼全部公開。中文就是變量名，中文就是註釋，中文就是邏輯。

**DNA**: `#龍芯⚡️2026-06-18-LONGHUN-CHINESE-EDITOR-FILE1-FILE1-v1.0-1`

---

## 為什麼要做中文編輯器

國外的編輯器再好，也是國外語境長出來的。
龍碼中文編輯器只做一件事：讓中國人用中文思維寫代碼。

- 中文變量名
- 中文註釋
- 中文菜單
- 中文運行日誌

每個國家的語言都能跑在計算機裡面，那才叫牛逼。

---

## 功能

- 新建 / 打開 / 保存 / 另存為
- 撤銷 / 重做 / 剪切 / 複製 / 粘貼
- 運行 Python 腳本（F5）
- 運行選中的 Shell 命令
- 輸出面板與狀態欄
- 自動保存提示

---

## 啟動方式

### 桌面 App

`~/Desktop/龍碼中文編輯器.app`

雙擊即可啟動。

### 命令行

```bash
cd ~/longhun-system
python3 editor/龍碼編輯器.py
```

---

## 快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| Cmd+N | 新建 |
| Cmd+O | 打開 |
| Cmd+S | 保存 |
| Cmd+Z | 撤銷 |
| Cmd+Shift+Z | 重做 |
| F5 | 運行 Python |

---

## 技術說明

- 使用 Python 標準庫 `tkinter`，無外部依賴。
- 字型使用 macOS 內建 `PingFang SC`，中英文等寬體驗良好。
- 代碼語法仍是 Python，但變量名、函數名、註釋全部支持中文。
