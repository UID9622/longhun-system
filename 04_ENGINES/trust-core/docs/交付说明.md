## 四、调优参数
| 参数 | 默认 | 说明 |
|------|------|------|
| `--execute` | 关（dry_run） | 显式开启才执行安全策略修复 |
| `--log-dir` | 项目 logs | 日志扫描目录（plist 已指 $LONGHUN_HOME/logs） |
| `--ports` | 空 | 逗号分隔端口健康检查（warn 级） |
| `breaker_threshold` | 3 | 熔断矛盾次数 |
| `max_attempts` | 3 | 自愈重试上限，超限上耻辱墙 |

| `LONGHUN_DNA_GENERATOR` | 自动探测 | 指向本地干支生成器即升级 DNA 格式 |

## 七、QA / 错误排查
| 症状 | 排查 |
|------|------|
| `--status` 退出码 2 | 看最近 HEAL_REPORT；status 非0/1/2 会被 clamp 成 2 |
| 修复没执行 | 默认 dry_run，加 `--execute`；破坏性回滚另需确认码 |
| 耻辱墙有记录 | 该错误属业务逻辑/连续失败，设计上不自动碰，人工处理 |
| 服务重启策略变 ESCALATE | 该错误未带 restart_cmd，为防瞎跑不计入可执行 |
| DNA 显示占位串 | 正常：本地生成器未接入；设 LONGHUN_DNA_GENERATOR 即升级 |
