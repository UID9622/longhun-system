## 🔌 与龍魂系统的集成

### 集成点1：Widget S1 → 熔断系统

```
用户发布文章（CSDN/知乎/掘金）
  ↓
watermark-scanner.js 嵌入DNA
  ↓
dna-detector.js 三层检测
  ↓
hook-detector.js 识别18+11钩子
  ↓
计算威胁等级（低/P2/P1/P0/∞）
  ↓
调用 red_blue_simulator.check_threat()
  ↓
获得防御结果（成功/失败）
  ↓
人格决策引擎生成推荐
  ↓
宝宝执行决策（继续/隔离/停止）
```

### 集成点2：DNA 流水线 → 熔断系统

```
Step 1: 发布·打水印
  ↓ 如果威胁≥P0且防御失败
    → 熔断执行器·隔离处理
    → 哨兵P17·加强监控
  ↓
Step 2: 检测·取证
  ↓ 侵权评分×威胁等级
    → 更新人格决策矩阵
  ↓
Step 3: 追溯·发布
  ↓ 乔前辈审核
    → 代码签章·DNA追溯
  ↓
Step 4: 审计·闭环
  ↓ 账本记录
    → 不可变·SHA-256链
```

### 集成点2.5：桌面 Widget + 浏览器扩展 一体化

```
本地 LongHunWidget (桌面/iOS/macOS) 与 LongHunWidget-Browser (Chrome/浏览器插件)
  ↓
共享 DNA 追溯逻辑：本地 Widget 显示当前审计/路由/元字状态
  ↓
浏览器扩展捕获发布环境、打水印、检测侵权、生成证据
  ↓
双端协同：桌面可视化 + 浏览器实时采集
  ↓
统一进入 DNA 追溯流水线 + 熔断系统
```

**说明**：`LongHunWidget` 与 `LongHunWidget-Browser` 不是单独两个模块，而是同一套“龙魂追溯助手”体系中的两端，逻辑上密不可分。

### 集成点3：知识库 → 决策参考

```
Obsidian 龍魂知識庫/
├── 熔断系統_推演報告.md     ← 推演结果
├── 人格自動化_決策矩陣.md    ← 决策规则
└── LongHunWidget項目.md      ← Widget集成说明
```
