## 一、总纲·为什么要这个标准

### 1.1 问题

别人有系统的英文教学。我们没有——不是因为缺知识，是因为缺「根据对面的人是谁，自动换说法」的路子。

同一个概念「DNA追溯码」，对不同人该怎么说：

| 对谁说 | 该怎么说 |
|:---|------|
| 理工科程序员 | 「v∞干支卦哈希·区块链式不可逆链·A-BOM审计锚」 |
| 初中生 | 「给你的代码盖了个章，谁改过都看得见，赖不掉」 |
| 60岁农村大爷 | 「跟户口本一样，你的东西打了记号，丢不了也假冒不了」 |
| 外国开源社区 | 「Immutable lineage tracing with I Ching hexagram anchoring」 |

**四种说法都对，但说错了对象 = 白说。**

### 1.2 设计理念

> **不是做一个「最好的教程」，是做一套「自动换说法」的机制。**
>
> 知识不变。包装变。每个人用自己的语言、自己的节奏、自己的认知框架，走进同一个龍魂。

三个铁律：

| # | 铁律 |
|:---|------|
| 1 | **知识不变，表达自适应** — 同样的DNA追溯码概念，8种说法，核心含义不缩水 |
| 2 | **不侮辱学习者智商** — 不因学历低就喂简化版，给大白话但深度不减 |
| 3 | **中国温度** — 教学不是冷冰冰的技术文档翻译，是手把手带你进去 |

```
教学输出 = 核心知识 × 画像适配器 × 通心译转换 × 温度调幅
```

### 3.2 画像适配器

```python
adapter(level, knowledge_unit):
    """
    同一知识点，按画像等级生成不同表达。
    知识语义不变，包装变。
    """
    depth_map = {
        L1: ["是什么", "为什么重要", "一个类比"],
        L2: ["是什么", "为什么重要", "怎么运作", "一个类比+一个实例"],

        L5: ["全量·不限格式·UID9622自由导航"],
    }
    return render(knowledge_unit, depth_map[level])
```

### 3.4 温度调幅

```
温度 T ∈ [0.0, 1.0]

T=1.0  🧸 宝宝模式：「老大你看，这个东西其实很简单的嘛～来我手把手教你」

默认 T = 0.7（朋友温度）。
```

**任何知识点必须至少覆盖两个象限**，确保一个初中生和一个博士都能找到入口。

| 维度 | 要求 | 熔断条件 |
|:---|------|------|
| **准确性** | 科学事实·可溯源·标注确定性等级 | 事实错误 → 🔴 立即修正 |
| **完整性** | 覆盖概念链条不跳步·不默认前置知识 | 关键跳跃 > 2步 → 🟡 补充 |
| **可读性** | 目标画像80%的人能看懂 | 同画像可读率 < 60% → 🟡 重写 |
| **温度** | 不冰冷·不俯视·不说「你应该」 | 俯视/说教语气 → 🟡 改语气 |
| **文化锚** | 中国哲学框架·不自贬·不迎合西方审美 | 文化自贬 → 🔴 熔断 |

### 4.3 内容审核流程


## 五、教学交互标准

### 5.1 不自适应的场景不叫教学

以下场景**禁止**使用固定文本：

| 场景 | 自适应要求 |
|:---|------|
| 概念解释 | 必须根据画像选择解释深度 + 温度 |
| 报错提示 | 必须根据画像选择报错语言（L1:"出了点小问题"vs L4:"NullPointerException at line 42"）|
| 导航引导 | L1: 图文按钮 → L4: 命令清单 |
| 搜索/问答 | 同一问题·不同画像·不同答案 |

### 5.2 学习节奏自适应

```
快进权：答对3次连续 → 自动跳过已知内容
回退权：任意时刻可请求「用更简单的话再说一遍」
停滞检测：3分钟无交互 + 困惑信号 → 主动问「要不要换个说法？」
跳过权：标注「我已知晓」→ 跳过当前模块
```

### 5.3 挫败保护协议

> 学习是为了知道，不是为了被考试羞辱。

- 不问「你学会了吗」 → 改问「这块我说清楚了吗」
- 答错不扣分 → 记录为「需要换个说法」
- 连续3次挫败信号 → 自动降画像等级 + 换教学策略 + 安抚
- 永不显示排行榜/分数/与他人的比较（**外部评价是焦虑源**）
