## §4 七因子详细定义

| 因子 | 代码 | 含义 | 取值 | 权重 |
|:---:|:---:|:---|:---|:---:|
| P | Promise | 是否产生承诺 | 有承诺 / 无承诺 | 15% |
| F | Fulfill | 执行结果 | 已兑现 / 未兑现 / 部分兑现 | 20% |
| T | Time | 时效偏差 | 承诺时间−实际时间 (小时) | 10% |
| E | Emotion | 执行情绪 | 心甘情愿 / 敷衍 / 甩脸 / 麻木 | 15% |
| C | Cost | 成本计量 | 实际投入 (分钟/元) | 5% |
| R | Repeat | 重复失信 | 同类失信累计 | 10% |
| A | Audience | 受众指向 | 为自己/为伴侣/为家人/为外人/为公众 | 15% |
| X | eXplain | 解释倾向 | 爱解释 / 不解释 / 真认 / 无所谓 | 5% |
| Y | Yield | 认错模式 | 真改 / 硬扛 / 无所谓 / 无反应 | 5% |
| Z | Zigzag | 行为波动率 | 当日承诺数÷当日兑现数 | — |

```

if 7F-F == "已兑现" and 7F-A == "为外人"  → MODE-外耗型守信
if 7F-F == "未兑现" and 7F-Y == "无所谓"  → MODE-内耗型自毁
if 7F-Z > 2                              → MODE-波动型摇摆
else                                       → MODE-稳定型自律
```

## §6 单事件信用分算法

```
信用分 = Fulfillment × TimeBonus × EmotionMultiplier × CostFactor × RepeatPenalty × AudienceWeight

Fulfillment      = 7F-F == "已兑现" ? 1.0 : 0.0
TimeBonus        = 1 + (7F-T < 0 ? 0.5 : −0.3 × 7F-T)
EmotionMultiplier = 7F-E == "心甘情愿" ? 1.2 : "敷衍" ? 0.5 : 0.2
CostFactor       = 7F-C > 0 ? 1.0 : 0.5
RepeatPenalty    = 1 + 7F-R × (−0.5)
AudienceWeight   = 为伴侣?1.5 : 为家人?1.2 : 为自己?1.0 : −1.0

信用分 ∈ [−10, +10]
```
