二、数学模型（硬约束·焊死）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 2.1 变量定义

| 变量 | 含义 | 单位 | 数据来源 |
|:---|:---|:---|:---|
| N | 企业税后净利润 | 元（人民币） | 经审计的年度财报 |
| R_e | 员工分配总额 | 元 | 企业工资系统 + 分红记录 |
| R_f | 创始人/实控人提取 | 元 | 银行流水 + 税务申报 |
| R_i | 再投资/储备 | 元 | 企业对公账户留存 |
| R_p | 公益/社会 | 元 | 公益支出凭证 |
| R_b | 风险缓冲 | 元 | 专项储备金账户 |

### 2.2 不等式组（焊死·不可修改）

```
R_e ≥ 0.50 × N          （员工分配不得低于50%）
R_f ≤ 0.10 × N          （创始人提取不得高于10%）
R_i ≥ 0.30 × N          （再投资不得低于30%）
R_p ≥ 0.05 × N          （公益不得低于5%）
R_b ≤ 0.05 × N          （风险缓冲不高于5%）

恒等式约束：R_e + R_f + R_i + R_p + R_b = N
```

### 2.3 边界条件与边缘案例

| 场景 | 判定 | 处理 |
|:---|:---|:---|
| N ≤ 0（亏损） | 不触发分成审计 | 仅记录·不冻结·待下期盈利后补审 |
| N > 0 但极小（< 10万元） | 正常审计·放宽公益下限至2% | 小微企业保护阈值 |
| R_f 为负（创始人注资补亏） | 计入 R_i（再投资） | 创始人掏钱补公司 = 再投资行为 |
| 员工数 ≤ 3 人（含创始人） | R_e 下限调整为 40% | 微型企业·创始人即员工 |
| 公益支出无合适渠道 | R_p 可结转下期（≤ 2期） | 防止为凑数乱捐 |
| 风险缓冲超额（R_b > 5%） | 🟡 标记·要求说明用途 | 超额部分视为 R_i 或退还 |

### 2.4 冲突消解优先级（净利润不足时·逐级削减）

```
优先级 1（最高·不可削减）：R_e — 员工分配
优先级 2（可削减至0）    ：R_f — 创始人提取 → 自动归零
优先级 3（可削减至0）    ：R_b — 风险缓冲 → 削减至0
优先级 4（可削减至0）    ：R_p — 公益 → 削减至0
优先级 5（最后削减）    ：R_i — 再投资 → 最后削减
```

> **焊死规则**：无论任何情况，R_e（员工分配）绝对优先，不可削减。
> 创始人必须在员工分配满足后才有提取资格。
