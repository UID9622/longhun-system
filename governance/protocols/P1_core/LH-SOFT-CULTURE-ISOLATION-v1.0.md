## 一、问题定义

### 1.1 什么是"软文化污染"

软文化污染 ≠ 硬性文化入侵（如明确的文化贬低言论）。它是**温水煮青蛙式的认知渗透**：
- 表面看起来是"正常内容"
- 单个词单独看没问题
- 组合起来就形成话术范本
- 批量传播后改变人的认知基线

### 1.2 为什么不能用简单的关键词黑名单

"自由""人权""民主""觉醒""独立思考"——这些词本身是**中性词**，老百姓正常聊天时也用。

简单关键词匹配 = 误伤普通人 = 伤害言论自由 = 违背"为人民服务"P0天条。

**结论：必须用三层过滤架构，而非一刀切。**

### 2.1 三层分别回答了什么问题

| 层 | 回答的核心问题 | 为什么这样分 |
|:---:|------|------|
| L1 | **同一个词，为什么这次算、那次不算？** | 因为单一词无意义，组合特征才有意义 |
| L2 | **是真人随手发的，还是组织性批量操作？** | 因为批量=意图，单次=随机 |
| L3 | **语境是什么？带货？聊天？讨论？** | 因为包装话术有明确使用场景特征 |

### 2.2 边界判定的数学表达

```
P(污染 | 词串W, 传播路径P, 语境C) = 
  σ( α·f_combo(W) + β·f_path(P) + γ·f_context(C) - θ )

其中:
  f_combo(W) = 词串的共现概率偏离正常语料库的程度
  f_path(P)  = 传播路径的组织性程度
  f_context(C) = 语境的话术化程度
  α=0.35, β=0.35, γ=0.30  ← 组合特征+传播路径并重
  θ=0.45  ← 阈值，低于此视为正常表达
```

### 3.3 组合特征计算公式

```python
def combo_signal(words: list[str]) -> float:
    """
    输入: 一段话中提取的"信号词"列表
    输出: L1组合特征得分 [0,1]
    
    原理: 单个中性词 ≈ 0信号，多个模板词共现 → 指数增长
    """
    matched_templates = 0
    total_weight = 0.0
    
    for template in TEMPLATE_DB:
        hits = sum(1 for kw in template.keywords if kw in words)
        if hits >= template.min_hits:  # 通常 ≥2
            matched_templates += 1
            total_weight += template.weight * (hits / len(template.keywords))
    
    # 共现指数增长：匹配2个模板的信号远大于匹配1个
    if matched_templates == 0:
        return 0.0
    return 1 - math.exp(-total_weight * matched_templates / N_TOTAL_TEMPLATES)
```

### 4.2 L2路径得分

```python
def path_score(account_meta: dict, text: str) -> float:
    """
    传播路径得分 = 七因子可信度逆转 + 集群效应 + 时序异常
    """
    因子分 = extract_7factor(account_meta)
    可信度结果 = 水军补丁.可信度(因子分)
    c = 可信度结果['c']  # 可信度越高 → 越正常 → 路径分越低
    
    # 路径分 = 1 - 可信度（因为我们要的是"可疑度"）
    path = 1.0 - c
    
    # 集群效应加成
    cluster_boost = analyze_cluster(account_meta)  # 同集群发出 > 0.3加0.15
    if cluster_boost:
        path = min(1.0, path + 0.15)
    
    # 时序异常加成
    timing_boost = analyze_timing(account_meta)  # 协调时间 ≤5秒 > 0.2加0.10
    if timing_boost:
        path = min(1.0, path + 0.10)
    
    return path
```

### 5.2 语境检测方式

```python
def context_score(text: str, source_type: str) -> float:
    """
    语境加成得分
    """
    base = CONTEXT_TABLE[source_type]['base_score']
    
    # 如果文本自身带有强商业信号词
    commercial_signals = ['下单', '购买', '链接', '优惠', '限时', '点击']
    commercial_hits = sum(1 for s in commercial_signals if s in text)
    if commercial_hits >= 2:
        base += 0.10  # 确认是商业语境
    
    return clamp(base, -0.5, 1.0)
```
