## 第三章 核心原则（天条）

**第1条：真品显化** — 商品展示必须过真实度核验，视频太假=直接扣分。

**第2条：知情权前置** — 下单页强制披露清单，逐项确认后才可支付。目标不是说清楚了就不许退，是说清楚到不需要退。

**第3条：实证才计分** — 信誉分只认实证举报；模糊举报一律进反馈池，不扣分、不公示、不定罪。统计学语言：无证据不否定原假设。

**第4条：阶梯赔偿，敢赔加权** — 赔偿按问题严重度走L1-L4法定阶梯，首个实证者分悬赏。商家主动承诺更高档赔付的，信誉分加权。

**第5条：分数晒太阳** — 信誉分公式公开、每笔加减分可查可复核、看板公示。黑箱评分本身就是信任摩擦。

## 第四章 数学模型

### 4.1 信誉分引擎

S ∈ [0, 1000]，入驻初始 S₀ = 500。每日结算：

```
S_{t+1} = clamp(S_t + ΣΔ⁺ − ΣΔ⁻, 0, 1000)
```

**加分项 Δ⁺：**

| 事件 | 分值 |
|------|------|
| 如实描述抽检通过 | +2 / 次 |
| 主动赔付履约完成 | +5 / 次 |
| 连续30天零实证举报 | +10 / 期 |
| 承诺分级升档 | +20 / 档 |

**减分项 Δ⁻：**

| 事件 | 分值 |
|------|------|
| 实证举报成立 | −20 × w（w=严重度权重：轻1/中2/重3） |
| 视频/参数造假实锤 | −50 / 次 |
| 模糊举报 | 0（只进反馈池，永不计分） |
| 恶意举报他人查实 | −30 / 次（举报者反坐） |

**承诺加权系数 κ：** G1=1.0, G2=1.05, G3=1.1, G4=1.2
有效加分 = Δ⁺ × κ

**半衰恢复：** 单次减分记录满180天且该笔扣分之后180天内无新增扣分 → 该笔减分恢复50%。恢复只针对分数，记录永不删除；180天内有再犯则该笔记录维持原扣分。

### 4.2 举报分级

- **收单三要素：** 证据附件 ∧ 订单号 ∧ 具体诉求，缺一 → 模糊举报
- **模糊举报：** 进反馈池，商家7天内可回复；不计分、不公示
- **实证核验：** 证据链完整 → 立案；核验期7天，标记🟡
- **恶意举报反坐：** 同设备簇批量+证据伪造+竞争关系 → −30反坐+熔断

### 4.3 阶梯赔偿

| 档 | 触发 | 处置 | 法条锚 |
|----|------|------|--------|
| L1 | 描述轻微不符 | 退货退款+运费商家担 | 《消法》24条 |
| L2 | 质量问题/虚假宣传 | 退一赔三，不足500按500 | 《消法》55条 |
| L3 | 造假/知假售假实锤 | 退一赔三起步，可至5倍+全店公示7天 | 《消法》55条+承诺 |
| L4 | 食品/安全问题 | 价款十倍，不足1000按1000 | 《食安法》148条 |

赔偿金额 = max(法定下限, 价款 × 档位倍数 × 承诺系数)

### 4.4 找茬悬赏

首个实证举报者奖励 = 赔偿金的 10%（上限单笔5000元），48小时到账。
恶意索赔反坐：威胁曝光敲诈 → 黑名单+反坐扣分+移交线索。

### 4.5 视频真实度核验

```
R = 0.25·r_滤镜 + 0.25·r_AI + 0.20·r_摆拍 + 0.20·r_复测 + 0.10·r_历史
```

- R ≥ 0.85 → 🟢 正常展示
- 0.60 ≤ R < 0.85 → 🟡 强制标注"美化处理中"
- R < 0.60 → 🔴 下架整改+扣分

### 4.6 信任摩擦系数

τ = 纠纷单数 / 成交单数（滚动90天），按店铺、类目、全网三级公示。
目标：入驻商家 τ < 0.5%
