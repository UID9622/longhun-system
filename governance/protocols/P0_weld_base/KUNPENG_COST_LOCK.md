## 三、自动路由规则

### 3.1 任务类型→成本层映射

| 任务类型 | 默认成本层 | 理由 |
|:---|:---:|:---|
| 代码生成·文件操作·简单查询 | L0 本机 | 秒级响应·无网络延迟 |
| 知识查询·文档搜索·轻推理 | L0 本机 | 本地知识库已覆盖 |
| 战略推演·多路径决策 | L1 鲲鹏 | 需多人格并行·需大上下文 |

| 跨境API调用·外部服务 | L2 云端API | 需P77出口审查 |

```
L1 鲲鹏不可用 → 自动降级 L0 本机（轻任务）

```
