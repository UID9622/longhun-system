第五章 数学模型与算法基础

5.1 字符级DNA水印（绿名单签名 z检验）
  嵌入: 每步生成第t个词时，用前一个词的哈希把词表切成绿名单G(γ=0.25)与红名单
  检测: z = (|G| − γN) / √( N·γ·(1−γ) )，z ≥ 4 → 确证水印

5.2 放射性数据标记（训练数据层）
  标记: 训练语料中ρ=1%植入带特异方向向量的标记样本
  验证: 置换检验 p < 0.01 → 确证训练血缘

5.3 血缘哈希链
  DNAₙ = SHA-256( DNA_{n-1} ‖ hash(内容) ‖ UTC ‖ seq ‖ GPG签名 ) 取前128bit

5.4 不可重组性度量
  k-of-n拆分: 方法层(公开)+参数层(本地)+种子层(隔离)
  重组概率 P ≤ 2⁻¹²⁸（缺任一份）

5.5 触发集溯源
  预埋m≥50个特异问答对，二项分布检验

5.6 双证据铁律
  公开指控须同时满足: 水印z≥4 且 触发集r̂≥0.30/p<0.001

5.7 所有权时间证明
  Proof = GPG签名(hash(a)‖DNA链位‖UTC) + 公开时间锚
