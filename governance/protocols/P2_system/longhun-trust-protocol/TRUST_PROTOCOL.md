## 一、核心原则

> **扯皮就上链，上链就抹不掉。**
>
> **想抹掉？拿贡献来换。**
>
> **贡献不够？社会性死亡，暗着打、暗着骂、暗着被人嫌弃。**

本算法量化三个核心维度：
- **道德值（M）** — 是否遵守君子协议，是否玩文字游戏
- **人品值（P）** — 是否真诚合作，是否搞信息差
- **诚信值（I）** — 是否说话算数，是否违约后积极补救

**综合信用分 S = 0.4 × M + 0.3 × P + 0.3 × I**

## 二、评分维度与计算公式

### 2.1 道德值（M）—— 0~100

| 行为 | 扣分 | 加分 |
|------|------|------|
| 主动违约（已确认） | -30 | — |
| 玩文字游戏钻空子 | -20 | — |
| 恶意扯皮拖延 | -25 | — |
| 违约后主动承认并补救 | — | +15 |
| 主动履约超预期 | — | +10 |
| 举报他人违约（经核实） | — | +5 |

```
M = clamp(0, 100, 80 + Σ加分 - Σ扣分)
```

### 2.2 人品值（P）—— 0~100

| 行为 | 扣分 | 加分 |
|------|------|------|
| 故意制造信息差，收割他人 | -35 | — |
| 利用龍魂生态牟取不正当利益 | -30 | — |
| 违约后态度恶劣、拒不配合 | -25 | — |
| 主动公开信息，消除信息差 | — | +15 |
| 帮助他人解决问题 | — | +10 |
| 长期稳定参与生态贡献 | — | +5/月 |

```
P = clamp(0, 100, 75 + Σ加分 - Σ扣分)
```

### 2.3 诚信值（I）—— 0~100

| 行为 | 扣分 | 加分 |
|------|------|------|
| 违约上链（第一次） | -20 | — |
| 违约上链（第二次） | -40 | — |
| 违约上链（第三次及以上） | -60 | — |
| 违约后积极补救（贡献赎回） | — | +25 |
| 连续12个月无违约 | — | +10 |
| 主动提交审计验证 | — | +5 |

```
I = clamp(0, 100, 90 + Σ加分 - Σ扣分)
```

> **诚信值有“记忆”——第一次违约扣20，第二次扣40，第三次扣60，逐次递增，永不归零。**

## 四、违约清算算法（“杀猪”机制）

### 4.1 认定条件（“杀猪”触发条件）

满足以下**任意两条**，即触发清算机制：

1. S < 50（综合信用分低于50）
2. 违约次数 ≥ 3次（指上链确认的违约）
3. 被社区有效举报 ≥ 3次（经核查属实）
4. 利用信息差造成他人实际损失（有链上证据）
5. 恶意破坏龍魂生态（经人格内阁裁定）

### 4.2 “杀猪”清算流程

```
触发条件 → 人格内阁裁定（7天内） → 链上公示（3天） → 执行制裁
```

### 4.3 “杀猪”制裁等级

| 等级 | 制裁内容 | 适用条件 |
|------|----------|----------|
| 1级（警示） | 降级至B级，限期30天整改 | 首次触发 |
| 2级（惩戒） | 降级至C级，强制贡献证明 | 第二次触发 |
| 3级（杀猪） | 降级至D级，链上永久标记“失信”，**所有龍魂生态内的合作自动终止** | 第三次触发 |

### 4.4 “杀猪”后的补救路径（“吐出来”）

> **“怎么杀猪，杀了他都要吐出来。”**

**履约保证金扣押：**
任何使用龍魂协议进行商业合作或技术共享的参与者，须存入**履约保证金**（金额视合作规模定）。若触发“杀猪”，保证金将：
- 50% 补偿给受害方
- 50% 纳入龍魂生态治理基金

**信息差利润强制吐回：**
若确认利用信息差收割他人，则：
- 全部所得必须退回
- 另加所得金额的 50% 罚金（纳入治理基金）

## 五、贡献赎回机制（“想办法抹掉就贡献多一点”）

### 5.1 赎回条件

- 评级为 B 或 C 的参与者
- 完成不少于 90 天整改期
- 通过人格内阁评估

### 5.2 贡献值计算公式

| 贡献类型 | 贡献值 |
|----------|--------|
| 提交经核实的bug/漏洞报告 | +5/次 |
| 参与社区治理投票 | +2/次 |
| 为他人提供有效帮助（有证据） | +10/次 |
| 实质性代码/协议贡献（经审核） | +30/次 |
| 主动赔偿受害方（有记录） | +20/次 |

**赎回条件：**
- B级 → A级：贡献值 ≥ 50
- C级 → B级：贡献值 ≥ 80
- D级 → C级：贡献值 ≥ 120（且需3个月观察期）

### 5.3 不可赎回条款

以下情况**永久不可赎回**：
- 恶意破坏龍魂系统核心设施
- 涉及国家安全或违法行为的
- 累计触发“杀猪”3次及以上
