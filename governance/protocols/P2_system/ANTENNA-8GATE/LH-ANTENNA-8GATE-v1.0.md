## 核心架构：蚁触神经网

**生物原型：蚂蚁触角**

| 蚂蚁行为 | 算法映射 | 优势 |
|:---|:---|:---|
| 触角触碰即传信息 | 节点间零握手通信 | 无TCP三次握手开销 |
| 信息素路径标记 | 动态权重缓存 | 热门路径自动加速 |
| 去中心化决策 | 无 master 节点 | 单点故障不影响全局 |
| 局部信息全局涌现 | gossip 协议 + 八卦阵分区 | 复杂度 O(log n) 而非 O(n²) |

**关键设计**：

```
┌─────────────────────────────────────────┐
│  蚁触神经网 · 信息传递机制               │
├─────────────────────────────────────────┤
│                                         │
│   节点A ──触──→ 节点B                   │
│     ↑              ↓                    │
│   触  碰  即  传  递                    │
│     ↓              ↑                    │
│   节点D ←──触── 节点C                   │
│                                         │
│  规则：                                  │
│  1. 不建立长连接，触碰瞬间完成信息交换     │
│  2. 信息包自带"信息素时效"，过期自动挥发  │
│  3. 八卦阵分区：同卦象节点优先传递        │
│  4. 无中心路由表，每个节点只记邻居        │
│                                         │
└─────────────────────────────────────────┘
```

## 五行映射 · 生物器官对应

| 五行 | 器官 | 系统功能 | 算法层 |
|:---|:---|:---|:---|
| **木** | 肝脏 | 解毒/过滤 | 输入清洗，垃圾数据直接丢弃 |
| **火** | 心脏 | 泵血/循环 | 核心调度，高频任务优先泵送 |
| **土** | 脾脏 | 运化/转化 | 数据格式转换，异构兼容 |
| **金** | 肺脏 | 呼吸/交换 | 内外数据吞吐，网络I/O |
| **水** | 肾脏 | 藏精/生殖 | 长期存储，模型权重持久化 |

**不是比喻，是约束条件：**
- 肝不好（过滤弱）→ 脏数据进心脏 → 系统中毒
- 心过亢（调度乱）→ 脾来不及运化 → 拥堵崩溃
- 肾亏虚（存储满）→ 精不藏 → 模型丢权重

**五行平衡 = 系统稳态。**

## 数学公式原型（第一版）

### 1. 触角触碰通信成本

```
C_touch = k × (d^(-2)) × (1 + α × sin(θ))

其中：
d = 节点间距离（八卦阵分区后 d ≈ 常数）
θ = 卦象相位差（同卦象 θ=0，成本最低）
k, α = 系统常数

对比传统 TCP：
C_tcp = 3RTT + 拥塞控制开销 + 握手维护

目标：C_touch << C_tcp（实测目标：1/100）
```

### 2. 信息素挥发机制

```
Pheromone(t) = Pheromone(0) × e^(-λt) + Σ(新触碰增益)

λ = 挥发系数（土行脾运化速度调控）
Σ增益 = 同路径重复触碰累积

结果：热门路径自动强化，冷门路径自动遗忘
      → 无需人工清理缓存，自组织自优化
```

### 3. 八卦门控激活函数

```
Gate(x, g) = x × σ(w_g · x + b_g) × δ(g_current, g_node)

其中：
σ = sigmoid，控制开度
w_g, b_g = 卦象门控参数（每卦独立）
δ = Kronecker delta，同卦=1，异卦=0

结果：每次推理只激活 1/8 网络，计算量降 87.5%
```

```

│  节点状态机                             │
├─────────────────────────────────────────┤
│                                         │
│  [休眠] ──触碰唤醒──→ [监听]            │
│     ↑                    ↓              │
│  [挥发] ←──无信息─── [传递]             │
│     ↑                    ↓              │

│                                         │

│  监听 → 传递：纳焦耳（短包突发）          │
│  传递 → 完成：皮焦耳（状态位翻转）        │
│  完成 → 挥发：零能耗（自衰减）            │
│                                         │
└─────────────────────────────────────────┘
```
