### 🔴 红级审计单 · AUDIT-{编号}

> ⚠️ **红级 = 不得直接改动 · 需ADL记录 + 至少2人确认**

额外要求:
1. ADR (架构决策记录) 必须写入 `audit/adr/`
2. 至少UID9622 + 1名审计人格确认
3. 回滚必须在5分钟内完成
4. 执行前必须做完整备份

## 自动触发规则

| 触发条件 | 级别 | 动作 |
|------|:---:|------|
| 日常读取/查询/标记 | 🟢 | 自动记录日志，不生成审计单 |
| 合并/同步/导出/更新（可能覆盖数据） | 🟡 | 自动生成审计单，需确认 |
| 删除/高权限激活/对外发布/不可逆操作 | 🔴 | 自动拦截 + 生成审计单 + ADR |

## 审计链

- 所有审计单存入 `audit/sheets/`
- 审计日志追加到 `audit/audit_chain.jsonl`
- 不可篡改（追加模式 + GPG 可签名）

## 自动化引擎

```bash
# 创建黄级审计单
python3 bin/lh_audit_sheet_trigger.py --yellow "操作描述" --scope "影响范围"

# 创建红级审计单（拦截）
python3 bin/lh_audit_sheet_trigger.py --red "危险操作" --scope "影响范围"

# 确认审计单
python3 bin/lh_audit_sheet_trigger.py --confirm AUDIT-001

# 完成审计单
python3 bin/lh_audit_sheet_trigger.py --complete AUDIT-001

# 审计报告
python3 bin/lh_audit_sheet_trigger.py --report
```
