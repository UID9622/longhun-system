
### 4.2 DNA 签名必须保留

每次输出·必须带 DNA 签名：

```
格式：#龍芯⚡️YYYY-MM-DD-{主题}-v{版本}
```

```
数字根 dr∈{1,2,4,5,7,8} → 🟢 通行
数字根 dr=6             → 🟡 待审
数字根 dr∈{3,9}         → 🔴 熔断·不执行
```

熔断了·就是熔断了。不绕过·不强行。

### 4.4 账本 append-only

账本只能追加·不能删改。  
DNA 链式哈希·改一条后面全对不上。
