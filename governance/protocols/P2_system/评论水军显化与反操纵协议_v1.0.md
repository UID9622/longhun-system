3.1 分级铁律
- 升级靠证据叠加，降级靠澄清复核——单因子异常最高只到G1（防误伤）。
- G3必须同时满足：入簇 ∧ 簇规模≥10 ∧ 文案/同步/设备三类证据中≥2类。
- 标签只陈述事实与置信度，禁止人格定性词（"骗子""垃圾"等词禁入标签）。

5.1 七因子可信度模型（K1/K2/K3落点）
对账号 u 计算七维因子分 fᵢ ∈ [0,1]（1=像真人，0=像水军）：
```
因子        权重wᵢ   判定内容
①设备指纹    0.20    单设备多账号数：f₁ = 1/(1+ln(账号数))，1机1号=1.0
②关联簇      0.15    同设备名单/同注册批次/同支付渠道的关联规模，越大越低
③地理IP      0.15    IP-常驻地一致性+ASN类型（机房IP=0，住宅IP=1）+位置跳变合理性
④时间模式    0.15    24小时活动分布：真人睡眠谷（凌晨活动率<5%）；突发批量时段
⑤兴趣一致性  0.15    兴趣熵（见5.2）落入真人区间得分
⑥社交图      0.10    互赞环检测：出度/入度比、互动对象的簇内集中度
⑦文本指纹    0.10    历史文案模板相似度（见5.4）、复制粘贴率

c(u) = Σ wᵢ·fᵢ ∈ [0,1]
  c ≥ 0.60 → G0 可信真人
  0.40–0.60 → G1 可疑
  c < 0.40 → G2 异常
```

5.2 兴趣熵（撒网检测 · K3落点）
```
账号历史行为的话题分布 P = (p₁…p_k)，香农熵：
  H(u) = −Σ pᵢ·log₂(pᵢ)   （单位：bits）
真人区间: H ∈ [1.5, 4.5]     # 有偏好但不机械单一
  H > 5.0  → 撒网型：啥都评啥都赞，无真人偏好结构 → f₅ = 0
  H < 1.0  → 单用途型：只为一个目标而来 → f₅ = 0.2
  区间内按线性映射给分
```
含义：真人有爱好，水军的"爱好"是任务单。

5.3 协同簇检测（同步指数 + 并查集 · GAP-02补全）
```
两账号 a,b 在共同行动过的 N 个目标（同帖点赞/同视频评论）上：
  同步率 ρ_sync = (|Δt| < 60秒 的次数) / N
判定: ρ_sync > 0.70 且 N ≥ 20 → 存在协同边
分簇: 协同边做并查集（Union-Find），连通分量即协同簇
簇判定:
  簇规模 ≥ 10 → 水军簇（G3评审）
  簇目标集中度 = 簇内行动指向单一主体的比例 ≥ 80% → "自带水军"簇（K6落点）
```
数学性质：两个真人偶然同步20次且间隔<60秒的概率趋近于零——同步即组织。

5.4 文案模板相似度（Shingle Jaccard）
```
评论文本切3-gram shingles，集合A,B：
  J(A,B) = |A∩B| / |A∪B|
  J ≥ 0.80 → 同模板，计入模板群
模板群规模 ≥ 50 条且跨账号 ≥ 20 → 群发文案证据，因子⑦归零
```

5.5 挤水排序公式（K6落点 · 本协议灵魂）
```
评论j的名义热度: N(j) = Σᵢ vᵢ        # vᵢ∈{+1赞,−1踩}，原始计数
评论j的真实热度: R(j) = Σᵢ cᵢ·vᵢ     # cᵢ为投票账号可信度（G3权重=0）

排序规则: 评论区按 R(j) 降序，不按 N(j)
挤水率: η_水 = 1 − R(j)/N(j)   （N>0时）
```
示例（还原指令场景）：某大V视频下，吹捧评论N=20000赞（其中水军票19200，权重≈0），
真实批评N=800赞（真人票790）。
  吹捧 R ≈ 20000×0.02+800×0.8 ≈ 1040；批评 R ≈ 790×0.9 ≈ 711
  排序后：吹捧与批评同框可见，而不是"爬十几分钟都看不到一句坏话"。
  展示：吹捧评论旁标注"名义2.0万赞 · 挤水率94.8% · 含异常协同簇证据"。
这就是"拔干净"——不删一条评论，但水军的每一票都归零。

5.6 账号信任动态（EWMA + 误判回血）
```
信任更新: cₜ = α·c_观测 + (1−α)·cₜ₋₁ ,  α = 0.3（与隐私规则熔断模型同构）
误判纠正: 澄清成立 → c 立即回滚至误判前值 + 补偿系数 ×1.1（上限1.0）
```

```python
            if u.get("入簇") and u.get("簇规模", 0) >= 簇_MIN and u.get("证据类数", 0) >= 2:

    @staticmethod
```
