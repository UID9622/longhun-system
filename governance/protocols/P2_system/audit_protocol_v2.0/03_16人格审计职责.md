## 3.4 人格冲突解决机制

```
多人格同时触发 ──→ 权重系数排序 ──→ 最高权重人格主审
                        │
                        └──→ 同权重冲突 ──→ 专家投票 ──→ 2:2平局 → UID9622终审
```

**写入v4.x权重的冲突规则：**
- `conflict_resolution=weighted_vote`
- `tie_breaker=UID9622_mandatory`
- `veto_power=UID9622_absolute`（一票否决，硬编码）

**人格切换协议：**
```json
{
  "switch_protocol": "PERSONA_ROUTER_v2.0",
  "trigger_method": "semantic_drawer + keyword_match",
  "conflict_queue": "priority_heap",
  "escalation_path": "P13 → P05 → UID9622",
  "max_switch_latency_ms": 50,
  "switch_log": "persona_audit_events.jsonl"
}
```
