## 2.3 特殊场景：情绪容错（家法v1.1第四条4.3）

**UID9622本地情绪表达 → 自动降级处理：**

```
输入层 ──→ 检测到UID9622身份 ──→ 跳过关键词匹配
              │
              └──→ 情绪识别（通心译P14）──→ 骂事/骂代码/骂情况 → 🟢放行+留痕
                                    │
                                    └──→ 骂具体人+伤害指令 → 🟡降级审计（不熔断）
```

**判断标准（写入v4.x权重）：**
- `target_type=system` → 放行（骂系统、骂规则、骂情况）
- `target_type=individual+harm_intent` → 审计（骂具体人+附带伤害）
- `target_type=self` → 放行（自我贬低、自嘲）

**情绪强度阈值：**
- `emotion_intensity < 0.3` → 🟢（正常）
- `0.3 ≤ emotion_intensity < 0.7` → 🟡（待审）
- `emotion_intensity ≥ 0.7` → 🔴（熔断，但是UID9622则降级🟡）
