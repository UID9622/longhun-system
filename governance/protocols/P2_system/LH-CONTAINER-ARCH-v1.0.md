### 2.2 隐私保护机制

```yaml
摄入即加密:
  所有数据进入容器时:
    1. 身份信息自动脱敏 (姓名/手机/身份证/银行卡)
    2. 位置信息模糊化 (GPS→城市级别)
    3. 密码/密钥类文件自动识别并加密存储

主权标记:
  每条数据摄入时自动打标:
    - 来源设备ID
    - 摄入时间 (农历干支)
    - 数据归属人 (UID9622)
    - 隐私等级 (P0公开/P1内部/P2受限/P3机密/P4私密)
    - DNA追溯码
```

## 三、8线分解引擎

### 3.1 每条分解线的职责

| 线路 | 名 | 输入 | 输出 | 触发条件 |
|:---:|------|------|------|------|
| L1 | 代码分解 | 代码文件 | AST·依赖图·质量报告·安全告警 | 文件类型=code |
| L2 | 文档分解 | 文档/文章 | 摘要·关键词·分类·语义段落 | 文件类型=doc |
| L3 | 知识图谱 | 所有文本 | 实体·关系·三元组 | 始终运行 |
| L4 | 决策分解 | 决策相关文本 | 选项·推演·权重·建议 | 检测到决策信号 |
| L5 | 人格分解 | 对话/日记 | 情感向量·偏好·人格匹配 | 始终运行(低优先级) |
| L6 | 主权分解 | 所有数据 | 隐私标记·归属·加密策略 | 始终运行 |
| L7 | 时间分解 | 所有数据 | 时间线·记忆衰减·遗忘策略 | 始终运行 |
| L8 | 关联分解 | 跨线输出 | 关联发现·因果链·协同建议 | 其他线有输出时触发 |

### 3.2 并行执行策略

```
不是顺序管道，是并行分解:
  - 8条线同时启动
  - GPU/多核并行
  - 某条线无相关输入则跳过
  - 线路之间通过关联分解(L8)沟通
  - 每条线有独立的权重阈值
```

## 四、权重触发系统

### 4.1 权重计算

```python
def compute_weight(item, decomposition_results):
    """
    权重 = 数字根(内容) × 三闸门系数 × 九宫位置因子
    
    数字根: 内容哈希 → 1-9
    三闸门:
      G1(身份): 谁的数据? → 系数0.1-2.0
      G2(规则): 触发了什么规则? → 系数0.5-3.0
      G3(伦理): 风险等级? → 系数0.1-5.0
    九宫: 洛书九宫位置 → 系数0.5-1.5
    """
```

### 4.2 阈值表

| 范围 | 动作 | 说明 |
|:---:|------|------|
| W < 0.3 | 静默归档 | 直接入库，不通知 |
| 0.3 ≤ W < 0.6 | 静默处理 | 自动分类+标记，记录日志 |
| 0.6 ≤ W < 0.8 | 联动协同 | 触发关联线路，多引擎并行 |
| 0.8 ≤ W < 0.95 | 通知建议 | 推送通知+AI建议，等用户确认 |
| W ≥ 0.95 | 人工确认+熔断 | 强制UID9622确认，含风险评估 |

| 库 | 路径 | 存储内容 | 生命周期 |
|------|------|------|------|

### 5.2 知识库的多元分解

```
不是一套固定的知识格式。

同一份知识，从不同角度拆解:
  ┌─ 五行视角: 金/木/水/火/土 归类
  ├─ 八卦视角: 乾/坤/震/巽/坎/离/艮/兑 映射
  ├─ 三才视角: 天/地/人 三层理解
  ├─ 时间视角: 过去/现在/未来 时间线
  ├─ 人格视角: 20人格分别如何解读
  ├─ 实用视角: 怎么用·什么时候用·和什么一起用
  └─ 主权视角: 谁的·从哪里来·能到哪里去
```
