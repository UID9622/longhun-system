## 📋 摘要

**当前AI内容认证方法存在根本性缺陷：它们试图回答"这是不是AI生成的"，而非"这段内容的来路能否被证明"。** 这种错位导致水印可被擦除、统计检测可被绕过、C2PA元数据可被剥离、AI检测工具可被对抗样本欺骗。本文提出**行为密码学（Behavioral Cryptography）**：一种面向人机协作内容认证的**七因子来源追溯框架**。该框架不假设内容由人或AI单独创作，而是假设创作过程是一段**可追溯的行为链**——包含身份、时间、规则、人格、术语、风格、修正共七个维度。每个因子均可独立验证，组合后形成难以伪造的来源证据链。本文以**龍魂系统（LongHun System）** 为参考实现，展示了该框架在纯文本、思想演化、多AI协作场景中的应用。实验表明，七因子组合对改写、翻译、重组、AI重写等常见攻击的抵抗能力显著高于任何单一方法。行为密码学不替代现有的C2PA、水印或版权登记，而是作为它们的补充——专注于**思想的来路认证**。

**关键词：** 行为密码学、来源追溯、内容认证、人机协作、数字主权、七因子模型、责任塌缩概率、龍魂系统

## 1. 引言

### 1.1 问题的本质：来路，而非来源

当一段文本、一个想法、一篇论文在互联网上传播时，最核心的信任问题不是“这是人写的还是AI写的”，而是：**这段内容从哪里来？经过谁的手？被什么规则处理过？有没有被篡改？**

当前的主流方法，无论是**C2PA（内容来源与真实性联盟）**、**数字水印**、**AI文本检测工具**，都试图回答一个不同的问题：“这是否由AI生成”。这个问题在今天已经意义有限——AI生成内容已经无处不在，且生成质量与人类难分伯仲。真正的挑战是：**如何在一个人机深度协作的内容生态中，建立可追溯、可验证、不可抵赖的来源链？**

### 1.2 传统方法的三个局限

| 方法 | 局限 |
|:---|:---|
| **数字水印** | 可被擦除、可被扰动、对纯文本无效 |
| **C2PA元数据** | 可被剥离、依赖平台支持、不覆盖思想层面 |
| **AI文本检测** | 准确率不稳定、可被对抗样本欺骗、不提供追溯能力 |

上述方法均假设内容是一个**静态文件**，而非一段**动态行为链**。它们关注“成品”，而非“过程”。行为密码学正是针对这一盲区提出——它将内容创作视为**行为过程**，而非最终产物。

### 1.3 行为密码学的核心主张

**行为密码学（Behavioral Cryptography）** 的核心主张是：

> **每一个内容的“来路”都可以被编码为一组行为因子。这些因子组合后，比任何单一水印都更难以伪造，因为伪造者需要同时复制七个维度的行为痕迹，而不仅仅是文本本身。**


## 2. 理论背景与相关工作

### 2.1 C2PA与内容来源标准

C2PA（Coalition for Content Provenance and Authenticity）定义了内容来源的技术标准，通过加密元数据记录内容的创建者和修改历史。其局限在于：依赖平台支持、元数据可被剥离、不覆盖纯文本的思想溯源。

### 2.2 数字水印技术

数字水印在图像、音频、视频中嵌入不可见标记。对纯文本内容，水印技术天然不适用。

### 2.3 AI文本检测方法

基于统计特征、语言模型困惑度、水印嵌入等方法试图判断文本是否由AI生成。准确率不稳定，且容易被对抗样本绕过。

### 2.4 行为密码学的定位

行为密码学**不替代**上述方法，而是作为它们的**补充**——专注于**思想、文本、流程、人机协作的来路认证**。C2PA更偏文件和媒体来源，行为密码学更偏行为和思想来源。

## 3. 威胁模型

### 3.1 攻击者模型

本文假设攻击者具有以下能力：

| 能力等级 | 描述 | 对应攻击 |
|:---|:---|:---|
| **Level 1（被动观察）** | 只能读取公开内容，无法修改 | 复制、截图、手动记录 |
| **Level 2（内容改写）** | 可以修改文本内容，但不知道七因子结构 | 同义词替换、翻译、段落重组 |
| **Level 3（结构感知）** | 知道七因子框架，试图针对性清洗 | 逐因子伪造、一致性攻击 |
| **Level 4（系统渗透）** | 可以访问龍魂系统内部数据 | 篡改日志、伪造DNA、冒充身份 |

### 3.2 攻击场景

**场景A：洗稿攻击（Plagiarism）**
> 攻击者复制龍魂系统内容，进行同义词替换和段落重组，声称原创。
> **防御：** F5受保护词表 + F6长期风格向量 + F7纠错账本组合识别。

**场景B：AI重写攻击（AI Paraphrasing）**
> 攻击者将内容输入GPT-4o等模型，要求"用不同方式表达同样的意思"。
> **防御：** F1身份DNA + F2时间锚点 + F4人格路由组合，重写无法伪造历史记录。

**场景C：跨语言攻击（Translation Attack）**
> 攻击者将内容中→英→中翻译，试图消除语言特征。
> **防御：** F5受保护词表保留核心术语（如"龍魂"、"CNSH"、"UID9622"），翻译后仍可识别。

**场景D：内部渗透攻击（Insider Attack）**
> 攻击者获取龍魂系统内部权限，试图篡改日志或伪造DNA。
> **防御：** F1身份DNA使用GPG签名，私钥由UID9622独占；F7纠错账本使用哈希链，篡改即断裂。

### 3.3 安全假设

1. **GPG私钥安全假设：** UID9622的GPG私钥不被泄露。
2. **时间戳可信假设：** 系统时间戳由NTP同步，不被本地篡改。
3. **哈希函数抗碰撞假设：** SHA-256在计算上不可碰撞。
4. **行为不可完全模仿假设：** 长期风格向量（F6）具有足够的熵，无法被完美复制。

## 4. 七因子来源追溯模型

### 3.1 模型定义

行为密码学将内容创作的来源追溯定义为七因子的组合：

```
来源证据链 S = {F1, F2, F3, F4, F5, F6, F7}
```

其中每个因子都是一类可独立验证的“行为痕迹”，它们共同构成一条难以完整伪造的来源链。

### 3.2 七因子定义

| 因子 | 符号 | 定义 | 防伪逻辑 |
|:---|:---|:---|:---|
| **身份DNA** | F1 | 原创者的唯一标识符 | UID9622、GPG指纹A2D0092C、龍芯/龍魂标识 |
| **时间锚点** | F2 | 内容创建与修改的时间线 | 每份文档带时间戳，公开记录可查 |
| **规则轨迹** | F3 | 内容经过的处理规则链 | CNSH三色审计、审核过滤系统 |
| **人格路由** | F4 | 参与创作的AI人格/模块 | 龍芯家族花名册、多AI协作窗口 |
| **受保护词表** | F5 | 不能因改写而消失的关键术语 | CNSH语义入口、五行向量、道德经锚 |
| **长期风格向量** | F6 | 原创者的表达习惯 | 七因子行为指纹中的F2/F6行为特征 |
| **纠错账本** | F7 | 错误、修正、版本演化是否连续 | 版本链、父DNA/子DNA追溯 |

### 3.3 单因子可伪造，七因子组合不可伪造

单个因子都可能被伪造（例如伪造一个时间戳、复制一段DNA码），但七个因子合在一起，就形成一条很难复制的来源链。其数学逻辑是：

```
伪造成本 C_fake = Σ(c_i × w_i) + 一致性惩罚 P
```

其中：
- c_i = 伪造第i个因子的成本
- w_i = 第i个因子的权重
- P = 使所有因子互相一致所需的额外成本

**推论：** 当n≥7时，伪造成本趋于无限，因为因子之间需要相互一致，而伪造者难以同时满足所有约束。


## 5. 责任塌缩概率模型

### 4.1 核心公式

行为密码学的底层数学模型是**责任塌缩概率模型**：

```
P(善行 | 环境) = P₀ × [reward(善行) / risk(善行)]ˣ
```

其中：
- **P₀** = 个人基率（底层道德底色）
- **x** = 环境压力系数，取值范围 [0.5, 3.0]
- **reward(善行)** = 行善的预期收益
- **risk(善行)** = 行善的预期风险

### 4.2 推论

```
当 risk(善行) > reward(善行) 且 x → 2.0 时，P(善行) → 0
当 reward(善行) > risk(善行) 时，P(善行) → 1
```

**行为密码学的责任判断：** 人的行为不是由“善恶本质”决定的，而是由环境压力系数x和收益/风险比共同决定的概率结果。

### 4.3 七因子责任塌缩风险公式

```
R = F2锐度 × F6长期权重 - F1缺席率
```

其中：
- **F1** = 缺席率（逃避责任的倾向）
- **F2** = 锐度（直面问题的胆量）
- **F6** = 长期权重（历史行为积累的信用）

**判断规则：**

```
R ≥ 0.85 → 🟢 可信行为
0.60 ≤ R < 0.85 → 🟡 可疑行为
R < 0.60 → 🔴 不可信行为（触发来源审查）
```

## 7. 实验与验证

### 7.1 实验设计

**测试目的：** 验证七因子组合对内容改写的抵抗能力。

## 8. 安全性分析

### 8.1 七因子组合的安全性证明

**定理（七因子抗伪造性）：** 在攻击者不知道原始七因子完整结构的前提下，成功伪造全部七因子的概率上界为：

```
P(forge) ≤ Π(i=1 to 7) P(forge|F_i) × P(consistency|F_1...F_7)
```

其中：
- P(forge|F_i) = 伪造单个因子F_i的概率
- P(consistency) = 使七个因子互相一致的概率

**证明概要：**
1. 每个因子的伪造需要不同的知识和资源（时间戳需要NTP、DNA需要私钥、风格向量需要历史数据）。
2. 即使攻击者能伪造k个因子（k<7），剩余(7-k)个因子的验证仍会失败。
3. 一致性约束P(consistency)随因子数量指数下降，因为因子之间存在交叉验证关系（如F2时间戳必须与F7版本链时间单调递增）。
