## 🧩 二、核心组件

### 组件1：常驻浏览器服务（核心）

**选型：** `@cjwddz/browser-server`——专为AI Agent设计的自托管常驻浏览器服务。支持跨天登录态保持、Web管理界面、MCP协议集成。

**功能：**
- 浏览器7×24小时在鲲鹏上运行
- 登录态永久保持（cookies、localStorage、IndexedDB）
- 你登录一次，它永远记住
- 支持人工介入（遇到验证码时，你在手机上点一下就能继续）

**替代方案：** Steel CLI——支持24小时长会话、可复用命名配置、持久化认证上下文。同样适合鲲鹏部署。

### 组件2：自然语言 → 浏览器操作（指令翻译）

**选型：** `browser-use` + LangGraph——让AI Agent用自然语言控制浏览器。你说“登录淘宝查物流”，它自动翻译成“打开淘宝→点击登录→输入账号→跳转订单页→读取物流信息→返回结果”。

**功能：**
- 你说中文，它干活
- 支持多步骤复杂操作
- 支持错误重试和异常处理

### 组件3：会话持久化（登录态永不丢）

**选型：** Playwright Persistent Context——cookies、localStorage在会话间持久保存。支持`--storage-state`参数加载已保存的登录状态。使用`launch_persistent_context()`配合`user_data_dir`也能实现完整的浏览器Profile持久化。

**功能：**
- 登录一次，永久有效
- 重启鲲鹏也不丢
- 多网站分别记住

### 组件4：安全与主权

| 安全层 | 实现方式 |
|:---|:---|
| **传输加密** | 鲲鹏到你的设备全链路TLS 1.3 |
| **身份验证** | 每次操作需要你的DNA确认 |
| **操作审计** | 所有操作入史官，可追溯 |
| **数据主权** | 所有cookies、登录态、操作记录存在鲲鹏，不出境 |
| **三色审计** | 每次操作自动审计 🟢/🟡/🔴 |


## 🚀 三、鲲鹏部署步骤（一键执行）

### 第一步：安装浏览器服务

```bash
# 登录鲲鹏
ssh root@你的鲲鹏IP

# 安装 Node.js（如果未安装）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 browser-server
npm install -g @cjwddz/browser-server
```

### 第二步：启动常驻浏览器

```bash
# 启动服务（设置管理员密码）
browser-server start -u admin -p 你的密码

# 服务默认运行在：
# - Web管理界面: http://鲲鹏IP:33000
# - MCP服务端口: 33001
```

### 第三步：首次登录（只需一次）

1. 在浏览器打开 `http://鲲鹏IP:33000`
2. 用 `admin/你的密码` 登录管理界面
3. 在管理界面中打开浏览器窗口
4. 手动登录你需要的所有网站（淘宝、京东、微信网页版、微博……）
5. 登录完成后，关闭管理界面

**之后浏览器会自动记住所有登录态，再也不用重复登录。**

### 第四步：安装龍魂指令适配器

## 🔧 五、遇到验证码怎么办？

有些网站登录时需要扫码/滑块验证。解决方案：

| 验证码类型 | 处理方式 |
|:---|:---|
| 扫码登录 | 浏览器服务会生成二维码，通过龍魂App推送到你手机上，你扫码即可 |
| 滑块验证 | 推送通知给你，你在手机上滑动完成 |
| 短信验证码 | 你输入验证码，浏览器自动填入 |

**你不需要在电脑前，手机就能完成所有验证。**
