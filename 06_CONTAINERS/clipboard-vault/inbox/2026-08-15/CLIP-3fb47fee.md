## 核心定位

> **龍魂生态不是“开源社区”，是“主权开发者联盟”。**
>
> 注册即锚定，代码即资产，贡献即股权。1元是门槛，不是价格。

你可以理解为：GitHub是代码仓库，龍魂是代码的主权登记处。在GitHub上放代码和在龍魂上登记代码，关系类似于“在纸上写字”和“去公证处公证”。


## 一、开发者注册入口

**位置**：官网 `/developer/register`

**流程**：

```
1. 填写基本信息（姓名/邮箱/昵称）
2. 支付 1 元（微信/支付宝/数字人民币）
3. 系统生成开发者DNA：`#龍芯⚡️{干支}·{时辰}·{卦}-DEV-{hash8}-UID9622`
4. 生成 GPG 密钥对（或绑定已有 GPG）
5. 注册完成 → 获得开发者面板

支付页面说明：
- 1元支付后不可退款（这不是商品，是主权登记费）
- 支付即表示同意龍魂开发者协议
- 支付记录自动写入史官，永久可查
```

**存量开发者如何处理**：

已经在龍魂生态中贡献过的开发者，可以凭之前的贡献记录兑换注册资格（相当于免1元门槛），兑换后同样获得开发者DNA。


## 二、代码DNA自动注入

**核心机制**：每个开发者注册后，其提交的所有代码自动携带DNA水印。

| 场景 | 水印位置 | 说明 |
|:---|:---|:---|
| CNSH 脚本 | 文件头 | `DNA: #龍芯⚡️...-DEV-...-UID9622` |
| Python 文件 | 文件头 | `# DNA: #龍芯⚡️...` |
| Markdown 文档 | 文件头 | `**DNA:** ...` |
| Git commit | commit message | 自动追加 DNA 追溯 |
| 剪贴板内容 | 自动包裹 | 通过 `lh_clipboard_vault.py` 自动注入 |
| API 输出 | 响应头 | `X-Dragon-DNA` |

```
开发者在龍魂生态中写代码
    ↓
每一行代码自动携带开发者DNA
    ↓
代码被复制、粘贴、修改
    ↓
DNA追溯链始终存在 → 抹不掉、洗不掉、改不掉
```


## 三、存量代码水印补全

针对已经存在的代码仓库，提供批量补全工具：

```bash
lh dna inject --path ./my-repo/ --recursive
```

该命令会：
1. 扫描所有代码文件
2. 检查是否已有DNA
3. 没有则自动注入当前开发者的DNA
4. 生成注入报告，记录哪些文件被修改
