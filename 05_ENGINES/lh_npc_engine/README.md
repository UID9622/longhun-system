## 接真 LLM（灵活点在这）

```python
def ollama钩子(人设, 上下文, 输入):
    import urllib.request, json
    req = urllib.request.Request("http://localhost:11434/api/generate",
        data=json.dumps({"model":"qwen2.5:7b","prompt":f"{人设}\n回忆:{上下文}\n玩家:{输入}\n回应:","stream":False}).encode())
    return json.loads(urllib.request.urlopen(req).read())["response"]

npc = NPC(二十四人格[0], db路径="npc.db", llm钩子=ollama钩子)
```

LLM 负责文采，引擎负责灵魂：人设、记忆、好感度、行为状态全部由引擎注入和维持——换任何模型，NPC 的"人格连续性"不断。
