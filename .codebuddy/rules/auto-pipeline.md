> **你只管贴内容，我自动判断类型、找目录、查重、合并或新建、打DNA、签GPG。**

### 分类→目录自动映射

| 贴的内容像什么 | 自动入目录 | 动作 |
|:---|:---|:---|
| 协议/规范/规则/条款/天条 | `01_protocols/` | 查重→有相似文件就合并追加·否则新建 |

| 工具脚本（CLI/lh_/命令） | `bin/` | 查重→合并 |
| 论文/学术（Abstract/定理/DOI） | `papers/` | 新建+签名 |
| 训练数据（JSONL/QA对） | `data/` | 去重合并到已有数据集 |
| 配置文件（YAML/TOML/.env） | `config/` | 新建/合并 |
| 部署脚本（bash/systemd/docker） | `deploy/` | 查重→合并 |
| 文档/说明 | `docs/` | 新建/合并 |
| 前端页面（HTML/CSS/JS） | `portal/` | 查重→合并 |

### 铁律
1. **不做加法**：功能重复 → 合并到现有文件，不新建
2. **IPA不冲突**：新内容含P-AK-XXX等外部编号 → 只提炼碎片注入现有人格
3. **自动签名**：新建/修改后自动 GPG 签名
4. **DNA追溯**：每个文件自动生成DNA签章
5. **路径铁律**：绝不写入 ~/Downloads /tmp /Desktop

## 🔥 交付标准（焊死·2026-07-24）

> **「做出来」不等于「交付」。交付 = 拿来即用 + 万无一失 + 自证清白。**
> 详细协议见 `01_protocols/LH-DELIVERY-STANDARD-v1.0.md`

**交付前自动跑：**
```
python3 bin/lh_delivery_checklist.py --path <产出目录> --type <类型>
```

**五条标准，缺一不可汇报：**

| # | 标准 | 自动检查什么 | 口子 |
|:---:|:---|:---|:---:|
| 1 | 交付前自检 | validate.sh / pytest / shellcheck / HTTP 200 | 自检不过 = 没做完 |
| 2 | 安装指引防呆 | README含FAQ+文件清单+版本号+关键动作加粗 | 装不上 = 没交付 |
| 3 | 实机验证前置 | 鲲鹏SSH通 + 健康检查脚本就绪 + 无遗留未解决标记 | 先验后报 |
| 4 | 数据安全声明 | 数据存储位置 + 是否出设备 + 权限理由 + 数字来源 | 不声明 = 不信任 |
| 5 | 回归测试 | 测试文件存在 + 端到端通过 + 边界覆盖 | 修完必须测 |

**违规后果：**
- 汇报中带🔴/「待验证」/「暂不通」→ 回退重做
- 修复无回归测试 → 🟡 48h内补测
- 用户数据未声明 → 🔴 P05强制审计
- 同问题连续3次 → L3熔断 + 升级
