# RFC1918 本地地址白名单

**DNA**: #龍芯⚡️20260701015352332099-RFC1918 本地地址白名单-53C35EB6
**分类**: 网络安全 / 主权网关
**英文缩写**: RFC1918

## 定义

龍魂主权网关仅允许目标地址落在 10/8、172.16/12、192.168/16、169.254/16、127/8、fc00::/7、fe80::/10 等本地段，外网传输一律阻断。

## 触发场景

本地地址、RFC1918、Link-local、出境阻断、白名单

## Python 示例

```python
import ipaddress
def is_local(ip):
    addr = ipaddress.ip_address(ip)
    return addr.is_private or addr.is_link_local or addr.is_loopback
print(is_local('192.168.1.3'), is_local('8.8.8.8'))
```
