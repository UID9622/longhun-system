# 字体回退与跨平台字体坑位

**DNA**: #龍芯⚡️20260701023008578843-字体回退与跨平台字体坑位-F247853B
**分类**: 设备生态 / 字体渲染
**英文缩写**: Font Fallback

## 定义

iOS 优先 PingFang SC / SF Pro，鸿蒙优先 HarmonyOS Sans，Android 优先 Roboto/Noto。跨平台 UI 若硬编码字体名，另一端没有该字体会回退到默认字体，导致排版错位。

## 触发场景

跨平台字体不一致、鸿蒙字体、iOS 字体回退、UI 错位

## CNSH 命令

```text
龍魂 字体 回退 检查
```

## 操作步骤

1. 使用系统字体族：iOS system(-apple-system)、鸿蒙 HarmonyOS Sans
2. 中文指定 sans-serif 而非具体字体名
3. 提供自定义字体文件作为兜底

## CLI 示例

```bash
# 检查 Mac 已安装中文字体
fc-list :lang=zh family | sort -u
```



## 坑位提醒

- ⚠️ PingFang SC 在鸿蒙/安卓不存在
- ⚠️ 鸿蒙 HarmonyOS Sans 在 iOS 不存在
- ⚠️ 字体行高和字重差异会导致换行不一致
