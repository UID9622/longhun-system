# 跨平台同步需两端互信

**DNA**: #龍芯⚡️20260701023008579654-跨平台同步需两端互信-6FF96DCD
**分类**: 设备生态 / 操作坑位
**英文缩写**: Trust / Pairing

## 定义

无论是 iOS↔鸿蒙还是 iOS↔Mac，端到端同步都要求两端在同一网络/已配对、已授权、已安装对应组件。任何一端拒绝信任或缺少权限，同步都会失败。

## 触发场景

同步连不上、设备不互信、配对失败、本地网络权限

## CNSH 命令

```text
龍魂 跨平台 配对 检查
```

## 操作步骤

1. 两端都开启蓝牙/Wi-Fi/本地网络权限
2. iOS 需要在弹窗中点'信任'
3. 鸿蒙需要允许 USB/无线调试

## CLI 示例

```bash
idevicepair pair && hdc list targets
```



## 坑位提醒

- ⚠️ iOS 本地网络权限未授权会导致 mDNS 不可见
- ⚠️ 鸿蒙 USB 调试未授权 hdc shell 失败
- ⚠️ 信任弹窗有时只出现一次
