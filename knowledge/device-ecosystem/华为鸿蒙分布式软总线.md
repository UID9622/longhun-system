# 华为鸿蒙分布式软总线

**DNA**: #龍芯⚡️20260701023008578586-华为鸿蒙分布式软总线-4B65E2FA
**分类**: 设备生态 / HarmonyOS 开发对接
**英文缩写**: Soft Bus

## 定义

鸿蒙的分布式软总线（Distributed Soft Bus）让多设备像一台设备一样通信，提供设备发现、组网、传输能力。开发上用 @ohos.distributedHardware 与 DeviceManager API。

## 触发场景

鸿蒙分布式软总线、跨设备调用、HarmonyOS 软总线

## CNSH 命令

```text
龍魂 华为 软总线 设备发现
```

## 操作步骤

1. 同一华为账号并登录 HMS
2. 开启蓝牙/Wi-Fi 并靠近
3. 应用调用 DeviceManager 获取可信设备列表

## CLI 示例

```bash
# 通过 hdc shell 查看软总线服务
hdc shell ps -ef | grep softbus
```



## 坑位提醒

- ⚠️ 需要同一账号和同一局域网或蓝牙
- ⚠️ 设备间安全认证不可绕过
- ⚠️ API 版本差异大
