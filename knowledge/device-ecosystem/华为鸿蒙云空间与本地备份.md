# 华为鸿蒙云空间与本地备份

**DNA**: #龍芯⚡️20260701023008578647-华为鸿蒙云空间与本地备份-249E06C6
**分类**: 设备生态 / HarmonyOS 备份恢复
**英文缩写**: HiSuite / Huawei Cloud

## 定义

华为云空间自动备份图库、联系人、备忘录等；本地完整备份通过'华为手机助手'（HiSuite）USB 连接到电脑，可备份应用数据、系统设置到 PC。备份文件加密依赖 Huawei ID。

## 触发场景

华为手机怎么备份、华为云空间、HiSuite、华为手机助手

## CNSH 命令

```text
龍魂 华为 备份 本地
```

## 操作步骤

1. 安装华为手机助手（Windows/Mac）
2. USB 连接手机并选择'传输文件'
3. 在手机助手里选择'数据备份'
4. 选择加密并设置密码

## CLI 示例

```bash
# hdc 无官方整机备份命令，仅支持文件级 pull
hdc file recv /data/local/tmp/important ./backup/
```



## 坑位提醒

- ⚠️ 鸿蒙 NEXT 不再支持 HiSuite 老版本
- ⚠️ 云空间免费容量有限
- ⚠️ 本地备份密码丢失无法恢复
