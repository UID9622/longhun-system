## 定义

鸿蒙设置路径与 Android 差异大：设置 → 系统和更新 → 开发人员选项；HMS Core 提供账号、推送、定位、支付等基础服务，应用权限管理在 设置 → 隐私 → 权限管理。

## 触发场景

华为手机设置、鸿蒙开发者选项、HMS Core、权限管理

## CNSH 命令

```text
龍魂 华为 设置 开发者选项
```

## 操作步骤

1. 设置 → 关于手机 → 连击'版本号'开启开发者选项
2. 返回 系统和更新 → 开发人员选项
3. 开启 USB 调试 / 无线调试
