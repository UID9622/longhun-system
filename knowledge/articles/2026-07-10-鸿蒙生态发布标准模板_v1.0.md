## 六、代码片段规范（直接引用鸿蒙API交付标准）

所有鸿蒙相关代码必须引用：
`knowledge/device-ecosystem/鸿蒙API交付标准模板_v1.0.md`

必须包含：
1. `module.json5` 权限声明
2. `build-profile.json5` 构建配置
3. 权限运行时请求（`PermissionHelper`）
4. 设备能力检查（`DeviceCapability`）
5. 动态服务器地址（`ServerConfig`）
6. 网络请求封装（`HttpClient`）
7. UI 动态适配（`ScreenAdapter`）

**最小可运行示例**：

```typescript
// entry/src/main/ets/pages/Index.ets
import { PermissionHelper } from '../permissions/PermissionHelper';
import { DeviceCapability } from '../utils/DeviceCapability';
import { HttpClient } from '../utils/HttpClient';

const REQUIRED_CAPS = [
  DeviceCapability.CAPS.INTERNET,
  DeviceCapability.CAPS.PASTEBOARD,
];

@Entry
@Component
struct Index {
  @State message: string = '鸿蒙行为审计 SDK 已就绪';

  aboutToAppear() {
    const missing = DeviceCapability.validateRequiredCaps(REQUIRED_CAPS);
    if (missing.length > 0) {
      this.message = `缺少能力: ${missing.join(', ')}`;
      return;
    }
    // 运行时权限请求
    PermissionHelper.requestPermissions(
      getContext(this) as Record<string, Object>,
      ['ohos.permission.INTERNET', 'ohos.permission.READ_PASTEBOARD']
    );
  }

  build() {
    Column() {
      Text(this.message)
        .fontSize(20)
        .fontWeight(FontWeight.Bold)
    }
    .width('100%')
    .height('100%')
  }
}
```
