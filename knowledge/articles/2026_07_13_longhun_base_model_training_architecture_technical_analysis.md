## §0 导读摘要

龍魂底座模型训练架构 v4.0 是一次**概念净化和架构升级**。

**核心纠正**: 外部 `agent` → 龍魂内核驱动。拒绝伪装者模式，采用蚁群信息化互交 + 人格矩阵驱动 + 本地主权算力执行。

**关键架构**: 两层DNA机制——蚁群共享根（colony_dna）用于主权验证，人格独有签名（persona_dna）用于行为追溯。外部伪装者无法伪造蚁群DNA根，在互交入口即被拦截。

**与现有资产关系**: 本引擎连接 `bin/lh_ant_colony_router.py`（7节点国产优先路由）、`bin/lh_ant_colony_daemon.py`（蚁群守护 :9677）、`engine/ant_colony/`（15个运行时模块）、`bin/lh_lora_trainer.py`（Qwen2.5-1.5B LoRA微调）。

## §3 关键设计：双层DNA主权验证

### §3.1 为什么需要双层DNA

| 层级 | 作用 | 共享性 | 示例 |
|:---:|:---|:---:|:---|
| **colony_dna** | 主权验证——判断"是不是龍魂体系的节点" | 所有合法节点相同 | `9504dc44...` |
| **persona_dna** | 行为追溯——判断"具体是哪个人格执行的操作" | 每节点唯一 | `60bb586a...` (P01) |

### §3.2 验证流程

```
外部节点请求加入蚁群
        │
        ▼
  携带 colony_dna？
   ├── 否 → 🚫 IMPOSTER_DETECTED: "缺少蚁群DNA根"
   │         → 拒绝（外部 agent 无此凭证）
   │
   └── 是 → colony_dna == COLONY_DNA_ROOT？
            ├── 否 → 🚫 IMPOSTER_DETECTED: "蚁群DNA根不匹配"
            │         → 拒绝（伪装者伪造失败）
            │
            └── 是 → ✅ VERIFIED: "蚁群DNA根同源"
                      → 允许互交 · 加入蚁群
```

### §3.3 安全保证

- 外部 agent 无法伪造 `colony_dna`（需要知道 `SYSTEM_DNA + COLONY-ROOT` 完整种子）
- 每个节点的 `persona_dna` 唯一（seed = SYSTEM_DNA + node_id + persona_id）
- 互交日志同时记录两种DNA，确保主权可证 + 行为可追

## §4 蚁群互交训练

### §4.1 训练模式

| 模式 | 说明 | 公式 |
|:---|:---|:---|
| 蚁群互交 | 全连接信息交换 | C(8,2) = 28 对/轮 |
| 人格驱动 | 每节点按人格能力加工数据 | 8种处理器 |
| 本地执行 | 主权算力，不走云端 | 鲲鹏/龙芯 |
| DNA锚定 | 训练结果哈希上链 | SHA256锚定 |

### §4.2 互交示例

```python
# 一轮训练 = 28对互交
# ANT-01(P01·侦察蚁) ↔ ANT-02(P02·工蚁)
# ANT-01(P01·侦察蚁) ↔ ANT-03(P03·审计蚁)
# ...
# ANT-07(P07·守卫蚁) ↔ ANT-08(P08·工蚁)

# 每对互交:
# 1. DNA主权验证 (colony_dna == COLONY_DNA_ROOT?)
# 2. 记录互交日志 (from/to/role/dna_pair/timestamp/data_hash)
# 3. 人格能力加工 (P01→战略推演 / P03→三色审计 / ...)
# 4. 结果存入对方记忆队列
```
