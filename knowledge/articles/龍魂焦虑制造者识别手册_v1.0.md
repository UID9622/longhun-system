## 二、五类话术模板 + 反制公式

### 类型A：年龄绑架型
**话术模板：**
- "都60多岁了"
- "这么大年纪了"
- "该退休了"
- "别折腾了"

**底层逻辑：** 用生理年龄否定创作价值，把"年龄"偷换成"能力上限"

**反制公式：**
```
义务边界法
= 你妈妈生你是必须的（义务）
+ 别人的妈妈养你是没有必要的（非义务）
→ 核心：区分"必须"与"可以"，打爆"别人欠你"的潜意识
```

**实战例：**
> 你："你妈妈生你是必须的，别人的妈妈养你是没有必要的"
> 效果：对方无法反驳，因为逻辑上把"期待"和"义务"切开了

### 类型B：道德绑架型
**话术模板：**
- "作为影迷能看到就开心了"
- "要求别太高"
- "人家也不容易"
- "你行你上"

**底层逻辑：** 用"感恩"包装"降标"，把合理期待污名化为"贪婪"

**反制公式：**
```
标准锚定法
= 消费者付费 = 有权要求质量
+ 创作者选择 = 承担市场反馈
→ 核心：商业关系 ≠ 慈善关系，花钱不是打赏
```

**实战例：**
> 你："我花钱买票，不是来领救济的。质量差就是差，跟容不容易没关系。"

### 类型C：对比拉踩型
**话术模板：**
- "赵本山不也这么大岁数"
- "别人都能接受"
- "比上不足比下有余"
- "你看看人家"

**底层逻辑：** 跨领域/跨标准对比，把"不同"偷换成"相同"

**反制公式：**
```
标准隔离法
= 赵本山是喜剧/周星驰是喜剧+动作
+ 不同赛道 ≠ 同一标准
→ 核心：打断类比链条，逼对方回到同一维度论证
```

**实战例：**
> 你："赵本山演的是农村喜剧，周星驰演的是无厘头+武打。赛道不同，标准不同。你拿跳远的标准量举重？"
