def 派生覆写码(生物因子: bytes, 设备因子: bytes, 环境因子: bytes, 脑内盐: bytes) -> str:
    """
    公式:

      覆写码 = HMAC-SHA256(融合, 脑内盐)

```

私有的部分: 你的指纹（生物唯一）+ 你的设备（硬件唯一）+ 你的网络（拓扑私密）

### 5.2 攻击面分析

| 攻击方式 | 可行性 | 说明 |
|:---|:---|:---|
| 暴力穷举覆写码 | ❌ 不可行 | HMAC-SHA256输出空间 2^256，宇宙年龄不够 |
| 替换设备因子 | ❌ 不可行 | 需要物理拿到设备+模拟硬件ID |
| 伪造生物因子 | ❌ 不可行 | Secure Enclave硬件隔离，无法软件模拟 |
| 猜测脑内盐 | ❌ 不可行 | 不知长度、不知内容、无任何线索 |
| 侧信道攻击 | ⚠️ 理论可行 | 需要物理接触设备+TEE漏洞利用 |
| 社工骗取脑内盐 | ⚠️ 唯一弱点 | 人的因素是最后防线 |

### 5.3 换设备安全模型

```
旧设备 → 新设备:
  设备因子改变 → 覆写码自动改变 → 旧覆写码在新设备上无法计算
  旧设备覆写码 → 自然失效，不需要"远程擦除"
  新设备 → 重新走三层绑定流程 → 生成新覆写码
