## §3 ｜ 无痕续迹：跨镜时空连续性

### 3.1 问题定义

跨镜追踪的核心难点：**同一目标在不同摄像头中表现为不同的"数字人"**。
传统方案依赖 ReID（行人重识别）单独匹配，断点不可避免。

龍魂方案：**不依赖单一时刻的匹配，而是在时空连续体中寻找连续性。**

### 3.2 三维连续性判定

```
无痕续迹 = f(时间连续性, 空间连续性, 特征连续性)

判定条件（三者同时满足）：
┌────────────────────────────────────────────┐
│ 条件1 · 时间: |T_new - T_last| ≤ 2.0s     │
│ 条件2 · 空间: ||P_new - P_last|| ≤ 100m   │
│ 条件3 · 特征: cos_sim(F_new, F_last) > 0.85│
└────────────────────────────────────────────┘

跨镜合并额外条件：
  相邻摄像头拓扑约束 + 时间窗口 ≤ 1.5s
```

### 3.3 算法伪码

```
算法: 无痕续迹 (WeaveNode)
────────────────────────────────────────
输入: target_id, camera_id, position, timestamp, features
输出: trajectory_id

1. 遍历已有轨迹，计算时间/空间/特征三维得分
2. 若最高分 > 阈值(0.85) → 续迹成功，返回已有轨迹ID
3. 否则遍历相邻摄像头活跃目标
4. 若跨镜特征相似度 > 阈值 → 合并轨迹
5. 否则创建新轨迹 TRJ-{target_id}-{timestamp}
6. 链接前后节点 (双向链表)
7. 触发主动安全检测
```

### 3.4 核心代码（简化版）

```python
def _find_trajectory_continuity(self, target_id, features, timestamp, position):
    """无痕续迹核心 — 跨镜时空连续性匹配"""
    best_score, best_traj = 0, None

    # 1. 匹配已有轨迹
    for traj_id, node_ids in self.trajectories.items():
        last_node = self.spacetime_nodes.get(node_ids[-1])
        if not last_node:
            continue

        time_gap = timestamp - last_node.timestamp
        if not (0 < time_gap <= 2.0):           # 时间窗口
            continue

        spatial_gap = np.linalg.norm(pos - last_node.position)
        if spatial_gap > 100:                    # 空间阈值
            continue

        similarity = cos_sim(features, last_node.feature_vector)
        if similarity > best_score:
            best_score = similarity
            best_traj = traj_id

    if best_score > 0.85 and best_traj:          # 特征阈值
        return best_traj                          # ✅ 无痕续迹

    # 2. 跨镜合并（相邻摄像头）
    for traj_id, node_ids in self.trajectories.items():
        last_node = self.spacetime_nodes.get(node_ids[-1])
        if last_node.target_id == target_id:
            continue
        if abs(timestamp - last_node.timestamp) > 1.5:
            continue

        sim = cos_sim(features, last_node.feature_vector)
        if sim > 0.85:
            return self._merge_trajectories(traj_id, new_traj)  # 🔄 跨镜合并

    return f"TRJ-{target_id[:8]}-{int(timestamp)}"  # 🆕 新轨迹
```

## §4 ｜ ST-GNN 时空图神经网络

### 4.1 为什么 ST-GNN？

传统方案（CNN+LSTM）在时空数据上有两个瓶颈：
1. **空间图不规则** — 摄像头网络不是网格，CNN 卷积核假设规则网格
2. **时间依赖非线性** — LSTM 门控对长程时空关系建模不足

ST-GNN 的答案：**空间用图卷积（任意拓扑），时间用因果卷积 + 自注意力融合。**

### 4.2 网络结构

```
输入层:
  spatial_nodes: [N, 256]  — 同一时刻 N 个摄像头节点特征
  temporal_seq:  [T, 256]  — 同一目标 T 个时间步特征

前向传播:
  ┌─────────────────────────────────────────────┐
  │ 空间分支                时间分支              │
  │ h_s = ReLU(X @ W_s)    h_t = Conv1D(seq)    │
  │ [N, 256]               [T, 256]             │
  └──────────┬──────────────────┬───────────────┘
             │     对齐长度      │
             └────────┬─────────┘
                      ↓
  ┌─────────────────────────────────────────────┐
  │          自注意力融合                         │
  │  Q,K,V = h_t @ W_q, h_t @ W_k, h_t @ W_v   │
  │  attn = softmax(Q @ K^T / √d) @ V          │
  └──────────────────────┬──────────────────────┘
                         ↓
  ┌─────────────────────────────────────────────┐
  │          门控融合                             │
  │  g = σ([h_s, attn] @ W_g + b_g)            │
  │  out = g ⊙ attn + (1-g) ⊙ h_s              │
  └─────────────────────────────────────────────┘

输出: [min(N,T), 256]  时空融合特征
```

### 4.3 纯 NumPy 实现

```python
class NumpySTGNN:
    """纯 numpy ST-GNN — 无 torch 依赖可运行"""

    def __init__(self, in_dim=256, out_dim=256, temporal_window=5):
        rng = np.random.RandomState(9622)
        self.W_spatial = rng.randn(in_dim, out_dim) * sqrt(2/in_dim)  # He init
        self.W_temporal = rng.randn(temporal_window, out_dim) * 0.1
        self.W_q = rng.randn(out_dim, out_dim) * 0.1
        self.W_k = rng.randn(out_dim, out_dim) * 0.1
        self.W_v = rng.randn(out_dim, out_dim) * 0.1
        self.W_gate = rng.randn(out_dim*2, out_dim) * 0.1

    def forward(self, spatial_nodes, temporal_sequence):
        # 空间图卷积
        h_spatial = relu(spatial_nodes @ self.W_spatial + self.b_spatial)

        # 时间因果卷积
        h_temporal = []
        for t in range(len(temporal_sequence)):
            window = pad_to_window(temporal_sequence[:t+1])
            val = sum(window[:,:,None] * self.W_temporal[:,None,:])
            h_temporal.append(relu(val + self.b_temporal))

        # 自注意力 + 门控融合
        Q, K, V = h_temporal @ W_q, h_temporal @ W_k, h_temporal @ W_v
        attn = softmax(Q @ K.T / sqrt(d)) @ V
        g = sigmoid(concat(h_spatial, attn) @ W_gate + b_gate)

        return g * attn + (1-g) * h_spatial
```

## §9 ｜ 安全与审计

### 9.1 国密体系

| 层级 | 算法 | 用途 |
|:---:|------|------|
| 传输 | SM4-CTR | 边缘→区域特征流加密 |
| 存储 | SM4-GCM | 轨迹数据 + 安全事件落盘 |
| 签名 | SM2 | 事件回执签名 + 不可否认 |
| 哈希 | SM3 | 特征向量指纹 + 证据链哈希 |

### 9.2 三色审计

| 色 | 含义 | 时空织网映射 |
|:---:|------|------|
| 🟢 | 合规 | 正常轨迹 · 无安全事件 |
| 🟡 | 预警 | 异常行为 · 聚集检测 · 走失 |
| 🔴 | 违规 | 禁区入侵 · 证据链锁定 · 不可篡改 |

### 9.3 证据链

```
每个安全事件 = {
    event_id,          // 唯一编号
    event_type,        // 类型
    target_trajectory,  // 关联轨迹（前后各30s）
    camera_snapshots,   // 多摄像头截图
    prediction_compare, // 预测 vs 实际偏差
    sm3_chain_hash,     // 哈希链
    sm2_signature,      // 签名
    audit_trail,        // 完整审计追踪
}
```
