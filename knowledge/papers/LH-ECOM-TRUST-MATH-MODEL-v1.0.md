## 0. 摘要

电商信任危机的本质是信息不对称与惩罚不可计算。本模型将「信任」量化为五个可计算维度——信誉分 S、举报分级、阶梯赔偿、视频真实度 R、信任摩擦系数 τ——形成一套完整的数学框架。所有公式公开、所有参数可复核、所有计算可复现。

**关键词**: 电商信任、信誉分引擎、实证举报、阶梯赔偿、视频真实度、信任摩擦、数学建模

## 1. 问题形式化

### 1.1 基本假设

**公理 1（无罪推定）**: 无证据不否定原假设 H₀: "商家描述属实"。
  模糊举报（缺证据、缺订单、缺诉求任一）不进计分通道。

**公理 2（实证计分）**: 信誉分变动 ΔS 仅由可验证事件驱动。
  ΔS ∈ {f(事件类型, 严重度, 承诺加权) | 事件 ∈ 实证事件集}

**公理 3（公开可复核）**: 所有分数公式公开，每笔变动可追溯。
  黑箱评分自身构成信任摩擦源，自反。

**公理 4（半衰恢复）**: 惩罚不是目的，改造才是。
  减分满 180 天且无再犯 → 恢复 50%，记录永不删除。

### 1.2 符号约定

| 符号 | 含义 | 值域 |
|:---|:---|:---|
| S | 商家信誉分 | [0, 1000] |
| S₀ | 初始信誉分 | 500 |

## 2. 核心数学模型

### 2.1 信誉分引擎 S

**定义 2.1（信誉分递推）**

```
S_{t+1} = clamp(S_t + Σᵢ Δ⁺ᵢ − Σⱼ Δ⁻ⱼ, 0, 1000)
```

其中 `clamp(x, a, b) = max(a, min(b, x))`

**定义 2.2（加分事件集）**

| 事件 e | Δ⁺(e, κ) |
|:---|:---|
| 如实描述抽检通过 | 2κ |
| 主动赔付履约完成 | 5κ |
| 连续 30 天零实证举报 | 10κ |
| 承诺分级升档 | 20κ |

**定义 2.3（减分事件集）**

| 事件 e | Δ⁻(e) |
|:---|:---|
| 实证举报成立（严重度 w） | −20w |
| 视频/参数造假实锤 | −50 |
| 模糊举报（不计分） | 0 |
| 恶意举报反坐（对举报者） | −30 |

**定义 2.4（承诺加权 κ）**

```
κ(G) = {
  1.00,  G = G1 (守法档)
  1.05,  G = G2 (担当档)
  1.10,  G = G3 (格局档)
  1.20,  G = G4 (标杆档)
}
```

**性质 2.1（单调性）**: κ 随承诺档位严格递增。敢赔 ≠ 吃亏，是可计算的信用资产。

**定理 2.1（半衰恢复）**: 设减分记录集 D = {(d_i, t_i)}，其中 d_i 为扣分绝对值，t_i 为发生日期。
对某条记录 d_k，定义其再犯窗口 W_k = {t_j ∈ D | t_k < t_j ≤ t_k + 180}。
若 `today − t_k ≥ 180` 且 W_k = ∅（窗口内无再犯），则该记录恢复：

```
S_recovered = min(1000, S + d_k × 0.50)
```

恢复后该记录标记为已恢复，不重复恢复；若 W_k ≠ ∅ 则该记录维持原扣分。

### 2.2 举报分级模型

**定义 2.5（收单三要素谓词）**

```
Φ(R) = has_evidence(R) ∧ has_order(R) ∧ has_claim(R)
```

**定义 2.6（恶意谓词）**

```
Ψ(R) = device_cluster(R) ∨ evidence_faked(R) ∨ competitor_relation(R)
```

**定义 2.7（举报分类函数）**

```
classify(R) = {
  🔴 MALICIOUS,   if Ψ(R)
  🟡 EMPIRICAL,   if Φ(R) ∧ ¬Ψ(R)
  ⚪ FUZZY,       otherwise
}
```

**性质 2.2（模糊举报永不计分）**: ∀R ∈ FUZZY, ΔS(R) = 0。

### 2.3 阶梯赔偿模型

**定义 2.8（赔偿计算）**

```
C(L, P, m) = {
  0,                                    L = L1
  max(500,  P × 3),                     L = L2
  max(500,  P × max(3, m)),             L = L3
  max(1000, P × 10),                    L = L4
}
```

其中 m 为商家承诺倍数（仅 L3 适用）。

**定义 2.9（总退还）**

```
T(L, P, m) = P + C(L, P, m)
```

**性质 2.3（法定下界不可降）**: C(L, P, m) ≥ C_law(L, P)，其中 C_law 为对应法条法定下限。

**性质 2.4（承诺只升不降）**: m ≥ multiplier_law(L)，商家承诺不得低于法定倍数。

**定义 2.10（找茬悬赏）**

```
B(C) = min(5000, C × 0.10)
```

### 2.4 视频真实度模型

**定义 2.11（真实度评分）**

```
R = 0.25·r_f + 0.25·r_a + 0.20·r_s + 0.20·r_p + 0.10·r_h
```

其中各项 ∈ [0, 1] 分别对应：
- r_f: 滤镜/美化检测
- r_a: AI 生成痕迹检测
- r_s: 摆拍一致性
- r_p: 参数可复测性
- r_h: 历史造假记录（1 − 历史造假次数/max）

**定义 2.12（真实度分级）**

```
grade(R) = {
  🟢 NORMAL,   R ≥ 0.85
  🟡 WARNING,  0.60 ≤ R < 0.85
  🔴 BANNED,   R < 0.60
}
```

**性质 2.5（权重归一化）**: Σw_i = 0.25 + 0.25 + 0.20 + 0.20 + 0.10 = 1.0，R 是各项的凸组合，故 R ∈ [0, 1]。

**性质 2.6（单调性）**: R 对每个分量 r_i 单调不减。任一分量提升 → R 不降。

### 2.5 信任摩擦系数

**定义 2.13（信任摩擦 τ）**

```
τ = N_disputes / N_transactions    (滚动 90 天)
```

**定义 2.14（τ 分级）**

```
τ_grade(τ) = {
  🟢 NORMAL,   τ < 0.005
  🟡 WARNING,  0.005 ≤ τ < 0.010
  🔴 DANGER,   τ ≥ 0.010
}
```

**性质 2.7（τ 与 S 负相关）**: 在正常运营条件下，τ ↓ ⇒ S ↑，二者形成耦合反馈：
低摩擦 → 少举报 → 高分 → 高信任 → 低摩擦。

## 3. 关键定理与证明

### 定理 3.1（信誉分有界性）

∀t ≥ 0, S_t ∈ [0, 1000]

**证明**: S₀ = 500 ∈ [0, 1000]。假设 S_t ∈ [0, 1000]，则 S_{t+1} = clamp(S_t + ΣΔ, 0, 1000)。
clamp 函数保证输出 ∈ [0, 1000]。由数学归纳法，∀t, S_t ∈ [0, 1000]。∎

### 定理 3.2（承诺不亏定理）

设同一商家的同一正向事件 e，在 G_a 档和 G_b 档下的加分分别为 Δ_a, Δ_b。
若 κ(G_a) > κ(G_b)，则 Δ_a > Δ_b。

**证明**: Δ = base_score × κ，base_score ≥ 2 > 0。κ(G_a) > κ(G_b) ⇒ Δ_a > Δ_b。∎

> 推论：敢赔的商家，同样的好评更值钱——不是吃亏，是可计算的信用资产。

### 定理 3.3（恶意举报可检测性）

若举报者满足 Ψ(R) = True（设备簇批量 ∨ 证据伪造 ∨ 竞争关系），则 classify(R) = MALICIOUS。

**证明**: 由定义 2.7，Ψ(R) 为第一判定条件，优先于 Φ(R)。故 Ψ(R)=True ⇒ MALICIOUS。∎

### 定理 3.4（半衰恢复阶跃性）

设商家在时间 t₁ 有减分 d，且在 (t₁, t₁+180] 内无再犯。则对任意 t₂ > t₁：
若 t₂ − t₁ < 180，恢复量 = 0；
若 t₂ − t₁ ≥ 180，恢复量 = 0.5d（一次性）。
若在 (t₁, t₁+180] 内存在再犯，则该记录永不恢复。

**证明**: 由定理 2.1，恢复条件为 (today − t_k) ≥ 180 且再犯窗口 W_k = ∅。
满足条件后标记 recovered=True，后续不再触发，故恢复是阶跃函数。
若窗口内存在再犯，条件永不满足，故恢复量恒为0。∎

## 5. 参数灵敏度分析

### 5.1 κ 的杠杆效应

设 G1 档商家和 G4 档商家各有同等数量的正向事件：

| 事件 | G1 (κ=1.0) | G4 (κ=1.2) | G4 优势 |
|:---|:---:|:---:|:---:|
| 10次抽检通过 | +20 | +24 | +4 |
| 5次主动赔付 | +25 | +30 | +5 |
| 3期30天零实证 | +30 | +36 | +6 |

结论：同等努力下，G4 档比 G1 档多 20% 的加分效率。差异化足够显著但不至于让低档商家无法竞争。

### 5.2 w 的阶跃影响

| w=1 (轻) | w=2 (中) | w=3 (重) |
|:---:|:---:|:---:|
| −20 | −40 | −60 |

轻中重之间的跳变为 20 分/级，确保严重度差异可感知。

### 5.3 半衰恢复的激励效果

一次 w=2 的实证举报扣 40 分。若无再犯，180 天后恢复 20 分。
- 短期：扣分形成即时威慑
- 长期：给改正者台阶——「改了就回血，死了就死透」

## 6. 限制与边界条件

1. **τ = 0 陷阱**: 新店交易量为 0 时 τ=0 不代表低摩擦，需标注「数据不足」。
2. **恶意举报反坐的假阳性风险**: 竞争关系判定需人工复核，自动化只做初步标记。
3. **视频真实度 r_i 的标定**: 各权重分量需定期校准，防止检测模型老化。
4. **赔偿倍数上界**: 虽不封顶，但受限于商家保证金，超额部分走平台先行赔付基金。
5. **跨境场景**: 本模型法条锚定中国法律，境外适配需换法条底座。

## 7. 结论

本模型将「电商信任」拆解为五个可计算维度，形成了从展示 → 举报 → 判定 → 赔偿 → 恢复的完整闭环。核心设计原则：

1. **公式公开**: 每个分数都可被任何利益相关方复算
2. **无罪推定**: 模糊举报不计分，杜绝「被举报 = 有罪」的暴政
3. **敢赔加权**: 把格局变成可计算的信用资产
4. **给改正的路**: 半衰恢复机制让惩罚不是终点
5. **师出有名**: 所有赔偿阶梯锚定中国现行法律
