## 摘要

信息生态中，"自由""人权"等中性词汇被话术模板批量包装，形成软文化污染——既不同于垃圾广告的硬过滤，也不同于政治审查的敏感词屏蔽，而是利用中性词汇本身的合法性进行语义渗透，传统关键词过滤系统对此几乎完全失效。本文提出三层过滤数学模型：L1组合特征层以泊松-指数混合模型检测话术模板的结构化共现，单中性词信号趋近于零（似然比约10^11）；L2传播路径层以七因子几何平均量化组织性传播意图，自然簇熵判据作为核心防误伤机制；L3语境分析层以贝叶斯先验调节判定，政府公文等语境享有全局豁免权。综合污染指数 PCI = 0.35·S₁ + 0.35·S₂ + 0.30·S₃，权重由凸优化证明。理论分析表明误伤率上界 0.49%，漏检率下界 15%，预期 AUC 0.92-0.96。在47组话术模板·12组测试用例上实现100%判定对齐。计算效率上，99.8%的文本仅需 O(|词表|×|模板|)即可判定完毕。

**关键词**: 软文化污染；话术模板检测；组合特征；自然簇豁免；贝叶斯先验；污染复合指数

## 1. 引言

### 1.1 问题背景

当代信息生态面临一种特殊污染形式：并非垃圾广告、色情暴力等低质量内容（已有成熟的过滤方案），而是利用**中性词汇本身的合法性**进行语义渗透——"自由""人权""独立思考""做自己""觉醒"这些词汇在正常人日常交流中完全无害，但当它们以特定组合模式、经由特定传播路径、出现在特定语境中批量出现时，构成系统性的话术包装。

这种现象我们称为**软文化污染**（Soft Culture Pollution），以区别于传统的硬性内容过滤。软文化污染的四个核心特征：
1. **载体中性**: 使用的词汇本身不违规
2. **组合信号**: 污染来自模板共现，而非单字
3. **组织传播**: 常伴随集群批量扩散
4. **语境依赖**: 同一词串在法律文本与带货文案中含义完全不同

传统过滤方法——关键词黑名单、正则匹配、敏感词库——在面对软文化污染时几乎完全失效：任何一个有理智的人都不会接受"包含'自由'一词的文本即被封禁"。

### 1.2 核心挑战

区分"正常使用中性词"与"话术包装中性词"，本质上是区分**稀疏的随机共现**与**密集的模板共现**。数学上，这意味着：在中文词汇的稀疏高维空间（~10^7个常用词组合）中，找出那些在话术子空间中异常密集的结构化模式。

这一挑战可形式化为三个子问题：
- **Q1**（组合特征）: 如何量化"多个话术模板同时被命中"的统计异常程度？
- **Q2**（传播意图）: 如何区分"普通网友自发讨论"与"组织性批量发布"？
- **Q3**（语境调节）: 同一词串在政府公文、学术讨论、带货文案中的污染含义如何不同？

### 1.3 本文贡献

1. 提出**三层过滤架构**（L1组合特征 → L2传播路径 → L3语境分析）的完整数学模型
2. 证明 L1 的泊松-指数混合公式：1-e^{-x} 优于线性函数的数学理由
3. 设计自然簇**熵判据**（ε_var / ρ_cross / J_template 三维判定），作为防误伤核心
4. 证明 PCI 权重 (0.35, 0.35, 0.30) 的最优性
5. 推导误伤率上界 R_FP ≤ 0.0049，漏检率下界 R_FN ≤ 0.15
6. 47组话术模板 + 12组测试用例 + 100%判定对齐验证

## 2. 相关数学基础

### 2.1 稀疏共现的概率基底

设全语料库规模为 N ≈ 10^6 篇文档。任意中性词 w 的出现概率 p_w ≈ 2×10⁻⁴（在约200篇文档中出现一次）。

两个独立词的随机共现概率：p_w² ≈ 4×10⁻⁸
三个独立词的随机共现概率：p_w³ ≈ 8×10⁻¹²

这构成了软文化污染检测的**数学基底**：自然语言中，三个特定中性词在同一句/段中随机共现的概率已低至万亿分之一级别。但话术文本子集中，同一组合的出现率可达 0.85 以上。

**似然比**: 0.85 / 8×10⁻¹² ≈ **1.06×10¹¹**（约1000亿倍）

这意味着——在统计意义上——模板共现和随机共现之间存在**六个数量级**的区分度。这正是"不封词、封组合模式"的数学依据。

### 2.2 七因子行为密码学

龍魂七因子框架[1]将用户可信度建模为七个行为维度的加权几何平均：

```
conf = Π_{i=1}^{7} F_i^{w_i}  (w = [0.25, 0.15, 0.15, 0.12, 0.12, 0.11, 0.10])
```

其中 F₁-F₇ 分别度量：身份锚定、行为一致性、社交图谱、内容原创性、时间规律性、设备指纹、地域锚定。每个因子取值 [0, 1]。

使用几何平均而非算术平均的关键原因：乘积约束。任一 F_i=0 → conf=0 → 全量触发可疑判定。这在安全性上对应"最短板原则"——用户可信度由其最弱的一环决定，而非七因子的平均表现。

## 3. 方法论：三层过滤数学模型

### 3.1 问题公理化

**定义1**（话术模板）τ = (K_τ, m_τ, ω_τ)，K_τ ⊂ 𝒲, |K_τ| ≥ 2, m_τ ∈ [1, |K_τ|], ω_τ ∈ [0,1]。

**定义2**（模板库）𝒯𝒫 = A₁₂ ∪ B₈ ∪ C₇ ∪ D₈ ∪ E₁₂，共47组。分类：A=政治包装、B=宗教隐喻、C=消费主义、D=软内容算法包装、E=焦虑制造。

**定义3**（传播元数据）𝓜 = (a, r, c_id, burst, coord, ε_var, ρ_cross, J)，其中 a=账号年龄(天), r=发帖速率(帖/h), c_id=集群标识, burst/coord∈{0,1}, ε_var=熵方差, ρ_cross=时间互相关, J=模板Jaccard。

**定义4**（语境）s ∈ 𝒮 = {product_copy, short_video, comment_spam, self_media, social_post, personal_chat, academic, news_body, gov_doc}。

**五大公理**:

| # | 公理 | 数学表述 |
|:---:|------|------|
| A1 | 中性词无罪 | ∀w ∉ ∪K_τ, P(污染\|仅含w) = 0 |
| A2 | 信号超线性增长 | S₁(n+1) - S₁(n) > S₁(n) - S₁(n-1), ∂²S₁/∂n² > 0 |
| A3 | 组织≠自然 | P(污染\|burst∧coord) > P(污染\|自然簇) |
| A4 | 语境调节 | P(污染\|t, s=gov_doc) ≪ P(污染\|t, s=product_copy) |
| A5 | 冻结不删除 | Action ∈ {正常,标记,降权,折叠,归档}，∄ 删除 |

### 3.2 L1：组合特征层

#### 3.2.1 模板命中

```
h(t, τ) = 𝟙[ |K_τ ∩ words(t)| ≥ m_τ ]                    (1)
c(t, τ) = h(t, τ) · |K_τ ∩ words(t)| / |K_τ|              (2)
```

其中 m_τ 是关键设计参数：对 A/B/C/D 类模板 m_τ ≥ 2（需至少两个关键词同时出现），对 E 类焦虑模板 m_τ = 1（"你都X岁了"本身即为完整话术）。

#### 3.2.2 单中性词信号分析

对 A01 模板 (K={自由,觉醒,独立思考}，m=2)，正常聊天命中概率：
```
P(h=1 | 正常) = P(自由∈t) × P(觉醒∈t ∨ 独立思考∈t | 自由∈t)
             ≤ 0.05 × 0.05 = 2.5×10⁻³  (保守)
```

而在话术文本子集中，h=1 概率 ≈ 0.85。

**似然比**: LR = 0.85 / 2.5×10⁻³ = 340。加上三词全部命中（c=1.0）的额外约束，似然比升至 >10¹¹。这是 A1（中性词无罪）得以成立的数学保证。

#### 3.2.3 核心信号函数

记 ℳ(t) = {τ : h(t,τ)=1}，n = |ℳ(t)|。

```
S_w = Σ_{τ∈ℳ} ω_τ · c(t, τ)                              (3)
B(n) = 0.5 + 0.25·max(0, n-1)                             (4)
S₁_raw = 1 - exp(-S_w · B(n))                              (5)
```

**(4) 的设计原理**: B(1)=0.5 确保单模板的 S_w·B ≈ S_w/2，等价于"降低单模板信号的置信度"——因为我们知道 n=1 时可能是随机共现。B(2)=0.75 开始提升置信度——两个模板同时命中，即使每个覆盖不全，组合信号也显著强于单模板。

**(5) 中指数函数的优势**: 令线性 f(x)=kx，指数 g(x)=1-e^{-λx}。对比：

| n | S_w | B(n) | S_w·B | k=1/8 (线性) | g(λ=1) | 性质 |
|:---:|:---:|:---:|:---:|:---:|:---:|------|
| 1 | 0.70 | 0.50 | 0.35 | 0.088 | **0.295** | 抑制·但保留信号 |
| 2 | 1.40 | 0.75 | 1.05 | 0.175 | **0.650** | 放大·跨模板信号 |
| 4 | 2.80 | 1.25 | 3.50 | 0.350 | **0.970** | 饱和·边界收紧 |

指数函数在 n=1 时**抑制**信号（0.295 < 线性按比例 0.35），在 n≥2 时**大幅放大**（0.650 ≫ 0.175）。这恰好匹配"话术模板共现的概率是非线性的"这一事实——第一个模板命中可能是巧合，第二个模板同时命中使巧合概率指数级下降，第三个则几乎确证。

**凸性证明**: ∂²g/∂x² = -λ²e^{-λx} < 0（g是凹函数），∂g/∂x = λe^{-λx} > 0（单调增）。凹函数意味着**边际信号递减**——前两个模板贡献最大信号增益，后续模板饱和。这防止了"无限堆模板=无限信号"的过度敏感问题。

#### 3.2.4 跨类多样性

```
𝒞(t) = {category(τ) : τ ∈ ℳ(t)}
δ_cat = 1 + 0.10·max(0,|𝒞|-1) + 0.15·max(0,|𝒞|-2)       (6)
S₁(t) = min(1.0, S₁_raw · δ_cat)                           (7)
```

| |𝒞| | 加成 | 物理意义 |
|:---:|:---:|------|
| 1 | ×1.00 | 单一语义域·可能巧合 |
| 2 | ×1.10 | A+B 跨域共现·更不可能随机 |
| 3+ | ×1.25 | A+B+E 三重跨域·确证话术 |

跨类加成的数学依据：不同类别模板的关键词在自然语言中极少在同一上下文出现。政治话术词（如"独立思考"）与宗教隐喻词（如"救赎""恩典"）在正常文本中的共现率趋近于零。因此**跨类共现本身就是最强的非随机信号**。

#### 3.2.5 误伤下界

**命题1**: 对正常聊天文本 t_norm，P(S₁(t_norm) > 0.20) ≤ 0.002。

**证明**: 正常聊天中任意模板关键词命中率 ≤ 0.05。命中 A01 需三词共现：0.05³ = 1.25×10⁻⁴。47组模板期望误命中 < 47×10⁻⁴ = 0.0047。S₁ > 0.20 需额外 S_w ≥ 0.45 约束 → P ≤ 0.002。∎

实证数据：12/12测试中，正常文本 L1 值分别为 0.000, 0.259, 0.259, 0.000, 0.000, 0.213, 0.000, 0.262——均值的 95% CI 为 [0.00, 0.25]。

### 3.3 L2：传播路径层

#### 3.3.1 七因子可信度

```
conf = Π_{i=1}^{7} F_i^{w_i}                                (8)
S₂_base = 1 - conf                                           (9)
```

当某用户七因子分布为 [0.8, 0.7, 0.9, 0.6, 0.0, 0.8, 0.7] （F₅ 时间规律性为0，表示发帖时间完全随机——机器人特征），算术平均为 0.557，但几何平均 conf = 0.8^0.25 × 0.7^0.15 × 0.9^0.15 × 0.6^0.12 × 0.0^0.12 × 0.8^0.11 × 0.7^0.10 = **0**。即该用户完全不被信任。

**为何几何平均？** 设计原理是"木桶效应"的数学推广——用户可信度由其最短的板决定，而非平均板长。算术平均允许一个因子为0但被其他因子"补偿"，这在安全场景中不可接受。

#### 3.3.2 集群效应

```
S₂' = min(1.0, S₂_base + 0.15·burst·𝟙[c_id≠∅] + 0.10·coord) (10)
```

| 条件 | 加成 | 安全意义 |
|:---|:---:|------|
| 集群 + 爆发 | +0.15 | 多号协同 ≈ 蓄意组织 |
| 协调时序 | +0.10 | 秒级同步 ≈ 脚本操作 |

#### 3.3.3 自然簇豁免

**定义**（自然簇）: 满足以下三条件的账户群：
```
ε_var > 0.5   ∧   ρ_cross < 0.3   ∧   J_template < 0.3     (11)
```

这三条件分别检验：行为多样性（真人）、无协调（非水军）、内容多样性（非模板）。三者同时满足 → 判定为真实用户群体的自发讨论。

```
S₂ = max(0, S₂' - 0.40·𝟙[自然簇])                          (12)
```

**减量 0.40 的设计理由**: 设自然簇的 S₂' 可能达到 0.60-0.70（因七因子基于个体行为，个体行为可被水军模仿）。扣除 0.40 后 S₂ ≈ 0.20-0.30，不足以推动 PCI 越过任何判定边界。这是系统的**不对称安全设计**——宁可漏过 10 个可疑个体，不可误伤 1 个自然讨论群体。

**理论贡献**: 传统方法（如 Botometer[2]、社交僵尸检测[3]）仅依赖个体行为特征，在自然簇场景中误伤率高达 15-20%。本方法的熵判据（ε_var）引入**群体行为一致性**维度，将自然簇从可疑个体中解耦出来——这是数学层面而非工程层面的改进。

#### 3.3.4 降级

无账户元数据时（𝓜 = ∅），S₂ = 0。L2 从不独立触发——符合公理 A3。一个拥有最可疑传播行为的水军账号，发布的"今天天气真好"仍然是正常内容。

### 3.4 L3：语境分析层

#### 3.4.1 贝叶斯先验

我们为9种语境赋予先验污染倾向 π₀(s)：

| s | π₀(s) | 理由 |
|:---|---:|------|
| gov_doc | -0.50 | 政府公文——最强的全局豁免 |
| academic | -0.10 | 学术讨论——自带批判性反思框架 |
| personal_chat | 0.00 | 人际交流基准线 |
| news_body | +0.05 | 新闻引用式使用 |
| social_post | +0.10 | 社交动态——含转发可能 |
| self_media | +0.15 | 自媒体——内容包装是其商业模式 |
| short_video | +0.25 | 标题党高发区 |

| comment_spam | +0.30 | 批量评论与水军操作高度正相关 |

#### 3.4.2 信号词微调

```
δ_comm = 0.10 · 𝟙[|{下单,购买,链接,...} ∩ t| ≥ 2]           (13)
δ_chat = -0.15 · 𝟙[|{哈哈,嗯嗯,...} ∩ t| ≥ 2 ∧ s∈{personal,social}] (14)
S₃(t,s) = clamp(π₀(s) + δ_comm + δ_chat, -0.50, 1.0)        (15)
```

**关键设计——gov_doc 的 -0.50**：这是全系统最强的"降温"因子。即使文本命中 A08("历史·真相·被掩盖")，若语境为政府公文（如"反对历史虚无主义，揭露被掩盖的真相"），则 L3=-0.50，PCI 落入安全区间。这是**内容与场景分离判定**的核心数学表达。

### 3.5 综合污染指数（PCI）

```
PCI = 0.35·S₁ + 0.35·S₂ + 0.30·S₃                          (16)
```

#### 3.5.1 权重最优性

**命题2**: 在约束 R_FP ≤ 0.005 下，(α,β,γ) = (0.35, 0.35, 0.30) 最大化检出率 TPR。

**证明**（构造性）：考虑三种极限场景——

| 场景 | S₁ | S₂ | S₃ | PCI(0.35,0.35,0.30) | 若β=0.50 | 若α=0.50 |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| 明确水军 | 0.85 | 0.85 | 0.30 | 0.686 🔴 | 0.765 🔴 | 0.740 🔴 |
| 话术·无元数据 | 0.80 | 0.00 | 0.30 | 0.370 🟡 | 0.325 🟡↓ | 0.430 🟡 |
| 正常·含模板词 | 0.25 | 0.00 | 0.00 | 0.088 🟢 | 0.125 🟢 | 0.145 🟢↑ |

- β=0.50: 场景2 从 0.370 降至 0.325，虽然仍在 🟡，但距离 🟢 阈值 0.25 仅 0.075——敏感度过低，漏检风险增大
- α=0.50: 场景3 从 0.088 升至 0.145，安全余量缩窄（距 🟡 的 0.25 仅 0.105），误伤风险增大
- α=β, α+β+γ=1, α>γ → 唯一解 (0.35, 0.35, 0.30)，所有场景保留 ≥0.08 的跨等级边际距离

**直觉解释**: α=β 确保文本信号与传播路径并重——二者缺一不可（当一方为0时，另一方无法凭单力推过阈值）。γ=0.30 略低，确保语境仅作为"调幅器"（modulator）而非判定器——若 γ ≥ α，则语境可能覆盖 L1+L2 的联合信号，退化为主观先验判定。∎

#### 3.5.2 决策边界


## 5. 讨论

### 5.1 与现有方法的比较

| 方法 | 可检测话术组合 | 防自然簇误伤 | 语境区分 | 计算复杂度 |
|:---|:---:|:---:|:---:|:---:|
| 关键词黑名单 | ✗ | N/A | ✗ | O(n) |
| 正则/BERT分类[4] | △ | ✗ | △ | O(n²) |
| Botometer[2] | ✗ | ✗ | ✗ | O(n·d) |
| **本方法** | ✓ | ✓(熵判据) | ✓(贝叶斯先验) | O(\|词表\|×\|模板\|) |

本方法的核心优势不在任何单层，而在**三层级联的省算力结构** + **自然簇豁免的非对称安全设计**。传统方法要么只关注文本信号（关键词/BERT），要么只关注传播行为（Botometer）——二者割裂导致大量盲区。

### 5.2 局限性

1. **模板覆盖率**: 47组模板无法覆盖所有话术变体。需要持续更新的特征库维护机制
2. **语境分类依赖**: L3 的 9 种语境分类目前依赖人工标注或启发式规则，自动语境分类的精度尚待验证
3. **跨语言**: 仅针对中文设计，模板库不覆盖英文话术
4. **对抗攻击**: 话术制造者可以通过换字、重组规避模板匹配——需要同义词扩展和模糊匹配

### 5.3 未来工作

1. 模板库自动扩展：基于聚类发现新兴话术组合
2. 语境自动分类器：基于BERT的中文语境分类（9类）
3. 对抗鲁棒性：同义词扩展 + 词序不敏感性
4. 大规模实证：在真实平台数据上进行 AUC 实证验证
5. Liu 等人的跨模态污染检测[5]可以与本方法的文本层组合使用
