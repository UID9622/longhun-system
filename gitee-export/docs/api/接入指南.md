# API 接入指南

> 合作伙伴专用 · REST API · 5 分钟接入

---

## 端点

| 方法 | 路径 | 说明 |
|:---|:---|:---|
| `POST` | `/v1/route` | 人格路由（核心） |
| `POST` | `/v1/audit` | 三色安全审计 |
| `GET` | `/v1/health` | 健康检查 |
| `POST` | `/v1/dna/verify` | DNA 追溯码验证 |

---

## 认证

所有请求需携带 API Key：

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
     http://127.0.0.1:8788/v1/health
```

## 核心接口：人格路由

```bash
POST /v1/route
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{
  "text": "帮我检查一下系统安全",
  "mode": "auto"
}
```

响应：

```json
{
  "persona": "P05",
  "persona_name": "上帝之眼",
  "action": "security_audit",
  "result": {
    "status": "🟢",
    "findings": [],
    "summary": "无异常"
  },
  "dna": "#龍芯⚡️丙午·丙申·乙卯·亥时·需-A1B2C3D4"
}
```

## 安全审计

```bash
POST /v1/audit
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{
  "content": "要审计的文本或代码",
  "source": "external"
}
```

| source | 说明 |
|:---|:---|
| `external` | 外部内容 → 全量扫描 |
| `self` | 自研内容 → 跳过模糊词 |

响应：

```json
{
  "level": "green",
  "score": 0.12,
  "alerts": [],
  "fuse_appeal": null
}
```

| level | 含义 |
|:---|:---|
| 🟢 green | 通过 |
| 🟡 yellow | 待人工确认 |
| 🔴 red | 熔断 |

## 错误码

| 状态码 | 含义 |
|:---|:---|
| 200 | 成功 |
| 401 | API Key 无效 |
| 403 | 权限不足 |
| 429 | 请求频率过高 |
| 503 | 服务不可用（自动切 Ollama 兜底） |
