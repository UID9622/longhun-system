## 真声克隆

基于 XTTS-v2，UID9622 本人录音训练。

```python
from longhun.voice import VoiceSynthesizer

synth = VoiceSynthesizer(persona="P02")  # 龍芯人格
audio = synth.speak("系统安全检查完毕，无异常。")
# → 返回 UID9622 真声音频

# 不同人格不同音色
synth_p00 = VoiceSynthesizer(persona="P00")  # 文心人格 — 沉稳
synth_p05 = VoiceSynthesizer(persona="P05")  # 上帝之眼 — 冷峻
```

### 训练数据
- 31 分钟有效音源（UID9622 本人）
- 24kHz 单声道 WAV
- 6 秒 + 24 秒优化参考音

## 声纹DNA

声纹特征 → SHA256 哈希 → DNA 追溯链。

```python
from longhun.voice import VoiceDNA

vdna = VoiceDNA()
# 录入声纹
vdna.register(user_id="UID9622", text="龍魂系统启动")
# 验证
result = vdna.verify(user_id="UID9622", audio_file="verify.wav")
# → {match: True, confidence: 0.97, dna: "#龍芯⚡️..."}
```
