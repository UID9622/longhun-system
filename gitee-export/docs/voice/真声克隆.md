# 🎯 真声克隆技术

> 基于 XTTS-v2 · UID9622 本人声音 · 本地训练 · 零云端依赖

---

## 原理

```
UID9622 录音 → 降噪/切分 → 特征提取 → XTTS-v2 微调 → TTS 合成
                                                    ↓
                                           不同人格 → 不同音色/语速
```

## 环境

```bash
python3.11 -m venv .venv-tts
source .venv-tts/bin/activate
pip install TTS transformers soundfile
```

## 数据准备

```bash
cd voice-twin
python3 voice_clone_trainer.py --prepare
```

产物：
- `voice_dataset/wav/` — 24kHz 单声道（31 分钟）
- `voice_dataset/chunks/` — 按静音切分的短片段
- `voice_dataset/reference.wav` — 6 秒参考音
- `voice_dataset/reference_optimized.wav` — 24 秒优化参考音

## 伦理声明

- ✅ 仅使用 UID9622 本人录音训练
- ❌ 不克隆他人声音
- 📛 知识库仅用于智慧解读，不用于声音克隆

## 人格音色切换

```python
from longhun.voice import PersonaVoice

pv = PersonaVoice()

# 切换人格 → 自动切换音色
pv.set_persona("P02")   # 龍芯 · 干练
pv.set_persona("P00")   # 文心 · 沉稳
pv.set_persona("宝宝")   # 温暖 · 柔和

pv.speak("你好，我是龍魂系统。")
```

## 服务端点

```
POST /v1/voice/synthesize
{
  "text": "要合成的文本",
  "persona": "P02",
  "speed": 1.0,
  "format": "wav"
}
```

响应：`audio/wav` 二进制流
