# 快速开始

5 分钟跑通第一个龍魂调用。

---

## 环境要求

- Python 3.10+
- 4GB+ 内存
- macOS / Linux / Windows

## 安装

```bash
pip install longhun
```

## 验证

```bash
python3 -c "from longhun import __version__; print(__version__)"
# → 2.1.0
```

## Hello World

```python
from longhun import PersonaRouter

router = PersonaRouter()

# 中文自然语言输入，自动路由到对应人格
result = router.route("帮我检查一下系统安全")
print(result)
```

输出：

```
🟢 P05 上帝之眼 · audit
   confidence: 0.80
   DNA: #龍芯⚡️丙午·丙申·丙辰·戊子·坎-ROUTE-AUDIT-XXXXXXXX
```

## 更多示例

```python
from longhun import PersonaRouter, Auditor, DNA

# 人格路由 — 不同输入自动匹配不同人格
router = PersonaRouter()
for text in ["检查安全", "修代码", "部署上线", "算五行"]:
    r = router.route(text)
    print(f"{text} → {r.persona} {r.persona_name}")

# 安全审计 — 三色判定
auditor = Auditor()
print(auditor.scan("正常内容").level)           # → green
print(auditor.scan("技术无国界").level)          # → red

# DNA 追溯
dna = DNA.generate("MYAPP", "INIT")
print(f"DNA: {dna} 有效: {DNA.verify(dna)}")
```
