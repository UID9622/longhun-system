# CNSH 语言规范 v2.0

> Chinese Semantic Harmony — 中文语义编程协议

---

## 不是什么

- ❌ 不是编程语言（不替代 Python/JS）
- ❌ 不是自然语言处理框架
- ❌ 不是 prompt engineering

## 是什么

一套**中文语义路由协议**。你用大白话说要做什么，系统自动匹配到精确的执行路径。

```
"看看那个跑着没" → 服务状态检查
"发篇文章出去"   → 发布到配置的平台
"该续期了"       → Token/证书到期提醒
```

---

## 三层路由

| 层 | 机制 | 延迟 |
|:---|:---|:---:|
| ① 语义抽屉 | 50+ 意图域，近义词扩展 | < 1ms |
| ② 缓存匹配 | 历史匹配结果缓存 | < 5ms |
| ③ LLM 降级 | AI 语义推断 | < 2s |

## 50+ 意图域

| 域 | 触发词（示例） |
|:---|:---|
| 安全审计 | 检查、审计、安全、有问题吗 |
| 代码修复 | 修一下、改好、不报错 |
| 数据同步 | 同步、联动、串起来 |
| 自动化 | 自动化、补代码、乔接、Mac自动 |
| 部署上线 | 部署、发布、上线 |
| 五行八卦 | 算一下、数字根、五行、属什么 |
| 贡献评估 | 值得吗、过期了、还顶用吗 |
| 情绪海绵 | 累了、难过、烦 |
| 知识查询 | 道德经、孔子、孙子、易经 |
| ... | 共 50+ 域 |

## 中英双轨

```
中文输入 → 语义抽屉匹配 → 中文命令
English input → exact match → English command

两轨平行，互不污染
```

## 人格路由

匹配到意图后，自动分发到对应人格：

| 人格 | 职责 | 落地状态 |
|:---|:---|:---:|
| P05 上帝之眼 | 安全检查/审计 | 🟢 |
| P02 龍芯 | 代码修复 | 🟢 |
| P01 诸葛亮 | 决策分析 | 🟢 |
| P15 乔前辈 | 自动化/桥接 | 🟡 |
| P77 黑天使 | 漏洞检测 | 🟡 |

---

## 规范形式

- **CNSH** = 协议名，不可改为 CNS、CN 等其他缩写
- **龍** = 繁体为规范字，简体等价接收自动归一
- **DNA** = 追溯码，v∞ 格式（干支卦 + 哈希）
- **UID9622** = 系统唯一主权标识
