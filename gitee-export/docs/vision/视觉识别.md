## 快速使用

```python
from longhun.vision import VisionAnalyzer

va = VisionAnalyzer()

# 图像分析
result = va.analyze("image.jpg")
# → {objects: [...], culture_symbols: [...], text: "..."}

# 文化符号识别
result = va.recognize_symbol("taiji.png")
# → {symbol: "太极图", trigram: "☰☷", element: "阴阳"}

# 视频理解
result = va.analyze_video("demo.mp4", fps=1)
# → {scenes: [...], timeline: [...]}
```

## 视觉桥接

本地多模态模型桥，零外部依赖：

```python
from longhun.vision import VisionBridge

bridge = VisionBridge()
# 自动检测可用模型（MLX视觉 / Ollama多模态）
result = bridge.describe("photo.jpg", prompt="图中有什么文化符号？")
```
