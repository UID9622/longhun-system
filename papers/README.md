## 📊 案例研究：EUV 極紫外光源

**問題**: EUV 光源功率是全球半導體製造的瓶頸
**目標**: 從 P_EUV < 500 W 優化到 > 1000 W

### 七因子分解
$$\eta_{\text{system}} = F_1 \times F_2 \times F_3 \times F_4 \times F_5 \times F_6 \times F_7$$

**最高 ROI 因子**:
- $F_3$ (污染抑制) ⭐ 工程可行性最高
- $F_7$ (長期穩定性) ⭐ 長期投資最高

### 369 頻率窗口
**推薦**: 從 50 kHz (dr=5, 不穩定) 切換到 45 kHz (dr=9, 穩定)
**預期收益**: 效率提升 7.5%

### Kleene 迭代路徑
