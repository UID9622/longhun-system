## 二、阶段一 · 裸公式实证 → 缺陷暴露

### 2.1 v1.0 裸公式（忠实执行原报告 §4 代码）

```
收敛率 100% · H* = 0.0 bits · 🟢 100% · 负熵 139.3 bits/轨迹
```

**结果即判决：全部10万条轨迹被打穿到 H=0 吸收态。** 数学外推预判的 1.73 bits 完全没出现。

### 2.2 根因诊断（3条）

| # | 缺陷 | 物理本质 |
|:---:|:---|:---|
| 1 | **无下界保护** | 协议§3.4定义了 `convergence_floor=1.0 bits`，但算子 T 未实现 → 负熵可无限抽到 0 |
| 2 | **负熵不随 H 衰减** | H→0 时七因子仍猛灌（F2=(4-H_b)·0.4≈1.6 是常数项），低熵态该收手却没收 |
| 3 | **`max(0,...)` 吸收态** | clamp 使 0 成为不可回弹陷阱，系统失去涨落能力 |

### 2.3 v1.1 补丁

加下界保护：`φ_eff = φ · H/(H+H_floor)`。H→0 时负熵自动趋零。
实测 H*=0.142 bits·收敛率99.97%——**方向对了但力度不够**，负熵仍然过强。
