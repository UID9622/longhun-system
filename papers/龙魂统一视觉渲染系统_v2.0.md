## 〇、丝滑设计原则（🆕 v2.0 新增 · 本次升级的核心）

### 0.1 为什么 v1.x 不够"丝滑"

| 问题 | v1.x 做法 | 观感后果 |
|------|-----------|----------|
| **硬闪烁** | `opacity: 1 → 0.2` 线性对半跳 | 刺眼、焦躁、像故障 |
| **匀速缓动** | 全部 `ease-in-out` | 机械感，无呼吸韵律 |
| **阻塞终端** | `while + time.sleep()` 独占主线程 | 动画期间 CLI 卡死，Ctrl+C 才能退 |
| **无安全阈值** | pulse 0.5s 周期（每秒闪 2 次） | 踩 WCAG 2.3.1 红线（≤3次/秒），光敏风险 |
| **无视系统偏好** | 不检测 `prefers-reduced-motion` | 对前庭敏感用户强制播放动画 |

### 0.2 丝滑五条军规

```javascript
军规一 · 亮度连续：动画只调亮度/辉光，opacity 永不低于 0.65（文字永远可读）
军规二 · 曲线有机：核心曲线用 sin() 正弦（呼吸的天然形状），不用线性折返
军规三 · 终端不阻塞：动画渲染走独立线程，主线程随时可继续输出
军规四 · 频率安全：任何动画完整周期 ≥ 0.8s，每秒闪烁 ≤ 2.5 次（低于 WCAG 3次红线）
军规五 · 尊重偏好：prefers-reduced-motion: reduce 时全部降级为静态 3D
```

### 0.3 缓动函数规范

| 用途 | 曲线 | 理由 |
|------|------|------|
| 呼吸/辉光 | `sin()` 正弦 / `ease-in-out-sine` | 模拟自然呼吸，加减速最柔和 |
| 脉冲 | `cubic-bezier(0.34, 1.56, 0.64, 1)`（带回弹） | 一次"弹跳"而非来回抽风 |
| 状态切换 | `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint） | 快起慢收，干脆不拖沓 |
| 进场 | `cubic-bezier(0.16, 1, 0.3, 1)`（easeOutExpo） | 瞬间响应 + 长尾平顺 |

    "🟡": {"fg": 93, "name": "主权金", "anim": "breath"},
    "🔵": {"fg": 94, "name": "追踪蓝", "anim": "pulse"},
    "⚪": {"fg": 37, "name": "过渡银", "anim": "none"},
    "🟢": {"fg": 92, "name": "放行绿", "anim": "none"},
}

# ✨ 安全频率：完整周期秒数（≥2.0s，每秒闪烁 ≤0.5 次）
ANIMATION_PERIOD = {
    "flash": 2.0,
    "breath": 3.5,
    "pulse": 2.5,
    "slow": 3.0,
    "none": 0,
}

class SmoothTerminalAnimator:
    """✨ 非阻塞终端动画器：后台线程渲染，主线程随时可用"""

    def __init__(self):
        self._thread = None
        self._stop = threading.Event()
        self._lock = threading.Lock()

    @staticmethod
    def _supports_color() -> bool:
        """✨ 降级检测：无 TTY 或不支持颜色时直接纯文本输出"""
        return sys.stdout.isatty() and not sys.platform.startswith("win") or \
               os.environ.get("TERM", "") not in ("", "dumb")

    def start(self, text: str, color_emoji: str, animation: str = "breath"):
        """启动后台动画，立即返回（不阻塞）"""
        self.stop()  # 先停掉上一个动画
        if color_emoji not in COLOR_ANSI or animation == "none":
            fg = COLOR_ANSI.get(color_emoji, {}).get("fg", 37)
            print(f"\033[{fg}m{text}\033[0m")
            return

        self._stop.clear()
        self._thread = threading.Thread(
            target=self._animate_loop,
            args=(text, color_emoji, animation),
            daemon=True,          # ✨ 守护线程：主程序退出时自动回收
        )
        self._thread.start()

    def _animate_loop(self, text, color_emoji, animation):
        fg = COLOR_ANSI[color_emoji]["fg"]
        period = ANIMATION_PERIOD.get(animation, 3.0)
        frame_dt = 1 / 30        # ✨ 30fps 刷新，正弦采样足够平滑
        t0 = time.time()
        while not self._stop.is_set():
            t = (time.time() - t0) % period
            # ✨ 正弦亮度曲线：0.7 ~ 1.0 连续呼吸（不再二值跳变）
            brightness = 0.85 + 0.15 * math.sin(2 * math.pi * t / period)
            style = f"{fg};1" if brightness > 0.92 else (str(fg) if brightness > 0.78 else f"{fg};2")
            with self._lock:
                sys.stdout.write(f"\r\033[{style}m{text}\033[0m\033[K")
                sys.stdout.flush()
            time.sleep(frame_dt)

    def stop(self, final_text: str = None, color_emoji: str = "🟢"):
        """停止动画，恢复常亮并换行"""
        self._stop.set()
        if self._thread and self._thread.is_alive():
            self._thread.join(timeout=0.5)
        if final_text:
            fg = COLOR_ANSI.get(color_emoji, {}).get("fg", 92)
            with self._lock:
                sys.stdout.write(f"\r\033[{fg}m{final_text}\033[0m\033[K\n")
                sys.stdout.flush()

# ============================================================
# 演示：动画播放的同时主线程继续工作
# ============================================================

def demo():
    anim = SmoothTerminalAnimator()
    print("🐉 丝滑动画演示（后台渲染，主线程不阻塞）\n")

    anim.start("🔴 断空红 · 熔断警戒中", "🔴", "flash")
    for i in range(5):
        time.sleep(0.8)
        print(f"  ↳ 主线程日志 {i+1}/5：动画期间我照样能输出")  # ✨ 关键证据
    anim.stop("🔴 断空红 · 熔断已确认，转入人工", "🔴")

    anim.start("🟡 主权金 · 身份核验呼吸中", "🟡", "breath")
    time.sleep(3.5)
    anim.stop("🟡 主权金 · 核验完成", "🟡")

if __name__ == "__main__":
    demo()
