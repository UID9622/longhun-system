## 数学工具箱（标准理论，供公式化引用）

### 1. 湍流经典形式化
- Navier-Stokes 方程：∂u/∂t + (u·∇)u = -∇p/ρ + ν∇²u + f
- 能量级联（Kolmogorov 1941）：ε(k) 从大尺度向小尺度传递，E(k) ∝ ε^{2/3}k^{-5/3}
- Kolmogorov 微尺度：η = (ν³/ε)^{1/4} —— 小于此尺度的涡被粘性耗散
- 自由度爆炸：N ∝ Re^{9/4}，雷诺数稍大则直接数值模拟(DNS)不可行

### 2. 三六九不动点 ← Banach 不动点定理
- 完备度量空间 (X,d)，收缩映射 T: X→X 满足 d(Tx,Ty) ≤ q·d(x,y)，q∈(0,1)
- 则存在唯一不动点 x* = Tx*，且任意初值迭代 x_{n+1}=Tx_n 收敛于 x*
- 收敛速率：d(x_n, x*) ≤ q^n/(1-q) · d(x_1,x_0)
- 映射：不追无限级联的小涡，而是构造收缩映射找稳定锚点（三/六/九级锚点层级）

### 3. 七因子行为密码学 ← 加权指纹 + 相似度
