# /water-army-detect · 水军识别引擎

## 摘要

水军识别引擎（water-army-detect）是龍魂系统的防御性水军行为检测引擎。基于审计过滤系统规格书第七层规范，对评论/发言/举报行为执行六维检测：文本重复度分析（哈希+余弦相似度）、新号高频模式识别、时间窗口协同攻击检测、IP/设备指纹聚类、内容模板化识别、举报成功率追踪。输出三色审计结果（🟢正常/🟡可疑/🔴水军特征），**只标记不封禁、只降权不删号、可申诉可追溯**。铁律：防御性检测，不做主动进攻。

## 关键词

水军检测 Water Army Detection, 协同攻击 Coordinated Attack, 文本去重 Text Dedup, 行为聚类 Behavior Clustering, 三色审计 Three-Color Audit, 举报降权 Report Downgrade, 模板化识别 Template Recognition, 防御性检测 Defensive Detection

## 检测维度

### 一、文本重复度
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| 完全相同内容 | SHA256 哈希去重 | 相同哈希 ≥ 5 次 → 🟡 |
| 高度相似内容 | 余弦相似度（jieba 分词 + TF-IDF） | 相似度 > 0.9 且 ≥ 10 条/h → 🔴 |
| 模板化内容 | 正则模版匹配（替换变量部分） | 模板命中 ≥ 3 条/h → 🟡 |

### 二、账号生命周期
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| 新号高频发言 | 注册时间 < 7天 + 日发言 > 50条 | 命中 → 🟡 |
| 新号极限发言 | 注册时间 < 1天 + 日发言 > 100条 | 命中 → 🔴 |
| 休眠激活 | 长期不活跃 → 突然高频 | 7天无活动 → 日发言 > 30条 → 🟡 |

### 三、时间窗口协同
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| 协同举报 | 多账号同时举报同一目标 | 5min内 ≥ 5 不同账号 → 🔴 |
| 协同刷评 | 多账号密集评论同一内容 | 10min内 ≥ 10 不同账号 → 🟡 |
| 定时发布 | 固定时间间隔批量发布 | 间隔标准差 < 5s → 🟡 |

### 四、内容模式
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| 情绪操控 | 感叹号/emoji密集 + 短句重复 | 感叹号占比 > 15% + 重复率 > 30% → 🟡 |
| 导向性话术 | "必须转发"/"不转不是XX"/"都来看" | 导向性话术命中 → 🟡 |
| 语义漂移 | 同一账号短时间在不同话题间跳跃 | 1h内 > 5 个不相关话题 → 🟡 |

### 五、关联分析
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| IP/设备聚类 | 同 IP 同设备指纹多账号 | 同 IP ≥ 3 个账号 → 🟡 / ≥ 10 个 → 🔴 |

### 六、举报信用
| 特征 | 检测方法 | 阈值 |
|------|---------|------|
| 恶意举报 | 历史举报成功率 < 20% | 命中 → 举报权重归零 |

## 诚实局限

1. 文本相似度依赖 jieba 分词，对非中文内容检测精度下降。
2. IP/设备指纹聚类需接入实际日志数据，本地离线模式下仅做模拟。
3. 时间窗口分析依赖时间戳数据，不适用于无时间信息的静态文本。
4. 模板化识别基于正则模式库，新模板需要持续更新。
5. 检测结果仅作为参考标记，不可直接用于自动封禁。

## 使用方式

```bash
# 对单个文本片段检测
python3 bin/lh_water_army_detect.py scan "评论文本内容"

# 对文件批量检测
python3 bin/lh_water_army_detect.py scan-file <文件路径>

# 对 JSONL 评论数据进行批量分析
python3 bin/lh_water_army_detect.py batch <jsonl文件>

# 查看检测规则
python3 bin/lh_water_army_detect.py rules
```
