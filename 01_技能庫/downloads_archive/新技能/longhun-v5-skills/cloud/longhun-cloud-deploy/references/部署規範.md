## 1. 概述

本文檔定義龍魂部署引擎的標準部署規範，包含 27 步藍綠部署流程的詳細說明、配置標準、操作準則。

## 2. 部署流程規範

## 3. 配置標準

### 3.1 命名規範

```
命名空間: longhun-<環境>
部署名稱: <應用名>-<blue|green>
服務名稱: <應用名>
配置映射: <應用名>-config
密鑰名稱: <應用名>-secrets
入口名稱: <應用名>-ingress
HPA 名稱: <應用名>-hpa
```

### 3.2 標籤規範

```yaml
labels:
  app: <應用名>
  version: <blue|green>
  longhun.dna: "#龍芯⚡️2026-06-19-LONGHUN-DEPLOY-v5.0"
  longhun.deploy.id: <部署ID>
  managed-by: longhun-deploy
```

### 3.3 資源限制標準

| 環境 | CPU Request | CPU Limit | 內存 Request | 內存 Limit |
|------|------------|-----------|-------------|-----------|
| 開發 | 100m | 500m | 128Mi | 512Mi |
| 測試 | 200m | 1000m | 256Mi | 1Gi |
| 預發布 | 500m | 2000m | 512Mi | 2Gi |
| 生產 | 1000m | 4000m | 1Gi | 4Gi |

## 4. 回滾規範

### 4.1 回滾策略選擇

| 策略 | 適用場景 | 回滾時間 | 風險 |
|------|---------|---------|------|
| 全量回滾 | 標準部署失敗 | ~30s | 低 |
| 漸進回滾 | 流量切換異常 | ~90s | 低 |
| 熔斷回滾 | 緊急故障 | ~10s | 中 |
| 手動確認 | 生產環境審批 | 不確定 | 最低 |

### 4.2 回滾觸發條件

- 部署步驟返回非零狀態
- 健康檢查連續失敗 3 次
- 流量切換階段錯誤率 > 1%
- 人工手動觸發
- 外部監控告警觸發

## 5. 安全規範

- 生產環境部署必須經過雙人審批
- 數據庫遷移必須先備份
- 容器鏡像必須掃描無 HIGH 漏洞
- 所有操作記錄審計日誌
- 遵循最小權限原則
