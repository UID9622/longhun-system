## 1. 驗證目標

確保部署目標環境滿足運行要求，包括基礎設施、權限、網絡、資源等方面。

## 2. 驗證項目清單

### 2.1 基礎工具驗證

| 工具 | 最低版本 | 驗證命令 | 說明 |
|------|---------|---------|------|
| Python | 3.9 | `python3 --version` | 運行時環境 |
| Docker | 20.10 | `docker --version` | 容器引擎 (Docker 模式) |
| kubectl | 1.25 | `kubectl version --client` | K8s 控制工具 |
| curl | 7.0 | `curl --version` | HTTP 測試工具 |
| git | 2.30 | `git --version` | 源碼管理 |

### 2.2 網絡連通驗證

| 目標 | 驗證方法 | 超時 |
|------|---------|------|
| 容器倉庫 | ping / curl | 5s |
| K8s API Server | kubectl cluster-info | 10s |
| 外部依賴服務 | curl health endpoint | 10s |
| DNS 解析 | nslookup | 5s |

### 2.3 權限驗證

| 權限項 | 驗證命令 | 說明 |
|--------|---------|------|
| K8s 讀取權限 | `kubectl auth can-i get deployments` | 查看資源 |
| K8s 創建權限 | `kubectl auth can-i create deployments` | 創建資源 |
| K8s 更新權限 | `kubectl auth can-i patch services` | 更新服務 |
| K8s 刪除權限 | `kubectl auth can-i delete pods` | 清理資源 |
| Docker 權限 | `docker ps` | 容器管理 |

### 2.4 資源驗證

| 資源類型 | 最低要求 | 驗證方法 |
|---------|---------|---------|
| CPU | 2核 | `nproc` / K8s node info |
| 內存 | 4GB | `free -m` / K8s allocatable |
| 磁盤 | 20GB | `df -h` |
| 網絡帶寬 | 100Mbps | `iperf3` |

## 4. 驗證結果等級

| 等級 | 標記 | 處理方式 |
|------|------|---------|
| 通過 | 🟢 | 繼續部署流程 |
| 警告 | 🟡 | 記錄警告，繼續部署但需關注 |
| 阻塞 | 🔴 | 終止部署，需先解決問題 |

## 5. 驗證腳本

```python
# 快速驗證示例
python3 -c "
import subprocess

def 驗證工具(名稱, 命令):
    try:
        結果 = subprocess.run(命令, shell=True, capture_output=True, text=True, timeout=5)
        if 結果.returncode == 0:
            print(f'🟢 {名稱}: {結果.stdout.strip()[:50]}')
            return True
        else:
            print(f'🔴 {名稱}: 驗證失敗')
            return False
    except Exception as e:
        print(f'🔴 {名稱}: {e}')
        return False

# 執行驗證
驗證工具('Python', 'python3 --version')
驗證工具('Docker', 'docker --version')
驗證工具('kubectl', 'kubectl version --client')
驗證工具('curl', 'curl --version | head -1')
"
```
