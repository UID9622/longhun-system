## 1. 五行基礎

五行（金木水火土）是中華傳統哲學的核心概念，用於描述宇宙間事物的相互關係與變化規律。

### 1.1 五行屬性對照

| 元素 | 屬性 | 金融含義 | 權重 |
|------|------|----------|------|
| 金 | 剛健、收斂 | 資金、風控 | 0.25 |
| 木 | 生發、條達 | 增長、投資 | 0.20 |
| 水 | 潤下、流動 | 流動性 | 0.20 |
| 火 | 炎上、熱情 | 熱度、市場情緒 | 0.15 |
| 土 | 稼穡、承載 | 穩定性、基礎設施 | 0.20 |

### 1.2 五行相生

```
金生水 → 水生木 → 木生火 → 火生土 → 土生金
```

### 1.3 五行相克

```
金克木 → 木克土 → 土克水 → 水克火 → 火克金
```

## 2. 核心公式

### 2.1 平衡指數

衡量五行力量的均衡程度：

```
平均值 μ = (金+木+水+火+土) / 5
方差 σ² = Σ(xi - μ)² / 5
標準差 σ = √σ²
平衡指數 = max(0, 1 - σ × 2)
```

**解讀**: 越接近1表示五行越平衡。

### 2.2 生克強度

分析五行之間的相生相克態勢：

```
生力 = Σ(生者值 × 被生者值 × 0.5)  [遍歷相生表]
克力 = Σ(克者值 × 被克者值 × 0.5)  [遍歷相克表]
生克比 = 生力 / (生力 + 克力)
理想偏差 = |生克比 - 0.6|
生克強度 = max(0, 1 - 理想偏差 × 2.5)
```

**解讀**: 理想狀態是生略大於克（0.6左右）。

### 2.3 三才系數

三才（天、地、人）和諧度：

```
和諧度 = max(0, 1 - std(天,地,人) × 3)
特別獎勵: min(天,地,人) > 0.7 → 和諧度 × 1.2
```

### 2.4 複合決策強度

```
複合決策強度 = 平衡指數×0.35 + 生克強度×0.30 + 三才系數×0.35
```
