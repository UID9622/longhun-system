# 🏯 中央藏经阁 · longhun-archive

## 1. 技能概述 (Overview)

中央藏经阁是龍魂体系的统一文档索引和检索系统，管理29部核心文档的元数据。
采用五行分类法（金木水火土）对文档进行分类，支持三色审计标注（🔴核心🟡重要🟢参考），
提供关键词检索、DNA追溯链检索、全文检索、五行分类检索等多维度查询能力。

## 6. 执行流程 (Execution Flow)

```
[接收查询] → [解析动作类型] → [执行对应操作] → [格式化输出] → [返回结果]
    │
    ├─ search → 关键词/DNA/五行/全文检索
    ├─ list → 列出所有文档（支持按五行排序）
    ├─ register → 注册新文档到索引
    ├─ unregister → 从索引注销文档
    ├─ stats → 生成统计报告
    ├─ export → 导出Markdown目录
    └─ init → 初始化29部核心文档索引
```

## 10. 错误处理 (Error Handling)

| 错误场景 | 处理方式 |
|----------|----------|
| 文档名称已存在 | 提示并执行更新操作 |
| 文档不存在 | 返回警告信息，操作失败 |
| 索引文件不存在 | 创建新空索引 |
| 无效五行分类 | 返回空列表并打印警告 |
| JSON解析失败 | 捕获异常，返回False |
| 保存路径无效 | 自动创建目录 |
