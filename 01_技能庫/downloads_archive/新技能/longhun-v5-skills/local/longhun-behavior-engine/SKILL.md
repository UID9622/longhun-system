# 龍魂公民画像引擎 v1.0

## 核心思想

> 我不商业，但是要有规矩。
> 点外卖选"不要餐具"=环保贡献值。
> 随手点赞 vs 真心评价，权重不一样。
> 为人民服务的人，必须亮出来。

## 六大维度

| 维度 | 说明 | 权重 | 示例 |
|------|------|------|------|
| 环保贡献 | 绿色行为累计 | 15% | 不要餐具、骑单车、节水 |
| 信誉分 | 诚信历史 | 25% | 履约、准时、承诺兑现 |
| 互动质量 | 点赞评论真实度 | 15% | 真心评价权重高，敷衍打折 |
| 服务分 | 为人民服务 | **30%** | 帮助老人、清理公共区域 |
| 习惯分 | 长期行为模式 | 15% | 连续天数越多分越高 |

## 真实度判定

| 真实度 | 等级 | 权重影响 |
|--------|------|----------|
| 1.0 | 真心 | 100% |
| 0.8 | 认真 | 80% |
| 0.5 | 一般 | 50% |
| 0.2 | 敷衍 | 20% |
| 0.1 | 刷量 | 10% |

## 亮灯控制（用户自主）

用户自己决定哪些维度对外展示：
- 🟢 亮灯 = 对外可见
- 🔴 熄灯 = 隐私保护

## API

```python
from 公民画像引擎 import 公民画像引擎

引擎 = 公民画像引擎("UID9622")
引擎.记录环保行为("点外卖-不要餐具", 2.0)
引擎.记录服务行为("帮助老人搬运", 5.0)
引擎.记录互动质量("旅游评价-200字", 1.0, 真实度=1.0)
引擎.设置亮灯("服务分", True)
print(引擎.获取亮灯展示())
```
