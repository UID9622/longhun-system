## 1.3 库存差异率（满分20分）

### 1.3.1 差异率指标（8分）

**目标：库存差异率 ≤ ±0.1%**

差异率计算公式：
```
差异率 = |系统库存 - 实物库存| / 总SKU数 × 100%
```

| 差异率范围 | 得分 | 评级 |
|------------|------|------|
| ≤0.05% | 8分 | 🟢 A |
| 0.05%-0.1% | 6分 | 🟢 B |
| 0.1%-0.3% | 4分 | 🟡 C |
| 0.3%-0.5% | 2分 | 🟡 D |
| >0.5% | 0分 | 🔴 E |
