## 4. 太极阴阳动力学方程

### 4.1 从几何到动力学

太极图的S形曲线不仅是阴阳平衡的象征，更是非线性动力学中相空间吸引子的几何模型。

### 4.2 太极微分方程组

**定义3（太极动力学系统）**: 定义二维非线性微分方程组：

```
 dx/dt =  α·y - β·x·(x² + y²) + γ·sin(ωt)
 dy/dt = -α·x - β·y·(x² + y²) + γ·cos(ωt)
```

其中：
- x(t) = 阳势（显性力量）
- y(t) = 阴势（隐性力量）
- α = 耦合强度（阴阳相互作用）
- β = 阻尼系数（防止无限增长的自限机制）
- γ = 外力振幅（环境扰动）
- ω = 外力频率（周期节律）

### 4.3 不动点分析

**定理4（太极不动点定理）**: 当γ = 0（无外力）时，系统有唯一稳定不动点：(x*, y*) = (0, 0)，对应太极图的"无极"状态。

当γ ≠ 0时，系统存在周期轨道，对应太极图的阴阳旋转。

**证明**: 令dx/dt = dy/dt = 0，解代数方程组。雅可比矩阵在(0,0)处的特征值为 λ = -βr² ± iα，实部为负（当r > 0），故稳定。∎

### 4.4 阴阳势的量化定义

**定义4（阴阳势函数）**: 

```
Φ(x, y) = (x² + y²) / 2          —— 总势能
Ψ(x, y) = arctan(y/x) / (2π)     —— 阴阳比例 (0=纯阳, 0.5=平衡, 1=纯阴)
```

### 4.5 可计算验证

from scipy.integrate import odeint
import matplotlib.pyplot as plt

def taiji_system(state, t, alpha=1.0, beta=0.1, gamma=0.5, omega=1.0):
    """太极阴阳动力学系统"""
    x, y = state
    dxdt = alpha * y - beta * x * (x**2 + y**2) + gamma * np.sin(omega * t)
    dydt = -alpha * x - beta * y * (x**2 + y**2) + gamma * np.cos(omega * t)
    return [dxdt, dydt]

# 数值积分
t = np.linspace(0, 20, 2000)
state0 = [1.0, 0.0]  # 初始状态：纯阳

x, y = solution[:, 0], solution[:, 1]

Phi = (x**2 + y**2) / 2        # 总势能
