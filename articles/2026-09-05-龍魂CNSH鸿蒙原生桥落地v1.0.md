## 二、真实落地：三层编译路径（可编译可验证版）

```
CNSH 源码 (.cnsh · tests/cnsh_samples/ 权威语法)
        ↓  cnsh_cgen.py v0.1（08_BIN/ · 纯标准库单文件）
C/C++ 逻辑 (cpp/cnsh_logic.c · 自动生成勿手改)
        ↓  鸿蒙 NDK N-API unity 桥（cpp/cnsh_napi.cpp）
鸿蒙原生模块 libcnsh_bridge.so → ArkTS import 调用
```

