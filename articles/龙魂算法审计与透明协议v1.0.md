5.1 算法备案覆盖率 C（GAP-02补全）
```
C = |备案算法 ∩ 探测到运行中的算法| / |探测到运行中的算法| × 100%
探测手段（AI巡检自动执行）:
  ① 流量特征指纹比对（请求模式/模型输出风格/接口调用序列）
  ② 变更探测：同一功能输出分布突变（KS检验，见5.4）→ 存在未声明算法上线
铁律: C < 100% → 🔴 立即熔断该平台全部接入，未备案算法单独立案
```
含义：备案不是交个名单就完事——名单之外跑任何一个算法，链上都会留脚印。

5.2 AIGC双标识合规率 η
```
抽检AIGC样本 n ≥ 300/月：
η = 同时满足(显式水印 ∧ 隐式元数据 ∧ 来源链完整)的样本数 / n
合规线: η ≥ 0.99；0.95≤η<0.99 → 🟡限期整改；η<0.95 → 🔴暂停AIGC功能
隐式元数据必含: 生成模型DNA、生成时间(UTC)、平台ID、是否二次加工
```

5.3 杀熟检测（Mann-Whitney U 显著性检验 · GAP-03补全）
```
对照设计: 新客组与老客组，同商品/同服务/同时段，各询价 n ≥ 30 次（神秘客采样）
价差率: δ = 中位数( (P老 − P新) / P新 )
统计检验: 两组价格分布做Mann-Whitney U检验（价格非正态，用非参检验）
判定（三与门）: p < 0.05 ∧ δ > 3% ∧ 平台无法给出成本/促销的合理证据 → 杀熟成立
法律依据: 《个人信息保护法》第24条——自动化决策须透明，不得实行不合理差别待遇
处置: 杀熟成立 = L4禁区级算法 = 极端违规（差价退还+处罚+公示）
```
含义：不靠用户截图喊冤，靠双组对照+显著性检验——让数据自己说话。

5.4 上影/限流检测（KS分布检验 · GAP-04补全）
```
对照设计: 申报疑似被限流账号 vs 同量级同垂类对照组（≥20个账号）
指标: 单位粉丝曝光量 E = 曝光数/粉丝数，取30天日序列
检验: 两组E的分布做Kolmogorov–Smirnov检验
  D = sup_x |F_申报(x) − F_对照(x)|
  临界值: D_临界(α=0.05) ≈ 1.36·√((n+m)/(n·m))
判定:
  D > D_临界 ∧ 平台无该账号违规记录公示 → 存在未声明干预 = 上影算法成立
  上影成立且平台曾否认 → 暗箱+撒谎，罪加一等（严重→极端升级）
申诉正用: 同一公式也是创作者自证清白的工具——"我没有违规，是平台压我"可统计举证
```

5.5 授权诱导指数 I（GAP-05补全 · K3核心）
```
T_需要 = 协议总字数 / 400        # 平均阅读速度400字/分钟，单位：分钟
T_实际 = 授权页平均停留时长（分钟，遥测中位数）
I = T_需要 / T_实际

判定:
  I > 1     → 物理上不可能读完 → 诱导成立，该授权全体无效
  0.5 < I ≤ 1 → 🟡 警示，强制整改为"要点摘要卡"（≤300字，五号字以上）
  I ≤ 0.5   → 可读性达标

附加铁律（全部为0容忍项，任一违反=授权无效）:
  默认勾选数 = 0        # 禁默选
  捆绑授权数 = 0        # 敏感权限一次一权，逐项确认
  撤回步骤数 ≤ 授权步骤数   # 对称原则：一键进来的，必须能一键出去
  协议要点摘要卡 = 必须有   # ≤300字+显著标识+版本变更重签
```

5.6 分层抽检模型（GAP-06补全 · 监督资源最优分配）
```
抽检密度按算法级别×平台信用动态分配：
| 级别 | 基础月抽检率 |
| L0/L1 | 5%（季度） |
| L2    | 20%（月度） |
| L3    | 100%（月度全检） |
| L4    | 不适用（禁止运行） |
信用修正系数: 密度 × (1 + 0.5·近12月违规次数)
免检通道: 连续365天零违规 + 三次飞检全过 → 抽检率降至基础值20%（信用是挣来的）
一次违规 → 免检资格立即取消，365天重新计
```
统计依据：分层抽样保证高危算法100%被照到，低危算法低成本覆盖——好钢用在刀刃上。

                秩[t] = (i + j) / 2 + 1
            i = j + 1
        R1 = sum(秩[t] for t in range(len(合并)) if 合并[t][1] == 0)
        U = n1 * n2 + n1 * (n1 + 1) / 2 - R1
        μ, σ = n1 * n2 / 2, math.sqrt(n1 * n2 * (n1 + n2 + 1) / 12)
        z = (U - μ) / σ
        p = math.erfc(abs(z) / math.sqrt(2))                  # 双侧p值
        δ = median([(o - n) / n for o, n in zip(sorted(老客价), sorted(新客价))])
        return {"成立": bool(p < ALPHA_SIG and δ > DELTA_MIN),
                "p": round(p, 4), "价差中位数": round(δ, 4)}

    # ===== 5.4 上影检测：KS分布检验 =====
    @staticmethod
    def 上影检验(申报组: list, 对照组: list) -> dict:
        a, b = sorted(申报组), sorted(对照组)
        n, m = len(a), len(b)
        D, i, j = 0.0, 0, 0
        while i < n and j < m:                                # 双指针求最大分布差
            if a[i] <= b[j]: i += 1
            else: j += 1
            D = max(D, abs(i / n - j / m))
        D临界 = 1.36 * math.sqrt((n + m) / (n * m))           # α=0.05
        return {"成立": D > D临界, "D": round(D, 3), "D临界": round(D临界, 3)}

    # ===== 5.5 授权诱导指数 =====
    @staticmethod
    def 诱导判定(协议字数: int, 停留分钟: float, 默认勾选数: int,
                 授权步骤: int, 撤回步骤: int) -> dict:
        I = (协议字数 / 阅读速度) / max(停留分钟, 1e-6)
        违规项 = []
        if I > 1: 违规项.append("物理上不可能读完")
        if 默认勾选数 > 0: 违规项.append("存在默认勾选")
        if 撤回步骤 > 授权步骤: 违规项.append("撤回难于授权")
        return {"授权有效": not 违规项, "I": round(I, 1), "违规项": 违规项}

    # ===== 5.6 分层抽检密度（含信用修正） =====
    @staticmethod
    def 抽检密度(级别: str, 近12月违规次数: int, 免检: bool) -> float:
        密度 = 基础抽检率[级别] * (1 + 0.5 * 近12月违规次数)
        return min(1.0, 密度 * (0.2 if 免检 else 1.0))

    # ===== 5.7 接入综合判定（与门 + fail-closed） =====
    def 接入判定(self, p: dict) -> dict:
        try:
            C = self.备案覆盖率(p["备案"], p["探测运行"])
            检查 = {
                "备案100%": C >= 1.0,
                "初审通过": p["初审通过"],
                "透明签章": p["透明签章"],
                "授权合规": self.诱导判定(**p["授权参数"])["授权有效"],
                "标识达标": p.get("标识率", 1.0) >= ETA_MIN,
                "母体已整顿": p.get("母体CIVIL_OK", True),
            }
            return {"接入": all(检查.values()),
                    "未过项": [k for k, v in 检查.items() if not v],
                    "level": "ECO_OK" if all(检查.values()) else "DENIED",
                    "dna": self.DNA}
        except Exception as 异常:
            return {"接入": False, "reason": f"🔴 验证异常，默认拒绝: {异常}",
                    "level": "FAIL_CLOSED", "dna": self.DNA}
