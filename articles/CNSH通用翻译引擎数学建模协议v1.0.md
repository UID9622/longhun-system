4.1 智能路由模型（K4/K6落点 · 硬规则+软学习）
```
特征向量: x = (语言, 质量q∈[0,100], 复杂度c∈[0,100], 有DNA∈{0,1}, 可疑度s∈[0,100])

第一步·硬规则筛合法路径集 P(x)（安全规则，学习无权越过）:
  有DNA=1 且 q≥80      → 极速路径 P1 = [DNA验证→极速翻译→输出]
  s > 60               → 强制含 [AI鉴定→来源追溯]（对接BUG-04统一定义）
  q < 50               → 强制含 [代码优化]
  c > 80               → 强制并行 [数学验证]
  c < 20 且 q > 80     → 候选极速 P1
  全部不满足           → 标准路径 P2 = [解析→翻译→质检→输出]

第二步·软学习在 P(x) 内选最优（效率规则，见4.2）:
  选择 p* = argmax_{p∈P(x)} U(p|x)
  效用 U(p|x) = 路径权重W_p × 历史在该特征区间的成功率
设计依据: 安全不可学（硬规则），效率可以学（软学习）——
  前额叶管决策，但脑干管保命，保命的规则不许学习改写。
```

4.2 路径学习（Hedge指数权重 · BUG-06修复）
```
每条候选路径维护权重 W_p（初值1.0），用户反馈 r ∈ [0,1]（满意度/10）:
  更新: W_p ← W_p · e^(η·r) ,  η = 0.1
  边界: W_p ∈ [0.1, 10]（截断，防单路径锁死或锁死他路径）
  衰减: 每周 W_p ← W_p·0.9 + 均匀均值·0.1（遗忘曲线，防历史绑架现在）
防刷三闸:
  ① 单用户反馈速率 ≤ 10次/日，超出丢弃
  ② 反馈账号过七因子（对接评论显化协议5.1），c<0.4的反馈权重×0.05
  ③ 同一(特征,路径)的重复反馈取时间衰减平均，刷量无效
数学性质: Hedge算法在对抗环境下的遗憾界 Regret ≤ O(√(T·ln N))——
  即"最坏情况下，跟最好固定路径的差距增长极慢"，这是"越用越聪明"的严格含义。
```

4.5 复杂度模型（数学大师🧮）
```
静态估算（从AST）:
  循环嵌套深度 d（对输入规模的迭代层数）→ 时间复杂度估计 O(n^d)
  递归无记忆化且分支≥2 → 标记 O(2^n) 风险
  每函数圈复杂度 CC = 判定节点数 + 1
综合评分: c = min(100, 25·d + 10·递归风险 + 2·CC_max/10)
优化触发（原设计保留）: d ≥ 3 或 指数风险 → 协作请求代码优化模块
```

4.6 翻译质量模型（K1落点 · BUG-08修复 · 语义保真天条）
```
4.6.1 语义保留度（核心）:
  SR = 回译后通过的原测试用例数 / 原测试用例总数
  流程: 原代码+测试套件 → 译为CNSH → 回译为源语言 → 跑同一测试套件
  无测试套件时: 用自动生成的边界用例（≥20个）替代，SR标注"自动用例"降级
4.6.2 语法正确率 GR: 译出代码通过目标语言编译/解析 = 1，否则 0（逐文件）
4.6.3 可读性 RR: CNSH规范检查通过率（命名/结构/注释三子项均值）
综合: Q = 0.5·SR + 0.3·GR + 0.2·RR
  Q ≥ 0.85 → 🟢 输出（对接熔断阈值）
  0.70–0.85 → 🟡 输出但附质量警告
  Q < 0.70  → 🔴 拒绝输出，回炉
4.6.4 语言覆盖度: C_lang = 已支持语言语法规则数 / 目标语言语法规则总数
  "翻译所有语言"的诚实刻度：每种语言公示 C_lang，<0.9 不得宣称"支持"
```

  0.85–0.90   → 🟡 警告（对接原熔断条件"准确率<85%"，升级为统计下界版）

鉴定模块同理: 误判率上界 FPR_U = Wilson上界(FPR̂, N) ≥ 15% → 🔴
含义: 不是"这一百次对了85次"就算过——统计上95%置信达标才算过。
```

4.8 压缩双层模型与哈希升级（BUG-01/02修复 · 对接DNA协议）
```

  C(X) = DEFLATE(X) ; 压缩率 R_zip = 1 − |C(X)|/|X|
  性质: 解压即原文，一字不落（对接DNA可逆编码协议第三章）

  摘要层标"可还原" = 虚标 = 违反第2条天条（原HTML代码即踩此线，已修复）

"""

import math, zlib, hashlib

# ---------- 第四章参数（上链公开，修改=修协议） ----------
W_AI   = {"TODO": 0.15, "伪变量": 0.15, "幻觉函数": 0.35, "错而顺": 0.20, "缺导入": 0.15}
THETA  = 1.0          # sigmoid偏置（刻度依据见4.3）
P_可疑 = 0.60         # BUG-04统一阈值
Q_绿, Q_黄 = 0.85, 0.70
ETA, W_MIN, W_MAX = 0.1, 0.1, 10.0


class CNSH_翻译数学引擎:
    DNA = "#龍芯⚡️丙午·乙未·甲午·庚午·䷳艮为山-CNSH-TRANSLATOR-MATH-V1.0"

    # ===== 4.1 硬规则筛路径 =====
    @staticmethod
    def 路由(x: dict) -> dict:
        路径 = ["语言解析"]
        if x["有DNA"] and x["质量"] >= 80:
            return {"路径": ["DNA验证", "极速翻译", "输出"], "通道": "P1极速"}
        if x["可疑度"] > 60:
            路径 += ["AI鉴定", "来源追溯"]
        if x["质量"] < 50:
            路径 += ["代码优化"]
        路径 += ["CNSH翻译", "质量检查", "输出"]
        并行 = ["数学验证"] if x["复杂度"] > 80 else []
        return {"路径": 路径, "并行": 并行, "通道": "P3深度" if x["可疑度"] > 60 else "P2标准"}

    # ===== 4.2 Hedge学习（有界+防刷） =====
    def __init__(self):
        self.W = {}

    def 学习(self, 路径键: str, 满意度: float, 反馈者可信度: float = 1.0) -> float:
        r = max(0.0, min(1.0, 满意度 / 10))
        if 反馈者可信度 < 0.4:                       # 防刷：水军反馈权重×0.05
            r *= 0.05
        W = self.W.get(路径键, 1.0) * math.exp(ETA * r)
        self.W[路径键] = max(W_MIN, min(W_MAX, W))   # 截断防锁死
        return self.W[路径键]

    def 周期衰减(self):
        均值 = sum(self.W.values()) / max(len(self.W), 1)
        for k in self.W:
            self.W[k] = self.W[k] * 0.9 + 均值 * 0.1

    # ===== 4.3 AI鉴定（BUG-04统一定义） =====
    @staticmethod
    def AI鉴定(f: dict) -> dict:
        S = sum(W_AI[k] * f.get(k, 0) for k in W_AI)
        P = 1 / (1 + math.exp(-(S - THETA)))
        return {"P_AI": round(P, 3), "可疑": P >= P_可疑}

    # ===== 4.4 来源相似度 =====
    @staticmethod
    def 相似度(sim_AST: float, sim_edit: float, sim_sem: float) -> dict:
        S = 0.40 * sim_AST + 0.25 * sim_edit + 0.35 * sim_sem
        级别 = "明确来源" if S >= 0.95 else ("疑似来源" if S >= 0.80 else "未找到")
        return {"S_sim": round(S, 3), "级别": 级别}

    # ===== 4.5 复杂度 =====
    @staticmethod
    def 复杂度(嵌套深度: int, 指数递归: bool, CC_max: int) -> dict:
        c = min(100, 25 * 嵌套深度 + (10 if 指数递归 else 0) + CC_max // 5)
        return {"复杂度": c, "触发优化": 嵌套深度 >= 3 or 指数递归}

    # ===== 4.6 翻译质量 =====
    @staticmethod
    def 质量(SR: float, GR: float, RR: float) -> dict:
        Q = 0.5 * SR + 0.3 * GR + 0.2 * RR
        色 = "🟢" if Q >= Q_绿 else ("🟡" if Q >= Q_黄 else "🔴")
        return {"Q": round(Q, 3), "颜色": 色, "放行": Q >= Q_黄}

    # ===== 4.7 Wilson熔断 =====
    @staticmethod
    def 熔断检查(正确数: int, 总数: int, z: float = 1.96) -> dict:
        if 总数 == 0: return {"级别": "🟡", "原因": "无数据"}
        p = 正确数 / 总数
        L = (p + z*z/(2*总数) - z*math.sqrt(p*(1-p)/总数 + z*z/(4*总数**2))) / (1 + z*z/总数)
        级别 = "🟢" if L >= 0.90 else ("🟡" if L >= 0.85 else "🔴")
        return {"acc_L": round(L, 4), "级别": 级别, "熔断": L < 0.85}

    # ===== 4.8 诚实压缩（BUG-01/02修复） =====
    @staticmethod
    def 压缩(原文: str) -> dict:
        X = 原文.encode("utf-8")
        C = zlib.compress(X)
        摘要 = 原文[:100] + ("..." if len(原文) > 100 else "")
        return {
            "无损层": {"数据": C, "压缩率": round((1 - len(C)/len(X)) * 100, 1),
                       "可还原": True},
            "摘要层": {"内容": 摘要, "标注": "【有损摘要，不可还原】", "可还原": False},
            "语义哈希128": hashlib.sha256("金".encode() + X).hexdigest()[:32],
        }
