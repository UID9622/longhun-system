### 第二层：频域盲水印（鲁棒 v4.0）

`engines/lh_media_sovereignty_marker.py` 的 `VideoMarker` 类实现了当前最完整的视频盲水印方案：

**策略**：
- 固定网格（40×22 块），不管输入分辨率多少，先缩放到固定网格再嵌入 → **抗缩放**
- 每帧 Y/Cb/Cr 三通道 DCT 低频系数嵌入指纹 → **抗压缩**
- 32 位同步头（0xA5A5A5A5）+ 160 位指纹 → **抗丢帧/帧率变化**
- 提取时：跨帧中位数投票 + 3σ 离群值剔除 → **抗录屏**
- 双重提取：帧相关索引 → 帧无关索引回退 → **抗帧率变化**
- 自动 CRC32 校验 + 最多 2 位暴力纠错 → **抗信道噪声**
- 音频轨 Patchwork 指纹作为第二重保险 → **视频帧严重破坏时的回退**

**核心参数**：
```python
VIDEO_DCT_BLOCK = 16                # 16×16 DCT 块
VIDEO_DCT_COEFS = [(1,1),(1,2),(2,1)]  # 低频到中频分散系数
VIDEO_DCT_ALPHA_Y = 80.0            # 亮度通道强度
VIDEO_DCT_ALPHA_C = 55.0            # 色度通道强度
GRID_W, GRID_H = 40, 22             # 固定网格 → 缩放不变
SYNC_BITS = 32                       # 帧同步头
```

## 五、熔断机制（系统级，不是视频专用）

`bin/lh_circuit_breaker.py` —— 观澜断路器。三类自动触发：

| 条件 | 阈值 | 锁定时间 |
|:---|:---|:---|
| 连续失败 | 3次 | 600s |
| 越权访问 | 2次 | 600s |
| 异常频率 | >50 req/s | 600s |

状态流转：CLOSED（正常）→ OPEN（熔断）→ HALF_OPEN（试探恢复）→ CLOSED

注意：这是**系统级断路器**，保护的是整个龍魂服务的安全，不是专门为"视频签章缺失"设计的。视频主权验证走的是媒体主权标记引擎的 `extract()` 方法——能提取到 DNA 指纹就是真品，提取不到就是赝品。
