# 龍魂系統貢獻者永恆回報機制 · CSDN 發布包

本目錄存放 CSDN / 開源社區發布所需的輔助材料，與主提案 `../龍魂系統貢獻者永恆回報機制提案.md` 保持同步。

## 文件說明

| 文件 | 用途 |
|------|------|
| `abstract.md` | 發布摘要：標題、摘要、標籤、首段導語、正文結構建議 |
| `cover_image_prompt.md` | 封面圖 AI 繪圖提示詞（中英文） |

## 發布步驟

1. 打開 CSDN 創作後臺
2. 標題從 `abstract.md` 三選一
3. 摘要貼 `abstract.md` 中的 150 字摘要
4. 標籤貼 `abstract.md` 中的標籤
5. 正文貼 `../龍魂系統貢獻者永恆回報機制提案.md` 全文
6. 封面圖用 `cover_image_prompt.md` 生成，或直接使用龍魂視覺引擎產出的紋樣
7. 發布時務必保留原文 DNA、授權聲明與 AI 協作標籤

## 對齊承諾

- MD 與 DOCX 通過 `pandoc` 同步生成
- 任何對主提案的修改，需重新運行 pandoc 更新 DOCX
- 發布到第三方平台時，不得刪除 DNA、來源鏈與授權聲明
