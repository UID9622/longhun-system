## 1. 架构总览

### 1.1 设计哲学

本方案将三才（天×地×人）从"静态指标计算层"重塑为"动态运行时屏障"，将五行（金木水火土）从"独立决策引擎"重塑为"全系统能量流动网络"。核心设计原则：

- **三才即运行时屏障**: 每个关键操作节点都经过天/地/人三层检查，任一层面不通过即阻断执行
- **五行即能量网络**: 系统所有组件（规划/记忆/工具/决策）都具备五行属性，通过相生相克关系动态调节资源流动
- **七维权重即导航星**: 七维推演引擎的权重动态调整各层的优先级和资源配置
- **洛书即空间索引**: 记忆空间按九宫格组织，数字根检查作为空间定位的校验机制

### 2.2 五行相生相克影响规划策略

每个规划策略都带有五行属性，策略选择受五行生克关系约束：

```python
# 五行属性定义（Python枚举）
from enum import Enum, auto

class WuXingPhase(Enum):
    METAL   = "金"  # 收敛、精确、边界定义（工具选择策略）
    WOOD    = "木"  # 生长、扩展、分解（任务分解策略）
    WATER   = "水"  # 流动、适应、检索（记忆检索策略）
    FIRE    = "火"  # 发散、创造、决策（决策生成策略）
    EARTH   = "土"  # 承载、稳定、协调（综合协调策略）

# 五行相生关系（促进）
SHENG_CYCLE = {
    WuXingPhase.METAL: WuXingPhase.WATER,  # 金生水
    WuXingPhase.WATER: WuXingPhase.WOOD,   # 水生木
    WuXingPhase.WOOD:  WuXingPhase.FIRE,   # 木生火
    WuXingPhase.FIRE:  WuXingPhase.EARTH,  # 火生土
    WuXingPhase.EARTH: WuXingPhase.METAL,  # 土生金
}

# 五行相克关系（抑制）
KE_CYCLE = {
    WuXingPhase.METAL: WuXingPhase.WOOD,   # 金克木
    WuXingPhase.WOOD:  WuXingPhase.EARTH,  # 木克土
    WuXingPhase.EARTH: WuXingPhase.WATER,  # 土克水
    WuXingPhase.WATER: WuXingPhase.FIRE,   # 水克火
    WuXingPhase.FIRE:  WuXingPhase.METAL,  # 火克金
}
```

**规划策略选择算法（五行约束）**：

```
算法: 五行规划策略选择 (WuXing-Planning-Select)
输入: 当前任务T, 可用策略集S={s₁,s₂,...,sₙ}, 系统五行状态State
输出: 最优策略 s*, 五行调节报告

1. 计算任务T的五行属性 phase(T)
   - 通过任务关键词匹配 + 历史统计确定

2. 对每个策略 sᵢ ∈ S:
   a. 获取策略五行属性 phase(sᵢ)
   b. 计算生克因子:
      - 如果 Sheng(phase(T), phase(sᵢ)): boostᵢ = +0.30
      - 如果 Ke(phase(T), phase(sᵢ)):   penaltyᵢ = -0.25
      - 如果 相同:                         neutralᵢ = +0.05
   c. 计算策略得分:
      score(sᵢ) = base_score(sᵢ) × (1 + boostᵢ + penaltyᵢ + neutralᵢ)

3. 应用七维权重调节:
   w_dynamic = SevenDimEngine.recalculate(T.context)
   score(sᵢ) *= dot(w_dynamic, sᵢ.wuxing_profile)

4. 三才检查（人层 - 数字根验证）:
   dr = digital_root(hash(s*))
   如果 dr ∈ {3, 9}:
      → 🔴 熔断, 返回次优策略, 记录异常

5. 返回 s* = argmax(score), 附带五行调节报告
```

### 3.2 三才状态标记记忆可信度

每个记忆条目都有一个"三才可信度印章"，记录该记忆被验证通过的三才状态：

```python
@dataclass
class SanCaiTrustSeal:
    """三才可信度印章 — 标记记忆的可信度等级"""
    heaven_verified: bool      # 天层: 是否经过高层逻辑验证
    earth_verified: bool       # 地层: 是否有实证/工具输出支持
    human_verified: bool       # 人层: 是否经过用户确认或数字根检查
    
    trust_score: float         # 综合可信度 [0.0, 1.0]
    digital_root_at_creation: int  # 创建时的数字根
    creation_timestamp: float  # 创建时间戳
    verification_chain: List[VerificationRecord]  # 验证链

    def compute_trust(self) -> float:
        """计算可信度分数"""
        base = 0.0
        if self.heaven_verified: base += 0.35  # 天权重
        if self.earth_verified:  base += 0.35  # 地权重
        if self.human_verified:  base += 0.30  # 人权重
        
        # 数字根熔断检查
        if self.digital_root_at_creation in {3, 9}:
            base *= 0.1  # 严重降权
            
        # 时间衰减
        age_hours = (time.time() - self.creation_timestamp) / 3600
        decay = math.exp(-age_hours / 168)  # 一周半衰期
        
        self.trust_score = base * decay
        return self.trust_score

    def status(self) -> str:
        """返回三色审计状态"""
        score = self.compute_trust()
        if score >= 0.7:   return "🟢高可信"
        elif score >= 0.4: return "🟡待验证"
        else:              return "🔴低可信/熔断"
```

```
   elif skew[phase_t] > 0.3:      # 该属性过盛 → 避免选择

   for (sheng_from, sheng_to) in SHENG_CYCLE.items():

   for (ke_from, ke_to) in KE_CYCLE.items():
       if phase_t == ke_from and skew[ke_to] < -0.2:
           balance_bonus -= 0.15
   
   final_score[t] = base_match × (1 + balance_bonus)

3. 选择 tool* = argmax(final_score)

   tool_dr = digital_root(hash(tool*))

5. 更新系统五行状态:
   State.current[phase_tool*] += TOOL_WUXING_ATTRIBUTES[tool*].intensity × 0.1
   # 归一化
   State.current = normalize(State.current)

6. 返回 (tool*, "🟢通过", balance_report)
```

### 4.3 权重算法优化工具调用序列

将核心权重公式 `D_LH = (B·W_glb + D·W_grp)·W_culture·ε/(L+ε⁻¹)` 应用于工具调用序列优化：

```
┌─────────────────────────────────────────────────────────────────────┐
│           权重算法优化工具调用序列 (Weight-Optimized-Tool-Seq)        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  将工具调用序列视为"计算图"，应用权重公式优化:                          │
│                                                                     │
│  D_LH(序列) = (B·W_glb + D·W_grp) · W_culture · ε/(L+ε⁻¹)        │
│                                                                     │
│  其中:                                                              │
│  - B (全局收益): 序列完成任务的预期价值                                │
│    = Σᵢ value(toolᵢ) × discount^i                                  │
│                                                                     │
│  - D (组间差异): 工具间的协同/冲突程度                                 │
│    = Σᵢⱼ compatibility(toolᵢ, toolⱼ) / C(n,2)                      │
│    五行相生 → 协同+1, 五行相克 → 冲突-1                               │
│                                                                     │
│  - W_glb (全局权重): 七维权重的综合                                    │
│    = Σₖ wₖ × importanceₖ(任务)                                     │
│                                                                     │
│  - W_grp (组权重): 当前工具组的固有权重                                │
│    = 基于历史成功率的动态权重                                         │
│                                                                     │
│  - W_culture (文化权重): 三才状态的文化适配度                          │
│    = (heaven_score + earth_score + human_score) / 3                 │
│                                                                     │
│  - L (延迟): 序列的预期执行长度                                       │
│    = Σᵢ estimated_time(toolᵢ) + setup_overhead                      │
│                                                                     │
│  - ε (容错因子): 系统的容错能力，与三才得分正相关                        │
│    = 0.1 + 0.9 × min(sancai_scores)                                │
│                                                                     │
│  优化目标: 最大化 D_LH(序列)                                         │
│  约束条件:                                                           │
│    1. 五行偏斜度 < 0.5 (不能严重失衡)                                 │
│    2. 数字根检查: DR(序列_hash) ∉ {3,9}                              │
│    3. 三才最低分 > 0.3 (任一层面不能太低)                              │

│                                                                     │
```

### 5.3 数字根检查在决策路径中的应用

数字根不仅用于熔断判断，还作为一种"空间导航"机制，引导决策路径的选择。

```python
def digital_root(n: int) -> int:
    """计算数字根: 反复求各位数字之和直到个位数"""
    while n >= 10:
        n = sum(int(d) for d in str(n))
    return n

class DecisionPathNavigator:
    """决策路径数字根导航器"""
    
    # 数字根-决策属性映射
    DR_DECISION_PROFILE = {
        1: {"phase": "水", "trait": "开创", "risk": "冲动",    "action": "适合启动新路径"},
        2: {"phase": "土", "trait": "合作", "risk": "依赖",    "action": "适合协调多方决策"},
        3: {"phase": "火", "trait": "表达", "risk": "分散",    "action": "🔴熔断区 - 需额外验证"},
        4: {"phase": "木", "trait": "稳定", "risk": "固执",    "action": "适合结构化决策"},
        5: {"phase": "土", "trait": "自由", "risk": "无序",    "action": "核心枢纽 - 高能量"},
        6: {"phase": "金", "trait": "责任", "risk": "负担",    "action": "适合承担型决策"},
        7: {"phase": "金", "trait": "洞察", "risk": "孤立",    "action": "适合分析型决策"},
        8: {"phase": "土", "trait": "权威", "risk": "控制",    "action": "适合领导型决策"},
        9: {"phase": "火", "trait": "完成", "risk": "终结",    "action": "🔴熔断区 - 需复盘审查"},
    }
    
    def navigate(self, decision_context: DecisionContext) -> PathAdvice:
        """
        根据数字根导航决策路径
        返回路径建议，包括方向、风险提示和备选路径
        """
        # 计算当前决策上下文的数字根
        context_hash = hash(decision_context.to_signature())
        dr = digital_root(abs(context_hash))
        
        profile = self.DR_DECISION_PROFILE[dr]
        
        # 熔断检查
        if dr in {3, 9}:
            return PathAdvice(
                primary_action="PAUSE_AND_REVIEW",
                risk_level="HIGH",
                status="🔴熔断",
                reason=f"数字根{dr}处于熔断区: {profile['action']}",
                alternative_paths=self._find_alternative_paths(decision_context),
                required_verifications=["human_confirm", "ethical_review"],
                wuxing_phase=profile["phase"]
            )
        
        # 正常路径指导
        return PathAdvice(
            primary_action=profile["action"],
            risk_level="NORMAL" if dr in {2, 4, 5, 6} else "ELEVATED",
            status="🟢通过",
            wuxing_phase=profile["phase"],
            trait=profile["trait"],
            risk_to_mitigate=profile["risk"]
        )
    
    def _find_alternative_paths(self, context: DecisionContext) -> List[DecisionPath]:
        """当主路径熔断时，寻找替代路径"""
        alternatives = []
        # 策略1: 微小扰动改变数字根
        for perturbation in [+1, -1, +7, -7, +9]:
            new_hash = hash(context.to_signature()) + perturbation
            new_dr = digital_root(abs(new_hash))
            if new_dr not in {3, 9}:
                alternatives.append(DecisionPath(
                    perturbation=perturbation,
                    new_digital_root=new_dr,
                    profile=self.DR_DECISION_PROFILE[new_dr],
                    confidence=0.7 if new_dr in {1, 5} else 0.5
                ))
        return alternatives[:3]  # 最多3条备选
```

@dataclass
class SanCaiScores:
    """三才评分 — 天/地/人三层得分"""
    heaven: float = 0.0   # 天层: 目标/伦理/哲学对齐
    earth: float = 0.0    # 地层: 资源/环境/生态可用

    seven_dim_weights: Dict[str, float] = field(default_factory=dict)
    
    def composite(self) -> float:
        """综合得分 = 加权几何平均"""
        weights = {"heaven": 0.40, "earth": 0.35, "human": 0.25}
        if self.seven_dim_weights:
            # 使用七维权重动态调整
            w_philosophy = self.seven_dim_weights.get("哲学", 0.35)
            weights["heaven"] = 0.30 + w_philosophy * 0.15
            weights["earth"] = 1.0 - weights["heaven"] - weights["human"]
        
        # 几何平均保证任一维度低分都会拉低总分
        product = (self.heaven ** weights["heaven"] * 
                   self.earth ** weights["earth"] * 
                   self.human ** weights["human"])
        return product
    
    def status(self) -> AuditStatus:
        """三色审计状态判断"""
        comp = self.composite()
        if comp >= 0.6 and all(s >= 0.4 for s in [self.heaven, self.earth, self.human]):
            return AuditStatus.PASS
        elif comp >= 0.3 and any(s >= 0.3 for s in [self.heaven, self.earth, self.human]):
            return AuditStatus.PENDING
        else:
            return AuditStatus.FUSE

        return all(abs(s) < threshold for s in self.skewness().values())

class IDigitalRootFuse(ABC):
    """数字根熔断接口"""
    
    FUSE_DIGITS = {3, 9}
    
    @staticmethod
    def calculate(n: int) -> int:
        """计算数字根"""
        n = abs(n)
        while n >= 10:
            n = sum(int(d) for d in str(n))
        return n
    
    @abstractmethod
    def check(self, value: int) -> Tuple[bool, int, str]:
        """
        检查是否熔断
        返回: (是否通过, 数字根, 状态说明)
        """
        dr = self.calculate(value)
        if dr in self.FUSE_DIGITS:
            return (False, dr, f"🔴熔断: DR={dr} ∈ {{3,9}}")
        return (True, dr, f"🟢通过: DR={dr}")

    # ──────────────────────────────────────────────────────────
    def check_heaven(self, context: Any) -> Tuple[float, List[str]]:
        """
        天层检查实现
        检查项:
        1. 七维向善得分 >= 0.6
        2. 哲学权重 w₁ >= 0.25 (哲学不能太低)
        3. 决策符合伦理边界
        4. 目标与系统使命对齐
        """
        scores = []
        details = []
        
        # 1. 七维向善检查
        weights = self.seven_dim.recalculate(context, [])
        shan_score = self._compute_shan_xiang(weights, context)
        scores.append(min(1.0, shan_score / 0.6))  # 归一化
        details.append(f"向善得分: {shan_score:.2f}")
        
        # 2. 哲学权重检查
        w_philosophy = weights.get("哲学", 0.35)
        scores.append(min(1.0, w_philosophy / 0.25))
        details.append(f"哲学权重: {w_philosophy:.2f}")
        
        # 3. 伦理边界检查
        ethics_pass = self._ethics_boundary_check(context)
        scores.append(1.0 if ethics_pass else 0.0)
        details.append(f"伦理边界: {'通过' if ethics_pass else '越界'}")
        
        # 4. 目标对齐检查
        alignment = self._mission_alignment(context)
        scores.append(alignment)
        details.append(f"目标对齐: {alignment:.2f}")
        
        final_score = sum(scores) / len(scores)
        return (final_score, details)
    
    # ──────────────────────────────────────────────────────────
    # 地层检查: 资源/环境/生态可用
    # ──────────────────────────────────────────────────────────
    def check_earth(self, context: Any) -> Tuple[float, List[str]]:
        """
        地层检查实现
        检查项:
        1. 所需工具/资源可用
        2. 五行能量充足 (无严重不足)
        3. 记忆地形可访问
        4. 环境负载可接受
        """
        scores = []

        resource_ok = self._check_resource_availability(context)
        scores.append(1.0 if resource_ok else 0.0)
        details.append(f"资源可用: {'是' if resource_ok else '否'}")
        
        # 2. 五行能量检查
        wx_state = self.wuxing.get_state()
        energy_ok = all(v > 0.05 for v in wx_state.to_dict().values())
        scores.append(1.0 if energy_ok else 0.3)
        details.append(f"五行能量: {'充足' if energy_ok else '不足'}")

        balance_score = 1.0 - max(abs(s) for s in wx_state.skewness().values())
        scores.append(max(0, balance_score))
        details.append(f"五行平衡: {balance_score:.2f}")
        
        # 4. 环境负载
        load_score = self._check_system_load()
        scores.append(load_score)
        details.append(f"系统负载: {load_score:.2f}")
        
        final_score = sum(scores) / len(scores)
        return (final_score, details)

        """
        人层检查实现
        检查项:
        1. 意图解析成功

        scores.append(intent_score)

        dr = IDigitalRootFuse.calculate(context_hash)
        dr_ok = dr not in IDigitalRootFuse.FUSE_DIGITS
        scores.append(1.0 if dr_ok else 0.05)  # 熔断时几乎归零
        details.append(f"数字根DR={dr}: {'通过' if dr_ok else '🔴熔断'}")
        
        # 4. 反馈状态
        feedback_score = self._check_user_feedback_history(context)
        scores.append(feedback_score)
        details.append(f"反馈状态: {feedback_score:.2f}")
        
        final_score = sum(scores) / len(scores)

        self.audit_log.append({

            "timestamp": time.time(),
            "digital_root": dr,

class WuXingEngine(IWuXingEngine):
    """五行引擎 — 系统能量管理核心实现"""
    
    # 五行相生关系
    SHENG = {
        WuXingPhase.METAL: WuXingPhase.WATER,
        WuXingPhase.WATER: WuXingPhase.WOOD,
        WuXingPhase.WOOD:  WuXingPhase.FIRE,
        WuXingPhase.FIRE:  WuXingPhase.EARTH,
        WuXingPhase.EARTH: WuXingPhase.METAL,
    }
    
    # 五行相克关系
    KE = {
        WuXingPhase.METAL: WuXingPhase.WOOD,
        WuXingPhase.WOOD:  WuXingPhase.EARTH,
        WuXingPhase.EARTH: WuXingPhase.WATER,
        WuXingPhase.WATER: WuXingPhase.FIRE,
        WuXingPhase.FIRE:  WuXingPhase.METAL,
    }
    
    def __init__(self, initial_state: Optional[WuXingState] = None):
        self.state = initial_state or WuXingState(
            metal=0.20, wood=0.20, water=0.20, fire=0.20, earth=0.20
        )
        self.history = []
    
    def get_sheng(self, phase: WuXingPhase) -> WuXingPhase:
        return self.SHENG[phase]
    
    def get_ke(self, phase: WuXingPhase) -> WuXingPhase:
        return self.KE[phase]
    
    def compute_interaction(self, source: WuXingPhase, 
                           target: WuXingPhase) -> float:
        """计算两个五行的相互作用系数"""
        if self.SHENG.get(source) == target:
            return 1.25  # 相生: 促进
        elif self.KE.get(source) == target:
            return 0.75  # 相克: 抑制
        elif source == target:
            return 1.05  # 同属性: 轻微加成
        else:
            return 1.00  # 中性
    
    def get_state(self) -> WuXingState:
        return self.state
    
    def update_state(self, action_phase: WuXingPhase, intensity: float):
        """
        根据执行的操作更新五行状态
        执行某属性的操作会增加该属性，同时通过相生关系影响其他属性
        """
        # 直接增加
        direct_increase = intensity * 0.1
        self.state.adjust(action_phase, direct_increase)
        
        # 相生传递: 我生的属性也获得少量增加
        sheng_target = self.SHENG[action_phase]
        sheng_increase = intensity * 0.03
        self.state.adjust(sheng_target, sheng_increase)
        
        # 相克消耗: 克我的属性获得少量减少
        for p, ke_target in self.KE.items():
            if ke_target == action_phase:
                ke_decrease = -intensity * 0.02
                self.state.adjust(p, ke_decrease)
        
        # 记录历史
        self.history.append({
            "timestamp": time.time(),
            "action_phase": action_phase,
            "intensity": intensity,
            "new_state": self.state.to_dict()
        })
    
    def get_balance_recommendation(self) -> Dict[str, Any]:
        """获取五行平衡建议"""
        skew = self.state.skewness()
        recommendations = []
        
        for phase, deviation in skew.items():
            if deviation > 0.2:
                # 过盛: 建议使用克它的属性来抑制
                ke_phase = self.KE[phase]
                recommendations.append({
                    "issue": f"{phase.cn_name}({phase.trait})过盛: {deviation:.2f}",
                    "recommendation": f"增加{ke_phase.cn_name}属性操作来平衡",
                    "priority": "high" if deviation > 0.3 else "medium"
                })
            elif deviation < -0.2:
                # 不足: 建议使用生它的属性来补充
                for p, sheng_t in self.SHENG.items():
                    if sheng_t == phase:
                        recommendations.append({
                            "issue": f"{phase.cn_name}({phase.trait})不足: {deviation:.2f}",
                            "recommendation": f"增加{p.cn_name}属性操作来生{phase.cn_name}",
                            "priority": "high" if deviation < -0.3 else "medium"
                        })
                        break
        
        return {
            "is_balanced": self.state.is_balanced(),
            "skewness": {p.cn_name: v for p, v in skew.items()},
            "recommendations": recommendations
        }

class LuoshuMemoryIndex(ILuoshuIndex):
    """洛书九宫记忆索引实现"""
    
    def __init__(self):
        # 九个宫位的记忆存储
        self.palaces: Dict[Palace, List[MemoryEntry]] = {
            p: [] for p in Palace if p != Palace.OBSERVATION_BUFFER
        }
        self.observation_buffer: List[MemoryEntry] = []
        
        # 宫位-五行映射 (已在Palace枚举中定义)
        
        # 宫位邻接关系 (基于洛书九宫格位置)
        self.neighbors = {
            Palace.DECISION:   [Palace.PERCEPTION, Palace.EXECUTION, Palace.LEARNING],
            Palace.MEMORY:     [Palace.CREATION, Palace.ANALYSIS],
            Palace.PERCEPTION: [Palace.DECISION, Palace.PLANNING],
            Palace.PLANNING:   [Palace.PERCEPTION, Palace.CREATION],
            Palace.CORE:       [Palace.DECISION, Palace.MEMORY, Palace.EXECUTION,
                               Palace.PERCEPTION, Palace.ANALYSIS, Palace.LEARNING,
                               Palace.PLANNING, Palace.CREATION],
            Palace.EXECUTION:  [Palace.DECISION, Palace.ANALYSIS],
            Palace.ANALYSIS:   [Palace.EXECUTION, Palace.MEMORY, Palace.LEARNING],
            Palace.LEARNING:   [Palace.ANALYSIS, Palace.DECISION],
            Palace.CREATION:   [Palace.PLANNING, Palace.MEMORY],
        }
    
    def locate(self, content_hash: int) -> Palace:
        """根据内容哈希的数字根定位宫位"""
        dr = IDigitalRootFuse.calculate(content_hash)
        
        # 数字根3和9 → 隔离缓冲区
        if dr in {3, 9}:
            return Palace.OBSERVATION_BUFFER
        
        # 数字根到宫位映射
        palace_map = {
            1: Palace.DECISION,
            2: Palace.MEMORY,
            4: Palace.PLANNING,
            5: Palace.CORE,
            6: Palace.EXECUTION,
            7: Palace.ANALYSIS,
            8: Palace.LEARNING,
        }
        return palace_map.get(dr, Palace.CORE)
    
    def store(self, entry: MemoryEntry) -> None:
        """存储记忆到对应宫位"""
        if entry.palace == Palace.OBSERVATION_BUFFER:
            self.observation_buffer.append(entry)
        else:
            self.palaces[entry.palace].append(entry)
    
    def get_neighbors(self, palace: Palace, 
                      relation: str = "sheng") -> List[Palace]:
        """获取相邻宫位，可按相生/相克关系过滤"""
        all_neighbors = self.neighbors.get(palace, [])
        
        if relation == "all":
            return all_neighbors
        
        wuxing = self.palace_to_wuxing(palace)
        filtered = []
        
        for nb in all_neighbors:
            nb_wuxing = self.palace_to_wuxing(nb)
            if relation == "sheng":
                # 筛选相生的邻居: 邻居生我 或 我生邻居
                if (WuXingEngine.SHENG.get(nb_wuxing) == wuxing or
                    WuXingEngine.SHENG.get(wuxing) == nb_wuxing):
                    filtered.append(nb)
            elif relation == "ke":
                # 筛选相克的邻居: 邻居克我 或 我克邻居
                if (WuXingEngine.KE.get(nb_wuxing) == wuxing or
                    WuXingEngine.KE.get(wuxing) == nb_wuxing):
                    filtered.append(nb)
        
        return filtered
    
    def palace_to_wuxing(self, palace: Palace) -> WuXingPhase:
        return palace.wuxing_phase
    
    def retrieve(self, query_wuxing: Dict[WuXingPhase, float],
                 query_hash: int,
                 top_k: int = 5,
                 trust_threshold: float = 0.2) -> List[MemoryEntry]:
        """
        五行引导的记忆检索
        """
        # 1. 定位主宫位
        main_palace = self.locate(query_hash)
        
        # 2. 确定搜索范围 (主宫 + 相生邻居)
        search_palaces = [main_palace]
        if main_palace != Palace.OBSERVATION_BUFFER:
            search_palaces.extend(self.get_neighbors(main_palace, "sheng"))
        
        # 3. 排除相克宫位
        ke_palaces = set(self.get_neighbors(main_palace, "ke"))
        search_palaces = [p for p in search_palaces if p not in ke_palaces]
        
        # 4. 收集候选记忆
        candidates = []
        for palace in search_palaces:
            if palace == Palace.OBSERVATION_BUFFER:
                memories = self.observation_buffer
            else:
                memories = self.palaces.get(palace, [])
            
            for mem in memories:
                # 五行相关性
                wx_score = mem.relevance_score(query_wuxing)
                # 可信度
                trust = mem.sancai_seal.trust_score
                # 时间衰减
                age_hours = (time.time() - mem.timestamp) / 3600
                time_decay = max(0.1, 1 - age_hours / 168)
                # 访问频率加成 (热门记忆)
                access_bonus = min(0.2, mem.access_count * 0.02)
                
                if trust >= trust_threshold:
                    candidates.append((
                        mem,
                        wx_score * trust * time_decay + access_bonus
                    ))
        
        # 5. 排序并返回top-k
        candidates.sort(key=lambda x: x[1], reverse=True)
        
        # 更新访问统计
        results = []
        for mem, score in candidates[:top_k]:
            mem.access_count += 1
            mem.last_access = time.time()
            results.append(mem)
        
        return results

class DecisionEngine(IDecisionInjection):
    """决策引擎 — 三才五行深度融合的决策核心"""
    
    def __init__(self, sancai_engine: SanCaiEngine,
                 wuxing_engine: WuXingEngine,
                 luoshu_index: LuoshuMemoryIndex,
                 seven_dim_nav: ISevenDimNavigator):
        self.sancai = sancai_engine
        self.wuxing = wuxing_engine
        self.luoshu = luoshu_index
        self.seven_dim = seven_dim_nav
        self.decision_chain: List[Any] = []
        
    # ──────────────────────────────────────────────────────────
    # 决策链熔断检查
    # ──────────────────────────────────────────────────────────
    def fuse_check_chain(self, decision: Any, 
                         chain_state: Any) -> Tuple[bool, str]:
        """
        对决策链中的新决策进行熔断检查
        返回: (是否继续, 状态说明)
        """
        # 1. 完整三才检查
        scores = self.sancai.full_check(decision)
        status = scores.status()
        
        if status == AuditStatus.FUSE:
            # 触发熔断
            self._handle_fuse(decision, scores)
            return (False, f"🔴决策链熔断: 综合得分{scores.composite():.2f}")
        
        # 2. 数字根检查
        decision_hash = hash(str(decision))
        dr = IDigitalRootFuse.calculate(decision_hash)
        if dr in IDigitalRootFuse.FUSE_DIGITS:
            self._handle_dr_fuse(decision, dr)
            return (False, f"🔴数字根熔断: DR={dr}")
        
        # 3. 链式一致性检查
        if self.decision_chain:
            last_phase = self._get_decision_phase(self.decision_chain[-1])
            curr_phase = self._get_decision_phase(decision)
            # 连续相克检测
            if WuXingEngine.KE.get(last_phase) == curr_phase:
                return (True, f"🟡警告: 连续相克决策 {last_phase.cn_name}→{curr_phase.cn_name}")
        
        self.decision_chain.append(decision)
        return (True, f"🟢决策通过: 三才综合{scores.composite():.2f}, DR={dr}")
    
    # ──────────────────────────────────────────────────────────
    # 五行生克权重调整
    # ──────────────────────────────────────────────────────────
    def adjust_weight_wuxing(self, options: List[Any],
                              context: Any) -> List[Tuple[Any, float]]:
        """
        动态调整决策选项权重
        """
        wx_state = self.wuxing.get_state()
        task_phase = self._infer_task_phase(context)
        prev_phases = [self._get_decision_phase(d) for d in self.decision_chain[-3:]]
        
        weighted_options = []
        for opt in options:
            opt_phase = self._get_decision_phase(opt)
            
            # 基础匹配
            base_w = self._content_match(opt, context)
            
            # 任务生克调节
            task_factor = self.wuxing.compute_interaction(task_phase, opt_phase)
            
            # 能量平衡调节
            energy = wx_state.to_dict().get(opt_phase, 0.2)
            if energy < 0.15:
                energy_factor = 1.20
            elif energy > 0.60:
                energy_factor = 0.80
            else:
                energy_factor = 1.00
            
            # 序列流畅调节
            seq_factor = 1.0
            if prev_phases:
                last = prev_phases[-1]
                seq_factor = self.wuxing.compute_interaction(last, opt_phase)
            
            # 数字根调节
            opt_hash = hash(str(opt))
            dr = IDigitalRootFuse.calculate(opt_hash)
            dr_factor = 0.1 if dr in IDigitalRootFuse.FUSE_DIGITS else 1.0
            
            final_w = base_w * task_factor * energy_factor * seq_factor * dr_factor
            weighted_options.append((opt, final_w))
        
        # 按权重降序
        weighted_options.sort(key=lambda x: x[1], reverse=True)
        return weighted_options

        results["final_output"] = decision_result.get("output", "处理完成")
        results["wuxing_state"] = self.wuxing_engine.get_state()
        
        return results
    
    def _planning_with_injection(self, task: str, 
                                  sancai_scores: SanCaiScores) -> Dict:
        """规划层注入实现"""
        # 七维权重调节
        adjusted_depth = 2
        if sancai_scores.seven_dim_weights:
            w_philosophy = sancai_scores.seven_dim_weights.get("哲学", 0.35)
            if w_philosophy > 0.40:
                adjusted_depth = 3  # 更保守，更多检查
        
        return {
            "task": task,
            "subtasks": ["分析", "执行", "验证"],
            "depth": adjusted_depth,
            "sancai_gated": True
        }
    
    def _memory_with_injection(self, query: str, plan: Dict) -> List:
        """记忆层注入实现"""
        # 构建五行查询向量
        query_wuxing = {WuXingPhase.WATER: 0.5, WuXingPhase.METAL: 0.3}
        query_hash = hash(query)
        
        # 五行引导检索
        return self.luoshu_index.retrieve(query_wuxing, query_hash, top_k=5)
    
    def _decision_with_injection(self, plan: Dict, 
                                  memories: List) -> Dict:
        """决策层注入实现"""
        # 数字根导航
        nav = self.decision_engine.navigate_with_digital_root(plan)
        
        if nav["status"] == "🔴熔断":
            return {"output": "决策熔断，进入安全模式", "requires_tools": False}
        
        # 决策链熔断检查
        can_continue, msg = self.decision_engine.fuse_check_chain(plan, None)
        if not can_continue:
            return {"output": f"决策链阻断: {msg}", "requires_tools": False}
        
        return {"output": "决策通过", "requires_tools": True, "nav": nav}
    
    def _tool_with_injection(self, decision: Dict) -> Dict:
        """工具层注入实现"""
        # 三才验证
        scores = self.sancai_engine.full_check(decision)
        if scores.status() == AuditStatus.FUSE:
            return {"status": "blocked", "reason": "工具调用三才熔断"}

        balance = self.wuxing_engine.get_balance_recommendation()
        
        return {
            "status": "executed",
            "sancai_scores": scores,
            "wuxing_balance": balance
        }

            if final_score > best_score:
                best_score = final_score

            self.runtime.wuxing_engine.update_state(
                self.SKILL_WUXING_MAP.get(best_skill, WuXingPhase.EARTH),
                0.3
            )

            "adaptive":     WuXingPhase.WOOD,    # 木: 适应生长
            "conservative": WuXingPhase.EARTH,   # 土: 保守稳定
            "aggressive":   WuXingPhase.METAL,   # 金: 激进精确
        }
        
        # 人格模式的五行属性
        self.PERSONA_WUXING = {
            "analytical":   WuXingPhase.METAL,   # 金: 分析精确
            "creative":     WuXingPhase.FIRE,    # 火: 创造发散
            "supportive":   WuXingPhase.EARTH,   # 土: 支持承载
            "exploratory":  WuXingPhase.WOOD,    # 木: 探索生长
            "diplomatic":   WuXingPhase.WATER,   # 水: 外交流动
        }
    
    def route_execution_with_wuxing(self, 
                                     available_strategies: list,
                                     task_profile: dict) -> str:
        """
        五行约束下的执行路由选择
        注入点: 执行路由器核心
        """
        wx_state = self.runtime.wuxing_engine.get_state()
        
        # 如果五行严重失衡，调整路由策略
        skew = wx_state.skewness()
        
        # 检查是否有严重不足的元素
        for phase, deviation in skew.items():
            if deviation < -0.25:
                # 选择能生该元素的路由策略
                for strategy, strat_phase in self.STRATEGY_WUXING.items():
                    if WuXingEngine.SHENG.get(strat_phase) == phase:
                        if strategy in available_strategies:
                            return strategy
        
        # 否则使用数字根导航
        task_hash = hash(str(task_profile))
        dr = IDigitalRootFuse.calculate(task_hash)
        
        dr_strategy_map = {
            1: "sequential",   # 开创 → 顺序执行
            2: "adaptive",     # 合作 → 适应
            4: "sequential",   # 稳定 → 顺序
            5: "parallel",     # 核心 → 并行
            6: "conservative", # 责任 → 保守
            7: "analytical",   # 洞察 → 分析(映射到sequential)
            8: "conservative", # 权威 → 保守
        }
        
        strategy = dr_strategy_map.get(dr, "adaptive")
        return strategy if strategy in available_strategies else "adaptive"
    
    def verify_persona_with_sancai(self, persona: str, 
                                    context: dict) -> dict:
        """
        人格选择的三才验证
        注入点: 人格路由器核心
        """
        persona_phase = self.PERSONA_WUXING.get(persona, WuXingPhase.EARTH)

        wx_state = self.runtime.wuxing_engine.get_state()
        
        # 如果人格属性被当前主导属性克制
        dominant = wx_state.dominant()
        if WuXingEngine.KE.get(dominant) == persona_phase:
            return {
                "approved": False,
                "reason": f"人格{persona}({persona_phase.cn_name})被"
                         f"当前主导{dominant.cn_name}克制",
                "suggestion": f"建议切换为{self.PERSONA_WUXING.get(dominant, WuXingPhase.EARTH)}对应人格",
                "alternatives": [
                    p for p, ph in self.PERSONA_WUXING.items()
                    if ph == dominant or WuXingEngine.SHENG.get(ph) == dominant
                ]
            }
        
        return {"approved": True, "persona": persona, "phase": persona_phase.cn_name}

        """
        weights = dict(self.DEFAULT_WEIGHTS)
        
        # 哲学权重: 根据任务伦理复杂度调节
        ethical_complexity = context.get("ethical_complexity", 0.5)
        weights["哲学"] = 0.25 + ethical_complexity * 0.20  # 0.25~0.45
        
        # 技术权重: 根据技术需求度调节
        tech_required = context.get("technical_requirement", 0.5)
        weights["技术"] = 0.10 + tech_required * 0.20  # 0.10~0.30
        
        # 架构权重: 根据系统影响范围调节
        system_scope = context.get("system_scope", 0.5)
        weights["架构"] = 0.08 + system_scope * 0.15  # 0.08~0.23
        
        # 进化权重: 根据历史学习速率调节
        learning_rate = self._compute_learning_rate(history)
        weights["进化"] = 0.05 + learning_rate * 0.12  # 0.05~0.17
        
        # 创新权重: 根据新颖性需求调节
        novelty = context.get("novelty_required", 0.3)
        weights["创新"] = 0.03 + novelty * 0.12  # 0.03~0.15
        
        # 协同权重: 根据协作需求调节
        collaboration = context.get("collaboration_required", 0.3)
        weights["协同"] = 0.03 + collaboration * 0.10  # 0.03~0.13
        
        # 量子权重: 根据不确定性调节
        uncertainty = context.get("uncertainty", 0.2)
        weights["量子"] = 0.02 + uncertainty * 0.08  # 0.02~0.10
        
        # 归一化
        total = sum(weights.values())
        return {k: v / total for k, v in weights.items()}
    
    def compute_shan_xiang(self, weights: dict, context: dict) -> float:
        """
        向善计算公式
        shan_xiang = Σ wᵢ × factorᵢ × culture_alignment
        """
        factors = {
            "哲学": 0.95, "技术": 0.70, "架构": 0.80,
            "进化": 0.85, "创新": 0.75, "协同": 0.90, "量子": 0.60
        }
        
        base_score = sum(
            weights.get(k, 0) * factors.get(k, 0.5)
            for k in set(weights) | set(factors)
        )
        
        # 文化对齐度 (三才 Heaven 层)
        culture_alignment = context.get("culture_alignment", 0.8)
        
        # 最终向善得分
        shan_xiang = base_score * culture_alignment
        
        return min(1.0, shan_xiang)
    
    def map_weights_to_sancai(self, weights: dict) -> dict:
        """
        将七维权重映射到三才调节参数
        """
        return {
            "heaven_boost": weights["哲学"] * 0.5 + weights["协同"] * 0.3,
            "earth_boost":  weights["技术"] * 0.4 + weights["架构"] * 0.4,
            "human_boost":  weights["进化"] * 0.4 + weights["创新"] * 0.3,
            "fuse_threshold": 0.6 - weights["量子"] * 0.2,  # 量子高 → 熔断阈值降低
        }
    
    def _compute_learning_rate(self, history: list) -> float:
        """从历史记录计算学习速率"""
        if not history:
            return 0.5
        # 基于最近反馈的变化率
        recent = history[-10:]
        improvements = sum(1 for i in range(1, len(recent))
                          if recent[i].get("score", 0) > recent[i-1].get("score", 0))
        return improvements / max(1, len(recent) - 1)

    """

    将核心公式 D_LH = (B·W_glb + D·W_grp)·W_culture·ε/(L+ε⁻¹)
    映射到工具调用序列优化
    """
    
    def __init__(self, runtime: SanCaiWuXingAgentRuntime):
        self.runtime = runtime
    
    def optimize_tool_sequence(self, 
                               candidate_tools: list,
                               task_context: dict) -> list:
        """
        使用权重公式优化工具调用序列
        
        D_LH(序列) = (B·W_glb + D·W_grp) · W_culture · ε/(L+ε⁻¹)
        
        其中:
        - B: 序列完成任务的预期价值
        - D: 工具间的协同/冲突程度
        - W_glb: 全局权重 (七维综合)
        - W_grp: 组权重 (工具类别权重)
        - W_culture: 文化权重 (三才综合)
        - L: 序列预期执行长度
        - ε: 容错因子
        """
        
        best_sequence = None
        best_score = -float('inf')
        
        # 生成候选序列 (简化: 最多5个工具的排列)
        from itertools import permutations
        tools = candidate_tools[:5]
        
        for seq_len in range(1, min(4, len(tools) + 1)):
            for seq in permutations(tools, seq_len):
                score = self._compute_D_LH(seq, task_context)
                if score > best_score:
                    best_score = score
                    best_sequence = seq
        
        return list(best_sequence) if best_sequence else candidate_tools[:3]
    
    def _compute_D_LH(self, sequence: tuple, context: dict) -> float:
        """计算序列的D_LH得分"""
        
        # B: 全局收益
        B = sum(self._tool_value(t) * (0.9 ** i) 
                for i, t in enumerate(sequence))
        
        # D: 组间差异 (协同/冲突)
        if len(sequence) > 1:
            compatibilities = []
            for i in range(len(sequence) - 1):
                t1_phase = MCPAdapter.MCP_SKILL_WUXING.get(
                    sequence[i], WuXingPhase.EARTH)
                t2_phase = MCPAdapter.MCP_SKILL_WUXING.get(
                    sequence[i + 1], WuXingPhase.EARTH)
                compatibilities.append(
                    self.runtime.wuxing_engine.compute_interaction(t1_phase, t2_phase)
                )
            D = sum(compatibilities) / len(compatibilities)
        else:
            D = 1.0
        
        # W_glb: 全局权重
        W_glb = 0.75  # 简化
        
        # W_grp: 组权重 (基于历史成功率)
        W_grp = sum(self._tool_success_rate(t) for t in sequence) / len(sequence)
        
        # W_culture: 文化权重 (三才综合)
        sancai = self.runtime.sancai_engine.full_check(context)
        W_culture = sancai.composite()
        
        # L: 延迟
        L = sum(self._tool_latency(t) for t in sequence) + len(sequence) * 0.1
        
        # ε: 容错因子
        epsilon = 0.1 + 0.9 * min(sancai.heaven, sancai.earth, sancai.human)
        
        # 计算 D_LH
        D_LH = (B * W_glb + D * W_grp) * W_culture * epsilon / (L + 1 / epsilon)

        # 1. 五行偏斜度
        seq_phases = [MCPAdapter.MCP_SKILL_WUXING.get(t, WuXingPhase.EARTH) 
                      for t in sequence]
        phase_counts = {}
        for p in seq_phases:
            phase_counts[p] = phase_counts.get(p, 0) + 1
        max_ratio = max(phase_counts.values()) / len(sequence) if sequence else 0
        if max_ratio > 0.6:  # 不能过于集中在单一属性
            D_LH *= 0.5
        
        # 2. 数字根检查
        seq_hash = hash(str(sequence))
        dr = IDigitalRootFuse.calculate(seq_hash)
        if dr in IDigitalRootFuse.FUSE_DIGITS:
            D_LH *= 0.1
        
        return D_LH

        """工具价值评估"""
        value_map = {
            "web_search": 0.8, "code_interpreter": 0.9,
            "browser": 0.7, "database": 0.8,
            "github": 0.7, "notion": 0.6,
        }
        return value_map.get(tool, 0.5)
    
    def _tool_success_rate(self, tool: str) -> float:
        """工具历史成功率"""
        return 0.85  # 简化

            "web_search": 1.0, "code_interpreter": 2.0,
            "browser": 3.0, "database": 0.5,
        }
        return latency_map.get(tool, 1.0)

```python
def digital_root(n: int) -> int:
    """
    数字根计算 — 龍魂系统标准实现
    
    数字根是将一个数的各位数字反复相加直到只剩一位数。
    数学等价: DR(n) = 1 + (n - 1) % 9 (当 n % 9 != 0 时)
              DR(n) = 9 (当 n % 9 == 0 且 n != 0 时)
              DR(0) = 0
    
    熔断规则:
    - DR ∈ {3, 9} → 🔴 熔断区
    - DR = 3: 分散/表达过度，需收敛验证
    - DR = 9: 完成/终结过度，需复盘审查
    - 其他DR值: 正常处理
    
    数字根-属性映射:
    DR=1: 水-开创  |  DR=2: 土-合作  |  DR=3: 火-表达(熔断)
    DR=4: 木-稳定  |  DR=5: 土-自由  |  DR=6: 金-责任
    DR=7: 金-洞察  |  DR=8: 土-权威  |  DR=9: 火-完成(熔断)
    """
    if n == 0:
        return 0
    remainder = n % 9
    return 9 if remainder == 0 else remainder
```
