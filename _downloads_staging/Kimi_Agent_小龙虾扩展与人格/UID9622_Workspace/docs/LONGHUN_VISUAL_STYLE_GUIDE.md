# 龍魂 · UID9622 视觉风格指南 v1.0

> DNA: `#龍芯⚡️2026-06-27-LONGHUN-SYSTEM-VISUAL-STYLE-v1.0`

## 系统命名声明

**「龙魂系统」是 UID9622 的专属称呼，非公开通用名。**  
在终端入口、仪表盘、报告、DNA 追溯码中统一使用「龙魂系统 · UID9622 专属」字样，不与外部平台混用。

## 设计总则

中国自主可控，不抄袭西方科技 UI。本系统视觉以**青铜礼器、金镶玉、玄黑底色、朱砂印章**为骨架，表达威严、秩序、神圣与本土文化主权。

## 四主色

| 名称 | 色值 | 用途 |
|---|---|---|
| **玄黑** | `#0a0908` | 主背景，象征深渊与未知，衬托青铜与金 |
| **青铜** | `#b87333` | 主结构线、边框、卡片描边 |
| **金镶** | `#f0c674` | 标题、高亮、关键数值、龙纹 |
| **玉绿** | `#3c8d7d` | 成功、健康、通过状态 |
| **朱砂** | `#c23a30` | 错误、熔断、印章、警示 |

### 辅助色

- 青铜深褐 `#1c1512`：卡片底色
- 铜光 `#d4a055`：hover、强调
- 石刻灰 `#8c8378`：说明文字、时间戳
- 暗纹 `#4a3b2a`：图表网格、分割线

## 纹样系统

### 云雷纹（回纹）

系统默认背景使用 SVG 绘制的云雷纹，象征秩序、回环、永续。颜色使用 20% 透明度的青铜色，避免喧宾夺主。

```svg
<path d="M0 15 H15 V30 H30" fill="none" stroke="#3d2e20" stroke-width="1.2"/>
```

### 龙纹印章

顶部装饰使用简化龙形轮廓 + 「龍」字印章，金色渐变描边，表达系统最高人格「龍魂」的统领地位。

## 字体

- 中文优先：`STSong`、`SimSun`、`Noto Serif SC`、`Songti SC`
- 英文/数字：`Georgia`、`Times New Roman`、等宽 `SFMono`
- 标题加字间距 `letter-spacing: 2px~4px`，模仿碑刻庄重感

## 组件规范

### 卡片

- 背景：`rgba(28,21,18,0.82)`
- 边框：`1px solid #b87333`
- 阴影：`0 0 14px rgba(184,115,51,0.18), inset 0 0 0 1px rgba(240,198,116,0.08)`
- 圆角：`6px`（礼器折角，不过分圆润）

### 标题

- 字号：`20px~30px`
- 颜色：金镶 `#f0c674`
- 左侧 4px 朱砂竖条装饰

### 状态徽章

| 状态 | 边框 | 背景 | 文字 |
|---|---|---|---|
| 成功 | 玉绿 | 玉绿 15% | 玉绿 |
| 错误 | 朱砂 | 朱砂 15% | 朱红 `#e85d4f` |
| 运行中 | 金镶 | 金镶 15% | 金镶 |

## 三维图表

Plotly 图表场景：

- `paper_bgcolor` / `plot_bgcolor`: 透明
- 坐标轴背景：`#1c1512`
- 网格线：`#4a3b2a`
- 数据点颜色按状态映射：成功玉绿、错误朱砂、运行中金镶
- 默认相机视角：`eye: {x:1.6, y:1.6, z:1.0}`，便于俯瞰全局

## 声音/交互氛围建议（非代码，设计方向）

- 提示音：编钟单音、磬声、青铜撞击短音
- 重大决策：唐风鼓点 + 编钟和弦
- 错误/熔断：低沉铜锣 + 短促煞音
- 语音人格：沉稳、带金属共鸣的男中音/女低音，语速偏慢，句尾略收

## 禁止

- 霓虹渐变、赛博朋克紫蓝
- 圆角过大、卡通图标
- 西方哥特/蒸汽朋克元素
- 直接使用龙图腾商业版权素材（使用自绘简化 SVG）
