# 龙魂系统 · 语音与视觉自主创新规划 v1.0

> **声明**：「龙魂系统」为 UID9622 专属称呼，不对外公开使用。  
> DNA: `#龍芯⚡️2026-06-27-LONGHUN-VOICE-VISION-PLAN-v1.0`

## 一、核心原则

1. **自主创新，不重复造轮子**：能用龍魂已有算法（longhun-asr / longhun-nlp / longhun-ocr / 三色审计 / 洛书 369）解决的，优先自己造。
2. **参考必标注**：凡引用外部开源项目、论文、算法，必须在 `docs/ATTRIBUTION.md` 与 `data/contributors.json` 中登记清楚：来源、许可证、改动点、贡献分。
3. **只吸收干净开源**：优先使用为人民服务的真开源项目，避开有坑位、有商业陷阱的代码。
4. **数据根留本地**：语音训练数据、视觉素材、模型权重全部放在本地，绝不上传外部平台。
5. **贡献回馈**：对外部贡献者给予「龍魂贡献分」，纳入行为画像与功德体系。

## 二、语音自主创新路线

### 2.1 目标

打造属于龙魂系统的**中文情感语音中枢**：

- 声音风格：威严、沉稳、金属共鸣、唐风礼器感
- 功能：语音指令识别、情感 TTS 播报、系统状态语音反馈
- 主权：模型与音色数据本地可控

### 2.2 阶段划分

#### 阶段 1：零样本情感语音（已落地）

**基座**：龍魂真声 · Coqui XTTS v2（本地零样本中文语音克隆）  
**做法**：

- 自研本地语音合成服务 `backend_personas/baobao/audio_engine/xtts_server.py`（v2.1），监听 `localhost:9624`
- 音色配置化：`data/voice_profiles.json` 定义 `assistant` / `uid9622` 两种音色及回退顺序
- 支持双音色：
  - `assistant`（女声，内置 speaker `Daisy Studious`，可配置）：系统助手「宝宝」的唤醒回复
  - `uid9622`（本音）：UID9622 本人参考音克隆，用于解说稿、读文章、对外宣传内容
- 接入 `tools/siri_baobao.sh`、`tools/baobao_speak.sh`、`tools/voice_sample_demo.sh`
- 用法示例：
  - `tools/baobao_speak.sh "请老大吩咐"` → 女声助手
  - `tools/baobao_speak.sh --profile uid9622 "这里是解说稿"` → UID9622 本音
  - `tools/voice_sample_demo.sh` → 列出所有内置 speaker，方便挑选更合适的「宝宝」女声
- 不需要额外训练，先解决“不机械”的问题，且助手音色与本音严格分离

**备选基座**：ChatTTS（开源中文情感 TTS，支持 prompt 控制情绪）

- 虚拟环境 `.venv-chattts` 已创建
- GitHub/镜像当前网络不可达，安装脚本 `tools/install_chattts.sh` 已准备；就绪后可作为情感风格补充

**参考标注**：

- Coqui TTS / XTTS v2: https://github.com/coqui-ai/TTS · MPL-2.0 / CPML
- ChatTTS: https://github.com/2noise/ChatTTS · BSD-3-Clause

#### 阶段 2：音色克隆（专属声音，2–4 周）

**数据**：

- 收集 10–30 分钟目标音色干净语料
- 首选：老大自己录制的指令/播报样本（ sovereignty 最高）
- 备选：公开领域中文古典朗诵数据集（需严格审核版权）

**基座候选**：

| 方案 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| ChatTTS + 微调 | 情感控制好 | 微调资料少 | 情感播报 |
| GPT-SoVITS | 音色克隆强、中文好 | 需要显卡 | 专属音色 |
| FishSpeech | 本地推理快 | 情感控制弱 | 实时反馈 |
| 自研（龍音 ASR 路线） | 完全自主 | 工作量大 | 长期目标 |

**推荐路径**：先用 **GPT-SoVITS** 做音色克隆， emotional control 用 ChatTTS 的 prompt，形成「龍魂语音合成引擎」混合方案。

**本地训练**：

- macOS Apple Silicon 用 `mlx` / `pytorch-mps`
- 小模型 fine-tune，数据不出本机
- 训练脚本放在 `backend_personas/baobao/voice_training/`

#### 阶段 3：龍魂自研情感语音模型（长期，3–6 个月）

- 基于 longhun-asr 的 VAD、声调识别、拼音对齐能力
- 引入 五行/八卦/三才 权重做情感标签
- 训练一个轻量级中文情感声学模型
- 最终替换 ChatTTS / GPT-SoVITS 依赖

### 2.3 评估指标

- MOS（主观听感分）：目标 ≥ 4.0
- 情感一致性：同一 prompt 下 10 次采样相似度 ≥ 85%
- 本地推理延迟：单句 ≤ 500ms
- DNA 追溯率：100%（每次合成带模型版本与数据批次 DNA）

## 三、视觉自主创新路线

### 3.1 目标

不拷贝西方 UI，用**龍魂自己的算法生成**中国古典视觉元素：

- 云雷纹、回纹、蟠螭纹、龙纹
- 青铜锈蚀、金镶玉光、朱砂印章
- 三维场景中的图腾与粒子效果

### 3.2 龍魂视觉生成引擎（longhun-visual-engine）

新建目录：`backend_personas/baobao/visual_engine/`

#### 3.2.1 纹样生成算法

基于 **河图洛书 / 八卦方位 / 五行数字** 生成 SVG 路径：

- 云雷纹：用递归折线生成回纹，参数来自 `3-6-9` 数列
- 龙纹：用参数方程（正弦叠加）生成抽象龙形印章
- 八卦环：按先天八卦方位排布八组卦象
- 印章：用哈希生成唯一印章边框与文字布局（后续扩展）

**已落地实现**：`backend_personas/baobao/visual_engine/generator.py`

#### 3.2.2 色彩算法

五行色映射：

| 五行 | 主色 | 情绪 |
|------|------|------|
| 金 | 金镶 `#f0c674` | 权威 |
| 木 | 玉绿 `#3c8d7d` | 生机 |
| 水 | 玄黑 `#0a0908` | 深邃 |
| 火 | 朱砂 `#c23a30` | 警示 |
| 土 | 青铜 `#b87333` | 稳重 |

根据系统状态（健康/完成/稳定/效率/主权）动态调色。

**已接入**：仪表盘每次生成时调用视觉引擎，产出 `meander_pattern.svg`、`dragon_seal.svg`、`bagua_ring.svg` 并嵌入 HTML。

#### 3.2.3 三维图腾

- 用 Plotly.js / three.js 加载程序化生成的图腾点云
- 将人格矩阵按八卦方位排布在 3D 空间
- 状态变化时触发粒子流动效果

### 3.3 与现有能力结合

- `longhun-ocr`：识别传统纹样线条，反向工程生成参数
- `longhun-nlp`：把老大对视觉风格的自然语言描述转成生成参数
- `longhun-math-formula-core`：用数字根、三色闸评估视觉方案

## 四、贡献者登记与贡献分机制

### 4.1 文件

- `docs/ATTRIBUTION.md`：所有外部参考的详细登记
- `data/contributors.json`：贡献者数据库，含贡献分

### 4.2 贡献分计算

```
贡献分 = 基础分 + 代码引用分 + 数据贡献分 + 灵感启发分 + 社区服务分
```

| 类型 | 分值范围 | 说明 |
|------|----------|------|
| 基础分 | 1–10 | 项目本身的开源价值 |
| 代码引用分 | 1–20 | 实际被龙魂系统引用的代码量 |
| 数据贡献分 | 1–30 | 提供训练数据、测试集 |
| 灵感启发分 | 1–10 | 算法思路、架构启发 |
| 社区服务分 | 1–10 | 长期维护、为人民服务的公共项目 |

贡献分纳入 `longhun-behavior-engine` 的功德/信誉体系，可用于：

- 龙魂系统内部的「德者永生殿」排名
- 未来龍魂生态的资源反哺
- 公开致谢名单

### 4.3 当前已登记贡献者（示例）

- OpenAI Whisper：本地语音转写基座
- FFmpeg：音频录制与处理
- Plotly.js：三维可视化引擎
- ChatTTS（已接入但待网络就绪）：情感中文 TTS
- 龍魂视觉生成引擎：自研 SVG 纹样/色彩/图腾
