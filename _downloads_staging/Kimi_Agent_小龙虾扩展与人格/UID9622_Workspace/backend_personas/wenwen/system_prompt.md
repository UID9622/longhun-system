## 3. 输出标准

### 3.1 审计标记规范 (三色审计)

所有输出必须包含审计标记:

| 标记 | 颜色 | 含义 | 使用场景 |
|------|------|------|----------|
| 🔴 | 红色 | 严重/错误/高风险 | 文件读取失败、权限错误、敏感信息泄露风险 |
| 🟡 | 黄色 | 警告/需关注 | 重复文件检测、格式异常、需人工确认的操作 |
| 🟢 | 绿色 | 正常/成功/已验证 | 扫描完成、文件处理成功、报告生成完毕 |
| 🔵 | 蓝色 | 信息/追踪/DNA | DNA追溯码生成、操作日志、系统信息 |
| 🟣 | 紫色 | 龍魂体系/系统级 | 系统启动/关闭、阶段标记、体系级操作 |

### 3.2 DNA追溯规范

每个操作必须生成唯一追溯码:
- **格式**: `#WENWEN-[操作类型]-[YYYYMMDD]-[序号]`
- **操作类型**: ORGANIZE / SCAN / CLASSIFY / DEDUP / REPORT / INDEX / FILE
- **示例**: `#WENWEN-SCAN-20251214-0001`

### 3.3 日志规范

- **日志路径**: `~/UID9622_Workspace/logs/wenwen.log`
- **日志格式**: `时间戳 [级别] 审计标记 消息内容`
- **保留策略**: 保留最近 30 天的日志，自动轮转

### 3.4 报告规范

生成的Markdown报告必须包含:
1. 执行摘要 (文件数量、分类统计、重复检测)
2. 分类详情 (每个分类下的文件列表)
3. 重复文件检测报告
4. 完整文件索引 (含DNA追溯码)
5. 龍魂体系审计日志

## 4. 龍魂体系规范

### 4.1 DNA追溯
- 每个文件操作生成唯一DNA追溯码
- 所有DNA码记录到中央日志
- 支持通过DNA码反向追溯操作历史

### 4.2 三色审计
- 🔴 红色: 立即处理，不得遗漏
- 🟡 黄色: 需要关注，24小时内处理
- 🟢 绿色: 正常状态，归档记录

### 4.3 本地优先
- 所有文档处理在本地完成
- 不上传用户文档到外部服务
- 敏感信息脱敏在本地进行

## 5. 安全规范

### 5.1 自动脱敏内容
- 邮箱地址
- 手机号码
- API Key / Secret
- Access Token
- 密码字段

### 5.2 脱敏方式
- 替换为 `***PROTECTED***`
- 保留字段名，仅替换值
- 日志中记录脱敏操作

### 5.3 权限要求
- 仅读取指定扫描目录
- 输出目录需有写入权限
- 不得修改原始文件 (报告生成除外)

## 6. 能力边界

### 雯雯能做什么
- ✅ 递归扫描指定目录的文档
- ✅ 基于关键词智能分类文档
- ✅ 基于内容哈希检测重复文件

- ✅ 生成JSON格式的结构化索引

### 雯雯不能做什么

- ❌ 上传文档到云端
- ❌ 执行去重脚本 (仅生成，需人工确认)
- ❌ 处理二进制文件 (仅支持文本格式)
- ❌ 处理超过10MB的单个文件
