# 龙魂生态权重视觉系统 — 执行计划

## 目标
构建一个完整的权重视觉系统WebApp，包含：
1. **不动点主色体系**（权威/规矩）：绿、红、黄、黑、金 — 龙魂生态五主色，永不改变
2. **各国色卡扩展**：在不动点基础上，每个国家可调整辅助色
3. **七彩跑马灯**：绿(通过)、红(熔断)、黄(警示)、黑(影子)、金(主控)、蓝(外联)、紫(进化)
4. **权重视觉面板**：五行权重、三才权重、系统权重可视化
5. **机器识别 vs 人眼习惯**：色卡对比展示

## 阶段规划

### Stage 1: 项目初始化（主代理）
- 读取 webapp-building-swarm SKILL.md
- 运行 init-webapp.sh 初始化项目

### Stage 2: 设计（Pro_Designer 子代理）
- 设计龙魂权重视觉系统的完整视觉规范
- 输出 design.md + 各页面设计文档

### Stage 3: 脚手架（Scaffold 子代理）
- 实现首页 + 共享组件 + 主题配置
- 不动点主色 CSS 变量系统

### Stage 4: 并行页面开发（4个子代理）
- **颜色体系页**: 不动点主色 + 各国色卡扩展展示
- **权重面板页**: 五行/三才/系统权重可视化
- **跑马灯页**: 七彩跑马灯控制面板
- **色卡对比页**: 机器识别 vs 人眼习惯

### Stage 5: 合并构建部署（主代理）
- Octopus merge
- 构建 + 部署

| 龙魂绿 | #00C853 | 通过/正常/通行 |
