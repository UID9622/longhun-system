## §4 文化主权符号详情

### 4.1 易经体系（标准 Unicode）

- **64 个六爻卦象**：U+4DC0 ~ U+4DFF，含卦名（乾、坤、屯、蒙……未济）
- **8 个八卦符号**：U+2630 ~ U+2637（☰ ☱ ☲ ☳ ☴ ☵ ☶ ☷）
- **太极图**：U+262F ☯
- **两仪符号**：U+268A ~ U+268B（阳仪/阴仪）
- 脚本：`scripts/expand_yijing_symbols.py`

### 4.2 五行 · 河图 · 洛书（PUA U+E000 ~ U+E007）

| 编码 | 名称 |
|---|---|
| U+E000 | 金 |
| U+E001 | 木 |
| U+E002 | 水 |
| U+E003 | 火 |
| U+E004 | 土 |
| U+E005 | 河图 |
| U+E006 | 洛书 |
| U+E007 | 太极八卦 |

- 脚本：`scripts/expand_wuxing_hetu_luoshu.py`

### 4.3 甲骨文（PUA U+E100 ~ U+E136）

55 个高频甲骨文字形：日、月、山、水、火、土、石、田、雨、雪、人、大、天、王、父、母、子、女、夫、老、木、禾、草、虫、鱼、鸟、犬、牛、羊、马、鹿、虎、龙、凤、龟、刀、弓、矢、戈、鼎、门、户、井、邑、卜、占、吉、凶、东、西、南、北、上、下、中。

- 脚本：`scripts/expand_oracle_bone.py`

### 4.4 中国风文化图标（PUA U+E200 ~ U+E21C）

29 个图标：龙纹、凤纹、祥云、灯笼、红包、饺子、竹子、莲花、茶杯、筷子、扇子、宝塔、山水、波浪、梅花、明月、风铃、鞭炮、风筝、锦鲤、月饼、酒坛、笛子、大鼓、门楼，以及哲学关键字「道」「德」「无」「自然」。

- 脚本：`scripts/expand_chinese_culture.py`
