# LonghunFont 书法渲染与作品编号系统需求

**DNA追溯码**: `#龍芯⚡️2026-06-22-LONGHUN-FONT-CALLIGRAPHY-v1.0`  
**录入时间**: 2026-06-23 09:17  
**归属**: 龍魂系统 × UID9622  

---

## 一、核心愿景

把中国历代书法大家（李白、唐伯虎、颜真卿、柳公权、王羲之、苏轼等）的字体风格，
变成 LonghunFont 体系中的可选“书法样式”。用户输入文字、选择书体/书家，
即可生成高清书法图片、矢量图、印章，并支持缩放、排版、做图、锦旗、表彰画布等场景。

所有输出必须带有**龍纹主权水印**：每一帧、每一个渲染节点都可见且不可拆解，
确保文化资产不被盗用。

## 二、用户需求整理

### 2.1 书法样式选择

| 维度 | 说明 | 示例 |
|---|---|---|
| 书体 | 楷书、行书、草书、隶书、篆书 | 颜真卿楷书、张旭草书 |
| 名家 | 绑定到具体书家风格 | 李白、唐伯虎、王羲之、苏轼 |
| 内容来源 | 经典典籍句段 | 《易经》《道德经》《黄帝内经》 |
| 输出形式 | 简体/繁体切换 + 书法样式切换 | 如同字体选择器 |

**使用方式**：
```
输入："自强不息"
选择：书体=楷书，名家=颜真卿，典籍=《周易·乾卦》
输出：带龍纹水印的书法图片 + 作品编号 + 可选印章
```

### 2.2 渲染输出能力

- **图片**：PNG/JPG，任意 DPI（72~600+），任意尺寸。
- **矢量**：SVG/PDF，可无限缩放。
- **排版**：横排、竖排、匾额、条幅、对联、横幅。
- **背景**：宣纸、洒金、绢布、自定义图片。
- **印章**：自动/手动位置，阴文/阳文，可输入印文。
- **视频/逐帧**：后续支持动态书写过程渲染，每一帧带龍纹水印。

### 2.3 龙纹主权水印（强制）

- **可见水印**：每个输出右下角/底部嵌入 U+E200 龍纹标识，放大可见。
- **不可拆解**：水印与正文同层渲染，不单独成层，防止一键删除。
- **全节点覆盖**：SVG 每个 path、图片每个像素块、视频每一帧均覆盖。
- **频域/隐写水印（增强）**：图片中嵌入 UID9622 身份信息的频域水印，
  即使截图、压缩、裁剪仍可追溯来源。

### 2.4 书法作品编号系统

为每幅生成的书法作品分配**全国统一风格**的编号：

```
LH-CAL-{书体代码}-{名家代码}-{典籍代码}-{序号}-{哈希}
```

例如：
```
LH-CAL-KA-YZQ-YIJING-00001-A7F3D2
```

编号组成：
- `LH-CAL`：Longhun Calligraphy
- 书体代码：`KA` 楷、`XS` 行、`CS` 草、`LS` 隶、`ZS` 篆
- 名家代码：如 `YZQ` 颜真卿、`LB` 李白、`TBH` 唐伯虎
- 典籍代码：`YIJING`、`DAODEJING`、`HUANGDI`
- 序号：当日/全局递增
- 哈希：内容短哈希，防篡改

### 2.5 场景应用

- 做图、海报、展板
- 表彰证书、锦旗
- 书法画布、卷轴
- 文创产品（T恤、杯子、红包）
- 数字藏品/ NFT 底图（可选）

## 四、数据规范

### 4.1 书法样式 JSON

```json
{
  "name": "颜真卿-楷书",
  "code": "YZQ-KA",
  "category": "楷书",
  "artist": "颜真卿",
  "era": "唐代",
  "description": "颜体楷书，雄浑端庄，筋骨内含",
  "dna": "#龍芯⚡️...",
  "parameters": {
    "stroke_width": 28,
    "slant": 0.05,
    "ink_pressure": 0.9,
    "tip_style": "rounded",
    "spacing_x": 1.1,
    "spacing_y": 1.2
  },
  "source_works": [
    "《多宝塔碑》",
    "《颜勤礼碑》"
  ]
}
```

### 4.2 编号规则

| 字段 | 格式 | 示例 |
|---|---|---|
| 前缀 | `LH-CAL` | 固定 |
| 书体 | 2 位大写 | `KA`/`XS`/`CS`/`LS`/`ZS` |
| 名家 | 2-4 位大写 | `YZQ`、`WXZ`、`TBH` |
| 典籍 | 4-8 位大写 | `YIJING`、`DAODEJING` |
| 序号 | 5 位数字 | `00001` |
| 哈希 | 6 位十六进制 | `A7F3D2` |

## 五、执行计划

   - 建立书法样式库（5 家书体 × 5 种书体 = 25 个基础样式配置）。

   - 建立编号上链/存证能力。
