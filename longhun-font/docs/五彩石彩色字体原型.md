# LonghunFont 五彩石彩色字体原型

**DNA追溯码**: `#龍芯⚡️丙午·甲午·丁卯·丙午·䷚颐-LONGHUN-FONT-WUWU-COLOR-v1.0`

---

## 设计目标

女娲五彩石是 LonghunFont 的文化核心标识：红、黄、青、白、黑五色，对应五行、五方、五德。
为了让五色石在**所有系统、所有应用、无需额外 CSS/JS** 的前提下直接生效，
我们制作了基于 OpenType `COLR`/`CPAL` 标准的彩色字体原型 `LonghunFont-WuwuColor.otf`。

它与单色版 `LonghunFont-Regular.otf` 并行存在：
- **单色版**：兼容 Office/PDF/印刷，保证最大可用性。
- **彩色原型版**：用于系统级文化展示、标题、海报、品牌标识，五色石直接嵌入字形。

---

## 技术规格

| 项目 | 规格 |
|---|---|
| 格式 | OpenType CFF + COLR v0 + CPAL v0 |
| 文件 | `output/LonghunFont-WuwuColor.otf` |
| 色带数量 | 每个字形 5 层 |
| 颜色顺序（从左到右）| 红 `#FF0000` → 黄 `#FFFF00` → 青 `#00FFFF` → 白 `#FFFFFF` → 黑 `#000000` |
| 当前子集 | 默认 `红黄青白黑龍魂字体`，可自定义 |
| 兼容性 | Windows 10+/macOS 10.13+/iOS 13+/Android 8+（支持 COLR v0 的系统） |

## 生成方法

### 使用 Makefile
```bash
make demo-color
# 输出 output/LonghunFont-WuwuColor.otf
```

### 使用脚本
```bash
python3 scripts/build_wuwu_color_font.py \
    glyphs/龍魂字元库_v0019_龍纹书法版.json \
    output/LonghunFont-WuwuColor.otf \
    "龍魂字体红黄青白黑"
```

第三个参数是要生成彩色字形的字符子集。子集中的每个字符会生成：
- 1 个基础单色字形（后备，用于不支持 COLR 的系统）。
- 5 个图层字形，分别用五色填充。

## 安装与预览

### macOS
```bash
cp output/LonghunFont-WuwuColor.otf ~/Library/Fonts/
# 然后在 Pages / Keynote / 浏览器中输入子集中的字符
```

### Windows
右键点击字体文件 → 安装，或在设置 → 字体中拖入。

### Web
```css
@font-face {
  font-family: 'LonghunFontWuwuColor';
  src: url('LonghunFont-WuwuColor.otf') format('opentype');
}

h1 {
  font-family: 'LonghunFontWuwuColor', sans-serif;
  font-size: 72px;
}
```

## 当前限制

1. **原型阶段**：v1.0 使用纵向五色带作为色彩表达，尚未对每个笔画的内部区域进行精确五彩石纹理填充。
2. **文件体积**：当前子集很小；若对全部 28957 个字元生成彩色版，体积会大幅增长，后续需做按需子集化。
3. **COLR v0**：优先使用最广泛兼容的 v0；未来可考虑 COLR v1 的渐变与组合能力，实现更丰富的五彩石效果。

## 与 Wuwu 渲染层的关系

| 方案 | 技术层 | 优点 | 缺点 |
|---|---|---|---|
| `LonghunFont-WuwuColor.otf` | 字体内部 COLR/CPAL | 系统级、无脚本、Office 可用 | 体积大、彩色逻辑固定 |
| `css/wuwu.css` + `js/wuwu.js` | 渲染层 | 灵活、可动画、Web 可控 | 需要运行时支持 |
| `@uid9622/wuwu-renderer` | npm/小程序组件 | 跨端统一、可定制 | 依赖框架集成 |

推荐组合：单色版 + Wuwu 渲染层做日常；彩色版做品牌/海报/系统级强调。
