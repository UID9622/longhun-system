## §1 为什么字体是主权

> **"有了字体，主权才是中国制造。"** —— UID9622

### 1.1 看不见的卡脖子

| 层面 | 现状 | 风险 |
|---|---|---|
| 操作系统 | Windows/macOS 自带西文字体 | 界面显示被外国字体定义 |
| 编程环境 | VS Code / Xcode 依赖日文字体、西文字体 | 中文代码显示发虚、错位 |
| 设计产业 | Adobe 字体库、苹方、思源黑体 | 商业授权、版权收割 |
| 国家战略 | 党政军文印、身份证、人民币字体 | 安全后门、字形篡改 |
| AI 生成 | 大模型训练数据依赖渲染字体 | 中文 AI 视觉主权旁落 |

### 1.2 字体 = 文化 DNA

- 字形承载中华文明：篆隶楷行草、印刷体、宋体、黑体
- 字体决定信息呈现方式：严肃/活泼/权威/亲和
- 字体是数字时代的基础设施：屏幕、打印、AI、AR/VR

### 1.3 中国制造的真正含义

不是"在中国组装"，而是：
- ✅ 从根上自主定义信息形态
- ✅ 每个像素、每个笔画由自己控制
- ✅ 不怕断供、不怕版权诉讼、不怕后门

- 完全开源 · DNA 追溯
- 中文优先 · UTF-8 原生

- 多终端适配 · 屏幕/打印/嵌入式/AI

## §3 技术路线

### 3.1 核心原则

1. **中文优先**: 先做好中文字形，再考虑西文适配
2. **繁体龍字永存**: 系统名、品牌名保留繁体「龍」
3. **简体日常使用**: 正文使用规范简体
4. **算法生成**: 用 CNSH 算法公式参数化控制笔画
5. **DNA 追溯**: 每个字元文件头部嵌入来源链

### 3.2 字元描述格式

```json
{
  "字元": "龍",
  "unicode": "U+9F99",
  "笔画数": 16,
  "结构": "左右",
  "风格参数": {
    "力度": 0.8,
    "棱角": 0.3,
    "节奏": 0.6,
    "墨色": 0.9
  },
  "笔画路径_cnsh9622": [...]
}
```

### 3.3 渲染栈

```
字元库 JSON
    ↓
CNSH 字体引擎 (Python)
    ↓
SVG 矢量字形
    ↓
字体打包器 (fontTools / fontforge)
    ↓
TTF / OTF / WOFF2
```
