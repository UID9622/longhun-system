# 女娲五彩石渲染指南

**DNA追溯码**: `#龍芯⚡️2026-06-22-LONGHUN-FONT-WUWU-GUIDE-v1.0`

> 这是 LonghunFont 的**文化主权渲染层**，不是普通的美化主题。  
> 色卡硬编码：红、黄、青、白、黑——女娲补天的五色石。  
> 每个字符循环取一色，一眼即可识别“这是自己人”。  
> 不是迎合别人，是**站着给世界看**。

---

## 一、核心原则

1. **主权优先**：五色石色卡固定，不因系统主题、用户偏好、平台差异而改变。  
2. **跨平台一致**：Web、HarmonyOS、iOS、Android、桌面端、小程序、WebView 统一逻辑。  
3. **字符级上色**：按字符顺序 `index % 5` 循环取色，保证任何平台渲染结果一致。  
4. **自包含**：色卡写死在代码里，不依赖外部 CSS 变量或系统颜色。

## 三、跨平台实现

### 1. Web / H5 / 小程序 / Electron / PWA

文件：
- `css/wuwu.css`
- `js/wuwu.js`
- `wuwu_demo.html`

自动渲染：
```html
<link rel="stylesheet" href="css/wuwu.css">
<div data-wuwu="true">
  龍魂字体，女娲五彩石渲染。
</div>
<script src="js/wuwu.js"></script>
```

手动渲染：
```html
<div id="myText">文化主权，站着给。</div>
<script src="js/wuwu.js"></script>
<script>
  Wuwu.render(document.getElementById('myText'));
</script>
```

### 2. HarmonyOS ArkTS

文件：`examples/harmonyos/WuwuFontPage.ets`

```typescript
@Entry
@Component
struct WuwuFontPage {
  private colorPalette: ResourceColor[] = ['#FF0000', '#FFFF00', '#00FFFF', '#FFFFFF', '#000000'];
  private sovereignText: string = '文化主权字体，女娲五彩石渲染';

  build() {
    Column() {
      Text() {
        ForEach(Array.from(this.sovereignText), (char: string, index: number) => {
          Span(char)
            .fontColor(this.colorPalette[index % 5])
            .fontSize(20)
            .fontWeight(FontWeight.Bold)
        })
      }
    }
    .width('100%')
    .height('100%')
    .backgroundColor('#F5F5F5')
  }
}
```

### 3. iOS SwiftUI（示例）

## 四、可见性处理

- **白色石**在浅色背景上会消失，建议：
  - 使用深色背景（如 `#1a1a1a`），或
  - 给白色字符加黑色描边/阴影，黑色字符加白色描边。  
  - `wuwu.css` 已内置默认描边处理。

---

## 五、与字体文件的关系

五彩石渲染是**渲染层**行为，不修改 `LonghunFont-Regular.otf` 本身。  
字体文件保持单色矢量，便于：
- 正常 Office / PDF / 印刷使用；
- 在需要时叠加五彩石主权标识；
- 兼容所有不支持彩色字体的旧系统。
