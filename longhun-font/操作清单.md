## 三、如果要改字体

### 1. 修改字元库
文件位置：
```
/Users/zuimeidedeyihan/longhun-system/longhun-font/glyphs/龍魂字元库_v0018_龍纹书法版.json
```

### 2. 重新生成 OTF 字体（龍纹书法版）
```bash
cd /Users/zuimeidedeyihan/longhun-system/longhun-font
make build
# 或手动：python3 scripts/build_font.py glyphs/龍魂字元库_v0018_龍纹书法版.json output/LonghunFont-Regular.otf
```

生成后的字体文件：
```
output/LonghunFont-Regular.otf
```

### 3. 重新渲染全部样张
```bash
cd /Users/zuimeidedeyihan/longhun-system/longhun-font
make render
# 或手动：python3 scripts/batch_render.py glyphs/龍魂字元库_v0018_龍纹书法版.json output/all_glyphs_v0018
```

### 4. 校验字元库
```bash
cd /Users/zuimeidedeyihan/longhun-system/longhun-font
make check
# 或手动：python3 scripts/check_font.py glyphs/龍魂字元库_v0018_龍纹书法版.json
```

### 5. 一键发布（校验+构建+渲染+提交+标签+双仓推送）
```bash
cd /Users/zuimeidedeyihan/longhun-system/longhun-font
./scripts/release.sh v0018
```

### 6. 龍纹水印 + 书法骨架 + 五彩石渲染说明
- v0015 起：每个字形右下角嵌入 U+E200「龙纹」缩微水印；
- v0016 起：全部 CJK 汉字升级书法风格占位骨架；
- v0017 起：新增女娲五彩石渲染层，跨平台统一五色石色卡；
- v0018 起：书法骨架升级为曲线版（二次贝塞尔 + 双端笔锋），并发布 `@uid9622/wuwu-renderer` npm/小程序包。
如需标准骨架/无水印版，可回退到 v0013/v0014/v0015/v0016/v0017 字元库。

### 7. 安装字体
- **macOS**
  ```bash
  cd /Users/zuimeidedeyihan/longhun-system/longhun-font
  ./install_macos.sh
  ```
- **Windows**
  双击运行或在 CMD/PowerShell 中执行：
  ```bat
  install_windows.bat
  ```

### 8. Web 演示
用浏览器打开：
```
/Users/zuimeidedeyihan/longhun-system/longhun-font/output/demo.html
/Users/zuimeidedeyihan/longhun-system/longhun-font/wuwu_demo.html
```

### 9. 女娲五彩石渲染
Web 端直接给元素加 `data-wuwu="true"`：
```html
<link rel="stylesheet" href="css/wuwu.css">
<div data-wuwu="true">文化主权，站着给。</div>
<script src="js/wuwu.js"></script>
```
HarmonyOS 示例见 `examples/harmonyos/WuwuFontPage.ets`。

### 10. 手动同步到发布仓库（如果不用 release.sh）
