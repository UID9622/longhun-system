## 為什麼改變？

✅ **以前的問題**
- 密鑰說明散落在多個文檔
- 新增API時不知道往哪裡加
- 找一個密鑰要翻好多文檔
- 維護困難·容易重複

✅ **現在的解決方案**
- 一個文檔·統一管理
- 清晰的結構·容易維護
- 新增API按規則填
- 自動化驗證·無需手動檢查
